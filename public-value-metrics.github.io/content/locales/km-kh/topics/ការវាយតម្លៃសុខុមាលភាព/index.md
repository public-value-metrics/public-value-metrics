# ការវាយតម្លៃសុខុមាលភាព (WELLBY)

ការវាយតម្លៃសុខុមាលភាព (wellbeing valuation) កំណត់តម្លៃឥទ្ធិពលរបស់គោលនយោបាយដោយផ្ទាល់ជាលក្ខខណ្ឌការពេញចិត្តក្នុងជីវិត ដោយប្រើ WELLBY (ឆ្នាំជីវិតកែតម្រូវតាមសុខុមាលភាព) ជាឯកតា ដែល WELLBY មួយស្មើនឹងការផ្លាស់ប្តូរមួយពិន្ទុលើមាត្រដ្ឋានការពេញចិត្តក្នុងជីវិត 0–10 ដែលស្ថិតស្ថេរមួយឆ្នាំ។ វាជាជម្រើសដែលអនុម័តជាផ្លូវការរបស់ HM Treasury ជំនួសឱ្យការបម្លែងអត្ថប្រយោជន៍ទាំងអស់ជាប្រាក់តាមឆន្ទៈក្នុងការបង់។

## ហេតុអ្វីបានជាសំខាន់

"Wellbeing guidance for appraisal: supplementary Green Book guidance" របស់ HM Treasury (2021,
<https://www.gov.uk/government/publications/green-book-supplementary-guidance-wellbeing>)
បាននាំទិន្នន័យសុខុមាលភាពប្រធានបទចូលក្នុងការវាយតម្លៃរបស់រដ្ឋាភិបាលកណ្តាលជាផ្លូវការ ផ្តល់ឱ្យអ្នកវិភាគនូវផ្លូវដើម្បីវាយតម្លៃលទ្ធផល គឺទំនាក់ទំនងសង្គម សុខភាពផ្លូវចិត្ត សុវត្ថិភាព ការចូលរួមស៊ីវិល ដែលវិធីសាស្ត្រ[ចំណូលចិត្តដែលបានប្រកាស](../ការវាយតម្លៃតាមចំណូលចិត្តដែលបានប្រកាស/) និង[ចំណូលចិត្តដែលបានបង្ហាញ](../ការវាយតម្លៃតាមចំណូលចិត្តដែលបានបង្ហាញ/) ពិបាកកំណត់តម្លៃឱ្យគួរឱ្យជឿ ពីព្រោះមនុស្សជារឿយៗជាអ្នកព្យាករមិនល្អថា ទំនិញនឹងប៉ះពាល់ការពេញចិត្តក្នុងជីវិតរបស់ពួកគេប៉ុណ្ណា។ ការណែនាំនេះ ដែលបង្កើតរួមគ្នាជាមួយ What Works Centre for Wellbeing កំណត់តម្លៃជាប្រាក់ដែលណែនាំក្នុងមួយ WELLBY គឺ £13,000 (តម្លៃឆ្នាំ 2021 កែសម្រួលតាមកាលកំណត់) ដែលបានមកពីទំនាក់ទំនងដែលបានសង្កេតក្នុងការស្ទង់មតិសុខុមាលភាពធំៗ (ជាពិសេស Annual Population Survey របស់ ONS ដែលបានសួរសំណួរសុខុមាលភាព ONS4 ទាំងបួនតាំងពីឆ្នាំ 2011) រវាងប្រាក់ចំណូល និងការពេញចិត្តក្នុងជីវិត ផ្តល់ឱ្យអ្នកវិភាគនូវអត្រាបម្លែងត្រឡប់ទៅជាផោន នៅពេលត្រូវការការប្រៀបធៀបជាប្រាក់ធៀបនឹងការវាយតម្លៃ Green Book ផ្សេងទៀត។

វិធីសាស្ត្រនេះសំខាន់ ពីព្រោះវាបញ្ច្រាសតក្កវិជ្ជាវាយតម្លៃធម្មតា៖ ជាជាងសួរថាមនុស្សនឹងបង់ប៉ុន្មានសម្រាប់លទ្ធផល (ចំណូលចិត្តដែលបានប្រកាស) ឬសន្និដ្ឋានតម្លៃពីប្រតិបត្តិការទីផ្សារដែលទាក់ទង (ចំណូលចិត្តដែលបានបង្ហាញ) វាវាស់ឥទ្ធិពលរបស់លទ្ធផលលើការពេញចិត្តក្នុងជីវិតដែលរាយការណ៍ដោយផ្ទាល់ ដោយចៀសវាងគម្លាតរវាងអ្វីដែលមនុស្សនិយាយថាចង់បាន និងអ្វីដែលពិតជាធ្វើឱ្យពួកគេប្រសើរឡើង។ នេះក៏ជាដែនកំណត់ស្នូលរបស់វាដែរ គឺការពេញចិត្តក្នុងជីវិតដែលរាយការណ៍ដោយខ្លួនឯងរងឥទ្ធិពលនៃការសម្របខ្លួន និងឥទ្ធិពលនៃការដាក់ក្របខ័ណ្ឌ ដែលអ្នកអនុវត្តប្រុងប្រយ័ត្នត្រូវគ្រប់គ្រង។

## ឧទាហរណ៍គណនា

**អាជ្ញាធរមូលដ្ឋាន**៖ ក្រុមប្រឹក្សាមួយដំណើរការគម្រោងមិត្តភាពសហគមន៍សម្រាប់អ្នករស់នៅចាស់ឯកកោ បម្រើមនុស្ស 400 នាក់។ ការស្ទង់មតិសុខុមាលភាពមុន/ក្រោយ ដោយប្រើសំណួរការពេញចិត្តក្នុងជីវិត ONS4 បង្ហាញថាពិន្ទុមធ្យមរបស់អ្នកចូលរួមកើនពី 5.8 ទៅ 6.5 គឺកើន 0.7 ពិន្ទុ ស្ថិតស្ថេរក្នុងអំឡុងពេលឧបត្ថម្ភ 2 ឆ្នាំរបស់កម្មវិធី។

```
WELLBY ដែលបានបង្កើត = 400 នាក់ × 0.7 ពិន្ទុ × 2 ឆ្នាំ = 560 WELLBY
តម្លៃជាប្រាក់ = 560 × £13,000 = £7.28m
ថ្លៃចំណាយកម្មវិធី = £450,000 ក្នុង 2 ឆ្នាំ

សមាមាត្រអត្ថប្រយោជន៍-ថ្លៃចំណាយ ≈ £7.28m / £0.45m ≈ 16:1
```

សមាមាត្រខ្ពស់បែបនេះគួរតែជំរុញឱ្យមានការត្រួតពិនិត្យ ជាជាងអបអរសាទរ ការណែនាំសុខុមាលភាពរបស់ Green Book ព្រមានយ៉ាងច្បាស់ប្រឆាំងការទទួលយកការកើនឡើងដែលរាយការណ៍ដោយខ្លួនឯងក្នុងគំរូតូចតាមតម្លៃលើផ្ទៃ ដោយមិនពិនិត្យឥទ្ធិពលជ្រើសរើស (តើមានតែអ្នករស់នៅដែលរួសរាយ និងទំនងប្រសើរឡើងបំផុតទេដែលចូលរួមគម្រោង?) និងគ្មានក្រុមប្រៀបធៀប ការវាយតម្លៃដែលរចនាល្អនឹងដកការផ្លាស់ប្តូរcounterfactualដែលបានសង្កេតក្នុងអ្នកមិនចូលរួម សូមមើល [ការវិភាគ counterfactual](../ការវិភាគ-counterfactual/)។

**រដ្ឋាភិបាលជាតិ**៖ ការប្រៀបធៀបកម្មវិធីការងារពីរដោយប្រើ WELLBY ជាជាងប្រាក់ចំណូលតែមួយ ចាប់យកការពិតថា ការគ្មានការងារធ្វើមានថ្លៃចំណាយសុខុមាលភាពលើសពីប្រាក់ចំណូលដែលបាត់បង់ ការស្រាវជ្រាវសុខុមាលភាពរបស់ចក្រភពអង់គ្លេសរកឃើញជាប់លាប់ថា ការគ្មានការងារធ្វើកាត់បន្ថយការពេញចិត្តក្នុងជីវិតច្រើនជាងអ្វីដែលការបាត់បង់ប្រាក់ចំណូលតែមួយព្យាករ ដោយសារឥទ្ធិពលមិនមែនជាប្រាក់នៃការបាត់បង់រចនាសម្ព័ន្ធ គោលបំណង និងទំនាក់ទំនងសង្គម។ កម្មវិធីដែលបានវាយតម្លៃតែលើការកើនប្រាក់ចំណូល នឹងវាយតម្លៃទាបជាងការពិតធៀបនឹងកម្មវិធីដែលបានវាយតម្លៃបន្ថែមលើ WELLBY។

ការវាយតម្លៃសុខុមាលភាពកម្រទៅដល់ក្រុមវិស្វកម្មដោយផ្ទាល់ ប៉ុន្តែវាកំណត់រូបរាងអ្វីដែល "ជោគជ័យ" ត្រូវបានកំណត់សម្រាប់ផលិតផលវិស័យសង្គម និងសេវាសាធារណៈ គឺវេទិកាមិត្តភាពឌីជីថល ឧបករណ៍វិនិច្ឆ័យបឋមសុខភាពផ្លូវចិត្ត ឬវេទិកាសហគមន៍សម្រាប់អ្នករស់នៅឯកកោ គួររំពឹងថាផលប៉ះពាល់របស់វានឹងត្រូវបានវាស់តាមរបៀបនេះនៅទីបំផុត មានន័យថាការវិភាគផលិតផលត្រូវចាប់យក*នរណា*ត្រូវបានទៅដល់ និងរយៈពេលប៉ុន្មាន មិនមែនគ្រាន់តែចំនួនប្រើប្រាស់។ ត្រូវកសាងឧបករណ៍ស្ទង់មតិសុខុមាលភាព (ONS4 ឬសមមូលដែលបានផ្ទៀងផ្ទាត់) ក្នុងការវាយតម្លៃសេវាតាំងពីដំបូង ជាជាងបន្ថែមក្រោយ ការបន្ថែមមូលដ្ឋានសុខុមាលភាពក្រោយសេវាបានចាប់ផ្តើម បាត់បង់ការប្រៀបធៀបមុន/ក្រោយទាំងស្រុង។ សូមមើល [លទ្ធផល ធៀបនឹង ទិន្នផល](../លទ្ធផល-ធៀបនឹង-ទិន្នផល/) និង
[វិធីសាស្ត្រវាយតម្លៃផលប៉ះពាល់](../វិធីសាស្ត្រវាយតម្លៃផលប៉ះពាល់/)។

## កំហុសដែលតែងកើតមាន

- **គ្មានcounterfactual ឬក្រុមប្រៀបធៀប។** ការកើនសុខុមាលភាពមុន/ក្រោយ ដោយគ្មានការគ្រប់គ្រងលើអ្វីដែលនឹងកើតឡើងឯណាមួយ ធ្វើឱ្យឥទ្ធិពលកម្មវិធីហួសការពិត សូមមើល
  [ការវិភាគ counterfactual](../ការវិភាគ-counterfactual/) និង
  [ភាពបន្ថែម និង deadweight](../ភាពបន្ថែម-និងផលដែលនឹងកើតឡើងដោយខ្លួនឯង/)។
- **គំរូតូច ជ្រើសរើសដោយខ្លួនឯង។** ការស្ទង់មតិសុខុមាលភាពលើអ្នកចូលរួមកម្មវិធីដែលជ្រើសចូលដោយស្ម័គ្រចិត្ត ងាយរងភាពលំអៀងជ្រើសរើស មនុស្សដែលចូលរួម និងនៅតទៅ ទំនងជាកំពុងមាននិន្នាការប្រសើរឡើងរួចហើយ។
- **ការចាត់ទុកការបម្លែង £ ក្នុងមួយ WELLBY ថាជាក់លាក់។** តម្លៃជាប្រាក់គឺជាសន្ធិសញ្ញាគោលនយោបាយ ដែលបានមកពីតំរែតំរង់ប្រាក់ចំណូល-សុខុមាលភាព មិនមែនតម្លៃទីផ្សារទេ ត្រូវប្រើវាសម្រាប់ភាពអាចប្រៀបធៀបឆ្លងការវាយតម្លៃ Green Book មិនមែនជាការអះអាងថាសុខុមាលភាព "មានតម្លៃប៉ុន្មាន" ទេ។
- **ការច្រលំ WELLBY ជាមួយ QALY ទាក់ទងសុខភាព។** ទាំងពីរវាស់គំនិតខុសគ្នាលើមាត្រដ្ឋានខុសគ្នា សូមមើល [ឆ្នាំជីវិតកែតម្រូវតាមសុខុមាលភាព](../ឆ្នាំជីវិតកែតម្រូវតាមសុខុមាលភាព/) សម្រាប់បំរែបំរួលសេដ្ឋកិច្ចសុខភាព ហើយកុំគណនាមធ្យមទាំងពីរបញ្ចូលគ្នា។
