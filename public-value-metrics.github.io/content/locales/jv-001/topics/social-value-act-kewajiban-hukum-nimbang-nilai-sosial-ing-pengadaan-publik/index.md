# Social Value Act: Kewajiban Hukum Nimbang Nilai Sosial ing Pengadaan Publik

Public Services (Social Value) Act 2012 iku kewajiban hukum Britania Raya sing mrèntahaké otoritas publik ing Inggris lan Wales nimbang kepriyé barang sing diadakaké bisa nambah kesejahteraan ékonomi, sosial, lan lingkungan ing wilayah sing gegayutan, lan nimbang nganakaké konsultasi babagan iki, sadurungé miwiti proses pengadaan kanggo kontrak layanan publik. Undang-undang iki mlebu kekuwatan ing Januari 2013 minangka kewajiban "have regard to" (nimbang) sing cukup entheng, lan dikuwatké sacara signifikan déning Procurement Policy Note (PPN) 06/20 ing Januari 2021, sing mrèntahaké kontrak pamaréntah pusat kanthi gamblang ngevaluasi — dudu mung nimbang — nilai sosial, kanthi bobot minimum ing kritéria penghargaan.

## Kenapa penting

Sadurungé PPN 06/20, "nimbang" nilai sosial bisa dicukupi mung kanthi komisioner nyathet yèn dhèwèké wis mikir, tanpa kawajiban yèn iku ngaruhi kaputusan penghargaan — kewajiban sing gampang dituntasaké ing kertas lan dilirwakaké ing praktik. PPN 06/20 nutup celah iku kanggo pengadaan pamaréntah pusat: mrèntahaké nilai sosial diskor minangka bagéan evaluasi tender, diatur ing sekitar limang tema prioritas nasional — pemulihan COVID-19, ngatasi ketimpangan ékonomi, nglawan owah-owahan iklim, kesempatan sing padha, lan kesejahteraan — lan umumé diukur nganggo kerangka National TOMs (Themes, Outcomes, Measures) sing dikelola Social Value Portal. Kanggo insinyur piranti lunak sing mbangun piranti pengadaan, manajemen kontrak, utawa dhukungan penawaran kanggo sektor publik, iki dhasar hukum sing kudu dianut kliénmu, dudu tambahan opsional.

## Petungan

Nilai sosial iku topik sing bentuké kerangka; "petungané" yaiku struktur penilaian sing dienggo umumé otoritas:

```
Total skor tender = Bobot rega/biaya + Bobot kualitas + Bobot nilai sosial

PPN 06/20 (pamaréntah pusat): bobot nilai sosial ≥ 10% saka total skor

Tema nilai sosial (PPN 06/20):
 1. Pemulihan COVID-19
 2. Ngatasi ketimpangan ékonomi
 3. Nglawan owah-owahan iklim
 4. Kesempatan sing padha
 5. Kesejahteraan
```

Para penawar biasané ngowahi komitmen kanggo tema-tema iki dadi nilai moneter nganggo [basis data biaya satuan](../basis-data-biaya-satuan-proksi-keuangan-sing-wis-diteliti-kanggo-outcome-sosial/), lan logika monetisasi sing padha karo [social return on investment](../social-return-on-investment-ngukur-bali-modal-sosial-sing-wis-disesuaikan-karo-deadweight-lan-atribusi/) ditrapaké: komitmen kudu dibuktèkaké, bisa diatribusiaké marang kontrak, lan ora diétung kaping pindho karo pendanaan liyané.

## Conto petungan

**Kontrak IT otoritas lokal**: kontrak £2 yuta, 3 taun diskor 60% kualitas, 30% rega, 10% nilai sosial. Penawar A komitmen 2 magang, £150.000 belanja subkontrak lokal, lan 200 jam pelatihan kaprigelan digital pro bono kanggo sekolah lokal, dimonetisasi nganggo proksi saka basis data biaya satuan dadi total £90.000 nilai sosial tambahan. Penawar B komitmen paket sing luwih cilik, dimonetisasi £40.000. Yèn otoritas ngskor nilai sosial sacara proporsional mungsuh penawaran paling kuwat, Penawar A olèh kabèh 10 poin; Penawar B olèh 10 × (£40.000 ÷ £90.000) = 4,4 poin — selisih 5,6 poin sing bisa nemtokaké kontrak senajan kualitas lan rega cedhak.

**Penawar sektor sukarela**: VCSE cilik (voluntary, community and social enterprise — usaha sukarela, komunitas, lan sosial) sing nawar kontrak pangopènan taman mungsuh pesaing komersial ora bisa saingan mung ing rega satuan, nanging nganggo proksi Global Value Exchange kanggo ngowahi komitmen lapangan kerja komunitas lan sukarelawan sing wis ana dadi nilai moneter, nggawé kasus nilai sosial sing dibuktèkaké lan pantes diskor bebarengan karo rega lan kualitas.

## Gegayutan karo rekayasa piranti lunak

Menang tender kanthi komitmen nilai sosial sing dimonetisasi nggawé kewajiban kanggo mbuktèkaké pangiriman mungsuh iku liwat manajemen kontrak — piranti sing nyathet wiwitan magang, belanja lokal, lan jam pelatihan mungsuh komitmen tartamtu sing diskor ing tender, mlebu rapat tinjauan kontrak tinimbang dilalèkaké sakwisé kontrak ditandatangani. Daftar G-Cloud lan Digital Marketplace saya kerep mbutuhaké pernyataan nilai sosial nalika didaftar. Deleng [social return on investment](../social-return-on-investment-ngukur-bali-modal-sosial-sing-wis-disesuaikan-karo-deadweight-lan-atribusi/) kanggo metode penilaian ing mburi komitmen, [basis data biaya satuan](../basis-data-biaya-satuan-proksi-keuangan-sing-wis-diteliti-kanggo-outcome-sosial/) kanggo proksi sing dienggo penawar, lan [outcome lawan output](../outcome-vs-output-bedane-asil-langsung-lan-owah-owahan-nyata/) kanggo mesthekaké komitmen sing dikirim iku outcome, dudu mung cacahé aktivitas.

## Jebakan

- **Social-washing penawaran.** Komitmen samar ("kita ndhukung komunitas lokal") sing ora bisa diukur utawa ditagih nalika manajemen kontrak olèh skor apik nanging ora ngirim apa-apa sing bisa diverifikasi.
- **Nganggep nilai sosial minangka pemutus seri.** PPN 06/20 mrèntahaké nilai sosial dievaluasi kanthi gamblang ing kritéria penghargaan, dudu dienggo kanthi ora resmi kanggo mutusaké seri antarané penawaran sing lagi sepadha.
- **Ora ana tindak lanjut manajemen kontrak.** Komitmen sing diskor ing tender kerep ora tau dilacak nalika pangiriman — deleng [realisasi manfaat](../realisasi-manfaat-mbuktèkaké-manawa-manfaat-ing-business-case-tenan-kawujud/).
- **Kerangka ukuran sing ora konsisten antar kontrak.** Nganggo sumber proksi sing béda kanggo komitmen sing padha ing kontrak sing béda ndadèkaké perbandhingan tingkat portofolio ora ana artiné, mula ana kerangka umum kaya National TOMs lan basis data biaya satuan bersama.
