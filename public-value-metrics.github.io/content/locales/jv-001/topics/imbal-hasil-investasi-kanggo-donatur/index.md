# Imbal Hasil Investasi kanggo Donatur

Imbal hasil investasi donatur (donor return on investment) yaiku apa sing sejatine dituku dening pound saka donatur tartamtu ing wujud outcome — dudu rasio operasional amal, lan dudu imbal hasil amal marang sakabehe anggarane. Iki mbingkai ulang ROI saka sudut pandang organisasi (kepriye efisien kita mlaku) menyang sudut pandang donatur (apa sing diowahi dening kontribusi marjinalku), lan loro angka kasebut rutin, lan salah, dianggep padha.

## Kenapa penting

"ROI" sawijining amal dhewe, yen istilah kasebut digunakake, biasane nggambarake samubarang kaya [cost per beneficiary](../biaya-saben-panampa-manfaat-ngukur-jangkauan-dudu-owah-owahan/) utawa [charity overhead ratio](../rasio-overhead-lembaga-amal-kenapa-ukuran-efisiensi-iki-ora-bisa-dipercaya/) — ukuran efisiensi organisasi. ROI donatur iku pitakonan sing beda babar pisan: amarga amal iki wis nduwe penghasilan liyane, apa sing ditambahake dening dhuwit *donatur iki* ing sisih marjinal? Yen sawijining amal bakal nglakokake program sing padha mawa utawa tanpa hadiah £10.000 tartamtu — amarga duwe cadangan sing cukup, utawa amarga pendana liya bakal nutup kekurangane — ROI donatur saka hadiah kasebut cedhak karo nol, sepira apik rasio overhead utawa biaya per outcome amal kasebut sakabehe.

Iki pitakonan additionality sing padha sing dadi dhasar penilaian [value for money](../value-for-money-ngukur-apa-belanja-publik-menehi-imbangan-biaya-lan-manfaat-sing-paling-apik/) ing belanja publik Inggris lan [additionality lan deadweight](../additionality-lan-deadweight-nyingkirake-asil-sing-bakal-kedadéan-senajan-tanpa-program/) ing evaluasi program: nilai sing digawe mung bisa dikreditake marang pendana yen nilai kuwi ora bakal kedadean tanpa dheweke. Platform donor-advised utama lan organisasi pemberian efektif (Giving What We Can, GiveWell) nyusun rekomendasie kanthi eksplisit ing sekitar pambeda iki, ora takon "apa iki amal sing apik" nanging "apa amal iki isih duwe ruang kanggo pendanaan luwih akeh supaya hadiahku dadi additional."

## Petungan

```
ROI donatur ≠ Efisiensi operasional amal

ROI donatur ≈ (Outcome sing dicapai karo hadiah) − (Outcome sing bakal
              kedadean tanpa hadiah, yaiku kontrafaktual)
             ─────────────────────────────────────────────────
                              Ukuran hadiah

Input utama:
  - Ruang kanggo pendanaan luwih akeh (apa amal diwatesi dana ing sisih marjinal?)
  - Funging (apa donatur liya bakal nutup kekurangane?)
  - Cost-effectiveness marjinal ing tingkat pendanaan tartamtu (biaya asring
    munggah nalika intervensi diskalakake ngluwihi populasi sing paling gampang dijangkau)
```

Deleng [cost-effectiveness effective altruism](../cost-effectiveness-altruisme-efektif/) kanggo kepriye GiveWell ngoperasionalake pitakonan "ruang kanggo pendanaan luwih akeh", lan [analisis kontrafaktual](../analisis-kontrafaktual-ngira-ira-apa-sing-bakal-kedadéan-tanpa-intervensi/) kanggo cara umume.

## Conto petungan

Sawijining donatur milih antarane rong hadiah £5.000:

- **Amal C**: nduwe program inti sing didanai kebak kanthi cadangan £2 yuta lan daftar tunggu pendana; £5.000 marjinal kemungkinan ditambahake menyang cadangan utawa aktivitas prioritas luwih endhek. Perkiraan outcome tambahan donatur: minimal — dhuwit kuwi ora jelas ngowahi apa sing kedadean.
- **Amal D**: program cilik sing didhukung bukti sing wis ngumumake yen bakal kudu nolak 200 wong ing kuartal ngarep tanpa tambahan £50.000, lan wis ngumpulake £42.000 saka iku. £5.000 marjinal kemungkinan gedhe bakal mbiayai pangiriman tambahan sing nyata — umpamane 20 wong tambahan sing dilayani, kanthi biaya per beneficiary sing dinyatakake amal dhewe £250.

Ukuran hadiah padha, donatur padha, nanging ROI donatur beda banget — dudu amarga Amal C organisasi sing luwih ala (bisa wae nduwe angka biaya-per-outcome sing luwih apik sakabehe) nanging amarga kekurangan pendanaan marjinale wis ketutup.

## Gegayutan karo rekayasa piranti lunak

Platform donatur lan piranti rekomendasi pemberian asring mung nampilake metrik efisiensi tingkat organisasi (rasio overhead, biaya per beneficiary) amarga kuwi sing diterbitake amal ing laporan taunan lan sing paling gampang dilebokake ing tabel perbandingan. Nggambarake ROI donatur kanthi bener mbutuhake data sing beda lan luwih angel digoleki: kekurangan pendanaan utawa "ruang kanggo pendanaan luwih akeh" sing dinyatakake amal saiki, sing owah sajrone taun lan arang dadi data terstruktur. Platform sing pengin ndhukung nalar ROI donatur sing sejati mbutuhake feed langsung saka pambukaan kekurangan pendanaan (kaya sing dijaga GiveWell kanthi manual kanggo amal sing direkomendasi) utawa penafian eksplisit yen tabel perbandingan nuduhake efisiensi organisasi, dudu additionality donatur. Deleng [charity overhead ratio](../rasio-overhead-lembaga-amal-kenapa-ukuran-efisiensi-iki-ora-bisa-dipercaya/) kanggo metrik sing paling kerep, lan salah, dicampur karo ROI donatur.

## Jebakan

- **Nyampur efisiensi amal karo additionality donatur.** Amal sing dikelola apik lan overhead endhek isih bisa nduwe ROI donatur marjinal cedhak nol yen ora diwatesi dana.
- **Ngabaikake funging.** Yen pendana institusional gedhe bakal nutup kekurangan kasebut tanpa hadiah, hadiah donatur individu mung mindhahake dhuwit pendana kuwi, dudu nambah pangiriman anyar.
- **Nganggep cost-effectiveness linear ing skala gedhe.** Beneficiary sing paling murah dijangkau asring dilayani luwih dhisik; biaya marjinal per outcome kerep munggah nalika program ngembang, dadi ROI pound sabanjure ora padha karo ROI pound rata-rata sing wis dibelanjakake.
- **Ora ana kekurangan pendanaan sing dinyatakake.** Amal utawa platform sing ora bisa ngomong apa sing bakal dibiayai £X sabanjure ora bisa ndhukung klaim ROI donatur sing sejati, mung klaim biaya rata-rata.
