# બહુપરિમાણીય ગરીબી સૂચકાંક (Multidimensional Poverty Index)

MPI ગરીબીને ફક્ત આવક કોઈ રેખાથી નીચે હોય તેવી નહીં, પણ આરોગ્ય, શિક્ષણ અને જીવનધોરણમાં વ્યક્તિ એક જ સમયે અનુભવતી ઓવરલૅપ થતી વંચિતતાઓ તરીકે માપે છે. તે Oxford Poverty and Human Development Initiative (OPHI) દ્વારા Sabina Alkire અને James Foster સાથે વિકસાવાયો હતો, અને 2010 થી દરેક Human Development Report માં [માનવ વિકાસ સૂચકાંક (Human Development Index)](../માનવ-વિકાસ-સૂચકાંક/) ની સાથે UNDP સાથે સંયુક્ત રીતે પ્રકાશિત થાય છે.

## તે શા માટે મહત્વનું છે

આવક-આધારિત ગરીબી રેખાઓ એવા લોકોને ચૂકી જાય છે જેમની પાસે રોકડ આવક પૂરતી છે પણ સ્વચ્છ પાણી, શાળાનું શિક્ષણ નથી, કે જેમણે બાળકનું મૃત્યુ જોયું છે. તે એ હકીકત પણ ચૂકી જાય છે કે વંચિતતાઓ ગુચ્છમાં આવે છે: વીજળી વગરના ઘરમાં સ્વચ્છતા-સુવિધાનો અભાવ અને કુપોષિત બાળક હોવાની સંભાવના પ્રમાણમાં વધુ હોય છે. Alkire-Foster પદ્ધતિ, જેના પર MPI રચાયેલો છે, દરેક વ્યક્તિની વંચિતતાઓને દસ સૂચકોમાં ગણે છે, જે ત્રણ સમાન ભારવાળા પરિમાણોમાં જૂથબદ્ધ છે: આરોગ્ય, શિક્ષણ, જીવનધોરણ. અને કોઈને "MPI-ગરીબ" ત્યારે જ ગણે છે જ્યારે તેનો ભારિત વંચિતતા ગુણાંક નિશ્ચિત સીમા ઓળંગે, જેથી એવી ઓવરલૅપ પકડાય જે અલગ અલગ એક-સૂચક આંકડાઓ પકડી શકતા નથી. OPHI સંપૂર્ણ પદ્ધતિ અને દેશવાર ડેટા <https://ophi.org.uk/multidimensional-poverty-index/> પર પ્રકાશિત કરે છે; UNDP સાથે સંયુક્ત રીતે જાળવાતો વૈશ્વિક MPI હવે 110 થી વધુ દેશોને આવરી લે છે. ગરીબી-વિરોધી કાર્યક્રમો માટેના સૉફ્ટવેર (રોકડ ટ્રાન્સફર, સામાજિક સંભાળની પ્રાથમિકતા નક્કી કરવી, સહાયનું લક્ષ્યીકરણ) માટે MPI નો સૂચક-સમૂહ ઘણી વાર પ્રમાણિત વંચિતતા સ્કીમાની સૌથી નજીકની વસ્તુ છે, જે ડઝનબંધ રાષ્ટ્રીય આંકડાકીય કચેરીઓમાં પહેલેથી ચકાસાઈ ચૂકી છે.

## ગણિત

```
10 indicators, 3 dimensions, each dimension weighted 1/3:

Health (1/3):            nutrition (1/6), child mortality (1/6)
Education (1/3):         years of schooling (1/6), school attendance (1/6)
Living standards (1/3):  cooking fuel, sanitation, drinking water,
                          electricity, housing, assets (1/18 each)

deprivation score (c) = sum of weights of indicators a person is deprived in

person is "MPI poor" if c ≥ 1/3 (the poverty cut-off, k = 33%)

H (headcount ratio) = number of MPI poor / total population
A (intensity)        = average deprivation score among the MPI poor only

MPI = H × A
```

MPI ગરીબ લોકોના *હિસ્સા* ને તેઓ *કેટલા* ગરીબ છે તેનાથી ગુણે છે, એટલે સમાન હેડકાઉન્ટ ગુણોત્તર ધરાવતા બે પ્રદેશોના MPI સ્કોર ઘણા જુદા હોઈ શકે જો એકમાં વંચિતતાઓ વધુ ગંભીર હોય. આ HDI ના ભૌમિતિક સરેરાશ પાછળના "પરિમાણો વચ્ચે અવેજી નહીં" તર્ક જેવું જ છે.

## ઉદાહરણ સાથે ગણતરી

**1,000 લોકોનો રાષ્ટ્રીય સર્વે**: 350 લોકો બહુપરિમાણીય રીતે ગરીબ તરીકે ઓળખાય છે (વંચિતતા ગુણાંક ≥ 33%). ફક્ત આ 350 ગરીબ વ્યક્તિઓમાં સરેરાશ વંચિતતા ગુણાંક 45% છે.

```
H = 350 / 1000                = 0.350
A = 0.45
MPI = H × A = 0.350 × 0.45    = 0.1575
```

**સમાન હેડકાઉન્ટ ધરાવતા બે જિલ્લાની સરખામણી**: જિલ્લો A માં H = 0.30 અને A = 0.40 (ઘણા ગરીબ, મધ્યમ વંચિત); જિલ્લો B માં H = 0.30 અને A = 0.60 (ગરીબોની સંખ્યા સરખી, પણ વધુ ગંભીર રીતે વંચિત: વીજળી *અને* સ્વચ્છતા *અને* શાળા-હાજરી એકસાથે ખૂટે છે).

```
MPI_A = 0.30 × 0.40 = 0.120
MPI_B = 0.30 × 0.60 = 0.180
```

હેડકાઉન્ટ ગુણોત્તર સમાન, પણ જિલ્લો B નો MPI 50% વધુ છે. ફક્ત હેડકાઉન્ટ ગરીબી પર આધારિત લક્ષ્યીકરણ પ્રણાલી બંને જિલ્લાને સરખા ક્રમે મૂકશે અને ચૂકી જશે કે જિલ્લો B ને વધુ ઊંડા હસ્તક્ષેપની જરૂર છે.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

- સામાજિક કાર્યક્રમોની કેસ-મેનેજમેન્ટ અને પાત્રતા પ્રણાલીઓ ઘણી વાર પહેલેથી દસમાંથી કેટલાક સૂચકો (આવાસ, શાળા-હાજરી, આરોગ્ય સૂચકો) અલગ અલગ સાઇલોમાં સંગ્રહે છે; Alkire-Foster ગણતરી પદ્ધતિ તેમને એક વંચિતતા ગુણાંકમાં જોડવા માટેનું તૈયાર સ્કીમા છે, શરૂઆતથી અલગ ગુણાંકન મૉડલ બનાવવાને બદલે.
- હેડકાઉન્ટ/તીવ્રતાનું વિભાજન (H × A) એ કોઈ પણ ડૅશબોર્ડ માટે સામાન્ય રીતે ઉપયોગી પૅટર્ન છે જે "કેટલા અસરગ્રસ્ત છે" અને "કેટલી ગંભીર રીતે" બંને જણાવે છે. બંનેને એક સંખ્યામાં સંકેલવાથી, જેમ કાચા વ્યાપના આંકડા કરે છે, સૌથી વધુ સંસાધનોની જરૂર ધરાવતો કિસ્સો જ છુપાઈ જાય છે.
- MPI-શૈલીના સૂચક ડૅશબોર્ડ ગરીબી-વિરોધી કાર્યક્રમો માટે [લાભાર્થી દીઠ ખર્ચ](../પ્રતિ-લાભાર્થી-ખર્ચ/) ના અહેવાલ સાથે સ્વાભાવિક રીતે જોડાય છે: MPI માં એક પૉઇન્ટના ઘટાડા દીઠ ખર્ચ એ ખૂબ અલગ હસ્તક્ષેપો (રોકડ ટ્રાન્સફર વિરુદ્ધ સ્વચ્છતા માળખું) ની સરખામણી માટે સમર્થનીય એકમ છે.

## સામાન્ય ભૂલો

- **દસ સૂચકોને સાર્વત્રિક ગણવા.** OPHI ના વૈશ્વિક MPI સૂચકો દેશો વચ્ચે સરખામણી થઈ શકે તે માટે ગોઠવાયેલા છે; રાષ્ટ્રીય MPI (દક્ષિણ એશિયા અને આફ્રિકાના કેટલાક સહિત ઘણા દેશો પોતાના પ્રકાશિત કરે છે) સૂચકો અને ભારને સ્થાનિક સંદર્ભ પ્રમાણે ઢાળે છે, અને બંનેની સીધી સરખામણી થઈ શકતી નથી.
- **ફક્ત H નો અહેવાલ આપવો.** હેડકાઉન્ટ ગુણોત્તર તીવ્રતાને સંપૂર્ણપણે અવગણે છે; તેની સાથે A, અથવા MPI પોતે, હંમેશાં જણાવો કે ગણો.
- **MPI-ગરીબ અને આવક-ગરીબ એ એક જ વસ્તી છે એમ માનવું.** OPHI ના પોતાના દેશ-સંક્ષેપો સામાન્ય રીતે બંને વચ્ચે માત્ર આંશિક ઓવરલૅપ બતાવે છે; ફક્ત આવક-ગરીબોને લક્ષ્ય બનાવતો કાર્યક્રમ બહુપરિમાણીય ગરીબોના નોંધપાત્ર હિસ્સાને વ્યવસ્થિત રીતે ચૂકી જશે.
