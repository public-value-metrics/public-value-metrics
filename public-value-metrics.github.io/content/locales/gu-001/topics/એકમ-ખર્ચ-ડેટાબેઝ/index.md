# એકમ ખર્ચ ડેટાબેઝ

એકમ ખર્ચ ડેટાબેઝ (unit cost database) એ સામાજિક પરિણામો માટે અગાઉથી સંશોધિત, પુરાવા-આધારિત નાણાકીય પ્રોક્સીઓનું ગ્રંથાલય છે — બેરોજગારીમાંથી રોજગારમાં જવાનું મૂલ્ય, ઘટેલી એકલતાનું, સ્થિર ભાડૂઆતનું — જે વ્યવસાયીને દર વખતે વિશેષ મૂલ્યાંકન સંશોધન કમિશન કર્યા વિના પરિણામને નાણાકીય રૂપમાં મૂકવા દે છે. તે એટલા માટે અસ્તિત્વમાં છે કે ભંડોળ બિડ લખતી નાની ચેરિટી સારા સંસાધનોવાળી કન્સલ્ટન્સી જેટલી જ ચોકસાઈ લાગુ કરી શકે, બીજા કોઈએ પહેલેથી તારવેલી અને પ્રકાશિત કરેલી પ્રોક્સીનો પુનઃઉપયોગ કરીને.

## તે શા માટે મહત્વનું છે

HACT ની UK Social Value Bank, જે અર્થશાસ્ત્રી Daniel Fujiwara સાથે કલ્યાણ મૂલ્યાંકન પદ્ધતિઓ વડે વિકસાવાઈ હતી, અને Global Value Exchange, નાણાકીય પ્રોક્સીઓનો ખુલ્લો, ક્રાઉડસોર્સ્ડ ડેટાબેઝ, યુકેના ત્રીજા અને જાહેર ક્ષેત્રોમાં સૌથી વ્યાપક રીતે વપરાતા બે છે. બંને એટલા માટે છે કે પાયાનું મૂલ્યાંકન કાર્ય — [કલ્યાણ મૂલ્યાંકન](../કલ્યાણ-મૂલ્યાંકન/) અને [જાહેર કરેલી પસંદગી આધારિત મૂલ્યાંકન](../જાહેર-કરેલી-પસંદગી-આધારિત-મૂલ્યાંકન/) — ખર્ચાળ, પદ્ધતિગત રીતે માગણીવાળું અને દરેક પ્રોજેક્ટ માટે શરૂઆતથી ચલાવવામાં ધીમું છે. સહિયારી, પ્રકાશિત પ્રોક્સી લાઇબ્રેરી જે અન્યથા મહિનાઓની સંશોધન કવાયત હોત તેને લુકઅપમાં ફેરવે છે, એટલે જ તે [સામાજિક રોકાણ પર વળતર](../સામાજિક-રોકાણ-પર-વળતર/) ગણતરીઓ અને [સામાજિક મૂલ્ય અધિનિયમ](../સામાજિક-મૂલ્ય-અધિનિયમ/) બિડ મૂલ્યાંકનો બંને માટે મહત્વના છે: તેમના વિના, કડક નાણાકીયકરણ ફક્ત પોતાના અભ્યાસો કમિશન કરી શકે તેવી મોટી સંસ્થાઓને પરવડે.

## ગણિત

એકમ ખર્ચ ડેટાબેઝ પોતે કશું ગણતો નથી; તે બીજે થતી ગણતરીને એક ઇનપુટ પૂરું પાડે છે:

```
નાણાકીય પ્રોક્સી મૂલ્ય = બજાર કિંમત, અથવા શેડો પ્રાઇસ, અથવા કલ્યાણ મૂલ્યાંકન,
                         અથવા જાહેર કરેલી પસંદગીનું મૂલ્ય
                         પરિણામ ફેરફારના નિશ્ચિત એકમ માટે
                         (દા.ત. "બેરોજગારીમાંથી રોજગારમાં જતી વ્યક્તિ દીઠ, વર્ષે")

લાગુ કરેલું મૂલ્ય = પ્રાપ્ત પરિણામોની સંખ્યા × એકમ પ્રોક્સી મૂલ્ય
```

બજાર કિંમત ન હોય ત્યારે પ્રોક્સી કેવી રીતે બને છે તે માટે જુઓ [શેડો પ્રાઇસિંગ](../શેડો-પ્રાઇસિંગ/), અને ડેડવેઇટ અને શ્રેય-નિર્ધારણ સમાયોજનો પછી લાગુ કરેલું મૂલ્ય ગુણોત્તરમાં કેવી રીતે જાય છે તે માટે [સામાજિક રોકાણ પર વળતર](../સામાજિક-રોકાણ-પર-વળતર/).

## ઉદાહરણ સાથે ગણતરી

**ચેરિટી (મિત્રતા સેવા SROI)**: "એકલતામાં ઘટાડો" માટેની એકમ ખર્ચ ડેટાબેઝ એન્ટ્રી વ્યક્તિ દીઠ વર્ષે £1,100 ની દૃષ્ટાંતરૂપ પ્રોક્સી આપે છે. 80 લાભાર્થીઓ પર લાગુ કરતાં: 80 × £1,100 = £88,000 કુલ મૂલ્ય. જો એ જ ડેટાબેઝમાં "સુધરેલું માનસિક કલ્યાણ" માટે પણ પ્રોક્સી હોય જે ઓવરલૅપ થતા કલ્યાણ સર્વેક્ષણ આઇટમ પર આધારિત હોય, તો એ જ 80 લોકો માટે બંને પ્રોક્સી ઉપરાઉપરી મૂકવાથી એ જ મૂળભૂત ફેરફારનો ભાગ બેવડો ગણાશે — ડેટાબેઝ આંકડો પૂરો પાડે છે, પણ આ ઓવરલૅપ ટાળવાની જવાબદારી વિશ્લેષકની છે.

**સ્થાનિક સત્તામંડળ (જોબ ક્લબ SROI)**: "બેરોજગારીમાંથી ટકાઉ રોજગારમાં જવા" માટેની એકમ ખર્ચ ડેટાબેઝ એન્ટ્રી 45 સહભાગીઓ પર વ્યક્તિ દીઠ વર્ષે £8,500 ની દૃષ્ટાંતરૂપ પ્રોક્સીએ લાગુ થાય છે: 45 × £8,500 = £382,500 કુલ મૂલ્ય, [સામાજિક રોકાણ પર વળતર](../સામાજિક-રોકાણ-પર-વળતર/) માં દર્શાવેલા ડેડવેઇટ અને શ્રેય-નિર્ધારણ સમાયોજનો પહેલાં.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

ચેરિટી કે કમિશનરો માટે રિપોર્ટિંગ સાધનો બનાવતી ટીમોને આંતરિક "પરિણામ સૂચિ" થી ફાયદો થાય છે — એક કોષ્ટક જે ઉત્પાદન કે સેવા વાજબી રીતે દાવો કરી શકે તેવા દરેક પરિણામને નામવાળી પ્રોક્સી, તેના સ્રોત ડેટાબેઝ, તેની પ્રકાશન તારીખ અને આવૃત્તિ ઓળખકર્તા સાથે જોડે — જેથી સંસ્થાની જુદી ટીમો એ જ પરિણામ માટે દરેક થોડાં જુદાં મૂલ્યો ન પસંદ કરે. Global Value Exchange ના ખુલ્લા ડેટાને લુકઅપ સેવા પાછળ મૂકવાથી, આંકડા સાથે સ્રોત અને તારીખ હંમેશાં દર્શાવીને, પ્રોક્સી ઑડિટ કરી શકાય તેવી રહે છે, સ્પ્રેડશીટમાં દટાયેલા જાદુઈ આંકડા તરીકે નહીં. આ પ્રોક્સીઓ જ્યાં મુખ્યત્વે વપરાય છે તે બે સ્થાનો માટે જુઓ [સામાજિક રોકાણ પર વળતર](../સામાજિક-રોકાણ-પર-વળતર/) અને [સામાજિક મૂલ્ય અધિનિયમ](../સામાજિક-મૂલ્ય-અધિનિયમ/).

## સામાન્ય ભૂલો

- **પ્રોક્સીને ચોક્કસ ગણવી.** મોટા ભાગની પ્રકાશિત પ્રોક્સીઓ કલ્યાણ મૂલ્યાંકન અભ્યાસોમાંથી મૉડલ કરેલી સરેરાશો છે જેમાં વિશાળ વિશ્વાસ અંતરાલો હોય છે; પાઉન્ડ સુધી ચોક્કસ ટાંકવાથી મૂળભૂત સંશોધન જેટલી ચોકસાઈને ટેકો આપે છે તેનાથી વધુ દર્શાવાય છે.
- **ઓવરલૅપ થતી પ્રોક્સીની બેવડી ગણતરી.** ઓવરલૅપ થતા સર્વેક્ષણ ખ્યાલોમાંથી તારવેલી પ્રોક્સીઓ (દા.ત. "ઘટેલી એકલતા" અને "સુધરેલું માનસિક કલ્યાણ") ભેગી કરવાથી એ જ મૂળભૂત ફેરફારનું બે વાર મૂલ્ય થાય છે.
- **સંદર્ભ બહારની પ્રોક્સી સમાયોજન વિના વાપરવી.** એક રાષ્ટ્રીય વસ્તી અને વર્ષ પર માપાંકિત પ્રોક્સી, ફુગાવા કે સંદર્ભ સમાયોજન વિના બીજે લાગુ કરવાથી ચૂપચાપ મૂલ્ય ખોટું દર્શાવાય છે.
- **ઉદ્ભવ તપાસવો નહીં.** Global Value Exchange ખુલ્લું અને ક્રાઉડસોર્સ્ડ છે, તેથી એન્ટ્રીની ગુણવત્તા ફાળો આપનાર પ્રમાણે બદલાય છે; ભંડોળ બિડ કે ખરીદી રજૂઆતમાં આંકડો ટાંકતાં પહેલાં મૂળભૂત સ્રોત તપાસો.
