# अतिरिक्तता आणि डेडवेट

अतिरिक्तता (additionality) हा प्रश्न विचारते की एखाद्या हस्तक्षेपामुळे असा परिणाम घडला का, जो अन्यथा घडला नसता. डेडवेट (deadweight) हा त्याचा आरसा आहे: कार्यक्रम, अनुदान किंवा सबसिडी नसतानाही जो परिणाम तरीही घडला असता, त्याचा वाटा. डेडवेट वजा केल्याशिवाय सरकारी कार्यक्रमाचा किंवा धर्मादाय संस्थेचा जवळजवळ प्रत्येक प्रभावाचा दावा त्याचा परिणाम फुगवून सांगतो; म्हणूनच यूकेमधील मूल्यमापन मार्गदर्शन कोणत्याही मुख्य आकड्यातील हे पहिले आणि सर्वात महत्त्वाचे समायोजन मानते.

## हे का महत्त्वाचे आहे

"आम्ही 500 व्यवसायांना वाढण्यास मदत केली" हे यशासारखे वाटते; पण त्यांपैकी 300 व्यवसाय तरीही वाढले असते — कारण स्थानिक अर्थव्यवस्था सावरत होती, त्यांना निधीचे इतर मार्ग उपलब्ध होते, किंवा कार्यक्रम सुरू होण्यापूर्वीच ते वाढीच्या मार्गावर होते — तर कार्यक्रमाचे खरे अतिरिक्त योगदान 500 नसून 200 आहे. एचएम ट्रेझरीचे Magenta Book आणि एचएम ट्रेझरी/BIS चे दीर्घकाळ वापरात असलेले "Additionality Guide" (मूळतः प्रादेशिक विकास आणि पुनरुज्जीवन कार्यक्रमांसाठी विकसित, आणि तेव्हापासून यूके सरकारच्या मूल्यमापनात व्यापकपणे वापरले जाणारे) हे डेडवेटला निव्वळ-परिणामाच्या प्रमाण क्रमातील पहिले समायोजन म्हणून औपचारिक रूप देतात: एकूण परिणाम वजा डेडवेट, वजा विस्थापन, वजा गळती, गुणक परिणामांसाठी समायोजित, म्हणजे निव्वळ अतिरिक्त परिणाम. ही पायरी वगळणे हा सार्वजनिक आणि सामाजिक क्षेत्रातील प्रभावाचे दावे — जाणूनबुजून किंवा नकळत — फुगवण्याचा सर्वात सामान्य मार्ग आहे: जो अनुदान कार्यक्रम तुलना गटाशिवाय फक्त सहभागींचे एकूण (gross) परिणाम मोजतो, तो स्वतःचा परिणाम आणि काहीही केले नसते तरी जे घडले असते त्यातील फरक ओळखू शकत नाही.

डेडवेट हा निश्चित टक्का नाही; तो विशिष्ट लोकसंख्या आणि हस्तक्षेपासाठीच्या प्रतितथ्यावर (counterfactual) पूर्णपणे अवलंबून असतो (पहा [प्रतितथ्य विश्लेषण](../प्रतितथ्य-विश्लेषण/)). पूर्वीच्या Regional Development Agencies अंतर्गत झालेल्या इंग्लंडमधील प्रादेशिक विकासाच्या मूल्यमापनांमध्ये व्यवसाय-सहाय्याच्या प्रकारानुसार डेडवेटचे प्रमाण सामान्यतः 20–60% च्या दरम्यान आढळले; म्हणूनच विश्वासार्ह कार्यक्रम-मूल्यमापने एकच गृहीत आकडा देण्याऐवजी डेडवेट-समायोजित श्रेणी नोंदवतात, आणि National Lottery Community Fund व Big Society Capital यांसारखे निधीदाते अनुदानितांनी सहभागींच्या एकूण संख्या नोंदवण्याऐवजी परिणाम-अहवालात डेडवेटचा स्पष्टपणे विचार करावा, अशी अपेक्षा ठेवतात.

## गणित

यूके मूल्यमापन मार्गदर्शनात (Magenta Book; HM Treasury/BIS Additionality Guide; ESIF आणि संरचनात्मक निधी मूल्यमापन मार्गदर्शन) मांडलेला निव्वळ-परिणाम समायोजनाचा प्रमाण क्रम:

```
एकूण परिणाम (Gross outcome)
  − डेडवेट           (जे तरीही घडले असते)
  − विस्थापन         (इतरत्रून हलवलेली क्रिया/लाभ, नव्याने निर्माण झालेली नाही — पहा
                       displacement-and-attribution)
  − गळती             (लक्ष्य गट/क्षेत्राबाहेर जाणारा लाभ)
  × गुणक             (अतिरिक्त अप्रत्यक्ष/प्रेरित आर्थिक क्रिया, जिथे सकारात्मक असेल तिथे)
  = निव्वळ अतिरिक्त परिणाम
```

डेडवेट दर प्रमाण म्हणून:

```
डेडवेट दर = हस्तक्षेपाशिवाय घडले असते असे परिणाम
             / निरीक्षण केलेले एकूण परिणाम

निव्वळ अतिरिक्त परिणाम = एकूण परिणाम × (1 − डेडवेट दर)
```

## सोडवलेले उदाहरण

**व्यवसाय-सहाय्य अनुदान कार्यक्रम**: एक प्रादेशिक अनुदान योजना कळवते की पाठिंबा दिलेल्या 500 व्यवसायांनी पुढील वर्षात रोजगार वाढवला, सरासरी प्रत्येकी 3 नोकऱ्या — म्हणजे 1,500 नोकऱ्यांचा एकूण दावा.

पाठिंबा न मिळालेल्या तत्सम व्यवसायांचा जुळवलेला तुलना गट (पहा [प्रतितथ्य विश्लेषण](../प्रतितथ्य-विश्लेषण/)) दाखवतो की, त्याच कालावधीत जुळवलेल्या गटाच्या कामगिरीवरून, पाठिंबा मिळालेल्या व्यवसायांतील रोजगारवाढीपैकी 40% तरीही घडली असती.

```
डेडवेट दर = 40%
निव्वळ अतिरिक्त नोकऱ्या = 1,500 × (1 − 0.40) = 900 नोकऱ्या
```

कार्यक्रमाची प्रामाणिकपणे सांगता येण्याजोगी उपलब्धी 900 नोकऱ्या आहे, 1,500 नव्हे — विस्थापन किंवा गळतीचा विचार करण्यापूर्वीच केवळ डेडवेट समायोजनामुळे 40% घट.

**धर्मादाय रोजगार कार्यक्रम**: एक धर्मादाय संस्था £600,000 खर्चात 200 दीर्घकालीन बेरोजगार लोकांना नोकऱ्यांमध्ये ठेवते (एकूण £3,000 प्रति नियुक्ती). राष्ट्रीय श्रमबाजार आकडेवारी दाखवते की, कोणताही हस्तक्षेप नसताना, तुलनायोग्य दीर्घकालीन बेरोजगार गटातील सुमारे 15% लोकांना त्याच कालावधीत नोकरीबाजारातील नैसर्गिक हालचालीमुळे काम मिळते.

```
डेडवेट दर = 15%
निव्वळ अतिरिक्त नियुक्त्या = 200 × (1 − 0.15) = 170
प्रति अतिरिक्त नियुक्तीचा खरा खर्च = £600,000 / 170 ≈ £3,529
```

एकूण प्रति-नियुक्ती आकडा (£3,000) हा संस्थेच्या अतिरिक्त योगदानाचा खरा खर्च सुमारे 15% ने कमी दाखवतो.

## सॉफ्टवेअर अभियांत्रिकीशी संबंध

सार्वजनिक किंवा सामाजिक क्षेत्रासाठी प्रभाव-मापन किंवा अनुदान-व्यवस्थापन सॉफ्टवेअर बनवणाऱ्या कोणासाठीही अतिरिक्तता आणि डेडवेट थेट महत्त्वाचे आहेत.

- परिणाम-अहवाल प्रणालींनी केवळ सहभागींचे परिणाम नव्हे, तर तुलना किंवा आधाररेषा गटही सुरुवातीपासूनच नोंदवला पाहिजे — प्रणाली सुरू झाल्यानंतर प्रतितथ्य नसलेल्या प्रणालीत ते मागाहून जोडणे, सुरुवातीपासूनच नोंदणी अंतर्भूत करण्यापेक्षा कितीतरी कठीण असते (पहा [प्रतितथ्य विश्लेषण](../प्रतितथ्य-विश्लेषण/)).
- केवळ सहभागींच्या एकूण संख्या दाखवणारे डॅशबोर्ड निधीदाते आणि देखरेख संस्थांसमोर प्रभाव पद्धतशीरपणे फुगवून दाखवतात; जिथे डेडवेटचे अंदाज उपलब्ध आहेत (मूल्यमापन साहित्यातून किंवा तुलना गटातून), तिथे सॉफ्टवेअरने एकूण आकड्याच्या जागी नव्हे तर त्याच्या बरोबरीने डेडवेट-वजा निव्वळ आकडा दाखवला पाहिजे.
- याचा थेट संबंध [सामाजिक गुंतवणूक परतावा](../सामाजिक-गुंतवणूक-परतावा/) याच्याशी आहे; त्याचे SROI गुणोत्तर तेव्हाच विश्वासार्ह ठरते जेव्हा दावा केलेल्या एकूण परिणामांतून डेडवेट (आणि विस्थापन) वजा केलेले असते — ही पायरी वगळणारा SROI कॅल्क्युलेटर फुगवलेली गुणोत्तरे देईल, जी छाननीत टिकणार नाहीत.

## सामान्य चुका

- **एकूण परिणाम सर्व अतिरिक्त असल्यासारखे नोंदवणे.** अनुदान आणि कार्यक्रम अहवालातील ही सर्वात सामान्य प्रभाव-मापन चूक आहे; मुख्य आकडा प्रसिद्ध करण्यापूर्वी नेहमी विचारा, "हे तरीही घडले असते का?"
- **एकच डेडवेट टक्का सर्वत्र लागू होतो असे मानणे.** डेडवेट क्षेत्र, लोकसंख्या आणि स्थानिक आर्थिक परिस्थितीनुसार खूप बदलतो; असंबंधित मूल्यमापनातील आकडा पुन्हा वापरण्याऐवजी तुलना गट किंवा क्षेत्र-विशिष्ट पुरावा वापरा.
- **डेडवेटची विस्थापनाशी गल्लत करणे.** डेडवेट म्हणजे त्याच सहभागींसाठीचे प्रतितथ्य परिणाम; विस्थापन म्हणजे इतर लोकांवर किंवा ठिकाणांवरील परिणाम — पहा [विस्थापन आणि कारणत्व](../विस्थापन-आणि-श्रेयनिर्धारण/). दोन्हींची सरमिसळ केल्यास समायोजन दुहेरी मोजले जाते किंवा कमी मोजले जाते.
- **सहभागींनी स्वतः सांगितलेला डेडवेट.** लाभार्थ्यांना "आमच्या मदतीशिवाय हे घडले असते का?" असे विचारल्यास डेडवेटचे अंदाज पद्धतशीरपणे कमी येतात (सहभागी कार्यक्रमाला श्रेय देतात); स्वतंत्र तुलना गट कितीतरी अधिक विश्वासार्ह आहे.
