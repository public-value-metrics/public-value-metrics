# अनुदान परिणाम अहवाल (IRIS+)

अनुदान परिणाम अहवाल (grant outcomes reporting) ही अशी पद्धत आहे ज्यात अनुदान घेणारे निधीदात्यांना प्रमाणित, तुलनायोग्य परिणाम मेट्रिक्स कळवतात — प्रत्येक निधीदाता स्वतःचा वेगळा अहवाल नमुना बनवण्याच्या विपरीत. Global Impact Investing Network (GIIN) द्वारे सांभाळले जाणारे IRIS+ हे असे सर्वात व्यापकपणे स्वीकारलेले मानक आहे: पूर्वनिश्चित सामाजिक, पर्यावरणीय आणि आर्थिक कामगिरी मेट्रिक्सचा कॅटलॉग, जो प्रभाव गुंतवणूकदार आणि वाढत्या प्रमाणात अनुदान देणाऱ्या प्रतिष्ठाने अनुदान घेणाऱ्यांनी वापरावा अशी अट घालतात किंवा शिफारस करतात.

## हे का महत्त्वाचे आहे

प्रमाणित अहवालापूर्वी, प्रत्येक प्रतिष्ठान अनुदान घेणाऱ्यांकडून वेगळ्या स्वरूपात वेगळे निर्देशक मागत असे, आणि दहा निधीदाते असलेली मध्यम आकाराची धर्मादाय संस्था एकमेकांवर आच्छादणाऱ्या कामासाठी दहा समांतर अहवाल प्रक्रिया चालवत असू शकत असे — अनुदान-परिणाम प्रमाणीकरण ज्याला कमी करण्यासाठी अस्तित्वात आहे त्या अहवाल-ओझ्याचे हे चांगल्या प्रकारे दस्तऐवजीकृत कारण आहे. IRIS+ निधीदाते आणि अनुदान घेणाऱ्यांना सामायिक शब्दसंग्रह देऊन हे हाताळते: विषयानुसार गटबद्ध Core Metrics Sets (उदा. परवडणारी घरे, स्वच्छ ऊर्जा उपलब्धता, आर्थिक समावेशन), प्रत्येक मेट्रिक इतक्या अचूकपणे व्याख्यित की "निर्माण केलेले रोजगार" किंवा "सेवा दिलेली कुटुंबे" याचा अर्थ कोणीही कळवला तरी तोच असतो, आणि UN Sustainable Development Goals शी संरेखित, जेणेकरून निधीदाता अनुदान घेणाऱ्या-स्तरावरील डेटा पोर्टफोलिओ-स्तरावरील SDG कथनात एकत्र करू शकतो. GIIN कळवते की IRIS मेट्रिक्स सुमारे निम्म्या प्रभाव गुंतवणूकदारांकडून आणि या क्षेत्रात सक्रिय असलेल्या फंड व्यवस्थापक, बँका आणि विकास वित्तीय संस्थांपैकी बहुसंख्य संस्थांकडून वापरली जातात.

प्रमाणीकरण सर्वाधिक महत्त्वाचे तेथे ठरते जेथे ते [परिणाम विरुद्ध आउटपुट](../परिणाम-विरुद्ध-निष्पादन/) शी जुळते: IRIS+ अहवालाला अनुदान घेणाऱ्याच्या विद्यमान केस व्यवस्थापन प्रणालीत जे काही नोंदते त्याऐवजी व्याख्यित परिणाम आणि प्रभाव मेट्रिक्सकडे ढकलते, आणि [प्रति परिणाम खर्च](../प्रति-परिणाम-खर्च/) विरुद्ध [प्रति लाभार्थी खर्च](../प्रति-लाभार्थी-खर्च/) नेमकी हीच तफावत वर्णन करतात.

## गणित

अनुदान परिणाम अहवाल ही चौकट आणि प्रक्रिया आहे, सूत्र नव्हे:

```
1. Funder selects a Core Metrics Set relevant to the grant's theme
   (e.g. IRIS+ "Financial Inclusion" or "Sustainable Agriculture")
2. Each metric has a fixed definition, unit, and calculation method
   published by GIIN — not invented per-funder
3. Grantee reports against the same metric definitions across all
   its funders using that standard, cutting duplicate reporting effort
4. Funder aggregates grantee-level metrics into portfolio-level reporting,
   comparable year over year and across grantees using the same metric
```

कार्यक्षमतेतील वाढ संयोजनात्मक आहे: N निधीदाते × M अनुदान घेणाऱ्यांना एका सामायिक शब्दसंग्रहावर प्रमाणित केल्याने N×M स्वतंत्र अहवाल-संबंधांचे एका मानकाविरुद्ध सुमारे N+M मॅपिंग होते.

## सोडवलेले उदाहरण

**तीन निधीदाते असलेला अनुदान घेणारा, प्रमाणीकरणापूर्वी**: निधीदाता 1 ला "सेवा दिलेले लोक" मुंडकी-गणना (headcount) व्याख्येनुसार, निधीदाता 2 ला "पोहोचलेले लाभार्थी" कुटुंब व्याख्येनुसार, आणि निधीदाता 3 ला "प्रभावित व्यक्ती" सेवा-प्रसंग व्याख्येनुसार (त्यामुळे दोनदा येणारी एक व्यक्ती दोनदा मोजली जाते) कळवतो. तीन अहवाल, तीन आकडे, एकही तुलनायोग्य नाही, आणि त्याच निधीदात्याच्या पोर्टफोलिओतील दुसऱ्या अनुदान घेणाऱ्याच्या आकड्यांशीही तुलनायोग्य नाही.

**IRIS+ अंतर्गत तोच अनुदान घेणारा**: व्याख्यित IRIS+ पोहोचलेल्या-व्यक्ती मेट्रिकसह संबंधित Core Metrics Set मधील व्याख्यित परिणाम मेट्रिकविरुद्ध, दोन्हींसाठी GIIN च्या प्रकाशित गणना पद्धतीनुसार, अहवाल देतो. तीनही निधीदात्यांना आता तोच आकडा, त्याच पद्धतीने मोजलेला मिळतो, आणि ते या अनुदान घेणाऱ्याचा प्रति IRIS+-व्याख्यित एकक खर्च त्यांच्या पोर्टफोलिओतील इतरांशी एकसमान मेट्रिक वापरून तुलना करू शकतात — अहवाल-पायाभूत सुविधेच्या प्रमाणावर, सामायिक [एकक खर्च डेटाबेस](../एकक-खर्च-डेटाबेस/) असण्याच्या समतुल्य.

## सॉफ्टवेअर अभियांत्रिकीशी संबंध

अनुदान व्यवस्थापन व्यासपीठांनी IRIS+ मेट्रिक अभिज्ञापकांना मुक्त मजकूर नव्हे तर foreign key मानले पाहिजे: अनुदान घेणाऱ्याच्या कळवलेल्या मूल्यासोबत प्रकाशित मेट्रिक कोड साठवणे ("लाभार्थी" नावाचे स्थानिकरीत्या शोधलेले फील्ड नव्हे) हेच नंतर डेटा-स्वच्छता प्रकल्पाशिवाय निधीदात्यांमध्ये आणि पोर्टफोलिओंमध्ये एकत्रीकरण शक्य करते. जिथे व्यासपीठाला IRIS+ न स्वीकारलेल्या निधीदात्यांना पाठबळ द्यावे लागते, तिथे व्यवहार्य रचना अशी की प्रत्येक निधीदात्याला ताबडतोब मानकावर आणण्याऐवजी स्थानिक मेट्रिकला जवळच्या IRIS+ व्याख्येशी मॅप करू द्यावे — आलेखाचा अधिक भाग सामायिक अभिज्ञापकांवर मॅप होत जाईल तसतशी तुलनायोग्यता टप्प्याटप्प्याने सुधारते. गोळा केल्यानंतर कळवलेले आकडे कशाची गणना करण्यासाठी वापरावेत यासाठी भावंड विषय [प्रति परिणाम खर्च](../प्रति-परिणाम-खर्च/) पाहा.

## सामान्य चुका

- **IRIS+ स्वीकार म्हणजे आपोआप तुलनायोग्यता असे मानणे.** दोन अनुदान घेणारे एकाच IRIS+ मेट्रिकविरुद्ध अहवाल देऊनही त्यांचा मूळ डेटा दर्जा किंवा प्रतितथ्यात्मक गृहीतके वेगळी असल्यास तुलनायोग्य नसतात; मानक व्याख्या निश्चित करते, मोजमापाची काटेकोरता नव्हे.
- **निधीदात्याने शोधलेले "IRIS-संरेखित" मेट्रिक्स.** केवळ IRIS+ भाषेतून प्रेरित पण प्रत्यक्ष प्रकाशित व्याख्या नसलेले मेट्रिक, मानक ज्या विखंडनाला सोडवण्यासाठी आहे तेच विखंडन पुन्हा आणते.
- **अतिनिवडीमुळे अहवाल-थकवा.** फक्त दोन किंवा तीन मेट्रिक्स निर्णयाशी संबंधित असताना अनुदान घेणाऱ्याला संपूर्ण Core Metrics Set विरुद्ध अहवाल देण्यास सांगणे हे ओझ्याची समस्या प्रमाणित आवरणात पुन्हा निर्माण करते.
- **परिणाम मेट्रिक अजिबात नसणे.** IRIS+ मध्ये अनेक शुद्ध आउटपुट मेट्रिक्स (उदा. सेवा दिलेल्या लोकांची संख्या) आहेत; फक्त तेच निवडणे आणि परिणाम-स्तराचे एकही नसणे हे परिणाम-अहवालाच्या नावाखाली [प्रति लाभार्थी खर्च](../प्रति-लाभार्थी-खर्च/)-स्वरूपाचा अहवाल तयार करते.
