# ភាពបន្ថែម និងផលដែលនឹងកើតឡើងដោយខ្លួនឯង

ភាពបន្ថែម (additionality) សួរថា តើអន្តរាគមន៍មួយបានបង្កឱ្យមានលទ្ធផលដែលមិនអាចកើតឡើងដោយខ្លួនឯងឬទេ។ ផលដែលនឹងកើតឡើងដោយខ្លួនឯង (deadweight) គឺជាផ្នែកផ្ទុយ៖ ជាសមាមាត្រនៃលទ្ធផលដែលនឹងកើតឡើងដដែល ទោះបីគ្មានកម្មវិធី ជំនួយឧបត្ថម្ភ ឬឧបត្ថម្ភធនក៏ដោយ។ ការអះអាងអំពីផលប៉ះពាល់ស្ទើរតែទាំងអស់ពីកម្មវិធីរដ្ឋាភិបាល ឬសប្បុរសធម៌ តែងតែបំផ្លើសអំពីឥទ្ធិពលរបស់ខ្លួន លុះត្រាតែដកផល deadweight ចេញ ហេតុនេះហើយបានជាការណែនាំស្តីពីការវាយតម្លៃរបស់ចក្រភពអង់គ្លេសចាត់ទុកវាជាការកែតម្រូវដំបូង និងសំខាន់បំផុតចំពោះតួលេខចំណងជើងណាមួយ។

## ហេតុអ្វីបានជាសំខាន់

ពាក្យថា «យើងបានគាំទ្រអាជីវកម្ម 500 ឱ្យលូតលាស់» ស្តាប់ទៅដូចជាសមិទ្ធផលមួយ ប៉ុន្តែប្រសិនបើអាជីវកម្ម 300 ក្នុងចំណោមនោះនឹងលូតលាស់ដដែល ព្រោះសេដ្ឋកិច្ចមូលដ្ឋានកំពុងងើបឡើងវិញ ព្រោះពួកគេមានប្រភពមូលនិធិផ្សេងទៀត ឬព្រោះពួកគេស្ថិតនៅលើគន្លងលូតលាស់រួចហើយមុនពេលកម្មវិធីចាប់ផ្តើម នោះការរួមចំណែកបន្ថែមពិតប្រាកដរបស់កម្មវិធីគឺ 200 មិនមែន 500 ទេ។ សៀវភៅ Magenta Book របស់ HM Treasury និង «Additionality Guide» របស់ HM Treasury/BIS ដែលមានតាំងពីយូរមកហើយ (ដើមឡើយបង្កើតសម្រាប់កម្មវិធីអភិវឌ្ឍន៍តំបន់ និងការស្តារទីក្រុងឡើងវិញ ហើយត្រូវបានប្រើយ៉ាងទូលំទូលាយក្នុងការវាយតម្លៃរបស់រដ្ឋាភិបាលចក្រភពអង់គ្លេសតាំងពីពេលនោះមក) បានកំណត់ deadweight ជាការកែតម្រូវចាប់ផ្តើមក្នុងលំដាប់ផលប៉ះពាល់សុទ្ធស្តង់ដារ៖ ផលសរុប ដកផល deadweight ដកការជំនួស (displacement) ដកការលេចធ្លាយ (leakage) កែតម្រូវតាមឥទ្ធិពលមេគុណ ស្មើនឹងផលប៉ះពាល់បន្ថែមសុទ្ធ។ ការរំលងជំហាននេះ គឺជាមធ្យោបាយទូទៅបំផុតមួយដែលធ្វើឱ្យការអះអាងអំពីផលប៉ះពាល់ក្នុងវិស័យសាធារណៈ និងវិស័យសង្គមត្រូវបានបំផ្លើស ទោះដោយចេតនា ឬដោយអចេតនា ព្រោះកម្មវិធីជំនួយឧបត្ថម្ភដែលវាស់តែលទ្ធផលសរុបរបស់អ្នកចូលរួម ដោយគ្មានក្រុមប្រៀបធៀប មិនអាចញែកឥទ្ធិពលរបស់ខ្លួនចេញពីអ្វីដែលនឹងកើតឡើងដោយមិនគិតពីកម្មវិធីនោះបានឡើយ។

Deadweight មិនមែនជាភាគរយថេរទេ វាអាស្រ័យទាំងស្រុងលើស្ថានភាពប្រៀបធៀបអវត្តមានអន្តរាគមន៍ (counterfactual) សម្រាប់ក្រុមប្រជាជន និងអន្តរាគមន៍ជាក់លាក់ (សូមមើល [ការវិភាគ counterfactual](../ការវិភាគ-counterfactual/))។ ការវាយតម្លៃការអភិវឌ្ឍន៍តំបន់នៅអង់គ្លេស ក្រោមទីភ្នាក់ងារអភិវឌ្ឍន៍តំបន់ (Regional Development Agencies) កាលពីមុន ច្រើនតែរកឃើញអត្រា deadweight ក្នុងចន្លោះ 20–60% ដោយអាស្រ័យលើប្រភេទនៃការគាំទ្រអាជីវកម្ម ដូច្នេះការវាយតម្លៃកម្មវិធីដែលគួរឱ្យទុកចិត្តបានរាយការណ៍ជាចន្លោះដែលបានកែតម្រូវ deadweight ជាជាងតួលេខតែមួយដែលសន្មតទុក ហើយក៏ជាមូលហេតុដែលម្ចាស់មូលនិធិដូចជា National Lottery Community Fund និង Big Society Capital តម្រូវឱ្យអ្នកទទួលជំនួយដោះស្រាយ deadweight ដោយច្បាស់លាស់ក្នុងការរាយការណ៍លទ្ធផល ជាជាងរាយការណ៍ចំនួនអ្នកចូលរួមសរុបប៉ុណ្ណោះ។

## គណិតវិទ្យា

លំដាប់កែតម្រូវផលប៉ះពាល់សុទ្ធស្តង់ដារ ដូចមានចែងក្នុងការណែនាំស្តីពីការវាយតម្លៃរបស់ចក្រភពអង់គ្លេស (Magenta Book; HM Treasury/BIS Additionality Guide; ការណែនាំវាយតម្លៃ ESIF និងមូលនិធិរចនាសម្ព័ន្ធ)៖

```
Gross outcome
  − Deadweight       (what would have happened anyway)
  − Displacement     (activity/benefit shifted from elsewhere, not created — see
                       displacement-and-attribution)
  − Leakage          (benefit accruing outside the target group/area)
  × Multiplier        (additional indirect/induced economic activity, where positive)
  = Net additional impact
```

អត្រា deadweight ជាសមាមាត្រ៖

```
Deadweight rate = outcomes that would have occurred without the intervention
                   / total gross outcomes observed

Net additional outcomes = Gross outcomes × (1 − Deadweight rate)
```

## ឧទាហរណ៍គណនា

**កម្មវិធីជំនួយឧបត្ថម្ភគាំទ្រអាជីវកម្ម**៖ គម្រោងជំនួយឧបត្ថម្ភក្នុងតំបន់មួយរាយការណ៍ថា អាជីវកម្មដែលបានគាំទ្រ 500 បានបង្កើនការងារក្នុងឆ្នាំបន្ទាប់ ជាមធ្យម 3 ការងារក្នុងមួយអាជីវកម្ម ដែលជាការអះអាងសរុប 1,500 ការងារ។

ក្រុមប្រៀបធៀបដែលផ្គូផ្គងរួច ជាអាជីវកម្មស្រដៀងគ្នាដែលមិនបានទទួលការគាំទ្រ (សូមមើល [ការវិភាគ counterfactual](../ការវិភាគ-counterfactual/)) បង្ហាញថា 40% នៃកំណើនការងាររបស់អាជីវកម្មដែលបានគាំទ្រ នឹងកើតឡើងដដែល ដោយផ្អែកលើលទ្ធផលរបស់ក្រុមផ្គូផ្គងក្នុងរយៈពេលដូចគ្នា។

```
Deadweight rate = 40%
Net additional jobs = 1,500 × (1 − 0.40) = 900 jobs
```

សមិទ្ធផលដែលកម្មវិធីអាចរាយការណ៍បានដោយស្មោះត្រង់គឺ 900 ការងារ មិនមែន 1,500 ទេ ដែលជាការថយចុះ 40% ដោយសារតែការកែតម្រូវ deadweight តែប៉ុណ្ណោះ មុនពេលពិចារណាអំពី displacement ឬ leakage ទៅទៀត។

**កម្មវិធីការងាររបស់អង្គការសប្បុរសធម៌**៖ អង្គការសប្បុរសធម៌មួយរកការងារឱ្យអ្នកអត់ការងារធ្វើរយៈពេលយូរចំនួន 200 នាក់ ដោយចំណាយ £600,000 (£3,000 ក្នុងមួយការដាក់ឱ្យចូលធ្វើការ គិតជាសរុប)។ ទិន្នន័យទីផ្សារការងារថ្នាក់ជាតិបង្ហាញថា ប្រសិនបើគ្មានអន្តរាគមន៍ណាមួយទេ ប្រហែល 15% នៃក្រុមអ្នកអត់ការងារធ្វើរយៈពេលយូរដែលអាចប្រៀបធៀបបាន រកការងារបានក្នុងរយៈពេលដូចគ្នា តាមរយៈចលនាធម្មតាក្នុងទីផ្សារការងារ។

```
Deadweight rate = 15%
Net additional placements = 200 × (1 − 0.15) = 170
True cost per additional placement = £600,000 / 170 ≈ £3,529
```

តួលេខថ្លៃចំណាយសរុបក្នុងមួយការដាក់ឱ្យចូលធ្វើការ (£3,000) បានមើលស្រាលថ្លៃចំណាយពិតនៃការរួមចំណែកបន្ថែមរបស់អង្គការសប្បុរសធម៌ ប្រហែល 15%។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

ភាពបន្ថែម និង deadweight សំខាន់ដោយផ្ទាល់សម្រាប់អ្នកដែលកំពុងបង្កើតកម្មវិធីវាស់ផលប៉ះពាល់ ឬកម្មវិធីគ្រប់គ្រងជំនួយឧបត្ថម្ភសម្រាប់វិស័យសាធារណៈ ឬវិស័យសង្គម៖

- ប្រព័ន្ធរាយការណ៍លទ្ធផលគួរតែប្រមូលក្រុមប្រៀបធៀប ឬក្រុមមូលដ្ឋានតាំងពីការរចនា មិនមែនត្រឹមតែលទ្ធផលរបស់អ្នកចូលរួមប៉ុណ្ណោះទេ ព្រោះការបន្ថែម counterfactual ក្រោយពេលប្រព័ន្ធដំណើរការដោយគ្មានវា ពិបាកជាងការដាក់បញ្ចូលការប្រមូលទិន្នន័យតាំងពីដំបូងឆ្ងាយណាស់ (សូមមើល [ការវិភាគ counterfactual](../ការវិភាគ-counterfactual/))។
- ផ្ទាំងគ្រប់គ្រង (dashboard) ដែលរាយការណ៍តែចំនួនអ្នកចូលរួមសរុប នឹងបំផ្លើសផលប៉ះពាល់ជាប្រព័ន្ធចំពោះម្ចាស់មូលនិធិ និងស្ថាប័នត្រួតពិនិត្យ ដូច្នេះនៅពេលមានការប៉ាន់ស្មាន deadweight (ពីអក្សរសិល្ប៍វាយតម្លៃ ឬក្រុមប្រៀបធៀប) កម្មវិធីគួរបង្ហាញតួលេខដកផល deadweight រួចរួមជាមួយតួលេខសរុប មិនមែនជំនួសវាឡើយ។
- នេះភ្ជាប់ដោយផ្ទាល់ទៅនឹង [ផលត្រឡប់សង្គមលើការវិនិយោគ](../ផលចំណេញសង្គមលើការវិនិយោគ/) ដែលសមាមាត្រ SROI របស់វាអាចទុកចិត្តបានលុះត្រាតែបានដក deadweight (និង displacement) ចេញពីលទ្ធផលសរុបដែលបានអះអាង ដូច្នេះម៉ាស៊ីនគណនា SROI ដែលរំលងជំហាននេះ នឹងផលិតសមាមាត្រដែលត្រូវបានបំផ្លើស ហើយមិនអាចទប់ទល់នឹងការត្រួតពិនិត្យបាន។

## កំហុសដែលតែងកើតមាន

- **ការរាយការណ៍លទ្ធផលសរុប ដូចជាវាទាំងអស់ជាលទ្ធផលបន្ថែម។** នេះគឺជាកំហុសក្នុងការវាស់ផលប៉ះពាល់ដែលកើតមានញឹកញាប់បំផុតក្នុងការរាយការណ៍ជំនួយឧបត្ថម្ភ និងកម្មវិធី ដូច្នេះត្រូវសួរជានិច្ចថា «តើរឿងនេះនឹងកើតឡើងដដែលឬទេ?» មុនពេលបោះពុម្ពផ្សាយតួលេខចំណងជើង។
- **ការសន្មតថាភាគរយ deadweight តែមួយអាចប្រើបានគ្រប់កន្លែង។** Deadweight ប្រែប្រួលខ្លាំងតាមវិស័យ ក្រុមប្រជាជន និងស្ថានភាពសេដ្ឋកិច្ចមូលដ្ឋាន ដូច្នេះត្រូវប្រើក្រុមប្រៀបធៀប ឬភស្តុតាងតាមវិស័យជាក់លាក់ ជាជាងយកតួលេខពីការវាយតម្លៃដែលមិនពាក់ព័ន្ធមកប្រើឡើងវិញ។
- **ការច្រឡំ deadweight ជាមួយ displacement។** Deadweight ទាក់ទងនឹងលទ្ធផល counterfactual សម្រាប់អ្នកចូលរួមដដែល ចំណែក displacement ទាក់ទងនឹងឥទ្ធិពលលើមនុស្ស ឬទីកន្លែងផ្សេងទៀត សូមមើល [ការជំនួស និងការសន្មតមូលហេតុ](../ការបំលាស់ទី-និងការសន្មតផល/)។ ការច្រឡំទាំងពីរនាំឱ្យមានការរាប់ស្ទួន ឬរាប់ខ្វះក្នុងការកែតម្រូវ។
- **deadweight ដែលអ្នកចូលរួមរាយការណ៍ដោយខ្លួនឯង។** ការសួរអ្នកទទួលផលថា «តើរឿងនេះនឹងកើតឡើងដោយគ្មានជំនួយរបស់យើងឬទេ?» បង្កើតការប៉ាន់ស្មាន deadweight ទាបជាប្រព័ន្ធ (អ្នកចូលរួមមានទំនោរផ្តល់កិត្តិយសដល់កម្មវិធី) ដូច្នេះក្រុមប្រៀបធៀបឯករាជ្យគួរឱ្យទុកចិត្តជាងឆ្ងាយ។
