# សូចនាករសំខាន់ៗនៃការអនុវត្ត (KPI) ក្នុងវិស័យសាធារណៈ

សូចនាករសំខាន់នៃការអនុវត្ត (key performance indicator, KPI) គឺជារង្វាស់ដែលបានជ្រើសរើស និងតាមដាន ដើម្បីតំណាងឱ្យថាតើសេវាសាធារណៈកំពុងបំពេញការងាររបស់ខ្លួនបានល្អឬអត់។ នៅក្នុងរដ្ឋាភិបាល ការជ្រើសរើស KPI មិនដែលអព្យាក្រឹតទេ៖ ដោយសារ KPI ភ្ជាប់ទៅនឹងថវិកា តារាងចំណាត់ថ្នាក់ និងអាជីព ការជ្រើសរើសមួយក៏រៀបចំឥរិយាបថរបស់អ្នកទាំងអស់នៅខាងក្រោម ជារឿយៗខ្លាំងជាងគោលនយោបាយដែលបង្កើតសេវានោះទៅទៀត។

## ហេតុអ្វីបានជាសំខាន់

ការសង្កេតរបស់ Charles Goodhart ក្នុងឆ្នាំ 1975 លើគោលនយោបាយរូបិយវត្ថុ — ដែលក្រោយមក Marilyn Strathern ធ្វើឱ្យពេញនិយមថា "នៅពេលរង្វាស់ក្លាយជាគោលដៅ វាឈប់ជារង្វាស់ល្អ" — គឺជាស្លាកព្រមានសំខាន់បំផុតតែមួយនៅក្នុងការគ្រប់គ្រងដំណើរការវិស័យសាធារណៈ។ KPI ដែលត្រូវបានជ្រើសរើសដើម្បី*ពិពណ៌នា*ប្រព័ន្ធមួយ ចាប់ផ្តើម*បំភ្លៃ*ប្រព័ន្ធនោះភ្លាមៗ នៅពេលដែលធនធាន ប្រាក់ឈ្នួល ឬការរស់រានមានជីវិតនយោបាយភ្ជាប់ទៅនឹងវា។ ឧទាហរណ៍បុរាណគឺពេលវេលាឆ្លើយតបរបស់រថយន្តសង្គ្រោះបន្ទាន់ NHS៖ នៅពេលដែលគោលដៅឆ្លើយតបប្រភេទ A ប្រាំបីនាទីក្លាយជាកាតព្វកិច្ច Trust ខ្លះត្រូវបានបង្ហាញថា "ជង់" រថយន្តសង្គ្រោះបន្ទាន់នៅខាងក្រៅនាឡិកាពេលវេលាឆ្លើយតប ឬចាត់ថ្នាក់ការហៅឡើងវិញ ដើម្បីឈានដល់លេខ ដោយមិនផ្លាស់ប្តូរលទ្ធផលអ្នកជំងឺ។ ការណែនាំរបស់ National Audit Office នៃចក្រភពអង់គ្លេស អំពីការជ្រើសរើស និងប្រើសូចនាករដំណើរការ — ដែលចែងក្នុងរបាយការណ៍តម្លៃសមស្របនឹងថវិការបស់ខ្លួន និងក្របខ័ណ្ឌ "Performance Measurement by Regulators" និង "Choosing the Right FABRIC" (Fit for purpose, Appropriate, Balanced, Robust, Integrated, Cost-effective) — មានដោយសារតែនាយកដ្ឋានបន្តជ្រើសរើសសូចនាករដែលងាយរាយការណ៍ ជាជាងសូចនាករដែលពិបាកបន្លំ។ វិស្វករកម្មវិធីដែលចេញផ្ទាំងគ្រប់គ្រងដែលរដ្ឋមន្ត្រី ឬនាយកនឹងត្រូវបានវិនិច្ឆ័យតាម គឺកំពុងរចនារចនាសម្ព័ន្ធលើកទឹកចិត្តរបស់ស្ថាប័នសាធារណៈមួយ ទោះបីមានចេតនាឬអត់។

## គណិតវិទ្យា

ការរចនា KPI គឺជាប្រធានបទទម្រង់ក្របខ័ណ្ឌ ប៉ុន្តែ*ការវាយតម្លៃ* KPI បេក្ខភាពគឺជាបញ្ជីត្រួតពិនិត្យដែលអាចធ្វើឡើងវិញបាន មិនមែនរូបមន្តទេ៖

```
សម្រាប់ KPI បេក្ខភាពនីមួយៗ ដាក់ពិន្ទុតាម៖
  Fit for purpose  — តើវាវាស់លទ្ធផល ឬជាតំណាងដែលឆ្ងាយច្រើនជំហាន?
  Appropriate      — តើវាជារបស់អ្នកដែលអាចមានឥទ្ធិពលលើវាពិតប្រាកដឬទេ?
  Balanced         — តើវាត្រូវបានភ្ជាប់ជាមួយរង្វាស់ប្រឆាំងដែលចាប់ការបន្លំឬទេ?
  Robust           — តើវាអាចឈរបានក្នុងសវនកម្ម ឬជារបាយការណ៍ខ្លួនឯងដែលមិនអាចផ្ទៀងផ្ទាត់?
  Integrated       — តើវាសមនឹងសំណុំទូលំទូលាយ ឬច្រានចោល KPI ផ្សេងទៀត?
  Cost-effective   — តើការប្រមូលវាថ្លៃជាងការសម្រេចចិត្តដែលវាផ្តល់ព័ត៌មានឬទេ?

ការបំបែកសូចនាករនាំមុខ ធៀបនឹងសូចនាករតាមក្រោយ៖
  សូចនាករនាំមុខ    → ព្យាករលទ្ធផលអនាគត ប៉ុន្តែជារឿយៗអាចបន្លំបាន (ឧ. ការហៅឆ្លើយក្នុង <60 វិនាទី)
  សូចនាករតាមក្រោយ  → បញ្ជាក់ថាលទ្ធផលបានកើតឡើង ប៉ុន្តែមកដល់យឺតពេលក្នុងការដឹកនាំ (ឧ. ការស្ទង់មតិ
                        ការពេញចិត្តប្រចាំឆ្នាំ)
  សំណុំ KPI ដែលអាចការពារបាន ភ្ជាប់យ៉ាងតិចមួយនៃប្រភេទនីមួយៗក្នុងមួយគោលបំណង។
```

## ឧទាហរណ៍គណនា

**Trust សេវារថយន្តសង្គ្រោះបន្ទាន់**៖ Trust មួយរាយការណ៍ KPI ពេលវេលាឆ្លើយតបប្រភេទ A (គំរាមកំហែងជីវិត) ថា "75% នៃការហៅត្រូវបានឆ្លើយតបក្នុងរយៈពេល 8 នាទី"។ ក្នុងត្រីមាសមួយ ការហៅប្រភេទ A ចំនួន 6,000 ចូលមក 4,500 ត្រូវបានបំពេញក្នុងរយៈពេល 8 នាទី ផ្តល់ 75.0% — ហាក់ដូចជាសម្រេចគោលដៅ។

```
KPI ចំណងជើង = 4,500 / 6,000 × 100 = 75.0%  (បំពេញកម្រិត 75%)
```

ប៉ុន្តែសវនកម្ម Goodhart បន្ថែមរង្វាស់ប្រឆាំង៖ ពេលវេលាឆ្លើយតបមធ្យមសម្រាប់ 10% យឺតបំផុតនៃការហៅ។

```
ពេលវេលាឆ្លើយតបមធ្យមនៃដេស៊ីលយឺតបំផុត = 34 នាទី (ឡើងពី 19 នាទី កាលពីពីរឆ្នាំមុន)
```

Trust កំពុងសម្រេចគោលដៅ ខណៈដែលកន្ទុយ — ការហៅដែលទំនងជាគំរាមកំហែងជីវិតពិតបំផុត នៅពេលដែលការចាត់ថ្នាក់មិនល្អឥតខ្ចោះ — កាន់តែអាក្រក់ខ្លាំង ព្រោះក្រុមត្រូវបានផ្តល់អាទិភាពទៅរកការហៅដែលជិតគែមច្រាំង 8 នាទី ជាជាងទៅរកភាពបន្ទាន់ព្យាបាល។ KPI តែមួយប្រាប់រឿងមិនពិត។ KPI គូប្រាប់រឿងពិត។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

វិស្វករដែលសាងសង់ផ្ទាំងគ្រប់គ្រងដំណើរការសម្រាប់រដ្ឋាភិបាល ពិតជាកំពុងរចនា API ការលើកទឹកចិត្តរបស់ស្ថាប័ន។ ផលប៉ះពាល់ជាក់ស្តែង៖ ដាក់ឧបករណ៍វាស់*ភាគបែង*ឱ្យតឹងរ៉ឹងដូចភាគយក (KPI ដែលរាយការណ៍ជាភាគរយទទេអញ្ជើញការបន្លំភាគបែង — សូមមើល [ថ្លៃដើមក្នុងមួយប្រតិបត្តិការ](../ថ្លៃចំណាយក្នុងមួយប្រតិបត្តិការ/) សម្រាប់អន្ទាក់ដូចគ្នាក្នុងសេវាឌីជីថល)។ សាងសង់រង្វាស់ប្រឆាំងចូលក្នុងផ្ទាំងគ្រប់គ្រងតែមួយ ជាជាងរបាយការណ៍ដាច់ដោយឡែកដែលគ្មាននរណាអាន ដើម្បីឱ្យការបន្លំអាចមើលឃើញនៅចំណុចសម្រេចចិត្ត។ ហើយគ្រប់គ្រងកំណែនិយមន័យ KPI ព្រោះការកំណត់និយមន័យឡើងវិញដោយស្ងាត់ៗ (ការផ្លាស់ប្តូរអ្វីដែលរាប់ជា "ការហៅ" "ករណី" ឬ "ការបញ្ចប់") ស្មើនឹងការផ្លាស់ប្តូរគោលដៅដោយមិនប្រកាស។ [ក្រដាសពិន្ទុតម្លៃសាធារណៈ](../ក្រដាសពិន្ទុតម្លៃសាធារណៈ/) គឺជាវិធីមានរចនាសម្ព័ន្ធមួយដើម្បីបញ្ឈប់ KPI តែមួយមិនឱ្យត្រូវបានអានដាច់ដោយឡែក ហើយ[គណនេយ្យភាពផ្អែកលើលទ្ធផល](../គណនេយ្យភាពផ្អែកលើលទ្ធផល/) គឺជាវិន័យនៃការជ្រើសរើស KPI កម្រិតប្រជាជន ដែលក្រុមតែមួយមិនអាចបំភ្លៃដោយឯកតោភាគី។

## កំហុសដែលតែងកើតមាន

- **ជ្រើសរង្វាស់ដែលងាយប្រមូល ជាជាងរង្វាស់ដែលមានន័យ**៖ ពេលវេលាឆ្លើយការហៅស្រួលកត់ត្រា។ ការហៅនោះដោះស្រាយបញ្ហារបស់ប្រជាពលរដ្ឋឬអត់ មិនស្រួលទេ — ប៉ុន្តែមានតែចំណុចទីពីរប៉ុណ្ណោះដែលជាលទ្ធផល។ ចៀសវាងការជ្រើសអ្វីដែលប្រព័ន្ធបញ្ចេញរួចហើយ។
- **គ្មានរង្វាស់ប្រឆាំង**៖ KPI ណាដែលភ្ជាប់ទៅនឹងប្រាក់ ឬកេរ្តិ៍ឈ្មោះ នឹងត្រូវបានបន្លំនៅគែម។ ចេញវាជាមួយរង្វាស់គូដែលចាប់វ៉ិចទ័របន្លំដែលទំនងកើតឡើង មុនពេលបោះពុម្ពផ្សាយ។
- **កំណត់រង្វាស់ឡើងវិញដោយគ្មានកំណត់ត្រាការផ្លាស់ប្តូរ**៖ ការប្តូរ "ការហៅដែលទទួលបាន" ទៅ "ការហៅដែលបានឆ្លើយ" ដើម្បីបំផ្លើសនិន្នាការ បំផ្លាញភាពជឿជាក់នៃស៊េរីពេលវេលាភ្លាមៗនៅពេលរកឃើញ — តែងតែបោះពុម្ពកំណត់ត្រាការផ្លាស់ប្តូរនិយមន័យ រួមជាមួយលេខ។
- **ច្រឡំសកម្មភាពជាមួយលទ្ធផល**៖ ការរាប់ការត្រួតពិនិត្យដែលបានបញ្ចប់ គឺជាទិន្នផល។ ការរាប់ទីតាំងដែលត្រូវបាននាំឱ្យអនុលោមតាម ជិតជាងទៅរកលទ្ធផល (សូមមើល
  [លទ្ធផល ធៀបនឹង ទិន្នផល](../លទ្ធផល-ធៀបនឹង-ទិន្នផល/))។
