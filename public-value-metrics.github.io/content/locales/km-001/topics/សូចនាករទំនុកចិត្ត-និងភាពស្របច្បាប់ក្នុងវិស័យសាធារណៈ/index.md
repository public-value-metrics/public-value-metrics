# សូចនាករទំនុកចិត្ត និងភាពស្របច្បាប់ក្នុងវិស័យសាធារណៈ

ភាពស្របច្បាប់ និងការគាំទ្រ គឺជាជើងមួយក្នុងចំណោមបីនៃ "ត្រីកោណយុទ្ធសាស្ត្រ" របស់ Mark Moore ក្នុង *Creating Public Value* (1995) ជាមួយនឹងតម្លៃសាធារណៈខ្លួនឯង និងសមត្ថភាពប្រតិបត្តិការ ហើយវាជាជើងដែលភាគច្រើនមិនត្រូវបានវាស់ ពីព្រោះមិនដូចថវិកា ឬចំនួនទិន្នផលទេ ភាពស្របច្បាប់គ្មានលេខតែមួយច្បាស់លាស់ភ្ជាប់នឹងវា។ សូចនាករទំនុកចិត្ត និងភាពស្របច្បាប់ គឺជាក្រុមវិធានការតំណាងដែលរដ្ឋាភិបាលប្រើដើម្បីបំពេញគម្លាតនោះ៖ ការស្ទង់មតិទំនុកចិត្តលើស្ថាប័ន ការវាយតម្លៃទំនុកចិត្តរបស់អង្គភាពត្រួតពិនិត្យ ទិន្នន័យបណ្តឹង និងបណ្តឹងឧទ្ធរណ៍ និងសូចនាករនៃការគាំទ្រខាងនយោបាយ/នីតិប្បញ្ញត្តិ។

## ហេតុអ្វីបានជាសំខាន់

អំណះអំណាងរបស់ Moore គឺថា អ្នកគ្រប់គ្រងសាធារណៈដែលផ្តល់តម្លៃពិតប្រាកដ ប៉ុន្តែបាត់បង់ភាពស្របច្បាប់ខាងនយោបាយ និងសាធារណៈ នឹងបាត់បង់បរិយាកាសអនុញ្ញាតដែលចាំបាច់ដើម្បីបន្តផ្តល់វានៅទីបំផុត គឺថវិកាត្រូវកាត់ អាណត្តិត្រូវរួម ហើយសេវាត្រូវអត់ឃ្លាន ទោះលទ្ធផលល្អប៉ុណ្ណាក៏ដោយ។ ដូច្នេះភាពស្របច្បាប់មិនមែនជាការផ្សព្វផ្សាយទំនាក់ទំនងសាធារណៈ ដែលបន្ថែមក្រោយលើតារាងពិន្ទុបំពេញការងារទេ វាជាធាតុបញ្ចូលទ្រទ្រង់ទម្ងន់ ថាតើបេសកកម្មអាចបន្តបានឬអត់ ដែលជាមូលហេតុដែលវាស្ថិតជាទស្សនៈស្មើគ្នាក្នុង[ក្រដាសពិន្ទុតម្លៃសាធារណៈ](../ក្រដាសពិន្ទុតម្លៃសាធារណៈ/) ជាជាងជាកំណត់សម្គាល់ខាងក្រោម។ កម្មវិធីស្ទង់មតិ "Trust in Government" របស់ OECD គឺជាការព្យាយាមឆ្លងប្រទេសឈានមុខគេ ក្នុងការវាស់វែងបញ្ហានេះ៖ វាតាមដានចំណែកនៃពលរដ្ឋនៅទូទាំងប្រទេសសមាជិក OECD ដែលនិយាយថាពួកគេមានទំនុកចិត្តលើរដ្ឋាភិបាលជាតិរបស់ខ្លួន ហើយទិន្នន័យរយៈពេលវែងរបស់វាបង្ហាញថា ទំនុកចិត្តរសើបខ្លាំងចំពោះការប៉ះទង្គិច ទាំងវិបត្តិហិរញ្ញវត្ថុឆ្នាំ 2008 និងជំងឺរាតត្បាត COVID-19 បង្កឱ្យមានការប្រែប្រួលយ៉ាងខ្លាំងនៅកម្រិតជាតិ ជារឿយៗបន្ទាប់ដោយការងើបឡើងវិញដោយផ្នែកតែប៉ុណ្ណោះ ដោយការវិភាគរបស់ OECD រកឃើញជាប់លាប់ថា *សមត្ថភាព* ដែលយល់ឃើញ (តើរដ្ឋាភិបាលផ្តល់អ្វីដែលវាសន្យាឬអត់) និង *យុត្តិធម៌/សុចរិតភាព* ដែលយល់ឃើញ (តើរដ្ឋាភិបាលត្រូវបានគេមើលឃើញថាធ្វើសកម្មភាពដោយគ្មានអំពើពុករលួយ ឬការរើសអើងឬអត់) គឺជាកត្តាជំរុញខ្លាំងបំផុតពីរនៃតួលេខទំនុកចិត្ត ដាច់ដោយឡែកពីការពេញចិត្តលើប្រតិបត្តិការតែមួយ។ រដ្ឋាភិបាលកាន់តែព្យាយាមដាក់ឱ្យប្រតិបត្តិភាពស្របច្បាប់នៅកម្រិតលម្អិតជាងមុនដែរ អ្នកគ្រប់គ្រង និងអង្គភាពត្រួតពិនិត្យឯករាជ្យរបស់ចក្រភពអង់គ្លេស (ការិយាល័យសវនកម្មជាតិ អ្នកផ្សះផ្សាសភា និងសេវាសុខភាព និងអ្នកគ្រប់គ្រងវិស័យដូចជា Ofsted និង Care Quality Commission) ដើរតួជាការត្រួតពិនិត្យភាពស្របច្បាប់ជាស្ថាប័ន ដែលបម្លែង "តើសាធារណជននៅតែទុកចិត្តសេវានេះឬអត់" ទៅជាការវាយតម្លៃដែលអាចធ្វើសវនកម្មបាន។

## គណិតវិទ្យា

ទំនុកចិត្ត និងភាពស្របច្បាប់ជាប្រធានបទដែលមានរូបរាងជាក្របខ័ណ្ឌ ដែលតំណាងបរិមាណដែលអាចប្រើបានរួមមាន៖

```
សន្ទស្សន៍ទំនុកចិត្តលើស្ថាប័ន (តាមបែប OECD)
  = % នៃអ្នកឆ្លើយស្ទង់មតិដែលឆ្លើយ "បាទ/ចាស" ចំពោះសំណួរទំនុកចិត្តលើរដ្ឋាភិបាល
    តាមដានតាមពេលវេលា បែងចែកតាមក្រុមប្រជាសាស្ត្រ

សំណុំតំណាងភាពស្របច្បាប់ (គ្មានលេខតែមួយជំនួសគំនិតនេះបានទេ)៖
  - បណ្តឹងដែលបានទទួលស្គាល់ក្នុងអ្នកប្រើសេវា 1,000 នាក់ (ទិន្នន័យអ្នកផ្សះផ្សា ឬបណ្តឹងផ្ទៃក្នុង)
  - អត្រាជោគជ័យនៃការពិនិត្យតុលាការ / បណ្តឹងឧទ្ធរណ៍ប្រឆាំងការសម្រេចចិត្តរបស់អង្គភាព
  - ការវាយតម្លៃរបស់អ្នកគ្រប់គ្រង/អង្គភាពត្រួតពិនិត្យឯករាជ្យ (ឧ. ក្រុម "ឆ្នើម" ដល់ "មិនគ្រប់គ្រាន់")
  - ការបោះឆ្នោតទំនុកចិត្តរបស់គណៈកម្មាធិការនីតិប្បញ្ញត្តិ/ត្រួតពិនិត្យ ឬភាពញឹកញាប់នៃរបាយការណ៍រិះគន់
  - បរិមាណសំណើសេរីភាពនៃព័ត៌មាន និងអត្រាបង្ហាញ/បដិសេធ ជាតំណាង
    នៃតម្លាភាពដែលយល់ឃើញ

ភាពស្របច្បាប់ត្រូវបានបញ្ជាក់ដោយភស្តុតាង មិនមែនគណនាទេ៖ ការវាយតម្លៃភាពស្របច្បាប់ដែលអាចការពារបាន
ធ្វើត្រីកោណរួមនៃពីរឬច្រើនខាងលើ ជាជាងពឹងផ្អែកលើតំណាងតែមួយ។
```

```

  64% ពីរឆ្នាំមុន)

ការអានឆ្លងកាត់ទាំងបី៖ ទំនុកចិត្តកំពុងធ្លាក់ បណ្តឹងដែលទទួលស្គាល់កំពុងកើន និង
ការរកឃើញរបស់អ្នកផ្សះផ្សាឯករាជ្យកាន់តែចាប់ជ្រើសខាងប្រឆាំងអាជ្ញាធរ
```

តួលេខតែមួយក្នុងចំណោមទាំងនេះផ្លាស់ប្តូរ គឺជាភស្តុតាងខ្សោយ ប៉ុន្តែវិធានការឯករាជ្យបីដែលផ្លាស់ប្តូរជាមួយគ្នាក្នុងអំឡុងពេលដូចគ្នា គឺជាលំនាំដែលធ្វើឱ្យការអះអាងភាពស្របច្បាប់អាចការពារបាន។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

សូចនាករភាពស្របច្បាប់កម្រត្រូវបានផលិតដោយផ្ទាំងគ្រប់គ្រងរបស់ក្រុមតែមួយ ដែលខ្លួនវាជាមេរៀនរចនា៖ កសាងបំពង់រាយការណ៍ដែលអាចទទួល និងផ្សះផ្សាទិន្នន័យពីប្រភពខាងក្រៅឯករាជ្យ (ប្រព័ន្ធករណីរបស់អ្នកផ្សះផ្សា ព័ត៌មានវាយតម្លៃរបស់អ្នកគ្រប់គ្រង អ្នកលក់ការស្ទង់មតិ) ជាជាងរចនាស្ថាបត្យកម្មរាយការណ៍ភាពស្របច្បាប់ជាសូចនាករផ្ទៃក្នុងតែប៉ុណ្ណោះ ពីព្រោះការអះអាងភាពស្របច្បាប់ដែលមានប្រភពផ្ទៃក្នុង ("យើងវាយតម្លៃខ្លួនឯងថាគួរឱ្យទុកចិត្ត") មានទម្ងន់ភស្តុតាងតិចតួច គឺបញ្ហាឯករាជ្យភាពដូចគ្នាដែលបានកត់សម្គាល់សម្រាប់ទស្សនៈភាពស្របច្បាប់ក្នុង[ក្រដាសពិន្ទុតម្លៃសាធារណៈ](../ក្រដាសពិន្ទុតម្លៃសាធារណៈ/)។ បំពង់ទិន្នន័យបណ្តឹង និងបណ្តឹងឧទ្ធរណ៍សមនឹងទទួលភាពតឹងរ៉ឹងគុណភាពទិន្នន័យដូចបំពង់លទ្ធផលណាមួយដែលបញ្ចូលកិច្ចសន្យា[ការបង់ប្រាក់តាមលទ្ធផល](../ការបង់ប្រាក់តាមលទ្ធផល-និងមូលបត្របំណុលផលប៉ះពាល់សង្គម/) ដោយសារសំណុំទិន្នន័យបណ្តឹងដែលរាយការណ៍តិច ឬចាត់ថ្នាក់មិនល្អ ធ្វើឱ្យបញ្ហាភាពស្របច្បាប់ទាបជាងការពារដោយស្ងាត់ស្ងៀម មុនពេលវាអាចមើលឃើញក្នុងការស្ទង់មតិទំនុកចិត្តមួយឆ្នាំក្រោយមក។ សូមមើល
[សូចនាករការពេញចិត្តរបស់ពលរដ្ឋ](../រង្វាស់ការពេញចិត្តរបស់ពលរដ្ឋ/) សម្រាប់ផ្នែកដែលត្រូវគ្នាកម្រិតប្រតិបត្តិការនៃវិធានការកម្រិតស្ថាប័ននេះ និង[តម្លៃសាធារណៈ](../តម្លៃសាធារណៈ/) សម្រាប់ក្របខ័ណ្ឌត្រីកោណយុទ្ធសាស្ត្រពេញលេញរបស់ Moore ដែលជើងនេះជាកម្មសិទ្ធិ។

## កំហុសដែលតែងកើតមាន

- **ការចាត់ទុកការពេញចិត្តជាតំណាងនៃភាពស្របច្បាប់**៖ ពលរដ្ឋម្នាក់អាចពេញចិត្តនឹងចំណុចប្រទាក់នៃប្រតិបត្តិការតែមួយ ខណៈដែលមិនទុកចិត្តស្ថាប័នទាំងមូល (ឬផ្ទុយមកវិញ) សូមមើល [សូចនាករការពេញចិត្តរបស់ពលរដ្ឋ](../រង្វាស់ការពេញចិត្តរបស់ពលរដ្ឋ/) ពីមូលហេតុដែលទាំងពីរត្រូវរាយការណ៍ដោយឡែកពីគ្នា។
- **ការពឹងផ្អែកលើវិធានការរាយការណ៍ខ្លួនឯងតែមួយ**៖ ការស្ទង់មតិទំនុកចិត្តដែលដំណើរការផ្ទៃក្នុង ដោយគ្មានការបញ្ជាក់ឯករាជ្យ (ទិន្នន័យអ្នកផ្សះផ្សា ការវាយតម្លៃអ្នកគ្រប់គ្រង) ងាយនឹងត្រូវបដិសេធថាជាការដាក់ពិន្ទុខ្លួនឯង ត្រូវធ្វើត្រីកោណ។
- **ការមិនអើពើការបែងចែកតាមប្រជាសាស្ត្រ**៖ តួលេខទំនុកចិត្តជាតិសរុបអាចលាក់ភាពស្របច្បាប់ដែលខុសគ្នាខ្លាំងក្នុងចំណោមក្រុមជាក់លាក់ (តាមអាយុ ជនជាតិ ប្រាក់ចំណូល ឬតំបន់) ការចេញផ្សាយ Trust in Government របស់ OECD ផ្ទាល់បែងចែកដោយសារមូលហេតុនេះ។
- **ការអានការធ្លាក់ចុះដែលបណ្តាលពីការប៉ះទង្គិចតែមួយថាជានិន្នាការអចិន្ត្រៃយ៍**៖ តួលេខទំនុកចិត្តផ្លាស់ប្តូរយ៉ាងខ្លាំងជុំវិញវិបត្តិ (ការដួលរលំហិរញ្ញវត្ថុ ជំងឺរាតត្បាត ពាក្យចចាមអារ៉ាមធំៗ) ហើយងើបឡើងវិញមួយផ្នែក ចំណុចទិន្នន័យក្រោយការប៉ះទង្គិចតែមួយមិនគួរត្រូវបានបន្តទៅជាការធ្លាក់ចុះរយៈពេលវែងដោយគ្មានទិន្នន័យបន្ថែមទេ។
