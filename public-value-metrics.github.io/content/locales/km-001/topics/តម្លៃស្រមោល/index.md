# តម្លៃស្រមោល

តម្លៃស្រមោល (shadow price) គឺជាតម្លៃប៉ាន់ស្មានដែលកំណត់ឱ្យទំនិញ ធនធាន ឬផលប៉ះពាល់ខាងក្រៅ (externality) ណាមួយដែលគ្មានតម្លៃទីផ្សារដែលអាចសង្កេតបាន ឬដែលតម្លៃទីផ្សាររបស់វាមានភាពរូងរេ ហើយមិនឆ្លុះបញ្ចាំងពីតម្លៃសង្គមពិតប្រាកដរបស់វា។ ការវាយតម្លៃគម្រោងរបស់រដ្ឋាភិបាលពឹងផ្អែកលើតម្លៃស្រមោលផ្លូវការមួយចំនួនតូច ដូចជា កាបូន ពេលវេលាក្រៅម៉ោងធ្វើការ និងកម្លាំងពលកម្មដែលអ្នកធ្វើការនឹងគ្មានការងារធ្វើ ដែលត្រូវបានផ្សព្វផ្សាយពីមជ្ឈមណ្ឌលកណ្តាល ដើម្បីឱ្យគ្រប់ក្រសួងទាំងអស់ប្រើតួលេខតែមួយ។

## ហេតុអ្វីបានជាសំខាន់

តម្លៃស្រមោលមានឡើង ពីព្រោះ[ការវិភាគថ្លៃដើម-អត្ថប្រយោជន៍សង្គម](../ការវិភាគថ្លៃដើម-អត្ថប្រយោជន៍សង្គម/) មិនអាចដំណើរការបានទេ បើគ្មានតម្លៃជាប្រាក់សម្រាប់រាល់ថ្លៃចំណាយ និងអត្ថប្រយោជន៍នីមួយៗ។ ហើយធាតុសំខាន់ៗមួយចំនួនដូចជា កាបូនមួយតោនដែលបានបញ្ចេញ ម៉ោងធ្វើដំណើរមួយម៉ោងរបស់អ្នកធ្វើដំណើរទៅធ្វើការ ឬម៉ោងពលកម្មមួយម៉ោងរបស់អ្នកដែលបើមិនដូច្នេះនឹងគ្មានការងារធ្វើ គឺគ្មានតម្លៃទីផ្សារទាល់តែសោះ ឬមានតម្លៃទីផ្សារដែលបង្ហាញខុសពីថ្លៃចំណាយសង្គមពិតប្រាកដរបស់វា។ ក្រសួងរតនាគារអង់គ្លេស (HM Treasury) និងក្រសួងសន្តិសុខថាមពល និងសូន្យពុលសុទ្ធ (Department for Energy Security and Net Zero) ចេញផ្សាយរួមគ្នាជាបន្តបន្ទាប់នូវតម្លៃស្រមោលនៃកាបូន ដែលត្រូវបានប្រើក្នុងការវាយតម្លៃគម្រោងទាំងអស់របស់រដ្ឋាភិបាលអង់គ្លេស

តម្លៃស្រមោលកម្រប៉ះពាល់ដល់ការអភិវឌ្ឍកម្មវិធីដោយផ្ទាល់ ប៉ុន្តែវាសំខាន់នៅពេលណាដែលករណីអាជីវកម្មអះអាងអត្ថប្រយោជន៍កាបូន ឬសង្គមពីការផ្លាស់ប្តូរ IT។ ឧទាហរណ៍ ការបញ្ចូលមជ្ឈមណ្ឌលទិន្នន័យអះអាងថាសន្សំកាបូន ឬសេវាគ្មានក្រដាសអះអាងថាជៀសវាងកាបូនពីការបោះពុម្ព និងប្រៃសណីយ៍ ត្រូវប្រើតម្លៃស្រមោលផ្លូវការបច្ចុប្បន្ននៃកាបូន ជាជាងតួលេខប្រឌិត ហើយត្រូវប្រើតារាងតាមឆ្នាំត្រឹមត្រូវ ជាជាងអត្រាថេរ ដូចគ្នាទៅនឹងធាតុបញ្ចូលវាយតម្លៃ Green Book ផ្សេងទៀតដែរ។ សូមមើល

## កំហុសដែលតែងកើតមាន

- **ការប្រើតួលេខកាបូន ឬប្រាក់ឈ្នួលហួសសម័យ។** តម្លៃទាំងពីរត្រូវបានកែសម្រួលតាមកាលកំណត់ដោយការណែនាំកណ្តាល។ ការវាយតម្លៃដែលផ្អែកលើតួលេខដែលត្រូវជំនួសហើយ នឹងមិនអាចឆ្លងកាត់ការត្រួតពិនិត្យរបស់ក្រសួងរតនាគារបានទេ។
- **ការប្រើតម្លៃកាបូនស្រមោលថេរពេញមួយការវាយតម្លៃច្រើនទសវត្ស។** តារាងផ្លូវការកើនឡើងតាមពេលវេលា ការប្រើតម្លៃឆ្នាំទី 1 ពេញមួយរយៈពេលធ្វើឱ្យទម្រង់នៃអត្ថប្រយោជន៍ ឬថ្លៃចំណាយខុសពីការពិត។
- **ការច្រលំអត្រាប្រាក់ឈ្នួលស្រមោលជាមួយការបញ្ចុះប្រាក់ខែពិតរបស់កម្មករ។** អត្រាប្រាក់ឈ្នួលស្រមោលកែសម្រួលការវាយតម្លៃ*ក្នុងការវាយតម្លៃគម្រោង*នូវធាតុបញ្ចូលពលកម្ម មិនមែនប្រាក់ឈ្នួលដែលកម្មករទទួលបានជាក់ស្តែងទេ ការច្រលំទាំងពីរនេះអាចនាំឱ្យមានការបង្ហាញហេតុផល (មិនត្រឹមត្រូវ) ដើម្បីបង់ប្រាក់ទាបជាងទីផ្សារ។
- **ការបង្កើតតម្លៃស្រមោលផ្ទាល់ខ្លួនជំនួសឱ្យការប្រើតម្លៃផ្លូវការ។** តម្លៃស្រមោលជាសន្ធិសញ្ញាគោលនយោបាយ ដើម្បីឱ្យការវាយតម្លៃអាចប្រៀបធៀបបានរវាងក្រសួងនានា។ តួលេខដែលបង្កើតក្នុងមូលដ្ឋាន ទោះមានហេតុផលល្អប៉ុណ្ណាក៏ដោយ ក៏បំផ្លាញលទ្ធភាពប្រៀបធៀបនោះដែរ។
