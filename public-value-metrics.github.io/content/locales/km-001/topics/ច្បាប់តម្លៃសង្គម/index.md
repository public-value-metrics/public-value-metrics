# ច្បាប់តម្លៃសង្គម

ច្បាប់សេវាសាធារណៈ (តម្លៃសង្គម) ឆ្នាំ 2012 (Public Services (Social Value) Act 2012) គឺជាកាតព្វកិច្ចតាមច្បាប់របស់ចក្រភពអង់គ្លេស ដែលតម្រូវឱ្យអាជ្ញាធរសាធារណៈនៅអង់គ្លេស និងវែលស៍ ពិចារណាថាតើអ្វីដែលកំពុងទិញអាចកែលម្អសុខុមាលភាពសេដ្ឋកិច្ច សង្គម និងបរិស្ថាននៃតំបន់ពាក់ព័ន្ធបានយ៉ាងដូចម្តេច ហើយពិចារណាពិគ្រោះយោបល់លើបញ្ហានេះ មុនចាប់ផ្តើមដំណើរការទិញសម្រាប់កិច្ចសន្យាសេវាសាធារណៈ។ វាចូលជាធរមាននៅខែមករា 2013 ជាកាតព្វកិច្ច "ត្រូវគិតគូរ" ដែលមានសម្ពាធស្រាល ហើយត្រូវបានពង្រឹងយ៉ាងខ្លាំងដោយកំណត់ចំណាំគោលនយោបាយលទ្ធកម្ម (Procurement Policy Note, PPN) 06/20 នៅខែមករា 2021 ដែលតម្រូវឱ្យកិច្ចសន្យារដ្ឋាភិបាលកណ្តាលវាយតម្លៃតម្លៃសង្គមយ៉ាងច្បាស់លាស់ មិនមែនគ្រាន់តែពិចារណាទេ ដោយមានទម្ងន់អប្បបរមាក្នុងលក្ខខណ្ឌផ្តល់ជ័យលាភី។

## ហេតុអ្វីបានជាសំខាន់

មុន PPN 06/20 ការ "ពិចារណា" តម្លៃសង្គមអាចត្រូវបានបំពេញដោយអ្នកដាក់បញ្ជាទិញកត់ចំណាំថាខ្លួនបានគិតអំពីវា ដោយគ្មានតម្រូវការណាមួយឱ្យវាប៉ះពាល់ដល់ការសម្រេចចិត្តផ្តល់កិច្ចសន្យា ជាកាតព្វកិច្ចដែលងាយបំពេញលើក្រដាស ហើយមិនអើពើក្នុងការអនុវត្តជាក់ស្តែង។ PPN 06/20 បានបិទគម្លាតនោះសម្រាប់លទ្ធកម្មរដ្ឋាភិបាលកណ្តាល៖ វាតម្រូវឱ្យតម្លៃសង្គមត្រូវបានដាក់ពិន្ទុជាផ្នែកមួយនៃការវាយតម្លៃការដេញថ្លៃ ដែលរៀបចំជុំវិញប្រធានបទអាទិភាពជាតិប្រាំ គឺ ការងើបឡើងវិញពី COVID-19 ការដោះស្រាយវិសមភាពសេដ្ឋកិច្ច ការប្រយុទ្ធប្រឆាំងការប្រែប្រួលអាកាសធាតុ ឱកាសស្មើគ្នា និងសុខុមាលភាព ហើយជាទូទៅត្រូវបានវាស់ដោយប្រើក្របខ័ណ្ឌ National TOMs (Themes, Outcomes, Measures) ដែលថែរក្សាដោយ Social Value Portal។ សម្រាប់វិស្វករកម្មវិធីដែលកសាងឧបករណ៍លទ្ធកម្ម ការគ្រប់គ្រងកិច្ចសន្យា ឬការគាំទ្រការដេញថ្លៃសម្រាប់វិស័យសាធារណៈ នេះគឺជាមូលដ្ឋានផ្លូវច្បាប់ដែលអតិថិជនរបស់អ្នកត្រូវតែកសាងតាម មិនមែនជាអ្វីដែលល្អមានទេ។

## គណិតវិទ្យា

តម្លៃសង្គមគឺជាប្រធានបទដែលមានរូបរាងជាក្របខ័ណ្ឌ "គណិតវិទ្យា" របស់វាគឺរចនាសម្ព័ន្ធដាក់ពិន្ទុដែលអាជ្ញាធរភាគច្រើនប្រើ៖

```
ពិន្ទុដេញថ្លៃសរុប = ទម្ងន់តម្លៃ/ថ្លៃចំណាយ + ទម្ងន់គុណភាព + ទម្ងន់តម្លៃសង្គម

PPN 06/20 (រដ្ឋាភិបាលកណ្តាល)៖ ទម្ងន់តម្លៃសង្គម ≥ 10% នៃពិន្ទុសរុប

ប្រធានបទតម្លៃសង្គម (PPN 06/20)៖
 1. ការងើបឡើងវិញពី COVID-19
 2. ការដោះស្រាយវិសមភាពសេដ្ឋកិច្ច
 3. ការប្រយុទ្ធប្រឆាំងការប្រែប្រួលអាកាសធាតុ
 4. ឱកាសស្មើគ្នា
 5. សុខុមាលភាព
```

អ្នកដេញថ្លៃជាទូទៅបម្លែងការប្តេជ្ញាចិត្តរបស់ខ្លួនទៅជាប្រាក់ធៀបនឹងប្រធានបទទាំងនេះ ដោយប្រើ
[មូលដ្ឋានទិន្នន័យថ្លៃចំណាយឯកតា](../មូលដ្ឋានទិន្នន័យថ្លៃចំណាយឯកតា/) ហើយតក្កវិជ្ជាបម្លែងជាប្រាក់ដូចគ្នាដែលប្រើក្នុង
[ផលចំណេញសង្គមលើការវិនិយោគ](../ផលចំណេញសង្គមលើការវិនិយោគ/) អនុវត្ត៖ ការប្តេជ្ញាចិត្តគួរតែមានភស្តុតាង អាចសន្មត់ទៅកិច្ចសន្យា និងមិនរាប់ស្ទួនជាមួយមូលនិធិផ្សេងទៀត។

## ឧទាហរណ៍គណនា

## កំហុសដែលតែងកើតមាន

- **ការលាបពណ៌សង្គមលើការដេញថ្លៃ (social-washing)។** ការប្តេជ្ញាចិត្តមិនច្បាស់លាស់ ("យើងគាំទ្រសហគមន៍ក្នុងមូលដ្ឋាន") ដែលមិនអាចវាស់ ឬទាមទារក្នុងអំឡុងការគ្រប់គ្រងកិច្ចសន្យា ទទួលបានពិន្ទុល្អ ប៉ុន្តែមិនផ្តល់អ្វីដែលអាចផ្ទៀងផ្ទាត់បាន។
- **ការចាត់ទុកតម្លៃសង្គមជាអ្នកកាត់ក្តីស្មើពិន្ទុ។** PPN 06/20 តម្រូវឱ្យតម្លៃសង្គមត្រូវបានវាយតម្លៃយ៉ាងច្បាស់លាស់ក្នុងលក្ខខណ្ឌផ្តល់ជ័យលាភី មិនមែនប្រើដោយមិនផ្លូវការដើម្បីកាត់ក្តីស្មើគ្នារវាងការដេញថ្លៃដែលស្មើគ្នាទេ។
- **គ្មានការតាមដានការគ្រប់គ្រងកិច្ចសន្យា។** ការប្តេជ្ញាចិត្តដែលបានដាក់ពិន្ទុនៅពេលដេញថ្លៃ ជារឿយៗមិនដែលត្រូវបានតាមដានក្នុងអំឡុងការអនុវត្ត សូមមើល [ការសម្រេចអត្ថប្រយោជន៍](../ការសម្រេចអត្ថប្រយោជន៍/)។
- **ក្របខ័ណ្ឌវាស់វែងមិនស៊ីសង្វាក់គ្នាឆ្លងកាត់កិច្ចសន្យា។** ការប្រើប្រភពតំណាងខុសគ្នាសម្រាប់ការប្តេជ្ញាចិត្តស្រដៀងគ្នានៅលើកិច្ចសន្យាខុសគ្នា ធ្វើឱ្យការប្រៀបធៀបកម្រិតផលប័ត្រគ្មានន័យ ដែលជាមូលហេតុដែលក្របខ័ណ្ឌរួមដូចជា National TOMs និងមូលដ្ឋានទិន្នន័យថ្លៃចំណាយឯកតារួមមាន។
