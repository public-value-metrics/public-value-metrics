# ផលចំណេញសង្គមលើការវិនិយោគ

ផលចំណេញសង្គមលើការវិនិយោគ (Social Return on Investment, SROI) គឺជាក្របខ័ណ្ឌសម្រាប់វាស់វែង បម្លែងជាប្រាក់ និងគណនេយ្យនូវគំនិតទូលំទូលាយនៃតម្លៃ គឺតម្លៃសង្គម បរិស្ថាន និងសេដ្ឋកិច្ច ហើយបង្ហាញជាសមាមាត្រធៀបនឹងធនធានដែលបានវិនិយោគ ឧទាហរណ៍ "តម្លៃសង្គម £1.44 សម្រាប់រាល់ £1 ដែលបានវិនិយោគ"។ វាត្រូវបានរចនាឡើងដើម្បីពង្រីកតក្កវិជ្ជាគណនេយ្យហិរញ្ញវត្ថុទៅកាន់លទ្ធផលដែលទីផ្សារមិនកំណត់តម្លៃ ដោយមិនបាត់បង់វិន័យរបស់គណនេយ្យ៖ រាល់លេខក្នុង SROI ត្រូវតែអាចតាមដានទៅកាន់លទ្ធផលដែលភាគីពាក់ព័ន្ធបានកំណត់ មូលដ្ឋានភស្តុតាង និងការកែតម្រូវច្បាស់លាស់សម្រាប់អ្វីដែលនឹងកើតឡើងឯណាមួយ។

## ហេតុអ្វីបានជាសំខាន់

SROI ត្រូវបានថែរក្សាដោយ Social Value UK និង Social Value International ដែលជាអង្គការស្នងតំណែងពី SROI Network ដែល "A Guide to Social Return on Investment" (2012) របស់ពួកគេនៅតែជាវិធីសាស្ត្រយោង។ ក្របខ័ណ្ឌនេះផ្អែកលើគោលការណ៍ប្រាំពីរ គឺ ចូលរួមជាមួយភាគីពាក់ព័ន្ធ យល់ពីអ្វីដែលផ្លាស់ប្តូរ វាយតម្លៃអ្វីដែលសំខាន់ រួមបញ្ចូលតែអ្វីដែលមានសារៈសំខាន់ កុំអះអាងហួសហេតុ មានតម្លាភាព និងផ្ទៀងផ្ទាត់លទ្ធផល ហើយគោលការណ៍ទីប្រាំ "កុំអះអាងហួសហេតុ" គឺជាអ្វីដែលរបាយការណ៍ SROI ភាគច្រើនជាក់ស្តែងបរាជ័យ។ សមាមាត្រដែលបង្កើតដោយរំលងការកែតម្រូវ deadweight និងការសន្មតផល មិនមែនជា SROI ទេ វាគឺជាលេខផ្សព្វផ្សាយដែលពាក់សម្លៀកបំពាក់របស់ SROI។ វិស្វករកម្មវិធីដែលកសាងឧបករណ៍រាយការណ៍សម្រាប់អង្គការសប្បុរសធម៌ សហគ្រាសសង្គម ឬអ្នកដាក់បញ្ជាទិញ ត្រូវដឹងពីភាពខុសគ្នា ពីព្រោះឧបករណ៍នឹងអនុវត្តវិន័យ ឬធ្វើឱ្យវាងាយស្រួលរំលង។

```
ដំណើរការ៖

 6. រាយការណ៍ ប្រើប្រាស់ និងបញ្ចូលក្នុងប្រព័ន្ធ សមាមាត្រគឺជាឧបករណ៍ទំនាក់ទំនង មិនមែនចំណុចបញ្ចប់ទេ
```

## ឧទាហរណ៍គណនា

**កម្មវិធីការងាររបស់អាជ្ញាធរមូលដ្ឋាន**៖ ថ្លៃចំណាយធាតុបញ្ចូលប្រចាំឆ្នាំ £250,000។ អ្នកចូលរួមហុកសិបនាក់ទទួលបានការងារយូរអង្វែង។ តំណាងហិរញ្ញវត្ថុសម្រាប់លទ្ធផលនោះ (ការកើនសុខុមាលភាព ការពឹងផ្អែកលើប្រាក់ឧបត្ថម្ភថយចុះ និងចំណូលពន្ធរួមបញ្ចូលគ្នា) គឺ £8,500 ក្នុងមួយនាក់សម្រាប់ឆ្នាំដំបូង សូមមើល [មូលដ្ឋានទិន្នន័យថ្លៃចំណាយឯកតា](../មូលដ្ឋានទិន្នន័យថ្លៃចំណាយឯកតា/) សម្រាប់ប្រភពនៃតំណាងបែបនេះ។

- តម្លៃលទ្ធផលសរុប៖ 60 × £8,500 = £510,000
- ដក deadweight (40% ទំនងជារកការងារបានដោយគ្មានកម្មវិធី)៖ £510,000 × 0.60 = £306,000
- ដកការសន្មតផល (30% នៃការផ្លាស់ប្តូរដែលនៅសល់ គឺដោយសារការគាំទ្ររបស់ទីភ្នាក់ងារផ្សេងទៀត)៖ £306,000 × 0.70 = £214,200
- លទ្ធផលឆ្នាំទី 2 ដោយការធ្លាក់ចុះ 30%៖ £214,200 × 0.70 = £149,940 បញ្ចុះតម្លៃ 3.5%/ឆ្នាំ (សូមមើល
  [អត្រាបញ្ចុះតម្លៃសង្គម](../អត្រាបញ្ចុះតម្លៃសង្គម/))៖ £149,940 ÷ 1.035 = £144,870
- តម្លៃបច្ចុប្បន្នសរុបនៃផលប៉ះពាល់៖ £214,200 + £144,870 = £359,070
- **សមាមាត្រ SROI៖ £359,070 ÷ £250,000 = 1.44** រាយការណ៍ថា "តម្លៃសង្គម £1.44 សម្រាប់រាល់ £1 ដែលបានវិនិយោគ"

**អង្គការសប្បុរសធម៌**៖ សេវាមិត្តភាព £60,000 កាត់បន្ថយភាពឯកកោសម្រាប់មនុស្សចាស់ 80 នាក់ ដែលត្រូវបានវាយតម្លៃដោយតំណាង £1,100/នាក់/ឆ្នាំ។ តម្លៃសរុប £88,000 បន្ទាប់ពី deadweight 35% និងការសន្មតផល 15% ផលប៉ះពាល់សុទ្ធគឺ £88,000 × 0.65 × 0.85 = £48,620 សមាមាត្រ SROI 0.81 ដែលក្រោមចំណុចស្មើទុន ជាការរកឃើញស្របច្បាប់ និងមានប្រយោជន៍ មិនមែនជាការបរាជ័យក្នុងការសរសេររបាយការណ៍ទេ។

## កំហុសដែលតែងកើតមាន

- **ការរំលង deadweight និងការសន្មតផល។** សមាមាត្រចម្បងដែលគ្មានការកែតម្រូវទាំងនេះ គឺតួលេខសរុប មិនមែនតួលេខផលប៉ះពាល់សុទ្ធទេ ហើយគោលការណ៍របស់ Social Value UK តម្រូវទាំងពីរយ៉ាងច្បាស់លាស់។
- **ការប្រៀបធៀបសមាមាត្រឆ្លងកាត់អង្គការ។** សមាមាត្រ SROI អាស្រ័យលើវិសាលភាព និងជម្រើសតំណាងដែលធ្វើជាករណីៗ។ ការចាត់ទុកសមាមាត្រ 4:1 ពីរបាយការណ៍មួយថា "ប្រសើរជាង" សមាមាត្រ 2:1 ពីរបាយការណ៍មួយទៀត មិនអើពើថា ការសន្មត់ទាំងនោះមិនមានស្តង់ដារដូចសមាមាត្រគណនេយ្យហិរញ្ញវត្ថុទេ។
- **ការរាប់ស្ទួននូវតំណាងដែលត្រួតគ្នា។** ការដាក់បន្ថែមតំណាង "ភាពឯកកោថយចុះ" ជាមួយតំណាង "សុខុមាលភាពផ្លូវចិត្តប្រសើរឡើង" សម្រាប់អ្នកទទួលផលដូចគ្នា អាចវាយតម្លៃទ្វេដងលើការផ្លាស់ប្តូរមូលដ្ឋានតែមួយ។
- **ការរំលងការចូលរួមរបស់ភាគីពាក់ព័ន្ធ។** គោលការណ៍ទីមួយតម្រូវឱ្យលទ្ធផលត្រូវបានកំណត់ជាមួយអ្នកដែលជួបប្រទះវា មិនមែនសន្មត់ដោយអ្នកវិភាគដែលកសាងគំរូទេ។
