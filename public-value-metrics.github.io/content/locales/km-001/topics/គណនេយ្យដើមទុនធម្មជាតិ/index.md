# គណនេយ្យដើមទុនធម្មជាតិ

គណនេយ្យដើមទុនធម្មជាតិដាក់បរិស្ថាននៅលើមូលដ្ឋានដូចគ្នានឹងទ្រព្យសកម្មជាតិ ឬស្ថាប័នផ្សេងទៀត៖ វាវាស់ស្តុកធនធានធម្មជាតិ (ព្រៃឈើ ដី ទន្លេ វាលភក់ បរិយាកាស) និងចរន្តសេវាដែលពួកវាផលិត (ការស្រូបកាបូន ការការពារទឹកជំនន់ ការកម្សាន្ត អាហារ) ទាំងក្នុងលក្ខខណ្ឌរូបវន្ត និងរូបិយវត្ថុ ដើម្បីឱ្យការថយចុះនៃបរិស្ថានបង្ហាញក្នុងការសម្រេចចិត្ត ដូចការប្រើប្រាស់ដើមទុនហិរញ្ញវត្ថុ។ ចក្រភពអង់គ្លេសគឺជារដ្ឋាភិបាលមួយក្នុងចំណោមរដ្ឋាភិបាលដែលជឿនលឿនបំផុតក្នុងការធ្វើរឿងនេះជាប្រព័ន្ធ ដែលជំរុញដោយផែនការបរិស្ថាន 25 ឆ្នាំ (2018) ហើយអនុវត្តតាមរយៈគណនីដើមទុនធម្មជាតិចក្រភពអង់គ្លេសរបស់ ONS និងការណែនាំបន្ថែមរបស់ Green Book នៃ HM Treasury។

## ហេតុអ្វីបានជាសំខាន់

គណនេយ្យធម្មតា — ទាំងសាជីវកម្ម និងរដ្ឋាភិបាល — ចាត់ទុកព្រៃឈើថាគ្មានតម្លៃរហូតដល់វាត្រូវបានកាប់ និងលក់ជាឈើ ពេលនោះវាក្លាយជា GDP។ គណនេយ្យដើមទុនធម្មជាតិមានដើម្បីបិទគម្លាតនោះ៖ ផែនការបរិស្ថាន 25 ឆ្នាំរបស់ចក្រភពអង់គ្លេសបានប្តេជ្ញាឱ្យរដ្ឋាភិបាលបង្កប់គំនិតដើមទុនធម្មជាតិទូទាំងគោលនយោបាយ ដោយចែងយ៉ាងច្បាស់នូវមហិច្ឆតា ដើម្បីជា "ជំនាន់ដំបូងដែលទុកបរិស្ថានក្នុងស្ថានភាពប្រសើរជាងពេលយើងរកឃើញ"។ ONS បានបោះពុម្ពគណនីដើមទុនធម្មជាតិចក្រភពអង់គ្លេសប្រចាំឆ្នាំតាំងពីពេលនោះ (<https://www.ons.gov.uk/economy/environmentalaccounts/bulletins/uknaturalcapitalaccounts/latest>) ដែលប៉ាន់ស្មានតម្លៃរូបិយវត្ថុនៃសេវាប្រព័ន្ធអេកូឡូស៊ី — ពីការកម្សាន្តក្នុងព្រៃឈើ ដល់អត្ថប្រយោជន៍សុខភាពនៃទីធ្លាបៃតងក្នុងទីក្រុង ដល់ការរក្សាទុកកាបូនក្នុងវាលភក់ — ដោយប្រើក្របខ័ណ្ឌគណនីជាតិដូចគ្នាដែលប្រើសម្រាប់ដើមទុនដែលផលិត ដូច្នេះនៅទីបំផុតដើមទុនធម្មជាតិអាចស្ថិតក្នុងតារាងតុល្យការដូចគ្នាជាមួយផ្លូវ អគារ និងឧបករណ៍។ ការណែនាំ Enabling a Natural Capital Approach (ENCA) របស់ HM Treasury ដែលបន្ថែមលើ Green Book
(<https://www.gov.uk/government/publications/enabling-a-natural-capital-approach-enca-guidance>)
ចែងពីរបៀបដែលអ្នកវាយតម្លៃគួរវាយតម្លៃថ្លៃដើម និងអត្ថប្រយោជន៍បរិស្ថានក្នុងករណីអាជីវកម្ម ដូច្នេះគម្រោងផ្លូវដែលបំផ្លាញព្រៃបុរាណ ឬគម្រោងទឹកជំនន់ដែលស្តារវាលភក់ អាចត្រូវបានប្រៀបធៀបលើលក្ខខណ្ឌរូបិយវត្ថុស្របគ្នា ជាជាងមួយមានលេខ ហើយមួយទៀតមានកថាខណ្ឌនៃការព្រមាន។

## គណិតវិទ្យា

```
តម្លៃទ្រព្យសកម្មសេវាប្រព័ន្ធអេកូឡូស៊ី = NPV នៃចរន្តសេវាដែលទ្រព្យសកម្មផ្តល់

តម្លៃទ្រព្យសកម្ម = Σ (t = 1 ដល់ T) [តម្លៃចរន្តសេវាប្រចាំឆ្នាំ_t / (1 + r)^t]

ដែល៖
  តម្លៃចរន្តសេវា_t = បរិមាណសេវាក្នុងឆ្នាំ t × តម្លៃឯកតា
                          (ឧ. ការទស្សនាកម្សាន្ត × តម្លៃក្នុងមួយការទស្សនា
                           តោនកាបូនដែលស្រូប × តម្លៃកាបូន)
  r = អត្រាបញ្ចុះតម្លៃ (អត្រាបញ្ចុះតម្លៃសង្គមរបស់ Green Book — សូមមើល
      [អត្រាបញ្ចុះតម្លៃសង្គម](../អត្រាបញ្ចុះតម្លៃសង្គម/))
  T = ផ្តេកពេលវេលាដែលទ្រព្យសកម្មត្រូវបានរំពឹងថាផ្តល់សេវា
```

នេះគឺជារចនាសម្ព័ន្ធតម្លៃបច្ចុប្បន្នសុទ្ធដូចគ្នាដែលប្រើដើម្បីវាយតម្លៃដើមទុនដែលផលិត ឬវាយតម្លៃការវិនិយោគសាធារណៈណាមួយក្រោម[ការវាយតម្លៃ Green Book](../ការវាយតម្លៃតាម-green-book/) — ការរួមចំណែករបស់គណនេយ្យដើមទុនធម្មជាតិគឺការផ្តល់បរិមាណរូបវន្ត និងតម្លៃឯកតាដែលអាចជឿជាក់បាន សម្រាប់សេវាដែលពីមុនត្រូវបានកំណត់តម្លៃសូន្យ។

## ឧទាហរណ៍គណនា

**ព្រៃឈើក្នុងទីក្រុង តម្លៃកម្សាន្ត**៖ ព្រៃឈើ 50 ហិកតា ទទួលបានការទស្សនាកម្សាន្តប៉ាន់ស្មាន 80,000 ក្នុងមួយឆ្នាំ នីមួយៗត្រូវបានវាយតម្លៃ (តាមវិធីសាស្ត្រថ្លៃធ្វើដំណើរ ឬចំណូលចិត្តដែលបានប្រកាស — សូមមើល [ការវាយតម្លៃតាមចំណូលចិត្តដែលបានបង្ហាញ](../ការវាយតម្លៃតាមចំណូលចិត្តដែលបានបង្ហាញ/) និង [ការវាយតម្លៃតាមចំណូលចិត្តដែលបានប្រកាស](../ការវាយតម្លៃតាមចំណូលចិត្តដែលបានប្រកាស/)) £3 ក្នុងមួយការទស្សនា។ ព្រៃឈើត្រូវបានរំពឹងថានឹងបន្តផ្តល់សេវានេះរយៈពេល 50 ឆ្នាំ ដែលវាយតម្លៃក្នុងអត្រាបញ្ចុះតម្លៃ 3.5%។

```
តម្លៃកម្សាន្តប្រចាំឆ្នាំ = 80,000 × £3 = £240,000/ឆ្នាំ

NPV ក្នុងរយៈពេល 50 ឆ្នាំ ក្នុង 3.5% ≈ £240,000 × កត្តាប្រាក់ឆ្នាំ (3.5%, 50 ឆ្នាំ)
កត្តាប្រាក់ឆ្នាំ (3.5%, 50) ≈ 21.4

តម្លៃទ្រព្យសកម្ម ≈ £240,000 × 21.4 ≈ £5,136,000
```

**បន្ថែមការរក្សាទុកកាបូន**៖ ព្រៃឈើដូចគ្នាស្រូប CO2 ប្រហែល 400 តោនក្នុងមួយឆ្នាំ ដែលវាយតម្លៃតាមតម្លៃកាបូនមិនជួញដូររបស់រដ្ឋាភិបាលប្រហែល £75/តោន (ជាឧទាហរណ៍ — ប្រើតម្លៃកាបូនដែលបានបោះពុម្ពបច្ចុប្បន្នរបស់ BEIS/DESNZ សម្រាប់ការវាយតម្លៃផ្ទាល់)។

```
តម្លៃកាបូនប្រចាំឆ្នាំ = 400 × £75 = £30,000/ឆ្នាំ
NPV ក្នុងរយៈពេល 50 ឆ្នាំ ក្នុង 3.5% ≈ £30,000 × 21.4 ≈ £642,000

តម្លៃទ្រព្យសកម្មព្រៃឈើសរុប (កម្សាន្ត + កាបូន) ≈ £5,136,000 + £642,000
                                                   ≈ £5,778,000
```

នេះគឺមុនបន្ថែមការបន្ថយទឹកជំនន់ ជីវចម្រុះ ឬសេវាគុណភាពខ្យល់ដែលការណែនាំ ENCA ក៏សុំឱ្យអ្នកវាយតម្លៃពិចារណា — ចំនួនសរុបគឺជាកម្រិតខាងក្រោមដោយចេតនា មិនមែនកម្រិតខាងលើទេ។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

- ប្រព័ន្ធបរិស្ថាន និងគ្រប់គ្រងទ្រព្យសកម្មសម្រាប់អាជ្ញាធរមូលដ្ឋាន និងទីភ្នាក់ងារ (សួនច្បារ ផ្លូវហាយវ៉េ តួរាងទឹក) អាចភ្ជាប់ចុះបញ្ជីដើមទុនធម្មជាតិក្បែរចុះបញ្ជីទ្រព្យសកម្មរូបវន្ត ដោយប្រើលំនាំចរន្តសេវាគុណនឹងតម្លៃឯកតាដូចគ្នាជាមួយ[មូលដ្ឋានទិន្នន័យថ្លៃឯកតា](../មូលដ្ឋានទិន្នន័យថ្លៃចំណាយឯកតា/)ណាមួយដែលស្ថាប័នថែរក្សា។
- ដោយសារ NPV ដើមទុនធម្មជាតិប្រែប្រួលតាមអត្រាបញ្ចុះតម្លៃ (សូមមើលកត្តាប្រាក់ឆ្នាំក្នុងឧទាហរណ៍គណនា) ឧបករណ៍ណាដែលគណនាវាគួរបង្ហាញអត្រា និងផ្តេកពេលវេលាជាធាតុចូលដែលមើលឃើញ មិនកប់វាទេ — គោលការណ៍តម្លាភាពដូចគ្នាដែលបានគ្របដណ្តប់ក្រោម
  [សមធម៌អន្តរជំនាន់ និងការបញ្ចុះតម្លៃចីរភាព](../សមធម៌រវាងជំនាន់-និងការបញ្ចុះតម្លៃនិរន្តរភាព/)។
- គណនីដើមទុនធម្មជាតិកាន់តែក្លាយជាធាតុចូលចាំបាច់ចំពោះផ្នែកផលប៉ះពាល់បរិស្ថាននៃករណីអាជីវកម្ម[ការវាយតម្លៃ Green Book](../ការវាយតម្លៃតាម-green-book/)។ ក្រុមផ្តល់ជូនដែលសាងសង់ឧបករណ៍ករណីអាជីវកម្ម គួរចាត់ទុកគណនី ONS និងតម្លៃឯកតា ENCA ជាទិន្នន័យយោងដើម្បីរួមបញ្ចូល មិនមែនអ្វីដែលអ្នកវាយតម្លៃគណនាឡើងវិញពីសូន្យរាល់ពេលទេ។

## កំហុសដែលតែងកើតមាន

- **រាប់ទ្វេដងនូវសេវាប្រព័ន្ធអេកូឡូស៊ីដែលត្រួតស៊ីគ្នា** — តម្លៃកម្សាន្ត និងតម្លៃជីវចម្រុះសម្រាប់ទីតាំងតែមួយអាចចែករំលែកទិន្នន័យឆន្ទៈបង់ដែលមូលដ្ឋានដូចគ្នា។ ការណែនាំ ENCA ព្រមានយ៉ាងច្បាស់ប្រឆាំងនឹងការបូកការវាយតម្លៃដែលទាញពីឧបករណ៍ស្ទង់មតិត្រួតស៊ីគ្នា។
- **ចាត់ទុកតម្លៃទ្រព្យសកម្មដើមទុនធម្មជាតិថាស្ថិតនឹង** — ចរន្តសេវាផ្លាស់ប្តូរតាមអាកាសធាតុ ការគ្រប់គ្រង និងសម្ពាធការប្រើប្រាស់ដី។ តម្លៃកាបូន និងការបន្ថយទឹកជំនន់របស់ព្រៃឈើក្នុងទសវត្សរ៍នេះ មិនមែនជាលក្ខណៈអចិន្ត្រៃយ៍របស់ទីតាំងទេ។
- **ប្រើតម្លៃឯកតាមធ្យមជាតិសម្រាប់ការសម្រេចចិត្តដែលមានលក្ខណៈមូលដ្ឋានខ្លាំង** — ហិកតានៃព្រៃក្នុងទីក្រុងដែលអាចចូលដំណើរការបាន និងហិកតានៃតំបន់ខ្ពង់រាបឆ្ងាយមានតម្លៃកម្សាន្តខុសគ្នាខ្លាំង។ ការណែនាំ ENCA ណែនាំតម្លៃមូលដ្ឋាន ឬជាក់លាក់ទីតាំង កន្លែងដែលមាន ជាជាងប្រើមធ្យមជាតិតាមលំនាំដើម។
