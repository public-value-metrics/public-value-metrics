# មូលដ្ឋានទិន្នន័យថ្លៃចំណាយឯកតា

## គណិតវិទ្យា

មូលដ្ឋានទិន្នន័យថ្លៃចំណាយឯកតាមិនគណនាអ្វីដោយខ្លួនឯងទេ វាផ្គត់ផ្គង់ធាតុបញ្ចូលមួយដល់ការគណនាដែលធ្វើនៅកន្លែងផ្សេង៖

```
តម្លៃតំណាងហិរញ្ញវត្ថុ = តម្លៃទីផ្សារ ឬតម្លៃស្រមោល ឬការវាយតម្លៃសុខុមាលភាព
                         ឬតម្លៃចំណូលចិត្តដែលបានប្រកាស
                         សម្រាប់ឯកតាកំណត់នៃការផ្លាស់ប្តូរលទ្ធផល
                         (ឧ. "ក្នុងមួយនាក់ដែលផ្លាស់ពីគ្មានការងារធ្វើទៅមានការងារធ្វើ ក្នុងមួយឆ្នាំ")

តម្លៃដែលអនុវត្ត = ចំនួនលទ្ធផលដែលសម្រេចបាន × តម្លៃតំណាងឯកតា
```

សូមមើល [តម្លៃស្រមោល](../តម្លៃស្រមោល/) ពីរបៀបដែលតំណាងត្រូវបានបង្កើត នៅពេលគ្មានតម្លៃទីផ្សារ និង [ផលចំណេញសង្គមលើការវិនិយោគ](../ផលចំណេញសង្គមលើការវិនិយោគ/) ពីរបៀបដែលតម្លៃដែលអនុវត្តបន្ទាប់មកបញ្ចូលទៅក្នុងសមាមាត្រ បន្ទាប់ពីការកែតម្រូវ deadweight និងការសន្មតផល។

- **ការរាប់ស្ទួននូវតំណាងដែលត្រួតគ្នា។** ការបូកបញ្ចូលតំណាង (ឧ. "ភាពឯកកោថយចុះ" និង "សុខុមាលភាពផ្លូវចិត្តប្រសើរឡើង") ដែលបានមកពីគំនិតស្ទង់មតិត្រួតគ្នា វាយតម្លៃការផ្លាស់ប្តូរមូលដ្ឋានដូចគ្នាពីរដង។
- **ការប្រើតំណាងក្រៅបរិបទដោយមិនកែតម្រូវ។** តំណាងដែលកែតម្រូវលើប្រជាជនជាតិ និងឆ្នាំមួយ ហើយអនុវត្តនៅកន្លែងផ្សេងដោយគ្មានការកែតម្រូវអតិផរណា ឬបរិបទ បង្ហាញតម្លៃខុសដោយស្ងាត់ស្ងៀម។
- **ការមិនពិនិត្យប្រភពដើម។** Global Value Exchange បើកចំហ និងប្រមូលពីសហគមន៍ ដូច្នេះគុណភាពធាតុខុសគ្នាតាមអ្នកចូលរួម ត្រូវពិនិត្យប្រភពមូលដ្ឋាន មុនពេលដកស្រង់តួលេខក្នុងការដេញថ្លៃទទួលមូលនិធិ ឬការដាក់ស្នើលទ្ធកម្ម។
