# ក្រដាសពិន្ទុតម្លៃសាធារណៈ

ក្រដាសពិន្ទុតម្លៃសាធារណៈ (public value scorecard) ធ្វើឱ្យ balanced scorecard របស់ Robert Kaplan និង David Norton ក្នុងឆ្នាំ 1992 សមស្របទៅនឹងស្ថាប័ន — ដែលត្រូវបានបង្កើតសម្រាប់ក្រុមហ៊ុនបង្កើនប្រាក់ចំណេញតាមទស្សនៈហិរញ្ញវត្ថុ អតិថិជន ដំណើរការផ្ទៃក្នុង និងការរៀនសូត្រ និងការលូតលាស់ — ដែលបន្ទាត់ខាងក្រោមរបស់វាជាបេសកកម្ម មិនមែនរឹមប្រាក់ចំណេញ។ វាបង្ខំឱ្យស្ថាប័នសាធារណៈរាយការណ៍ដំណើរការឆ្លងវិមាត្រមិនអាចកាត់បន្ថយបានច្រើនក្នុងពេលតែមួយ ជាជាងបង្រួមអ្វីៗទាំងអស់ទៅជាលេខតែមួយដែលលាក់ការដោះដូរ។

## ហេតុអ្វីបានជាសំខាន់

អំណះអំណាងដើមរបស់ Kaplan និង Norton ក្នុង Harvard Business Review គឺថារង្វាស់ហិរញ្ញវត្ថុតែមួយ គឺជាសូចនាករតាមក្រោយដែលមិនប្រាប់អ្នកអ្វីអំពី*មូលហេតុ*ដែលដំណើរការនឹងផ្លាស់ប្តូរក្នុងត្រីមាសបន្ទាប់។ ក្នុងវិស័យឯកជន ដំណោះស្រាយគឺទស្សនៈបួនដែលភ្ជាប់គ្នា។ នៅក្នុងរដ្ឋាភិបាល "ត្រីកោណយុទ្ធសាស្ត្រ" របស់ Mark Moore (ពី *Creating Public Value*, 1995) ផ្តល់រចនាសម្ព័ន្ធស្មើគ្នា៖ សេវាត្រូវតែក្នុងពេលតែមួយផ្តល់ជូន**តម្លៃសាធារណៈ** (លទ្ធផលបេសកកម្ម) រក្សា**ភាពស្របធម៌ និងការគាំទ្រ** (ការគាំទ្រនយោបាយ និងសាធារណៈ) និង**អាចអនុវត្តបានក្នុងប្រតិបត្តិការ** (អាចផ្តល់ជូនបានជាមួយធនធាន និងសមត្ថភាពដែលមានជាក់ស្តែង)។ សៀវភៅ *Balanced Scorecard: Step-by-Step for Government and Nonprofit Agencies* (2003) របស់ Paul Niven គឺជាសៀវភៅណែនាំអ្នកអនុវត្តសម្រាប់បកប្រែប្រអប់ទាំងបួនរបស់ Kaplan និង Norton ទៅជាត្រីកោណនេះ — ជាធម្មតាដាក់ស្លាកឡើងវិញ "ហិរញ្ញវត្ថុ" ជា "ការគ្រប់គ្រងធនធាន" ដាក់ "បេសកកម្ម" នៅកំពូលជំនួស "តម្លៃម្ចាស់ហ៊ុន" នៅបាត និងចាត់ទុកទស្សនៈអតិថិជន និងភាគីពាក់ព័ន្ធស្មើគ្នា ជាជាងចុះក្រោមប្រាក់ចំណេញ។ មូលហេតុដែលរឿងនេះសំខាន់ដល់ក្រុមផ្តល់ជូនគឺថា សេវាឌីជីថលសាធារណៈដែលត្រូវបានវិនិច្ឆ័យតែលើរង្វាស់ហិរញ្ញវត្ថុ ឬប្រសិទ្ធភាព (ឧ. ថ្លៃដើមក្នុងមួយប្រតិបត្តិការ) នឹងវិនិយោគមិនគ្រប់គ្រាន់ជាប្រព័ន្ធលើវិមាត្រភាពស្របធម៌ និងលទ្ធផល ដែលរង្វាស់ហិរញ្ញវត្ថុមើលមិនឃើញ។

## ឧទាហរណ៍គណនា

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

សម្រាប់ក្រុមដែលសាងសង់ផ្ទាំងគ្រប់គ្រងផ្ទៃក្នុង ឬបែរមុខទៅសាធារណជន ក្រដាសពិន្ទុគឺជាអំណះអំណាងផ្ទាល់ប្រឆាំងនឹង widget "ពិន្ទុសុខភាព" តែមួយ៖ សាងសង់ផ្ទាំងមួយក្នុងមួយទស្សនៈ ហើយទប់ទល់សម្ពាធផលិតផលក្នុងការសំយោគវាទៅជាភ្លើងចរាចរណ៍ ព្រោះជំហានសំយោគគឺជាកន្លែងដែលព័ត៌មានការដោះដូរត្រូវបានបំផ្លាញ។ វាក៏ត្រូវនឹងរចនាសម្ព័ន្ធ OKR របស់ក្រុមផលិតផលយ៉ាងស្អាត៖ OKR បេសកកម្មដោយគ្មាន OKR ការគ្រប់គ្រងធនធាន ឬដំណើរការជាគូ ផលិតឡើងវិញនូវទម្រង់បរាជ័យរង្វាស់តែមួយ ដែល Kaplan និង Norton កំពុងសរសេរប្រឆាំងក្នុងឆ្នាំ 1992។ សូមមើល[តម្លៃសាធារណៈ](../តម្លៃសាធារណៈ/) សម្រាប់ទ្រឹស្តីមូលដ្ឋានរបស់ Moore អំពីអ្វីដែលប្រអប់ "បេសកកម្ម" គួរមាន និង
[រង្វាស់ទំនុកចិត្ត និងភាពស្របធម៌](../សូចនាករទំនុកចិត្ត-និងភាពស្របច្បាប់ក្នុងវិស័យសាធារណៈ/) សម្រាប់របៀបបំពេញទស្សនៈភាពស្របធម៌ជាមួយសូចនាករពិតប្រាកដ មានប្រភព ជាជាងតំណាងដែលគ្មាននរណាអាចការពារបាន។

## កំហុសដែលតែងកើតមាន

- **បង្រួមក្រដាសពិន្ទុទៅជាពិន្ទុតែមួយ**៖ ការយកមធ្យមទស្សនៈបួនទៅជាលេខតែមួយ នាំបញ្ហាដូចគ្នាត្រឡប់មកវិញ — ពិន្ទុភាពស្របធម៌អាក្រក់ត្រូវបានបិទបាំងដោយពិន្ទុការគ្រប់គ្រងធនធានល្អ — ដែលក្រដាសពិន្ទុមានដើម្បីទប់ស្កាត់។
- **ចម្លងទស្សនៈ "ហិរញ្ញវត្ថុ" វិស័យឯកជនដោយមិនកែប្រែ**៖ ទស្សនៈការគ្រប់គ្រងធនធានរបស់ស្ថាប័នសាធារណៈ គឺអំពីការស្ថិតក្នុងថវិកាដែលបានអនុញ្ញាត ជារឿយៗត្រូវបានបម្រុងទុក មិនមែនអំពីការបង្កើនចំណូលទេ — ការដាក់ស្លាកឡើងវិញរបស់ Niven មិនមែនគ្រាន់តែលម្អទេ។
- **ជ្រើសសូចនាករដែលក្រុមម្ចាស់ក្រដាសពិន្ទុអាចផ្លាស់ទីដោយឯកតោភាគី**៖ សូចនាករភាពស្របធម៌ដែលមកពីក្រុមតែមួយដែលវាវិនិច្ឆ័យ (ឧ. ការដោះស្រាយពាក្យបណ្តឹងដែលរាយការណ៍ដោយខ្លួនឯង) មិនមែនជាភស្តុតាងឯករាជ្យទេ។
- **សាងសង់ក្រដាសពិន្ទុម្តង ហើយមិនដែលពិនិត្យទម្ងន់ ឬសូចនាករឡើងវិញ**៖ Kaplan និង Norton មានបំណងឱ្យមានការពិនិត្យយុទ្ធសាស្ត្រប្រចាំឆ្នាំ។ ក្រដាសពិន្ទុដែលត្រូវបានបង្កក្នុងរយៈពេលច្រើនឆ្នាំ ឃ្លាតចេញពីបេសកកម្មដែលវាត្រូវបានសាងសង់ដើម្បីតាមដាន។
