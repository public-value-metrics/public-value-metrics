# ថ្លៃចំណាយក្នុងមួយអ្នកទទួលផល

ថ្លៃចំណាយក្នុងមួយអ្នកទទួលផល (cost per beneficiary) គឺជាថ្លៃចំណាយកម្មវិធីសរុបចែកនឹងចំនួនមនុស្សតែមួយគត់ដែលបានទទួលសេវា ដែលជាអ្នកណាដែលត្រូវបានប៉ះពាល់ មិនថាស្ថានភាពរបស់ពួកគេបានផ្លាស់ប្តូរពិតឬអត់។ វាជាលេខប្រសិទ្ធភាពលឿនបំផុតដែលអង្គការអាចផលិតបាន ព្រោះ «តើយើងបានបម្រើអ្នកណា» ស្ទើរតែតែងតែមានក្នុងប្រព័ន្ធគ្រប់គ្រងករណីរួចហើយ ចំណែក «តើអ្នកណាត្រូវបានជួយ» ជាធម្មតាមិនមានទេ។

## ហេតុអ្វីបានជាសំខាន់

ម្ចាស់មូលនិធិសុំថ្លៃចំណាយក្នុងមួយអ្នកទទួលផលជាប្រចាំ ដោយមានហេតុផលអាចការពារបាន៖ វាមានភ្លាមៗ វាអាចប្រៀបធៀបបានទូទាំងផលប័ត្រនៃកម្មវិធីខុសគ្នាខ្លាំង ហើយវាស្មោះត្រង់អំពីវិសាលភាពក្នុងរបៀបដែលការអះអាងលទ្ធផល ដែលត្រូវការពេលវេលាច្រើនជាងដើម្បីផ្ទៀងផ្ទាត់ និងងាយបំផ្លើសជាងនោះ មិនមែន។ ក្បួនអនុវត្តដែលបានណែនាំរបស់ Charities SORP ចក្រភពអង់គ្លេស (Statement of Recommended Practice) ដែលគ្រប់គ្រងរបៀបដែលអង្គការសប្បុរសធម៌រាយការណ៍ក្រោម FRS 102 តម្រូវឱ្យរបាយការណ៍ប្រចាំឆ្នាំរបស់អ្នកគ្រប់គ្រងពណ៌នាសមិទ្ធផលធៀបនឹងគោលបំណង ប៉ុន្តែគណនេយ្យគ្រប់គ្រងរបស់អង្គការសប្បុរសធម៌តូចៗភាគច្រើននៅតែលំនាំដើមទៅថ្លៃចំណាយឯកតាផ្អែកលើវិសាលភាព ព្រោះវាថោកក្នុងការផលិត និងងាយសវនកម្ម។

គ្រោះថ្នាក់គឺការចាត់ទុកថ្លៃចំណាយក្នុងមួយអ្នកទទួលផលដូចជាវាឆ្លើយសំណួរដែលវាមិនអាចឆ្លើយបាន គឺថាតើប្រាក់ដំណើរការឬអត់។ សូមមើល [ថ្លៃចំណាយក្នុងមួយលទ្ធផល](../ថ្លៃចំណាយក្នុងមួយលទ្ធផល/) សម្រាប់រង្វាស់ដែលឆ្លើយបានពិតប្រាកដ និង [លទ្ធផល ធៀបនឹងផលិតកម្ម](../លទ្ធផល-ធៀបនឹង-ទិន្នផល/) សម្រាប់ភាពខុសគ្នាមូលដ្ឋាន។ ថ្លៃចំណាយក្នុងមួយអ្នកទទួលផលគឺជារង្វាស់បែងចែកអាទិភាព និងវិសាលភាពស្របច្បាប់ ដែលប្រាប់ម្ចាស់មូលនិធិថាប្រាក់លាតសន្ធឹងបានឆ្ងាយប៉ុនណា ប៉ុន្តែថ្លៃចំណាយក្នុងមួយអ្នកទទួលផលទាបអាចមានន័យថាប្រសិទ្ធភាពពិតប្រាកដ ឬសេវាស្តើងពេកដែលមិនផ្លាស់ប្តូរអ្វីទាល់តែសោះ។

## គណិតវិទ្យា

```
Cost per beneficiary = Total programme cost / Number of unique people served

Contrast:
Cost per outcome      = Total programme cost / Number of people achieving the defined outcome

Cost per beneficiary is always ≤ cost per outcome, because the outcome population is a subset
(often a small one) of the beneficiary population.
```

## ឧទាហរណ៍គណនា

**ធនាគារអាហារ ក្នុងឆ្នាំដូចគ្នានឹងឧទាហរណ៍ថ្លៃចំណាយក្នុងមួយលទ្ធផល**៖

- ថ្លៃចំណាយកម្មវិធីសរុប៖ £450,000
- គ្រួសារតែមួយគត់ដែលបានបម្រើ (កញ្ចប់បីឬច្រើនជាងនេះ)៖ 1,800

```
Cost per beneficiary = £450,000 / 1,800 = £250 per household served
```

ប្រៀបធៀបរង្វាស់ទាំងពីរជាប់គ្នា៖

| រង្វាស់ | ភាគបែង | លទ្ធផល |
|---|---|---|
| ថ្លៃចំណាយក្នុងមួយអ្នកទទួលផល | គ្រួសារ 1,800 ដែលបានបម្រើ | £250 |
| ថ្លៃចំណាយក្នុងមួយលទ្ធផល | គ្រួសារ 630 ដែលសម្រេចសន្តិសុខស្បៀង | £714 |

ម្ចាស់មូលនិធិដែលឃើញតែ £250 អាចសន្និដ្ឋានថានេះជាអង្គការសប្បុរសធម៌ដែលមានប្រសិទ្ធភាពខ្ពស់។ ម្ចាស់មូលនិធិដែលឃើញលេខទាំងពីរអាចសួរសំណួរមានប្រយោជន៍ជាង៖ តើគម្លាតរវាងវិសាលភាព (1,800) និងលទ្ធផល (630) ជាគម្លាតប្រមូលទិន្នន័យ គម្លាតរចនា ឬជាការឆ្លុះបញ្ចាំងស្មោះត្រង់អំពីភាពលំបាកក្នុងការសម្រេចសន្តិសុខស្បៀងដោយជំនួយអាហារតែមួយ?

**អង្គការសប្បុរសធម៌បណ្តុះបណ្តាលការងារ ឧទាហរណ៍**៖ ថ្លៃចំណាយក្នុងមួយអ្នកទទួលផល (បានចុះឈ្មោះ) = £2,000 ថ្លៃចំណាយក្នុងមួយលទ្ធផល (ការងារប្រកបដោយនិរន្តរភាពនៅ 6 ខែ) = £11,000 ព្រោះមានតែ 18% នៃអ្នកចុះឈ្មោះបំពេញកម្មវិធី និងរកការងារប្រកបដោយនិរន្តរភាព។ លេខទាំងពីរខុសគ្នាដោយកត្តាប្រាំគឺទូទៅគ្រប់កន្លែងដែលអត្រាបំពេញ ឬភាពស្ថិតស្ថេរទាប ដែលអង្គការសប្បុរសធម៌បណ្តុះបណ្តាល និងធនាគារអាហារមានរចនាសម្ព័ន្ធដូចគ្នានៅទីនេះ។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

ថ្លៃចំណាយក្នុងមួយអ្នកទទួលផលគឺជារង្វាស់លំនាំដើមក្នុងកម្មវិធីអង្គការមិនស្វែងរកប្រាក់ចំណេញ ព្រោះវាជារង្វាស់ដែលចេញពីកំណត់ត្រាអ្នកទទួលផលដោយមិនចាំបាច់ធ្វើការបន្ថែម៖ បង្កើតករណី កត់ត្រាសេវា រាប់ជួរដេក។ ការកសាងប្រព័ន្ធដែលគាំទ្រថ្លៃចំណាយក្នុងមួយលទ្ធផលផងដែរ មានន័យថាបន្ថែមដោយចេតនានូវអង្គភាពថ្នាក់ទីមួយទីពីរ គឺព្រឹត្តិការណ៍លទ្ធផល ដែលមានកាលបរិច្ឆេទ និងកំណត់ដាច់ដោយឡែកពីការផ្តល់សេវា ហើយទប់ទល់នឹងការល្បួងឱ្យ «បិទករណី» តំណាង «លទ្ធផលសម្រេច»។ នៅពេលកំណត់វិសាលភាពវេទិកាគ្រប់គ្រងជំនួយឧបត្ថម្ភ ឬ CRM ត្រូវសួរថារង្វាស់ណាមួយនៃទាំងពីរដែលផ្ទាំងគ្រប់គ្រងនីមួយៗកំពុងបង្ហាញជាក់ស្តែង ហើយដាក់ស្លាកតាមនោះ ព្រោះការច្រឡំវាក្នុងប្លុក «ផលប៉ះពាល់» តែមួយ គឺជាមូលហេតុកម្រិតកម្មវិធីទូទៅបំផុតមួយនៃកំហុសខាងក្រោម។ សូមមើល [មូលដ្ឋានទិន្នន័យថ្លៃចំណាយឯកតា](../មូលដ្ឋានទិន្នន័យថ្លៃចំណាយឯកតា/) សម្រាប់ការប្រៀបធៀបរង្វាស់ណាមួយ នៅពេលវាត្រូវបានដាក់ស្លាកត្រឹមត្រូវ។

## កំហុសដែលតែងកើតមាន

- **ការបង្ហាញថ្លៃចំណាយក្នុងមួយអ្នកទទួលផលជាផលប៉ះពាល់។** វាវាស់វិសាលភាព មិនមែនការផ្លាស់ប្តូរទេ។ ដាក់ស្លាកផ្ទាំងគ្រប់គ្រង និងរបាយការណ៍ថា «ថ្លៃចំណាយក្នុងមួយអ្នកដែលបានបម្រើ» មិនមែន «ថ្លៃចំណាយក្នុងមួយអ្នកដែលបានជួយ» ទេ។
- **ការរាប់ស្ទួនឆ្លងកម្មវិធី។** អ្នកដែលទទួលទាំងកញ្ចប់អាហារ និងដំបូន្មានបំណុលពីអង្គការសប្បុរសធម៌ដូចគ្នា គឺជាអ្នកទទួលផលម្នាក់ មិនមែនពីរនាក់ទេ ប្រសិនបើភាគបែងមានបំណងពិពណ៌នាវិសាលភាពតែមួយគត់ ដូច្នេះត្រូវសម្រេច និងចងក្រងឯកសារថាអនុសញ្ញាណាត្រូវបានប្រើ។
- **ការចាត់ទុកលេខទាបជាងល្អជាងជានិច្ច។** ក្លឹបអាហារថ្ងៃត្រង់ដែលចូលបាននឹងឈ្នះសេវាគ្រប់គ្រងករណីដែលស៊ីជម្រៅជានិច្ចលើថ្លៃចំណាយក្នុងមួយអ្នកទទួលផល ព្រោះវាថោកជាងក្នុងការប៉ះមនុស្សស្រាលៗ។ នោះមិនប្រាប់អ្វីអំពីអ្វីដែលបង្កើតការផ្លាស់ប្តូរស្ថិតស្ថេរជាងក្នុងមួយប៉ោនទេ។
- **ការប្តូរភាគបែងដោយស្ងាត់ស្ងៀមរវាងរបាយការណ៍។** តួលេខថ្លៃចំណាយក្នុងមួយអ្នកទទួលផលដែលដកស្រង់ក្នុងរបាយការណ៍ប្រចាំឆ្នាំមួយធៀបនឹង «បានចុះឈ្មោះ» ហើយក្នុងឆ្នាំបន្ទាប់ធៀបនឹង «បានបំពេញ» មិនអាចប្រៀបធៀបបានពីឆ្នាំមួយទៅឆ្នាំមួយទេ ដូច្នេះត្រូវបញ្ជាក់ភាគបែងរាល់ពេល។
