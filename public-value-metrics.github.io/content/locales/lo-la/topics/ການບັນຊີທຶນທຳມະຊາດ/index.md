# ການບັນຊີທຶນທຳມະຊາດ

ການບັນຊີທຶນທຳມະຊາດວາງສິ່ງແວດລ້ອມໄວ້ໃນຖານະດຽວກັນກັບຊັບສິນແຫ່ງຊາດ ຫຼື ຊັບສິນຂອງອົງກອນອື່ນໆ: ມັນວັດແທກສະຕັອກຂອງຊັບພະຍາກອນທຳມະຊາດ
(ປ່າໄມ້, ດິນ, ແມ່ນ້ຳ, ທີ່ມີນ້ຳຂັງ, ຊັ້ນບັນຍາກາດ) ແລະ ກະແສບໍລິການທີ່ພວກມັນຜະລິດ (ການດູດຊັບຄາບອນ, ການປ້ອງກັນນ້ຳຖ້ວມ,
ການພັກຜ່ອນຫຍໍ່ນໃຈ, ອາຫານ) ທັງໃນຮູບຂອງປະລິມານກາຍະພາບ ແລະ ມູນຄ່າເງິນ, ເພື່ອໃຫ້ການເສື່ອມຖອຍຂອງສິ່ງແວດລ້ອມປາກົດໃນການຕັດສິນໃຈ
ເໝືອນດັ່ງການໃຊ້ທຶນການເງິນໃຫ້ໝົດໄປ. ສະຫະລາຊະອານາຈັກເປັນໜຶ່ງໃນລັດຖະບານທີ່ກ້າວໜ້າທີ່ສຸດໃນການເຮັດສິ່ງນີ້ຢ່າງເປັນລະບົບ,
ຂັບເຄື່ອນໂດຍແຜນສິ່ງແວດລ້ອມ 25 ປີ (2018) ແລະ ຈັດຕັ້ງປະຕິບັດຜ່ານບັນຊີທຶນທຳມະຊາດຂອງ UK ໂດຍ ONS ແລະ
ຄຳແນະນຳເສີມຂອງ Green Book ຈາກ HM Treasury.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ການບັນຊີແບບດັ້ງເດີມ — ທັງພາກທຸລະກິດ ແລະ ລັດຖະບານ — ຖືວ່າປ່າໄມ້ບໍ່ມີຄ່າຈົນກວ່າຈະຖືກຕັດ ແລະ ຂາຍເປັນໄມ້ແປຮູບ,
ເຊິ່ງໃນຈຸດນັ້ນມັນກາຍເປັນ GDP. ການບັນຊີທຶນທຳມະຊາດມີຂຶ້ນເພື່ອປິດຊ່ອງຫວ່າງນັ້ນ: ແຜນສິ່ງແວດລ້ອມ 25 ປີຂອງ UK ໄດ້ຜູກພັນລັດຖະບານໃຫ້ຝັງ
ແນວຄິດທຶນທຳມະຊາດເຂົ້າໃນທຸກນະໂຍບາຍ, ໂດຍລະບຸຄວາມມຸ່ງມັ່ນຢ່າງຊັດເຈນທີ່ຈະ "ເປັນລຸ້ນຄົນທຳອິດທີ່ປະສິ່ງແວດລ້ອມໄວ້ໃນສະພາບທີ່ດີກວ່າທີ່ພວກເຮົາພົບ."
ຕັ້ງແຕ່ນັ້ນມາ ONS ໄດ້ເຜີຍແຜ່ບັນຊີທຶນທຳມະຊາດຂອງ UK ປະຈຳປີ
(<https://www.ons.gov.uk/economy/environmentalaccounts/bulletins/uknaturalcapitalaccounts/latest>)
ທີ່ຄາດຄະເນມູນຄ່າເງິນຂອງບໍລິການລະບົບນິເວດ — ຕັ້ງແຕ່ການພັກຜ່ອນໃນປ່າໄມ້ ເຖິງປະໂຫຍດຕໍ່ສຸຂະພາບຂອງພື້ນທີ່ສີຂຽວໃນຕົວເມືອງ
ຈົນເຖິງການເກັບຄາບອນໃນດິນພີດ — ໂດຍໃຊ້ກອບບັນຊີແຫ່ງຊາດດຽວກັນທີ່ໃຊ້ກັບທຶນທີ່ຜະລິດຂຶ້ນ, ເພື່ອໃຫ້ທຶນທຳມະຊາດສາມາດຢູ່ໃນງົບດຸນດຽວກັນກັບ
ຖະໜົນ, ອາຄານ ແລະ ອຸປະກອນໃນທີ່ສຸດ. ຄຳແນະນຳ Enabling a Natural Capital Approach (ENCA) ຂອງ HM Treasury ທີ່ເປັນສ່ວນເສີມຂອງ Green Book
(<https://www.gov.uk/government/publications/enabling-a-natural-capital-approach-enca-guidance>)
ກຳນົດວ່າຜູ້ປະເມີນຄວນປະເມີນມູນຄ່າຕົ້ນທຶນ ແລະ ຜົນປະໂຫຍດດ້ານສິ່ງແວດລ້ອມໃນກໍລະນີທຸລະກິດແນວໃດ, ເພື່ອໃຫ້ໂຄງການທາງຫຼວງທີ່ທຳລາຍປ່າໄມ້ເກົ່າແກ່
ຫຼື ໂຄງການປ້ອງກັນນ້ຳຖ້ວມທີ່ຟື້ນຟູທີ່ມີນ້ຳຂັງ ສາມາດປຽບທຽບໄດ້ດ້ວຍມູນຄ່າເງິນທີ່ສອດຄ່ອງກັນ ແທນທີ່ຈະມີອັນໜຶ່ງເປັນຕົວເລກ ແລະ ອີກອັນເປັນວັກຂໍ້ແມ່ນຍົກເວັ້ນ.

## ຄະນິດສາດ

```
ມູນຄ່າຊັບສິນບໍລິການລະບົບນິເວດ = NPV ຂອງກະແສບໍລິການທີ່ຊັບສິນໃຫ້

ມູນຄ່າຊັບສິນ = Σ (t = 1 ເຖິງ T) [ມູນຄ່າກະແສບໍລິການປະຈຳປີ_t / (1 + r)^t]

ໂດຍທີ່:
  ມູນຄ່າກະແສບໍລິການ_t = ປະລິມານບໍລິການໃນປີ t × ມູນຄ່າຕໍ່ໜ່ວຍ
                          (ເຊັ່ນ ຈຳນວນຜູ້ເຂົ້າພັກຜ່ອນ × ມູນຄ່າຕໍ່ຄັ້ງ;
                           ໂຕນຄາບອນທີ່ດູດຊັບ × ລາຄາຄາບອນ)
  r = ອັດຕາສ່ວນຫຼຸດ (ອັດຕາສ່ວນຫຼຸດທາງສັງຄົມຂອງ Green Book — ເບິ່ງ
      [ອັດຕາສ່ວນຫຼຸດທາງສັງຄົມ](../ອັດຕາຄິດຫຼຸດທາງສັງຄົມ/))
  T = ຂອບເຂດເວລາທີ່ຄາດວ່າຊັບສິນຈະໃຫ້ບໍລິການນັ້ນ
```

ນີ້ເປັນໂຄງສ້າງມູນຄ່າປັດຈຸບັນສຸດທິດຽວກັນທີ່ໃຊ້ປະເມີນມູນຄ່າທຶນທີ່ຜະລິດຂຶ້ນ ຫຼື ປະເມີນການລົງທຶນສາທາລະນະໃດໆພາຍໃຕ້
[ການປະເມີນຕາມ Green Book](../ການປະເມີນຄຸນຄ່າຕາມ-green-book/) — ການປະກອບສ່ວນຂອງການບັນຊີທຶນທຳມະຊາດແມ່ນການໃຫ້ປະລິມານກາຍະພາບ ແລະ ມູນຄ່າຕໍ່ໜ່ວຍທີ່ໜ້າເຊື່ອຖື
ສຳລັບບໍລິການທີ່ກ່ອນນັ້ນຖືກກຳນົດລາຄາເປັນສູນ.

## ຕົວຢ່າງການຄິດໄລ່

**ປ່າໄມ້ໃນຕົວເມືອງ, ມູນຄ່າການພັກຜ່ອນ**: ປ່າໄມ້ 50 ເຮັກຕາ ມີຜູ້ເຂົ້າພັກຜ່ອນປະມານ 80,000 ຄັ້ງຕໍ່ປີ, ແຕ່ລະຄັ້ງມີມູນຄ່າ
(ຜ່ານວິທີຕົ້ນທຶນການເດີນທາງ ຫຼື ການຕັ້ງຄ່າທີ່ລະບຸ — ເບິ່ງ
[ການປະເມີນມູນຄ່າຈາກຄວາມມັກທີ່ເປີດເຜີຍ](../ການປະເມີນມູນຄ່າຈາກຄວາມມັກທີ່ເປີດເຜີຍ/) ແລະ
[ການປະເມີນມູນຄ່າຈາກຄວາມມັກທີ່ລະບຸ](../ການຕີມູນຄ່າດ້ວຍຄວາມມັກທີ່ລະບຸ/)) £3 ຕໍ່ຄັ້ງ. ປ່າໄມ້ຄາດວ່າຈະໃຫ້ບໍລິການນີ້ຕໍ່ໄປ 50 ປີ,
ປະເມີນດ້ວຍອັດຕາສ່ວນຫຼຸດ 3.5%.

```
ມູນຄ່າການພັກຜ່ອນປະຈຳປີ = 80,000 × £3 = £240,000/ປີ

NPV ໃນ 50 ປີ ທີ່ 3.5% ≈ £240,000 × ປັດໄຈເງິນງວດ(3.5%, 50 ປີ)
ປັດໄຈເງິນງວດ(3.5%, 50) ≈ 21.4

ມູນຄ່າຊັບສິນ ≈ £240,000 × 21.4 ≈ £5,136,000
```

**ເພີ່ມການເກັບຄາບອນ**: ປ່າໄມ້ດຽວກັນດູດຊັບ CO2 ປະມານ 400 ໂຕນຕໍ່ປີ, ມີມູນຄ່າຕາມລາຄາຄາບອນທີ່ບໍ່ໄດ້ຊື້ຂາຍຂອງລັດຖະບານ
ປະມານ £75/ໂຕນ (ເປັນຕົວຢ່າງ — ໃຊ້ມູນຄ່າຄາບອນທີ່ BEIS/DESNZ ເຜີຍແຜ່ປັດຈຸບັນສຳລັບການປະເມີນຈິງ).

```
ມູນຄ່າຄາບອນປະຈຳປີ = 400 × £75 = £30,000/ປີ
NPV ໃນ 50 ປີ ທີ່ 3.5% ≈ £30,000 × 21.4 ≈ £642,000

ມູນຄ່າຊັບສິນປ່າໄມ້ທັງໝົດ (ການພັກຜ່ອນ + ຄາບອນ) ≈ £5,136,000 + £642,000
                                                   ≈ £5,778,000
```

ນີ້ຍັງບໍ່ໄດ້ລວມບໍລິການຫຼຸດຄວາມແຮງນ້ຳຖ້ວມ, ຄວາມຫຼາກຫຼາຍທາງຊີວະພາບ, ຫຼື ຄຸນນະພາບອາກາດ ທີ່ຄຳແນະນຳ ENCA ຍັງຂໍໃຫ້ຜູ້ປະເມີນພິຈາລະນາ —
ຜົນລວມນີ້ຕັ້ງໃຈໃຫ້ເປັນຂອບລຸ່ມ, ບໍ່ແມ່ນຂອບເທິງ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

- ລະບົບສິ່ງແວດລ້ອມ ແລະ ການຈັດການຊັບສິນຂອງອົງການປົກຄອງທ້ອງຖິ່ນ ແລະ ຫົວໜ່ວຍງານ (ສວນສາທາລະນະ, ທາງຫຼວງ,
  ແຫຼ່ງນ້ຳ) ສາມາດຕິດທະບຽນທຶນທຳມະຊາດຄຽງຄູ່ກັບທະບຽນຊັບສິນກາຍະພາບ,
  ໂດຍໃຊ້ຮູບແບບກະແສບໍລິການຄູນມູນຄ່າຕໍ່ໜ່ວຍດຽວກັບ[ຖານຂໍ້ມູນຕົ້ນທຶນຕໍ່ໜ່ວຍ](../ຖານຂໍ້ມູນຕົ້ນທຶນຕໍ່ໜ່ວຍ/)ອື່ນໆ
  ທີ່ອົງກອນຮັກສາ.
- ເນື່ອງຈາກ NPV ຂອງທຶນທຳມະຊາດອ່ອນໄຫວຕໍ່ອັດຕາສ່ວນຫຼຸດ (ເບິ່ງປັດໄຈເງິນງວດໃນຕົວຢ່າງການຄິດໄລ່), ເຄື່ອງມືໃດກໍຕາມທີ່ຄິດໄລ່ມັນຄວນສະແດງອັດຕາ ແລະ ຂອບເຂດເວລາ
  ເປັນຂໍ້ມູນນຳເຂົ້າທີ່ເຫັນໄດ້ ບໍ່ແມ່ນຝັງໄວ້ — ຫຼັກການຄວາມໂປ່ງໃສດຽວກັນທີ່ກ່າວເຖິງພາຍໃຕ້
  [ຄວາມເທົ່າທຽມລະຫວ່າງລຸ້ນຄົນ ແລະ ການຫຼຸດມູນຄ່າເພື່ອຄວາມຍືນຍົງ](../ຄວາມເປັນທຳລະຫວ່າງລຸ້ນຄົນ-ແລະ-ການຫຼຸດມູນຄ່າເພື່ອຄວາມຍືນຍົງ/).
- ບັນຊີທຶນທຳມະຊາດກຳລັງກາຍເປັນຂໍ້ມູນນຳເຂົ້າທີ່ຈຳເປັນຫຼາຍຂຶ້ນສຳລັບພາກຜົນກະທົບດ້ານສິ່ງແວດລ້ອມຂອງ
  ກໍລະນີທຸລະກິດຕາມ [green-book-appraisal](../ການປະເມີນຄຸນຄ່າຕາມ-green-book/); ທີມສົ່ງມອບທີ່ສ້າງເຄື່ອງມືກໍລະນີທຸລະກິດຄວນຖືວ່າ
  ບັນຊີ ONS ແລະ ມູນຄ່າຕໍ່ໜ່ວຍຂອງ ENCA ເປັນຂໍ້ມູນອ້າງອີງທີ່ຕ້ອງເຊື່ອມໂຍງ, ບໍ່ແມ່ນສິ່ງທີ່ຜູ້ປະເມີນຄິດໄລ່ໃໝ່ຕັ້ງແຕ່ຕົ້ນທຸກຄັ້ງ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ນັບຊ້ຳບໍລິການລະບົບນິເວດທີ່ຊ້ອນທັບກັນ** — ມູນຄ່າການພັກຜ່ອນ ແລະ ມູນຄ່າຄວາມຫຼາກຫຼາຍທາງຊີວະພາບຂອງສະຖານທີ່ດຽວກັນ
  ອາດໃຊ້ຂໍ້ມູນຄວາມເຕັມໃຈຈ່າຍພື້ນຖານດຽວກັນ; ຄຳແນະນຳ ENCA ເຕືອນຢ່າງຊັດເຈນບໍ່ໃຫ້ລວມມູນຄ່າທີ່ໄດ້ຈາກເຄື່ອງມືສຳຫຼວດທີ່ຊ້ອນທັບກັນ.
- **ຖືວ່າມູນຄ່າຊັບສິນທຶນທຳມະຊາດຄົງທີ່** — ກະແສບໍລິການປ່ຽນແປງຕາມສະພາບອາກາດ, ການຈັດການ ແລະ ແຮງກົດດັນການໃຊ້ທີ່ດິນ;
  ມູນຄ່າຄາບອນ ແລະ ການຫຼຸດຄວາມແຮງນ້ຳຖ້ວມຂອງປ່າໄມ້ໃນທົດສະວັດນີ້ບໍ່ແມ່ນຄຸນສົມບັດຖາວອນຂອງສະຖານທີ່.
- **ໃຊ້ມູນຄ່າຕໍ່ໜ່ວຍສະເລ່ຍແຫ່ງຊາດສຳລັບການຕັດສິນໃຈໃນທ້ອງຖິ່ນສະເພາະ** — ປ່າໄມ້ໃນຕົວເມືອງທີ່ເຂົ້າເຖິງໄດ້ໜຶ່ງເຮັກຕາ ແລະ
  ພື້ນທີ່ສູງຫ່າງໄກໜຶ່ງເຮັກຕາ ມີມູນຄ່າການພັກຜ່ອນແຕກຕ່າງກັນຫຼາຍ; ຄຳແນະນຳ ENCA ແນະນຳໃຫ້ໃຊ້ມູນຄ່າທ້ອງຖິ່ນ ຫຼື ສະເພາະສະຖານທີ່ເມື່ອມີ
  ແທນທີ່ຈະຕົກລົງໃຊ້ຄ່າສະເລ່ຍແຫ່ງຊາດ.
