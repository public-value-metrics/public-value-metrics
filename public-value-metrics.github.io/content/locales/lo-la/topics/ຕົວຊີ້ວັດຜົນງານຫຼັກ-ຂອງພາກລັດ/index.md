# ຕົວຊີ້ວັດຜົນງານຫຼັກ (KPI) ຂອງພາກລັດ

ຕົວຊີ້ວັດຜົນງານຫຼັກ (KPI) ແມ່ນມາດຕະການທີ່ຖືກເລືອກ ແລະ ຕິດຕາມ ເຊິ່ງເປັນຕົວແທນວ່າບໍລິການສາທາລະນະກຳລັງເຮັດວຽກຂອງມັນໄດ້ດີຫຼືບໍ່.
ໃນລັດຖະບານ ການເລືອກ KPI ບໍ່ເຄີຍເປັນກາງ: ເນື່ອງຈາກ KPI ຜູກກັບງົບປະມານ, ຕາຕະລາງຈັດອັນດັບ ແລະ ອາຊີບການງານ,
ການເລືອກອັນໜຶ່ງຈຶ່ງກຳນົດພຶດຕິກຳຂອງທຸກຄົນຕໍ່ລຸ່ມມັນ, ມັກຫຼາຍກວ່ານະໂຍບາຍທີ່ສ້າງບໍລິການນັ້ນຂຶ້ນ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ຂໍ້ສັງເກດຂອງ Charles Goodhart ປີ 1975 ກ່ຽວກັບນະໂຍບາຍການເງິນ — ຕໍ່ມາຖືກເຜີຍແຜ່ໂດຍ Marilyn Strathern ເປັນ
"ເມື່ອມາດຕະການກາຍເປັນເປົ້າໝາຍ, ມັນຢຸດເປັນມາດຕະການທີ່ດີ" — ເປັນປ້າຍເຕືອນສຳຄັນທີ່ສຸດໃນການຈັດການຜົນງານຂອງພາກລັດ. KPI ທີ່ເລືອກເພື່ອ *ພັນລະນາ* ລະບົບ
ເລີ່ມ *ບິດເບືອນ* ລະບົບນັ້ນທັນທີທີ່ການຈັດສັນຊັບພະຍາກອນ, ຄ່າຈ້າງ, ຫຼື ການຢູ່ລອດທາງການເມືອງຖືກຜູກກັບມັນ. ຕົວຢ່າງຄລາສສິກແມ່ນເວລາຕອບໂຕ້ຂອງລົດພະຍາບານ NHS:
ເມື່ອເປົ້າໝາຍການຕອບໂຕ້ປະເພດ A ແປດນາທີກາຍເປັນຂໍ້ຜູກມັດ, ບາງ trust ຖືກສະແດງວ່າ "ຈອດ" ລົດພະຍາບານຢູ່ນອກນາຬິກາການຕອບໂຕ້ພໍດີ, ຫຼື ຈັດປະເພດສາຍໂທໃໝ່,
ເພື່ອໃຫ້ໄດ້ຕົວເລກໂດຍບໍ່ປ່ຽນຜົນລັບຂອງຄົນເຈັບ. ຄຳແນະນຳຂອງສຳນັກງານກວດສອບແຫ່ງຊາດ (NAO) ຂອງ UK ກ່ຽວກັບການເລືອກ ແລະ ໃຊ້ຕົວຊີ້ວັດຜົນງານ — ທີ່ກຳນົດໄວ້
ທົ່ວລາຍງານຄວາມຄຸ້ມຄ່າເງິນ ແລະ ກອບ "Performance Measurement by Regulators" ແລະ "Choosing
the Right FABRIC" (Fit for purpose, Appropriate, Balanced, Robust, Integrated,
Cost-effective) — ມີຂຶ້ນກໍເພາະກະຊວງຕ່າງໆເລືອກຕົວຊີ້ວັດທີ່ລາຍງານງ່າຍແທນຕົວຊີ້ວັດທີ່ເກມຍາກ. ວິສະວະກອນຊອບແວທີ່ສົ່ງມອບແຜງຄວບຄຸມທີ່ລັດຖະມົນຕີ
ຫຼື ຜູ້ອຳນວຍການຈະຖືກຕັດສິນຕາມ, ບໍ່ວ່າຈະຕັ້ງໃຈຫຼືບໍ່, ກຳລັງອອກແບບໂຄງສ້າງແຮງຈູງໃຈຂອງສະຖາບັນສາທາລະນະ.

## ຄະນິດສາດ

ການອອກແບບ KPI ເປັນຫົວຂໍ້ແບບກອບ, ແຕ່ *ການປະເມີນ* KPI ຜູ້ສະໝັກເປັນບັນຊີກວດທີ່ເຮັດຊ້ຳໄດ້, ບໍ່ແມ່ນສູດ:

```
ສຳລັບແຕ່ລະ KPI ຜູ້ສະໝັກ, ໃຫ້ຄະແນນຕາມ:
  Fit for purpose  — ມັນວັດຜົນລັບ, ຫຼື ຕົວແທນທີ່ຫ່າງໄກຫຼາຍຂັ້ນຕອນ?
  Appropriate      — ມັນເປັນຂອງຄົນທີ່ສາມາດມີອິດທິພົນຕໍ່ມັນໄດ້ຈິງບໍ?
  Balanced         — ມັນຈັບຄູ່ກັບຕົວຊີ້ວັດຕ້ານທີ່ຈັບການເກມບໍ?
  Robust           — ມັນຜ່ານການກວດສອບໄດ້ບໍ, ຫຼື ລາຍງານເອງ ແລະ ຢັ້ງຢືນບໍ່ໄດ້?
  Integrated       — ມັນເຂົ້າກັບຊຸດທີ່ກວ້າງກວ່າ, ຫຼື ຂັດກັບ KPI ອື່ນ?
  Cost-effective   — ການເກັບມັນມີຕົ້ນທຶນສູງກວ່າການຕັດສິນໃຈທີ່ມັນໃຫ້ຂໍ້ມູນບໍ?

ການແບ່ງຕົວຊີ້ວັດນຳໜ້າ ທຽບ ຕາມຫຼັງ:
  ຕົວຊີ້ວັດນຳໜ້າ   → ພະຍາກອນຜົນລັບໃນອະນາຄົດ, ແຕ່ມັກເກມໄດ້ (ເຊັ່ນ ຮັບສາຍ <60 ວິນາທີ)
  ຕົວຊີ້ວັດຕາມຫຼັງ → ຢືນຢັນວ່າຜົນລັບເກີດຂຶ້ນ, ແຕ່ມາຊ້າເກີນກວ່າຈະຊີ້ນຳ (ເຊັ່ນ ແບບສຳຫຼວດ
                        ຄວາມພໍໃຈປະຈຳປີ)
  ຊຸດ KPI ທີ່ປ້ອງກັນໄດ້ຈັບຄູ່ຢ່າງໜ້ອຍໜຶ່ງຂອງແຕ່ລະປະເພດຕໍ່ວັດຖຸປະສົງ.
```

## ຕົວຢ່າງການຄິດໄລ່

**Trust ພະຍາບານ**: trust ລາຍງານ KPI ເວລາຕອບໂຕ້ປະເພດ A (ເປັນອັນຕະລາຍເຖິງຊີວິດ) ວ່າ "75% ຂອງ
ສາຍໄດ້ຮັບການຕອບໂຕ້ພາຍໃນ 8 ນາທີ." ໃນໄຕມາດໜຶ່ງ, ມີສາຍປະເພດ A 6,000 ສາຍ; 4,500 ສາຍບັນລຸ
ພາຍໃນ 8 ນາທີ, ໄດ້ 75.0% — ເບິ່ງຄືບັນລຸເປົ້າໝາຍ.

```
KPI ຫົວຂໍ້ = 4,500 / 6,000 × 100 = 75.0%  (ບັນລຸເກນ 75%)
```

ແຕ່ການກວດສອບ Goodhart ເພີ່ມຕົວຊີ້ວັດຕ້ານ: ເວລາຕອບໂຕ້ສະເລ່ຍຂອງ 10% ສາຍທີ່ຊ້າທີ່ສຸດ.

```
ເວລາຕອບໂຕ້ສະເລ່ຍຂອງເດຊິລຊ້າທີ່ສຸດ = 34 ນາທີ (ເພີ່ມຈາກ 19 ນາທີສອງປີກ່ອນ)
```

trust ບັນລຸເປົ້າໝາຍໃນຂະນະທີ່ຫາງ — ສາຍທີ່ມີໂອກາດເປັນອັນຕະລາຍເຖິງຊີວິດຈິງຫຼາຍທີ່ສຸດ ເມື່ອການຄັດກອງບໍ່ສົມບູນ — ຮ້າຍລົງຫຼາຍ, ເພາະທີມງານຖືກຈັດ
ລຳດັບຄວາມສຳຄັນໄປຫາສາຍທີ່ໃກ້ຜາຜົ້ງ 8 ນາທີ ແທນຄວາມຮີບດ່ວນທາງການແພດ. KPI ດຽວບອກເລື່ອງບໍ່ຈິງ; KPI ທີ່ຈັບຄູ່ບອກເລື່ອງຈິງ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ວິສະວະກອນທີ່ສ້າງແຜງຄວບຄຸມຜົນງານສຳລັບລັດຖະບານ, ໃນທາງໜ້າທີ່, ກຳລັງອອກແບບ API ແຮງຈູງໃຈຂອງອົງກອນ. ຜົນໃນທາງປະຕິບັດ: ວັດ *ຕົວຫານ* ຢ່າງເຂັ້ມງວດເທົ່າຕົວຕັ້ງ
(KPI ທີ່ລາຍງານເປັນເປີເຊັນເປົ່າໆເຊື້ອເຊີນການເກມຕົວຫານ — ເບິ່ງ
[cost-per-transaction](../ຕົ້ນທຶນຕໍ່ທຸລະກຳ/) ສຳລັບກັບດັກດຽວກັນໃນບໍລິການດິຈິຕອນ); ສ້າງຕົວຊີ້ວັດຕ້ານໃນແຜງຄວບຄຸມດຽວກັນ
ແທນລາຍງານແຍກທີ່ບໍ່ມີໃຜອ່ານ, ເພື່ອໃຫ້ການເກມເຫັນໄດ້ຢູ່ຈຸດຕັດສິນໃຈ; ແລະ ຄວບຄຸມເວີຊັນນິຍາມ KPI, ເພາະການນິຍາມໃໝ່ແບບງຽບໆ
(ປ່ຽນສິ່ງທີ່ນັບເປັນ "ສາຍ", "ກໍລະນີ", ຫຼື "ການສຳເລັດ") ເທົ່າກັບການປ່ຽນເປົ້າໝາຍໂດຍບໍ່ປະກາດ. [ບັດຄະແນນຄຸນຄ່າສາທາລະນະ](../ບັດຄະແນນຄຸນຄ່າສາທາລະນະ/)
ເປັນວິທີທີ່ມີໂຄງສ້າງວິທີໜຶ່ງເພື່ອຢຸດບໍ່ໃຫ້ KPI ດຽວຖືກອ່ານແບບໂດດດ່ຽວ, ແລະ
[ຄວາມຮັບຜິດຊອບຕາມຜົນລັບ](../ຄວາມຮັບຜິດຊອບຕາມຜົນລັບ/) ແມ່ນວິໄນຂອງການເລືອກ
KPI ລະດັບປະຊາກອນທີ່ທີມດຽວບໍ່ສາມາດບິດເບືອນໂດຍລຳພັງ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ເລືອກມາດຕະການທີ່ເກັບງ່າຍແທນອັນທີ່ມີຄວາມໝາຍ**: ເວລາຮັບສາຍບັນທຶກໄດ້ງ່າຍ;
  ວ່າສາຍນັ້ນແກ້ບັນຫາຂອງພົນລະເມືອງຫຼືບໍ່ ບໍ່ງ່າຍ — ແຕ່ມີແຕ່ອັນທີສອງທີ່ເປັນຜົນລັບ. ຢ່າຕົກລົງໃຊ້ສິ່ງທີ່ລະບົບປ່ອຍອອກມາຢູ່ແລ້ວ.
- **ບໍ່ມີຕົວຊີ້ວັດຕ້ານ**: KPI ໃດກໍຕາມທີ່ຜູກກັບເງິນ ຫຼື ຊື່ສຽງຈະຖືກເກມທີ່ຂອບ;
  ສົ່ງມັນພ້ອມຕົວຊີ້ວັດຈັບຄູ່ທີ່ຈັບເສັ້ນທາງການເກມທີ່ເປັນໄປໄດ້ກ່ອນເຜີຍແຜ່.
- **ນິຍາມຕົວຊີ້ວັດໃໝ່ໂດຍບໍ່ມີບັນທຶກການປ່ຽນແປງ**: ການສະຫຼັບ "ສາຍທີ່ໄດ້ຮັບ" ເປັນ "ສາຍທີ່ຕອບ" ເພື່ອ
  ເຮັດໃຫ້ແນວໂນ້ມເບິ່ງດີທຳລາຍຄວາມໜ້າເຊື່ອຖືຂອງອະນຸກົມເວລາທັນທີທີ່ຖືກຄົ້ນພົບ — ເຜີຍແຜ່ບັນທຶກການປ່ຽນແປງນິຍາມພ້ອມຕົວເລກສະເໝີ.
- **ສັບສົນກິດຈະກຳກັບຜົນສຳເລັດ**: ການນັບການກວດກາທີ່ສຳເລັດແມ່ນຜົນຜະລິດ; ການນັບສະຖານທີ່ທີ່ເຂົ້າສູ່ການປະຕິບັດຕາມ
