# ອັດຕາສ່ວນຄ່າໃຊ້ຈ່າຍບໍລິຫານຂອງອົງການການກຸສົນ (Overhead Ratio)

ອັດຕາສ່ວນຄ່າໃຊ້ຈ່າຍບໍລິຫານຂອງອົງການການກຸສົນ (overhead ratio) ແມ່ນລາຍຈ່າຍດ້ານບໍລິຫານ ແລະ ການລະດົມທຶນ ທີ່ສະແດງເປັນເປີເຊັນຂອງລາຍຈ່າຍທັງໝົດ. ມັນເປັນຕົວເລກທີ່ຖືກຂໍຫຼາຍທີ່ສຸດໃນການບໍລິຈາກ — ຜູ້ບໍລິຈາກ, ອົງການເຝົ້າລະວັງ ແລະ ແມ່ນແຕ່ຜູ້ໃຫ້ທຶນບາງຄົນໃຊ້ເປັນຕົວແທນຂອງປະສິດທິພາບ — ແລະ ມັນກໍເປັນໜຶ່ງໃນຕົວຊີ້ວັດປະສິດທິພາບທີ່ຖືກປະຕິເສດຢ່າງເຕັມທີ່ທີ່ສຸດໃນຂະແໜງນີ້ ໂດຍອົງກອນທີ່ເຮັດໃຫ້ມັນເປັນທີ່ນິຍົມ ໄດ້ປະກາດປະຕິເສດມັນຢ່າງເປີດເຜີຍໃນປີ 2013.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ໃນວັນທີ 17 ມິຖຸນາ 2013, GuideStar, BBB Wise Giving Alliance ແລະ Charity Navigator — ສາມອົງການຈັດອັນດັບ ແລະ ໃຫ້ຂໍ້ມູນອົງກອນບໍ່ຫວັງກຳໄລທີ່ໃຫຍ່ທີ່ສຸດຂອງສະຫະລັດ, ທີ່ການຈັດອັນດັບໃນອະດີດຂອງຕົນເອງໄດ້ຊ່ວຍຝັງ overhead ratio ໃຫ້ເປັນຕົວຫຍໍ້ຂອງຄຸນນະພາບອົງການການກຸສົນ — ໄດ້ເຜີຍແຜ່ຈົດໝາຍເປີດຜະໜຶກເຖິງຜູ້ບໍລິຈາກຊາວອາເມຣິກັນ ຊື່ "The Overhead Myth", ລະບຸຢ່າງຊັດເຈນວ່າ overhead ratio ເປັນຕົວວັດຜົນງານຂອງອົງການການກຸສົນທີ່ບໍ່ດີ ແລະ ຮຽກຮ້ອງໃຫ້ຜູ້ບໍລິຈາກເບິ່ງຄວາມໂປ່ງໃສ, ການກຳກັບດູແລ ແລະ ຜົນໄດ້ຮັບແທນ. ນີ້ແມ່ນການປ່ຽນທິດທາງໂດຍກົງຂອງສະຖາບັນທີ່ສ້າງວັດທະນະທຳຜູ້ບໍລິຈາກອ້ອມອັດຕາສ່ວນນີ້ມາເປັນເວລາໜຶ່ງທົດສະວັດ.

ບັນຫາພື້ນຖານເປັນເລື່ອງໂຄງສ້າງ, ບໍ່ແມ່ນພຽງພາບລັກ: overhead ratio ຕ່ຳສາມາດບັນລຸໄດ້ໂດຍການລົງທຶນໃນສິ່ງທີ່ເຮັດໃຫ້ອົງການການກຸສົນມີປະສິດທິຜົນໃຫ້ໜ້ອຍເກີນໄປ — ລະບົບຈັດການກໍລະນີທີ່ດີ, ພະນັກງານທີ່ໄດ້ຮັບການຝຶກອົບຮົມ, ການຕິດຕາມ ແລະ ປະເມີນຜົນ — ເພາະສິ່ງເຫຼົ່ານີ້ມັກຖືກບັນທຶກເປັນຕົ້ນທຶນ "ບໍລິຫານ" ແທນ "ໂຄງການ". ອົງການການກຸສົນທີ່ອຶດຢາກຫ້ອງເຮັດວຽກຫຼັງບ້ານເພື່ອລາຍງານ overhead 5% ອາດມີຄວາມສາມາດໃນການສົ່ງມອບຜົນໄດ້ຮັບໜ້ອຍກວ່າອົງການທີ່ໃຊ້ 20% ກັບການດຳເນີນງານທີ່ມີຊັບພະຍາກອນພຽງພໍ. ໃນອັງກິດ ແລະ ເວວ, ຄຳແນະນຳຂອງ Charity Commission ຕໍ່ຜູ້ຮັບຜິດຊອບ (trustees) ຫຼີກເວັ້ນເປີເຊັນ overhead ດຽວເປັນການທົດສອບປະສິດທິພາບ, ແຕ່ຂໍໃຫ້ຜູ້ຮັບຜິດຊອບລາຍງານວ່າອົງການການກຸສົນບັນລຸຫຍັງເມື່ອທຽບກັບຈຸດປະສົງຂອງຕົນ — ເບິ່ງຂໍ້ກຳນົດການລາຍງານ SORP ທີ່ອະທິບາຍໃນ [ຕົ້ນທຶນຕໍ່ຜູ້ໄດ້ຮັບຜົນປະໂຫຍດ](../ຕົ້ນທຶນຕໍ່ຜູ້ໄດ້ຮັບຜົນປະໂຫຍດ/).

## ຄະນິດສາດ

```
Overhead ratio = (Administrative cost + Fundraising cost) / Total expenditure

Common variants:
  Programme ratio        = Programme (direct charitable) spend / Total expenditure
                          = 1 − overhead ratio
  Fundraising efficiency  = Fundraising cost / Funds raised
```

ບໍ່ມີສູດໃດໃນນີ້ມີຂໍ້ມູນກ່ຽວກັບຜົນໄດ້ຮັບທີ່ບັນລຸເລີຍ. ອົງການການກຸສົນສາມາດເຮັດໃຫ້ທຸກຕົວນີ້ຕ່ຳສຸດ ແລະ ຍັງລົ້ມເຫຼວຕໍ່ຜູ້ໄດ້ຮັບຜົນປະໂຫຍດທຸກຄົນ; ເບິ່ງ [ຕົ້ນທຶນຕໍ່ຜົນໄດ້ຮັບ](../ຕົ້ນທຶນຕໍ່ຜົນໄດ້ຮັບ/) ສຳລັບຕົວຊີ້ວັດທີ່ກ່ຽວຂ້ອງກັບການທີ່ເງິນໄດ້ຜົນຈິງຫຼືບໍ່.

## ຕົວຢ່າງການຄິດໄລ່

ສອງອົງການການກຸສົນ, ລາຍຈ່າຍທັງໝົດເທົ່າກັນ:

- **ອົງການການກຸສົນ A**: ລາຍຈ່າຍທັງໝົດ £1,000,000, ບໍລິຫານ + ລະດົມທຶນ £80,000 → overhead ratio 8%. ບໍ່ມີໜ້າທີ່ຕິດຕາມ ແລະ ປະເມີນຜົນ, ມີເຈົ້າໜ້າທີ່ການເງິນໜຶ່ງຄົນທີ່ເຮັດວຽກໜັກເກີນ, ແລະ ບໍ່ມີລະບົບຈັດການກໍລະນີ; ອັດຕາການລາອອກຂອງພະນັກງານສູງ ແລະ ບໍ່ເກັບຂໍ້ມູນຜົນໄດ້ຮັບ.
- **ອົງການການກຸສົນ B**: ລາຍຈ່າຍທັງໝົດ £1,000,000, ບໍລິຫານ + ລະດົມທຶນ £220,000 → overhead ratio 22%. ສະໜອງທຶນໃຫ້ທີມປະເມີນຜົນຂະໜາດນ້ອຍ, ລະບົບຈັດການກໍລະນີທີ່ເກັບການຕິດຕາມຜົນໄດ້ຮັບ, ແລະ ການຝຶກອົບຮົມການປົກປ້ອງ (safeguarding) ທີ່ເໝາະສົມ.

ຜູ້ບໍລິຈາກທີ່ຄັດກອງດ້ວຍ overhead ratio ຢ່າງດຽວຈະເລືອກ A ແລະ ປະຕິເສດ B — ກົງກັນຂ້າມກັບສິ່ງທີ່ຫຼັກຖານ [ຕົ້ນທຶນຕໍ່ຜົນໄດ້ຮັບ](../ຕົ້ນທຶນຕໍ່ຜົນໄດ້ຮັບ/) ຈະສະແດງ, ເພາະ B ເປັນອົງການດຽວໃນສອງທີ່ຢູ່ໃນຖານະສາມາດສະແດງ ຫຼື ປັບປຸງຜົນໄດ້ຮັບແທ້ຂອງຕົນ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ຊອບແວການເງິນ ແລະ ການລາຍງານເງິນອຸດໜູນສຳລັບຂະແໜງນີ້ມັກຝັງການແບ່ງ overhead/ໂຄງການເປັນຊ່ອງປະເພດໃນທຸກລາຍການຕົ້ນທຶນ ເພາະນັ້ນແມ່ນສິ່ງທີ່ຜູ້ກຳກັບດູແລ ແລະ ຜູ້ໃຫ້ທຶນບາງຄົນຍັງຮຽກຮ້ອງໃນການສົ່ງລາຍງານຕາມກົດໝາຍ. ວິສະວະກອນທີ່ສ້າງລະບົບເຫຼົ່ານີ້ຄວນຖືຂໍ້ກຳນົດນັ້ນເປັນພັນທະການປະຕິບັດຕາມກົດລະບຽບ, ບໍ່ແມ່ນສັນຍານການອອກແບບວ່າ overhead ratio ເປັນຕົວຊີ້ວັດທີ່ຄວນສະແດງເດັ່ນໃນແດຊບອດ; ຈົ່ງຄູ່ມັນກັບຕົວຊີ້ວັດຕາມຜົນໄດ້ຮັບທຸກບ່ອນທີ່ສະແດງ ເພື່ອໃຫ້ຜູ້ເບິ່ງບໍ່ອ່ານ overhead ratio ແບບໂດດດ່ຽວ. ເບິ່ງ [ຜົນຕອບແທນຕໍ່ການລົງທຶນຂອງຜູ້ບໍລິຈາກ](../ຜົນຕອບແທນຈາກການລົງທຶນຂອງຜູ້ບໍລິຈາກ/) ສຳລັບຕົວຊີ້ວັດທີ່ຄວນຢູ່ຂ້າງມັນ, ແລະ [ຄວາມຄຸ້ມຄ່າເງິນ](../ຄວາມຄຸ້ມຄ່າເງິນ/) ສຳລັບຂໍ້ໂຕ້ແຍ້ງທຽບເທົ່າໃນພາກລັດຕໍ່ຕົວແທນປະສິດທິພາບແບບອັດຕາສ່ວນດຽວ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ໃຊ້ overhead ratio ເປັນເກນຕັດ.** ການປະຕິເສດອົງການການກຸສົນໃດທີ່ເກີນເກນຕາມໃຈ (ເຊັ່ນ "ບໍ່ເກີນ 15% overhead") ລົງໂທດອົງກອນທີ່ມີຊັບພະຍາກອນພຽງພໍ ແລະ ປະເມີນຜົນດີຢ່າງເປັນລະບົບ ແລະ ໃຫ້ລາງວັນແກ່ການລົງທຶນຕ່ຳເກີນ.
- **ຈັດປະເພດຕົ້ນທຶນການສົ່ງມອບໂດຍກົງເປັນ overhead ຜິດ**, ຫຼື ກົງກັນຂ້າມ — ຮີດຄອງບັນຊີກ່ຽວກັບສິ່ງທີ່ນັບເປັນ "ໂຄງການ" ທຽບກັບ "ບໍລິຫານ" ແຕກຕ່າງກັນຫຼາຍລະຫວ່າງອົງການການກຸສົນ ຈົນອັດຕາສ່ວນມັກປຽບທຽບກັນບໍ່ໄດ້ແມ່ນແຕ່ຕາມໜ້າຕົວເລກ.
- **ສົມມຸດວ່າ overhead ຕ່ຳໝາຍເຖິງຜົນກະທົບສູງ.** ທັງສອງຢ່າງ, ຢ່າງຫຼາຍ, ບໍ່ມີຄວາມສຳພັນກັນ; ເບິ່ງຂໍ້ອ້າງຫຼັກຂອງຈົດໝາຍ Overhead Myth ປີ 2013.
- **ເມີນເສີຍວ່າຍຸດທະສາດທີ່ຊອບທຳບາງຢ່າງຕ້ອງການ overhead ໄລຍະສັ້ນທີ່ສູງກວ່າ.** ໄລຍະສ້າງຄວາມສາມາດ ຫຼື ພັດທະນາອົງກອນ ຕັ້ງໃຈເພີ່ມລາຍຈ່າຍບໍລິຫານເພື່ອປັບປຸງການສົ່ງມອບໃນພາຍຫຼັງ.
