# ການວິເຄາະປະສິດທິຜົນຕໍ່ຕົ້ນທຶນໃນລັດຖະບານ (Cost-Effectiveness Analysis)

ການວິເຄາະປະສິດທິຜົນຕໍ່ຕົ້ນທຶນ (cost-effectiveness analysis, CEA) ປຽບທຽບຕົ້ນທຶນຂອງວິທີທາງເລືອກຕ່າງໆໃນການບັນລຸຜົນໄດ້ຮັບ*ອັນດຽວກັນ*, ສະແດງເປັນຫົວໜ່ວຍທຳມະຊາດ — ຕົ້ນທຶນຕໍ່ຜູ້ນອນຖະໜົນທີ່ໄດ້ທີ່ຢູ່ອາໄສ, ຕົ້ນທຶນຕໍ່ນັກຮຽນທີ່ຍົກຂຶ້ນສູ່ມາດຕະຖານທີ່ຄາດໄວ້, ຕົ້ນທຶນຕໍ່ໜຶ່ງໂຕນ CO2 ທີ່ຫຼຸດໄດ້ — ໂດຍບໍ່ແປງຕົວຜົນໄດ້ຮັບເປັນເງິນ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

Green Book ຖື CEA ເປັນວິທີສຳຮອງ ເມື່ອຂໍ້ກຳນົດຂອງ [ການວິເຄາະຕົ້ນທຶນ-ຜົນປະໂຫຍດທາງສັງຄົມ](../ການວິເຄາະຕົ້ນທຶນ-ຜົນປະໂຫຍດທາງສັງຄົມ/) ທີ່ຕ້ອງແປງທຸກຜົນປະໂຫຍດເປັນເງິນ ກາຍເປັນບໍ່ແມ່ນພຽງຍາກ ແຕ່ບໍ່ຊື່ສັດ — ບ່ອນທີ່ການໃສ່ລາຄາທີ່ເຊື່ອຖືໄດ້ໃຫ້ຜົນໄດ້ຮັບຈະຕ້ອງໃຊ້ສົມມຸດຖານທີ່ບໍ່ມີໃຜຖືຈິງ (<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>, ບົດທີ 5, ກ່ຽວກັບການປະເມີນທາງເລືອກເມື່ອຜົນໄດ້ຮັບບໍ່ແປງເປັນເງິນໄດ້ງ່າຍ). CEA ເປັນວິທີທີ່ຢືມມາໂດຍກົງທີ່ສຸດຈາກເສດຖະສາດສຸຂະພາບ — ມັນມີໂຄງສ້າງຄືກັບທີ່ NICE ປຽບທຽບການປິ່ນປົວດ້ວຍຕົ້ນທຶນຕໍ່ປີຊີວິດທີ່ປັບຄຸນນະພາບ (QALY) — ແຕ່ນຳມາໃຊ້ກັບໂຄງການສາທາລະນະທີ່ບໍ່ແມ່ນດ້ານສຸຂະພາບ: ການແຊກແຊງດ້ານການສຶກສາຕໍ່ຄະແນນຜົນໄດ້ຮັບຂອງນັກຮຽນ, ໂຄງການທີ່ຢູ່ອາໄສຕໍ່ຄົວເຮືອນທີ່ປ້ອງກັນບໍ່ໃຫ້ສູນເສຍທີ່ຢູ່ອາໄສ, ໂຄງການການຈ້າງງານຕໍ່ຜົນໄດ້ຮັບວຽກທີ່ຍືນຍົງ.

ເຫດຜົນທີ່ CEA ມີບ່ອນຢືນຄຽງຄູ່ SCBA ແທນທີ່ຈະຖືກດູດເຂົ້າໄປໃນມັນ ແມ່ນວ່າ ການບັງຄັບໃສ່ມູນຄ່າເງິນໃຫ້ບາງຜົນໄດ້ຮັບ ສ້າງຕົວເລກທີ່ແມ່ນຍຳພໍທີ່ຈະເບິ່ງມີອຳນາດ ແລະ ຖືກໂຕ້ແຍ້ງພໍທີ່ຈະບໍ່ມີຄ່າໃນການໂຕ້ວາທີສາທາລະນະ — ການໃສ່ລາຄາ "ເດັກທີ່ອ່ານໄດ້ຕາມມາດຕະຖານທີ່ຄາດໄວ້" ເຊື້ອເຊີນການທ້າທາຍແບບທີ່ເຮັດໃຫ້ກໍລະນີທຸລະກິດລົ້ມທີ່ຄະນະກຳມາທິການສະພາ. CEA ຫຼີກເວັ້ນການໂຕ້ແຍ້ງໂດຍປະຕິເສດທີ່ຈະມີມັນ: ມັນຈັດອັນດັບທາງເລືອກຕາມຕົ້ນທຶນຕໍ່ຫົວໜ່ວຍຂອງ*ຕົວຜົນໄດ້ຮັບເອງ*, ປ່ອຍການຕັດສິນທາງການເມືອງແຍກຕ່າງຫາກວ່າຜົນໄດ້ຮັບຄຸ້ມຄ່າທີ່ຈະໄລ່ຕາມຫຼືບໍ່ ໃຫ້ກໍລະນີຍຸດທະສາດ.

## ຄະນິດສາດ

```
Cost-effectiveness ratio (average) = Total cost / Total outcome units achieved

Incremental cost-effectiveness ratio (ICER), comparing option A to option B:
ICER = (Cost_A − Cost_B) / (Outcome_A − Outcome_B)

Procedure:
1. Fix the outcome unit and measurement method across all options being compared.
2. Cost every option on the same basis (see ../green-book-appraisal/, financial case)
   over the same time horizon.
3. Discard dominated options: any option costing more per unit than a cheaper
   alternative achieving the same or better outcome is dropped.
4. Rank remaining options by incremental, not average, cost-effectiveness ratio.
```

CEA ບໍ່ສາມາດບອກດ້ວຍຕົນເອງວ່າໂຄງການຄຸ້ມຄ່າກັບການສະໜອງທຶນຫຼືບໍ່ — ບອກໄດ້ພຽງວ່າໃນຫຼາຍວິທີທີ່ມຸ່ງເປົ້າດຽວກັນ ວິທີໃດຖືກທີ່ສຸດຕໍ່ຫົວໜ່ວຍ. ການຕັດສິນວ່າເປົ້າໝາຍຄຸ້ມຄ່າກັບການໃຊ້ຈ່າຍຫຼືບໍ່ ຕ້ອງປ່ຽນກັບໄປເປັນ SCBA (ຖ້າມີການປະເມີນມູນຄ່າທີ່ເຊື່ອຖືໄດ້) ຫຼື ການຕັດສິນທາງການເມືອງ/ຍຸດທະສາດນອກຄະນິດສາດ. ບ່ອນທີ່ຜົນໄດ້ຮັບບໍ່ສາມາດຫຼຸດເປັນຫົວໜ່ວຍດຽວໄດ້ແທ້ — ເພາະໂຄງການສ້າງຫຼາຍຜົນໄດ້ຮັບທີ່ສຳຄັນໃນແບບຕ່າງກັນ — ໃຫ້ໃຊ້ [ການວິເຄາະການຕັດສິນໃຈຫຼາຍເກນ](../ການວິເຄາະການຕັດສິນໃຈຫຼາຍເກນ/) ແທນ.

## ຕົວຢ່າງການຄິດໄລ່

**ອົງການປົກຄອງທ້ອງຖິ່ນ**: ສະພາປຽບທຽບສາມວິທີຫຼຸດການນອນຖະໜົນ, ແຕ່ລະວິທີຄິດຕົ້ນທຶນໃນໜຶ່ງປີ ຕໍ່ຜົນໄດ້ຮັບ "ບຸກຄົນທີ່ຍ້າຍເຂົ້າທີ່ຢູ່ອາໄສທີ່ໝັ້ນຄົງ 6 ເດືອນຂຶ້ນໄປ":

```
Option                          Cost       Outcomes achieved   Avg CER
Housing First (intensive)       £900,000   60                  £15,000/outcome
Hostel + move-on support        £600,000   50                  £12,000/outcome
Outreach + private rented sector £350,000  20                  £17,500/outcome

ICER, Hostel vs Outreach:  (600k−350k)/(50−20) = £8,333 per additional outcome
ICER, Housing First vs Hostel: (900k−600k)/(60−50) = £30,000 per additional outcome
```

Outreach ຖືກ Hostel ເດັ່ນກວ່າໃນຕົ້ນທຶນສະເລ່ຍ, ແຕ່ຂັ້ນ*ເພີ່ມ*ຈາກ Outreach ໄປ Hostel ມີຕົ້ນທຶນພຽງ £8,333 ຕໍ່ຄົນທີ່ໄດ້ທີ່ຢູ່ອາໄສເພີ່ມ — ຖືກເມື່ອທຽບກັບຂັ້ນ Housing First ທີ່ມີຕົ້ນທຶນ £30,000 ຕໍ່ຄົນເພີ່ມທີ່ເກີນສິ່ງທີ່ Hostel ໄດ້. ອົງການທີ່ມີງົບຈຳກັດ ແລະ ກຳລັງຂະຫຍາຍຄວນເລືອກຂະຫຍາຍ Hostel ກ່ອນ Housing First, ເຖິງແມ່ນ Housing First ຈະເບິ່ງດີກວ່າໃນອັດຕາສ່ວນສະເລ່ຍຂອງຕົນເອງ.

**ລັດຖະບານແຫ່ງຊາດ**: ໂຄງການຊ່ວຍການອ່ານໃຫ້ທັນເພື່ອນ ຖືກປຽບທຽບຕາມສາມຮູບແບບການສົ່ງມອບໃນ "ຕົ້ນທຶນຕໍ່ນັກຮຽນທີ່ໄປຮອດມາດຕະຖານການອ່ານຕາມອາຍຸ": ການສອນຕົວຕໍ່ຕົວ (£1,800/ນັກຮຽນ), ການສອນກຸ່ມນ້ອຍ (£700/ນັກຮຽນ), ແລະ ການແຊກແຊງດິຈິຕອນຢ່າງດຽວ (£150/ນັກຮຽນ, ແຕ່ມີພຽງ 40% ຂອງອັດຕາຜົນໄດ້ຮັບຂອງການສອນກຸ່ມນ້ອຍຕໍ່ນັກຮຽນທີ່ລົງທະບຽນ ເມື່ອປັບຕາມການຫຼຸດລົງຂອງການມີສ່ວນຮ່ວມ). ເມື່ອປັບຕາມການສຳເລັດຕົວຈິງ, ດິຈິຕອນຢ່າງດຽວມີຕົ້ນທຶນ £375 ຕໍ່ນັກຮຽນທີ່ໄປຮອດມາດຕະຖານ — ຍັງຖືກທີ່ສຸດ, ແຕ່ CEA ບອກບໍ່ໄດ້ວ່າຈຳນວນນັກຮຽນທີ່ໄດ້ຮັບການຊ່ວຍເຫຼືອສົມບູນໜ້ອຍກວ່າຈາກດິຈິຕອນຢ່າງດຽວ ຖ້າສົ່ງມອບດ້ວຍງົບເທົ່າກັບກຸ່ມນ້ອຍ ເປັນການແລກປ່ຽນທີ່ຍອມຮັບໄດ້ກັບການເຖິງນັກຮຽນໜ້ອຍກວ່າແຕ່ເລິກກວ່າຫຼືບໍ່; ນັ້ນແມ່ນການຕັດສິນດ້ານການແຈກຢາຍທີ່ CEA ສົ່ງຄືນໃຫ້ຜູ້ຕັດສິນໃຈ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

CEA ແມ່ນກອບທີ່ຖືກຕ້ອງເມື່ອໃດກໍຕາມທີ່ທີມວິສະວະກຳປະເມີນວິທີການສົ່ງມອບສຳລັບຜົນໄດ້ຮັບຂອງບໍລິການ*ອັນດຽວກັນ* — ຕົ້ນທຶນຕໍ່ຕົວຕົນທີ່ຢືນຢັນສຳເລັດໃນບັນດາຜູ້ຂາຍການຢືນຢັນຕົວຕົນສາມຮາຍ, ຕົ້ນທຶນຕໍ່ກໍລະນີທີ່ຄັດແຍກຖືກຕ້ອງໃນສອງການອອກແບບລະບົບອັດຕະໂນມັດວຽກກໍລະນີ, ຕົ້ນທຶນຕໍ່ຂໍ້ບົກຜ່ອງດ້ານການເຂົ້າເຖິງທີ່ແກ້ແລ້ວ ລະຫວ່າງການແກ້ໄຂພາຍໃນກັບການຈ້າງພາຍນອກ. ວິໄນທີ່ມັນນຳເຂົ້າມາໂດຍກົງ: ກຳນົດຫົວໜ່ວຍຜົນໄດ້ຮັບກ່ອນປຽບທຽບຕົ້ນທຶນ (ບໍ່ແມ່ນ "ຕັ໋ວທີ່ປິດ" — ເປັນຜົນຜະລິດ — ແຕ່ແມ່ນ "ຄວາມຕ້ອງການຂອງຜູ້ໃຊ້ທີ່ຖືກແກ້ແທ້"), ແລະ ຄິດອັດຕາສ່ວນສ່ວນເພີ່ມລະຫວ່າງລະບົບທີ່ໃຊ້ຢູ່ກັບລະບົບທົດແທນທີ່ສະເໜີສະເໝີ, ບໍ່ແມ່ນຕົ້ນທຶນສະເລ່ຍຂອງແຕ່ລະລະບົບແບບໂດດດ່ຽວ. ເບິ່ງ [ຜົນໄດ້ຮັບ ທຽບກັບ ຜົນຜະລິດ](../ຜົນລັບ-ທຽບ-ຜົນຜະລິດ/) ແລະ [ຕົ້ນທຶນຕໍ່ຜົນໄດ້ຮັບ](../ຕົ້ນທຶນຕໍ່ຜົນໄດ້ຮັບ/).

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ປຽບທຽບອັດຕາສະເລ່ຍ ບໍ່ແມ່ນອັດຕາສ່ວນເພີ່ມ ເມື່ອຕັດສິນໃຈຂະຫຍາຍ.** ດັ່ງຕົວຢ່າງການນອນຖະໜົນສະແດງ, ທາງເລືອກທີ່ມີອັດຕາສະເລ່ຍດີທີ່ສຸດບໍ່ແມ່ນຫົວໜ່ວຍຜົນໄດ້ຮັບຖັດໄປທີ່ຖືກທີ່ສຸດທີ່ຈະຊື້ສະເໝີ.
- **ເລືອກຫົວໜ່ວຍຜົນໄດ້ຮັບທີ່ຄວາມຈິງແມ່ນຜົນຜະລິດ.** "ການສົ່ງຕໍ່ທີ່ເຮັດ" ຫຼື "ຄາບຮຽນທີ່ສົ່ງມອບ" ວັດກິດຈະກຳ, ບໍ່ແມ່ນຜົນໄດ້ຮັບທີ່ໂຄງການມີຢູ່ເພື່ອສ້າງ; CEA ກັບຜົນຜະລິດໃຫ້ຕົວເລກທີ່ເບິ່ງໝັ້ນໃຈແຕ່ຕອບຜິດຄຳຖາມ.
- **ປຽບທຽບຜົນໄດ້ຮັບທີ່ແຕກຕ່າງກັນແທ້.** CEA ຖືກຕ້ອງກໍຕໍ່ເມື່ອທຸກທາງເລືອກມຸ່ງຜົນໄດ້ຮັບດຽວກັນທີ່ວັດແບບດຽວກັນ; ການປຽບທຽບ "ຕົ້ນທຶນຕໍ່ຜູ້ນອນຖະໜົນທີ່ໄດ້ທີ່ຢູ່" ກັບ "ຕົ້ນທຶນຕໍ່ຜູ້ອອກຈາກການດູແລທີ່ຢູ່ໃນສັນຍາເຊົ່າໝັ້ນຄົງ" ຕ້ອງການຕົວວັດຜົນໄດ້ຮັບທົ່ວໄປ ຫຼື [ການວິເຄາະການຕັດສິນໃຈຫຼາຍເກນ](../ການວິເຄາະການຕັດສິນໃຈຫຼາຍເກນ/), ບໍ່ແມ່ນ CEA.
- **ເມີນເສີຍຄວາມທົນທານຂອງຜົນໄດ້ຮັບ.** ທາງເລືອກທີ່ຖືກກວ່າແຕ່ຜົນໄດ້ຮັບບໍ່ຄົງຢູ່ (ນັກຮຽນທີ່ຖອຍຫຼັງຫຼັງການແຊກແຊງສິ້ນສຸດ) ບໍ່ໄດ້ມີປະສິດທິຜົນຕໍ່ຕົ້ນທຶນຫຼາຍກວ່າແທ້ ເມື່ອວັດໃນຂອບເຂດເວລາທີ່ປຽບທຽບໄດ້; ຈົ່ງໃຫ້ໄລຍະຕິດຕາມເທົ່າກັນໃນທຸກທາງເລືອກທີ່ປຽບທຽບ.
