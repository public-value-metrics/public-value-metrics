# ແບບຈຳລອງເຫດຜົນ (Logic Model)

ແບບຈຳລອງເຫດຜົນແມ່ນແຜນວາດເສັ້ນຊື່ທີ່ເຊື່ອມໂຍງປັດໄຈນຳເຂົ້າ, ກິດຈະກຳ, ຜົນຜະລິດ, ຜົນລັບ ແລະ ຜົນກະທົບຂອງໂຄງການ
ອ່ານຈາກຊ້າຍໄປຂວາເປັນຕ່ອງໂສ້ຄວາມຮັບຜິດຊອບ: ຊັບພະຍາກອນຖືກນຳເຂົ້າ, ກິດຈະກຳຖືກດຳເນີນ,
ຜົນຜະລິດຖືກສ້າງຂຶ້ນ, ຜົນລັບປ່ຽນແປງຕໍ່ຜູ້ໄດ້ຮັບຜົນປະໂຫຍດ, ແລະ ຜົນກະທົບສະສົມຂຶ້ນໃນຂອບເຂດທີ່ກວ້າງກວ່າ ຫຼື ໄລຍະເວລາທີ່ຍາວກວ່າ.
ມັນເປັນໂຄງສ້າງມາດຕະຖານທີ່ຜູ້ໃຫ້ທຶນ ແລະ ຜູ້ກວດສອບຄາດຫວັງໃຫ້ໂຄງການລາຍງານຕາມ, ແລະ ເປັນຄູ່ຫຼຸ້ນທີ່ເບິ່ງໄປຂ້າງໜ້າ
ຂອງ[ທິດສະດີການປ່ຽນແປງ](../ທິດສະດີການປ່ຽນແປງ/) ທີ່ວາງແຜນຍ້ອນຫຼັງ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ຄູ່ມື Magenta Book ຂອງ HM Treasury (ກະຊວງການຄັງຂອງສະຫະລາຊະອານາຈັກ) ກຳນົດໃຫ້ແບບຈຳລອງເຫດຜົນເປັນອົງປະກອບທີ່ຈຳເປັນຂອງການອອກແບບການປະເມີນໂຄງການ,
ແລະ ຜູ້ໃຫ້ທຶນເຊັ່ນ National Lottery Community Fund ສ້າງແບບຟອມການສະໝັກ ແລະ ການລາຍງານຂອງຕົນອ້ອມຮອບຕ່ອງໂສ້ຫ້າຖັນນີ້ພໍດີ.
ຄຸນຄ່າຂອງມັນແມ່ນບັງຄັບໃຫ້ໂຄງການລະບຸໄວ້ໃນແຜນວາດດຽວວ່າຈະໃຊ້ຈ່າຍຫຍັງ, ຈະເຮັດຫຍັງກັບມັນ, ຈະຜະລິດຫຍັງ, ແລະ — ທີ່ສຳຄັນທີ່ສຸດ —
ຈະມີຫຍັງປ່ຽນແປງເປັນຜົນ, ໃນລະດັບຄວາມລະອຽດທີ່ຂໍ້ຄວາມບັນຍາຍຍາວໆມັກຈະເຮັດໃຫ້ມົວໄປ. ແບບຈຳລອງເຫດຜົນທີ່ມີຖັນປັດໄຈນຳເຂົ້າ ແລະ ກິດຈະກຳຄົບຖ້ວນ
ແຕ່ຖັນຜົນລັບຫວ່າງເປົ່າ ຫຼື ບໍ່ຊັດເຈນ ສາມາດວິນິດໄສໄດ້ໃນພຽງຊົ່ວຫຼຽວເບິ່ງ, ແລະ ນັ້ນຄືເຫດຜົນທີ່ຜູ້ໃຫ້ທຶນຮ້ອງຂໍມັນ.

## ຄະນິດສາດ

ແບບຈຳລອງເຫດຜົນເປັນຕ່ອງໂສ້ໂຄງສ້າງ ບໍ່ແມ່ນສູດ:

```
ປັດໄຈນຳເຂົ້າ      ກິດຈະກຳ            ຜົນຜະລິດ             ຜົນລັບ                ຜົນກະທົບ
(ຊັບພະຍາກອນ      (ສິ່ງທີ່ເຮັດ        (ຜະລິດຕະພັນໂດຍກົງ     (ການປ່ຽນແປງຂອງ         (ການປ່ຽນແປງໄລຍະຍາວ,
 ທີ່ຜູກພັນ)        ດ້ວຍຊັບພະຍາກອນ)    ທີ່ນັບໄດ້)            ຜູ້ໄດ້ຮັບຜົນປະໂຫຍດ)   ລະດັບປະຊາກອນ
                                                                               ຫຼື ລະດັບລະບົບ)
```

ແຕ່ລະຖັນຄວນສະເພາະເຈາະຈົງກວ່າຖັນກ່ອນໜ້າ: ປັດໄຈນຳເຂົ້າຄືສິ່ງທີ່ທ່ານໃຊ້ຈ່າຍ, ກິດຈະກຳຄືສິ່ງທີ່ທ່ານເຮັດ,
ຜົນຜະລິດຄືສິ່ງທີ່ສົ່ງມອບໄດ້ໂດຍບໍ່ຄຳນຶງເຖິງຜົນ, ຜົນລັບຄືສິ່ງທີ່ປ່ຽນແປງເປັນຜົນສຳເລັດ —
ຄວາມແຕກຕ່າງທີ່ອະທິບາຍຢ່າງເຕັມທີ່ໃນ
[ຜົນລັບ ທຽບ ຜົນຜະລິດ](../ຜົນລັບ-ທຽບ-ຜົນຜະລິດ/) — ແລະ ຜົນກະທົບຄືການປ່ຽນແປງໄລຍະຍາວທີ່ຍືນຍົງ,
ເຊິ່ງມັກຈະຖືວ່າເປັນຜົນຂອງໂຄງການໄດ້ພຽງບາງສ່ວນ.

## ຕົວຢ່າງການຄິດໄລ່

**ອົງການປົກຄອງທ້ອງຖິ່ນ (ບໍລິການໃຫ້ຄຳປຶກສາດ້ານໜີ້ສິນແບບດິຈິຕອນ)**:

- ປັດໄຈນຳເຂົ້າ: ງົບປະມານປະຈຳປີ £180,000, ທີ່ປຶກສາ 4.0 FTE (ພະນັກງານເຕັມເວລາທຽບເທົ່າ), ລະບົບຈັດການກໍລະນີ.
- ກິດຈະກຳ: ກອງປະຊຸມເຜີຍແຜ່ເຖິງຊຸມຊົນ, ການນັດໝາຍໃຫ້ຄຳປຶກສາດ້ານໜີ້ສິນແບບໜຶ່ງຕໍ່ໜຶ່ງ.
- ຜົນຜະລິດ: ສົ່ງມອບການນັດໝາຍ 900 ຄັ້ງ; ອອກແຜນຈັດການໜີ້ສິນ ແລະ ສິດຮັບເງິນອຸດໜູນ 750 ແຜນ.
- ຜົນລັບ: ໃນບັນດາລູກຄ້າທີ່ເຖິງການຕິດຕາມຜົນ 6 ເດືອນ, 60% (450 ຈາກ 750) ລາຍງານວ່າໜີ້ຄ້າງຊຳລະຫຼຸດລົງ,
  ສະເລ່ຍຫຼຸດລົງ £1,200 ຕໍ່ລູກຄ້າ — ລວມໜີ້ຄ້າງຊຳລະຫຼຸດລົງ £540,000.
- ຜົນກະທົບ: ຈຳນວນຄຳຮ້ອງຂໍທີ່ຢູ່ອາໄສສຸກເສີນຈາກກຸ່ມລູກຄ້າຂອງບໍລິການຫຼຸດລົງຢ່າງວັດແທກໄດ້ຕະຫຼອດສອງປີ,
  ເຊິ່ງເປັນຜົນຂອງບໍລິການນີ້ໄດ້ພຽງບາງສ່ວນ ເມື່ອທຽບກັບມາດຕະການແຊກແຊງອື່ນໆ (ເບິ່ງ
  [ການວິເຄາະສະຖານະການສົມມຸດທຽບ](../ການວິເຄາະສະຖານະການສົມມຸດ/)).

**ອົງການການກຸສົນ (ຄວາມຮ່ວມມືແນະນຳສົ່ງຕໍ່ທະນາຄານອາຫານ)**:

- ປັດໄຈນຳເຂົ້າ: £45,000, ຜູ້ປະສານງານ 1.5 FTE, ຂໍ້ຕົກລົງຄວາມຮ່ວມມືກັບ 12 ອົງການສົ່ງຕໍ່.
- ກິດຈະກຳ: ການຄັດກອງການສົ່ງຕໍ່, ການຫຸ້ມຫໍ່ ແລະ ແຈກຢາຍຖົງອາຫານ.
- ຜົນຜະລິດ: ແຈກຢາຍຖົງອາຫານ 5,000 ຖົງໃຫ້ 1,100 ຄົວເຮືອນ.
- ຜົນລັບ: 68% ຂອງຄົວເຮືອນທີ່ສຳຫຼວດ (748 ຈາກ 1,100) ລາຍງານວ່າຄວາມໝັ້ນຄົງດ້ານອາຫານດີຂຶ້ນ
  ໃນການໂທຕິດຕາມຜົນ 4 ອາທິດ.
- ຜົນກະທົບ: ມີສ່ວນຊ່ວຍຫຼຸດຄວາມຕ້ອງການບໍລິການສຸກເສີນໃນທ້ອງຖິ່ນ, ມີຫຼັກຖານສະແດງໃນສະຖິຕິລວມຂອງເຂດເທົ່ານັ້ນ,
  ບໍ່ສາມາດຖືວ່າເປັນຜົນຂອງອົງການການກຸສົນນີ້ພຽງຜູ້ດຽວ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ແບບຈຳລອງເຫດຜົນເກືອບເປັນແບບຈຳລອງຂໍ້ມູນຕາມຕົວຈິງສຳລັບລະບົບຜົນລັບ: ປັດໄຈນຳເຂົ້າ ແລະ ກິດຈະກຳແມ່ນຂໍ້ມູນການດຳເນີນງານ
ທີ່ທ່ານມີຢູ່ແລ້ວ (ລາຍຈ່າຍ, ພະນັກງານ, ບັນທຶກກອງປະຊຸມ); ຜົນຜະລິດວັດແທກໄດ້ງ່າຍເພາະນັບໄດ້ຢູ່ຈຸດສົ່ງມອບ;
ຜົນລັບຕ້ອງມີການເກັບກຳຂໍ້ມູນຕິດຕາມຜົນທີ່ອອກແບບໄວ້ຢ່າງຕັ້ງໃຈ (ແບບສຳຫຼວດ, ການເຊື່ອມໂຍງຂໍ້ມູນບໍລິຫານ) ເຊິ່ງຈະບໍ່ມີຢູ່ເວັ້ນແຕ່ມີຜູ້ສ້າງມັນ;
ຜົນກະທົບໂດຍທົ່ວໄປຕ້ອງການຂໍ້ມູນທີ່ເຊື່ອມໂຍງ, ຕາມໄລຍະຍາວ ຫຼື ລະດັບປະຊາກອນ ເກີນກວ່າລະບົບຂອງໂຄງການໃດໜຶ່ງ.
ວິສະວະກອນທີ່ສ້າງເຄື່ອງມືລາຍງານຄວນຜັກດັນໃຫ້ຜູ້ວ່າຈ້າງກຳນົດຕົວຊີ້ວັດຜົນລັບ ແລະ ຜົນກະທົບຕັ້ງແຕ່ຂັ້ນຕອນອອກແບບ,
ແທນທີ່ຈະຕົກລົງໃຊ້ແຜງຄວບຄຸມທີ່ມີແຕ່ຜົນຜະລິດ ເພາະນັ້ນຄືສິ່ງທີ່ຂໍ້ມູນທຸລະກຳຮອງຮັບຢູ່ແລ້ວ. ເບິ່ງ
[ຜົນຕອບແທນທາງສັງຄົມຕໍ່ການລົງທຶນ](../ຜົນຕອບແທນທາງສັງຄົມຈາກການລົງທຶນ/) ສຳລັບວິທີການທີ່ປະເມີນມູນຄ່າຖັນຜົນລັບ ແລະ ຜົນກະທົບໂດຍສະເພາະ, ແລະ
[ການຮັບຮູ້ຜົນປະໂຫຍດ](../ການຮັບຮູ້ຜົນປະໂຫຍດໃຫ້ເປັນຈິງ/) ສຳລັບການຕິດຕາມວ່າຖັນຜົນກະທົບໄດ້ຖືກສົ່ງມອບຈິງຫຼືບໍ່.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ຢຸດທີ່ຜົນຜະລິດ.** ແຜງຄວບຄຸມທີ່ລາຍງານການນັດໝາຍທີ່ສົ່ງມອບ ຫຼື ຖົງອາຫານທີ່ແຈກຢາຍ
  ແລ້ວສື່ເປັນນັຍວ່າມີຜົນປະໂຫຍດ ແມ່ນກຳລັງລາຍງານກິດຈະກຳ ບໍ່ແມ່ນຜົນສຳເລັດ — ເບິ່ງ [ຜົນລັບ ທຽບ ຜົນຜະລິດ](../ຜົນລັບ-ທຽບ-ຜົນຜະລິດ/).
- **ບໍ່ມີການລະບຸຄວາມສຳພັນເຫດ-ຜົນລະຫວ່າງຖັນ.** ແບບຈຳລອງເຫດຜົນລະບຸຕ່ອງໂສ້ແຕ່ບໍ່ໄດ້ອະທິບາຍວ່າເປັນຫຍັງກິດຈະກຳຄວນສ້າງຜົນຜະລິດ
  ແລະ ຜົນຜະລິດຄວນສ້າງຜົນລັບ; ເຫດຜົນນັ້ນຢູ່ໃນ[ທິດສະດີການປ່ຽນແປງ](../ທິດສະດີການປ່ຽນແປງ/), ແລະ ແບບຈຳລອງເຫດຜົນທີ່ບໍ່ມີທິດສະດີນັ້ນຢູ່ເບື້ອງຫຼັງແມ່ນຍັງບໍ່ໄດ້ຜ່ານການທົດສອບ.
- **ຖືວ່າເປັນເອກະສານປະມູນຄັ້ງດຽວ.** ແບບຈຳລອງເຫດຜົນທີ່ເຮັດຂຶ້ນພຽງເພື່ອຕອບສະໜອງຄຳຮ້ອງຂໍທຶນ ແລ້ວບໍ່ເຄີຍປັບປຸງ
  ຈະຢຸດສະທ້ອນສິ່ງທີ່ໂຄງການເຮັດຢູ່ຕົວຈິງ.
- **ການອ້າງຜົນເກີນຕົວຈິງທີ່ຖັນຜົນກະທົບ.** ການອ້າງວ່າການປ່ຽນແປງລະດັບປະຊາກອນເກີດຈາກໂຄງການດຽວພຽງຜູ້ດຽວ
  ໂດຍບໍ່ມີສະຖານະການສົມມຸດທຽບ ແມ່ນເກີນກວ່າສິ່ງທີ່ຫຼັກຖານຮອງຮັບ.
