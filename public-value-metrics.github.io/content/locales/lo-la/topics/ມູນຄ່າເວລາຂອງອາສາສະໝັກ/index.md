# ມູນຄ່າເວລາຂອງອາສາສະໝັກ

ມູນຄ່າເວລາຂອງອາສາສະໝັກ (volunteer time value) ແມ່ນການປະເມີນເປັນເງິນຂອງແຮງງານທີ່ບໍ່ໄດ້ຮັບຄ່າຈ້າງ, ໃຊ້ຫຼາຍທີ່ສຸດເພື່ອລະບຸຮອຍຕີນທາງເສດຖະກິດທີ່ແທ້ຈິງຂອງອົງການການກຸສົນ — ບັນຊີຂອງມັນບວກແຮງງານທີ່ມັນບໍ່ຕ້ອງຈ່າຍ — ຫຼື ເພື່ອສະແດງວ່າການແຊກແຊງໜຶ່ງມີປະສິດທິຜົນດ້ານຕົ້ນທຶນຫຼາຍກວ່າທີ່ງົບເງິນສົດຢ່າງດຽວບົ່ງບອກ. ສອງວິທີວິທະຍາລະດັບຊາດຄອບງຳ: ການປະເມີນຂອງ Independent Sector ຂອງສະຫະລັດ ແລະ ແນວທາງຂອງສຳນັກງານສະຖິຕິແຫ່ງຊາດ / NCVO ຂອງອັງກິດ, ແລະ ພວກມັນຕີລາຄາແຮງງານໜຶ່ງຊົ່ວໂມງດຽວກັນແຕກຕ່າງກັນຫຼາຍ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ທຸກປີ, Independent Sector ຮ່ວມກັບ Do Good Institute ຂອງມະຫາວິທະຍາໄລ Maryland ເຜີຍແຜ່ມູນຄ່າຕໍ່ຊົ່ວໂມງລະດັບຊາດຂອງເວລາອາສາສະໝັກ, ສ້າງຈາກຂໍ້ມູນຄ່າຈ້າງຂອງ Bureau of Labor Statistics — ໂດຍສະເພາະລາຍໄດ້ສະເລ່ຍຕໍ່ຊົ່ວໂມງຂອງຄົນງານຜະລິດ ແລະ ຄົນງານທີ່ບໍ່ແມ່ນຜູ້ຄວບຄຸມໃນບັນຊີເງິນເດືອນເອກະຊົນນອກກະສິກຳ, ບວກການປັບສິດທິປະໂຫຍດເສີມ — ແລະ ແຍກຕາມລັດຂອງສະຫະລັດ. ການເຜີຍແຜ່ຫຼ້າສຸດກຳນົດມູນຄ່າເປັນ **$36.14 ຕໍ່ຊົ່ວໂມງສຳລັບປີ 2025**, ເພີ່ມຂຶ້ນ 3.9% ຈາກປີກ່ອນ, ໂດຍມູນຄ່າລະດັບລັດຢູ່ໃນຊ່ວງຈາກສູງກວ່າ $50 ໃນ Washington, DC ເຖິງຕ່ຳກວ່າ $20 ໃນ Puerto Rico. ໃນອັງກິດ, ສຳນັກງານສະຖິຕິແຫ່ງຊາດໄດ້ປະເມີນແຍກຕ່າງຫາກຕົ້ນທຶນການທົດແທນຂອງການເປັນອາສາສະໝັກແບບເປັນທາງການທີ່ **£14.43 ຕໍ່ຊົ່ວໂມງ** (ການປະເມີນປີ 2017), ແລະ UK Civil Society Almanac 2024 ຂອງ NCVO ໃຊ້ຂໍ້ມູນການມີສ່ວນຮ່ວມອາສາສະໝັກ — ປະມານ 14.2 ລ້ານຄົນເປັນອາສາສະໝັກແບບເປັນທາງການໃນປີ 2021–22 — ເພື່ອປະເມີນການປະກອບສ່ວນອາສາສະໝັກທັງໝົດຂອງຂະແໜງທີ່ປະມານ **£18 ຕື້**, ປະມານ 0.8% ຂອງ GDP ອັງກິດ.

ເຫດຜົນທີ່ມັນສຳຄັນນອກເໜືອຈາກເລື່ອງເຄື່ອງສຳອາງດ້ານບັນຊີ: ໂຄງການທີ່ອີງໃສ່ແຮງງານອາສາສະໝັກຫຼາຍສາມາດເບິ່ງຖືກກວ່າຫຼາຍເມື່ອຄິດ[ຕົ້ນທຶນຕໍ່ຜົນລັບ](../ຕົ້ນທຶນຕໍ່ຜົນໄດ້ຮັບ/) ດ້ວຍເງິນສົດລ້ວນໆ ເມື່ອທຽບກັບໂຄງການທີ່ອີງໃສ່ພະນັກງານທີ່ໄດ້ຮັບຄ່າຈ້າງ, ເຖິງແມ່ນຕົ້ນທຶນຊັບພະຍາກອນແທ້ຈິງ — ຕົ້ນທຶນທີ່ຈະທົດແທນແຮງງານນັ້ນ — ຈະຄ້າຍຄືກັນ ຫຼື ສູງກວ່າ. ຜູ້ໃຫ້ທຶນ ແລະ ຜູ້ປະເມີນທີ່ເມີນເສີຍມູນຄ່າເວລາອາສາສະໝັກ ຈະນັບຕົ້ນທຶນແທ້ຈິງຂອງຮູບແບບການສົ່ງມອບທີ່ເນັ້ນອາສາສະໝັກຕ່ຳເກີນໄປຢ່າງເປັນລະບົບ, ເຊິ່ງບິດເບືອນການປຽບທຽບປະສິດທິພາບກັບຮູບແບບພະນັກງານທີ່ໄດ້ຮັບຄ່າຈ້າງທີ່ສົ່ງມອບຜົນລັບດຽວກັນ.

## ຄະນິດສາດ

```
Value of volunteer time = Volunteer hours contributed × hourly rate

Rate choice matters and changes the answer:
  - Replacement cost approach: the wage of a paid worker who would do the
    same task (e.g. a replacement-cost rate for a qualified youth worker,
    not a generic average wage) — most defensible for task-specific valuation
  - Opportunity cost approach: the volunteer's own forgone wage — most
    defensible for valuing what the volunteer gave up
  - National average approach: Independent Sector's or ONS's single
    blended rate — most defensible for headline, cross-sector comparability
```

ສາມວິທີສາມາດຕ່າງກັນຫຼາຍເທົ່າສຳລັບຊົ່ວໂມງດຽວກັນ (ທະນາຍຄວາມທີ່ເປັນອາສາສະໝັກເປັນຄະນະກຳມະການຜູ້ຮັບຜິດຊອບ ມີອັດຕາຕົ້ນທຶນໂອກາດຕ່າງຈາກອັດຕາສະເລ່ຍລະດັບຊາດຫຼາຍ), ສະນັ້ນຕົວເລກທີ່ລາຍງານຕ້ອງລະບຸວ່າໃຊ້ວິທີໃດ.

## ຕົວຢ່າງການຄິດໄລ່

**ອົງການການກຸສົນອັງກິດ, ວິທີສະເລ່ຍລະດັບຊາດ**: ເວລາອາສາສະໝັກ 5,000 ຊົ່ວໂມງໃນປີໜຶ່ງ, ຕີມູນຄ່າທີ່ £14.43/ຊົ່ວໂມງ (ການປະເມີນຕົ້ນທຶນທົດແທນຂອງ ONS):

```
Value = 5,000 × £14.43 = £72,150
```

ຖ້າການໃຊ້ຈ່າຍເງິນສົດຂອງອົງການການກຸສົນໃນປີນັ້ນແມ່ນ £300,000, ຕົ້ນທຶນຊັບພະຍາກອນແທ້ຈິງຂອງມັນ — ເງິນສົດບວກແຮງງານອາສາສະໝັກ — ແມ່ນ £372,150, ສູງກວ່າຕົວເລກເງິນສົດຢ່າງດຽວປະມານ 24%. ການຄິດໄລ່ຕົ້ນທຶນຕໍ່ຜົນລັບທີ່ໃຊ້ສະເພາະຕົວເລກເງິນສົດ £300,000 ຕີຕົ້ນທຶນແທ້ຕ່ຳເກີນໄປໃນອັດຕາດຽວກັນ.

**ອົງການການກຸສົນສະຫະລັດ, ວິທີສະເລ່ຍລະດັບຊາດ**: ເວລາອາສາສະໝັກ 2,000 ຊົ່ວໂມງ ຕີມູນຄ່າທີ່ $36.14/ຊົ່ວໂມງ (Independent Sector, ການເຜີຍແຜ່ປີ 2025):

```
Value = 2,000 × $36.14 = $72,280
```

**ອົງການການກຸສົນສະຫະລັດດຽວກັນ, ວິທີຕົ້ນທຶນໂອກາດ**: ຖ້າອາສາສະໝັກສ່ວນໃຫຍ່ເປັນຜູ້ຊ່ຽວຊານທີ່ບຳນານແລ້ວ ເຊິ່ງລາຍໄດ້ກ່ອນໜ້າສະເລ່ຍ $60/ຊົ່ວໂມງ, ການຕີມູນຄ່າແບບຕົ້ນທຶນໂອກາດຈະເປັນ $120,000 — ສູງກວ່າຕົວເລກສະເລ່ຍລະດັບຊາດສອງສ່ວນສາມ, ສະແດງເຫດຜົນທີ່ຕ້ອງລະບຸວິທີ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ລະບົບທີ່ບັນທຶກຊົ່ວໂມງອາສາສະໝັກ (ເຄື່ອງມືຈັດຕາຕະລາງກະ, ແພລດຟອມຄຸ້ມຄອງອາສາສະໝັກ) ຄວນບັນທຶກຊົ່ວໂມງໃນລະດັບງານ ຫຼື ບົດບາດ, ບໍ່ແມ່ນພຽງຍອດລວມ, ເພື່ອໃຫ້ນຳໃຊ້ອັດຕາຕົ້ນທຶນທົດແທນຕໍ່ບົດບາດໄດ້ ແທນທີ່ຈະເປັນອັດຕາສະເລ່ຍລະດັບຊາດດຽວຕະຫຼອດກຳລັງອາສາສະໝັກທີ່ປົນກັນ (ຊົ່ວໂມງຂອງຜູ້ຮັບຜິດຊອບ ແລະ ຊົ່ວໂມງຂອງຜູ້ດູແລງານບໍ່ເທົ່າກັນທາງເສດຖະກິດ). ການເກັບອັດຕາ ແລະ ວິທີວິທະຍາທີ່ໃຊ້ຄຽງຄູ່ກັບມູນຄ່າທີ່ຄິດໄລ່ — ບໍ່ແມ່ນພຽງຕົວເລກສະກຸນເງິນສຸດທ້າຍ — ໃຫ້ການລາຍງານຕໍ່ເນື່ອງ (ບັນຊີປະຈຳປີ, ການຄິດໄລ່[ຜົນຕອບແທນທາງສັງຄົມຈາກການລົງທຶນ](../ຜົນຕອບແທນທາງສັງຄົມຈາກການລົງທຶນ/), ລາຍງານຜູ້ໃຫ້ທຶນ) ຜະລິດຄືນ ຫຼື ທ້າທາຍຕົວເລກໃນພາຍຫຼັງ ແທນທີ່ຈະຖືວ່າມັນເປັນຄ່າຄົງທີ່ທີ່ບໍ່ໂປ່ງໃສ. ເບິ່ງ [ຕົ້ນທຶນຕໍ່ຜົນລັບ](../ຕົ້ນທຶນຕໍ່ຜົນໄດ້ຮັບ/) ສຳລັບເຫດຜົນທີ່ການເມີນເສີຍມູນຄ່າເວລາອາສາສະໝັກຕີຕົ້ນທຶນການສົ່ງມອບແທ້ຕ່ຳເກີນໄປຢ່າງເປັນລະບົບ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ໃຊ້ອັດຕາດຽວຄຸມທຸກບົດບາດທີ່ແຕກຕ່າງທາງໂຄງສ້າງ.** ອັດຕາຄ່າຈ້າງສະເລ່ຍລະດັບຊາດທີ່ນຳໃຊ້ກັບຊົ່ວໂມງ pro bono ຂອງມືອາຊີບ (ກົດໝາຍ, ການເງິນ, ການແພດ) ຕີມູນຄ່າຕ່ຳເກີນຫຼາຍ; ໃຫ້ຈັບຄູ່ອັດຕາກັບບົດບາດທີ່ຖືກທົດແທນ ທຸກຄັ້ງທີ່ງານນັ້ນຕ້ອງການທັກສະ.
- **ນັບຊ້ຳກັບຕົ້ນທຶນພະນັກງານທີ່ໄດ້ຮັບຄ່າຈ້າງ.** ຖ້າອາສາສະໝັກແທນງານທີ່ຖ້າບໍ່ດັ່ງນັ້ນຈະມີຄ່າຈ້າງ, ໃຫ້ແນ່ໃຈວ່າການຕີມູນຄ່າເປັນສ່ວນເພີ່ມຕໍ່ເງິນສົດ, ບໍ່ແມ່ນຊ້ອນທັບການປະເມີນພະນັກງານທີ່ພອງແລ້ວ.
- **ອ້າງອັດຕາທີ່ລ້າສະໄໝໂດຍບໍ່ມີວັນທີ.** ອັດຕາຂອງ Independent Sector ແລະ ONS ປ່ຽນລາຍປີ (ຫຼືຖືກປະເມີນໃໝ່ເປັນໄລຍະເທົ່ານັ້ນ, ໃນກໍລະນີ ONS); ຕົວເລກເວລາອາສາສະໝັກທີ່ບໍ່ລະບຸວັນທີໃນລາຍງານເກືອບບໍ່ມີຄວາມໝາຍສຳລັບການປຽບທຽບ.
- **ຖືມູນຄ່າເວລາອາສາສະໝັກເປັນຊັບສິນລະດົມທຶນ.** ມັນເປັນການປັບບັນຊີຕົ້ນທຶນເພື່ອເຂົ້າໃຈຕົ້ນທຶນຊັບພະຍາກອນແທ້ຈິງ, ບໍ່ແມ່ນເງິນໃໝ່ທີ່ອົງການການກຸສົນໃຊ້ຈ່າຍໄດ້; ການສັບສົນສອງຢ່າງນີ້ເຮັດໃຫ້ຄະນະກຳມະການທີ່ອ່ານບັນຊີເຂົ້າໃຈຜິດ.
