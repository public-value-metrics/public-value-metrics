# ການວິເຄາະສະຖານະການສົມມຸດ (Counterfactual Analysis)

ສະຖານະການສົມມຸດ (counterfactual) ແມ່ນການປະມານວ່າຈະເກີດຫຍັງຂຶ້ນຖ້າບໍ່ມີການແຊກແຊງ. ຖ້າບໍ່ມີມັນ, ການປ່ຽນແປງທີ່ສັງເກດໄດ້ຫຼັງໂຄງການເລີ່ມ ແຍກບໍ່ໄດ້ຈາກການປ່ຽນແປງທີ່ຈະເກີດຂຶ້ນຢູ່ແລ້ວ — ບໍ່ມີ counterfactual ກໍບໍ່ມີຫຼັກຖານຂອງຜົນ, ບໍ່ວ່າຕົວເລກກ່ອນ-ຫຼັງຈະເບິ່ງໜ້າເຊື່ອຖືສໍ່າໃດ. Magenta Book ຂອງ HM Treasury ຖືການສ້າງ counterfactual ທີ່ເຊື່ອຖືໄດ້ເປັນພາລະກິດດ້ານວິທີການຫຼັກຂອງການປະເມີນຜົນກະທົບ, ສຳຄັນກວ່າທາງເລືອກການອອກແບບດຽວອື່ນໃດ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

"ອາຊະຍາກຳຫຼຸດລົງ 15% ໃນປີຫຼັງທີ່ພວກເຮົານຳໂຄງການມາໃຊ້" ບໍ່ແມ່ນຫຼັກຖານວ່າໂຄງການໄດ້ຜົນ ເວັ້ນເສຍແຕ່ທ່ານຮູ້ວ່າອາຊະຍາກຳຈະເປັນແນວໃດຖ້າບໍ່ມີມັນ — ອາຊະຍາກຳອາດຫຼຸດລົງ 20% ຢູ່ແລ້ວຍ້ອນແນວໂນ້ມເສດຖະກິດ ຫຼື ປະຊາກອນທີ່ບໍ່ກ່ຽວຂ້ອງ, ໝາຍຄວາມວ່າໂຄງການເຮັດໃຫ້ສິ່ງຕ່າງໆຮ້າຍລົງເມື່ອທຽບກັບ counterfactual, ທັງທີ່ຕົວເລກດິບດີຂຶ້ນ. ນີ້ແມ່ນຂໍ້ຜິດພາດດ້ານການວິເຄາະທີ່ພົບເລື້ອຍທີ່ສຸດໃນຄຳອ້າງຜົນກະທົບຂອງພາກລັດ ແລະ ພາກສັງຄົມ: ເຂົ້າໃຈຜິດການປຽບທຽບກ່ອນ/ຫຼັງວ່າເປັນຫຼັກຖານຂອງສາເຫດ. Magenta Book ລະບຸຢ່າງຊັດເຈນວ່າ ການປະເມີນຜົນກະທົບມີຢູ່ເພື່ອຕອບຄຳຖາມ counterfactual — "ການແຊກແຊງນີ້ສ້າງຄວາມແຕກຕ່າງຫຍັງ?" — ແລະ ການຕອບຕ້ອງໃຊ້ການປະມານ, ບໍ່ແມ່ນພຽງການພັນລະນາ, ໂລກທີ່ບໍ່ໄດ້ເກີດຂຶ້ນ.

ວິທີການຕ່າງໆສ້າງ counterfactual ດ້ວຍລະດັບຄວາມໝັ້ນໃຈທີ່ແຕກຕ່າງ, ແລະ ຄຳແນະນຳການປະເມີນຜົນຂອງລັດຖະບານຈັດອັນດັບຕາມນັ້ນ. ການທົດລອງແບບສຸ່ມທີ່ມີກຸ່ມຄວບຄຸມ (RCT) ທີ່ບຸກຄົນ ຫຼື ພື້ນທີ່ຖືກກຳນົດແບບສຸ່ມໃຫ້ຮັບ ຫຼື ບໍ່ຮັບການແຊກແຊງ ສ້າງ counterfactual ທີ່ແຂງແຮງທີ່ສຸດ ເພາະການສຸ່ມຮັບປະກັນວ່າກຸ່ມທົດລອງ ແລະ ກຸ່ມຄວບຄຸມແຕກຕ່າງກັນ, ໂດຍສະເລ່ຍ, ພຽງແຕ່ການໄດ້ຮັບການແຊກແຊງ. Cabinet Office ແລະ What Works Network ໄດ້ສົ່ງເສີມ RCT ທົ່ວນະໂຍບາຍສາທາລະນະຂອງສະຫະລາຊະອານາຈັກນັບແຕ່ລາຍງານ "Test, Learn, Adapt" ປີ 2012 ໂດຍ Behavioural Insights Team, ກໍເພາະການອອກແບບທີ່ອ່ອນກວ່າມີຄວາມສ່ຽງຕໍ່ຕົວແປສັບສົນ (confounding) — ຄວາມແຕກຕ່າງທີ່ສັງເກດໄດ້ອາດສະທ້ອນວ່າໃຜເລືອກເຂົ້າຮ່ວມ, ບໍ່ແມ່ນຜົນຂອງໂຄງການ. ບ່ອນທີ່ການສຸ່ມບໍ່ເປັນໄປໄດ້ ຫຼື ບໍ່ຖືກຈັນຍາບັນ (ດັ່ງທີ່ມັກເປັນສຳລັບໂຄງການທີ່ມີສິດຕາມກົດໝາຍ, ຫຼື ການປ່ຽນແປງນະໂຍບາຍທົ່ວປະຊາກອນ), Magenta Book ກຳນົດລຳດັບຊັ້ນທີ່ຊັດເຈນຂອງທາງເລືອກທີ່ອ່ອນກວ່າແຕ່ຍັງມີປະໂຫຍດ: ກຸ່ມປຽບທຽບທີ່ຈັບຄູ່, ການອອກແບບຜົນຕ່າງຂອງຜົນຕ່າງ (difference-in-differences), ການຕັດຂາດຂອງຄວາມຖົດຖອຍ (regression discontinuity) ອ້ອມເກນຄຸນສົມບັດ, ແລະ ເປັນທາງເລືອກສຸດທ້າຍ ການປຽບທຽບກ່ອນ/ຫຼັງແບບງ່າຍ — ທີ່ຖືກທຳເຄື່ອງໝາຍຢ່າງຊັດເຈນວ່າເປັນຫຼັກຖານຮູບແບບອ່ອນທີ່ສຸດ, ມີແນວໂນ້ມປົນຜົນຂອງໂຄງການກັບຜົນຂອງທຸກຢ່າງອື່ນທີ່ປ່ຽນໃນເວລາດຽວກັນ.

## ຄະນິດສາດ

ກອບ counterfactual ທີ່ໃຊ້ໄດ້ກັບທຸກວິທີ:

```
Estimated impact = Outcome(with intervention) − Outcome(counterfactual: without intervention)

NOT:
Estimated impact ≠ Outcome(after) − Outcome(before)   [confounds time with treatment]
```

Difference-in-differences ເປັນໜຶ່ງໃນການອອກແບບກຶ່ງທົດລອງທີ່ພົບທົ່ວໄປທີ່ສຸດໃນການປະເມີນຜົນຂອງລັດຖະບານ ແຍກຜົນຂອງການປິ່ນປົວອອກດ້ວຍການລົບການປ່ຽນແປງກ່ອນ/ຫຼັງຂອງກຸ່ມປຽບທຽບເອງ:

```
DiD estimate = [Outcome(treated, after) − Outcome(treated, before)]
             − [Outcome(comparison, after) − Outcome(comparison, before)]
```

ນີ້ກຳຈັດແນວໂນ້ມທີ່ທັງສອງກຸ່ມມີຮ່ວມກັນ (ເຊັ່ນ ການປ່ຽນແປງເສດຖະກິດແຫ່ງຊາດທີ່ກະທົບທຸກຄົນ), ເຫຼືອພຽງການປ່ຽນແປງສ່ວນຕ່າງທີ່ຖືກລະບຸເຖິງການແຊກແຊງ.

## ຕົວຢ່າງການຄິດໄລ່

**ໂຄງການການຈ້າງງານ, ກ່ອນ/ຫຼັງ (ການອອກແບບອ່ອນ)**: ໂຄງການສະໜັບສະໜູນການຫາງານລາຍງານວ່າການຈ້າງງານຂອງຜູ້ເຂົ້າຮ່ວມເພີ່ມຈາກ 40% ເປັນ 55% ໃນໜຶ່ງປີ — ຂໍ້ສະຫຼຸບແບບຂາດຄວາມຊັບຊ້ອນຄື "+15 ຈຸດເປີເຊັນເນື່ອງຈາກໂຄງການ."

**ໂຄງການດຽວກັນ, difference-in-differences (ການອອກແບບທີ່ແຂງກວ່າ)**: ກຸ່ມປຽບທຽບທີ່ຈັບຄູ່ຂອງຜູ້ບໍ່ໄດ້ເຂົ້າຮ່ວມທີ່ຄ້າຍຄືກັນ, ຈາກຕະຫຼາດແຮງງານທ້ອງຖິ່ນດຽວກັນ, ສະແດງການຈ້າງງານເພີ່ມຈາກ 38% ເປັນ 47% ໃນປີດຽວກັນ (ການຟື້ນຕົວເສດຖະກິດແຫ່ງຊາດກຳລັງດຳເນີນ).

```
Treated group change:    55% − 40% = +15 percentage points
Comparison group change: 47% − 38% = +9 percentage points

DiD estimate (true programme effect) = 15 − 9 = +6 percentage points
```

ຜົນທີ່ລະບຸເຖິງໂຄງການໄດ້ຢ່າງຊື່ສັດແມ່ນ 6 ຈຸດເປີເຊັນ, ບໍ່ແມ່ນ 15 — ຫຼາຍກວ່າເຄິ່ງໜຶ່ງຂອງການປັບປຸງກ່ອນ/ຫຼັງທີ່ເຫັນໄດ້ ຈະເກີດຂຶ້ນຢູ່ແລ້ວບໍ່ວ່າຈະມີໂຄງການຫຼືບໍ່, ຂັບເຄື່ອນໂດຍການຟື້ນຕົວເສດຖະກິດດຽວກັນທີ່ຍົກກຸ່ມປຽບທຽບຂຶ້ນ.

**Regression discontinuity, ເກນຄຸນສົມບັດ**: ໂຄງການເງິນອຸດໜູນເປີດສະເພາະທຸລະກິດທີ່ມີພະນັກງານໜ້ອຍກວ່າ 50 ຄົນ. ການປຽບທຽບຜົນໄດ້ຮັບຂອງທຸລະກິດທີ່ຢູ່ໃຕ້ເກນພໍດີ (45–49 ຄົນ, ມີສິດ) ກັບທຸລະກິດທີ່ຢູ່ເໜືອເກນພໍດີ (50–54 ຄົນ, ບໍ່ມີສິດ) ໃຫ້ counterfactual ທີ່ເຊື່ອຖືໄດ້ ເພາະທຸລະກິດທັງສອງຝັ່ງຂອງເສັ້ນຕັດທາງບໍລິຫານຕາມໃຈຄ້າຍຄືກັນໃນດ້ານອື່ນ — ເກນ, ບໍ່ແມ່ນລັກສະນະທຸລະກິດພື້ນຖານໃດ, ເປັນຕົວກຳນົດສິດ. ຄວາມແຕກຕ່າງຜົນໄດ້ຮັບສະເລ່ຍ £2,000 ລະຫວ່າງສອງກຸ່ມທີ່ສັງເກດຢູ່ເກນເທົ່ານັ້ນ ລະບຸເຖິງເງິນອຸດໜູນດ້ວຍຄວາມໝັ້ນໃຈຫຼາຍກວ່າການປຽບທຽບແບບງ່າຍຂອງທຸລະກິດທີ່ມີສິດທັງໝົດກັບທຸລະກິດທີ່ບໍ່ມີສິດທັງໝົດ (ທີ່ແຕກຕ່າງກັນໃນຂະໜາດຢ່າງເປັນລະບົບ).

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ຄວາມຄິດແບບ counterfactual ຄວນກຳນົດວິທີອອກແບບລະບົບຕິດຕາມຜົນກະທົບ ແລະ ທໍ່ປະເມີນຜົນສຳລັບຊອບແວຂອງລັດຖະບານ ແລະ ຂະແໜງສັງຄົມ:

- ສ້າງການເກັບກຸ່ມປຽບທຽບເຂົ້າໃນລະບົບຕັ້ງແຕ່ຕົ້ນ — ບັນທຶກວ່າໃຜມີສິດແຕ່ບໍ່ໄດ້ລົງທະບຽນ, ຫຼື ກຸ່ມຜູ້ບໍ່ໄດ້ເຂົ້າຮ່ວມທີ່ຈັບຄູ່ — ແທນທີ່ຈະເພີ່ມພາຍຫຼັງທີ່ໂຄງການດຳເນີນໄປແລ້ວ ແລະ ມີພຽງຂໍ້ມູນກ່ອນ/ຫຼັງ.
- ບ່ອນທີ່ການສຸ່ມເປັນໄປໄດ້ (ການນຳໃຊ້ເປັນໄລຍະ, ບໍລິການດິຈິຕອນທີ່ເປີດໃຫ້ຜູ້ໃຊ້ບາງຄົນກ່ອນຄົນອື່ນ), ຕິດຕັ້ງເຄື່ອງມືວັດແທກໃນລະບົບເພື່ອຮັກສາການກຳນົດແບບສຸ່ມເປັນຊ່ອງທີ່ສອບຖາມໄດ້; ການນຳໃຊ້ເປັນໄລຍະທຳລາຍຄຸນຄ່າການປະເມີນຂອງຕົນເອງໂດຍບັງເອີນ ຖ້າລຳດັບການກຳນົດບໍ່ຖືກບັນທຶກ.
- ນີ້ແມ່ນວິທີພື້ນຖານເບື້ອງຫຼັງ [ວິທີການປະເມີນຜົນກະທົບ](../ວິທີການປະເມີນຜົນກະທົບ/) ແລະ ແມ່ນສິ່ງທີ່ແຍກມັນຈາກ [ການປະເມີນຜົນກະທົບ ທຽບກັບ ການປະເມີນຂະບວນການ](../ການປະເມີນຜົນກະທົບ-ທຽບກັບ-ການປະເມີນຂະບວນການ/), ຊຶ່ງຢ່າງຫຼັງຖາມວ່າໂຄງການຖືກສົ່ງມອບຕາມທີ່ຕັ້ງໃຈຫຼືບໍ່ ແທນທີ່ຈະຖາມວ່າມັນເປັນສາເຫດຂອງຜົນຫຼືບໍ່.
- [ຜົນເພີ່ມເຕີມ ແລະ deadweight](../ຜົນເພີ່ມເຕີມ-ແລະ-ຜົນທີ່ຈະເກີດຂຶ້ນຢູ່ແລ້ວ/) ແລະ [ການຍ້າຍທີ່ ແລະ ການລະບຸເຫດຜົນ](../ການຍ້າຍທີ່-ແລະ-ການລະບຸຜົນງານ/) ທັງສອງ, ໃນຮາກ, ເປັນຄຳຖາມ counterfactual — deadweight ແມ່ນ "ຜົນໄດ້ຮັບສະເພາະນີ້ຈະເປັນແນວໃດຖ້າບໍ່ມີການແຊກແຊງ", ນຳໃຊ້ໃນລະດັບການປັບແກ້ ແທນການອອກແບບການປະເມີນເຕັມຮູບແບບ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ຖືການປຽບທຽບກ່ອນ/ຫຼັງເປັນຫຼັກຖານຂອງສາເຫດ.** ນີ້ແມ່ນຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ ແລະ ມີຜົນສະທ້ອນທີ່ສຸດໃນການລາຍງານຜົນກະທົບຂອງພາກລັດ ແລະ ພາກສັງຄົມ; ການປ່ຽນແປງກ່ອນ/ຫຼັງປົນຜົນຂອງໂຄງການກັບທຸກຢ່າງອື່ນທີ່ປ່ຽນໃນໄລຍະດຽວກັນ.
- **ໃຊ້ກຸ່ມປຽບທຽບທີ່ແຕກຕ່າງຈາກກຸ່ມທົດລອງຢ່າງເປັນລະບົບ.** ກຸ່ມປຽບທຽບທີ່ຈັບຄູ່ຕ້ອງຄ້າຍຄືກັນແທ້ໃນລັກສະນະທີ່ກ່ຽວຂ້ອງ (ເບິ່ງລຳດັບຊັ້ນວິທີການຂອງ [ການວິເຄາະສະຖານະການສົມມຸດ](../ການວິເຄາະສະຖານະການສົມມຸດ/) ໃນ Magenta Book); ການປຽບທຽບຜູ້ເຂົ້າຮ່ວມໂຄງການ (ຜູ້ເລືອກເຂົ້າເອງ ແລະ ມັກມີແຮງຈູງໃຈຫຼາຍກວ່າ) ກັບຜູ້ບໍ່ໄດ້ເຂົ້າຮ່ວມ (ຜູ້ບໍ່ເລືອກ) ມີຄວາມສ່ຽງທີ່ອະຄະຕິການຄັດເລືອກຈະປອມຕົວເປັນຜົນຂອງໂຄງການ.
- **ທຳລາຍໂອກາດການສຸ່ມດ້ວຍການອອກແບບການສົ່ງມອບທີ່ບໍ່ດີ.** ການນຳໃຊ້ແບບເປັນໄລຍະ ຫຼື ແບບສຸ່ມຮັກສາຄຸນຄ່າການປະເມີນໄດ້ກໍຕໍ່ເມື່ອການກຳນົດສຸ່ມແທ້ ແລະ ຖືກບັນທຶກ — ການໃຫ້ຜູ້ຈັດການທ້ອງຖິ່ນເລືອກວ່າໃຜໄປກ່ອນ ທຳລາຍຈຸດປະສົງ.
- **ເວົ້າເກີນຈິງກ່ຽວກັບຄວາມແມ່ນຍຳຈາກການອອກແບບອ່ອນ.** ຄ່າປະມານກ່ອນ/ຫຼັງຄວນນຳສະເໜີເປັນຕົວຊີ້ບອກ, ບໍ່ແມ່ນຂະໜາດຜົນທີ່ວັດໄດ້; ລຳດັບຊັ້ນຫຼັກຖານຂອງ Magenta Book ມີຢູ່ເພື່ອໃຫ້ຄວາມແຂງຂອງຄຳອ້າງກົງກັບຄວາມແຂງຂອງການອອກແບບທີ່ສ້າງມັນ.
