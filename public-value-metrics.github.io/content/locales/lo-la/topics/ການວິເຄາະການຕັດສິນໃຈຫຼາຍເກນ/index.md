# ການວິເຄາະການຕັດສິນໃຈຫຼາຍເກນ (MCDA)

MCDA ໃຫ້ຄະແນນ ແລະ ຖ່ວງນ້ຳໜັກທາງເລືອກຕາມຫຼາຍເກນທີ່ແຍກຕ່າງຫາກ ແລະ ມີນ້ຳໜັກ ພ້ອມກັນ, ໂດຍໃຫ້ຜົນການປຽບທຽບເປັນລຳດັບ
ໂດຍບໍ່ຕ້ອງບັງຄັບທຸກເກນເຂົ້າສູ່ມາດຕາດຽວທີ່ເປັນເງິນຕາ ຫຼື ໜ່ວຍທຳມະຊາດ. ມັນເປັນວິທີການປະເມີນສຳລັບການຕັດສິນໃຈ
ທີ່ຜົນລັບສຳຄັນບໍ່ສາມາດຫຍໍ້ລົງເປັນຕົວເລກດຽວໄດ້ຢ່າງແທ້ຈິງ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

Green Book ອະນຸມັດ MCDA ຢ່າງຊັດເຈນ (ທັງພາກຜະໜວກກໍລະນີສຶກສາ Box 2 ແລະ Annex A ລ້ວນກ່າວເຖິງມັນໂດຍກົງ)
ສຳລັບການປະເມີນທີ່ຜົນປະໂຫຍດ "ບໍ່ສາມາດວັດແທກດ້ວຍມາດຕາດຽວກັນໄດ້ຢ່າງແທ້ຈິງ" — ເຊິ່ງການແປງທຸກຢ່າງເປັນເງິນຜ່ານ
[ການວິເຄາະຕົ້ນທຶນ-ຜົນປະໂຫຍດທາງສັງຄົມ](../ການວິເຄາະຕົ້ນທຶນ-ຜົນປະໂຫຍດທາງສັງຄົມ/), ຫຼື ເປັນຜົນລັບດຽວຜ່ານ
[ການວິເຄາະປະສິດທິຜົນຕໍ່ຕົ້ນທຶນ](../ການວິເຄາະປະສິດທິຜົນຕໍ່ຕົ້ນທຶນໃນລັດຖະບານ/), ຈະບິດເບືອນການຕັດສິນໃຈແທນທີ່ຈະເຮັດໃຫ້ຊັດເຈນ
(<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>).
ຕົວຢ່າງ, ການເລືອກສະຖານທີ່ສຳລັບຄຸກແຫ່ງໃໝ່ ຕ້ອງແລກປ່ຽນລະຫວ່າງຕົ້ນທຶນທຶນກໍ່ສ້າງ ກັບຜົນກະທົບຕໍ່ຊຸມຊົນ,
ການເຊື່ອມຕໍ່ການຄົມມະນາຄົມ, ຜົນກະທົບຕໍ່ສິ່ງແວດລ້ອມ ແລະ ຄວາມສາມາດໃນການຈ້າງພະນັກງານ — ເກນທີ່ບໍ່ມີໜ່ວຍວັດແທກຮ່ວມກັນ
ແລະ ການບັງຄັບໃຫ້ມີໜ່ວຍຮ່ວມ (ໂດຍທົ່ວໄປແມ່ນເງິນ) ຈະເປັນການລັກລອບໃສ່ການຕັດສິນຄຸນຄ່າກ່ຽວກັບຄວາມສຳຄັນສຳພັດຂອງ, ຕົວຢ່າງ,
ຜົນກະທົບດ້ານສິ່ງແວດລ້ອມທຽບກັບຕົ້ນທຶນ ແລ້ວແຕ່ງຕົວເປັນເລກຄະນິດທີ່ເປັນວັດຖຸວິໄສ.

ຄວາມຊື່ສັດຂອງ MCDA ກໍເປັນຈຸດອ່ອນຫຼັກຂອງມັນ: ເນື່ອງຈາກນ້ຳໜັກຖືກກຳນົດໂດຍຜູ້ທີ່ດຳເນີນການປະເມີນ (ຫຼື ໂດຍຄະນະກຳມະການ),
ວິທີການນີ້ຈຶ່ງມີຄວາມຊອບທຳເທົ່າກັບຂະບວນການກຳນົດນ້ຳໜັກເທົ່ານັ້ນ. ຄຳແນະນຳຂອງ Green Book ລະບຸຢ່າງຊັດເຈນວ່າເກນ ແລະ ນ້ຳໜັກ
ຕ້ອງຕົກລົງ ແລະ ເຜີຍແຜ່ *ກ່ອນ* ໃຫ້ຄະແນນທາງເລືອກ, ເພື່ອປ້ອງກັນບໍ່ໃຫ້ຜູ້ທົບທວນເຮັດຍ້ອນກັບຈາກທາງເລືອກທີ່ມັກ
ໄປຫານ້ຳໜັກທີ່ຮອງຮັບມັນ.

## ຄະນິດສາດ

```
ສຳລັບແຕ່ລະທາງເລືອກ i ແລະ ເກນ j:
  Score_ij   = ຜົນງານຂອງທາງເລືອກຕາມເກນນັ້ນ (ມັກເປັນ 0-100
               ຫຼື 1-10, ຈາກຫຼັກຖານ, ການຕັດສິນຂອງຜູ້ຊ່ຽວຊານ, ຫຼື ການໃຫ້ຄະແນນຂອງຜູ້ມີສ່ວນໄດ້ສ່ວນເສຍ)
  Weight_j   = ຄວາມສຳຄັນສຳພັດຂອງເກນ j, ນ້ຳໜັກລວມກັນເປັນ 1 (ຫຼື 100)

ຄະແນນຖ່ວງນ້ຳໜັກຂອງທາງເລືອກ i = Σ_j (Score_ij × Weight_j)

ຂັ້ນຕອນ:
1. ຕົກລົງຊຸດເກນ ແລະ ນ້ຳໜັກ ກ່ອນໃຫ້ຄະແນນທາງເລືອກໃດໆ (ການຖ່ວງແບບ swing
   ຫຼື ການປຽບທຽບເປັນຄູ່ ເຊັ່ນ AHP ແມ່ນວິທີການຂໍຄວາມເຫັນທີ່ໃຊ້ທົ່ວໄປ).
2. ໃຫ້ຄະແນນທຸກທາງເລືອກຕາມທຸກເກນດ້ວຍມາດຕາສ່ວນດຽວກັນ, ຈາກຫຼັກຖານເທົ່າທີ່ເປັນໄປໄດ້.
3. ຄິດໄລ່ຜົນລວມຖ່ວງນ້ຳໜັກ; ຈັດອັນດັບທາງເລືອກ.
4. ທົດສອບຄວາມອ່ອນໄຫວຂອງນ້ຳໜັກ: ອັນດັບຍັງຄົງຢູ່ບໍ ເມື່ອມີຄວາມເຫັນຕ່າງ
   ທີ່ສົມເຫດສົມຜົນກ່ຽວກັບຄວາມສຳຄັນຂອງແຕ່ລະເກນ?
```

MCDA ບໍ່ໃຫ້ມູນຄ່າສົມບູນທີ່ປ້ອງກັນໄດ້ ຄືກັບມູນຄ່າປັດຈຸບັນສຸດທິຂອງ SCBA — ມັນໃຫ້ພຽງອັນດັບທີ່ຂຶ້ນກັບນ້ຳໜັກທີ່ຕົກລົງກັນ.
ນີ້ເປັນຂໍ້ດີເມື່ອການຕັດສິນໃຈແມ່ນກ່ຽວກັບການແລກປ່ຽນສິ່ງດີທີ່ວັດແທກດ້ວຍມາດຕາດຽວກັນບໍ່ໄດ້ຢ່າງແທ້ຈິງ, ແຕ່ເປັນພາລະ
ຖ້າໃຊ້ເພື່ອຫຼີກລ່ຽງວຽກທີ່ຍາກກວ່າຂອງການປ່ຽນເປັນມູນຄ່າເງິນ ໃນເມື່ອການປ່ຽນເປັນມູນຄ່າເງິນເປັນໄປໄດ້ຕົວຈິງ.

## ຕົວຢ່າງການຄິດໄລ່

**ອົງການປົກຄອງທ້ອງຖິ່ນ**: ສະພາທ້ອງຖິ່ນທີ່ກຳລັງເລືອກສະຖານທີ່ສຳລັບສູນຣີໄຊເຄິນຂີ້ເຫຍື້ອຄົວເຮືອນແຫ່ງໃໝ່
ໃຫ້ຄະແນນສາມສະຖານທີ່ຕາມສີ່ເກນ, ທີ່ຄະນະກຳມະການຂ້າມພະແນກຖ່ວງນ້ຳໜັກກ່ອນການລົງເບິ່ງສະຖານທີ່ໃດໆ:

```
ເກນ (ນ້ຳໜັກ):            ຕົ້ນທຶນກໍ່ສ້າງ (30%)  ການເຂົ້າເຖິງດ້ານຄົມມະນາຄົມ (25%)
                           ຜົນກະທົບຕໍ່ຊຸມຊົນ (25%)  ຜົນກະທົບຕໍ່ສິ່ງແວດລ້ອມ (20%)

ຄະແນນສະຖານທີ່ (0-100, ສູງກວ່າ = ດີກວ່າ):
ສະຖານທີ່ A: ຕົ້ນທຶນ 80, ການເຂົ້າເຖິງ 60, ຊຸມຊົນ 40, ສິ່ງແວດລ້ອມ 70
ສະຖານທີ່ B: ຕົ້ນທຶນ 60, ການເຂົ້າເຖິງ 90, ຊຸມຊົນ 70, ສິ່ງແວດລ້ອມ 50
ສະຖານທີ່ C: ຕົ້ນທຶນ 90, ການເຂົ້າເຖິງ 50, ຊຸມຊົນ 80, ສິ່ງແວດລ້ອມ 60

ຜົນລວມຖ່ວງນ້ຳໜັກ:
ສະຖານທີ່ A = 80(.30) + 60(.25) + 40(.25) + 70(.20) = 24+15+10+14 = 63
ສະຖານທີ່ B = 60(.30) + 90(.25) + 70(.25) + 50(.20) = 18+22.5+17.5+10 = 68
ສະຖານທີ່ C = 90(.30) + 50(.25) + 80(.25) + 60(.20) = 27+12.5+20+12 = 71.5
```

ສະຖານທີ່ C ໄດ້ອັນດັບສູງສຸດ. ການທົດສອບຄວາມອ່ອນໄຫວທີ່ເລື່ອນນ້ຳໜັກຜົນກະທົບຕໍ່ຊຸມຊົນຈາກ 25% ເປັນ 35%
(ເອົາ 10 ຈຸດຈາກຕົ້ນທຶນກໍ່ສ້າງ) ເຮັດໃຫ້ຜົນລວມຂອງສະຖານທີ່ C ເປັນ 71.5 − 3 + 8 = 76.5 ແລະ ຂອງສະຖານທີ່ B ເປັນ
68 − 6 + 7 = 69 — ສະຖານທີ່ C ຍັງນຳໜ້າ, ດັ່ງນັ້ນອັນດັບຈຶ່ງໝັ້ນຄົງຕໍ່ຄວາມເຫັນຕ່າງທີ່ສົມເຫດສົມຜົນກ່ຽວກັບການຖ່ວງນ້ຳໜັກ,
ເຊິ່ງແມ່ນການກວດສອບທີ່ Green Book ຄາດຫວັງໃຫ້ເຫັນໃນລາຍງານ.

**ອົງການການກຸສົນ**: ມູນນິທິໃຫ້ທຶນທີ່ເລືອກລະຫວ່າງການໃຫ້ທຶນບໍລິການໃຫ້ຄຳປຶກສາດ້ານໜີ້ສິນ, ເຄືອຂ່າຍທະນາຄານອາຫານ,
 ແລະ ໂຄງການຄວາມຮູ້ດ້ານການເງິນ ໃຊ້ MCDA ແທນ SROI (ເບິ່ງ
[ຜົນຕອບແທນທາງສັງຄົມຕໍ່ການລົງທຶນ](../ຜົນຕອບແທນທາງສັງຄົມຈາກການລົງທຶນ/)) ກໍຍ້ອນວ່າຄະນະຜູ້ຄຸ້ມຄອງມີຄວາມເຫັນຕ່າງກັນ
ດ້ວຍເຈດຕະນາດີ ກ່ຽວກັບວ່າການບັນເທົາວິກິດຫຼືການປ້ອງກັນຄວນມີນ້ຳໜັກຫຼາຍກວ່າ — MCDA ຊ່ວຍໃຫ້ພວກເຂົາຕົກລົງ *ຮູບຮ່າງ*
ຂອງຄວາມເຫັນຕ່າງນັ້ນ (ຊ່ວງນ້ຳໜັກ) ແທນທີ່ຈະເຮັດທ່າວ່າອັດຕາສ່ວນ SROI ດຽວແກ້ໄຂໄດ້.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

MCDA ເປັນເຄື່ອງມືທີ່ເໝາະສົມສຳລັບການເລືອກຜູ້ຂາຍ ແລະ ສະຖາປັດຕະຍະກຳ ເມື່ອເກນຂັດແຍ້ງກັນຢ່າງແທ້ຈິງ —
ການເລືອກລະຫວ່າງລະບົບຈັດການກໍລະນີທີ່ໂຮສຢູ່ເທິງຄລາວກັບແບບຕິດຕັ້ງໃນສະຖານທີ່ ແລກປ່ຽນລະຫວ່າງຕົ້ນທຶນ,
ຄວາມສ່ຽງດ້ານອະທິປະໄຕຂໍ້ມູນ, ການເຂົ້າເຖິງໄດ້ ແລະ ຄວາມໄວໃນການສົ່ງມອບ ໃນແບບທີ່ຫຍໍ້ເປັນຕົວເລກດຽວບໍ່ໄດ້.
ຫົວໜ້າວິສະວະກອນຄວນຢືນຢັນໃຫ້ການຖ່ວງນ້ຳໜັກເກີດຂຶ້ນກ່ອນໃຫ້ຄະແນນທາງເລືອກ ຕາມທີ່ Green Book ກຳນົດ,
ເພາະການຖ່ວງນ້ຳໜັກທີ່ເຮັດຫຼັງຈາກເຫັນລາຍຊື່ຜູ້ເຂົ້າຮອບຈະລອຍໄປຫາທາງເລືອກທີ່ຫ້ອງປະຊຸມມັກຢູ່ແລ້ວສະເໝີ. ເບິ່ງ
[ສ້າງເອງ ທຽບ ຊື້ ໃນລັດຖະບານ](../ສ້າງເອງ-ຫຼື-ຊື້-ໃນລັດຖະບານ/) ສຳລັບການນຳໃຊ້ MCDA ທົ່ວໄປ, ແລະ
[ບັດຄະແນນຄຸນຄ່າສາທາລະນະ](../ບັດຄະແນນຄຸນຄ່າສາທາລະນະ/) ສຳລັບເຄື່ອງມືໃຫ້ຄະແນນແບບມີໂຄງສ້າງທີ່ກ່ຽວຂ້ອງ
ທີ່ໃຊ້ຫຼັງການຕັດສິນໃຈແທນທີ່ຈະກ່ອນການຕັດສິນໃຈ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ກຳນົດນ້ຳໜັກຫຼັງຈາກເຫັນທາງເລືອກແລ້ວ.** ນີ້ແມ່ນວິທີທີ່ MCDA ຖືກເຮັດໃຫ້ບິດເບືອນພົບເລື້ອຍທີ່ສຸດ,
  ບໍ່ວ່າຕັ້ງໃຈຫຼືບໍ່; ເຜີຍແຜ່ນ້ຳໜັກກ່ອນໃຫ້ຄະແນນ, ແລະ ບັນທຶກວ່າໃຜເປັນຜູ້ກຳນົດ.
- **ຖືວ່າຜົນລວມຖ່ວງນ້ຳໜັກເປັນຕົວເລກທີ່ແນ່ນອນ.** ຄະແນນ 71.5 ທຽບກັບ 68 ບໍ່ແມ່ນຊ່ອງຫວ່າງທີ່ມີນັຍສຳຄັນທາງສະຖິຕິ
  ເວັ້ນແຕ່ການວິເຄາະຄວາມອ່ອນໄຫວຢືນຢັນວ່າອັນດັບໝັ້ນຄົງ; ລາຍງານເປັນຊ່ວງ, ບໍ່ແມ່ນຄວາມແມ່ນຍຳປອມ.
- **ໃຊ້ MCDA ເພື່ອຫຼີກລ່ຽງການປ່ຽນເປັນມູນຄ່າເງິນທີ່ເປັນໄປໄດ້ຕົວຈິງ.** ຖ້າສ່ວນໃຫຍ່ຂອງເກນສາມາດກຳນົດລາຄາໄດ້ຢ່າງໜ້າເຊື່ອຖື,
  ການຕົກລົງໃຊ້ MCDA ແທນ [SCBA](../ການວິເຄາະຕົ້ນທຶນ-ຜົນປະໂຫຍດທາງສັງຄົມ/) ຈະຖິ້ມຂໍ້ມູນທີ່ການປະເມີນສາມາດໃຊ້ໄດ້.
- **ປ່ອຍໃຫ້ຜູ້ມີສ່ວນໄດ້ສ່ວນເສຍທີ່ເດັ່ນຄົນດຽວກຳນົດນ້ຳໜັກທັງໝົດ.** ການປະຕິບັດທີ່ດີຕາມ Green Book ຄາດຫວັງໃຫ້ນ້ຳໜັກຖືກຂໍຄວາມເຫັນຈາກ
  ຄະນະກຳມະການຕົວແທນ, ບໍ່ແມ່ນຜູ້ອຳນວຍການຜູ້ສະໜັບສະໜູນ, ເພື່ອບໍ່ໃຫ້ການປະເມີນພຽງແຕ່ເປັນການຢືນຢັນຄືນສິ່ງທີ່ບຸກຄົນນັ້ນຕ້ອງການຢູ່ແລ້ວ.
