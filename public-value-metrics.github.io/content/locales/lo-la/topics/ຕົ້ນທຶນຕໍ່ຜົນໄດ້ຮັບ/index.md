# ຕົ້ນທຶນຕໍ່ຜົນໄດ້ຮັບ (Cost per Outcome)

ຕົ້ນທຶນຕໍ່ຜົນໄດ້ຮັບ (cost per outcome) ແມ່ນລາຍຈ່າຍໂຄງການທັງໝົດຫານດ້ວຍຈຳນວນຄົນທີ່ບັນລຸການປ່ຽນແປງທີ່ກຳນົດໄວ້ ແລະ ມີຄວາມໝາຍໃນສະຖານະການຂອງຕົນ — ບໍ່ແມ່ນຈຳນວນຄົນທີ່ພຽງແຕ່ໄດ້ຮັບບໍລິການ. ມັນເປັນຕົວຊີ້ວັດປະສິດທິພາບທີ່ແຫຼມທີ່ສຸດທີ່ຜູ້ໃຫ້ທຶນ ຫຼື ທີມສົ່ງມອບໃຊ້ໄດ້ ເພາະມັນບັງຄັບຄຳຖາມກ່ອນໜ້າທີ່ອົງການການກຸສົນສ່ວນໃຫຍ່ຫຼີກເວັ້ນ: ຄວາມສຳເລັດຄືຫຍັງ ຢ່າງແນ່ນອນ?

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ທະນາຄານອາຫານສາມາດລາຍງານສອງຕົວເລກທີ່ແຕກຕ່າງກັນຫຼາຍຈາກບັນຊີປີດຽວກັນ. ຕົ້ນທຶນຕໍ່ຖົງອາຫານທີ່ແຈກຢາຍອາດເປັນ £15. ຕົ້ນທຶນຕໍ່ຄົວເຮືອນທີ່ໄປບັນລຸຄວາມໝັ້ນຄົງດ້ານອາຫານ — ບໍ່ຕ້ອງການຄວາມຊ່ວຍເຫຼືອອາຫານສຸກເສີນອີກ, ກວດສອບໃນຈຸດຕິດຕາມ — ອາດເປັນ £340. ທັງສອງຖືກຕ້ອງ. ມີພຽງອັນດຽວທີ່ບອກຜູ້ໃຫ້ທຶນວ່າເງິນກຳລັງໄດ້ຜົນ. ຊ່ອງຫວ່າງລະຫວ່າງສອງຢ່າງແມ່ນຊ່ອງຫວ່າງລະຫວ່າງຜົນຜະລິດ ແລະ ຜົນໄດ້ຮັບ: ຖົງອາຫານທີ່ສົ່ງໃຫ້ແມ່ນຜົນຜະລິດ; ຄົວເຮືອນທີ່ບໍ່ຢູ່ໃນວິກິດອີກແມ່ນຜົນໄດ້ຮັບ. ເບິ່ງ [ຜົນໄດ້ຮັບ ທຽບກັບ ຜົນຜະລິດ](../ຜົນລັບ-ທຽບ-ຜົນຜະລິດ/).

ຂະແໜງທີສາມຂອງສະຫະລາຊະອານາຈັກໃຊ້ເວລາສອງທົດສະວັດສ້າງໂຄງລ່າງເພື່ອບັງຄັບຄວາມແຕກຕ່າງນີ້. "ວິທີສີ່ເສົາຫຼັກ" ຂອງ New Philanthropy Capital ຕໍ່ປະສິດທິຜົນຂອງອົງການການກຸສົນ ຂໍໃຫ້ອົງກອນລະບຸຜົນໄດ້ຮັບຂອງຕົນກ່ອນຜົນຜະລິດຢ່າງຊັດເຈນ, ແລະ Inspiring Impact — ການຮ່ວມມືວັດຜົນກະທົບທີ່ໄດ້ຮັບທຶນຈາກຜູ້ໃຫ້ທຶນຂອງສະຫະລາຊະອານາຈັກ — ເຜີຍແຜ່ Outcomes Matrix ທີ່ໃບສະໝັກຂໍເງິນອຸດໜູນຈຳນວນຫຼາຍຕອນນີ້ກຳນົດໃຫ້ອົງການການກຸສົນຕື່ມ. ໂຄງການຄົ້ນຄວ້າ "State of Hunger" ປະຈຳປີຂອງ Trussell Trust ທີ່ດຳເນີນກັບ Heriot-Watt University ມີຢູ່ກໍເພາະຈຳນວນຖົງອາຫານຢ່າງດຽວບອກຫຍັງບໍ່ໄດ້ວ່າຜູ້ຄົນຫຼຸດພົ້ນຈາກຄວາມບໍ່ໝັ້ນຄົງດ້ານອາຫານຫຼືບໍ່.

ຕົ້ນທຶນຕໍ່ຜົນໄດ້ຮັບມີຄວາມໝາຍກໍຕໍ່ເມື່ອທ່ານໄດ້ກຳນົດສະຖານະການສົມມຸດ (counterfactual) ແລ້ວ: ຜົນໄດ້ຮັບທີ່ບັນລຸ "ຢູ່ແລ້ວ" ບໍ່ແມ່ນຜົນໄດ້ຮັບທີ່ໂຄງການຊື້ມາ. ເບິ່ງ [ການວິເຄາະສະຖານະການສົມມຸດ](../ການວິເຄາະສະຖານະການສົມມຸດ/) ແລະ [ການຍ້າຍທີ່ ແລະ ການລະບຸເຫດຜົນ](../ການຍ້າຍທີ່-ແລະ-ການລະບຸຜົນງານ/).

## ຄະນິດສາດ

```
Cost per outcome = Total programme cost / Number of beneficiaries achieving the defined outcome

where:
  Total programme cost   = direct delivery cost + fair share of overhead
  Defined outcome        = a pre-specified, measurable state change
                            (e.g. "food secure at 6-month follow-up",
                            not "received a food parcel")
```

ປຽບທຽບກັບ [ຖານຂໍ້ມູນຕົ້ນທຶນຕໍ່ໜ່ວຍ](../ຖານຂໍ້ມູນຕົ້ນທຶນຕໍ່ໜ່ວຍ/) (ເຊັ່ນ ມາດຕະຖານຕົ້ນທຶນຕໍ່ໜ່ວຍສະເພາະຂະແໜງ) ເພື່ອຕັດສິນວ່າຕົ້ນທຶນຕໍ່ຜົນໄດ້ຮັບໜຶ່ງໆດີ, ສະເລ່ຍ ຫຼື ບໍ່ດີ ເມື່ອທຽບກັບການແຊກແຊງທີ່ປຽບທຽບໄດ້.

## ຕົວຢ່າງການຄິດໄລ່

**ທະນາຄານອາຫານ, ໜຶ່ງປີ**:

- ຕົ້ນທຶນໂຄງການທັງໝົດ: £450,000
- ຖົງອາຫານທີ່ແຈກຢາຍ: 30,000
- ຕົ້ນທຶນຕໍ່ຖົງ (ຕົວຊີ້ວັດຜົນຜະລິດ): £450,000 / 30,000 = **£15**

ອົງການການກຸສົນຍັງດຳເນີນການສຳຫຼວດຕິດຕາມຫົກເດືອນກັບຕົວຢ່າງຄົວເຮືອນ, ພົບວ່າ 35% ຂອງຄົວເຮືອນທີ່ໄດ້ຮັບສາມຖົງຂຶ້ນໄປ ລາຍງານວ່າບໍ່ຕ້ອງການຄວາມຊ່ວຍເຫຼືອອາຫານສຸກເສີນອີກ ແລະ ໄດ້ຄະແນນເກີນເກນຄວາມໝັ້ນຄົງດ້ານອາຫານໃນໂມດູນສຳຫຼວດຄວາມໝັ້ນຄົງດ້ານອາຫານມາດຕະຖານ. ຈາກ 1,800 ຄົວເຮືອນທີ່ໄດ້ຮັບສາມຖົງຂຶ້ນໄປໃນປີນັ້ນ, 630 ບັນລຸຜົນໄດ້ຮັບນັ້ນ.

```
Cost per outcome = £450,000 / 630 = £714 per household achieving food security
```

ຕົວເລກ £714 ນັ້ນແມ່ນອັນທີ່ຜູ້ໃຫ້ທຶນທີ່ປຽບທຽບອົງການການກຸສົນນີ້ກັບໂຄງການໂອນເງິນສົດ ຫຼື ບໍລິການໃຫ້ຄຳປຶກສາເລື່ອງໜີ້ຄວນໃຊ້ — ບໍ່ແມ່ນ £15. ຖ້າໂຄງການໂອນເງິນສົດທີ່ປຽບທຽບໄດ້ໃນພາກພື້ນດຽວກັນບັນລຸຄວາມໝັ້ນຄົງດ້ານອາຫານທີ່ £500 ຕໍ່ຄົວເຮືອນ, ທະນາຄານອາຫານກໍບໍ່ແມ່ນເສັ້ນທາງທີ່ມີປະສິດທິພາບກວ່າຢ່າງຊັດເຈນໄປສູ່ຜົນໄດ້ຮັບດຽວກັນ, ເຖິງແມ່ນຕົ້ນທຶນຕໍ່ຖົງເບິ່ງຖືກ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ລະບົບຈັດການກໍລະນີສ່ວນໃຫຍ່ຖືກສ້າງມາເພື່ອບັນທຶກຜົນຜະລິດ ເພາະຜົນຜະລິດແມ່ນສິ່ງທີ່ເກີດຂຶ້ນພາຍໃນທຸລະກຳ (ສົ່ງຖົງອາຫານ, ສົ່ງແບບຟອມ). ຜົນໄດ້ຮັບມັກເກີດຂຶ້ນຕໍ່ມາ, ມັກຢູ່ນອກໜ້າຕ່າງການເກັບຂໍ້ມູນປົກກະຕິຂອງລະບົບ, ແລະ ຕ້ອງການການຕັດສິນໃຈອອກແບບຢ່າງຕັ້ງໃຈ: ສ້າງກົນໄກຕິດຕາມ (ຕົວກະຕຸ້ນແບບສຳຫຼວດ, ຂະບວນການຕິດຕໍ່ຄືນ, ການເຊື່ອມຂໍ້ມູນ) ເປັນຄຸນສົມບັດຊັ້ນໜຶ່ງ, ບໍ່ແມ່ນສິ່ງຕິດເພີ່ມຕາມຫຼັງສຳລັບລາຍງານປະຈຳປີ. ວິສະວະກອນທີ່ສ້າງແພລດຟອມຈັດການເງິນອຸດໜູນ ຫຼື ຈັດການກໍລະນີສຳລັບຂະແໜງຄວນຖື "ເຫດການຜົນໄດ້ຮັບຄືຫຍັງ ແລະ ເຮົາສັງເກດມັນແນວໃດ" ເປັນຄຳຖາມຂໍ້ກຳນົດທີ່ຖາມກ່ອນແບບຈຳລອງຂໍ້ມູນຖືກກຳນົດ — ການເພີ່ມຊ່ອງຜົນໄດ້ຮັບພາຍຫຼັງຍາກກວ່າການເພີ່ມຕົວນັບຜົນຜະລິດຫຼາຍ. ເບິ່ງ [ຜົນໄດ້ຮັບ ທຽບກັບ ຜົນຜະລິດ](../ຜົນລັບ-ທຽບ-ຜົນຜະລິດ/) ແລະ [ແບບຈຳລອງເຫດຜົນ (logic model)](../ແບບຈຳລອງເຫດຜົນ/) ເພື່ອໃຫ້ຮູ້ວິທີຈັດໂຄງສ້າງການສົນທະນາຂໍ້ກຳນົດນັ້ນ, ແລະ [ຕົ້ນທຶນຕໍ່ຜູ້ໄດ້ຮັບຜົນປະໂຫຍດ](../ຕົ້ນທຶນຕໍ່ຜູ້ໄດ້ຮັບຜົນປະໂຫຍດ/) ສຳລັບຕົວຊີ້ວັດທີ່ໄວກວ່າ ແລະ ຫຍາບກວ່າທີ່ທີມໃຊ້ເມື່ອການຕິດຕາມຜົນໄດ້ຮັບຍັງບໍ່ໄດ້ສ້າງ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ລາຍງານຜົນຜະລິດທີ່ແຕ່ງເປັນຜົນໄດ້ຮັບ.** "ຄົນທີ່ເຖິງ" ບໍ່ແມ່ນ "ຄົນທີ່ໄດ້ຮັບຄວາມຊ່ວຍເຫຼືອ." ຖ້າຕົວຊີ້ວັດຜະລິດໄດ້ຈາກບັນທຶກລະບົບໂດຍບໍ່ຕ້ອງຕິດຕໍ່ຕິດຕາມ ມັນເກືອບແນ່ນອນແມ່ນຜົນຜະລິດ.
- **ການຫຼິ້ນກົນກັບຕົວຫານ.** ການຫຍໍ້ກຸ່ມຜົນໄດ້ຮັບເປັນ "ຜູ້ທີ່ຮຽນຈົບໂຄງການ" ຕັດຜູ້ທີ່ອອກກາງຄັນອອກຢ່າງງຽບໆ — ມັກເປັນກໍລະນີທີ່ຍາກທີ່ສຸດ — ແລະ ເຮັດໃຫ້ອັດຕາເບິ່ງສູງເກີນຈິງ. ລະບຸຕົວຫານເປັນທຸກຄົນທີ່ເລີ່ມ, ບໍ່ແມ່ນທຸກຄົນທີ່ຈົບ.
- **ບໍ່ມີສະຖານະການສົມມຸດ.** ການນັບທຸກຄົນທີ່ບັນລຸຜົນໄດ້ຮັບ ລວມທັງຜູ້ທີ່ຈະບັນລຸຢູ່ແລ້ວ ເວົ້າເກີນຈິງກ່ຽວກັບສິ່ງທີ່ໂຄງການຊື້ມາ. ເບິ່ງ [ການວິເຄາະສະຖານະການສົມມຸດ](../ການວິເຄາະສະຖານະການສົມມຸດ/).
- **ປຽບທຽບຂ້າມນິຍາມຜົນໄດ້ຮັບທີ່ເຂົ້າກັນບໍ່ໄດ້.** "ໝັ້ນຄົງດ້ານອາຫານ" ທີ່ວັດດ້ວຍໂມດູນສຳຫຼວດທີ່ຜ່ານການຢັ້ງຢືນ ປຽບທຽບບໍ່ໄດ້ກັບ "ໝັ້ນຄົງດ້ານອາຫານ" ທີ່ລາຍງານເອງໃນແບບຟອມຄວາມພໍໃຈ; ຕາຕາງລີກຕົ້ນທຶນຕໍ່ຜົນໄດ້ຮັບຊື່ສັດກໍຕໍ່ເມື່ອນິຍາມຜົນໄດ້ຮັບກົງກັນ.
