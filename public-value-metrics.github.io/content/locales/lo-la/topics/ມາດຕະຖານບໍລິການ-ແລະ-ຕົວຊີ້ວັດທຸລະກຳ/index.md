ໃນນີ້ກ່ຽວຂ້ອງກັບການວັດຄວາມໄວ້ວາງໃຈທີ່ກວ້າງກວ່າ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ການນຳໃຊ້ທີ່ໄດ້ມາຈາກການປິດຊ່ອງທາງທາງເລືອກ**: ການປິດສາຍໂທລະສັບເພີ່ມເປີເຊັນການນຳໃຊ້ດິຈິຕອນທາງເລກຄະນິດ
  ໃນຂະນະທີ່ຖິ້ມຄວາມຕ້ອງການທີ່ລົ້ມເຫຼວໃສ່ຊ່ອງທາງທີ່ເຫຼືອ (ມັກເປັນເສັ້ນທາງດິຈິຕອນທີ່ມີຜູ້ຊ່ວຍ ຫຼື ພົບໜ້າທີ່ແພງກວ່າ); ວັດຕົ້ນທຶນທັງລະບົບສະເໝີ,
  ບໍ່ແມ່ນອັດຕາສ່ວນຢ່າງດຽວ.
- **ວັດອັດຕາການສຳເລັດຈາກຂັ້ນທີສອງຂອງ funnel**: ການເລີ່ມນັບ "ເລີ່ມ" ຫຼັງຈຸດເຊົາທຳອິດຕົວຈິງ
  ເຮັດໃຫ້ອັດຕາການສຳເລັດເບິ່ງດີກວ່າຈິງ ແລະ ປິດບັງການສູນເສຍທີ່ແກ້ໄຂໄດ້ໃຫຍ່ທີ່ສຸດ.
- **ຕົ້ນທຶນຕໍ່ທຸລະກຳທີ່ບໍ່ລວມການຊ່ວຍເຫຼືອດິຈິຕອນ**: ຕົ້ນທຶນຕໍ່ໜ່ວຍແບບດິຈິຕອນຢ່າງດຽວທີ່ບໍ່ສົນໃຈ
  ເວລາພະນັກງານທີ່ໃຊ້ຊ່ວຍຜູ້ໃຊ້ທີ່ບໍ່ສາມາດບໍລິການຕົນເອງ ປະເມີນຕົ້ນທຶນແທ້ຂອງຊ່ອງທາງຕ່ຳເກີນໄປ.
- **ເຜີຍແຜ່ຕົວຊີ້ວັດໂດຍບໍ່ມີນິຍາມຮ່ວມກັນຂ້າມບໍລິການ**: "ທຸລະກຳ" ແລະ "ສຳເລັດ"
  ມີຄວາມໝາຍແຕກຕ່າງກັນໃນທີມບໍລິການຕ່າງໆ ເວັ້ນແຕ່ນິຍາມຖືກເຮັດໃຫ້ເປັນມາດຕະຖານ ແລະ ຄວບຄຸມເວີຊັນ,
  ເຮັດໃຫ້ການປຽບທຽບຂ້າມບໍລິການບໍ່ໜ້າເຊື່ອຖື.
