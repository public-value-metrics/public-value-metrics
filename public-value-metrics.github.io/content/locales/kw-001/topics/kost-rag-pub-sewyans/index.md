# Kost rag Pub Sewyans

Kost rag pub sewyans yw spenna hollek an towlen rannys dre niver an bobel a dhrehedh chanj dyffynys ha bri yn aga seyth — ha nyns an re hepken a dhegemmeras servis. Hi yw an metrik effeythyans moyha lymm a yll arghansor po bagas delivrans devnydhya, drefen hi dhe erghi govynn kynsa a fyth an brassa kharite: pyth, yn ewn, a gyfrif avel sewenans?

## Perag y talvos

Bank bwyd a yll rapportya dew niver pur dihaval dhiworth akontow an keth bledhen. Kost rag pub parsel bwyd dhelivrys a yll bos £15. Kost rag pub teylu a dhrehedh diogeledh bwyd wosa — na dhe-les gweres bwyd kris, gwiryes orth poynt holya — a yll bos £340. An dhew yw gwir. Hepken unn a laver dhe'n arghansor mar tel an arghans. An skell ynter an dhew yw an skell ynter askorrans ha sewyans: parsel dhelivrys yw askorrans; teylu na vo yn kris moy yw sewyans. Gwelewgh [sewyansow erbyn askorrow](../sewyansow-erbynn-dyllyansow/).

Tressa sektor an Rywvaneth Unys a dhispyndyas dew dheg bledhen ow tyllya infrastrukter dhe erghi an dhispartyans ma. "Fordh pedder piler" New Philanthropy Capital dhe effeythyans kharite a wovyn yn splann orth organyzasyonow dhe dhysplegya aga sewyansow kyns aga askorrow, ha Inspiring Impact — kesoberans musurans impakt skoodhys gans arghansoryon an Rywvaneth Unys — a bobl Matriks Sewyansow a erghy lies arghenn grant dhe kharitys dh'y gowlwul. Towlen hwithrans bledhenyek "State of Hunger" an Trussell Trust, gwrys gans Heriot-Watt University, a vew pur rag niver parselyow hepken ny laver tra a-dro dhe dhiank dhiworth anysogeth bwyd.

Kost rag pub sewyans a styr tra hepken wosa selya an konterfaktek: sewyans dhrehedhys "dre vyth" nyns yw sewyans a brenas an towlen. Gwelewgh [dhivyskans konterfaktek](../dhivyskans-konterfaktek/) ha [displasyans ha attributyans](../displasyans-ha-attribusyans/).

## An matematik

```
Kost rag pub sewyans = Kost hollek an towlen / Niver a gowethyoryon a dhrehedhas an sewyans dyffynys

may hyll:
  Kost hollek an towlen = kost delivrans ewn + rann deg a gostow hollek
  Sewyans dyffynys      = chanj stat rakspesys ha musurys
                           (dhe ensampel "diogel yn bwyd orth holya 6 mis",
                           ha nyns "degemmeres parsel bwyd")
```

Keskomparewgh erbyn [bonkow data kost unyans](../ostelyow-kost-an-unnenn/) (dhe ensampel benchmarkow kost unyans sektor-spesifek) dhe vreusa mar yw kost rag pub sewyans da, kres po drog orth ynvennow keskomparadow.

## Ensampel oberys

**Bank bwyd, unn bledhen**:

- Kost hollek an towlen: £450,000
- Parselyow dhelivrys: 30,000
- Kost rag pub parsel (metrik askorrans): £450,000 / 30,000 = **£15**

An kharite a wra ynwedh sondya holya hwegh mis gans sampla a deylyow, ow kavos bos 35% a'n teylyow a dhegemmeras tri po moy parsel ow rapportya na vos edhom moy a weres bwyd kris ha skorya a-ugh an drosglenn diogeledh bwyd war fodul sondya diogeledh bwyd standard. A'n 1,800 teylu a dhegemmeras tri-plus parsel an bledhen na, 630 a dhrehedhas an sewyans.

```
Kost rag pub sewyans = £450,000 / 630 = £714 rag pub teylu a dhrehedhas diogeledh bwyd
```

An niver £714 yw an niver a dal arghansor ow keskomparya an kharite ma gans towlen kynsa treylyans arghans po servis kusul dyvyow devnydhya — ha nyns £15. Mar teu towlen treylyans arghans keskomparadow y'n keth ranndir dhe dhrehedhes diogeledh bwyd orth £500 rag pub teylu, nyns yw an bank bwyd yn splann an fordh moyha effeythus dhe'n keth sewyans, kyn hevel y gost rag pub parsel kemmyn.

## Kevrenn gans ynjynnerieth medhelweyth

An brassa rann a systemow maner kasow yw byldys dhe logya askorrow, drefen bos askorrow an pyth a hwarvos a-ji an trehans (parsel dhelivrys, furv dhanvonys). Sewyansow a hwarvos yn kemmyn wosa, yn aswonnys a-ves fenester kuntell kres an system, hag a erghy dewis dhesein bos gwrys yn tien: byldyewgh mekanikel holya (trigger sondya, lergh daskontakt, ober kesplegya data) avel nodhva kynsa-klas, ha nyns kodhvarn kesunys rag rapport bledhenyek. Ynjynnoryon a vyld platformow maner grant po maner kasow rag an sektor a dal trettya "pyth yw an hwarvos sewyans, ha fatel y welyn?" avel govynn edhomow gorrys kyns selya an model data — yw meur galetter dhe asa fildys sewyans yn le es kontrol askorrans. Gwelewgh [sewyansow erbyn askorrow](../sewyansow-erbynn-dyllyansow/) ha [model rewl](../model-lojik/) dhe strokturya an kewsel edhomow, ha [kost rag pub kowethyer](../kost-rag-pub-kowethyer/) rag an metrik skonnyk ha kales dhe skon pan na veu holya sewyans byldys hweth.

## Trapow

- **Rapportya askorrow dhyghtys avel sewyansow.** "Tus kyrghys" nyns yw "tus gweresys." Mar hyll an metrik bos produsys dre log system heb kontakt holya, hi yw hepken askorrans ogas yn sur.
- **Gamya an hanow-ranner.** Skoryowhe poblans an sewyans dhe "an re a dhegowlwras an towlen" a dhisterkh yn tawesek an bobel a dhelaas — yn aswonnys an kasow kalessa — ha dhrehevel an skeul hevelys. Leverewgh an hanow-ranner avel pubonan a dhallathas, ha nyns pubonan a worfennas.
- **Heb konterfaktek.** Kyfrifa pubonan a dhrehedhas an sewyans, ow komprehendya an re a wrussa dre vyth, a wormola an pyth a brenas an towlen. Gwelewgh [dhivyskans konterfaktek](../dhivyskans-konterfaktek/).
- **Keskomparya dres dyffynyansow sewyans anhevelep.** "Diogel yn bwyd" musurys gans fodul sondya gwarantys nyns yw keskomparadow orth "diogel yn bwyd" omrapportys war furv lowender; tabel kost-rag-pub-sewyans yw onest hepken pan vo dyffynyansow an sewyans hevelep.
