# 資助成果匯報（IRIS+）

資助成果匯報，係指受助機構向資助者匯報標準化、可比較嘅成果指標，而唔係各個資助者自己發明專屬嘅匯報範本。由全球影響力投資網絡（Global Impact Investing Network，GIIN）維護嘅 IRIS+，係採用最廣泛嘅同類標準：一個預先定義嘅社會、環境同財務表現指標目錄，影響力投資者以至愈來愈多資助型基金會都要求或建議受助機構使用。

## 點解重要

標準化匯報出現之前，每個基金會都以唔同格式向受助機構索取一套唔同嘅指標，一間有十個資助者嘅中型慈善機構，可能要為重疊嘅工作同時運行十套平行嘅匯報流程——呢個係資助成果標準化要減輕嘅匯報負擔嘅一個有據可查嘅成因。IRIS+ 為資助者同受助機構提供共同詞彙去解決呢個問題：按主題（例如可負擔房屋、清潔能源取得、普惠金融）分組嘅核心指標組（Core Metrics Sets），每個指標都定義得足夠精確，令「創造職位」或「服務家庭」無論由邊個匯報都意思相同，並與聯合國可持續發展目標（SDG）對齊，令資助者可以將受助機構層面嘅數據匯總為組合層面嘅 SDG 敘述。GIIN 報告指，大約一半嘅影響力投資者，以及活躍於該領域嘅絕大部分基金經理、銀行同發展金融機構都使用 IRIS 指標。

標準化喺同 [成果與產出](../成果與產出/) 互動嘅地方最重要：IRIS+ 推動匯報走向已定義嘅成果同影響指標，而唔係受助機構現有個案管理系統碰巧記錄嘅數據，而呢個正正係 [每項成果成本](../每個成果成本/) 對比 [每名受益人成本](../每名受益人成本/) 所描述嘅落差。

## 數學原理

資助成果匯報係一個框架同流程，而唔係公式：

```
1. Funder selects a Core Metrics Set relevant to the grant's theme
   (e.g. IRIS+ "Financial Inclusion" or "Sustainable Agriculture")
2. Each metric has a fixed definition, unit, and calculation method
   published by GIIN — not invented per-funder
3. Grantee reports against the same metric definitions across all
   its funders using that standard, cutting duplicate reporting effort
4. Funder aggregates grantee-level metrics into portfolio-level reporting,
   comparable year over year and across grantees using the same metric
```

效率增益係組合式嘅：將 N 個資助者 × M 個受助機構標準化到同一套共同詞彙，會將 N×M 個專屬匯報關係，變成大約 N+M 個對應同一標準嘅映射。

## 實例演算

**標準化前，一個有三個資助者嘅受助機構**：向資助者 1 匯報「服務人數」，用人頭數定義；向資助者 2 匯報「接觸受益人」，用家庭定義；向資助者 3 匯報「受影響個人」，用服務次數定義（即一個人到訪兩次就計兩次）。三份報告、三個數字，彼此無法比較，即使喺同一資助者嘅組合內，亦無法同另一個受助機構嘅數字比較。

**同一個受助機構採用 IRIS+ 之後**：按已定義嘅 IRIS+ 接觸個人指標，連同相關核心指標組內一個已定義嘅成果指標匯報，兩者都採用 GIIN 公布嘅計算方法。三個資助者而家收到同一個數字，用同一方法計算，並可以用相同指標，將呢個受助機構每個 IRIS+ 定義單位嘅成本，同其組合內其他受助機構比較——喺匯報基建規模上，等同擁有一個共用嘅 [單位成本資料庫](../單位成本數據庫/)。

## 與軟件工程嘅關係

資助管理平台應該將 IRIS+ 指標識別碼視為外鍵，而唔係自由文字：將公布嘅指標代碼同受助機構匯報嘅數值一齊儲存（而唔係一個本地發明、叫做「受益人」嘅欄位），先可以令日後跨資助者同跨組合嘅匯總成為可能，而毋須進行數據清理項目。如果平台必須支持未採用 IRIS+ 嘅資助者，務實嘅設計係容許本地指標映射到最接近嘅 IRIS+ 定義，而唔係強迫每個資助者即時採用標準——隨住更多節點映射到共用識別碼，可比性會逐步提高。收集到數字之後應該用嚟計算啲乜，可參閱姊妹課題 [每項成果成本](../每個成果成本/)。

## 常見陷阱

- **將採用 IRIS+ 當成自動具備可比性。** 兩個受助機構可以按同一個 IRIS+ 指標匯報，但如果其底層數據質素或反事實假設唔同，仍然無法比較；標準固定嘅係定義，而唔係量度嘅嚴謹程度。
- **資助者自行發明「對齊 IRIS」嘅指標。** 一個只係受 IRIS+ 措辭啟發、而非實際公布定義嘅指標，會重新引入標準旨在解決嘅碎片化問題。
- **過度揀選造成匯報疲勞。** 當只有兩三個指標同決策相關時，卻要求受助機構按整個核心指標組匯報，等於用標準化嘅包裝重現負擔問題。
- **完全冇成果指標。** IRIS+ 包含好多純產出指標（例如服務人數統計）；如果只揀呢啲而冇揀任何成果層面指標，就會喺成果匯報嘅名義下產生 [每名受益人成本](../每名受益人成本/) 形態嘅匯報。
