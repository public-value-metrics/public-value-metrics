# 公共開支嘅機會成本

機會成本係指公營機構將金錢、員工時間或者政治資本投入某個方案，而放棄咗嘅最佳替代選擇嘅價值。喺預算固定嘅部門，每一鎊用喺一個計劃上，就係唔可以用喺次佳計劃上嘅一鎊——一個決定嘅真正成本，唔係佢花費咗幾多，而係佢排擠咗乜嘢。

## 點解重要

公共預算喺一個開支檢討期內有現金上限，所以——同不斷增長嘅私營公司唔同——政府部門唔可以為咗一個好意念就「搵多啲錢出嚟」；資助佢，就意味住要停止資助另一樣嘢。HM Treasury 嘅 Green Book 將呢點視為基礎：每項評估都必須將干預措施同「最低限度行動」(do minimum)基線*以及*同一資源嘅現實替代用途作比較，因為財政部開支團隊真正會問嘅，從來唔係「呢個好唔好？」，而係「呢個係咪好過呢筆錢本來可以買到嘅其他嘢？」Green Book 嘅核心評估原則——公共資源應該流向每鎊淨社會價值最高嘅干預措施——就係以政策形式表達嘅機會成本。

呢個原則易講難行，因為「次佳替代方案」好少會喺單一商業個案中睇得見。一個 £2 百萬嘅青年就業資助計劃，喺商業個案入面係同「乜都唔做」比較——但誠實嘅比較對象，係次佳嘅青年就業干預措施，甚至係投資組合入面任何地方、包括非就業開支嘅 £2 百萬嘅次佳用途。Magenta Book(HM Treasury，2020)明確警告，將「有干預」同「冇干預」比較嘅評估，會低估干預措施需要跨越嘅門檻，因為「冇呢項干預」唔等於「乜都冇」——釋放出嚟嘅資金會用於其他嘢。

## 數學原理

```
Opportunity cost of choosing A = value of the best forgone alternative B

Net public value of A = value(A) − value(B), not value(A) − 0
```

因為被放棄嘅替代方案視乎具體情況，所以冇通用公式，但做法可以推而廣之：識別同一預算項目嘅現實次佳用途(而唔係理想化嘅「乜都唔做」)，按相同基礎估值(盡可能貨幣化，依據[社會成本效益分析](../社會成本效益分析/))，然後相減。

## 實例演算

**部門預算項目**：一個 £5 百萬嘅數碼轉型基金，本財政年度剛好可以資助兩個建議之中嘅一個。

- *方案 A*：新嘅個案管理平台，5 年內貨幣化效益為 £7.2 百萬(效率節省加上更快結案)。
- *方案 B*：三個部門共用嘅身份驗證服務，5 年內貨幣化效益為 £6.4 百萬。

一份天真嘅 A 方案商業個案，會將 £7.2 百萬效益同 £5 百萬成本比較，報告 1.44:1 嘅效益成本比——表面上好強勁。但因為 A 同 B 爭奪同一筆 £5 百萬，揀 A 嘅機會成本就係放棄咗 B 嘅 £6.4 百萬效益。相對現實替代方案，A 嘅*淨*理據只係 £7.2m − £6.4m = £0.8 百萬，而唔係頭條嘅整個 £7.2 百萬。如果有第三個方案 C，用同一筆 £5 百萬可以帶來 £7.5 百萬效益，咁資助 A 而唔資助 C，就會損失 £0.3 百萬公共價值，儘管 A 自己嘅商業個案單獨睇似乎完全合理。

**地方政府員工時間**：一個議會嘅三人數據團隊，可以建置房屋輪候冊儀表板(估計每年節省 400 個主任工時，按每小時 £28 估值為每年 £11,200)，或者福利欺詐分流工具(估計每年可預防 £85,000 嘅錯誤支付)。建置儀表板嘅機會成本係放棄每年 £85,000，而唔只係數據團隊嘅薪酬成本——「免費」內部自建嘅真正成本，係團隊本可以喺別處創造嘅大得多嘅效益。

## 與軟件工程嘅關係

公營機構內部嘅工程能力本身就係受限嘅預算——以衝刺(sprint)能力計，而唔係以英鎊計——同一原則可以直接應用：

- 一定要點明比較對象：功能嘅商業個案，應該說明同一批團隊週數可以交付乜嘢，而唔只係佢自己嘅回報。
- 將「我哋有閒置工程能力」視為機會成本分析嘅開始，而唔係終點——閒置能力仍然有最佳替代用途，即使該用途係償還技術債(見[技術債作為公共價值嘅侵蝕](../技術債務-侵蝕公共價值/))。
- 直接連繫到[物有所值](../物有所值/)：物有所值嘅「經濟」(economy)測試，冇誠實嘅機會成本比較對象就毫無意義；同埋連繫到[公共計劃嘅延誤成本](../公共計劃嘅延誤成本/)，後者為同一套放棄替代方案邏輯嘅時間維度定價。

## 常見陷阱

- **同「乜都唔做」比較，而唔係同次佳替代方案比較。** Green Book 要求「最低限度行動」基線，正正因為真正嘅機會成本好少係零；只係跨過「乜都唔做」門檻嘅商業個案，並未證明自己勝過現實嘅替代方案。
- **忽略跨部門爭奪同一筆資源。** 喺一個署級單位內看似專款專用嘅預算項目，往往喺更高層級(開支檢討、資本計劃)互相競爭，真正嘅機會成本就係喺嗰度實現。
- **假設釋放出嚟嘅員工時間冇進一步價值。** 「節省」嘅時間，只有重新調配到有價值嘅用途先會創造價值；如果替代用途並不存在，節省只係名義上嘅。
