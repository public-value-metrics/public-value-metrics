# 單位成本數據庫

單位成本數據庫係一個預先研究、有證據基礎嘅社會成果財務替代值庫——例如由失業轉為就業、減少孤獨感、穩定租約嘅價值——令從業員無須每次都委託專門估值研究，就可以將成果貨幣化。佢哋存在嘅目的，係令撰寫資助申請嘅小型慈善機構，可以透過重用別人已推導同發表嘅替代值，應用同資源充裕嘅顧問公司一樣嘅嚴謹度。

## 點解重要

HACT 嘅 UK Social Value Bank(由經濟學家 Daniel Fujiwara 以福祉估值方法開發)，同 Global Value Exchange(一個開放、眾包嘅財務替代值數據庫)，係英國第三部門同公共部門最廣泛使用嘅兩個。兩者存在，係因為底層估值工作——[福祉估值](../福祉估值/)同[陳述偏好估值](../陳述偏好估值/)——成本高昂、方法上要求高，而且為每個項目由零開始進行好慢。一個共用、已發表嘅替代值庫，將原本需時數月嘅研究工作變成一次查找，正正係點解佢哋對[社會投資回報](../社會投資回報/)計算同[社會價值法](../社會價值法/)投標評審都咁重要：冇佢哋，嚴謹嘅貨幣化只有大到可以自行委託研究嘅機構先負擔得起。

## 數學原理

單位成本數據庫本身唔計算任何嘢；佢為其他地方進行嘅計算提供一項輸入：

```
Financial proxy value = market price, OR shadow price, OR wellbeing valuation,
                         OR stated-preference value
                         for a defined unit of outcome change
                         (e.g. "per person moving from unemployment to employment, per year")

Applied value = number of outcomes achieved × unit proxy value
```

當冇市場價格時點樣建構替代值，見[影子價格](../影子價格/)；應用價值喺死重效應同歸因調整後如何輸入比率，見[社會投資回報](../社會投資回報/)。

## 實例演算

**慈善機構(探訪友伴服務 SROI)**：單位成本數據庫中「減少孤獨感」嘅條目，示意替代值為每人每年 £1,100。應用於 80 名受益人：80 × £1,100 = £88,000 總價值。如果同一個數據庫亦有「改善心理福祉」嘅替代值，並且採用重疊嘅福祉調查項目，為同一批 80 人疊加兩個替代值，就會重複計算同一底層改變嘅一部分——數據庫提供數字，但避免呢種重疊係分析人員嘅責任。

**地方政府(求職會 SROI)**：單位成本數據庫中「由失業轉為持續就業」嘅條目，按示意替代值每人每年 £8,500 應用於 45 名參加者：45 × £8,500 = £382,500 總價值，仍未作[社會投資回報](../社會投資回報/)所示嘅死重效應同歸因調整。

## 與軟件工程嘅關係

為慈善機構或委託機構開發報告工具嘅團隊，受惠於內部「成果目錄」——一個表格，將產品或服務可合理聲稱嘅每個成果，對應到一個具名替代值、其來源數據庫、發布日期同版本識別碼——令機構內唔同團隊唔會各自為同一成果揀選略有不同嘅數值。將 Global Value Exchange 嘅開放數據包裝喺查找服務之後，並始終喺數字旁邊顯示來源同日期，令替代值可被審計，而唔係埋藏喺試算表入面嘅神奇數字。呢啲替代值最主要被使用嘅兩個地方，見[社會投資回報](../社會投資回報/)同[社會價值法](../社會價值法/)。

## 常見陷阱

- **將替代值視為精確。** 大部分已發表替代值係福祉估值研究所得嘅建模平均值，信賴區間好闊；引用到個位英鎊，高估咗底層研究所能支持嘅精確度。
- **重複計算重疊替代值。** 將源自重疊調查建構嘅替代值(例如「減少孤獨」同「改善心理福祉」)合併使用，會對同一個底層改變估值兩次。
- **未經調整就使用脫離情境嘅替代值。** 喺某一國家人口同年份校準嘅替代值，在其他地方未經通脹或者情境調整就應用，會悄悄錯誤陳述價值。
- **冇檢查來源出處。** Global Value Exchange 係開放同眾包嘅，所以條目質素因貢獻者而異；喺資助申請或者採購提交中引用數字之前，應檢查底層來源。
