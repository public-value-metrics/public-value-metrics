# 邏輯模型

邏輯模型係一幅線性圖表，將一個計劃嘅投入(inputs)、活動(activities)、產出(outputs)、成果(outcomes)同影響(impact)連繫起上嚟，由左至右睇，就係一條問責鏈：資源投入、活動展開、產出生成、受益人嘅情況出現改變，最後喺更廣闊或者更長遠嘅時間尺度上產生影響。資助者同審計人員一般都期望計劃可以按呢個結構匯報，佢亦係由後向前推演嘅[變革理論](../變革理論/)嘅前瞻對應工具。

## 點解重要

HM Treasury(英國財政部)嘅 Magenta Book 將邏輯模型列為計劃評估設計嘅必備元素，而 National Lottery Community Fund 等資助機構，亦正正圍繞呢條五欄鏈條設計申請同匯報範本。佢嘅價值喺於迫使計劃用一幅圖講清楚：會花幾多資源、點樣運用、會產出啲乜，仲有最關鍵嘅——結果之後應該有咩改變，而且講到嘅具體程度，係一段文字往往含糊帶過嘅。一個「投入」同「活動」欄填得滿滿，但「成果」欄空白或者含糊嘅邏輯模型，一眼就睇得出問題所在，所以資助者先會要求提交。

## 數學原理

邏輯模型係一條結構鏈，而唔係一條公式：

```
Inputs          Activities        Outputs             Outcomes              Impact
(resources      (what is done     (direct, countable   (change for           (long-term,
 committed)      with them)        products)            beneficiaries)        population-level
                                                                               or systemic change)
```

每一欄都應該比上一欄更具體：投入係你花費嘅資源，活動係你所做嘅工作，產出係無論有冇成效都會交付嘅事物，成果係由此帶來嘅改變——呢個分別喺[成果與產出](../成果與產出/)有詳細討論——而影響則係持久、往往只能部分歸因嘅長遠改變。

## 實例演算

**地方政府(數碼債務諮詢服務)**：

- 投入：每年預算 £180,000、4.0 個全職等同(FTE)顧問、一套個案管理系統。
- 活動：外展環節、一對一債務諮詢預約。
- 產出：提供咗 900 次預約；發出 750 份債務同福利計劃。
- 成果：喺到達 6 個月跟進嘅客戶之中，60%(750 人中嘅 450 人)報告欠款減少，平均每人減少 £1,200——合共欠款減少 £540,000。
- 影響：兩年內，服務客戶群體嘅無家可歸申請有可量度嘅下降，但只有部分可歸因於呢項服務，因為同時有其他干預措施(見[反事實分析](../反事實分析/))。

**慈善機構(食物銀行轉介夥伴計劃)**：

- 投入：£45,000、1.5 個全職等同統籌員、同 12 間轉介機構簽訂嘅夥伴協議。
- 活動：轉介分流、包裝同派發食物包。
- 產出：向 1,100 個家庭派發 5,000 個食物包。
- 成果：喺 4 星期後嘅跟進電話中，68% 受訪家庭(1,100 個中嘅 748 個)報告糧食保障有改善。
- 影響：有助減少本地危機服務需求，但只有整體地區統計數字可以佐證，唔可以單獨歸功於呢間慈善機構。

## 與軟件工程嘅關係

邏輯模型簡直可以當作成果系統嘅數據模型：投入同活動係你已經持有嘅營運數據(開支、人手、環節記錄)；產出容易埋點，因為喺服務提供當刻就可以點算；成果就需要刻意設計嘅跟進數據收集(問卷、行政數據連結)，冇人去建，就唔會存在；影響通常需要連結嘅、縱向嘅或者人口層面嘅數據，超出任何單一計劃嘅系統範圍。開發匯報工具嘅工程師，應該推動委託方喺設計階段就界定成果同影響指標，而唔係因為交易數據只支援產出，就默認做一個純產出儀表板。專門估值成果同影響兩欄嘅方法，可參閱[社會投資回報](../社會投資回報/)；追蹤影響欄有冇真正兌現，則可參閱[效益實現](../效益實現/)。

## 常見陷阱

- **止步於產出。** 一個只匯報已提供預約數目或者已派發食物包、卻暗示有效益嘅儀表板，匯報嘅係活動而非成果——見[成果與產出](../成果與產出/)。
- **欄與欄之間冇交代因果關係。** 邏輯模型只列出鏈條，但冇解釋點解活動會帶來產出、產出又會帶來成果；呢種推理屬於[變革理論](../變革理論/)，冇變革理論支撐嘅邏輯模型，仍然未經檢驗。
- **當成一次過嘅投標文件。** 只係為咗應付資助申請而製作、之後從不更新嘅邏輯模型，就唔會再反映計劃實際做緊乜嘢。
- **喺影響欄出現歸因膨脹。** 冇反事實比較，就聲稱人口層面嘅改變全由單一計劃造成，會誇大證據所能支持嘅結論。
