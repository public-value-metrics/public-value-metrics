# 人類發展指數（Human Development Index，HDI）

HDI 係聯合國用嚟取代單靠收入為各國排名嘅標誌性指標：佢將預期壽命、教育同收入合成一個介乎 0 同 1 之間嘅數字，前提係——經濟學家 Amartya Sen 提出、並由 Mahbub ul Haq 為聯合國發展出嚟——發展在於擴大人們可以做乜同成為乜，而唔單止係賺幾多。自 1990 年起，佢每年都喺聯合國開發計劃署（UNDP）嘅《人類發展報告》（Human Development Report）中公布。

## 點解重要

HDI 出現之前，「發展」幾乎完全以人均國民生產總值（GNP）量度，但呢個數字完全無法反映增長有冇惠及普通人嘅健康或教育。Sen 嘅能力取向（capability approach）將發展重新定義為真正自由嘅擴展，而 ul Haq 將佢變成一個可以公布、令 UNDP 能夠為每個國家排名嘅指數，迫使單靠收入致富、卻忽視健康或教育嘅政府，面對比其 GDP 所顯示更差嘅排名（海灣產油國同部分資源開採型經濟體係標準例子）。HDI 嘅三方結構亦係 [多維貧窮指數](../多維貧窮指數/) 方法論上嘅直接祖先：兩者都拒絕俾一個維度彌補另一個維度嘅不足，採用幾何平均而非算術平均。UNDP 為每一屆公布完整嘅技術說明同底層數據（<https://hdr.undp.org/data-center/human-development-index>），係任何基於該指數開發、而非自行重新推導嘅人士嘅權威來源。

## 數學原理

```
Life Expectancy Index (LEI)     = (LE − 20) / (85 − 20)

Mean Years Schooling Index      = mean years of schooling / 15
Expected Years Schooling Index  = expected years of schooling / 18
Education Index (EI)            = (Mean Years Index + Expected Years Index) / 2

Income Index (II)               = (ln(GNI per capita) − ln(100)) / (ln(75000) − ln(100))

HDI = (LEI × EI × II) ^ (1/3)     [geometric mean of the three sub-indices]
```

幾何平均係刻意嘅選擇：因為佢係相乘而非平均，一個維度嘅極高分，無法完全抵銷另一個維度嘅極低分——UNDP 喺 2010 年採用呢個設計，專門用來懲罰失衡，取代之前嘅算術平均公式。

## 實例演算

**中等收入國家**：預期壽命 72 歲，平均受教育年期 8 年，預期受教育年期 13 年，人均國民總收入（GNI）$12,000。

```
LEI = (72 − 20) / (85 − 20)              = 52 / 65   = 0.800
MYSI = 8 / 15                                        = 0.533
EYSI = 13 / 18                                       = 0.722
EI = (0.533 + 0.722) / 2                             = 0.628
II = (ln(12000) − ln(100)) / (ln(75000) − ln(100))
   = (9.393 − 4.605) / (11.225 − 4.605)
   = 4.788 / 6.620                                   = 0.723

HDI = (0.800 × 0.628 × 0.723) ^ (1/3)
    = (0.363) ^ (1/3)                                ≈ 0.713
```

HDI 0.713 屬於 UNDP「高人類發展」組別（0.700–0.799）；「極高」由 0.800 開始。留意結果對最弱嘅分項指數幾敏感：如果平均受教育年期係 4 年而非 8 年（MYSI = 0.267，EI = 0.494），HDI 會跌至 (0.800 × 0.494 × 0.723)^(1/3) ≈ 0.639——跌咗成個組別——即使其他嘢都冇變。

## 與軟件工程嘅關係

- 幾何平均模式可以直接重用於任何你唔想令一個強項維度掩蓋關鍵弱項嘅綜合服務或產品分數——例如將公共數碼服務嘅無障礙、效能同可靠性分數以相乘而非加權平均結合，令一個快但唔無障礙嘅服務唔可能得到「好」嘅評分。
- HDI 對收入取對數（多一鎊嘅邊際價值遞減）同評估中 [分配權重](../分配權重/) 背後係同一邏輯：多 $1,000 對貧窮家庭嘅意義遠大過富裕家庭，兩者都按線性處理會令影響力定價錯誤。
- 任何匯報單一綜合「數碼包容」或「市民成果」分數嘅儀表板，都應該像 UNDP 技術說明咁明確記錄其匯總公式——參閱 [公共部門 KPI](../公營界別關鍵績效指標/) 同 [公共價值計分卡](../公共價值記分卡/)。

## 常見陷阱

- **用平均數而非幾何平均** ——算術平均會令高收入完全掩蓋差劣嘅健康或教育；2010 年方法論改變嘅全部目的，就係要阻止呢種替代。
- **將 HDI 逐年比較，當佢係經通脹調整嘅 GDP** ——UNDP 會不時重設指數基準（新嘅最小/最大界限、修訂嘅教育年期上限），所以排名變化可能反映方法論更新，而非真正轉變；務必檢查數字來自邊一屆《人類發展報告》。
- **將 HDI 當成貧窮量度** ——佢係全國平均數，完全無法反映一個國家內部嘅分配；如需要，請用 [多維貧窮指數](../多維貧窮指數/) 或 UNDP 另設嘅不平等調整人類發展指數（Inequality-adjusted HDI）。
