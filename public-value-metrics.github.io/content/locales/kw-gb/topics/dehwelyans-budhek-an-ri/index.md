# Dehwelyans Budhek an Ri

Dehwelyans budhek an ri yw an pyth a bren punt unn ri arbennek yn devethyow — nyns yw dhe arvysyans oberyans an kevarghadow, na dehwelyans an kevarghadow war y holl budjet. Ev a dreyl ROI dhyworth gwelva an organyzasyon (fatell wrons ni oberi yn effeythus) dhe wel an ri (pyth a dreyl ow ri ogasel ow honan), hag an dew nivel yw kemerys menough, yn ankamm, avel an keth tra.

## Perag y talvos

"ROI" kevarghadow y honan, mar kwra an lavar bos devnydhys vyth, a dhisqwedh nebes kepar ha [kost dhe bub budhekor](../kost-rag-pub-kowethyer/) po [nivel dhe-wartha kevarghadow](../skeul-kostow-hollek-kharite/) — musurow effeythieth organyzasyon. ROI an ri yw govyn dyffrans yn tien: ynwedh an kevarghadow a'n jy kevrennow erel, pyth a dhre arghans *an ri ma* orth an vorth? Mar kwrella kevarghadow delivra an keth program gans po heb ri a £10,000 arbennek — drefen y a'n jy gwithvaow lowr, po drefen ri aral a vensa lenwel an spas — ROI ri a'n ri na yw nes dhe seros, kyn fo da nivel dhe-wartha an kevarghadow hollek po kost dhe bub deveth.

Hemma yw an keth govyn ynkressyans a dhegor [talvos rag arghans](../talvedh-rag-arghans/) yn arvreythyans a wari poblek an UK ha [ynkressyans ha pwys marow](../additivans-ha-pols-marow/) yn arvreythyans program: talvos gwruthys yw dhe wra dhe skoodhyer hepken pan na wrussa hwarvos poken. Platformow ri bras ha organyzasyons ri effeythus (Giving What We Can, GiveWell) a vydh aga erghow savys yn eglur war an dyffrans ma, ow-govyn nyns "yw hemma kevarghadow da" mes "a'n jy an kevarghadow ma spas anlenwys rag moy a arghans may fo ow ri ynkressys."

## An matematik

```
ROI ri ≠ Effeythieth oberyans an kevarghadow

ROI ri  ≈  (Deveth kowlwrys gans an ri) − (Deveth a wrussa hwarvos
            heb ev, hen yw an kontrafaktel)
          ─────────────────────────────────────────────────
                          Myns an ri

Entrow bysyk:
  - Spas rag moy a arghans (a yw an kevarghadow strusys gans arghans orth an vorth?)
  - Funging (a vensa ri aral lenwel an spas?)
  - Kost-effeythieth ogasel orth an nivel arghans arbennek (kostow a
    dhrik menough pan wra ebyrnans tremena y boblans nessa dhe dhos dhe)
```

Mir [kost-effeythieth ynkressyans effeythus](../kost-effeythieth-altrewieth-effeythus/) rag fatell wra GiveWell oberi an govyn "spas rag moy a arghans", ha [dehwelyans kontrafaktel](../dhivyskans-konterfaktek/) rag an fordh kenedhlek.

## Ensampel oberys

Ri a dal dewis ynter dew ri a £5,000:

- **Kevarghadow C**: a'n jy program kres arghansys yn leun gans £2 vylyon yn gwithva ha rol a skoodhyoryon ow-gortos; an £5,000 ogasel a vydh ynkressys moy dhe'n gwithva po dhe oberyans a nessa-klass isella. Deveth ynkressys an ri rakwelys: byghan — nyns yw an arghans ow-chanjya yn eglur pyth a hwarva.
- **Kevarghadow D**: program byghan skoodhys gans dustuni a dherivas yn poblek bos res dhe'n kevarghadow dhe dhenegi 200 den an kwarter nessa heb £50,000 ynkressys, ha kuntellys re £42,000 anodho. An £5,000 ogasel a vydh fest dhe vos skoodh dhe delivrans ynkressys gwir — leveryn, 20 den moy servys, orth kost dhe bub budhekor a £250 derivys gans an kevarghadow y honan.

An keth myns ri, an keth ri, ROI ri fest dyffrans — nyns drefen bos Kevarghadow C organyzasyon gwessa (a yll kavos figyr kost-dhe-bub-deveth gwell yn hollek) mes drefen bos y dyvyth arghans ogasel degeys re.

## Kevrenn gans ynjynnerieth medhelweyth

Platformow ri ha toulys erghi ri a dhisqwedh re venough hepken musurow effeythieth nivel organyzasyon (nivel dhe-wartha, kost dhe bub budhekor) drefen hemma yw an pyth a dhyllo kevarghadow yn raportys bledhennek ha an pyth yw esya dhe dhegi yn tabel kehevelyans. Diskwedh ROI ri yn ewn a erghi pyth data dyffrans, kaletha dhe gavos: dyvyth arghans arvyssys a'n kevarghadow lemmyn po "spas rag moy a arghans," a dreyl dres an bledhen ha nyns yw menough data strukturys. Platformow a vynn skoodhya ewn-resonyans ROI ri a res bos dhedha po fynten ewn dhyworth dyllans dyvyth arghans (kepar dell wra GiveWell gans dorn rag y gevarghadow erghys) po awisyans eglur bos an tabel kehevelyans ow-tiskwedh effeythieth organyzasyon, nyns yw ynkressyans ri. Mir [nivel dhe-wartha kevarghadow](../skeul-kostow-hollek-kharite/) rag an musuryans may fo ROI ri kemmyskys orto an moyha menough, yn ankamm.

## Trapow

- **Kemmyska effeythieth kevarghadow gans ynkressyans an ri.** Kevarghadow gwrys yn ewn gans dhe-wartha isel a yll kavos ROI ri ogasel nes dhe seros mar nyns yw strusys gans arghans.
- **Ankevi funging.** Mar kwrella skoodhyer bras sherewyth gwarhe an spas hepken, ri ri unnik a displasa arghans an skoodhyer na dres delivrans nowydh.
- **Tybya kost-effeythieth linyek orth skeul bras.** An budhekoryon es dhe dhos dhedha a vydh servys kynsa; kost ogasel dhe bub deveth a dhrik menough pan wra program ekspandya, ytho ROI an punt nessa nyns yw an keth avel ROI an punt kresek dremmys.
- **Heb spas arghans derivys.** Kevarghadow po platform na yll leverel pyth a arghansa an £X nessa na yll skoodhya klam ROI ri gwir, hepken unn a gost kresek.
