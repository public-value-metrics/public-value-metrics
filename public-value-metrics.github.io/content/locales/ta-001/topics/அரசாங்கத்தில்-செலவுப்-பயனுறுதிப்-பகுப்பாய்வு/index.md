# அரசாங்கத்தில் செலவுப் பயனுறுதிப் பகுப்பாய்வு

செலவுப் பயனுறுதிப் பகுப்பாய்வு (cost-effectiveness analysis, CEA) என்பது *ஒரே* விளைவை அடைவதற்கான மாற்று வழிகளின் செலவுகளை, இயற்கை அலகுகளில் (தெருவில் உறங்கும் ஒருவருக்கு வீடு வழங்கும் செலவு, எதிர்பார்க்கும் தரத்தை எட்டிய ஒரு மாணவருக்கான செலவு, குறைக்கப்பட்ட ஒரு டன் CO2-க்கான செலவு) விளைவையே பணமாக மாற்றாமல் ஒப்பிடுகிறது.

## ஏன் இது முக்கியம்

[சமூகச் செலவு-பலன் பகுப்பாய்வு](../சமூகச்-செலவு-பயன்-பகுப்பாய்வு/) கோரும் ஒவ்வொரு பலனையும் பணமாக்கும் தேவை கடினமாவது மட்டுமன்றி நேர்மையற்றதாகவும் ஆகும்போது (விளைவுக்கு நம்பகமான விலை நிர்ணயிக்க யாரும் உண்மையில் கொண்டிராத அனுமானங்கள் தேவைப்படும்போது) Green Book CEA-ஐ மாற்று முறையாகக் கருதுகிறது (<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>, அத்தியாயம் 5, விளைவுகளை எளிதில் பணமாக்க முடியாத இடங்களில் விருப்ப மதிப்பீடு பற்றியது). CEA என்பது சுகாதாரப் பொருளியலிலிருந்து மிக நேரடியாகக் கடன்வாங்கிய முறை. NICE சிகிச்சைகளை ஒரு தர-சரிசெய்த வாழ்வாண்டுக்கான (Quality-Adjusted Life Year) செலவு மூலம் ஒப்பிடும் முறையுடன் கட்டமைப்பில் ஒன்றானது; ஆனால் சுகாதாரமற்ற பொதுத் திட்டங்களுக்குப் பயன்படுத்தப்படுகிறது: ஒரு மாணவர்-விளைவுப்-புள்ளிக்கான கல்வித் தலையீடுகள், வீடற்ற நிலையிலிருந்து தடுக்கப்பட்ட குடும்பத்துக்கான வீட்டுத் திட்டங்கள், நிலையான வேலை விளைவுக்கான வேலைவாய்ப்புத் திட்டங்கள்.

CEA, SCBA-க்குள் அடங்கிவிடாமல் அதனுடன் தன் இடத்தைப் பெறுவதற்குக் காரணம், சில விளைவுகளுக்குப் பண மதிப்பைத் திணிப்பது அதிகாரபூர்வமாகத் தோன்றும் அளவுக்குத் துல்லியமான, ஆனால் பொது விவாதத்தில் மதிப்பற்றதாகும் அளவுக்கு மறுக்கப்படும் எண்ணை உருவாக்குகிறது என்பதே. "எதிர்பார்த்த தரத்தில் படிக்கும் ஒரு குழந்தை" என்பதற்கு விலை நிர்ணயிப்பது, தேர்வுக் குழுவில் வணிக வழக்கைத் தடம்புரளச் செய்யும் அதே வகை சவாலை அழைக்கிறது. CEA அந்த வாதத்தை நடத்த மறுப்பதன் மூலம் அதைத் தவிர்க்கிறது: *விளைவின்* ஓர் அலகுக்கான செலவின் அடிப்படையில் விருப்பங்களை வரிசைப்படுத்துகிறது; விளைவு தொடரத் தகுந்ததா என்ற தனி அரசியல் தீர்ப்பை உத்தி வழக்குக்கு விட்டுவிடுகிறது.

## கணிதம்

```
செலவுப் பயனுறுதி விகிதம் (சராசரி) = மொத்தச் செலவு / அடைந்த மொத்த விளைவு அலகுகள்

விருப்பம் A-ஐ விருப்பம் B-உடன் ஒப்பிடும் கூடுதல் செலவுப் பயனுறுதி விகிதம் (ICER):
ICER = (செலவு_A − செலவு_B) / (விளைவு_A − விளைவு_B)

நடைமுறை:
1. ஒப்பிடப்படும் எல்லா விருப்பங்களுக்கும் விளைவு அலகையும் அளவீட்டு முறையையும் நிலைநிறுத்துங்கள்.
2. ஒவ்வொரு விருப்பத்தையும் ஒரே அடிப்படையில் (../green-book-appraisal/, நிதி வழக்கு பார்க்க)
   ஒரே கால எல்லைக்கு மேல் செலவிடுங்கள்.
3. ஆதிக்கம் செலுத்தப்பட்ட விருப்பங்களை நீக்குங்கள்: ஒரே அல்லது சிறந்த விளைவை
   அடையும் மலிவான மாற்றை விட ஓர் அலகுக்கு அதிகம் செலவாகும் எந்த விருப்பமும் கைவிடப்படும்.
4. மீதமுள்ள விருப்பங்களைச் சராசரி அல்ல, கூடுதல் செலவுப் பயனுறுதி விகிதத்தால் வரிசைப்படுத்துங்கள்.
```

ஒரு திட்டத்துக்கு நிதியளிக்கத் தகுந்ததா என்பதை CEA தானாகச் சொல்ல முடியாது; ஒரே இலக்குக்கான பல அணுகுமுறைகளில் எது ஓர் அலகுக்கு மலிவு என்பதை மட்டுமே சொல்கிறது. இலக்கே செலவுக்குத் தகுந்ததா என்பதை முடிவு செய்ய, SCBA-க்குத் திரும்ப மாற்றுதல் (நம்பகமான மதிப்பீடு இருந்தால்) அல்லது கணிதத்துக்கு வெளியே ஓர் அரசியல்/உத்தித் தீர்ப்பு தேவை. ஒரு திட்டம் வெவ்வேறு விதங்களில் முக்கியமான பல விளைவுகளை உருவாக்குவதால் விளைவுகளை உண்மையிலேயே ஒரே அலகாகக் குறைக்க முடியாத இடத்தில், அதற்குப் பதிலாக [பல-அளவுகோல் முடிவுப் பகுப்பாய்வு](../பல்வகை-அளவுகோல்-முடிவுப்-பகுப்பாய்வு/) பயன்படுத்துங்கள்.

## செயல்முறை எடுத்துக்காட்டு

**உள்ளூராட்சி அமைப்பு**: ஒரு மன்றம் தெருவில் உறங்குவதைக் குறைக்கும் மூன்று அணுகுமுறைகளை ஒப்பிடுகிறது; ஒவ்வொன்றும் "6+ மாதங்கள் நிலையான தங்குமிடத்துக்கு மாற்றப்பட்ட நபர்கள்" என்ற விளைவுக்கு எதிராக ஓர் ஆண்டுக்குச் செலவிடப்பட்டவை:

```
விருப்பம்                          செலவு      அடைந்த விளைவுகள்   சராசரி CER
Housing First (தீவிரம்)             £900,000   60                  £15,000/விளைவு
விடுதி + தொடர்ந்து நகர்த்தும் ஆதரவு  £600,000   50                  £12,000/விளைவு
அணுகுமுறை + தனியார் வாடகைத் துறை   £350,000   20                  £17,500/விளைவு

ICER, விடுதி எதிர் அணுகுமுறை:  (600k−350k)/(50−20) = கூடுதல் விளைவுக்கு £8,333
ICER, Housing First எதிர் விடுதி: (900k−600k)/(60−50) = கூடுதல் விளைவுக்கு £30,000
```

சராசரிச் செலவில் அணுகுமுறை விருப்பத்தை விடுதி ஆதிக்கம் செலுத்துகிறது; ஆனால் அணுகுமுறையிலிருந்து விடுதிக்கு *கூடுதல்* படி, வீடு பெறும் கூடுதல் நபருக்கு £8,333 மட்டுமே செலவாகிறது. விடுதி அடைவதற்கு மேல் ஒவ்வொரு கூடுதல் நபருக்கும் £30,000 செலவாகும் Housing First படியுடன் ஒப்பிட இது மலிவு. வரவுசெலவுக் கட்டுப்பாடுள்ள அமைப்பு விரிவாக்கும்போது, Housing First தன் சராசரி விகிதத்தில் சிறப்பாகத் தோன்றினாலும், Housing First-க்கு முன் விடுதியை விரிவாக்க விரும்ப வேண்டும்.

**தேசிய அரசாங்கம்**: ஒரு எழுத்தறிவு மீட்புத் திட்டம் "வயதுக்கு ஏற்ற வாசிப்புத் தரத்தை எட்டும் மாணவர் ஒருவருக்கான செலவு" என்பதில் மூன்று சேவை வழங்கல் மாதிரிகளிடையே ஒப்பிடப்படுகிறது: ஒருவருக்கு-ஒருவர் பயிற்சி (மாணவருக்கு £1,800), சிறு-குழுப் பயிற்சி (மாணவருக்கு £700), டிஜிட்டல்-மட்டும் தலையீடு (மாணவருக்கு £150, ஆனால் ஈடுபாட்டு வீழ்ச்சிக்குச் சரிசெய்த பின் சேர்ந்த ஒவ்வொரு மாணவருக்கும் சிறு-குழுப் பயிற்சியின் விளைவு விகிதத்தில் 40% மட்டுமே). உண்மை நிறைவுக்குச் சரிசெய்த பின், டிஜிட்டல்-மட்டும் தரத்தை எட்டும் மாணவருக்கு £375 ஆகும்; அது இன்னும் மிக மலிவு. ஆனால் சிறு-குழுவின் அதே வரவுசெலவில் வழங்கப்பட்டால் டிஜிட்டல்-மட்டுமால் உதவப்படும் முழுமையான சிறிய மாணவர் எண்ணிக்கை, குறைவான மாணவர்களை அதிக ஆழத்தில் சென்றடைவதற்கு எதிரான ஏற்கத்தக்க பரிமாற்றமா என்பதை CEA சொல்ல முடியாது; அது CEA முடிவெடுப்பவர்களிடம் திருப்பி ஒப்படைக்கும் பங்கீட்டுத் தீர்ப்பு.

## மென்பொருள் பொறியியல் தொடர்பு

பொறியியல் குழுக்கள் *ஒரே* சேவை விளைவுக்கான சேவை வழங்கல் அணுகுமுறைகளை மதிப்பிடும் ஒவ்வொரு முறையும் CEA சரியான சட்டகம்: மூன்று அடையாளச் சரிபார்ப்பு விற்பனையாளர்களிடையே வெற்றிகரமாகச் சரிபார்க்கப்பட்ட அடையாளத்துக்கான செலவு, இரு வழக்குப் பணித் தானியக்க வடிவமைப்புகளிடையே சரியாக வகைப்படுத்தப்பட்ட வழக்குக்கான செலவு, உள்ளகத் திருத்தம் எதிர் ஒப்பந்தத் திருத்தத்தில் தீர்க்கப்பட்ட அணுகல் குறைபாட்டுக்கான செலவு. அது நேரடியாக இறக்குமதி செய்யும் ஒழுங்குமுறை: செலவுகளை ஒப்பிடும் முன் விளைவு அலகை வரையறுங்கள் ("மூடிய டிக்கெட்டுகள்" அல்ல; அது வெளியீடு. "உண்மையில் தீர்க்கப்பட்ட பயனர் தேவை"), மேலும் ஒவ்வொரு அமைப்பின் தனித்த சராசரிச் செலவை அல்ல, நடப்பு அமைப்புக்கும் முன்மொழியப்பட்ட மாற்றுக்கும் இடையிலான கூடுதல் விகிதத்தை எப்போதும் கணக்கிடுங்கள். [விளைவுகள் எதிர் வெளியீடுகள்](../விளைவுகள்-எதிர்-வெளியீடுகள்/), [விளைவு ஒன்றுக்கான செலவு](../விளைவு-ஒன்றுக்கான-செலவு/) பார்க்க.

## பொதுவான தவறுகள்

- **விரிவாக்க முடிவில் சராசரி விகிதங்களை, கூடுதல் விகிதங்களுக்குப் பதிலாக ஒப்பிடுதல்.** தெருவில் உறங்குதல் எடுத்துக்காட்டு காட்டுவது போல், சிறந்த சராசரி விகிதமுள்ள விருப்பம் வாங்க வேண்டிய அடுத்த விளைவு அலகில் எப்போதும் மலிவானது அல்ல.
- **உண்மையில் வெளியீடாக இருக்கும் விளைவு அலகைத் தேர்ந்தெடுத்தல்.** "செய்த பரிந்துரைகள்" அல்லது "வழங்கிய அமர்வுகள்" செயல்பாட்டை அளக்கின்றன, திட்டம் உருவாக்க இருக்கும் விளைவை அல்ல. வெளியீடுகள் மீதான CEA, தவறான கேள்விக்குப் பதிலளிக்கும் நம்பிக்கையான தோற்றமுள்ள எண்ணை உருவாக்குகிறது.
- **உண்மையிலேயே வெவ்வேறு விளைவுகளிடையே ஒப்பிடுதல்.** ஒவ்வொரு விருப்பமும் ஒரே விளைவை ஒரே விதமாக அளந்து இலக்கு வைக்கும்போது மட்டுமே CEA செல்லுபடியாகும். "வீடு பெற்ற தெருவில் உறங்கும் நபருக்கான செலவு" என்பதை "நிலையான குடியிருப்பில் உள்ள பராமரிப்பு-நீங்கிய இளைஞருக்கான செலவு" உடன் ஒப்பிட, CEA அல்ல, பொதுவான விளைவு அளவீடு அல்லது [பல-அளவுகோல் முடிவுப் பகுப்பாய்வு](../பல்வகை-அளவுகோல்-முடிவுப்-பகுப்பாய்வு/) தேவை.
- **விளைவின் நீடித்துழைப்பைப் புறக்கணித்தல்.** நிலைக்காத விளைவுகளை உருவாக்கும் மலிவான விருப்பம் (தலையீடு முடிந்த பிறகு பின்னடையும் மாணவர்) ஒப்பிடத்தக்க எல்லையில் அளக்கப்படும்போது உண்மையில் அதிகப் பயனுறுதி கொண்டதல்ல. ஒப்பிடப்படும் விருப்பங்களிடையே தொடர்-கண்காணிப்புக் காலத்தைப் பொருத்துங்கள்.
