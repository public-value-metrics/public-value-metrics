# பொதுத் திட்டங்களில் தாமதச் செலவு (CoD)

தாமதச் செலவு (Cost of Delay) என்பது ஒரு திட்டம், சேவை அல்லது அமைப்பு மாற்றம் இன்னும் வழங்கப்படாமல் இருக்கும் ஒவ்வொரு அலகு நேரத்திலும் இழக்கப்படும் பொது மதிப்பு. இந்தத் தலைப்புக் குழுவின் தலைமைப் பாலம் அளவீடு இது: "நேரடி இயக்கம் ஆறு மாதம் தாமதமானது" என்பதை வாரத்துக்கு பவுண்டுகளாக, அல்லது வாரத்துக்கு WELLBY-களாக மாற்றுகிறது; அதனால் தாமதத்தை வணிக வழக்கின் அதே நாணயத்தில் வாதிட முடிகிறது.

## ஏன் இது முக்கியம்

Reinertsen-இன் விதி ("ஒன்றை மட்டுமே அளவிடுவதானால், தாமதச் செலவை அளவிடுங்கள்") கிட்டத்தட்ட மாறாமல் அரசாங்கத்துக்குள் பயணிக்கிறது; ஏனெனில் பொதுத் திட்டங்கள் இதற்கு அசாதாரணமாக வெளிப்படுகின்றன. வணிக வழக்குகள் முன்கணித்த பலன் ஓடைக்கு எதிராக அங்கீகரிக்கப்படுகின்றன, ஆனால் ஓடை நேரடி இயக்கத்தில்தான் பாயத் தொடங்குகிறது; தாமதமாகும் ஒவ்வொரு வாரமும் இடர்ப் பதிவேட்டில் யாரும் விலை நிர்ணயிக்காத, இழந்த மதிப்பின் ஒரு வாரம். Universal Credit அறிமுகம் குறித்த National Audit Office-இன் மீண்டும் மீண்டும் ஆய்வு ("Rolling Out Universal Credit" அறிக்கைகள், <https://www.nao.org.uk/>) இம்முறையை விளக்குகிறது: அட்டவணைத் தாமதம் கண்காணிக்கப்பட்டு அறிக்கையிடப்பட்டது; ஆனால் சீர்திருத்தப்பட்ட அமைப்பை அடுத்த தொகுதிக் கோருநர்களுக்கு *இன்னும்* வழங்காததன் வாரத்துக்கான பவுண்டுச் செலவு முதன்மை எண்ணாக அரிதாகவே கூறப்பட்டது; முன்னுரிமையையும் மேலுயர்த்தலையும் இயக்கியிருக்க வேண்டியது அந்த எண்ணே. தாமதச் செலவு எண் இல்லாமல், தாமதமான திட்டம் சேவை வழங்கல் வாரியத்துக்கு அட்டவணைச் சிக்கலாகத் தெரிகிறது; அது இருந்தால், கணக்கு அலுவலருக்கு (accounting officer) மதிப்பு அரிப்புச் சிக்கலாகிறது.

## கணிதம்

```
CoD = வழங்கப்படாத வரை இழக்கப்படும் அலகு நேரத்துக்கான பலன்   (£/வாரம் அல்லது WELLBY/வாரம்)

மொத்தத் தாமத இழப்பு = CoD × தாமதக் காலம்

பொதுத் திட்டங்களுக்குக் கூட்ட வேண்டிய பலன் ஓடைகள்:
  பணமாக விடுவிக்கப்படும் சேமிப்புகள்  (மோசடி/பிழைக் குறைப்பு, தவிர்க்கப்பட்ட தற்காலிகச் செலவுகள்)
+ பணமற்ற விடுவிக்கப்பட்ட திறன்          (வழக்குப் பணியாளர்/அலுவலர் மணிநேரம் × முழுச் செலவேற்றிய செலவு)
+ நல்வாழ்வுப் பலன்                      (WELLBY × £13,000/WELLBY, HMT Green Book
                                           நல்வாழ்வுத் துணை வழிகாட்டுதல், 2019 விலைகள்)
```

குடிமக்களை எதிர்கொள்ளும் சேவைகளுக்குப் பணத்தோடு நல்வாழ்வையும் அலகாகக் கொள்ளுங்கள். அடிப்படை அலகுக்கு [நல்வாழ்வு-சரிசெய்த வாழ்வாண்டுகள்](../நல்வாழ்வு-சரிசெய்யப்பட்ட-வாழ்நாள்-ஆண்டுகள்/), தாமதமான பவுண்டு வேறு எதற்கு நிதியளித்திருக்கக்கூடும் என்பதற்கு [பொதுச் செலவில் வாய்ப்புச் செலவு](../பொதுச்-செலவினத்தில்-வாய்ப்புச்-செலவு/) பார்க்க.

## செயல்முறை எடுத்துக்காட்டு

**உள்ளூராட்சி அமைப்பு**: ஒரு வீட்டுவசதிப் பலன் அமைப்பின் மேம்படுத்தல், 20,000 நேரடிக் கோரிக்கைகளில் ஒரு கோரிக்கைக்கு ஆண்டுக்கு £150 அளவு அதிகப்படிக் கொடுப்பனவுப் பிழையைக் குறைக்கிறது.

```
ஆண்டுப் பலன் = 150 × 20,000 = £3,000,000/ஆண்டு
CoD = 3,000,000 / 52 ≈ £57,700/வாரம்
12 மாத நிறைவேற்றத் தாமதம் தவிர்க்கத்தக்க பிழையில் 52 × 57,700 ≈ £3,000,000 செலவாகிறது.
```

**மத்திய அரசு முகமை**: ஒரு ஊனப் பலன் மதிப்பீட்டுச் சேவை திட்டமிட்டதை விட ஆறு மாதம் (26 வாரம்) தாமதமாக வழங்கப்படுவதால், ஆண்டுக்கு 200,000 கோருநர்கள் முடிவுக்குச் சராசரியாக மூன்று வாரம் கூடுதலாகக் காத்திருக்கிறார்கள். நிதி நிச்சயமின்மையின் ஒவ்வொரு கூடுதல் வாரமும் −0.0018 WELLBY (வாழ்க்கைத் திருப்திப் புள்ளி) விளைவாக மாதிரியாக்கப்படுகிறது:

```
கோருநர் ஒருவருக்கான WELLBY இழப்பு = 3 × 0.0018 = 0.0054
ஆண்டு WELLBY இழப்பு = 200,000 × 0.0054 = 1,080 WELLBY/ஆண்டு
CoD_நல்வாழ்வு = 1,080 / 52 ≈ 20.8 WELLBY/வாரம்
CoD_பணம் = 20.8 × £13,000 ≈ £270,000/வாரம் நல்வாழ்வு மதிப்பு
```

எனவே 26-வார தாமதம் ஏறத்தாழ 540 WELLBY-களை "செலவிடுகிறது"; Green Book-இன் நல்வாழ்வு மதிப்பீட்டில் இது சுமார் £7 மில்லியன் மதிப்புடையது. தவறவிட்ட நேரடி இயக்கத் தேதியைத் திட்ட மேலாண்மையின் அடிக்குறிப்பாக அல்லாமல், குடிமக்கள் நல்வாழ்வு நிகழ்வாக மறுவடிவமைக்கிறது.

## மென்பொருள் பொறியியல் தொடர்பு

[DORA அளவீடுகள்](../பொது-மதிப்புக்கான-dora-அளவீடுகள்/), [ஓட்ட அளவீடுகள்](../அரசின்-சேவை-வழங்கலில்-பாய்வு-அளவீடுகள்/) ஆகியவற்றை நிதிரீதியாகப் புரியும்படி செய்வது தாமதச் செலவே: குழாய்வழியில் முன்னணி நேரம் × CoD என்பது குடிமகனை எட்டும் முன்பே வரிசைகளில் எரிந்துபோகும் பணம் (அல்லது நல்வாழ்வு). குறிப்பாக:

- **முன்னுரிமை**: பங்குதாரர் மூப்பைக் கொண்டு அல்ல, CoD ÷ கால அளவைக் கொண்டு பின்னடைவை வரிசைப்படுத்துங்கள். விருப்பங்களை யார் கேட்கிறார்கள் என்பதன் அடிப்படையில் அல்ல, மதிப்பின் அடிப்படையில் மதிப்பிட வேண்டும் என்ற Green Book தேவையின் மென்பொருள் பொறியியல் இணை இது.
- **கொள்முதல்**: 12–18 மாதக் கட்டமைப்புக் கொள்முதல் சுழற்சிக்கும் CoD உண்டு. அதற்கு விலை நிர்ணயிப்பது, விரைவுபடுத்தப்பட்ட வழிகளுக்கான அவசர வழக்கை மாற்றுகிறது; மதிப்பை அடையும் நேரம் முடிவு இயக்கியாக உள்ள [உருவாக்கல் எதிர் வாங்கல்](../அரசாங்கத்தில்-உருவாக்கலா-வாங்கலா/) முடிவுகளுக்கு நேரடியாக உணவளிக்கிறது.
- **பலன் வழக்கு**: ஒப்புதலில் மேற்கோள் காட்டப்படும் ஒவ்வொரு CoD எண்ணும் [பலன்களை நனவாக்கல்](../பலன்களை-நனவாக்கல்/) கட்டத்தில் மீண்டும் தோன்ற வேண்டும். தாமதச் செலவு உண்மையானதாக இருந்தால், விரைவுபடுத்தப்பட்ட பலன் நேரடி இயக்கத்துக்குப் பின் அளக்கத்தக்கதாக இருக்க வேண்டும்.

## பொதுவான தவறுகள்

- **CoD நேர்கோட்டுத் தன்மை கொண்டது எனக் கருதுதல்**: சில பொதுச் சேவைகளுக்கு மென்மையான வாராந்திர விகிதத்துக்குப் பதிலாக, இறுதிநாள்-வடிவ மதிப்பு உண்டு (சட்டப்படியான இணக்கத் தேதி; தேதிக்குப் பின் CoD அமலாக்க-இடர் நிலைகளுக்குத் தாவும், முன்பு பூஜ்யத்துக்கு அருகில்). பெருக்கும் முன் அவசர வடிவை வகைப்படுத்துங்கள்.
- **யாருக்கும் தேவையில்லாத வெளியீடுகளுக்கு CoD**: வழங்கப்படாத பொருளுக்கு மதிப்பு இருந்தால் மட்டுமே தாமதத்துக்குச் செலவு உண்டு. யாரும் பயன்படுத்தாத அமைப்புக்கு எவ்வளவு தாமதமானாலும் CoD பூஜ்யம்.
- **தாமதத்தையும் கழிவையும் இரட்டை எண்ணுதல்**: பல ஆண்டு மதிப்பீட்டு எல்லைகளில் [சமூகக் கழிவு விகிதம்](../சமூகத்-தள்ளுபடி-விகிதம்/) ஏற்கெனவே நேரத்துக்கு விலை நிர்ணயிக்கிறது; வாரங்கள், மாதங்களுக்கான எல்லைக்குள் செயல்பாட்டு வடிவம் CoD. அட்டவணைத் தாமதத்துக்கு CoD-ஐயும், பல ஆண்டு மறுகட்டத்துக்கு NPV மாற்றத்தையும் பயன்படுத்துங்கள்.
