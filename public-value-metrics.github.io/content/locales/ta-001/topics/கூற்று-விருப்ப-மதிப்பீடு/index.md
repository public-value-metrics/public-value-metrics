# கூற்று விருப்ப மதிப்பீடு

கூற்று விருப்ப (stated preference) முறைகள், சந்தை சாராத ஒரு பண்டத்துக்கு மக்கள் செலுத்த விரும்பும் தொகையை, அல்லது அதை விட்டுக்கொடுக்க இழப்பீடாக ஏற்கத் தயாராக உள்ள தொகையை, நேரடியாகக் கேட்பதன் மூலம் அதன் மதிப்பை மதிப்பிடுகின்றன. இது பொதுவாகக் கற்பனைச் சூழலை விவரிக்கும் கட்டமைக்கப்பட்ட கணக்கெடுப்பு மூலம் நடக்கிறது. நிபந்தனை மதிப்பீடு (contingent valuation) இந்தக் குடும்பத்தில் மிகவும் அறியப்பட்ட நுட்பம்.

## ஏன் இது முக்கியம்

Green Book Annex 2 (சந்தை சாராத தாக்கங்களை மதிப்பிடுவது குறித்த துணை வழிகாட்டுதல்) மதிப்பை ஊகிக்கக் கவனிக்கத்தக்க சந்தைப் பரிவர்த்தனையே இல்லாத பண்டங்களுக்குக் கூற்று விருப்ப முறைகளை ஆதரிக்கிறது: காற்றின் தரம், பல்லுயிர், வெள்ளப் பாதுகாப்பு, ஒருவர் ஒருபோதும் பார்க்காமலிருக்கக்கூடிய நிலப்பரப்பின் இருப்பு மதிப்பு
(<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>).
சுற்றுச்சூழல் மதிப்பின் பெரும்பகுதிக்கு (வாழிடப் பாதுகாப்பு, நீரின் தரம்) எந்தப் பதிலிச் சந்தையும் இல்லை என்பதால் Defra, சுற்றுச்சூழல் மதிப்பீட்டுக்குத் தனது சொந்தக் கூற்று விருப்ப வழிகாட்டுதலை வெளியிட்டுள்ளது. எடுத்துக்காட்டாக ஒலி மாசு, குறைந்தபட்சம் கவனிக்கத்தக்க வீட்டு விலைகளுடன் தொடர்புடையது ([வெளிப்பாட்டு விருப்ப மதிப்பீடு](../வெளிப்படுத்தப்பட்ட-விருப்ப-மதிப்பீடு/) பார்க்க).

கூற்று விருப்பத்தின் மைய ஈர்ப்பு (எவரும் பரிவர்த்தனை செய்யாத பண்டங்கள் உட்பட, எதையும் மதிப்பிட முடியும்) அதன் நம்பகத்தன்மைச் சிக்கலின் மூலமாகவும் உள்ளது. பதிலளிப்போர் உண்மையில் பணம் செலவிடுவதில்லை என்பதால், நிபந்தனை மதிப்பீட்டுக் கணக்கெடுப்புகள் கற்பனைச் சார்புக்கு (உண்மையான வரவு-செலவுக் கட்டுப்பாடு இல்லாதபோது மக்கள் செலுத்த விரும்பும் தொகையை மிகைப்படுத்துவது), உட்பொதிவு விளைவுகளுக்கு (கணக்கெடுப்பில் வேறு என்ன உள்ளது என்பதைப் பொறுத்து அதே பண்டம் வேறுபட்டு மதிப்பிடப்படுவது), ஏலமிடும் விளையாட்டு வடிவமைப்பில் தொடக்கப்புள்ளிச் சார்புக்கு ஆளாகின்றன. Exxon Valdez எண்ணெய்க் கசிவு வழக்கைத் தொடர்ந்து கூட்டப்பட்ட 1993 NOAA நிபந்தனை மதிப்பீட்டுக் குழு, திறந்தமுடிவு ஏலமிடலுக்குப் பதிலாக "£X செலுத்துவீர்களா, ஆம்/இல்லை" என்ற இருமநிலை வாக்கெடுப்பு வடிவமும், பதிலளிப்பவரின் உண்மையான வரவு-செலவுக் கட்டுப்பாடு பற்றிய கட்டாய நினைவூட்டல்களும் என்ற வடிவமைப்புத் தரநிலைகளை வகுத்தது. அவை நியாயப்படுத்தத்தக்க கணக்கெடுப்புகளுக்கு இன்றும் குறிப்புத் தரநிலையாக உள்ளன.

## கணிதம்

```
நிபந்தனை மதிப்பீடு (வாக்கெடுப்பு வடிவம்):
  இருமநிலைத் தேர்வை முன்வையுங்கள்: "விளைவு Y-க்காக ஆண்டுக்கு £X செலுத்துவீர்களா? ஆம்/இல்லை"
  பதிலளிப்போரிடையே X-ஐ சீரற்ற முறையில் மாற்றுங்கள்.
  ஒவ்வொரு X-இலும் ஆம்/இல்லை பதில் விகிதத்தின் சார்பாக, செலுத்த விருப்பத்தொகையைப் பொருத்துங்கள்.

சராசரி WTP = மதிப்பிடப்பட்ட தேவை வளைவின் கீழுள்ள பரப்பு
மொத்த மதிப்பு = சராசரி WTP × பாதிக்கப்படும் மக்கள்தொகை

தேர்வுப் பரிசோதனை (தனித்த தேர்வு மாதிரியாக்கம்) மாறுபாடு:
  பதிலளிப்போருக்குப் பண்புக்கூறுத் தொகுப்புகளுக்கிடையே (செலவுப் பண்புக்கூறு
  உட்பட) மீண்டும் மீண்டும் தேர்வுகளை முன்வையுங்கள்; பதிலளிப்போர்
  வெளிப்படுத்தும் பரிமாற்றங்களிலிருந்து ஒவ்வொரு செலவற்ற பண்புக்கூறுக்கும்
  உள்ளார்ந்த விலைகளை மதிப்பிடுங்கள்.
```

தற்போதைய இங்கிலாந்து நடைமுறையில் ஒற்றைக் கேள்வி நிபந்தனை மதிப்பீட்டை விடத் தேர்வுப் பரிசோதனை மாறுபாடே பொதுவாக விரும்பப்படுகிறது. ஏனெனில் பதிலளிப்போர் பல பண்புக்கூறுகளைச் செலவுடன் மீண்டும் மீண்டும் பரிமாறிக்கொள்ளுமாறு கட்டாயப்படுத்துவது, ஒற்றை ஆம்/இல்லை கேள்வியை விட உள் முரண்பாடு குறைந்த, ஏமாற்றுவதற்குக் கடினமான மதிப்பீடுகளைத் தருகிறது.

## செயல்முறை எடுத்துக்காட்டு

**தேசிய அரசு**: ஆற்று நீர்த் தர மேம்பாட்டுத் திட்டத்தை மதிப்பிட Defra ஒரு நிபந்தனை மதிப்பீட்டுக் கணக்கெடுப்பை ஆணையிடுகிறது. 2,000 குடும்பங்களிடம் நடந்த வாக்கெடுப்பு வடிவக் கணக்கெடுப்பில், கற்பனை நீர்க் கட்டணக் கூடுதலாக ஆண்டுக்கு £40 செலுத்த 62% பேர் தயாராக உள்ளனர் எனத் தெரிகிறது; மதிப்பிடப்பட்ட தேவை வளைவு குடும்பத்துக்கு ஆண்டுக்கு £28 என்ற சராசரி செலுத்த விருப்பத்தொகையைத் தருகிறது.

```
சராசரி WTP = £28/குடும்பம்/ஆண்டு
நீர்ப்பிடிப்புப் பகுதிக் குடும்பங்கள் = 340,000
மொத்த ஆண்டு மதிப்பு = £28 × 340,000 = £9.52m/ஆண்டு

3.5% தள்ளுபடி விகிதத்தில் 20 ஆண்டு மதிப்பீட்டுக் காலத்துக்கு (ஆண்டுத்தொகைக் காரணி ≈ 14.2):
PV(பயன்) ≈ £9.52m × 14.2 ≈ £135m
```

இந்த மொத்த எண் பின்னர் திட்டத்தின் [சமூகச் செலவு-பயன் பகுப்பாய்வின்](../சமூகச்-செலவு-பயன்-பகுப்பாய்வு/) செலவுப் பக்கத்துடன் ஒப்பிடப்படுகிறது. இத்தகைய கூற்று விருப்பச் சான்றை வெறும் புள்ளி மதிப்பீடாக அல்லாமல், அதன் நம்பிக்கை இடைவெளி, கணக்கெடுப்பு முறையுடன் சேர்த்து அறிக்கையிடுமாறு Green Book கோருகிறது; ஏனெனில் அடிப்படை எண் சந்தை விலையை விட நொய்மையானது.

**அறக்கட்டளை**: ஒரு பாரம்பரிய அறக்கட்டளை, இரு தரப்பும் அவசியம் பார்வையிடாத ஒரு வரலாற்றுக் கட்டிடத்தின் மூடலைத் தடுக்கச் செலுத்த விருப்பத்தொகை குறித்துப் பார்வையாளர்களிடமும் பார்வையாளர் அல்லாதவர்களிடமும் கணக்கெடுக்கிறது (அதன் இருப்பு மதிப்பு). அக்கட்டிடத்தை ஒருபோதும் காணப்போகாத பார்வையாளர் அல்லாதவர்களும் நேர்மறை WTP தெரிவிப்பதால், பார்வையாளர் கட்டண வருவாய் எண்ணிக்கை (வெளிப்பாட்டு விருப்பப் பதிலி) முழுவதுமாகத் தவறவிடும் இருப்பு, மரபுரிமை மதிப்பைக் கணக்கெடுப்பு பதிவுசெய்கிறது. மதிப்பை வெளிப்படுத்த எந்த வகைச் சந்தைப் பரிவர்த்தனையும் இல்லாத இடத்தில் கூற்று விருப்பத்தின் உண்மையான நன்மையை இது காட்டுகிறது.

## மென்பொருள் பொறியியல் தொடர்பு

கூற்று விருப்ப முறைகள் மென்பொருள் பொறியியல் பணிக்கு நேரடியாகப் பொருந்துவது அரிது. ஆனால் குடிமக்கள் ஆலோசனைத் தளங்கள், வரவு-செலவுத் திட்டப் பங்கேற்புக் கருவிகள் அல்லது பொதுக் கணக்கெடுப்பு அடிப்படைக் கட்டமைப்பை உருவாக்கும் பொறியாளர்கள், பொருளியல் சார்ந்திருக்கும் கருவியையே அடிக்கடி உருவாக்குகிறார்கள். கணக்கெடுப்பு வடிவமைப்பு விவரங்களைச் சரியாகப் பெறுவது (சீரற்ற ஏலத் தொகைகள், திறந்தமுடிவுக் கேள்விகளுக்குப் பதிலாக இருமநிலை வாக்கெடுப்புச் சட்டகம், வெளிப்படையான வரவு-செலவுக் கட்டுப்பாட்டு நினைவூட்டல்கள்) பயனர் அனுபவ நளினம் அல்ல; அது விளைவான மதிப்பீட்டை ஆய்வின் கீழ் நியாயப்படுத்தத்தக்கதாக்குகிறது. மோசமாக வடிவமைக்கப்பட்ட செயலிக்குள் கணக்கெடுப்பு, பின்னர் வரும் பல மாதப் பொருளாதாரப் பகுப்பாய்வையே செல்லாததாக்கிவிடலாம். பகுப்பாய்வு எடையைத் தாங்கும் பொதுக் கருத்துத் தரவைப் பெறுவதற்கான பொதுவான ஒழுங்குக்கு [குடிமக்கள் திருப்தி அளவீடுகள்](../குடிமக்கள்-திருப்தி-அளவீடுகள்/) பார்க்க.

## பொதுவான தவறுகள்

- **திறந்தமுடிவு "எவ்வளவு செலுத்துவீர்கள்?" கேள்விகள்.** இவை இருமநிலை வாக்கெடுப்புச் சட்டகத்தை விட உத்திசார், நங்கூரச் சார்புக்கு மிகவும் ஆளாகும். திறந்தமுடிவு வெளிக்கொணர்தல் மோசமாகச் செயல்படுவதால்தான் NOAA குழு வாக்கெடுப்பு வடிவத்தைப் பரிந்துரைத்தது.
- **பதிலளிப்பவரின் உண்மையான வரவு-செலவுக் கட்டுப்பாடு பற்றிய நினைவூட்டல் இல்லாமை.** அது இல்லாவிட்டால், உண்மையான வரவு-செலவுப் பரிமாற்றம் நடக்கும்போது அதே மக்கள் செலுத்தும் தொகையை விடக் கூறப்பட்ட WTP வழக்கமாக அதிகமாக இருக்கும். இதுவே கற்பனைச் சார்பு.
- **உட்பொதிவு விளைவுகளைப் புறக்கணித்தல்.** அதே பண்டம் தனியாக மதிப்பிடப்படுவதற்கும் பெரிய தொகுப்பின் பகுதியாக மதிப்பிடப்படுவதற்கும் இடையே WTP மதிப்பீடுகள் வேறுபடும்; கணக்கெடுப்புச் சட்டகத்தில் வேறு எதாவது இருந்தால் அதைத் தெரிவியுங்கள்.
- **ஒற்றைக் கணக்கெடுப்பின் புள்ளி மதிப்பீட்டை இறுதியானது எனக் கருதுதல்.** Green Book நடைமுறை ஒரு வரம்பையும் அறியப்பட்ட சார்புகள் பற்றிய விவாதத்தையும் எதிர்பார்க்கிறது; சந்தை விலையைப் போல் செலவு-பயன் அட்டவணைக்குள் முன்னெடுத்துச் செல்லப்படும் வெற்று எண்ணை அல்ல.
