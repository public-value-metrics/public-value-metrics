# குடிமக்கள் திருப்தி அளவீடுகள்

குடிமக்கள் திருப்தி அளவீடுகள், ஒரு பொதுச் சேவையின் நேரடி அனுபவத்தை மக்கள் எப்படி மதிப்பிடுகிறார்கள் என்பதை அளக்கின்றன. இது பொதுவாக நிறுவனங்கள் மீதான நம்பிக்கையிலிருந்தும், சேவை உண்மையில் நல்ல விளைவை அடைந்ததா என்பதிலிருந்தும் வேறுபட்டது. ஒரு சேவை நன்கு விரும்பப்பட்டும் பயனற்றதாக இருக்கலாம்; அல்லது பயனுள்ளதாகவும் விரும்பப்படாததாகவும் இருக்கலாம். இவ்விரண்டுக்கும் இடையிலான இடைவெளியே ஒரு சேவை வழங்கல் குழு கவனிக்க வேண்டிய அறிகுறித் தகவல்.

## ஏன் இது முக்கியம்

திருப்தி இரு வெவ்வேறு உயரங்களில் அளக்கப்படுகிறது; அவை வழக்கமாகக் குழப்பப்படுகின்றன. சேவை மட்டத்தில், இங்கிலாந்தின் தற்போது ஓய்வுபெற்ற Performance Platform-உம் இன்றைய GOV.UK சேவை கையேடும் நான்கு கட்டாயச் சேவை KPI-களில் ஒன்றாக, ஒவ்வொரு சேவைக்குமான திருப்தி கருத்துக்கணிப்பைக் (பொதுவாக "மிகவும் திருப்தி" முதல் "மிகவும் அதிருப்தி" வரை ஐந்து புள்ளி அளவு, பரிவர்த்தனை நேரத்தில் நிர்வகிக்கப்படுவது) கோருகின்றன ([சேவைத் தரநிலைகளும் பரிவர்த்தனை அளவீடுகளும்](../சேவைத்-தரநிலைகளும்-பரிவர்த்தனை-அளவீடுகளும்/) பார்க்க). நிறுவன மட்டத்தில், இங்கிலாந்தின் குடிமைப்பணி மக்கள் கருத்துக்கணிப்பு (Civil Service People Survey) ஒவ்வொரு மத்திய அரசுத் துறையிலும் ஆண்டுதோறும் ஊழியர் ஈடுபாட்டையும் அனுபவத்தையும் அளக்கிறது. தனியாக, OECD-இன் "Trust in Government" திட்டம் உறுப்பு நாடுகளில் தேசிய அரசாங்கத்தின் மீதான பொது நம்பிக்கையைக் கருத்துக்கணிப்பு செய்து, நெருக்கடிகளால் பெரிதும் வடிவமைக்கப்பட்ட நீண்டகால வீழ்ச்சி-மீட்பு முறையைக் கண்காணிக்கிறது (2008 நிதி நெருக்கடியும் கோவிட்-19 பெருந்தொற்றும் OECD நம்பிக்கை எண்களில் கூர்மையான, தெரியும் நகர்வுகளை உருவாக்கின). குடிமக்களை எதிர்கொள்ளும் சேவைகளை உருவாக்கும் பொறியாளர்கள் திருப்தியையும் விளைவையும் தனியே வைத்திருக்க வேண்டிய காரணம், சேவை வடிவமைப்பின் அறியப்பட்ட தோல்வி முறை: பலன் கோரிக்கைக்கான அழகாக வடிவமைக்கப்பட்ட, பயன்படுத்த எளிதான டிஜிட்டல் படிவம் மிக உயர்ந்த திருப்தி மதிப்பெண்ணைப் பெறலாம்; ஆனால் அடிப்படைக் கொள்கை (தகுதி விதிகள், செயலாக்கத் தேக்கங்கள், வழங்கல் தொகைகள்) கோருபவரை முன்பை விட நல்ல நிலையில் வைக்காமல் போகலாம். திருப்தி இடைமுகத்தை அளக்கிறது; அதன் பின்னால் வழங்கப்படும் மதிப்பை அளப்பதில்லை.

## கணிதம்

```
நிகரத் திருப்தி = % திருப்தி (அல்லது மிகவும் திருப்தி) − % அதிருப்தி (அல்லது மிகவும் அதிருப்தி)
                    (நடுநிலை/கருத்தில்லை பதில்கள் இரு உறுப்புகளிலிருந்தும் விலக்கப்படும்,
                    ஆனால் ஒவ்வொரு சதவீதத்தையும் கணக்கிடும் பதிலளிப்போர் அடிப்படையில்
                    எண்ணப்படும்)

திருப்தி-விளைவு இடைவெளி = திருப்தி மதிப்பெண் − விளைவு அடைவு மதிப்பெண்
                    (இரண்டும் 0–100 ஆக இயல்பாக்கப்பட்டவை; பெரிய நேர்மறை இடைவெளி
                    "நன்றாக உணர வைக்கும்" ஆனால் சாரத்தில் குறைவாக வழங்கும்
                    சேவையைக் குறிக்கிறது)

நம்பிக்கைக் குறியீடு (OECD-பாணி) = "[தேசிய அரசாங்கத்தின் மீது] உங்களுக்கு
                    நம்பிக்கை உள்ளதா?" என்பதற்கு "ஆம்" என்று பதிலளிக்கும்
                    கருத்துக்கணிப்புப் பதிலளிப்போரின் %
                    காலத் தொடராகக் கண்காணிக்கப்படுகிறது, பொதுவாக வயது,
                    வருமானம், கல்வி வாரியாகப் பிரிக்கப்படுகிறது
```

## செயல்முறை எடுத்துக்காட்டு

**உள்ளூராட்சி மன்ற வரி மின்-பட்டியல் சேவை**: வெற்றிகரமான பரிவர்த்தனை நேரத்தில் நடத்திய திருப்தி கருத்துக்கணிப்பில் 2,400 பதிலளிப்போர்: 1,650 பேர் திருப்தி/மிகவும் திருப்தி, 250 பேர் அதிருப்தி/மிகவும் அதிருப்தி, 500 பேர் நடுநிலை.

```
நிகரத் திருப்தி = (1,650/2,400 × 100) − (250/2,400 × 100)
                  = 68.75% − 10.42%
                  = +58.3 நிகரத் திருப்தி
```

தனியாகப் பார்த்தால் இது வலுவாகத் தெரிகிறது. ஆனால் கருத்துக்கணிப்பு பரிவர்த்தனையை *வெற்றிகரமாக* முடிக்கும் பயனர்களுக்கு மட்டுமே காட்டப்படுகிறது; இது அறியப்பட்ட அளவீட்டுச் சார்பு (கீழுள்ள தவறுகள் பார்க்க). [சேவைத் தரநிலைகளும் பரிவர்த்தனை அளவீடுகளும்](../சேவைத்-தரநிலைகளும்-பரிவர்த்தனை-அளவீடுகளும்/) தலைப்பிலிருந்து நிறைவு விகித அளவீட்டுடன் இணைத்தால் நிறைவு 71% மட்டுமே எனத் தெரிகிறது; அதன் பொருள்:

```
பயணத்தைக் கைவிட்ட 29% பேருக்கு உண்மையான மக்கள்தொகைத் திருப்தி
அளக்கப்படவில்லை — கைவிடுதலே கருத்துக்கணிப்பு ஒருபோதும் பதிவுசெய்யாத
வலுவான எதிர்மறைச் சமிக்ஞை என்பதால், இவர்களே மிகவும் அதிருப்தியுற்ற
குழுவாக இருக்கலாம்.
```

**தேசிய மட்ட விளக்கம் (OECD-பாணி நம்பிக்கைத் தொடரின் கட்டமைப்பு)**: தேசிய அரசாங்க நம்பிக்கை 1-ஆம் ஆண்டில் 42% எனப் பதிவாகி, 2-ஆம் ஆண்டில் (நெருக்கடி ஆண்டு) 34% ஆகக் குறைந்து, 3-ஆம் ஆண்டில் 39% ஆக மீள்கிறது. பெரிய நெருக்கடிகளுக்குப் பிறகு உறுப்பு நாடுகளில் OECD பதிவுசெய்யும் அதிர்ச்சி-பகுதி மீட்பு முறையின் வழக்கமான பாதை இது.

## மென்பொருள் பொறியியல் தொடர்பு

பயனர் பயணத்தின் ஒவ்வொரு அர்த்தமுள்ள வெளியேறு புள்ளியிலும் திருப்தி கருத்துக்கணிப்புகளைக் கருவியமையுங்கள்; வெற்றிகரமான நிறைவில் மட்டும் அல்ல. இந்தத் துறையில் இதுவே மிகப் பொதுவான பொறியியல் தவறு; அது திருப்தி அளவீட்டை அமைதியாக, தப்பிப்பிழைத்தோர் சார்புள்ள வெற்று அளவீடாக மாற்றுகிறது. முடிந்தவரை திருப்தி மதிப்பெண்ணை அதே டாஷ்போர்டில் நிறைவு அல்லது விளைவு அளவீட்டுடன் இணையுங்கள்; அப்போது நிறைவு அமைதியாகக் குறையும்போது குழு உயரும் திருப்தியைக் கொண்டாட முடியாது ([பரிவர்த்தனைக்கான செலவு](../பரிவர்த்தனை-ஒன்றுக்கான-செலவு/), மற்றும் டிஜிட்டல் திருப்தி மாதிரியெடுப்பிலிருந்தே யார் விலக்கப்படுகிறார்கள் என்பதற்கு [டிஜிட்டல் உள்ளடக்கப்படுத்தல்](../டிஜிட்டல்-உள்ளடக்கப்படுத்தல்/) பார்க்க; டிஜிட்டல் அல்லாத, உதவியுடன்-டிஜிட்டல் பயனர்கள் சேவைக்குள் நடக்கும் கருத்துக்கணிப்புகளில் முறைப்படி குறைவாகப் பிரதிநிதித்துவம் பெறுகிறார்கள்). திருப்தி, நம்பிக்கைத் தரவும் [மூர்-இன் உத்தி முக்கோணத்தின்](../பொது-மதிப்பு/) சட்டபூர்வத்தன்மைக் காலுக்கு நேரடியாக உணவளிக்கின்றன; [பொது மதிப்பு மதிப்பெண் அட்டை](../பொது-மதிப்பு-மதிப்பெண்-அட்டை/) இன் "வாடிக்கையாளர்", "சட்டபூர்வத்தன்மை" கண்ணோட்டங்களில் இடம்பெற வேண்டும். இந்தச் சேவை-மட்ட அளவீட்டின் நிறுவன-மட்ட இணைக்கு [நம்பிக்கை, சட்டபூர்வத்தன்மை அளவீடுகள்](../நம்பிக்கை-சட்டபூர்வத்தன்மை-அளவீடுகள்/) பார்க்க.

## பொதுவான தவறுகள்

- **நிறைவு-புள்ளிக் கருத்துக்கணிப்புகளில் தப்பிப்பிழைத்தோர் சார்பு**: பயணத்தைக் கைவிடும் பயனர்கள் கருத்துக்கணிப்பைப் பார்ப்பதே இல்லை. எனவே உயர் சேவைக்குள் திருப்தி மதிப்பெண், குறைந்த நிறைவு விகிதத்துடனும், அதிருப்தியுற்ற, நிறைவு செய்யாதோரின் பெரிய கண்ணுக்குத் தெரியாத மக்கள்தொகையுடனும் இணைந்து இருக்கலாம்.
- **திருப்தியை விளைவின் பதிலியாகக் கருதுதல்**: மோசமாக வடிவமைக்கப்பட்ட கொள்கைக்கு நன்கு வடிவமைக்கப்பட்ட இடைமுகம் திருப்தியில் நன்றாகவும் விளைவில் மோசமாகவும் மதிப்பெண் பெறும். எப்போதும் இரண்டையும் அறிக்கையிடுங்கள், ஒன்றை மற்றொன்றுக்கு மாற்றாக ஒருபோதும் வைக்காதீர்கள்.
- **சிறிய, பிரதிநிதித்துவமற்ற மாதிரிகளைப் பொய்த் துல்லியத்துடன் அறிக்கையிடுதல்**: தாமாகத் தேர்ந்தெடுத்த சில நூறு பதிலளிப்போரிடமிருந்து பெறப்பட்ட திருப்தி மதிப்பெண்ணை ஒரு தசம இடம் வரை அறிக்கையிடுவது, மாதிரி அளவு தாங்க முடியாத நம்பிக்கையைக் குறிக்கிறது.
- **மக்கள்தொகைப் பிரிப்பைப் புறக்கணித்தல்**: வயது, வருமானம், ஊனம், டிஜிட்டல் அணுகல் வாரியாகப் பிரிக்கப்படாத தேசிய நம்பிக்கை, திருப்தி எண்கள் குழுக்களிடையே கூர்மையாக வேறுபடும் அனுபவங்களை மறைக்கக்கூடும். OECD-இன் சொந்த Trust in Government வெளியீடுகள் வெளிப்படையாகப் பிரிக்கும் முறை இது.
