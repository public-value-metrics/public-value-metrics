# Public Value Metrics

Complete introduction to public value maths, examples and reasoning, wey dem write for software engineers wey dey build for government and social sector organizations for everywhere for di world. Each file dey cover one metric or concept: di definition, why e matter, di maths, one worked example, how e connect to software engineering, di wahala dem wey you suppose avoid, and sources.

You new here? Start with [public value](locales/pcm-001/topics/public-value-wetin-government-and-social-organizations-really-create-for-citizens/), [value for money](locales/pcm-001/topics/value-for-money-di-test-whether-public-spending-dey-worth-am/) and [theory of change](locales/pcm-001/topics/theory-of-change-how-to-map-di-road-from-activities-go-long-term-goal/) — di three ideas wey everything else dey stand on.
