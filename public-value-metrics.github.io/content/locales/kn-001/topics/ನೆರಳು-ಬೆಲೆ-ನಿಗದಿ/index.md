# ನೆರಳು ಬೆಲೆ ನಿಗದಿ

ನೆರಳು ಬೆಲೆ (shadow price) ಎಂದರೆ ಗಮನಿಸಬಹುದಾದ ಮಾರುಕಟ್ಟೆ ಬೆಲೆ ಇಲ್ಲದ, ಅಥವಾ ಮಾರುಕಟ್ಟೆ ಬೆಲೆ ವಿರೂಪಗೊಂಡು ನಿಜವಾದ ಸಾಮಾಜಿಕ ಮೌಲ್ಯವನ್ನು ಪ್ರತಿಬಿಂಬಿಸದ ಸರಕು, ಸಂಪನ್ಮೂಲ ಅಥವಾ ಬಾಹ್ಯ ಪರಿಣಾಮಕ್ಕೆ ನೀಡುವ ಅಂದಾಜು ಮೌಲ್ಯ. ಸರ್ಕಾರಿ ಮೌಲ್ಯಮಾಪನವು ಇಂಗಾಲ, ಕೆಲಸೇತರ ಸಮಯ, ನಿರುದ್ಯೋಗಿ ಶ್ರಮ ಇವುಗಳ ಒಂದು ಸಣ್ಣ ಅಧಿಕೃತ ನೆರಳು ಬೆಲೆಗಳ ಗುಚ್ಛವನ್ನು ಅವಲಂಬಿಸಿದೆ. ಇವನ್ನು ಕೇಂದ್ರೀಯವಾಗಿ ಪ್ರಕಟಿಸಲಾಗುತ್ತದೆ, ಆದ್ದರಿಂದ ಪ್ರತಿ ಇಲಾಖೆಯೂ ಒಂದೇ ಸಂಖ್ಯೆಯನ್ನು ಬಳಸುತ್ತದೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ನೆರಳು ಬೆಲೆಗಳು ಅಸ್ತಿತ್ವದಲ್ಲಿರಲು ಕಾರಣ, [ಸಾಮಾಜಿಕ ವೆಚ್ಚ-ಲಾಭ ವಿಶ್ಲೇಷಣೆ](../ಸಾಮಾಜಿಕ-ವೆಚ್ಚ-ಲಾಭ-ವಿಶ್ಲೇಷಣೆ/)ಯು ಪ್ರತಿ ವೆಚ್ಚ ಮತ್ತು ಲಾಭಕ್ಕೆ ಹಣಕಾಸಿನ ಮೌಲ್ಯವಿಲ್ಲದೆ ಕೆಲಸ ಮಾಡಲಾರದು. ಆದರೆ ಅತ್ಯಂತ ಪರಿಣಾಮಕಾರಿಯಾದ ಹಲವು ಅಂಶಗಳಿಗೆ — ಹೊರಸೂಸಿದ ಒಂದು ಟನ್ ಇಂಗಾಲ, ಪ್ರಯಾಣಿಕರ ಒಂದು ಗಂಟೆಯ ಸಮಯ, ಇಲ್ಲದಿದ್ದರೆ ನಿರುದ್ಯೋಗಿಯಾಗಿರುತ್ತಿದ್ದ ಶ್ರಮದ ಒಂದು ಗಂಟೆ — ಮಾರುಕಟ್ಟೆ ಬೆಲೆಯೇ ಇಲ್ಲ, ಅಥವಾ ಇರುವ ಮಾರುಕಟ್ಟೆ ಬೆಲೆ ಅವುಗಳ ನಿಜವಾದ ಸಾಮಾಜಿಕ ವೆಚ್ಚವನ್ನು ತಪ್ಪಾಗಿ ಬಿಂಬಿಸುತ್ತದೆ. HM Treasury (ಬ್ರಿಟನ್ ಹಣಕಾಸು ಇಲಾಖೆ) ಮತ್ತು ಇಂಧನ ಭದ್ರತೆ ಮತ್ತು ನಿವ್ವಳ ಶೂನ್ಯ ಇಲಾಖೆ (Department for Energy Security and Net Zero) ಜಂಟಿಯಾಗಿ ಬ್ರಿಟನ್ನಿನ ಎಲ್ಲ ಸರ್ಕಾರಿ ಮೌಲ್ಯಮಾಪನಗಳಲ್ಲಿ ಬಳಸುವ ಇಂಗಾಲದ ನೆರಳು ಬೆಲೆಯನ್ನು ಪ್ರಕಟಿಸುತ್ತವೆ
(<https://www.gov.uk/government/publications/valuing-greenhouse-gas-emissions-in-policy-appraisal>).
ಇದನ್ನು ಯಾವುದೇ ಇಂಗಾಲ ಮಾರುಕಟ್ಟೆಯ ಬೆಲೆಯಿಂದ ಪಡೆಯುವುದಿಲ್ಲ; ಬದಲಿಗೆ ಗುರಿ-ಸಂಗತ ವಿಧಾನದಿಂದ ಪಡೆಯಲಾಗುತ್ತದೆ: ಇಂಗಾಲದ ಮೌಲ್ಯವನ್ನು ಬ್ರಿಟನ್ನಿನ ಕಾನೂನುಬದ್ಧ ಇಂಗಾಲ ಬಜೆಟ್‌ಗಳನ್ನು ತಲುಪಲು ಬೇಕಾದ ಕನಿಷ್ಠಾಂತರ ಹೊರಸೂಸುವಿಕೆ ತಗ್ಗಿಸುವ ವೆಚ್ಚದಲ್ಲಿ ನಿಗದಿಪಡಿಸಲಾಗುತ್ತದೆ. ಇದು EU ಅಥವಾ ಬ್ರಿಟನ್ನಿನ ಹೊರಸೂಸುವಿಕೆ ವ್ಯಾಪಾರ ಯೋಜನೆಯಲ್ಲಿ (Emissions Trading Scheme) ಇಂಗಾಲ ನಿಜವಾಗಿ ಯಾವ ಬೆಲೆಗೆ ವಹಿವಾಟಾಗುತ್ತದೆ ಎಂದು ಗಮನಿಸುವುದಕ್ಕಿಂತ ಮೂಲಭೂತವಾಗಿ ಭಿನ್ನವಾದ ತರ್ಕ.

ನೆರಳು ವೇತನ ದರವು ಶ್ರಮದ ಕಡೆ ಇದೇ ತರ್ಕವನ್ನು ಅನುಸರಿಸುತ್ತದೆ. ಇಲ್ಲದಿದ್ದರೆ ನಿರುದ್ಯೋಗಿಯಾಗಿರುತ್ತಿದ್ದ ವ್ಯಕ್ತಿಗೆ ಉದ್ಯೋಗ ನೀಡಿದರೆ ಸಮಾಜಕ್ಕೆ ಅವರ ಪೂರ್ಣ ವೇತನದಷ್ಟು ವೆಚ್ಚವಾಗುವುದಿಲ್ಲ — ಆ ವೇತನದ ಒಂದು ಭಾಗವು ಕೈಬಿಟ್ಟ ಭತ್ಯೆ ಪಾವತಿಗಳು ಮತ್ತು ಕಳೆದುಹೋದ ಬಿಡುವು/ಹುಡುಕಾಟದ ಸಮಯದಿಂದ ಬರುವ ವರ್ಗಾವಣೆಯೇ ಹೊರತು ಸಮಾಜದ ಸಂಪನ್ಮೂಲಗಳ ಮೇಲಿನ ಹೊಸ ನಿವ್ವಳ ಹೊರೆಯಲ್ಲ. ಆದ್ದರಿಂದ Green Book ಮಾರ್ಗದರ್ಶನವು ನಿರುದ್ಯೋಗದಿಂದ ಸೆಳೆದ ಶ್ರಮಕ್ಕೆ ಮಾರುಕಟ್ಟೆ ವೇತನಕ್ಕಿಂತ ಕಡಿಮೆ ನೆರಳು ಬೆಲೆಯನ್ನು ನಿಗದಿಪಡಿಸುತ್ತದೆ; ಇದು ಆ ಶ್ರಮದ ನಿಜವಾದ ಅವಕಾಶ ವೆಚ್ಚವನ್ನು (ನೋಡಿ [ಸಾರ್ವಜನಿಕ ಖರ್ಚಿನಲ್ಲಿ ಅವಕಾಶ ವೆಚ್ಚ](../ಸಾರ್ವಜನಿಕ-ಖರ್ಚಿನಲ್ಲಿ-ಅವಕಾಶ-ವೆಚ್ಚ/)) ಪ್ರತಿಬಿಂಬಿಸುತ್ತದೆ, ಮಾರುಕಟ್ಟೆ ಬೆಲೆಯನ್ನಲ್ಲ.

```

BEIS/DESNZ ಇಂಗಾಲ ಮೌಲ್ಯ ಸಾಧನದಿಂದ — ಹಳೆಯ ಅಂಕಿಗಳನ್ನು ಬಳಸಬೇಡಿ):
  ವಹಿವಾಟಾಗುವ ವಲಯದ ಮೌಲ್ಯ: ETS ಭತ್ಯೆ ಬೆಲೆಯ ಪ್ರವೃತ್ತಿಗಳಿಂದ ನಿರ್ಧರಿತ
  ವಹಿವಾಟಾಗದ ವಲಯದ (ಗುರಿ-ಸಂಗತ) ಮೌಲ್ಯ: ಕಾನೂನುಬದ್ಧ ಇಂಗಾಲ
    ಬಜೆಟ್‌ಗಳನ್ನು ತಲುಪಲು ಬೇಕಾದ ಕನಿಷ್ಠಾಂತರ ತಗ್ಗಿಸುವ ವೆಚ್ಚಕ್ಕೆ ನಿಗದಿ;
    ಸುಲಭ ತಗ್ಗಿಸುವ ಆಯ್ಕೆಗಳು ಮುಗಿದಂತೆ ಕಾಲಕ್ರಮೇಣ ಏರುತ್ತದೆ
  ಬಳಕೆ: £/ಟನ್ CO2e × ಆಯ್ಕೆಯಿಂದ ಹೊರಸೂಸಿದ ಅಥವಾ ತಗ್ಗಿಸಿದ ಟನ್‌ಗಳು,
    ಭವಿಷ್ಯದ ವರ್ಷಗಳಿಗೆ ಸಾಮಾಜಿಕ ರಿಯಾಯಿತಿ ದರದಲ್ಲಿ ರಿಯಾಯಿತಿ

ನೆರಳು ವೇತನ ದರ (SWR):
  SWR = ಮಾರುಕಟ್ಟೆ ವೇತನ − (ಉಳಿತಾಯವಾದ ಬಿಡುವು/ಹುಡುಕಾಟ ಸಮಯದ ಮೌಲ್ಯ
                        + ಇನ್ನು ಪಾವತಿಸದ ಕಲ್ಯಾಣ ಪಾವತಿಗಳ ಮೌಲ್ಯ)
  ಸಾಮಾನ್ಯವಾಗಿ ಮಾರುಕಟ್ಟೆ ವೇತನದ ಭಿನ್ನರಾಶಿಯಾಗಿ ವ್ಯಕ್ತಪಡಿಸಲಾಗುತ್ತದೆ (ಉದಾ. ಹೆಚ್ಚು
    ನಿರುದ್ಯೋಗವಿರುವ ಪ್ರದೇಶದಲ್ಲಿ SWR = 0.6 × ಮಾರುಕಟ್ಟೆ ವೇತನ, ಹೆಚ್ಚುವರಿ ಸಾಮರ್ಥ್ಯವಿರುವ
```

ಈ ಎರಡೂ ಅಂಕಿಗಳು ಕೇಂದ್ರೀಯವಾಗಿ ನಿಗದಿಪಡಿಸಿದ ನೀತಿ ಸಂಪ್ರದಾಯಗಳೇ ಹೊರತು ಪ್ರಾಯೋಗಿಕ ಮಾರುಕಟ್ಟೆ ಅವಲೋಕನಗಳಲ್ಲ. ನೆರಳು ಬೆಲೆಯ ಉದ್ದೇಶವೇ ಕಾಣೆಯಾದ ಅಥವಾ ವಿರೂಪಗೊಂಡ ಮಾರುಕಟ್ಟೆಗೆ ಬದಲಿಯಾಗುವುದು. ಆದ್ದರಿಂದ ಅದನ್ನು ಬಳಸುವ ಮೌಲ್ಯಮಾಪನವು ತನ್ನದೇ ಅಂಕಿಯನ್ನು ರೂಪಿಸದೆ ಈಗಿನ ಅಧಿಕೃತ ಆಕರವನ್ನು ಉಲ್ಲೇಖಿಸಬೇಕು; ಆಗ ಮಾತ್ರ ಪ್ರತಿ ಇಲಾಖೆಯ ಮೌಲ್ಯಮಾಪನ ಹೋಲಿಸಲು ಸಾಧ್ಯ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

**ರಾಷ್ಟ್ರೀಯ ಸರ್ಕಾರ**: ಪ್ರವಾಹ ರಕ್ಷಣಾ ಯೋಜನೆಯ ಮೌಲ್ಯಮಾಪನವು "ಕನಿಷ್ಠ ಕ್ರಮ" ಆಧಾರರೇಖೆಗೆ ಹೋಲಿಸಿದರೆ, 30 ವರ್ಷಗಳ ಮೌಲ್ಯಮಾಪನ ಅವಧಿಯಲ್ಲಿ ವರ್ಷಕ್ಕೆ 400 ಟನ್ CO2e ಹೊರಸೂಸುವಿಕೆಯನ್ನು ತಪ್ಪಿಸುತ್ತದೆ ಎಂದು ಅಂದಾಜಿಸುತ್ತದೆ (ತುರ್ತು ಯಂತ್ರೋಪಕರಣಗಳ ಬಳಕೆ ಕಡಿಮೆಯಾಗುವುದು ಮತ್ತು ತಪ್ಪಿದ ಪುನರ್ನಿರ್ಮಾಣದ ಅಂತರ್ಗತ ಇಂಗಾಲ ಕಡಿಮೆಯಾಗುವುದರ ಮೂಲಕ).

```
ಇಂಗಾಲದ ವಿವರಣಾತ್ಮಕ ನೆರಳು ಬೆಲೆ: £280/ಟನ್ CO2e (ವರ್ಷ 1; ಅಧಿಕೃತ
  ವಹಿವಾಟಾಗದ ಇಂಗಾಲ ಮೌಲ್ಯಗಳ ವೇಳಾಪಟ್ಟಿಯ ಪ್ರಕಾರ ಮೌಲ್ಯಮಾಪನ ಅವಧಿಯಲ್ಲಿ ಏರುತ್ತದೆ)
ವರ್ಷ 1 ಇಂಗಾಲ ಲಾಭ = 400 × £280 = £112,000
```

ಅಧಿಕೃತ ವೇಳಾಪಟ್ಟಿಯಲ್ಲಿ ಇಂಗಾಲದ ಮೌಲ್ಯವು ಮೌಲ್ಯಮಾಪನ ಅವಧಿಯಲ್ಲಿ *ಏರುತ್ತದೆ* (ಬಿಗಿಯಾಗುತ್ತಿರುವ ಇಂಗಾಲ ಬಜೆಟ್‌ಗಳ ಪ್ರತಿಬಿಂಬ). ಆದ್ದರಿಂದ ವಿಶ್ಲೇಷಕರು 30 ವರ್ಷಗಳ ಸರಣಿಯ ಪ್ರತಿ ವರ್ಷಕ್ಕೂ ಆ ವರ್ಷದ ಸರಿಯಾದ ಮೌಲ್ಯವನ್ನು ಬಳಸಬೇಕು, ಸ್ಥಿರ ದರವನ್ನಲ್ಲ. ವರ್ಷ 1ರ ಮೌಲ್ಯವನ್ನೇ ಎಲ್ಲ ವರ್ಷಕ್ಕೂ ಬಳಸಿದರೆ ನಂತರದ ವರ್ಷಗಳ ಲಾಭ ಕಡಿಮೆ ಅಂದಾಜಾಗುತ್ತದೆ ಮತ್ತು ವಿಭಿನ್ನ ಇಂಗಾಲ ಪ್ರೊಫೈಲ್ ಹೊಂದಿರುವ ಇತರ ಪ್ರವಾಹ ರಕ್ಷಣಾ ವಿನ್ಯಾಸಗಳ ವಿರುದ್ಧದ ಶ್ರೇಯಾಂಕ ತಿರುಚಲ್ಪಡುತ್ತದೆ.

**ಸ್ಥಳೀಯ ಪ್ರಾಧಿಕಾರ**: ದೀರ್ಘಕಾಲದ ನಿರುದ್ಯೋಗಿ ನಿವಾಸಿಗಳಿಗಾಗಿ ಪುರಸಭೆಯ ಉದ್ಯೋಗ ಬೆಂಬಲ ಕಾರ್ಯಕ್ರಮವು 150 ಜನರನ್ನು ಗಂಟೆಗೆ £11 ಸಂಬಳದ ಕೆಲಸಗಳಲ್ಲಿ ಇರಿಸುತ್ತದೆ. ಪೂರ್ಣ ಮಾರುಕಟ್ಟೆ ವೇತನದಲ್ಲಿ ಮೌಲ್ಯ ಕಟ್ಟಿದರೆ £11 × ಕೆಲಸ ಮಾಡಿದ ಗಂಟೆಗಳನ್ನು ಸಾಮಾಜಿಕ ಲಾಭವೆಂದು ಕಾರ್ಯಕ್ರಮಕ್ಕೆ ಜಮೆ ಮಾಡಿದಂತಾಗುತ್ತದೆ. ಆದರೆ ನೆರಳು ವೇತನ ದರದ ವಿಧಾನವು, ಇವರು ಬೇರೆ ಉದ್ಯೋಗಗಳಿಂದ ಸೆಳೆಯಲ್ಪಟ್ಟ ಕೆಲಸಗಾರರಲ್ಲ ಎಂಬುದನ್ನು ಗುರುತಿಸುತ್ತದೆ — ಕಾರ್ಯಕ್ರಮಕ್ಕೆ ಮೊದಲು ಅವರ ಶ್ರಮದ ನಿಜವಾದ ಅವಕಾಶ ವೆಚ್ಚ ಕಡಿಮೆಯಿತ್ತು.

```
ಮಾರುಕಟ್ಟೆ ವೇತನ: £11.00/ಗಂಟೆ
ನೆರಳು ವೇತನ ದರ (ವಿವರಣಾತ್ಮಕ, ಹೆಚ್ಚಿನ ಸ್ಥಳೀಯ ನಿರುದ್ಯೋಗ): 0.6 × ಮಾರುಕಟ್ಟೆ ವೇತನ = £6.60/ಗಂಟೆ

  (ನಿಜವಾಗಿಯೂ ಕೆಲಸವಿಲ್ಲದೆ ಇದ್ದ ಶ್ರಮವನ್ನು ಉತ್ಪಾದನೆಗೆ ತಂದಾಗ ಸೃಷ್ಟಿಯಾಗುವ "ಹೆಚ್ಚುವರಿ"
   ಮೌಲ್ಯ; ವೇತನವು ಹೆಚ್ಚಾಗಿ ವರ್ಗಾವಣೆಯಾದ್ದರಿಂದ ವೇತನಕ್ಕಿಂತ ಭಿನ್ನ)
```

ಇದೇ ಕಾರಣಕ್ಕೆ, ಹೆಚ್ಚು ನಿರುದ್ಯೋಗವಿರುವ ಪ್ರದೇಶಗಳಲ್ಲಿ ಉದ್ಯೋಗ ಕಾರ್ಯಕ್ರಮಗಳ ಮೌಲ್ಯಮಾಪನವು ಧನಾತ್ಮಕ ನಿವ್ವಳ ಸಾಮಾಜಿಕ ಮೌಲ್ಯವನ್ನು ತೋರಿಸಬಲ್ಲದು. ಅದೇ ಕಾರ್ಯಕ್ರಮವನ್ನು ಪೂರ್ಣ ಉದ್ಯೋಗವಿರುವ ಪ್ರದೇಶದಲ್ಲಿ ನಡೆಸಿದರೆ ಸ್ಥಳಾಂತರಗೊಂಡ ಶ್ರಮವು ಬೇರೆ ಉದ್ಯೋಗಗಳಿಂದಲೇ ಸೆಳೆಯಲ್ಪಡುವುದರಿಂದ ಅದು ಹಾಗೆ ತೋರಿಸದು.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್ ಸಂಪರ್ಕ

ನೆರಳು ಬೆಲೆ ನಿಗದಿಯು ಸಾಫ್ಟ್‌ವೇರ್ ಅಭಿವೃದ್ಧಿಯನ್ನು ನೇರವಾಗಿ ಮುಟ್ಟುವುದು ಅಪರೂಪ. ಆದರೆ ಯಾವುದೇ ವ್ಯವಹಾರ ಸಮರ್ಥನೆಯು ಐಟಿ ಬದಲಾವಣೆಯಿಂದ ಇಂಗಾಲ ಅಥವಾ ಸಾಮಾಜಿಕ ಲಾಭ ಸಿಗುತ್ತದೆ ಎಂದು ಹೇಳಿಕೊಂಡಾಗ ಇದು ಮುಖ್ಯವಾಗುತ್ತದೆ. ಇಂಗಾಲ ಉಳಿತಾಯ ಹೇಳಿಕೊಳ್ಳುವ ಡೇಟಾ ಕೇಂದ್ರ ಏಕೀಕರಣ, ಅಥವಾ ತಪ್ಪಿದ ಮುದ್ರಣ ಮತ್ತು ಅಂಚೆ ಇಂಗಾಲವನ್ನು ಹೇಳಿಕೊಳ್ಳುವ ಕಾಗದರಹಿತ ಸೇವೆಯು, ಇತರ ಯಾವುದೇ Green Book ಮೌಲ್ಯಮಾಪನ ಇನ್‌ಪುಟ್‌ನಂತೆಯೇ, ಸ್ವಂತ ಅಂಕಿಯನ್ನು ರೂಪಿಸದೆ ಈಗಿನ ಅಧಿಕೃತ ಇಂಗಾಲ ನೆರಳು ಬೆಲೆಯನ್ನು ಬಳಸಬೇಕು, ಮತ್ತು ಸ್ಥಿರ ದರದ ಬದಲು ವರ್ಷವಾರು ವೇಳಾಪಟ್ಟಿಯನ್ನು ಸರಿಯಾಗಿ ಅನ್ವಯಿಸಬೇಕು. ನೋಡಿ [ಸರ್ಕಾರಿ ಐಟಿಯಲ್ಲಿ ಒಟ್ಟು ಮಾಲೀಕತ್ವ ವೆಚ್ಚ](../ಸರ್ಕಾರಿ-ಐಟಿಯಲ್ಲಿ-ಒಟ್ಟು-ಮಾಲೀಕತ್ವ-ವೆಚ್ಚ/) ಮತ್ತು [ಸಾರ್ವಜನಿಕ ವಲಯದ ಸೈಬರ್ ಭದ್ರತೆಯ ಮೌಲ್ಯ](../ಸಾರ್ವಜನಿಕ-ವಲಯದ-ಸೈಬರ್-ಭದ್ರತೆಯ-ಮೌಲ್ಯ/); ಇವೆರಡರಲ್ಲೂ ನೇರವಾಗಿ ವೆಚ್ಚ ಕಟ್ಟಿದ ಅಂಶಗಳ ಜೊತೆಗೆ, ಹಣಕಾಸಿನ ಮೌಲ್ಯ ಕಟ್ಟಲು ಕಷ್ಟವಾದ ಇನ್‌ಪುಟ್‌ಗೆ (ಭಂಗದ ಅಪಾಯ, ಸ್ಥಗಿತಕಾಲ) ನೆರಳು ಬೆಲೆ ಬೇಕಾಗುವುದು ಸಾಮಾನ್ಯ.

## ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳು

- **ಹಳೆಯ ಇಂಗಾಲ ಅಥವಾ ವೇತನ ಅಂಕಿಯನ್ನು ಬಳಸುವುದು.** ಎರಡೂ ಮೌಲ್ಯಗಳನ್ನು ಕೇಂದ್ರ ಮಾರ್ಗದರ್ಶನವು ಕಾಲಕಾಲಕ್ಕೆ ಪರಿಷ್ಕರಿಸುತ್ತದೆ; ರದ್ದಾದ ಅಂಕಿಯ ಮೇಲೆ ನಿರ್ಮಿಸಿದ ಮೌಲ್ಯಮಾಪನವು ಹಣಕಾಸು ಇಲಾಖೆಯ ಪರಿಶೀಲನೆಯಲ್ಲಿ ಉಳಿಯುವುದಿಲ್ಲ.
- **ಹಲವು ದಶಕಗಳ ಮೌಲ್ಯಮಾಪನದಲ್ಲಿ ಸ್ಥಿರ ಇಂಗಾಲ ನೆರಳು ಬೆಲೆ ಅನ್ವಯಿಸುವುದು.** ಅಧಿಕೃತ ವೇಳಾಪಟ್ಟಿ ಕಾಲಕ್ರಮೇಣ ಏರುತ್ತದೆ; ವರ್ಷ 1ರ ಮೌಲ್ಯವನ್ನು ಎಲ್ಲೆಡೆ ಬಳಸಿದರೆ ಲಾಭ ಅಥವಾ ವೆಚ್ಚಗಳ ಪ್ರೊಫೈಲ್ ತಪ್ಪಾಗುತ್ತದೆ.
- **ನೆರಳು ವೇತನವನ್ನು ಕೆಲಸಗಾರನ ನಿಜವಾದ ಸಂಬಳದ ಮೇಲಿನ ರಿಯಾಯಿತಿ ಎಂದು ಗೊಂದಲ ಮಾಡಿಕೊಳ್ಳುವುದು.** ನೆರಳು ವೇತನ ದರವು *ಮೌಲ್ಯಮಾಪನದ* ಶ್ರಮ ಇನ್‌ಪುಟ್ ಮೌಲ್ಯವನ್ನು ಹೊಂದಿಸುತ್ತದೆ, ಕೆಲಸಗಾರನಿಗೆ ನಿಜವಾಗಿ ನೀಡುವ ವೇತನವನ್ನಲ್ಲ — ಇವೆರಡನ್ನು ಬೆರೆಸಿದರೆ ಮಾರುಕಟ್ಟೆಗಿಂತ ಕಡಿಮೆ ವೇತನವನ್ನು (ತಪ್ಪಾಗಿ) ಸಮರ್ಥಿಸುವ ಆಹ್ವಾನವಾಗುತ್ತದೆ.
- **ಅಧಿಕೃತ ನೆರಳು ಬೆಲೆಯ ಬದಲು ತನ್ನದೇ ನೆರಳು ಬೆಲೆಯನ್ನು ರೂಪಿಸುವುದು.** ಮೌಲ್ಯಮಾಪನಗಳು ಇಲಾಖೆಗಳಾದ್ಯಂತ ಹೋಲಿಸಬಹುದಾಗಿರಲೆಂದೇ ನೆರಳು ಬೆಲೆಗಳು ನೀತಿ ಸಂಪ್ರದಾಯಗಳಾಗಿವೆ; ಸ್ಥಳೀಯವಾಗಿ ರೂಪಿಸಿದ ಅಂಕಿ ಎಷ್ಟೇ ಚೆನ್ನಾಗಿ ತರ್ಕಿಸಿದ್ದರೂ ಆ ಹೋಲಿಕೆಯ ಸಾಧ್ಯತೆಯನ್ನು ಮುರಿಯುತ್ತದೆ.
