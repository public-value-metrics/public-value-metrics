# ಸರ್ಕಾರದಲ್ಲಿ ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ ವಿಶ್ಲೇಷಣೆ

ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ ವಿಶ್ಲೇಷಣೆ (cost-effectiveness analysis, CEA) *ಒಂದೇ* ಫಲಿತಾಂಶವನ್ನು ಸಾಧಿಸುವ ಪರ್ಯಾಯ ಮಾರ್ಗಗಳ ವೆಚ್ಚಗಳನ್ನು ಸ್ವಾಭಾವಿಕ ಘಟಕಗಳಲ್ಲಿ ವ್ಯಕ್ತಪಡಿಸಿ ಹೋಲಿಸುತ್ತದೆ — ಆಶ್ರಯ ಪಡೆದ ಪ್ರತಿ ಬೀದಿ ನಿದ್ರಿಗೆ ವೆಚ್ಚ, ನಿರೀಕ್ಷಿತ ಮಟ್ಟಕ್ಕೆ ತಂದ ಪ್ರತಿ ವಿದ್ಯಾರ್ಥಿಗೆ ವೆಚ್ಚ, ಕಡಿತಗೊಳಿಸಿದ ಪ್ರತಿ ಟನ್ CO2 ಗೆ ವೆಚ್ಚ — ಫಲಿತಾಂಶವನ್ನೇ ಹಣಕ್ಕೆ ಪರಿವರ್ತಿಸದೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

[ಸಾಮಾಜಿಕ ವೆಚ್ಚ-ಲಾಭ ವಿಶ್ಲೇಷಣೆ](../ಸಾಮಾಜಿಕ-ವೆಚ್ಚ-ಲಾಭ-ವಿಶ್ಲೇಷಣೆ/) ಯ ಪ್ರತಿ ಪ್ರಯೋಜನವನ್ನು ಹಣಕ್ಕೆ ಪರಿವರ್ತಿಸುವ ಅಗತ್ಯವು ಕೇವಲ ಕಷ್ಟವಲ್ಲ, ಅಪ್ರಾಮಾಣಿಕವೂ ಆಗುವಾಗ — ಫಲಿತಾಂಶಕ್ಕೆ ವಿಶ್ವಾಸಾರ್ಹ ಬೆಲೆ ಕಟ್ಟಲು ಯಾರೂ ನಿಜವಾಗಿ ಹೊಂದಿರದ ಊಹೆಗಳು ಬೇಕಾದಾಗ — Green Book CEA ಅನ್ನು ಪರ್ಯಾಯ ವಿಧಾನವೆಂದು ಪರಿಗಣಿಸುತ್ತದೆ (<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>, ಅಧ್ಯಾಯ 5, ಫಲಿತಾಂಶಗಳನ್ನು ಸುಲಭವಾಗಿ ಹಣಕ್ಕೆ ಪರಿವರ್ತಿಸಲಾಗದ ಆಯ್ಕೆ ಮೌಲ್ಯಮಾಪನದ ಬಗ್ಗೆ). CEA ಆರೋಗ್ಯ ಅರ್ಥಶಾಸ್ತ್ರದಿಂದ ಅತ್ಯಂತ ನೇರವಾಗಿ ಎರವಲು ಪಡೆದ ವಿಧಾನ — NICE ಚಿಕಿತ್ಸೆಗಳನ್ನು ಗುಣಮಟ್ಟ-ಹೊಂದಿಸಿದ ಜೀವ ವರ್ಷದ (Quality-Adjusted Life Year) ವೆಚ್ಚದ ಮೂಲಕ ಹೋಲಿಸುವ ರೀತಿಯಲ್ಲೇ ರಚನಾತ್ಮಕವಾಗಿ ಒಂದೇ — ಆದರೆ ಆರೋಗ್ಯೇತರ ಸಾರ್ವಜನಿಕ ಕಾರ್ಯಕ್ರಮಗಳಿಗೆ ಅನ್ವಯಿಸಲಾಗಿದೆ: ಪ್ರತಿ ವಿದ್ಯಾರ್ಥಿ-ಫಲಿತಾಂಶ-ಅಂಕಕ್ಕೆ ಶಿಕ್ಷಣ ಮಧ್ಯಸ್ಥಿಕೆಗಳು, ನಿರಾಶ್ರಿತತೆಯಿಂದ ತಡೆದ ಪ್ರತಿ ಕುಟುಂಬಕ್ಕೆ ವಸತಿ ಕಾರ್ಯಕ್ರಮಗಳು, ಸುಸ್ಥಿರ ಪ್ರತಿ ಉದ್ಯೋಗ ಫಲಿತಾಂಶಕ್ಕೆ ಉದ್ಯೋಗ ಕಾರ್ಯಕ್ರಮಗಳು.

CEA ಅನ್ನು SCBA ಯೊಳಗೆ ಸೇರಿಸದೆ ಅದರ ಜೊತೆಗೇ ಇರಿಸಲು ಕಾರಣ: ಕೆಲವು ಫಲಿತಾಂಶಗಳ ಮೇಲೆ ಹಣದ ಮೌಲ್ಯವನ್ನು ಒತ್ತಾಯಿಸುವುದರಿಂದ ಅಧಿಕೃತವಾಗಿ ಕಾಣುವಷ್ಟು ನಿಖರ, ಸಾರ್ವಜನಿಕ ಚರ್ಚೆಯಲ್ಲಿ ವ್ಯರ್ಥವಾಗುವಷ್ಟು ವಿವಾದಾತ್ಮಕ ಸಂಖ್ಯೆ ಉತ್ಪಾದನೆಯಾಗುತ್ತದೆ — "ನಿರೀಕ್ಷಿತ ಮಟ್ಟದಲ್ಲಿ ಓದುತ್ತಿರುವ ಮಗು" ಗೆ ಬೆಲೆ ಕಟ್ಟುವುದು ಆಯ್ಕೆ ಸಮಿತಿಯಲ್ಲಿ ವ್ಯವಹಾರ ಪ್ರಕರಣವನ್ನು ಹಳಿ ತಪ್ಪಿಸುವ ರೀತಿಯ ಸವಾಲನ್ನೇ ಆಹ್ವಾನಿಸುತ್ತದೆ. CEA ಆ ವಾದವನ್ನು ಹೊಂದಲು ನಿರಾಕರಿಸುವ ಮೂಲಕ ಅದನ್ನು ತಪ್ಪಿಸಿಕೊಳ್ಳುತ್ತದೆ: ಇದು ಆಯ್ಕೆಗಳನ್ನು *ಫಲಿತಾಂಶದ* ಪ್ರತಿ ಘಟಕದ ವೆಚ್ಚದ ಮೇಲೆ ಶ್ರೇಣೀಕರಿಸುತ್ತದೆ, ಫಲಿತಾಂಶವನ್ನು ಅನುಸರಿಸುವುದು ಯೋಗ್ಯವೇ ಎಂಬ ಪ್ರತ್ಯೇಕ ರಾಜಕೀಯ ತೀರ್ಮಾನವನ್ನು ಕಾರ್ಯತಂತ್ರ ಪ್ರಕರಣಕ್ಕೆ ಬಿಡುತ್ತದೆ.

## ಗಣಿತ

```
ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ ಅನುಪಾತ (ಸರಾಸರಿ) = ಒಟ್ಟು ವೆಚ್ಚ / ಸಾಧಿಸಿದ ಒಟ್ಟು ಫಲಿತಾಂಶ ಘಟಕಗಳು

ಹೆಚ್ಚುತ್ತಿರುವ ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ ಅನುಪಾತ (ICER), ಆಯ್ಕೆ A ಅನ್ನು ಆಯ್ಕೆ B ಗೆ ಹೋಲಿಸಿದಾಗ:
ICER = (ವೆಚ್ಚ_A − ವೆಚ್ಚ_B) / (ಫಲಿತಾಂಶ_A − ಫಲಿತಾಂಶ_B)

ಕಾರ್ಯವಿಧಾನ:
1. ಹೋಲಿಸುತ್ತಿರುವ ಎಲ್ಲ ಆಯ್ಕೆಗಳಿಗೆ ಫಲಿತಾಂಶ ಘಟಕ ಮತ್ತು ಮಾಪನ ವಿಧಾನವನ್ನು ನಿಗದಿಪಡಿಸಿ.
2. ಪ್ರತಿ ಆಯ್ಕೆಗೆ ಒಂದೇ ಆಧಾರದಲ್ಲಿ ವೆಚ್ಚ ಹಾಕಿ (../green-book-appraisal/, ಹಣಕಾಸು ಪ್ರಕರಣ ನೋಡಿ)
   ಒಂದೇ ಕಾಲಾವಧಿಯಲ್ಲಿ.
3. ಪ್ರಾಬಲ್ಯಕ್ಕೊಳಗಾದ ಆಯ್ಕೆಗಳನ್ನು ತಿರಸ್ಕರಿಸಿ: ಅದೇ ಅಥವಾ ಉತ್ತಮ ಫಲಿತಾಂಶ ಸಾಧಿಸುವ
   ಅಗ್ಗದ ಪರ್ಯಾಯಕ್ಕಿಂತ ಪ್ರತಿ ಘಟಕಕ್ಕೆ ಹೆಚ್ಚು ವೆಚ್ಚವಾಗುವ ಯಾವುದೇ ಆಯ್ಕೆಯನ್ನು ಕೈಬಿಡಲಾಗುತ್ತದೆ.
4. ಉಳಿದ ಆಯ್ಕೆಗಳನ್ನು ಸರಾಸರಿಯಲ್ಲ, ಹೆಚ್ಚುತ್ತಿರುವ ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ ಅನುಪಾತದಿಂದ ಶ್ರೇಣೀಕರಿಸಿ.
```

CEA ಸ್ವತಃ ಒಂದು ಕಾರ್ಯಕ್ರಮಕ್ಕೆ ನಿಧಿ ನೀಡುವುದು ಯೋಗ್ಯವೇ ಎಂದು ಹೇಳಲಾರದು — ಒಂದೇ ಗುರಿಯ ಹಲವು ವಿಧಾನಗಳಲ್ಲಿ ಪ್ರತಿ ಘಟಕಕ್ಕೆ ಯಾವುದು ಅಗ್ಗ ಎಂದು ಮಾತ್ರ ಹೇಳುತ್ತದೆ. ಗುರಿಯೇ ಖರ್ಚಿಗೆ ಯೋಗ್ಯವೇ ಎಂದು ನಿರ್ಧರಿಸಲು ಒಂದೋ SCBA ಗೆ ಮರಳಿ ಪರಿವರ್ತಿಸಬೇಕು (ವಿಶ್ವಾಸಾರ್ಹ ಮೌಲ್ಯಮಾಪನ ಇದ್ದರೆ) ಅಥವಾ ಗಣಿತದ ಹೊರಗಿನ ರಾಜಕೀಯ/ಕಾರ್ಯತಂತ್ರ ತೀರ್ಮಾನ ಬೇಕು. ಕಾರ್ಯಕ್ರಮವು ವಿಭಿನ್ನ ರೀತಿಯಲ್ಲಿ ಮುಖ್ಯವಾದ ಹಲವು ಫಲಿತಾಂಶಗಳನ್ನು ಉತ್ಪಾದಿಸುವುದರಿಂದ ಫಲಿತಾಂಶಗಳನ್ನು ಒಂದೇ ಘಟಕಕ್ಕೆ ಇಳಿಸಲಾಗದಿದ್ದಲ್ಲಿ, ಬದಲಿಗೆ [ಬಹು-ಮಾನದಂಡ ನಿರ್ಧಾರ ವಿಶ್ಲೇಷಣೆ](../ಬಹು-ಮಾನದಂಡ-ನಿರ್ಧಾರ-ವಿಶ್ಲೇಷಣೆ/) ಬಳಸಿ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

**ಸ್ಥಳೀಯ ಪ್ರಾಧಿಕಾರ**: ಒಂದು ಕೌನ್ಸಿಲ್ ಬೀದಿ ನಿದ್ರೆ ಕಡಿಮೆ ಮಾಡುವ ಮೂರು ವಿಧಾನಗಳನ್ನು ಹೋಲಿಸುತ್ತದೆ, ಪ್ರತಿಯೊಂದಕ್ಕೂ ಒಂದು ವರ್ಷಕ್ಕೆ ವೆಚ್ಚ ಹಾಕಲಾಗಿದೆ, ಫಲಿತಾಂಶ "6+ ತಿಂಗಳು ಸ್ಥಿರ ವಸತಿಗೆ ಸ್ಥಳಾಂತರಗೊಂಡ ವ್ಯಕ್ತಿಗಳು":

```
ಆಯ್ಕೆ                           ವೆಚ್ಚ      ಸಾಧಿಸಿದ ಫಲಿತಾಂಶ   ಸರಾಸರಿ CER
Housing First (ತೀವ್ರ)           £900,000   60                  £15,000/ಫಲಿತಾಂಶ
ಹಾಸ್ಟೆಲ್ + ಸ್ಥಳಾಂತರ ಬೆಂಬಲ       £600,000   50                  £12,000/ಫಲಿತಾಂಶ
ಔಟ್‌ರೀಚ್ + ಖಾಸಗಿ ಬಾಡಿಗೆ ವಲಯ    £350,000   20                  £17,500/ಫಲಿತಾಂಶ

ICER, ಹಾಸ್ಟೆಲ್ vs ಔಟ್‌ರೀಚ್:  (600k−350k)/(50−20) = ಪ್ರತಿ ಹೆಚ್ಚುವರಿ ಫಲಿತಾಂಶಕ್ಕೆ £8,333
ICER, Housing First vs ಹಾಸ್ಟೆಲ್: (900k−600k)/(60−50) = ಪ್ರತಿ ಹೆಚ್ಚುವರಿ ಫಲಿತಾಂಶಕ್ಕೆ £30,000
```

ಸರಾಸರಿ ವೆಚ್ಚದಲ್ಲಿ ಔಟ್‌ರೀಚ್ ಹಾಸ್ಟೆಲ್‌ಗೆ ಪ್ರಾಬಲ್ಯಕ್ಕೊಳಗಾಗುತ್ತದೆ, ಆದರೆ ಔಟ್‌ರೀಚ್‌ನಿಂದ ಹಾಸ್ಟೆಲ್‌ಗೆ *ಹೆಚ್ಚುತ್ತಿರುವ* ಹೆಜ್ಜೆಗೆ ಪ್ರತಿ ಹೆಚ್ಚುವರಿ ವಸತಿ ಪಡೆದ ವ್ಯಕ್ತಿಗೆ ಕೇವಲ £8,333 ವೆಚ್ಚ — ಹಾಸ್ಟೆಲ್ ಸಾಧಿಸಿದ್ದಕ್ಕಿಂತ ಹೆಚ್ಚುವರಿ ಪ್ರತಿ ವ್ಯಕ್ತಿಗೆ £30,000 ವೆಚ್ಚವಾಗುವ Housing First ಹೆಜ್ಜೆಗೆ ಹೋಲಿಸಿದರೆ ಅಗ್ಗ. ಬಜೆಟ್-ನಿರ್ಬಂಧಿತ ಪ್ರಾಧಿಕಾರ ವಿಸ್ತರಿಸುವಾಗ, Housing First ತನ್ನ ಸರಾಸರಿ ಅನುಪಾತದಲ್ಲಿ ಉತ್ತಮವಾಗಿ ಕಂಡರೂ, Housing First ಗಿಂತ ಮೊದಲು ಹಾಸ್ಟೆಲ್ ವಿಸ್ತರಣೆಗೆ ಆದ್ಯತೆ ನೀಡಬೇಕು.

**ರಾಷ್ಟ್ರೀಯ ಸರ್ಕಾರ**: ಓದುವ ಕೌಶಲ್ಯ ಹಿಡಿದುಕೊಳ್ಳುವ ಕಾರ್ಯಕ್ರಮವನ್ನು "ವಯಸ್ಸಿಗೆ ನಿರೀಕ್ಷಿತ ಓದುವ ಮಟ್ಟ ತಲುಪುವ ಪ್ರತಿ ವಿದ್ಯಾರ್ಥಿಗೆ ವೆಚ್ಚ" ದ ಮೇಲೆ ಮೂರು ವಿತರಣಾ ಮಾದರಿಗಳಲ್ಲಿ ಹೋಲಿಸಲಾಗುತ್ತದೆ: ಒಬ್ಬರಿಗೊಬ್ಬರು ಬೋಧನೆ (£1,800/ವಿದ್ಯಾರ್ಥಿ), ಸಣ್ಣ-ಗುಂಪು ಬೋಧನೆ (£700/ವಿದ್ಯಾರ್ಥಿ), ಮತ್ತು ಕೇವಲ-ಡಿಜಿಟಲ್ ಮಧ್ಯಸ್ಥಿಕೆ (£150/ವಿದ್ಯಾರ್ಥಿ, ಆದರೆ ತೊಡಗಿಸಿಕೊಳ್ಳುವಿಕೆ ಇಳಿಕೆಗೆ ಹೊಂದಿಸಿದ ನಂತರ ದಾಖಲಾದ ಪ್ರತಿ ವಿದ್ಯಾರ್ಥಿಗೆ ಸಣ್ಣ-ಗುಂಪು ಬೋಧನೆಯ ಫಲಿತಾಂಶ ದರದ ಕೇವಲ 40%). ನಿಜವಾದ ಪೂರ್ಣಗೊಳಿಸುವಿಕೆಗೆ ಹೊಂದಿಸಿದ ನಂತರ, ಕೇವಲ-ಡಿಜಿಟಲ್ ಮಟ್ಟ ತಲುಪುವ ಪ್ರತಿ ವಿದ್ಯಾರ್ಥಿಗೆ £375 ವೆಚ್ಚವಾಗುತ್ತದೆ — ಇನ್ನೂ ಅಗ್ಗ, ಆದರೆ ಸಣ್ಣ-ಗುಂಪಿನ ಅದೇ ಬಜೆಟ್‌ನಲ್ಲಿ ವಿತರಿಸಿದರೆ ಕೇವಲ-ಡಿಜಿಟಲ್‌ನಿಂದ ಸಹಾಯ ಪಡೆದ ಕಡಿಮೆ ಪರಿಮಾಣದ ವಿದ್ಯಾರ್ಥಿಗಳು, ಹೆಚ್ಚಿನ ಆಳದಲ್ಲಿ ಕಡಿಮೆ ವಿದ್ಯಾರ್ಥಿಗಳನ್ನು ತಲುಪುವುದರ ವಿರುದ್ಧ ಸ್ವೀಕಾರಾರ್ಹ ವಿನಿಮಯವೇ ಎಂದು CEA ಹೇಳಲಾರದು; ಅದು CEA ನಿರ್ಧಾರ-ಕೈಗೊಳ್ಳುವವರಿಗೆ ಮರಳಿ ಒಪ್ಪಿಸುವ ವಿತರಣಾತ್ಮಕ ತೀರ್ಮಾನ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್ ಸಂಪರ್ಕ

ಎಂಜಿನಿಯರಿಂಗ್ ತಂಡಗಳು *ಒಂದೇ* ಸೇವಾ ಫಲಿತಾಂಶಕ್ಕಾಗಿ ವಿತರಣಾ ವಿಧಾನಗಳನ್ನು ಮೌಲ್ಯಮಾಪನ ಮಾಡುವಾಗಲೆಲ್ಲಾ CEA ಸರಿಯಾದ ಚೌಕಟ್ಟು — ಮೂರು ಗುರುತು-ಪರಿಶೀಲನಾ ಮಾರಾಟಗಾರರಾದ್ಯಂತ ಯಶಸ್ವಿಯಾಗಿ ಪರಿಶೀಲಿಸಿದ ಪ್ರತಿ ಗುರುತಿಗೆ ವೆಚ್ಚ, ಎರಡು ಪ್ರಕರಣ-ಕಾರ್ಯ ಸ್ವಯಂಚಾಲನೆ ವಿನ್ಯಾಸಗಳಾದ್ಯಂತ ಸರಿಯಾಗಿ ವರ್ಗೀಕರಿಸಿದ ಪ್ರತಿ ಪ್ರಕರಣಕ್ಕೆ ವೆಚ್ಚ, ಆಂತರಿಕ ವಿರುದ್ಧ ಗುತ್ತಿಗೆ ಸರಿಪಡಿಸುವಿಕೆಯಾದ್ಯಂತ ಪರಿಹರಿಸಿದ ಪ್ರತಿ ಪ್ರವೇಶಸಾಧ್ಯತೆ ದೋಷಕ್ಕೆ ವೆಚ್ಚ. ಇದು ನೇರವಾಗಿ ತರುವ ಶಿಸ್ತು: ವೆಚ್ಚಗಳನ್ನು ಹೋಲಿಸುವ ಮೊದಲು ಫಲಿತಾಂಶ ಘಟಕವನ್ನು ವ್ಯಾಖ್ಯಾನಿಸಿ ("ಮುಚ್ಚಿದ ಟಿಕೆಟ್‌ಗಳು" ಅಲ್ಲ — ಅದು ಉತ್ಪಾದನೆ — ಆದರೆ "ನಿಜವಾಗಿ ಪರಿಹರಿಸಿದ ಬಳಕೆದಾರ ಅಗತ್ಯ"), ಮತ್ತು ಯಾವಾಗಲೂ ಪ್ರತಿ ವ್ಯವಸ್ಥೆಯ ಪ್ರತ್ಯೇಕ ಸರಾಸರಿ ವೆಚ್ಚವನ್ನಲ್ಲ, ಲೈವ್ ವ್ಯವಸ್ಥೆ ಮತ್ತು ಪ್ರಸ್ತಾಪಿತ ಬದಲಿ ನಡುವಿನ ಹೆಚ್ಚುತ್ತಿರುವ ಅನುಪಾತವನ್ನು ಲೆಕ್ಕಹಾಕಿ. [ಫಲಿತಾಂಶಗಳು ಮತ್ತು ಉತ್ಪಾದನೆಗಳು](../ಫಲಿತಾಂಶ-ಮತ್ತು-ಉತ್ಪನ್ನ/) ಮತ್ತು [ಪ್ರತಿ ಫಲಿತಾಂಶದ ವೆಚ್ಚ](../ಪ್ರತಿ-ಫಲಿತಾಂಶದ-ವೆಚ್ಚ/) ನೋಡಿ.

## ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳು

- **ವಿಸ್ತರಣೆಯ ಬಗ್ಗೆ ನಿರ್ಧರಿಸುವಾಗ ಹೆಚ್ಚುತ್ತಿರುವ ಅನುಪಾತಗಳ ಬದಲು ಸರಾಸರಿ ಅನುಪಾತಗಳನ್ನು ಹೋಲಿಸುವುದು.** ಬೀದಿ ನಿದ್ರೆ ಉದಾಹರಣೆ ತೋರಿಸುವಂತೆ, ಉತ್ತಮ ಸರಾಸರಿ ಅನುಪಾತವಿರುವ ಆಯ್ಕೆಯು ಖರೀದಿಸಲು ಮುಂದಿನ ಅಗ್ಗದ ಫಲಿತಾಂಶ ಘಟಕ ಯಾವಾಗಲೂ ಅಲ್ಲ.
- **ವಾಸ್ತವವಾಗಿ ಉತ್ಪಾದನೆಯಾಗಿರುವ ಫಲಿತಾಂಶ ಘಟಕವನ್ನು ಆರಿಸುವುದು.** "ಮಾಡಿದ ಶಿಫಾರಸುಗಳು" ಅಥವಾ "ವಿತರಿಸಿದ ಅವಧಿಗಳು" ಚಟುವಟಿಕೆಯನ್ನು ಅಳೆಯುತ್ತವೆ, ಕಾರ್ಯಕ್ರಮ ಉತ್ಪಾದಿಸಲು ಇರುವ ಫಲಿತಾಂಶವನ್ನಲ್ಲ; ಉತ್ಪಾದನೆಗಳ ಮೇಲಿನ CEA ತಪ್ಪು ಪ್ರಶ್ನೆಗೆ ಉತ್ತರಿಸುವ ವಿಶ್ವಾಸದಿಂದ ಕಾಣುವ ಸಂಖ್ಯೆಯನ್ನು ನೀಡುತ್ತದೆ.
- **ನಿಜವಾಗಿಯೂ ವಿಭಿನ್ನ ಫಲಿತಾಂಶಗಳಾದ್ಯಂತ ಹೋಲಿಸುವುದು.** ಪ್ರತಿ ಆಯ್ಕೆಯೂ ಒಂದೇ ರೀತಿ ಅಳೆದ ಒಂದೇ ಫಲಿತಾಂಶವನ್ನು ಗುರಿಯಾಗಿಸಿದಾಗ ಮಾತ್ರ CEA ಮಾನ್ಯ; "ವಸತಿ ಪಡೆದ ಪ್ರತಿ ಬೀದಿ ನಿದ್ರಿಗೆ ವೆಚ್ಚ" ವನ್ನು "ಸ್ಥಿರ ಬಾಡಿಗೆಯಲ್ಲಿರುವ ಪ್ರತಿ ಆರೈಕೆ-ಬಿಟ್ಟವರಿಗೆ ವೆಚ್ಚ" ದೊಂದಿಗೆ ಹೋಲಿಸಲು ಸಾಮಾನ್ಯ ಫಲಿತಾಂಶ ಮಾಪನ ಅಥವಾ [ಬಹು-ಮಾನದಂಡ ನಿರ್ಧಾರ ವಿಶ್ಲೇಷಣೆ](../ಬಹು-ಮಾನದಂಡ-ನಿರ್ಧಾರ-ವಿಶ್ಲೇಷಣೆ/) ಬೇಕು, CEA ಅಲ್ಲ.
- **ಫಲಿತಾಂಶದ ಬಾಳಿಕೆಯನ್ನು ನಿರ್ಲಕ್ಷಿಸುವುದು.** ಉಳಿಯದ ಫಲಿತಾಂಶಗಳನ್ನು ಉತ್ಪಾದಿಸುವ ಅಗ್ಗದ ಆಯ್ಕೆ (ಮಧ್ಯಸ್ಥಿಕೆ ಮುಗಿದ ನಂತರ ಹಿಂದಕ್ಕೆ ಜಾರುವ ವಿದ್ಯಾರ್ಥಿ), ಹೋಲಿಸಬಹುದಾದ ಅವಧಿಯಲ್ಲಿ ಅಳೆದಾಗ ನಿಜವಾಗಿ ಹೆಚ್ಚು ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿಯಲ್ಲ; ಹೋಲಿಸುತ್ತಿರುವ ಆಯ್ಕೆಗಳಾದ್ಯಂತ ಅನುಸರಣಾ ಅವಧಿಯನ್ನು ಹೊಂದಿಸಿ.
