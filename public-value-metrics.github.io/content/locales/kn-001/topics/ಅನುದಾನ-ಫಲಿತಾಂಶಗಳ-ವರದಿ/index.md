# ಅನುದಾನ ಫಲಿತಾಂಶಗಳ ವರದಿ (IRIS+)

ಅನುದಾನ ಫಲಿತಾಂಶಗಳ ವರದಿ ಎಂದರೆ ಪ್ರತಿ ಅನುದಾನದಾತರು ತಮ್ಮದೇ ವಿಶೇಷ ವರದಿ ಟೆಂಪ್ಲೇಟ್ ಕಂಡುಹಿಡಿಯುವ ಬದಲು, ಅನುದಾನ ಪಡೆದವರು ಪ್ರಮಾಣೀಕೃತ, ಹೋಲಿಸಬಹುದಾದ ಫಲಿತಾಂಶ ಮಾಪನಗಳನ್ನು ಅನುದಾನದಾತರಿಗೆ ವರದಿ ಮಾಡುವ ಅಭ್ಯಾಸ. ಜಾಗತಿಕ ಪರಿಣಾಮ ಹೂಡಿಕೆ ಜಾಲ (GIIN) ನಿರ್ವಹಿಸುವ IRIS+ ಇಂತಹ ಅತ್ಯಂತ ವ್ಯಾಪಕವಾಗಿ ಅಳವಡಿಸಿಕೊಂಡ ಮಾನದಂಡ: ಪರಿಣಾಮ ಹೂಡಿಕೆದಾರರು ಮತ್ತು ಹೆಚ್ಚುತ್ತಿರುವಂತೆ ಅನುದಾನ ನೀಡುವ ಪ್ರತಿಷ್ಠಾನಗಳು ಅನುದಾನ ಪಡೆದವರು ಬಳಸಬೇಕೆಂದು ಬೇಡುವ ಅಥವಾ ಶಿಫಾರಸು ಮಾಡುವ, ಮೊದಲೇ ವ್ಯಾಖ್ಯಾನಿಸಿದ ಸಾಮಾಜಿಕ, ಪರಿಸರ ಮತ್ತು ಆರ್ಥಿಕ ಕಾರ್ಯಕ್ಷಮತೆ ಮಾಪನಗಳ ಕ್ಯಾಟಲಾಗ್.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಪ್ರಮಾಣೀಕೃತ ವರದಿ ಇಲ್ಲದಿದ್ದ ಕಾಲದಲ್ಲಿ, ಪ್ರತಿ ಪ್ರತಿಷ್ಠಾನ ಅನುದಾನ ಪಡೆದವರಿಂದ ಬೇರೆ ಬೇರೆ ಸೂಚಕಗಳ ಸೆಟ್ ಅನ್ನು ಬೇರೆ ಬೇರೆ ಸ್ವರೂಪದಲ್ಲಿ ಕೇಳುತ್ತಿತ್ತು, ಮತ್ತು ಹತ್ತು ಅನುದಾನದಾತರಿರುವ ಮಧ್ಯಮ ಗಾತ್ರದ ದತ್ತಿ ಸಂಸ್ಥೆ ಒಂದೇ ರೀತಿಯ ಕೆಲಸಕ್ಕೆ ಹತ್ತು ಸಮಾನಾಂತರ ವರದಿ ಪ್ರಕ್ರಿಯೆಗಳನ್ನು ನಡೆಸಬೇಕಾಗಿತ್ತು; ಅನುದಾನ-ಫಲಿತಾಂಶ ಪ್ರಮಾಣೀಕರಣ ಕಡಿಮೆ ಮಾಡಲು ಇರುವ ವರದಿ ಹೊರೆಯ ಚೆನ್ನಾಗಿ ದಾಖಲಾದ ಕಾರಣ ಇದು. IRIS+ ಇದನ್ನು ಅನುದಾನದಾತರು ಮತ್ತು ಅನುದಾನ ಪಡೆದವರಿಗೆ ಹಂಚಿಕೆಯ ಶಬ್ದಕೋಶ ನೀಡುವ ಮೂಲಕ ಪರಿಹರಿಸುತ್ತದೆ: ವಿಷಯದ ಪ್ರಕಾರ (ಉದಾ. ಕೈಗೆಟುಕುವ ವಸತಿ, ಶುದ್ಧ ಇಂಧನ ಪ್ರವೇಶ, ಹಣಕಾಸು ಒಳಗೊಳ್ಳುವಿಕೆ) ಗುಂಪುಗೊಂಡ ಮೂಲ ಮಾಪನ ಸೆಟ್‌ಗಳು (Core Metrics Sets), ಪ್ರತಿ ಮಾಪನವನ್ನು ಯಾರು ವರದಿ ಮಾಡಿದರೂ "ಸೃಷ್ಟಿಸಿದ ಉದ್ಯೋಗಗಳು" ಅಥವಾ "ಸೇವೆ ಪಡೆದ ಕುಟುಂಬಗಳು" ಒಂದೇ ಅರ್ಥ ಕೊಡುವಷ್ಟು ನಿಖರವಾಗಿ ವ್ಯಾಖ್ಯಾನಿಸಲಾಗಿದೆ, ಮತ್ತು ವಿಶ್ವಸಂಸ್ಥೆಯ ಸುಸ್ಥಿರ ಅಭಿವೃದ್ಧಿ ಗುರಿಗಳಿಗೆ (SDG) ಹೊಂದಿಸಲಾಗಿದೆ, ಹಾಗಾಗಿ ಅನುದಾನದಾತರು ಅನುದಾನ ಪಡೆದವರ-ಮಟ್ಟದ ದತ್ತಾಂಶವನ್ನು ಪೋರ್ಟ್‌ಫೋಲಿಯೋ-ಮಟ್ಟದ SDG ಕಥನಕ್ಕೆ ಒಟ್ಟುಗೂಡಿಸಬಹುದು. IRIS ಮಾಪನಗಳನ್ನು ಸುಮಾರು ಅರ್ಧದಷ್ಟು ಪರಿಣಾಮ ಹೂಡಿಕೆದಾರರು ಮತ್ತು ಕ್ಷೇತ್ರದಲ್ಲಿ ಸಕ್ರಿಯವಾಗಿರುವ ನಿಧಿ ವ್ಯವಸ್ಥಾಪಕರು, ಬ್ಯಾಂಕ್‌ಗಳು ಮತ್ತು ಅಭಿವೃದ್ಧಿ ಹಣಕಾಸು ಸಂಸ್ಥೆಗಳ ಬಹುಪಾಲು ಬಳಸುತ್ತವೆ ಎಂದು GIIN ವರದಿ ಮಾಡುತ್ತದೆ.

ಪ್ರಮಾಣೀಕರಣ ಅತ್ಯಂತ ಮುಖ್ಯವಾಗುವುದು [ಫಲಿತಾಂಶಗಳು ಮತ್ತು ಔಟ್‌ಪುಟ್‌ಗಳು](../ಫಲಿತಾಂಶ-ಮತ್ತು-ಉತ್ಪನ್ನ/) ಜೊತೆ ಸಂವಹಿಸುವಲ್ಲಿ: ಅನುದಾನ ಪಡೆದವರ ಪ್ರಸ್ತುತ ಪ್ರಕರಣ ನಿರ್ವಹಣಾ ವ್ಯವಸ್ಥೆ ಏನನ್ನು ದಾಖಲಿಸುತ್ತದೋ ಅದರ ಬದಲು ವ್ಯಾಖ್ಯಾನಿತ ಫಲಿತಾಂಶ ಮತ್ತು ಪರಿಣಾಮ ಮಾಪನಗಳತ್ತ IRIS+ ವರದಿಯನ್ನು ತಳ್ಳುತ್ತದೆ; [ಫಲಿತಾಂಶಕ್ಕೆ ವೆಚ್ಚ](../ಪ್ರತಿ-ಫಲಿತಾಂಶದ-ವೆಚ್ಚ/) ಮತ್ತು [ಫಲಾನುಭವಿಗೆ ವೆಚ್ಚ](../ಪ್ರತಿ-ಫಲಾನುಭವಿಯ-ವೆಚ್ಚ/) ವಿವರಿಸುವ ಅಂತರ ಇದೇ.

## ಗಣಿತ

ಅನುದಾನ ಫಲಿತಾಂಶಗಳ ವರದಿ ಒಂದು ಚೌಕಟ್ಟು ಮತ್ತು ಪ್ರಕ್ರಿಯೆ, ಸೂತ್ರವಲ್ಲ:

```
1. Funder selects a Core Metrics Set relevant to the grant's theme
   (e.g. IRIS+ "Financial Inclusion" or "Sustainable Agriculture")
2. Each metric has a fixed definition, unit, and calculation method
   published by GIIN — not invented per-funder
3. Grantee reports against the same metric definitions across all
   its funders using that standard, cutting duplicate reporting effort
4. Funder aggregates grantee-level metrics into portfolio-level reporting,
   comparable year over year and across grantees using the same metric
```

ದಕ್ಷತೆಯ ಲಾಭ ಸಂಯೋಜನಾತ್ಮಕ: N ಅನುದಾನದಾತರು × M ಅನುದಾನ ಪಡೆದವರನ್ನು ಒಂದು ಹಂಚಿಕೆಯ ಶಬ್ದಕೋಶಕ್ಕೆ ಪ್ರಮಾಣೀಕರಿಸುವುದು N×M ವಿಶೇಷ ವರದಿ ಸಂಬಂಧಗಳನ್ನು ಒಂದು ಮಾನದಂಡದ ವಿರುದ್ಧ ಸುಮಾರು N+M ಮ್ಯಾಪಿಂಗ್‌ಗಳಾಗಿ ಪರಿವರ್ತಿಸುತ್ತದೆ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

**ಮೂವರು ಅನುದಾನದಾತರಿರುವ ಅನುದಾನ ಪಡೆದವರು, ಪ್ರಮಾಣೀಕರಣಕ್ಕೆ ಮೊದಲು**: ಅನುದಾನದಾತ 1ಕ್ಕೆ ತಲೆ ಎಣಿಕೆ ವ್ಯಾಖ್ಯಾನ ಬಳಸಿ "ಸೇವೆ ಪಡೆದ ಜನರು" ವರದಿ ಮಾಡುತ್ತಾರೆ, ಅನುದಾನದಾತ 2ಕ್ಕೆ ಕುಟುಂಬ ವ್ಯಾಖ್ಯಾನ ಬಳಸಿ "ತಲುಪಿದ ಫಲಾನುಭವಿಗಳು", ಅನುದಾನದಾತ 3ಕ್ಕೆ ಸೇವಾ-ಪ್ರಸಂಗ ವ್ಯಾಖ್ಯಾನ ಬಳಸಿ "ಪ್ರಭಾವಿತ ವ್ಯಕ್ತಿಗಳು" (ಹಾಗಾಗಿ ಎರಡು ಬಾರಿ ಬಂದ ಒಬ್ಬ ವ್ಯಕ್ತಿ ಎರಡು ಬಾರಿ ಎಣಿಕೆಯಾಗುತ್ತಾನೆ). ಮೂರು ವರದಿಗಳು, ಮೂರು ಸಂಖ್ಯೆಗಳು, ಯಾವುದೂ ಹೋಲಿಸಲಾಗದು, ಮತ್ತು ಅದೇ ಅನುದಾನದಾತರ ಪೋರ್ಟ್‌ಫೋಲಿಯೋದೊಳಗೂ ಇನ್ನೊಬ್ಬ ಅನುದಾನ ಪಡೆದವರ ಸಂಖ್ಯೆಗಳೊಂದಿಗೆ ಹೋಲಿಸಲಾಗದು.

**ಅದೇ ಅನುದಾನ ಪಡೆದವರು IRIS+ ಅಡಿಯಲ್ಲಿ**: ಸಂಬಂಧಿತ ಮೂಲ ಮಾಪನ ಸೆಟ್‌ನ ವ್ಯಾಖ್ಯಾನಿತ ಫಲಿತಾಂಶ ಮಾಪನದೊಂದಿಗೆ ವ್ಯಾಖ್ಯಾನಿತ IRIS+ ತಲುಪಿದ-ವ್ಯಕ್ತಿಗಳ ಮಾಪನದ ವಿರುದ್ಧ, ಎರಡಕ್ಕೂ GIIN ಪ್ರಕಟಿಸಿದ ಲೆಕ್ಕಾಚಾರ ವಿಧಾನ ಬಳಸಿ ವರದಿ ಮಾಡುತ್ತಾರೆ. ಈಗ ಮೂರೂ ಅನುದಾನದಾತರು ಒಂದೇ ರೀತಿಯಲ್ಲಿ ಲೆಕ್ಕ ಹಾಕಿದ ಒಂದೇ ಸಂಖ್ಯೆಯನ್ನು ಪಡೆಯುತ್ತಾರೆ, ಮತ್ತು ಅದೇ ಮಾಪನ ಬಳಸಿ ತಮ್ಮ ಪೋರ್ಟ್‌ಫೋಲಿಯೋದ ಇತರ ಅನುದಾನ ಪಡೆದವರೊಂದಿಗೆ IRIS+-ವ್ಯಾಖ್ಯಾನಿತ ಘಟಕಕ್ಕೆ ಈ ಅನುದಾನ ಪಡೆದವರ ವೆಚ್ಚವನ್ನು ಹೋಲಿಸಬಹುದು; ಇದು ವರದಿ-ಮೂಲಸೌಕರ್ಯದ ಪ್ರಮಾಣದಲ್ಲಿ ಹಂಚಿಕೆಯ [ಘಟಕ ವೆಚ್ಚ ದತ್ತಾಂಶ ಸಂಗ್ರಹ](../ಘಟಕ-ವೆಚ್ಚ-ದತ್ತಾಂಶ-ಸಂಗ್ರಹಗಳು/) ಹೊಂದಿರುವುದಕ್ಕೆ ಸಮಾನ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್ ಸಂಪರ್ಕ

ಅನುದಾನ ನಿರ್ವಹಣಾ ವೇದಿಕೆಗಳು IRIS+ ಮಾಪನ ಗುರುತುಗಳನ್ನು ಮುಕ್ತ ಪಠ್ಯವಾಗಿ ಅಲ್ಲ, ವಿದೇಶಿ ಕೀ ಆಗಿ ಪರಿಗಣಿಸಬೇಕು: ಅನುದಾನ ಪಡೆದವರು ವರದಿ ಮಾಡಿದ ಮೌಲ್ಯದೊಂದಿಗೆ ಪ್ರಕಟಿತ ಮಾಪನ ಕೋಡ್ ಅನ್ನು ಸಂಗ್ರಹಿಸುವುದು ("ಫಲಾನುಭವಿಗಳು" ಎಂಬ ಸ್ಥಳೀಯವಾಗಿ ಕಂಡುಹಿಡಿದ ಕ್ಷೇತ್ರದ ಬದಲು) ನಂತರ ದತ್ತಾಂಶ-ಶುದ್ಧೀಕರಣ ಯೋಜನೆ ಇಲ್ಲದೆ ಅನುದಾನದಾತರಾದ್ಯಂತ ಮತ್ತು ಪೋರ್ಟ್‌ಫೋಲಿಯೋಗಳಾದ್ಯಂತ ಒಟ್ಟುಗೂಡಿಕೆಯನ್ನು ಸಾಧ್ಯವಾಗಿಸುತ್ತದೆ. IRIS+ ಅಳವಡಿಸಿಕೊಳ್ಳದ ಅನುದಾನದಾತರನ್ನು ವೇದಿಕೆ ಬೆಂಬಲಿಸಬೇಕಾದಾಗ, ಪ್ರತಿ ಅನುದಾನದಾತರನ್ನು ತಕ್ಷಣ ಮಾನದಂಡಕ್ಕೆ ಒತ್ತಾಯಿಸುವ ಬದಲು ಸ್ಥಳೀಯ ಮಾಪನವನ್ನು ಹತ್ತಿರದ IRIS+ ವ್ಯಾಖ್ಯಾನಕ್ಕೆ ಮ್ಯಾಪ್ ಮಾಡಲು ಬಿಡುವುದೇ ವ್ಯವಹಾರಿಕ ವಿನ್ಯಾಸ; ಗ್ರಾಫ್‌ನ ಹೆಚ್ಚು ಭಾಗ ಹಂಚಿಕೆಯ ಗುರುತುಗಳಿಗೆ ಮ್ಯಾಪ್ ಆದಂತೆ ಹೋಲಿಕೆ ಹಂತ ಹಂತವಾಗಿ ಸುಧಾರಿಸುತ್ತದೆ. ಸಂಗ್ರಹಿಸಿದ ನಂತರ ವರದಿ ಮಾಡಿದ ಸಂಖ್ಯೆಗಳನ್ನು ಯಾವುದನ್ನು ಲೆಕ್ಕ ಹಾಕಲು ಬಳಸಬೇಕು ಎಂಬುದಕ್ಕೆ ಸೋದರ ವಿಷಯ [ಫಲಿತಾಂಶಕ್ಕೆ ವೆಚ್ಚ](../ಪ್ರತಿ-ಫಲಿತಾಂಶದ-ವೆಚ್ಚ/) ನೋಡಿ.

## ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳು

- **IRIS+ ಅಳವಡಿಕೆಯನ್ನು ಸ್ವಯಂಚಾಲಿತ ಹೋಲಿಕೆಯೆಂದು ಪರಿಗಣಿಸುವುದು.** ಇಬ್ಬರು ಅನುದಾನ ಪಡೆದವರು ಒಂದೇ IRIS+ ಮಾಪನದ ವಿರುದ್ಧ ವರದಿ ಮಾಡಿದರೂ, ಅವರ ಆಧಾರದ ದತ್ತಾಂಶ ಗುಣಮಟ್ಟ ಅಥವಾ ಪ್ರತಿವಾಸ್ತವ ಊಹೆಗಳು ಭಿನ್ನವಾಗಿದ್ದರೆ ಹೋಲಿಸಲಾಗದು; ಮಾನದಂಡ ವ್ಯಾಖ್ಯಾನಗಳನ್ನು ಸರಿಪಡಿಸುತ್ತದೆ, ಮಾಪನದ ಕಟ್ಟುನಿಟ್ಟನ್ನಲ್ಲ.
- **ಅನುದಾನದಾತರೇ ಕಂಡುಹಿಡಿದ "IRIS-ಹೊಂದಾಣಿಕೆಯ" ಮಾಪನಗಳು.** IRIS+ ಭಾಷೆಯಿಂದ ಪ್ರೇರಿತವಾದ ಆದರೆ ನಿಜವಾದ ಪ್ರಕಟಿತ ವ್ಯಾಖ್ಯಾನವಲ್ಲದ ಮಾಪನ, ಮಾನದಂಡ ಪರಿಹರಿಸಲು ಇರುವ ಛಿದ್ರತೆಯನ್ನು ಮತ್ತೆ ತರುತ್ತದೆ.
- **ಅತಿಯಾದ ಆಯ್ಕೆಯಿಂದ ವರದಿ ಆಯಾಸ.** ಕೇವಲ ಎರಡು ಅಥವಾ ಮೂರು ಮಾಪನಗಳು ನಿರ್ಧಾರಕ್ಕೆ ಸಂಬಂಧಿಸಿದಾಗ ಸಂಪೂರ್ಣ ಮೂಲ ಮಾಪನ ಸೆಟ್ ಅನ್ನು ವರದಿ ಮಾಡಲು ಅನುದಾನ ಪಡೆದವರನ್ನು ಬೇಡುವುದು, ಹೊರೆಯ ಸಮಸ್ಯೆಯನ್ನು ಪ್ರಮಾಣೀಕೃತ ಹೊದಿಕೆಯಲ್ಲಿ ಮರುಸೃಷ್ಟಿಸುತ್ತದೆ.
- **ಫಲಿತಾಂಶ ಮಾಪನವೇ ಇಲ್ಲದಿರುವುದು.** IRIS+ ಹಲವು ಶುದ್ಧ ಔಟ್‌ಪುಟ್ ಮಾಪನಗಳನ್ನು (ಉದಾ. ಸೇವೆ ಪಡೆದ ಜನರ ಎಣಿಕೆ) ಒಳಗೊಂಡಿದೆ; ಅವನ್ನು ಮಾತ್ರ ಆರಿಸಿ ಫಲಿತಾಂಶ-ಹಂತದ ಯಾವುದನ್ನೂ ಆರಿಸದಿದ್ದರೆ, ಫಲಿತಾಂಶ-ವರದಿಯ ಲೇಬಲ್ ಅಡಿಯಲ್ಲಿ [ಫಲಾನುಭವಿಗೆ ವೆಚ್ಚ](../ಪ್ರತಿ-ಫಲಾನುಭವಿಯ-ವೆಚ್ಚ/)-ಆಕಾರದ ವರದಿ ಬರುತ್ತದೆ.
