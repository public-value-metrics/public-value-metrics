# ಬಹು-ಮಾನದಂಡ ನಿರ್ಧಾರ ವಿಶ್ಲೇಷಣೆ

ಬಹು-ಮಾನದಂಡ ನಿರ್ಧಾರ ವಿಶ್ಲೇಷಣೆ (MCDA) ಹಲವಾರು ವಿಭಿನ್ನ, ತೂಕ ನೀಡಿದ ಮಾನದಂಡಗಳ ಮೇಲೆ ಆಯ್ಕೆಗಳಿಗೆ ಏಕಕಾಲದಲ್ಲಿ ಅಂಕ ನೀಡಿ ತೂಗುತ್ತದೆ;
ಪ್ರತಿ ಮಾನದಂಡವನ್ನೂ ಒಂದೇ ಹಣಕಾಸು ಅಥವಾ ನೈಸರ್ಗಿಕ ಮಾನದ ಅಳತೆಗೆ ಬಲವಂತವಾಗಿ ಇಳಿಸದೆ ಶ್ರೇಣೀಕೃತ ಹೋಲಿಕೆಯನ್ನು ನೀಡುತ್ತದೆ. ಮುಖ್ಯವಾದ
ಫಲಿತಾಂಶಗಳನ್ನು ನಿಜವಾಗಿಯೂ ಒಂದೇ ಸಂಖ್ಯೆಗೆ ಇಳಿಸಲಾಗದ ನಿರ್ಧಾರಗಳಿಗೆ ಇದು ಮೌಲ್ಯಮಾಪನ ವಿಧಾನ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

Green Book ಪ್ರಯೋಜನಗಳು "ನಿಜವಾಗಿಯೂ ಅಸಮಾನ ಮಾನದ" (genuinely incommensurable) ಆಗಿರುವ ಮೌಲ್ಯಮಾಪನಗಳಿಗೆ MCDA ಅನ್ನು ಸ್ಪಷ್ಟವಾಗಿ ಅನುಮೋದಿಸುತ್ತದೆ
(ಅದರ Box 2 ಪ್ರಕರಣ-ಅಧ್ಯಯನ ಅನುಬಂಧ ಮತ್ತು Annex A ಎರಡೂ ಇದನ್ನು ನೇರವಾಗಿ ಚರ್ಚಿಸುತ್ತವೆ). ಎಲ್ಲವನ್ನೂ
[ಸಾಮಾಜಿಕ ವೆಚ್ಚ-ಲಾಭ ವಿಶ್ಲೇಷಣೆ](../ಸಾಮಾಜಿಕ-ವೆಚ್ಚ-ಲಾಭ-ವಿಶ್ಲೇಷಣೆ/) ಮೂಲಕ ಹಣಕ್ಕೆ ಅಥವಾ
[ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ ವಿಶ್ಲೇಷಣೆ](../ಸರ್ಕಾರದಲ್ಲಿ-ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ-ವಿಶ್ಲೇಷಣೆ/) ಮೂಲಕ ಒಂದೇ ಫಲಿತಾಂಶಕ್ಕೆ ಪರಿವರ್ತಿಸಿದರೆ ನಿರ್ಧಾರ
ಸ್ಪಷ್ಟವಾಗುವುದರ ಬದಲು ತಪ್ಪಾಗಿ ಬಿಂಬಿತವಾಗುವ ಸಂದರ್ಭಗಳಲ್ಲಿ ಇದು ಅನ್ವಯಿಸುತ್ತದೆ
(<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>).
ಉದಾಹರಣೆಗೆ, ಹೊಸ ಕಾರಾಗೃಹಕ್ಕೆ ಸ್ಥಳ ಆಯ್ಕೆಯಲ್ಲಿ ಬಂಡವಾಳ ವೆಚ್ಚ, ಸಮುದಾಯದ ಮೇಲಿನ ಪರಿಣಾಮ, ಸಾರಿಗೆ ಸಂಪರ್ಕ, ಪರಿಸರ ಪ್ರಭಾವ ಮತ್ತು
ಸಿಬ್ಬಂದಿ ನೇಮಕಾತಿಯ ಸಾಧ್ಯತೆ — ಇವುಗಳ ನಡುವೆ ಹೊಂದಾಣಿಕೆ ಮಾಡಬೇಕಾಗುತ್ತದೆ. ಈ ಮಾನದಂಡಗಳಿಗೆ ಸಾಮಾನ್ಯ ಮಾನವಿಲ್ಲ; ಸಾಮಾನ್ಯ ಮಾನವನ್ನು (ಸಾಮಾನ್ಯವಾಗಿ
ಹಣ) ಬಲವಂತವಾಗಿ ಹೇರಿದರೆ, ಉದಾಹರಣೆಗೆ ಪರಿಸರ ಪ್ರಭಾವ ಮತ್ತು ವೆಚ್ಚದ ಸಾಪೇಕ್ಷ ಮಹತ್ವದ ಬಗ್ಗೆ ಒಂದು ಮೌಲ್ಯ ನಿರ್ಣಯವನ್ನು ವಸ್ತುನಿಷ್ಠ ಅಂಕಗಣಿತದ ವೇಷದಲ್ಲಿ
ಒಳಗೆ ತೂರಿಸಿದಂತಾಗುತ್ತದೆ.

MCDA ಯ ಪ್ರಾಮಾಣಿಕತೆಯೇ ಅದರ ಮುಖ್ಯ ದೌರ್ಬಲ್ಯವೂ ಹೌದು: ತೂಕಗಳನ್ನು ಮೌಲ್ಯಮಾಪನ ನಡೆಸುವವರು (ಅಥವಾ ಒಂದು ಸಮಿತಿ) ನಿಗದಿಪಡಿಸುವುದರಿಂದ,
ತೂಕ ನಿಗದಿ ಪ್ರಕ್ರಿಯೆ ಎಷ್ಟು ನ್ಯಾಯಸಮ್ಮತವೋ ವಿಧಾನವೂ ಅಷ್ಟೇ ನ್ಯಾಯಸಮ್ಮತ. ಮಾನದಂಡಗಳು ಮತ್ತು ತೂಕಗಳನ್ನು ಆಯ್ಕೆಗಳಿಗೆ ಅಂಕ ನೀಡುವುದಕ್ಕೆ *ಮೊದಲೇ*
ಒಪ್ಪಿ ಪ್ರಕಟಿಸಬೇಕು ಎಂದು Green Book ಮಾರ್ಗದರ್ಶನ ಸ್ಪಷ್ಟವಾಗಿ ಹೇಳುತ್ತದೆ; ಇದರಿಂದ ಒಬ್ಬ ಪರಿಶೀಲಕ ತನಗೆ ಬೇಕಾದ ಆಯ್ಕೆಯಿಂದ ಹಿಂದಕ್ಕೆ ಕೆಲಸ ಮಾಡಿ ಅದನ್ನು
ಸಮರ್ಥಿಸುವ ತೂಕಗಳನ್ನು ಹೊಂದಿಸುವುದನ್ನು ತಡೆಯಬಹುದು.

## ಗಣಿತ

```
For each option i and criterion j:
  Score_ij   = the option's performance against that criterion (often 0-100
               or 1-10, from evidence, expert judgement, or stakeholder scoring)
  Weight_j   = relative importance of criterion j, weights sum to 1 (or 100)

Weighted score of option i = Σ_j (Score_ij × Weight_j)

Procedure:
1. Agree the criteria set and weights BEFORE scoring any option (swing
   weighting or pairwise comparison, e.g. AHP, are common elicitation methods).
2. Score every option against every criterion on a common scale, from
   evidence where possible.
3. Compute weighted totals; rank options.
4. Sensitivity-test the weights: does the ranking survive plausible
   disagreement about how much each criterion should matter?
```

MCDA, SCBA ಯ ನಿವ್ವಳ ಪ್ರಸ್ತುತ ಮೌಲ್ಯದಂತೆ ಸಮರ್ಥನೀಯ ಸಂಪೂರ್ಣ ಮೌಲ್ಯವನ್ನು ನೀಡುವುದಿಲ್ಲ — ಒಪ್ಪಿದ ತೂಕಗಳಿಗೆ ಅನುಗುಣವಾದ ಶ್ರೇಣಿಯನ್ನು ಮಾತ್ರ ನೀಡುತ್ತದೆ.
ನಿರ್ಧಾರವು ಅಸಮಾನ ಮಾನದ ಒಳಿತುಗಳ ನಡುವಿನ ಹೊಂದಾಣಿಕೆಯ ಬಗ್ಗೆ ಇದ್ದಾಗ ಇದು ಗುಣ; ಹಣಕಾಸೀಕರಣ ಸಾಧ್ಯವಿದ್ದಾಗ ಅದರ ಕಠಿಣ ಕೆಲಸದಿಂದ ತಪ್ಪಿಸಿಕೊಳ್ಳಲು
ಬಳಸಿದರೆ ಇದು ಹೊಣೆಗಾರಿಕೆ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

**ಸ್ಥಳೀಯ ಪ್ರಾಧಿಕಾರ**: ಹೊಸ ಗೃಹ ತ್ಯಾಜ್ಯ ಮರುಬಳಕೆ ಕೇಂದ್ರಕ್ಕೆ ಸ್ಥಳ ಆಯ್ಕೆ ಮಾಡುವ ಪುರಸಭೆಯು ಮೂರು ಸ್ಥಳಗಳನ್ನು ನಾಲ್ಕು ಮಾನದಂಡಗಳ ಮೇಲೆ
ಅಂಕಿಸುತ್ತದೆ; ಯಾವುದೇ ಸ್ಥಳ ಭೇಟಿಗೆ ಮೊದಲೇ ಅಂತರ-ಇಲಾಖೆ ಸಮಿತಿಯು ತೂಕಗಳನ್ನು ನಿಗದಿಪಡಿಸುತ್ತದೆ:

```
Criteria (weight):        Capital cost (30%)  Transport access (25%)
                           Community impact (25%)  Environmental impact (20%)

Site scores (0-100, higher = better):
Site A: cost 80, access 60, community 40, environment 70
Site B: cost 60, access 90, community 70, environment 50
Site C: cost 90, access 50, community 80, environment 60

Weighted totals:
Site A = 80(.30) + 60(.25) + 40(.25) + 70(.20) = 24+15+10+14 = 63
Site B = 60(.30) + 90(.25) + 70(.25) + 50(.20) = 18+22.5+17.5+10 = 68
Site C = 90(.30) + 50(.25) + 80(.25) + 60(.20) = 27+12.5+20+12 = 71.5
```

ಸ್ಥಳ C ಅತ್ಯುನ್ನತ ಸ್ಥಾನ ಪಡೆಯುತ್ತದೆ. ಸಮುದಾಯ-ಪರಿಣಾಮದ ತೂಕವನ್ನು 25% ರಿಂದ 35% ಗೆ ಬದಲಿಸಿ (ಬಂಡವಾಳ ವೆಚ್ಚದಿಂದ 10 ಅಂಕ ತೆಗೆದು) ಸಂವೇದನಾ ಪರೀಕ್ಷೆ ಮಾಡಿದರೆ,
ಸ್ಥಳ C ಯ ಒಟ್ಟು 71.5 − 3 + 8 = 76.5 ಆಗುತ್ತದೆ ಮತ್ತು ಸ್ಥಳ B ಯದು 68 − 6 + 7 = 69 ಆಗುತ್ತದೆ — ಸ್ಥಳ C ಈಗಲೂ ಮುಂದಿದೆ; ಹೀಗಾಗಿ ತೂಕದ ಬಗ್ಗೆ ಆ ಸಹಜ
ಭಿನ್ನಾಭಿಪ್ರಾಯಕ್ಕೆ ಶ್ರೇಣಿ ದೃಢವಾಗಿದೆ, ಮತ್ತು Green Book ವರದಿಯಲ್ಲಿ ನೋಡಲು ನಿರೀಕ್ಷಿಸುವ ಪರಿಶೀಲನೆ ಇದೇ.

**ಚಾರಿಟಿ**: ಸಾಲ ಸಲಹಾ ಸೇವೆ, ಆಹಾರ ಬ್ಯಾಂಕ್ ಜಾಲ ಮತ್ತು ಆರ್ಥಿಕ ಸಾಕ್ಷರತಾ ಕಾರ್ಯಕ್ರಮ — ಇವುಗಳ ನಡುವೆ ಆಯ್ಕೆ ಮಾಡುವ ಅನುದಾನ ನೀಡುವ ಪ್ರತಿಷ್ಠಾನವು
SROI ಬದಲು (ನೋಡಿ [ಹೂಡಿಕೆಯ ಸಾಮಾಜಿಕ ಪ್ರತಿಫಲ](../ಸಾಮಾಜಿಕ-ಹೂಡಿಕೆ-ಪ್ರತಿಫಲ/)) MCDA ಅನ್ನು ಬಳಸುತ್ತದೆ; ಏಕೆಂದರೆ ಬಿಕ್ಕಟ್ಟು ಪರಿಹಾರಕ್ಕೆ ಹೆಚ್ಚು ತೂಕ ನೀಡಬೇಕೇ ಅಥವಾ
ತಡೆಗಟ್ಟುವಿಕೆಗೆ ಎಂಬ ಬಗ್ಗೆ ವಿಶ್ವಸ್ತರು ಪ್ರಾಮಾಣಿಕವಾಗಿ ಭಿನ್ನಾಭಿಪ್ರಾಯ ಹೊಂದಿದ್ದಾರೆ — ಒಂದೇ SROI ಅನುಪಾತ ಅದನ್ನು ಬಗೆಹರಿಸುತ್ತದೆ ಎಂದು ನಟಿಸುವ ಬದಲು,
ಆ ಭಿನ್ನಾಭಿಪ್ರಾಯದ *ಆಕಾರ*ವನ್ನು (ತೂಕದ ವ್ಯಾಪ್ತಿ) ಒಪ್ಪಲು MCDA ಅವರಿಗೆ ಅವಕಾಶ ನೀಡುತ್ತದೆ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್ ಸಂಪರ್ಕ

ಮಾನದಂಡಗಳು ನಿಜವಾಗಿಯೂ ಪರಸ್ಪರ ಸಂಘರ್ಷಿಸುವಾಗ ಮಾರಾಟಗಾರ ಮತ್ತು ವಾಸ್ತುಶಿಲ್ಪ ಆಯ್ಕೆಗೆ MCDA ಸಹಜ ಸಾಧನ — ಕ್ಲೌಡ್-ಹೋಸ್ಟ್ ಮಾಡಿದ ಮತ್ತು ಸ್ವಂತ ಆವರಣದ
ಪ್ರಕರಣ ನಿರ್ವಹಣಾ ವ್ಯವಸ್ಥೆಗಳ ನಡುವೆ ಆಯ್ಕೆ ಮಾಡುವಾಗ ವೆಚ್ಚ, ಡೇಟಾ-ಸಾರ್ವಭೌಮತ್ವ ಅಪಾಯ, ಪ್ರವೇಶಾರ್ಹತೆ ಮತ್ತು ವಿತರಣೆಯ ವೇಗದ ನಡುವೆ ಹೊಂದಾಣಿಕೆ ಮಾಡಬೇಕಾಗುತ್ತದೆ,
ಇವನ್ನು ಒಂದೇ ಸಂಖ್ಯೆಗೆ ಇಳಿಸಲಾಗದು. Green Book ಅಗತ್ಯಪಡಿಸುವಂತೆಯೇ, ಆಯ್ಕೆಗಳಿಗೆ ಅಂಕ ನೀಡುವ ಮೊದಲೇ ತೂಕ ನಿಗದಿ ನಡೆಯಬೇಕು ಎಂದು ಎಂಜಿನಿಯರಿಂಗ್ ಮುಖ್ಯಸ್ಥರು
ಒತ್ತಾಯಿಸಬೇಕು; ಏಕೆಂದರೆ ಆಯ್ಕೆ ಪಟ್ಟಿ ನೋಡಿದ ನಂತರ ನಡೆಸುವ ತೂಕ ನಿಗದಿ ಸಭೆ ಈಗಾಗಲೇ ಇಷ್ಟಪಟ್ಟ ಆಯ್ಕೆಯತ್ತ ಖಚಿತವಾಗಿ ವಾಲುತ್ತದೆ. MCDA ಯ ಸಾಮಾನ್ಯ ಅನ್ವಯಕ್ಕಾಗಿ
[ಸರ್ಕಾರದಲ್ಲಿ ಕಟ್ಟುವುದು ಅಥವಾ ಕೊಳ್ಳುವುದು](../ಸರ್ಕಾರದಲ್ಲಿ-ನಿರ್ಮಿಸುವುದೇ-ಅಥವಾ-ಖರೀದಿಸುವುದೇ/) ನೋಡಿ, ಮತ್ತು ನಿರ್ಧಾರದ ಮೊದಲಲ್ಲ, ನಂತರ ಬಳಸುವ ಸಂಬಂಧಿತ ರಚನಾತ್ಮಕ ಅಂಕ ನೀಡಿಕೆ ಸಾಧನಕ್ಕಾಗಿ
[ಸಾರ್ವಜನಿಕ ಮೌಲ್ಯ ಸ್ಕೋರ್‌ಕಾರ್ಡ್](../ಸಾರ್ವಜನಿಕ-ಮೌಲ್ಯ-ಸ್ಕೋರ್-ಕಾರ್ಡ್/) ನೋಡಿ.

## ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳು

- **ಆಯ್ಕೆಗಳನ್ನು ನೋಡಿದ ನಂತರ ತೂಕ ನಿಗದಿ ಮಾಡುವುದು.** ಉದ್ದೇಶಪೂರ್ವಕವಾಗಿಯೋ ಇಲ್ಲದೆಯೋ MCDA ಯನ್ನು ತಿರುಚುವ ಅತ್ಯಂತ ಸಾಮಾನ್ಯ ಮಾರ್ಗ ಇದು; ಅಂಕ ನೀಡುವ ಮೊದಲು
  ತೂಕಗಳನ್ನು ಪ್ರಕಟಿಸಿ, ಅವನ್ನು ಯಾರು ನಿಗದಿಪಡಿಸಿದರು ಎಂದು ದಾಖಲಿಸಿ.
- **ತೂಕದ ಒಟ್ಟು ಮೊತ್ತವನ್ನು ಕಟ್ಟುನಿಟ್ಟಿನ ಸಂಖ್ಯೆ ಎಂದು ಪರಿಗಣಿಸುವುದು.** ಶ್ರೇಣಿ ಸ್ಥಿರವೆಂದು ಸಂವೇದನಾ ವಿಶ್ಲೇಷಣೆ ದೃಢೀಕರಿಸದ ಹೊರತು 71.5 ಮತ್ತು 68 ರ ನಡುವಿನ ಅಂತರ
  ಅಂಕಿಅಂಶದ ದೃಷ್ಟಿಯಿಂದ ಅರ್ಥಪೂರ್ಣವಲ್ಲ; ಸುಳ್ಳು ನಿಖರತೆಯ ಬದಲು ವ್ಯಾಪ್ತಿಗಳನ್ನು ವರದಿ ಮಾಡಿ.
- **ಸಾಧ್ಯವಿದ್ದ ಹಣಕಾಸೀಕರಣವನ್ನು ತಪ್ಪಿಸಲು MCDA ಬಳಸುವುದು.** ಹೆಚ್ಚಿನ ಮಾನದಂಡಗಳಿಗೆ ವಿಶ್ವಾಸಾರ್ಹವಾಗಿ ಬೆಲೆ ಕಟ್ಟಬಹುದಾದರೆ,
  [SCBA](../ಸಾಮಾಜಿಕ-ವೆಚ್ಚ-ಲಾಭ-ವಿಶ್ಲೇಷಣೆ/) ಬದಲು MCDA ಗೆ ಜಾರುವುದು ಮೌಲ್ಯಮಾಪನ ಬಳಸಬಹುದಾಗಿದ್ದ ಮಾಹಿತಿಯನ್ನು ಕೈಬಿಡುತ್ತದೆ.
- **ಒಬ್ಬ ಪ್ರಬಲ ಪಾಲುದಾರನೇ ಎಲ್ಲ ತೂಕಗಳನ್ನು ಒಬ್ಬನೇ ನಿಗದಿಪಡಿಸುವುದು.** ಆ ವ್ಯಕ್ತಿ ಈಗಾಗಲೇ ಬಯಸಿದ್ದನ್ನೇ ಮೌಲ್ಯಮಾಪನ ಮರುಉತ್ಪಾದಿಸುವುದನ್ನು ತಪ್ಪಿಸಲು,
  ತೂಕಗಳನ್ನು ಪ್ರಾಯೋಜಕ ನಿರ್ದೇಶಕರಿಂದಲ್ಲ, ಪ್ರಾತಿನಿಧಿಕ ಸಮಿತಿಯಿಂದ ಪಡೆಯಬೇಕು ಎಂದು Green Book ನ ಉತ್ತಮ ಪದ್ಧತಿ ನಿರೀಕ್ಷಿಸುತ್ತದೆ.
