# ಸಾರ್ವಜನಿಕ ಸೇವಾ ಉತ್ಪಾದಕತೆ

ಸಾರ್ವಜನಿಕ ಸೇವಾ ಉತ್ಪಾದಕತೆಯು ಸಾರ್ವಜನಿಕ ಖರ್ಚು ಒಳಹರಿವುಗಳನ್ನು (ಸಿಬ್ಬಂದಿ, ಬಂಡವಾಳ, ಸರಕು ಮತ್ತು ಸೇವೆಗಳು) ಗುಣಮಟ್ಟ-ಹೊಂದಿಸಿದ ಉತ್ಪನ್ನಗಳಾಗಿ ಎಷ್ಟು ದಕ್ಷವಾಗಿ ಪರಿವರ್ತಿಸುತ್ತದೆ ಎಂದು ಅಳೆಯುತ್ತದೆ —
ಆರೋಗ್ಯ, ಶಿಕ್ಷಣ, ಪೊಲೀಸ್, ಸಾಮಾಜಿಕ ಆರೈಕೆಯಂತಹ ಮಾರುಕಟ್ಟೆ ಬೆಲೆಯಿಲ್ಲದ, ಹೀಗಾಗಿ ವೆಚ್ಚವನ್ನು ಭಾಗಿಸಲು ಆದಾಯದ ಅಂಕಿಅಂಶವಿಲ್ಲದ ಸೇವೆಗಳಿಗೆ. ಬ್ರಿಟನ್‌ನ Office for National Statistics 2000 ರ ದಶಕದ ಮಧ್ಯದಿಂದ ಈ ಸರಣಿಯನ್ನು
ಪ್ರಕಟಿಸುತ್ತಿದೆ, ಮತ್ತು "ಸರ್ಕಾರ ಹಣವನ್ನು ಸಾರ್ವಜನಿಕ ಸೇವೆಗಳಾಗಿ ಪರಿವರ್ತಿಸುವುದರಲ್ಲಿ ಉತ್ತಮವಾಗುತ್ತಿದೆಯೇ ಅಥವಾ ಕೆಟ್ಟದಾಗುತ್ತಿದೆಯೇ?" ಎಂದು ಉತ್ತರಿಸುವ ವಿಧಾನದ ದೃಷ್ಟಿಯಿಂದ ಅತ್ಯಂತ ಅಭಿವೃದ್ಧಿ ಹೊಂದಿದ ರಾಷ್ಟ್ರೀಯ ಪ್ರಯತ್ನ ಇದಾಗಿದೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಮಾರುಕಟ್ಟೆಯಲ್ಲಿ ಉತ್ಪಾದಕತೆ = (ಉತ್ಪನ್ನ ಮೌಲ್ಯ) / (ಒಳಹರಿವು ವೆಚ್ಚ), ಮತ್ತು ಉತ್ಪನ್ನ ಮೌಲ್ಯ ಗಮನಿಸಬಹುದಾದದ್ದು ಏಕೆಂದರೆ ಯಾರೋ ಅದಕ್ಕೆ ಪಾವತಿಸುತ್ತಾರೆ. ಸೊಂಟದ ಕೀಲು ಬದಲಿ, ಶಾಲಾ ಸ್ಥಾನ ಮತ್ತು ಪೊಲೀಸ್ ಗಸ್ತಿಗೆ ಮಾರಾಟ ಬೆಲೆ ಇಲ್ಲ,
ಆದ್ದರಿಂದ ಮುಗ್ಧವಾಗಿ ನೀವು ಅಳೆಯಬಹುದಾದದ್ದು *ಒಳಹರಿವುಗಳನ್ನು* (ಏನು ಖರ್ಚಾಯಿತು) ಮಾತ್ರ — ಇದು ವ್ಯಾಖ್ಯಾನಕಾರರನ್ನು ಏರುತ್ತಿರುವ ಸಾರ್ವಜನಿಕ ಖರ್ಚು ತನ್ನಿಂದ ತಾನೇ ಕೆಟ್ಟದ್ದು ಎಂದು ಪರಿಗಣಿಸಲು ಪ್ರಚೋದಿಸುತ್ತದೆ, ಏಕೆಂದರೆ ಸ್ಥಿರ ಮುಖ್ಯ ಚಟುವಟಿಕೆಯೊಂದಿಗೆ
ಹೆಚ್ಚು ಒಳಹರಿವು ಉತ್ಪಾದಕತೆ ಕುಸಿತದಂತೆ ಕಾಣುತ್ತದೆ. ಸಾರ್ವಜನಿಕ ಸೇವಾ ಉತ್ಪಾದಕತೆಯ ಬಗ್ಗೆ ತನ್ನ "Sources and Methods" ಪ್ರಕಟಣೆಗಳಲ್ಲಿ ವಿವರಿಸಿರುವ ONS ವಿಧಾನ, ಚಟುವಟಿಕೆ ಪ್ರಮಾಣಗಳಿಂದ (ನಡೆದ ಶಸ್ತ್ರಚಿಕಿತ್ಸೆಗಳು, ಕಲಿಸಿದ ವಿದ್ಯಾರ್ಥಿಗಳು, ತನಿಖೆ ಮಾಡಿದ ಅಪರಾಧಗಳು)
*ಉತ್ಪನ್ನ* ಸೂಚ್ಯಂಕವನ್ನು ರಚಿಸಿ ನಂತರ ಆ ಉತ್ಪನ್ನ ಸೂಚ್ಯಂಕವನ್ನು *ಗುಣಮಟ್ಟ-ಹೊಂದಿಸುವ* ಮೂಲಕ ಇದನ್ನು ಬಗೆಹರಿಸುತ್ತದೆ — ಆರೋಗ್ಯಕ್ಕೆ ಬದುಕುಳಿಯುವ ದರ ಮತ್ತು ಕಾಯುವ ಸಮಯವನ್ನು, ಶಿಕ್ಷಣಕ್ಕೆ ಸಾಧನೆಯನ್ನು, ಪೊಲೀಸ್‌ಗೆ ಪ್ರಕರಣ ಪರಿಹಾರದಂತಹ ಫಲಿತಾಂಶಗಳನ್ನು
ಸೇರಿಸಿ — ಹೀಗೆ ಅಷ್ಟೇ ಸಂಖ್ಯೆಯ ಶಸ್ತ್ರಚಿಕಿತ್ಸೆ ಮಾಡಿ ಉತ್ತಮ ಬದುಕುಳಿಯುವ ದರ ಸಾಧಿಸುವ ಸೇವೆ ಕೇವಲ ದುಬಾರಿ ಎಂದಲ್ಲ, ಹೆಚ್ಚು ಉತ್ಪಾದಕ ಎಂದು ದಾಖಲಾಗುತ್ತದೆ. ONS ಬಿಡುಗಡೆಗಳಾದ್ಯಂತ ಪುನರಾವರ್ತಿತವಾಗುವ ಮುಖ್ಯ ಸಂಶೋಧನೆ ವಲಯಕ್ಕೆ
ಗಂಭೀರ: ಬ್ರಿಟನ್‌ನ ಸಾರ್ವಜನಿಕ ಸೇವಾ ಉತ್ಪಾದಕತೆ COVID-19 ಸಾಂಕ್ರಾಮಿಕದ ಸಮಯದಲ್ಲಿ ತೀವ್ರವಾಗಿ ಕುಸಿಯಿತು, ಮತ್ತು ONS ನ 2020 ರ ಮಧ್ಯಭಾಗದ ಬಿಡುಗಡೆಗಳ ವೇಳೆಗೂ ಆರೋಗ್ಯ ಸೇರಿದಂತೆ ಹಲವು ಉಪ-ವಲಯಗಳಲ್ಲಿ 2019 ರ ಮಟ್ಟಕ್ಕೆ ಮರಳಿರಲಿಲ್ಲ,
ಖರ್ಚು ಏರಿದ್ದರೂ — ಈ ಅಂತರ "ಹೆಚ್ಚು ಹಣ" ಮತ್ತು "ಹೆಚ್ಚು ಉತ್ಪಾದಕತೆ" ಎಂಬ ಎರಡು ಸಂಪೂರ್ಣ ಬೇರೆ ಪ್ರಶ್ನೆಗಳೆಂದು ಮರುಚೌಕಟ್ಟು ಹಾಕುತ್ತದೆ.

## ಗಣಿತ

```
Output index (volume) = Σ (activity_i × relative unit cost weight_i), base-year weighted
                          across all service activities (e.g. hip ops, cataract ops,
                          GP consultations), analogous to a Laspeyres/Paasche volume index

Quality adjustment    = output index × quality adjustment factor
                          (e.g. incorporating a change in survival rates, waiting times,
                          attainment, or reoffending as a multiplier on raw volume)

Input index           = Σ (labour hours × labour cost weight) + (goods/services cost,
                          deflated) + (capital consumption)

Total factor productivity growth = % change in quality-adjusted output index
                                    − % change in input index
```

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

**ವಿವರಣಾತ್ಮಕ NHS ತೀವ್ರ-ವಲಯ ಉತ್ಪಾದಕತೆ ಲೆಕ್ಕಾಚಾರ** (ರಚನೆ ONS ವಿಧಾನವನ್ನು ಅನುಸರಿಸುತ್ತದೆ):

```
Year 1: output volume index = 100.0 (base year), input index = 100.0
        → productivity index = 100.0

Year 2: activity volume rises 3.0% (more operations, more appointments)
        but average waiting time worsens, applying a quality-adjustment
        discount of −1.0%
        Quality-adjusted output index = 100 × 1.030 × 0.990 = 101.97

        Inputs rise: staff numbers +4.0%, other costs (deflated) +1.5%,
        weighted input index = 100 × 1.032 = 103.2

Productivity growth = (101.97 / 100 − 1) − (103.2 / 100 − 1)
                     = 1.97% − 3.2% = −1.23 percentage points

Interpretation: activity rose, but inputs rose faster and quality fell
slightly, so productivity — output per unit of input — declined even
though "more care was delivered."
```

ಸಾಂಕ್ರಾಮಿಕದ ನಂತರ NHS ನ ಕೆಲವು ಭಾಗಗಳಿಗೆ ONS ಬಿಡುಗಡೆಗಳು ಪದೇಪದೇ ವರದಿ ಮಾಡಿರುವ ನಿಖರ ಮಾದರಿ ಇದು: ಗುಣಮಟ್ಟ ಹೊಂದಾಣಿಕೆ ಮತ್ತು ಒಳಹರಿವು ಬೆಳವಣಿಗೆ ಎರಡನ್ನೂ ಲೆಕ್ಕಿಸಿದಾಗ, ಏರುತ್ತಿರುವ ಖರ್ಚು ಮತ್ತು ಏರುತ್ತಿರುವ ಕಚ್ಚಾ ಚಟುವಟಿಕೆ ಕುಸಿಯುತ್ತಿರುವ
ಅಳೆದ ಉತ್ಪಾದಕತೆಯೊಂದಿಗೆ ಸಹಬಾಳ್ವೆ ನಡೆಸುತ್ತವೆ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್ ಸಂಪರ್ಕ

ಸಾರ್ವಜನಿಕ ಸೇವಾ ಉತ್ಪಾದಕತೆ ಎಂಜಿನಿಯರಿಂಗ್ ಉತ್ಪಾದಕತೆ ಚರ್ಚೆಗಳ (ಪೂರ್ಣಗೊಳಿಸಿದ ಸ್ಟೋರಿ ಪಾಯಿಂಟ್‌ಗಳು ವಿರುದ್ಧ [DORA ಅಳತೆಗಳು](../ಸಾರ್ವಜನಿಕ-ಮೌಲ್ಯಕ್ಕಾಗಿ-dora-ಮಾಪನಗಳು/) ವಿರುದ್ಧ [ಹರಿವಿನ ಅಳತೆಗಳು](../ಸರ್ಕಾರಿ-ವಿತರಣೆಯಲ್ಲಿ-ಹರಿವಿನ-ಮಾಪನಗಳು/))
ಜನಸಂಖ್ಯಾ-ಮಟ್ಟದ ಸಮಾನ: ಗುಣಮಟ್ಟ ಹೊಂದಾಣಿಕೆಯಿಲ್ಲದ ಕಚ್ಚಾ ಥ್ರೂಪುಟ್, ಸಾಫ್ಟ್‌ವೇರ್ ತಂಡದಲ್ಲಿ "ಬಿಡುಗಡೆ ಮಾಡಿದ ಕೋಡ್ ಸಾಲುಗಳು" ಹೇಗೆ ದಾರಿತಪ್ಪಿಸುತ್ತದೋ ಆಸ್ಪತ್ರೆಯಲ್ಲೂ ಹಾಗೆಯೇ. ಇಲಾಖೆಗಳಿಗೆ ಕಾರ್ಯಕ್ಷಮತೆ ಡೇಟಾ ಪೈಪ್‌ಲೈನ್‌ಗಳನ್ನು ಕಟ್ಟುವ ತಂಡಗಳು ಗುಣಮಟ್ಟ
ಹೊಂದಾಣಿಕೆಯನ್ನು ಅಡಿಟಿಪ್ಪಣಿಯಾಗಿ ಅಲ್ಲ, ಪ್ರಥಮ-ದರ್ಜೆಯ, ಆವೃತ್ತಿ ನೀಡಿದ ರೂಪಾಂತರ ಹಂತವಾಗಿ ಪರಿಗಣಿಸಬೇಕು — ಏಕೆಂದರೆ ONS ನ ವಿಶ್ವಾಸಾರ್ಹತೆ ಆ ಹೊಂದಾಣಿಕೆ ಪಾರದರ್ಶಕ, ಪುನರುತ್ಪಾದಿಸಬಹುದಾದ ಮತ್ತು ಉತ್ತಮ ಗುಣಮಟ್ಟದ ಡೇಟಾ ಬಂದಂತೆ ಪರಿಷ್ಕರಿಸಲ್ಪಡುವುದರ
ಮೇಲೆ ನಿಂತಿದೆ (ಅಂತರ್ಗತ ಗುಣಮಟ್ಟದ ಡೇಟಾ — ಉದಾ. ಬದುಕುಳಿಯುವ ದರಗಳು — ಅಂತಿಮಗೊಂಡಂತೆ ONS ಹಿಂದಿನ ವರ್ಷಗಳ ಉತ್ಪಾದಕತೆ ಅಂದಾಜುಗಳನ್ನು ಪರಿಷ್ಕರಿಸುತ್ತದೆ; ಆದ್ದರಿಂದ ಈ ಅಂಕಿಅಂಶಗಳನ್ನು ಬಳಸುವ ಯಾವುದೇ ಕೆಳಹಂತದ ವ್ಯವಸ್ಥೆ ಹೊಸ ಅವಧಿಗಳನ್ನು ಸೇರಿಸುವುದಷ್ಟೇ ಅಲ್ಲ,
ಹಿಂದಿನ ಪರಿಷ್ಕರಣೆಗಳನ್ನೂ ನಿಭಾಯಿಸಬೇಕು). ಇದು [ಒಟ್ಟು ಮಾಲೀಕತ್ವ ವೆಚ್ಚ](../ಸರ್ಕಾರಿ-ಐಟಿಯಲ್ಲಿ-ಒಟ್ಟು-ಮಾಲೀಕತ್ವ-ವೆಚ್ಚ/) ಮತ್ತು [ಸಾರ್ವಜನಿಕ ವಲಯದಲ್ಲಿ AI ಉತ್ಪಾದಕತೆ](../ಸಾರ್ವಜನಿಕ-ವಲಯದಲ್ಲಿ-ai-ಉತ್ಪಾದಕತೆ/) ದೊಂದಿಗೂ ನೇರವಾಗಿ ಛೇದಿಸುತ್ತದೆ: ಗುಣಮಟ್ಟವನ್ನು ಸುಧಾರಿಸದೆ ಅಥವಾ ಕಾಯ್ದುಕೊಳ್ಳದೆ ಕಚ್ಚಾ ಚಟುವಟಿಕೆ
ಪ್ರಮಾಣವನ್ನು ಹೆಚ್ಚಿಸುವ ವ್ಯವಸ್ಥೆ, ONS ನ ಸ್ವಂತ ವ್ಯಾಖ್ಯಾನದ ಪ್ರಕಾರ, ಉತ್ಪಾದಕತೆ ಸುಧಾರಣೆಯಲ್ಲ.

## ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳು

- **ಒಳಹರಿವು ಬೆಳವಣಿಗೆಯನ್ನು ಉತ್ಪಾದಕತೆ ಬೆಳವಣಿಗೆ ಎಂದು ಪರಿಗಣಿಸುವುದು**: ಹೆಚ್ಚು ಸಿಬ್ಬಂದಿಗೆ ಹಣ ನೀಡುವ ಹೆಚ್ಚು ಖರ್ಚು ಹೆಚ್ಚು *ಚಟುವಟಿಕೆ* ಉತ್ಪಾದಿಸುತ್ತದೆ, ಪ್ರತಿ ಒಳಹರಿವು ಘಟಕಕ್ಕೆ ಉತ್ಪನ್ನವೂ ಏರದ ಹೊರತು ಹೆಚ್ಚು *ಉತ್ಪಾದಕತೆ* ಅಲ್ಲ —
  ರಾಜಕೀಯ ವ್ಯಾಖ್ಯಾನದಲ್ಲಿ ಇವೆರಡನ್ನು ವಾಡಿಕೆಯಾಗಿ ಬೆರೆಸಲಾಗುತ್ತದೆ.
- **ಗುಣಮಟ್ಟ ಹೊಂದಾಣಿಕೆಯನ್ನು ಸಂಪೂರ್ಣ ನಿರ್ಲಕ್ಷಿಸುವುದು**: ಕಚ್ಚಾ ಚಟುವಟಿಕೆ ಎಣಿಕೆಗಳಿಂದ ಮಾತ್ರ ಕಟ್ಟಿದ ಉತ್ಪನ್ನ ಸೂಚ್ಯಂಕ, ಕಡಿಮೆ ಮೌಲ್ಯದ ಅಥವಾ ಕಡಿಮೆ ಗುಣಮಟ್ಟದ ಯಾವುದನ್ನೋ ಹೆಚ್ಚು ಮಾಡುವುದರಿಂದ "ಉತ್ಪಾದಕತೆ ಲಾಭ"ಗಳನ್ನು ತೋರಿಸುತ್ತದೆ;
  ONS ನ ಗುಣಮಟ್ಟ ಹೊಂದಾಣಿಕೆ ಇದನ್ನು ಹಿಡಿಯಲೆಂದೇ ಇದೆ.
- **ವಿಧಾನದ ಆವೃತ್ತಿ ಹೊಂದಿಸದೆ ಉಪ-ವಲಯಗಳ ನಡುವೆ ಉತ್ಪಾದಕತೆ ಸೂಚ್ಯಂಕಗಳನ್ನು ಹೋಲಿಸುವುದು**: ಆರೋಗ್ಯ, ಶಿಕ್ಷಣ ಮತ್ತು ಪೊಲೀಸ್ ಉತ್ಪಾದಕತೆಯನ್ನು ಬೇರೆ ಬೇರೆ ಪರಿಷ್ಕರಣೆ ಚಕ್ರಗಳ ಬೇರೆ ಬೇರೆ ಚಟುವಟಿಕೆ ಮತ್ತು ಗುಣಮಟ್ಟ ಡೇಟಾ ಮೂಲಗಳಿಂದ
  ಕಟ್ಟಲಾಗಿದೆ — ಮುಗ್ಧ ಅಡ್ಡ-ವಲಯ ಹೋಲಿಕೆ ಹೊಂದಾಣಿಕೆಯಾಗದ ಉಪಕರಣಗಳನ್ನು ಹೋಲಿಸುತ್ತದೆ.
- **ಒಂದು ವರ್ಷದ ಉತ್ಪಾದಕತೆ ಕುಸಿತವನ್ನು ಶಾಶ್ವತ ಪ್ರವೃತ್ತಿ ಎಂದು ಓದುವುದು**: ಸಾಂಕ್ರಾಮಿಕ ಮತ್ತು ಸಾಂಕ್ರಾಮಿಕೋತ್ತರ ಉತ್ಪಾದಕತೆ ಅಂಕಿಅಂಶಗಳು ಗುಣಮಟ್ಟದ ಡೇಟಾ (ಉದಾ. ಕಾಯುವ ಪಟ್ಟಿಗಳು, ಆಯ್ಕೆ ಚಿಕಿತ್ಸೆ ಚೇತರಿಕೆ) ತಾನೇ ಬದಲಾದಂತೆ
  ಗಮನಾರ್ಹ ವರ್ಷದಿಂದ-ವರ್ಷದ ಏರಿಳಿತ ತೋರಿಸಿವೆ; ಒಂದು ವರ್ಷದ ಚಲನೆಗಳನ್ನು ಅತಿಯಾಗಿ ಅರ್ಥೈಸುವುದರ ವಿರುದ್ಧ ONS ಸ್ಥಿರವಾಗಿ ಎಚ್ಚರಿಸುತ್ತದೆ.
