# ಸಾಮಾಜಿಕ ಹೂಡಿಕೆ ಪ್ರತಿಫಲ

ಸಾಮಾಜಿಕ ಹೂಡಿಕೆ ಪ್ರತಿಫಲ (Social Return on Investment, SROI) ಎಂದರೆ ಸಾಮಾಜಿಕ, ಪರಿಸರ ಮತ್ತು ಆರ್ಥಿಕ ಎಂಬ ವಿಶಾಲ ಮೌಲ್ಯ ಪರಿಕಲ್ಪನೆಯನ್ನು ಅಳೆಯಲು, ಹಣಕಾಸಿನ ಮೌಲ್ಯಕ್ಕೆ ತರಲು ಮತ್ತು ಲೆಕ್ಕ ಹಾಕಲು, ಹಾಗೂ ಹೂಡಿದ ಸಂಪನ್ಮೂಲಗಳ ವಿರುದ್ಧ ಅನುಪಾತವಾಗಿ ವ್ಯಕ್ತಪಡಿಸಲು ಇರುವ ಚೌಕಟ್ಟು — ಉದಾಹರಣೆಗೆ "ಹೂಡಿದ ಪ್ರತಿ £1ಕ್ಕೆ £1.44 ಸಾಮಾಜಿಕ ಮೌಲ್ಯ". ಮಾರುಕಟ್ಟೆಗಳು ಬೆಲೆ ಕಟ್ಟದ ಫಲಿತಾಂಶಗಳಿಗೆ ಹಣಕಾಸು ಲೆಕ್ಕಪತ್ರದ ತರ್ಕವನ್ನು ವಿಸ್ತರಿಸಲು, ಆದರೆ ಲೆಕ್ಕಪತ್ರದ ಶಿಸ್ತನ್ನು ಕಳೆದುಕೊಳ್ಳದೆ ಇದನ್ನು ರೂಪಿಸಲಾಗಿದೆ: SROI ಯ ಪ್ರತಿ ಸಂಖ್ಯೆಯೂ ಪಾಲುದಾರರೇ ವ್ಯಾಖ್ಯಾನಿಸಿದ ಫಲಿತಾಂಶಕ್ಕೆ, ಸಾಕ್ಷ್ಯಾಧಾರಕ್ಕೆ, ಮತ್ತು ಹೇಗಿದ್ದರೂ ಆಗುತ್ತಿದ್ದುದಕ್ಕೆ ಮಾಡಿದ ಸ್ಪಷ್ಟ ಹೊಂದಾಣಿಕೆಗೆ ಜಾಡು ಹಿಡಿಯಬಹುದಾಗಿರಬೇಕು.

## ಇದು ಏಕೆ ಮುಖ್ಯ

SROI ಅನ್ನು Social Value UK ಮತ್ತು Social Value International ನಿರ್ವಹಿಸುತ್ತವೆ; ಇವು SROI Network ನ ಉತ್ತರಾಧಿಕಾರಿ ಸಂಸ್ಥೆಗಳು, ಮತ್ತು ಅದರ "A Guide to Social Return on Investment" (2012) ಈಗಲೂ ಉಲ್ಲೇಖ ವಿಧಾನ. ಚೌಕಟ್ಟು ಏಳು ತತ್ತ್ವಗಳ ಮೇಲೆ ನಿಂತಿದೆ — ಪಾಲುದಾರರನ್ನು ಒಳಗೊಳ್ಳಿ, ಏನು ಬದಲಾಗುತ್ತದೆ ಎಂಬುದನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳಿ, ಮುಖ್ಯವಾದ ವಿಷಯಗಳಿಗೆ ಮೌಲ್ಯ ಕಟ್ಟಿ, ಮಹತ್ವದ್ದನ್ನು ಮಾತ್ರ ಸೇರಿಸಿ, ಅತಿಯಾಗಿ ಹೇಳಿಕೊಳ್ಳಬೇಡಿ, ಪಾರದರ್ಶಕರಾಗಿರಿ, ಮತ್ತು ಫಲಿತಾಂಶವನ್ನು ಪರಿಶೀಲಿಸಿ — ಮತ್ತು ಹೊರಗಿನ ಹೆಚ್ಚಿನ SROI ವರದಿಗಳು ವಿಫಲವಾಗುವುದು ಐದನೇ ತತ್ತ್ವ "ಅತಿಯಾಗಿ ಹೇಳಿಕೊಳ್ಳಬೇಡಿ" ಯಲ್ಲಿ. ಡೆಡ್‌ವೇಟ್ ಮತ್ತು ಆರೋಪಣೆ ಹೊಂದಾಣಿಕೆಗಳನ್ನು ಬಿಟ್ಟು ಬಂದ ಅನುಪಾತ SROI ಅಲ್ಲ; ಅದು SROI ಯ ಬಟ್ಟೆ ತೊಟ್ಟ ಮಾರುಕಟ್ಟೆ ಪ್ರಚಾರದ ಸಂಖ್ಯೆ. ದತ್ತಿ ಸಂಸ್ಥೆಗಳು, ಸಾಮಾಜಿಕ ಉದ್ಯಮಗಳು ಅಥವಾ ಆಯೋಗದಾತರಿಗಾಗಿ ವರದಿ ಸಾಧನಗಳನ್ನು ನಿರ್ಮಿಸುವ ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರ್‌ಗಳು ವ್ಯತ್ಯಾಸ ತಿಳಿದಿರಬೇಕು; ಏಕೆಂದರೆ ಸಾಧನವು ಶಿಸ್ತನ್ನು ಜಾರಿಗೊಳಿಸುತ್ತದೆ, ಅಥವಾ ಅದನ್ನು ಬಿಟ್ಟುಬಿಡುವುದನ್ನು ಸುಲಭ ಮಾಡುತ್ತದೆ.

## ಗಣಿತ

SROI ಯಾವ ಫಲಿತಾಂಶಗಳು ವ್ಯಾಪ್ತಿಯಲ್ಲಿವೆ ಎಂದು ಗುರುತಿಸಲು [ಬದಲಾವಣೆಯ ಸಿದ್ಧಾಂತ](../ಬದಲಾವಣೆಯ-ಸಿದ್ಧಾಂತ/)ವನ್ನು ಅವಲಂಬಿಸುತ್ತದೆ, ಮತ್ತು [ತಾರ್ಕಿಕ ಮಾದರಿ](../ತಾರ್ಕಿಕ-ಮಾದರಿ/)ಯ ಅದೇ ಹೊಣೆಗಾರಿಕೆ ಸರಪಳಿಯನ್ನು ಬಳಸಿ ಅವನ್ನು ವ್ಯಕ್ತಪಡಿಸುತ್ತದೆ:

```
SROI ಅನುಪಾತ = ಫಲಿತಾಂಶಗಳ ವರ್ತಮಾನ ಮೌಲ್ಯ / ಒಳಹರಿವುಗಳ ಮೌಲ್ಯ

ಪ್ರಕ್ರಿಯೆ:
 1. ವ್ಯಾಪ್ತಿ ನಿಗದಿಪಡಿಸಿ ಮತ್ತು ಫಲಿತಾಂಶಗಳನ್ನು ಅಳೆಯಬೇಕಾದ ಪಾಲುದಾರರನ್ನು ಗುರುತಿಸಿ
 2. ಫಲಿತಾಂಶಗಳನ್ನು ನಕ್ಷೆ ಮಾಡಿ (ಪಾಲುದಾರರೊಂದಿಗೆ ಸಾಕ್ಷ್ಯಾಧಾರಿತ ಬದಲಾವಣೆಯ ಸಿದ್ಧಾಂತ, ಊಹೆಯಲ್ಲ)
 3. ಫಲಿತಾಂಶಗಳಿಗೆ ಸಾಕ್ಷ್ಯ ಒದಗಿಸಿ, ಹಣಕಾಸಿನ ಪ್ರಾಕ್ಸಿಗಳ ಮೂಲಕ ಮೌಲ್ಯ ನೀಡಿ
 4. ಪ್ರಭಾವ ನಿಗದಿಪಡಿಸಿ: ಒಟ್ಟು ಮೌಲ್ಯ − ಡೆಡ್‌ವೇಟ್ − ಆರೋಪಣೆ − ಸ್ಥಳಾಂತರ, ನಂತರ ಕುಸಿತ (drop-off) ಅನ್ವಯಿಸಿ
 5. SROI ಲೆಕ್ಕ ಹಾಕಿ: ಪ್ರಭಾವದ ನಿವ್ವಳ ವರ್ತಮಾನ ಮೌಲ್ಯ ÷ ಒಳಹರಿವುಗಳ ಮೌಲ್ಯ
 6. ವರದಿ ಮಾಡಿ, ಬಳಸಿ, ಅಳವಡಿಸಿ — ಅನುಪಾತ ಸಂವಹನ ಸಾಧನ, ಅಂತಿಮ ಗುರಿಯಲ್ಲ
```

ಡೆಡ್‌ವೇಟ್, ಆರೋಪಣೆ ಮತ್ತು ಸ್ಥಳಾಂತರವನ್ನು [ಹೆಚ್ಚುವರಿತನ ಮತ್ತು ಡೆಡ್‌ವೇಟ್](../ಹೆಚ್ಚುವರಿತನ-ಮತ್ತು-ಡೆಡ್-ವೇಟ್/) ಮತ್ತು [ಸ್ಥಳಾಂತರ ಮತ್ತು ಕಾರಣ ನಿರ್ಣಯ](../ಸ್ಥಳಾಂತರ-ಮತ್ತು-ಕಾರಣ-ನಿರ್ಣಯ/)ಯಲ್ಲಿ ವಿವರಿಸಲಾಗಿದೆ; ಈ ಮೂರೂ ಒಟ್ಟು ಫಲಿತಾಂಶದಿಂದ ನಿಜವಾದ [ಪ್ರತಿವಾಸ್ತವಿಕ ವಿಶ್ಲೇಷಣೆ](../ಪ್ರತಿವಾಸ್ತವಿಕ-ವಿಶ್ಲೇಷಣೆ/) ಪ್ರಭಾವವನ್ನು ಪ್ರತ್ಯೇಕಿಸಲು ಇವೆ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

**ಸ್ಥಳೀಯ ಪ್ರಾಧಿಕಾರದ ಉದ್ಯೋಗ ಕಾರ್ಯಕ್ರಮ**: ವಾರ್ಷಿಕ ಒಳಹರಿವು ವೆಚ್ಚ £250,000. ಅರವತ್ತು ಭಾಗವಹಿಸುವವರು ಸ್ಥಿರ ಉದ್ಯೋಗಕ್ಕೆ ಸೇರುತ್ತಾರೆ; ಆ ಫಲಿತಾಂಶಕ್ಕೆ ಹಣಕಾಸಿನ ಪ್ರಾಕ್ಸಿ (ಯೋಗಕ್ಷೇಮ ಹೆಚ್ಚಳ, ಕಡಿಮೆ ಭತ್ಯೆ ಅವಲಂಬನೆ ಮತ್ತು ತೆರಿಗೆ ಆದಾಯ ಸೇರಿ) ಮೊದಲ ವರ್ಷಕ್ಕೆ ಪ್ರತಿ ವ್ಯಕ್ತಿಗೆ £8,500 — ಇಂತಹ ಪ್ರಾಕ್ಸಿಗಳು ಎಲ್ಲಿಂದ ಬರುತ್ತವೆ ಎಂಬುದಕ್ಕೆ [ಘಟಕ ವೆಚ್ಚ ದತ್ತಾಂಶ ಸಂಗ್ರಹಗಳು](../ಘಟಕ-ವೆಚ್ಚ-ದತ್ತಾಂಶ-ಸಂಗ್ರಹಗಳು/) ನೋಡಿ.

- ಒಟ್ಟು ಫಲಿತಾಂಶ ಮೌಲ್ಯ: 60 × £8,500 = £510,000
- ಕಳೆಯಿರಿ ಡೆಡ್‌ವೇಟ್ (ಕಾರ್ಯಕ್ರಮವಿಲ್ಲದೆಯೂ 40% ಜನ ಕೆಲಸ ಕಂಡುಕೊಳ್ಳುತ್ತಿದ್ದರು): £510,000 × 0.60 = £306,000
- ಕಳೆಯಿರಿ ಆರೋಪಣೆ (ಉಳಿದ ಬದಲಾವಣೆಯ 30% ಇತರ ಸಂಸ್ಥೆಗಳ ಬೆಂಬಲದಿಂದ): £306,000 × 0.70 = £214,200
- 30% ಕುಸಿತದೊಂದಿಗೆ ವರ್ಷ 2ರ ಫಲಿತಾಂಶ: £214,200 × 0.70 = £149,940; 3.5%/ವರ್ಷ ರಿಯಾಯಿತಿ ನೀಡಿ (ನೋಡಿ [ಸಾಮಾಜಿಕ ರಿಯಾಯಿತಿ ದರ](../ಸಾಮಾಜಿಕ-ರಿಯಾಯಿತಿ-ದರ/)): £149,940 ÷ 1.035 = £144,870
- ಪ್ರಭಾವದ ಒಟ್ಟು ವರ್ತಮಾನ ಮೌಲ್ಯ: £214,200 + £144,870 = £359,070
- **SROI ಅನುಪಾತ: £359,070 ÷ £250,000 = 1.44**, "ಹೂಡಿದ ಪ್ರತಿ £1ಕ್ಕೆ £1.44 ಸಾಮಾಜಿಕ ಮೌಲ್ಯ" ಎಂದು ವರದಿ ಮಾಡಲಾಗುತ್ತದೆ

**ದತ್ತಿ ಸಂಸ್ಥೆ**: £60,000 ವೆಚ್ಚದ ಸ್ನೇಹ ಸೇವೆಯು 80 ಹಿರಿಯರ ಒಂಟಿತನವನ್ನು ಕಡಿಮೆ ಮಾಡುತ್ತದೆ; ಪ್ರಾಕ್ಸಿ ಮೌಲ್ಯ ಪ್ರತಿ ವ್ಯಕ್ತಿಗೆ ವರ್ಷಕ್ಕೆ £1,100. ಒಟ್ಟು ಮೌಲ್ಯ £88,000; 35% ಡೆಡ್‌ವೇಟ್ ಮತ್ತು 15% ಆರೋಪಣೆಯ ನಂತರ ನಿವ್ವಳ ಪ್ರಭಾವ £88,000 × 0.65 × 0.85 = £48,620, SROI ಅನುಪಾತ 0.81 — ಸಮತೋಲನ ಬಿಂದುವಿಗಿಂತ ಕೆಳಗೆ; ಇದು ಸಮರ್ಪಕ ಮತ್ತು ಉಪಯುಕ್ತ ಫಲಿತಾಂಶ, ದಾಖಲಿಸಲು ಯೋಗ್ಯವಲ್ಲದ ವೈಫಲ್ಯವಲ್ಲ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್ ಸಂಪರ್ಕ

ಬಳಕೆದಾರರು ಫಲಿತಾಂಶಗಳ ಎಣಿಕೆ ಮತ್ತು ಪ್ರಾಕ್ಸಿ ಮೌಲ್ಯಗಳನ್ನು ನಮೂದಿಸಲು ಬಿಡುವ, ಆದರೆ ಡೆಡ್‌ವೇಟ್, ಆರೋಪಣೆ ಅಥವಾ ಸಂಯೋಜಿತ ಬದಲಾವಣೆಯ ಸಿದ್ಧಾಂತಕ್ಕೆ ಕಡ್ಡಾಯ ಕ್ಷೇತ್ರವಿಲ್ಲದ SROI ಕ್ಯಾಲ್ಕುಲೇಟರ್ ಡೀಫಾಲ್ಟ್ ಆಗಿ ಉಬ್ಬಿದ ಅನುಪಾತಗಳನ್ನು ನೀಡುತ್ತದೆ; ಏಕೆಂದರೆ ಹೊಂದಾಣಿಕೆಗಳನ್ನು ಬಿಡುವುದೇ ಕನಿಷ್ಠ ಪ್ರತಿರೋಧದ ದಾರಿ. ಶಿಸ್ತನ್ನು ಸ್ಕೀಮಾದಲ್ಲೇ ಅಳವಡಿಸಿ: ಪ್ರತಿ ಫಲಿತಾಂಶ ಸಾಲೂ ಒಂದು ಪಾಲುದಾರ ಗುಂಪು, ಸಾಕ್ಷ್ಯಾಧಾರಿತ ಪ್ರಮಾಣ, ಆಕರದೊಂದಿಗೆ ಹಣಕಾಸಿನ ಪ್ರಾಕ್ಸಿ, ಮತ್ತು ಐಚ್ಛಿಕವಲ್ಲದ ಡೆಡ್‌ವೇಟ್/ಆರೋಪಣೆ ಕ್ಷೇತ್ರಗಳನ್ನು ಉಲ್ಲೇಖಿಸಬೇಕು. SROI ಫಲಿತಾಂಶ ನಕ್ಷೆ ಅವಲಂಬಿಸಿರುವ ವ್ಯತ್ಯಾಸಕ್ಕಾಗಿ [ಫಲಿತಾಂಶ ಮತ್ತು ಉತ್ಪನ್ನ](../ಫಲಿತಾಂಶ-ಮತ್ತು-ಉತ್ಪನ್ನ/), ಮತ್ತು ಸಾಧನ ತನ್ನ ದತ್ತಾಂಶ ಮಾದರಿಯಲ್ಲಿ ಪ್ರತಿಬಿಂಬಿಸಬೇಕಾದ ಸರಪಳಿಗಾಗಿ [ತಾರ್ಕಿಕ ಮಾದರಿ](../ತಾರ್ಕಿಕ-ಮಾದರಿ/) ನೋಡಿ.

## ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳು

- **ಡೆಡ್‌ವೇಟ್ ಮತ್ತು ಆರೋಪಣೆಯನ್ನು ಬಿಟ್ಟುಬಿಡುವುದು.** ಈ ಹೊಂದಾಣಿಕೆಗಳಿಲ್ಲದ ಮುಖ್ಯ ಅನುಪಾತ ಒಟ್ಟು ಅಂಕಿಯೇ ಹೊರತು ನಿವ್ವಳ ಪ್ರಭಾವದ ಅಂಕಿಯಲ್ಲ, ಮತ್ತು Social Value UK ತತ್ತ್ವಗಳು ಎರಡನ್ನೂ ಸ್ಪಷ್ಟವಾಗಿ ಕೋರುತ್ತವೆ.
- **ಸಂಸ್ಥೆಗಳ ನಡುವೆ ಅನುಪಾತಗಳನ್ನು ಹೋಲಿಸುವುದು.** SROI ಅನುಪಾತ ಪ್ರಕರಣದಿಂದ ಪ್ರಕರಣಕ್ಕೆ ಮಾಡಿದ ವ್ಯಾಪ್ತಿ ಮತ್ತು ಪ್ರಾಕ್ಸಿ ಆಯ್ಕೆಗಳ ಮೇಲೆ ಅವಲಂಬಿತ; ಒಂದು ವರದಿಯ 4:1 ಅನುಪಾತವನ್ನು ಇನ್ನೊಂದರ 2:1 ಅನುಪಾತಕ್ಕಿಂತ "ಉತ್ತಮ" ಎಂದು ಪರಿಗಣಿಸಿದರೆ, ಊಹೆಗಳು ಹಣಕಾಸು ಲೆಕ್ಕಪತ್ರ ಅನುಪಾತದಂತೆ ಪ್ರಮಾಣೀಕೃತವಲ್ಲ ಎಂಬುದನ್ನು ಕಡೆಗಣಿಸಿದಂತಾಗುತ್ತದೆ.
- **ಅತಿಕ್ರಮಿಸುವ ಪ್ರಾಕ್ಸಿಗಳನ್ನು ಎರಡು ಬಾರಿ ಎಣಿಸುವುದು.** ಅದೇ ಫಲಾನುಭವಿಗಳಿಗೆ "ಕಡಿಮೆಯಾದ ಒಂಟಿತನ" ಪ್ರಾಕ್ಸಿ ಮತ್ತು "ಸುಧಾರಿತ ಮಾನಸಿಕ ಯೋಗಕ್ಷೇಮ" ಪ್ರಾಕ್ಸಿಯನ್ನು ಒಟ್ಟಿಗೆ ಜೋಡಿಸಿದರೆ ಒಂದೇ ಆಧಾರ ಬದಲಾವಣೆಗೆ ಎರಡು ಬಾರಿ ಮೌಲ್ಯ ಕಟ್ಟಿದಂತಾಗಬಹುದು.
- **ಪಾಲುದಾರರ ಸಂವಾದವನ್ನು ಬಿಟ್ಟುಬಿಡುವುದು.** ಮೊದಲ ತತ್ತ್ವವು ಫಲಿತಾಂಶಗಳನ್ನು ಅನುಭವಿಸುವ ಜನರೊಂದಿಗೆ ವ್ಯಾಖ್ಯಾನಿಸಬೇಕೆಂದು ಕೋರುತ್ತದೆ, ಮಾದರಿ ನಿರ್ಮಿಸುವ ವಿಶ್ಲೇಷಕರ ಊಹೆಯಲ್ಲ.
