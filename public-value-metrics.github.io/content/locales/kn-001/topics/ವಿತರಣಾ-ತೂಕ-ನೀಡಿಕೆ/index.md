# ವಿತರಣಾ ತೂಕ ನೀಡಿಕೆ

ಒಂದು ವೆಚ್ಚ ಅಥವಾ ಲಾಭವನ್ನು ಯಾರು ಪಡೆಯುತ್ತಾರೆ ಎಂಬುದರ ಆಧಾರದ ಮೇಲೆ ಅದರ ಹಣಕಾಸಿನ ಮೌಲ್ಯವನ್ನು ಹೊಂದಿಸುವುದೇ ವಿತರಣಾ ತೂಕ ನೀಡಿಕೆ (distributional weighting). ತತ್ವ ಇದು: ಒಂದು ಹೆಚ್ಚುವರಿ ಪೌಂಡ್ ಶ್ರೀಮಂತ ಕುಟುಂಬಕ್ಕಿಂತ ಬಡ ಕುಟುಂಬಕ್ಕೆ ಹೆಚ್ಚು ಮೌಲ್ಯದ್ದು. ಆದಾಯದ ಕ್ಷೀಣಿಸುವ ಅಂಚಿನ ಉಪಯುಕ್ತತೆಯ ಮೇಲೆ ನಿರ್ಮಿತವಾದ ಈ ತೂಕ ನೀಡಿಕೆಗೆ ಎಚ್‌ಎಂ ಟ್ರೆಷರಿಯ ಗ್ರೀನ್ ಬುಕ್ (Green Book) ಸ್ಪಷ್ಟ ವಿಧಾನವನ್ನು ಒದಗಿಸುತ್ತದೆ; ಇದರಿಂದ ಅತಿ ಶ್ರೀಮಂತ ದಶಮಾಂಶ ವರ್ಗ ಗಳಿಸಿದ ಪೌಂಡ್ ಮತ್ತು ಅತಿ ಬಡವರು ಗಳಿಸಿದ ಪೌಂಡ್ ಸಮಾನವೆಂದು ಮೌಲ್ಯಮಾಪನಗಳು ಮೌನವಾಗಿ ಪರಿಗಣಿಸುವುದಿಲ್ಲ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಪ್ರಮಾಣಿತ ವೆಚ್ಚ-ಲಾಭ ವಿಶ್ಲೇಷಣೆಯು ಪೌಂಡ್‌ಗಳನ್ನು ಯಾರದು ಎಂದು ಕೇಳದೆ ಕೂಡಿಸುತ್ತದೆ; ಇದು ಪ್ರತಿಯೊಬ್ಬರಿಗೂ ಒಂದು ಪೌಂಡ್ ಸಮಾನ ಮೌಲ್ಯದ್ದು ಎಂದು ಪರೋಕ್ಷವಾಗಿ ಭಾವಿಸುತ್ತದೆ. ಇದು ಸುಳ್ಳು ಎಂದು ಅರ್ಥಶಾಸ್ತ್ರಜ್ಞರು ಬಹುಕಾಲದಿಂದ ಬಲ್ಲರು. ವರ್ಷಕ್ಕೆ £15,000 ಗಳಿಸುವ ಕುಟುಂಬ £1,000 ಲಾಭವನ್ನು ವರ್ಷಕ್ಕೆ £150,000 ಗಳಿಸುವ ಕುಟುಂಬಕ್ಕಿಂತ ಬಹಳ ಭಿನ್ನವಾಗಿ ಅನುಭವಿಸುತ್ತದೆ, ಏಕೆಂದರೆ ಆದಾಯ ಹೆಚ್ಚಿದಂತೆ ಅಂಚಿನ ಉಪಯುಕ್ತತೆ ಕುಸಿಯುತ್ತದೆ. ತೂಕ ನೀಡದಿದ್ದರೆ ಪ್ರಮಾಣಿತ ಮೌಲ್ಯಮಾಪನವು ಈಗಾಗಲೇ ಉತ್ತಮ ಸ್ಥಿತಿಯಲ್ಲಿರುವ ಶ್ರೀಮಂತ ಗುಂಪುಗಳಿಗೆ ಲಾಭವಾಗುವ ಮಧ್ಯಸ್ಥಿಕೆಗಳನ್ನು ವ್ಯವಸ್ಥಿತವಾಗಿ ಬೆಂಬಲಿಸುತ್ತದೆ, ಏಕೆಂದರೆ ಅವರ ಹೆಚ್ಚಿನ ಖರೀದಿ ಸಾಮರ್ಥ್ಯ ಅವರಿಗೆ ತಲುಪುವ ಲಾಭಗಳ ಹಣಕಾಸಿನ ಮೌಲ್ಯವನ್ನು ಉಬ್ಬಿಸುತ್ತದೆ (ದುಬಾರಿ ವಸತಿ ಬಳಿಯ ಉದ್ಯಾನ ಸುಧಾರಣೆ, ಅಗ್ಗದ ವಸತಿ ಬಳಿಯ ಅದೇ ಸುಧಾರಣೆಗಿಂತ ದೊಡ್ಡ ಆಸ್ತಿ-ಮೌಲ್ಯ ಲಾಭವನ್ನು "ತೋರಿಸುತ್ತದೆ"; ಕಾರಣ ಕಲ್ಯಾಣ ಲಾಭ ಹೆಚ್ಚು ಎಂಬುದಲ್ಲ, ಬೆಲೆಗಳು ಹೆಚ್ಚು ಎಂಬುದಷ್ಟೇ).

ಮೌಲ್ಯಮಾಪನ ವಿಧಾನವು ಲಂಡನ್ ಮತ್ತು ಆಗ್ನೇಯ ಭಾಗಗಳಿಗೆ ವ್ಯವಸ್ಥಿತವಾಗಿ ಒಲವು ತೋರುತ್ತದೆ ಎಂಬ ಟೀಕೆಗೆ ಉತ್ತರವಾಗಿ ಟ್ರೆಷರಿಯ 2020ರ ಪರಿಶೀಲನೆಯ ನಂತರ ಬಲಪಡಿಸಲಾದ ಗ್ರೀನ್ ಬುಕ್‌ನ ವಿತರಣಾ ವಿಶ್ಲೇಷಣೆಯ ಪೂರಕ ಮಾರ್ಗದರ್ಶನವು, ಆದಾಯದ ಅಂಚಿನ ಉಪಯುಕ್ತತೆಯ ಸ್ಥಿತಿಸ್ಥಾಪಕತೆ ಸುಮಾರು 1.3 ಎಂದು ಭಾವಿಸಿದ ಔಪಚಾರಿಕ ತೂಕ ನೀಡಿಕೆ ವಿಧಾನವನ್ನು ಹೇಳುತ್ತದೆ. ಇದರ ಅರ್ಥ: ಆದಾಯ ದ್ವಿಗುಣವಾದರೆ ಹೆಚ್ಚುವರಿ ಪೌಂಡ್‌ನ ಅಂಚಿನ ಮೌಲ್ಯ ಸರಿಸುಮಾರು ಅರ್ಧವಾಗುತ್ತದೆ (ನಿಖರವಾಗಿ 2^-1.3 ≈ 0.41 ಪಟ್ಟು). ಇದು ಕೇವಲ ದುಂಡುಗೊಳಿಸುವ ಹೊಂದಾಣಿಕೆಯಲ್ಲ: ಇದನ್ನು ಅನ್ವಯಿಸುವುದು ಎರಡು ಸ್ಪರ್ಧಾತ್ಮಕ ಕಾರ್ಯಕ್ರಮಗಳಲ್ಲಿ ಯಾವುದು ಹೆಚ್ಚಿನ ನಿವ್ವಳ ವರ್ತಮಾನ ಮೌಲ್ಯವನ್ನು ತೋರಿಸುತ್ತದೆ ಎಂಬುದನ್ನೇ ಬದಲಿಸಬಹುದು; ವಿಶೇಷವಾಗಿ ಹಿಂದುಳಿದ ಪ್ರದೇಶದಲ್ಲಿ ಕೇಂದ್ರೀಕೃತ ಮಧ್ಯಸ್ಥಿಕೆಯನ್ನು ಸಾಮಾನ್ಯ ಜನಸಂಖ್ಯೆಯಾದ್ಯಂತ ಹರಡಿದ ಮಧ್ಯಸ್ಥಿಕೆಯೊಂದಿಗೆ ಹೋಲಿಸುವಾಗ.

## ಗಣಿತ

ಆದಾಯ ಮಟ್ಟ y ಇರುವ ಕುಟುಂಬಕ್ಕೆ ಸಿಗುವ ಒಂದು ಪೌಂಡ್ ಲಾಭಕ್ಕೆ, ರಾಷ್ಟ್ರೀಯ ಸರಾಸರಿ ಆದಾಯ ಮಟ್ಟ ȳ ಇರುವವರ ಪೌಂಡ್‌ಗೆ ಹೋಲಿಸಿದ ಗ್ರೀನ್ ಬುಕ್‌ನ ವಿತರಣಾ ತೂಕ:

```
Weight(y) = (ȳ / y)^e

where:
  y  = household income (or income of the affected group)
  ȳ  = average (reference) household income
  e  = elasticity of marginal utility of income (Green Book: approximately 1.3)
```

ನಿವ್ವಳ ಲಾಭಗಳಿಗೆ ತೂಕಗಳನ್ನು ಅನ್ವಯಿಸುವುದು:

```
Weighted benefit = Σ [unweighted benefit to group i × Weight(y_i)]
```

ರಾಷ್ಟ್ರೀಯ ಸರಾಸರಿಯ ಅರ್ಧ ಗಳಿಸುವ ಗುಂಪಿಗೆ (y = 0.5ȳ) ತೂಕ (1/0.5)^1.3 = 2^1.3 ≈ 2.46 ಸಿಗುತ್ತದೆ; ಆ ಗುಂಪಿಗೆ ಸಿಗುವ ಪ್ರತಿ ಪೌಂಡ್ ಲಾಭವು ಸರಾಸರಿ-ಆದಾಯದ ಕುಟುಂಬದ ಪೌಂಡ್‌ಗಿಂತ ಸುಮಾರು 2.46 ಪಟ್ಟು ಮೌಲ್ಯದ್ದಾಗಿ ಎಣಿಕೆಯಾಗುತ್ತದೆ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

**ಎರಡು ಸ್ಪರ್ಧಾತ್ಮಕ ಸ್ಥಳೀಯ ಕಾರ್ಯಕ್ರಮಗಳು**, ಪ್ರತಿಯೊಂದರ ತೂಕರಹಿತ ನಿವ್ವಳ ಲಾಭ ವರ್ಷಕ್ಕೆ £2 ಮಿಲಿಯನ್, ಒಂದೇ ಪ್ರಾದೇಶಿಕ ಬೆಳವಣಿಗೆ ನಿಧಿಗಾಗಿ ಸ್ಪರ್ಧಿಸುತ್ತಿವೆ:

- *ಕಾರ್ಯಕ್ರಮ A*: ಸಮೃದ್ಧ ಪಟ್ಟಣದಲ್ಲಿನ ವ್ಯಾಪಾರ-ಬೆಂಬಲ ಯೋಜನೆ, ಸರಾಸರಿ ಕುಟುಂಬ ಆದಾಯ £45,000 (ಭಾವಿತ ರಾಷ್ಟ್ರೀಯ ಸರಾಸರಿ £35,000ದ ಸುಮಾರು 1.3 ಪಟ್ಟು).
- *ಕಾರ್ಯಕ್ರಮ B*: ಹಿಂದುಳಿದ ವಾರ್ಡ್‌ನಲ್ಲಿನ ಕೌಶಲ್ಯ ಕಾರ್ಯಕ್ರಮ, ಸರಾಸರಿ ಕುಟುಂಬ ಆದಾಯ £18,000 (ರಾಷ್ಟ್ರೀಯ ಸರಾಸರಿಯ ಸುಮಾರು 0.51 ಪಟ್ಟು).

```
Weight(A) = (35,000 / 45,000)^1.3 = (0.778)^1.3 ≈ 0.72
Weight(B) = (35,000 / 18,000)^1.3 = (1.944)^1.3 ≈ 2.53

Weighted benefit A = £2,000,000 × 0.72 = £1.44 million
Weighted benefit B = £2,000,000 × 2.53 = £5.06 million
```

ತೂಕ ನೀಡದಿದ್ದಾಗ ಎರಡೂ ಕಾರ್ಯಕ್ರಮಗಳು ಸಮಾನ. ವಿತರಣಾ ಪರಿಣಾಮಕ್ಕೆ ತೂಕ ನೀಡಿದಾಗ ಕಾರ್ಯಕ್ರಮ Bಯ ಲಾಭ ಮೂರು ಪಟ್ಟಿಗಿಂತ ಹೆಚ್ಚು; ಈ ಫಲಿತಾಂಶವು ಹಣಕಾಸು ಶಿಫಾರಸನ್ನೇ ತಿರುಗುಮುರುಗು ಮಾಡುತ್ತದೆ, ಮತ್ತು ತೂಕರಹಿತ ಲಾಭ-ವೆಚ್ಚ ಅನುಪಾತ ಮಾತ್ರವಲ್ಲದೆ ತೂಕಸಹಿತವನ್ನೂ ತೋರಿಸಬೇಕೆಂಬ ಗ್ರೀನ್ ಬುಕ್‌ನ ಸ್ಪಷ್ಟ ಉದ್ದೇಶವನ್ನು ಪ್ರತಿಬಿಂಬಿಸುತ್ತದೆ.

**ದತ್ತಿ ಅನುದಾನ ಹಂಚಿಕೆ**: 1,000 ಕಡಿಮೆ-ಆದಾಯದ ಕುಟುಂಬಗಳಿಗೆ ತಲುಪುವ £500,000 ಅನುದಾನವನ್ನು (ತೂಕ ≈ 2.0, ತೂಕಸಹಿತ ಮೌಲ್ಯ £1 ಮಿಲಿಯನ್-ಸಮಾನ), 1,000 ಮಧ್ಯಮ-ಆದಾಯದ ಕುಟುಂಬಗಳಿಗೆ ತಲುಪುವ ಅದೇ £500,000ದೊಂದಿಗೆ (ತೂಕ ≈ 1.0, ತೂಕಸಹಿತ ಮೌಲ್ಯ £500,000-ಸಮಾನ) ಹೋಲಿಸುವ ಅನುದಾನದಾತರು, ವಿತರಣಾ ವಾದವನ್ನು ತಮ್ಮ ಮಂಡಳಿ ಪತ್ರದಲ್ಲಿ ಸ್ಪಷ್ಟವಾಗಿ ತೋರಿಸಬೇಕು, ಊಹಿಸಲು ಬಿಡಬಾರದು.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್ ಸಂಪರ್ಕ

ವಿತರಣಾ ತೂಕ ನೀಡಿಕೆ ತಂತ್ರಾಂಶ ವಿತರಣಾ ಮಾಪನಗಳಲ್ಲಿ ಅಪರೂಪವಾಗಿ ನೇರವಾಗಿ ಕಾಣಿಸುತ್ತದೆ, ಆದರೆ ಎಂಜಿನಿಯರಿಂಗ್ ಮತ್ತು ದತ್ತಾಂಶ ತಂಡಗಳು ಮಾಪನ ಮತ್ತು ಗುರಿ ನಿರ್ಧಾರವನ್ನು ಹೇಗೆ ವಿನ್ಯಾಸಗೊಳಿಸುತ್ತವೆ ಎಂಬುದನ್ನು ಇದು ರೂಪಿಸಬೇಕು:

- ಪರಿಣಾಮ ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ ಅಥವಾ ಲಾಭ ಕ್ಯಾಲ್ಕುಲೇಟರ್ ನಿರ್ಮಿಸುವಾಗ, ಕೇವಲ ಒಟ್ಟು ಲಾಭದ ಮೊತ್ತವಲ್ಲದೆ ಯಾರು ಪ್ರಭಾವಿತರು ಎಂಬ ಆದಾಯ ಅಥವಾ ವಂಚಿತತೆಯ ವಿವರವನ್ನು ತೋರಿಸಿ; ವಿತರಣಾ ವಿಭಜನೆ ಇಲ್ಲದ ಒಟ್ಟು ಅಂಕಿಗಳು ಮೇಲೆ ತೋರಿಸಿದ ತಿರುವನ್ನೇ ಮರೆಮಾಡುತ್ತವೆ.
- ಸೇವಾ ವಿನ್ಯಾಸದ ಗುರಿ ನಿರ್ಧಾರದ ತರ್ಕವನ್ನು ಗ್ರೀನ್ ಬುಕ್ ಬಳಸುವ ಅದೇ ವಂಚಿತತೆಯ ದತ್ತಾಂಶಕ್ಕೆ ಜೋಡಿಸಿ ([ಬಹು ವಂಚಿತತೆ ಸೂಚ್ಯಂಕ](../ಬಹು-ವಂಚಿತತೆ-ಸೂಚ್ಯಂಕ/) ನೋಡಿ); ಇದರಿಂದ ಡಿಜಿಟಲ್ ಸೇವೆಯ ವ್ಯಾಪ್ತಿಯನ್ನು ದಕ್ಷತೆಗಷ್ಟೇ ಅಲ್ಲ, ಸಮಾನತೆಗೂ (ವಿವಾದಾತ್ಮಕ ನಾಲ್ಕನೇ E, [ಹಣಕ್ಕೆ ತಕ್ಕ ಮೌಲ್ಯ](../ಹಣಕ್ಕೆ-ತಕ್ಕ-ಮೌಲ್ಯ/)) ಮೌಲ್ಯಮಾಪನ ಮಾಡಬಹುದು.
- ಅಲ್ಪ ಸಂಪನ್ಮೂಲವನ್ನು (ನೇಮಕಾತಿ ಸಮಯಗಳು, ಪ್ರಕರಣ ಕಾರ್ಯಕರ್ತರ ಸಮಯ, ಸಬ್ಸಿಡಿ) ಅಲ್ಗಾರಿದಮ್ ಹಂಚಿದಾಗ, ತೂಕರಹಿತ "ಒಟ್ಟು ಲಾಭ ಗರಿಷ್ಠಗೊಳಿಸಿ" ಉದ್ದೇಶ ಕಾರ್ಯವು ರಚನೆಯಿಂದಲೇ, ಗ್ರೀನ್ ಬುಕ್‌ನ ತೂಕ ನೀಡಿಕೆ ಸರಿಪಡಿಸಲು ಇರುವ ಅದೇ ಪಕ್ಷಪಾತವನ್ನು ಪುನರುತ್ಪಾದಿಸುತ್ತದೆ; ಅತ್ಯುತ್ತಮೀಕರಿಸುವ ಮೊದಲು ಇದನ್ನು ನೀತಿ ಮಾಲೀಕರಿಗೆ ಸ್ಪಷ್ಟವಾಗಿ ತಿಳಿಸಿ.

## ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳು

- **ಒಂದು ಪೋರ್ಟ್‌ಫೋಲಿಯೋದಾದ್ಯಂತ ವಿತರಣಾ ತೂಕಗಳನ್ನು ಅಸಮಂಜಸವಾಗಿ ಅನ್ವಯಿಸುವುದು.** ಒಂದು ಕಾರ್ಯಕ್ರಮದ ಲಾಭಗಳಿಗೆ ತೂಕ ನೀಡಿ, ಅದರ ಹೋಲಿಕೆಯ ಕಾರ್ಯಕ್ರಮಕ್ಕೆ ನೀಡದಿರುವುದು ನ್ಯಾಯಯುತವಲ್ಲದ, ಪಕ್ಷಪಾತದ ಹೋಲಿಕೆಯನ್ನು ನೀಡುತ್ತದೆ; ಗ್ರೀನ್ ಬುಕ್ ಸಮಾನ ಆಧಾರದ ಚಿಕಿತ್ಸೆಯನ್ನು ಬೇಡುತ್ತದೆ.
- **ಹೊಂದಾಣಿಕೆ ಇಲ್ಲದೆ ಆಸ್ತಿ ಅಥವಾ ಮಾರುಕಟ್ಟೆ ಮೌಲ್ಯಗಳನ್ನು ಕಲ್ಯಾಣದ ಪ್ರತಿನಿಧಿಯಾಗಿ ಬಳಸುವುದು.** ಮಾರುಕಟ್ಟೆ ಬೆಲೆಗಳು ಈಗಿರುವ ಆದಾಯ ಅಸಮಾನತೆಯಿಂದಲೇ ವಿರೂಪಗೊಂಡಿವೆ, ಮತ್ತು ವಿತರಣಾ ತೂಕ ನೀಡಿಕೆ ಸರಿಪಡಿಸಲು ಇರುವುದೇ ಅದನ್ನು; ಹೊಂದಾಣಿಕೆ ಇಲ್ಲದ ಮಾರುಕಟ್ಟೆ ಮೌಲ್ಯಗಳು ಪಕ್ಷಪಾತವನ್ನು ಎರಡು ಬಾರಿ ಎಣಿಸಬಹುದು.
- **ಗುಂಪಿನೊಳಗಿನ ಭಿನ್ನತೆಯನ್ನು ನಿರ್ಲಕ್ಷಿಸುವುದು.** ಪ್ರದೇಶದ ಸರಾಸರಿ ಆದಾಯದ ಆಧಾರದ ತೂಕ ನೀಡಿಕೆ (ಉದಾ. ಬಹು ವಂಚಿತತೆ ಸೂಚ್ಯಂಕದ ಒಂದು ದಶಮಾಂಶ ವರ್ಗ) ತಮ್ಮ ಪ್ರದೇಶದ ಸರಾಸರಿಗೆ ಹೊಂದದ ವ್ಯಕ್ತಿಗಳನ್ನು ತಪ್ಪಾಗಿ ಪ್ರತಿನಿಧಿಸಬಹುದು; ಸಮಂಜಸವಾಗಿ ಲಭ್ಯವಿರುವ ಅತ್ಯಂತ ಸೂಕ್ಷ್ಮ ಮಟ್ಟದ ಆದಾಯ ದತ್ತಾಂಶವನ್ನು ಬಳಸಿ.
- **1.3 ಸ್ಥಿತಿಸ್ಥಾಪಕತೆಯನ್ನು ಸಾರ್ವತ್ರಿಕ ಸ್ಥಿರಾಂಕವೆಂದು ಪರಿಗಣಿಸುವುದು.** ಇದು ಸಮಂಜಸ ವ್ಯಾಪ್ತಿಯಿರುವ ಅಂದಾಜು ಎಂದು ಗ್ರೀನ್ ಬುಕ್ ಸ್ವತಃ ಹೇಳುತ್ತದೆ; 1.3 ಅನ್ನು ನಿಖರವೆಂದು ಪರಿಗಣಿಸದೆ, ಪ್ರಮುಖ ನಿರ್ಧಾರಗಳನ್ನು ಪರ್ಯಾಯ ಸ್ಥಿತಿಸ್ಥಾಪಕತೆಗಳ ವಿರುದ್ಧ ಸಂವೇದನಾ-ಪರೀಕ್ಷೆ ಮಾಡಿ.
