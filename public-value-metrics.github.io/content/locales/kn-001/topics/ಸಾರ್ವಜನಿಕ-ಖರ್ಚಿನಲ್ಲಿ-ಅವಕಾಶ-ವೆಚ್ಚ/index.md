# ಸಾರ್ವಜನಿಕ ಖರ್ಚಿನಲ್ಲಿ ಅವಕಾಶ ವೆಚ್ಚ

ಅವಕಾಶ ವೆಚ್ಚ ಎಂದರೆ ಸಾರ್ವಜನಿಕ ಸಂಸ್ಥೆಯೊಂದು ಹಣ, ಸಿಬ್ಬಂದಿ ಸಮಯ ಅಥವಾ ರಾಜಕೀಯ ಬಂಡವಾಳವನ್ನು ಒಂದು ಆಯ್ಕೆಗೆ ಬದ್ಧಗೊಳಿಸಿದಾಗ ಬಿಟ್ಟುಕೊಟ್ಟ ಅತ್ಯುತ್ತಮ ಪರ್ಯಾಯದ ಮೌಲ್ಯ. ನಿಗದಿತ ಬಜೆಟ್ ಇರುವ
ಇಲಾಖೆಯಲ್ಲಿ ಒಂದು ಕಾರ್ಯಕ್ರಮಕ್ಕೆ ಖರ್ಚು ಮಾಡಿದ ಪ್ರತಿ ಪೌಂಡ್, ಮುಂದಿನ ಉತ್ತಮ ಕಾರ್ಯಕ್ರಮಕ್ಕೆ ಖರ್ಚು ಮಾಡಲಾಗದ ಪೌಂಡ್ — ನಿರ್ಧಾರದ ನಿಜವಾದ ವೆಚ್ಚ ಅದು ಖರ್ಚು ಮಾಡುವುದಲ್ಲ,
ಅದು ಸ್ಥಳಾಂತರಿಸುವುದು.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಸಾರ್ವಜನಿಕ ಬಜೆಟ್‌ಗಳು ಖರ್ಚು ಪರಿಶೀಲನಾ ಅವಧಿಯೊಳಗೆ ನಗದು-ಮಿತಿಗೊಳಪಟ್ಟಿವೆ; ಆದ್ದರಿಂದ ಬೆಳೆಯುತ್ತಿರುವ ಖಾಸಗಿ ಸಂಸ್ಥೆಯಂತೆ ಅಲ್ಲದೆ, ಸರ್ಕಾರಿ ಇಲಾಖೆ ಒಳ್ಳೆಯ ಕಲ್ಪನೆಗೆ ಸುಮ್ಮನೆ "ಹೆಚ್ಚು ಹಣ ಹುಡುಕಲಾಗದು";
ಅದಕ್ಕೆ ಹಣ ನೀಡುವುದೆಂದರೆ ಬೇರೆ ಯಾವುದರ ಹಣವನ್ನು ನಿಲ್ಲಿಸುವುದು. HM Treasury ಯ Green Book ಇದನ್ನು ಮೂಲಭೂತವೆಂದು ಪರಿಗಣಿಸುತ್ತದೆ: ಪ್ರತಿ ಮೌಲ್ಯಮಾಪನವೂ ಮಧ್ಯಸ್ಥಿಕೆಯನ್ನು "ಕನಿಷ್ಠ ಮಾಡು"
ಆಧಾರರೇಖೆಯೊಂದಿಗೆ *ಮತ್ತು* ಅದೇ ಸಂಪನ್ಮೂಲದ ವಾಸ್ತವಿಕ ಪರ್ಯಾಯ ಬಳಕೆಗಳೊಂದಿಗೆ ಹೋಲಿಸಬೇಕು; ಏಕೆಂದರೆ Treasury ಖರ್ಚು ತಂಡ ಕೇಳುವ ನಿಜವಾದ ಪ್ರಶ್ನೆ "ಇದು ಒಳ್ಳೆಯದೇ?" ಅಲ್ಲ, "ಈ ಹಣ ಬೇರೆ ಏನನ್ನು
ಕೊಳ್ಳಬಹುದಿತ್ತೋ ಅದಕ್ಕಿಂತ ಇದು ಉತ್ತಮವೇ?" ಎಂಬುದು. ಸಾರ್ವಜನಿಕ ಸಂಪನ್ಮೂಲಗಳು ಪ್ರತಿ ಪೌಂಡ್‌ಗೆ ಅತ್ಯಧಿಕ ನಿವ್ವಳ ಸಾಮಾಜಿಕ ಮೌಲ್ಯದ ಮಧ್ಯಸ್ಥಿಕೆಗೆ ಹರಿಯಬೇಕು ಎಂಬ Green Book ನ ಮೂಲ ಮೌಲ್ಯಮಾಪನ
ತತ್ವ ನೀತಿಯಾಗಿ ಹೇಳಿದ ಅವಕಾಶ ವೆಚ್ಚವೇ.

ಇದನ್ನು ಹೇಳುವುದು ಸುಲಭ, ಅನ್ವಯಿಸುವುದು ಕಷ್ಟ, ಏಕೆಂದರೆ "ಮುಂದಿನ ಉತ್ತಮ ಪರ್ಯಾಯ" ಒಂದೇ ವ್ಯವಹಾರ ಪ್ರಕರಣದಲ್ಲಿ ವಿರಳವಾಗಿ ಕಾಣುತ್ತದೆ. ಯುವ ಉದ್ಯೋಗಕ್ಕಾಗಿ £2 ಮಿಲಿಯನ್ ಅನುದಾನ ಕಾರ್ಯಕ್ರಮವನ್ನು
ವ್ಯವಹಾರ ಪ್ರಕರಣದಲ್ಲಿ ಏನೂ ಮಾಡದಿರುವುದರೊಂದಿಗೆ ಹೋಲಿಸಲಾಗುತ್ತದೆ — ಆದರೆ ಪ್ರಾಮಾಣಿಕ ಹೋಲಿಕೆ ಮುಂದಿನ ಉತ್ತಮ ಯುವ ಉದ್ಯೋಗ ಮಧ್ಯಸ್ಥಿಕೆ, ಅಥವಾ ಉದ್ಯೋಗೇತರ ಖರ್ಚು ಸೇರಿದಂತೆ ಇಡೀ ಸಂಯೋಜನೆಯಲ್ಲಿ ಎಲ್ಲಿಯಾದರೂ
£2 ಮಿಲಿಯನ್‌ನ ಮುಂದಿನ ಉತ್ತಮ ಬಳಕೆ. Magenta Book (HM Treasury, 2020) "ಮಧ್ಯಸ್ಥಿಕೆಯೊಂದಿಗೆ" ಮತ್ತು "ಮಧ್ಯಸ್ಥಿಕೆಯಿಲ್ಲದೆ" ಹೋಲಿಸುವ ಮೌಲ್ಯಮಾಪನಗಳು ಮಧ್ಯಸ್ಥಿಕೆ ದಾಟಬೇಕಾದ ಮಿತಿಯನ್ನು ಕಡಿಮೆ ಅಂದಾಜಿಸುತ್ತವೆ
ಎಂದು ಸ್ಪಷ್ಟವಾಗಿ ಎಚ್ಚರಿಸುತ್ತದೆ, ಏಕೆಂದರೆ "ಈ ಮಧ್ಯಸ್ಥಿಕೆಯಿಲ್ಲದೆ" ಎಂದರೆ "ಏನೂ ಇಲ್ಲದೆ" ಎಂದಲ್ಲ — ಬಿಡುಗಡೆಯಾದ ಹಣ ಬೇರೇನನ್ನೋ ಪೋಷಿಸುತ್ತದೆ.

## ಗಣಿತ

```
Opportunity cost of choosing A = value of the best forgone alternative B

Net public value of A = value(A) − value(B), not value(A) − 0
```

ಸಾರ್ವತ್ರಿಕ ಸೂತ್ರವಿಲ್ಲ, ಏಕೆಂದರೆ ಬಿಟ್ಟುಕೊಟ್ಟ ಪರ್ಯಾಯ ಸಂದರ್ಭಕ್ಕೆ ಅನುಗುಣವಾದದ್ದು; ಆದರೆ ಶಿಸ್ತು ಸಾಮಾನ್ಯೀಕರಿಸುತ್ತದೆ: ಅದೇ ಬಜೆಟ್ ಸಾಲಿನ ವಾಸ್ತವಿಕ ಮುಂದಿನ ಉತ್ತಮ ಬಳಕೆಯನ್ನು
(ಆದರ್ಶೀಕೃತ "ಏನೂ ಮಾಡದಿರುವುದು" ಅಲ್ಲ) ಗುರುತಿಸಿ, ಅದೇ ಆಧಾರದಲ್ಲಿ ಮೌಲ್ಯ ಕಟ್ಟಿ ([ಸಾಮಾಜಿಕ ವೆಚ್ಚ-ಲಾಭ ವಿಶ್ಲೇಷಣೆ](../ಸಾಮಾಜಿಕ-ವೆಚ್ಚ-ಲಾಭ-ವಿಶ್ಲೇಷಣೆ/) ಪ್ರಕಾರ, ಸಾಧ್ಯವಿದ್ದಲ್ಲಿ ಹಣದಲ್ಲಿ), ಕಳೆಯಿರಿ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

**ಇಲಾಖೆಯ ಬಜೆಟ್ ಸಾಲು**: £5 ಮಿಲಿಯನ್ ಡಿಜಿಟಲ್-ಪರಿವರ್ತನೆ ನಿಧಿ ಈ ಹಣಕಾಸು ವರ್ಷ ಎರಡು ಪ್ರಸ್ತಾವನೆಗಳಲ್ಲಿ ನಿಖರವಾಗಿ ಒಂದಕ್ಕೆ ಮಾತ್ರ ಹಣ ನೀಡಬಲ್ಲದು.

- *ಆಯ್ಕೆ A*: ಹೊಸ ಪ್ರಕರಣ-ನಿರ್ವಹಣಾ ವೇದಿಕೆ, ಹಣಕಾಸು ರೂಪದ ಪ್ರಯೋಜನ 5 ವರ್ಷಗಳಲ್ಲಿ £7.2 ಮಿಲಿಯನ್ (ದಕ್ಷತೆಯ ಉಳಿತಾಯ ಮತ್ತು ವೇಗದ ಪ್ರಕರಣ ಪರಿಹಾರ).
- *ಆಯ್ಕೆ B*: ಮೂರು ಇಲಾಖೆಗಳಲ್ಲಿ ಹಂಚಿಕೊಂಡ ಗುರುತು-ಪರಿಶೀಲನಾ ಸೇವೆ, ಹಣಕಾಸು ರೂಪದ ಪ್ರಯೋಜನ 5 ವರ್ಷಗಳಲ್ಲಿ £6.4 ಮಿಲಿಯನ್.

A ಯ ಮುಗ್ಧ ವ್ಯವಹಾರ ಪ್ರಕರಣ £7.2 ಮಿಲಿಯನ್ ಪ್ರಯೋಜನವನ್ನು £5 ಮಿಲಿಯನ್ ವೆಚ್ಚದೊಂದಿಗೆ ಹೋಲಿಸಿ 1.44:1 ಪ್ರಯೋಜನ-ವೆಚ್ಚ ಅನುಪಾತವನ್ನು ವರದಿ ಮಾಡುತ್ತದೆ — ಮೇಲ್ನೋಟಕ್ಕೆ ಬಲವಾಗಿದೆ.
ಆದರೆ A ಮತ್ತು B ಎರಡೂ ಅದೇ £5 ಮಿಲಿಯನ್‌ಗಾಗಿ ಸ್ಪರ್ಧಿಸುವುದರಿಂದ, A ಅನ್ನು ಆರಿಸುವ ಅವಕಾಶ ವೆಚ್ಚ B ಯ £6.4 ಮಿಲಿಯನ್ ಬಿಟ್ಟುಕೊಟ್ಟ ಪ್ರಯೋಜನ. ವಾಸ್ತವಿಕ ಪರ್ಯಾಯದ ಮೇಲೆ A ಯ
*ನಿವ್ವಳ* ಪ್ರಕರಣ ಕೇವಲ £7.2m − £6.4m = £0.8 ಮಿಲಿಯನ್, ಪೂರ್ಣ £7.2 ಮಿಲಿಯನ್ ಮುಖ್ಯ ಅಂಕಿಅಂಶವಲ್ಲ. ಅದೇ £5 ಮಿಲಿಯನ್‌ಗೆ ಮೂರನೇ ಆಯ್ಕೆ C £7.5 ಮಿಲಿಯನ್ ಪ್ರಯೋಜನ ನೀಡಿದ್ದರೆ,
A ಯನ್ನು C ಗಿಂತ ಮೊದಲು ಹಣಕಾಸು ನೀಡುವುದು, A ಯ ಸ್ವಂತ ವ್ಯವಹಾರ ಪ್ರಕರಣ ಒಂಟಿಯಾಗಿ ಸಂಪೂರ್ಣ ಸಮರ್ಥನೀಯವೆಂದು ತೋರಿದರೂ £0.3 ಮಿಲಿಯನ್ ಸಾರ್ವಜನಿಕ ಮೌಲ್ಯವನ್ನು ನಾಶಮಾಡುತ್ತಿತ್ತು.

**ಸ್ಥಳೀಯ ಪ್ರಾಧಿಕಾರದ ಸಿಬ್ಬಂದಿ ಸಮಯ**: ಪುರಸಭೆಯ ಮೂವರ ಡೇಟಾ ತಂಡ ಒಂದೋ ವಸತಿ-ಕಾಯ್ದಿರಿಸುವ ಪಟ್ಟಿ ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ (ವರ್ಷಕ್ಕೆ 400 ಅಧಿಕಾರಿ-ಗಂಟೆ ಉಳಿತಾಯ ಎಂದು ಅಂದಾಜು,
ಗಂಟೆಗೆ £28 ರಂತೆ ಮೌಲ್ಯ = ವರ್ಷಕ್ಕೆ £11,200) ಅಥವಾ ಸೌಲಭ್ಯ-ವಂಚನೆ ವಿಂಗಡಣಾ ಸಾಧನ (ವರ್ಷಕ್ಕೆ £85,000 ತಪ್ಪು ಪಾವತಿಗಳನ್ನು ತಡೆಯುವುದೆಂದು ಅಂದಾಜು) ಕಟ್ಟಬಹುದು. ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ ಕಟ್ಟುವ ಅವಕಾಶ
ವೆಚ್ಚ ವರ್ಷಕ್ಕೆ £85,000 ಬಿಟ್ಟುಕೊಟ್ಟದ್ದು, ಕೇವಲ ಡೇಟಾ ತಂಡದ ಸಂಬಳ ವೆಚ್ಚವಲ್ಲ — "ಉಚಿತ" ಆಂತರಿಕ ನಿರ್ಮಾಣದ ನಿಜವಾದ ವೆಚ್ಚ, ತಂಡ ಬೇರೆಡೆ ಉತ್ಪಾದಿಸಬಹುದಾಗಿದ್ದ ಅದಕ್ಕಿಂತ ಬಹಳ ದೊಡ್ಡ ಪ್ರಯೋಜನ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್ ಸಂಪರ್ಕ

ಸಾರ್ವಜನಿಕ ಸಂಸ್ಥೆಯೊಳಗಿನ ಎಂಜಿನಿಯರಿಂಗ್ ಸಾಮರ್ಥ್ಯವೇ ಒಂದು ಸೀಮಿತ ಬಜೆಟ್ — ಪೌಂಡ್‌ಗಳಲ್ಲ, ಸ್ಪ್ರಿಂಟ್ ಸಾಮರ್ಥ್ಯ — ಮತ್ತು ಅದೇ ಶಿಸ್ತು ನೇರವಾಗಿ ಅನ್ವಯಿಸುತ್ತದೆ:

- ಹೋಲಿಕೆಯ ಆಯ್ಕೆಯನ್ನು ಯಾವಾಗಲೂ ಹೆಸರಿಸಿ: ಒಂದು ವೈಶಿಷ್ಟ್ಯದ ವ್ಯವಹಾರ ಪ್ರಕರಣ ತನ್ನದೇ ಪ್ರತಿಫಲವನ್ನಷ್ಟೇ ಅಲ್ಲ, ಅದೇ ತಂಡ-ವಾರಗಳು ಬೇರೆ ಏನನ್ನು ತಲುಪಿಸಬಹುದು ಎಂಬುದನ್ನೂ ಹೇಳಬೇಕು.
- "ನಮ್ಮಲ್ಲಿ ಹೆಚ್ಚುವರಿ ಎಂಜಿನಿಯರಿಂಗ್ ಸಾಮರ್ಥ್ಯವಿದೆ" ಎಂಬುದನ್ನು ಅವಕಾಶ-ವೆಚ್ಚ ವಿಶ್ಲೇಷಣೆಯ ಅಂತ್ಯವಲ್ಲ, ಆರಂಭ ಎಂದು ಪರಿಗಣಿಸಿ — ಹೆಚ್ಚುವರಿ ಸಾಮರ್ಥ್ಯಕ್ಕೂ ಅತ್ಯುತ್ತಮ ಪರ್ಯಾಯ ಬಳಕೆ ಇರುತ್ತದೆ,
  ಅದು ತಾಂತ್ರಿಕ ಸಾಲ ತೀರಿಸುವುದಾದರೂ ಸರಿ (ನೋಡಿ [ಸಾರ್ವಜನಿಕ ಮೌಲ್ಯ ಸವೆತವಾಗಿ ತಾಂತ್ರಿಕ ಸಾಲ](../ತಾಂತ್ರಿಕ-ಸಾಲ-ಸಾರ್ವಜನಿಕ-ಮೌಲ್ಯದ-ಸವೆತ/)).
- ಇದನ್ನು ನೇರವಾಗಿ [ಹಣಕ್ಕೆ ತಕ್ಕ ಮೌಲ್ಯ](../ಹಣಕ್ಕೆ-ತಕ್ಕ-ಮೌಲ್ಯ/) ದೊಂದಿಗೆ ಜೋಡಿಸಿ: ಪ್ರಾಮಾಣಿಕ ಅವಕಾಶ-ವೆಚ್ಚ ಹೋಲಿಕೆಯಿಲ್ಲದೆ VFM ನ "ಮಿತವ್ಯಯ" ಪರೀಕ್ಷೆ ಅರ್ಥಹೀನ; ಮತ್ತು
  ಅದೇ ಬಿಟ್ಟುಕೊಟ್ಟ-ಪರ್ಯಾಯ ತರ್ಕದ ಸಮಯದ ಆಯಾಮಕ್ಕೆ ಬೆಲೆ ಕಟ್ಟುವ [ಸಾರ್ವಜನಿಕ ಕಾರ್ಯಕ್ರಮಗಳಲ್ಲಿ ವಿಳಂಬದ ವೆಚ್ಚ](../ಸಾರ್ವಜನಿಕ-ಕಾರ್ಯಕ್ರಮಗಳಲ್ಲಿ-ವಿಳಂಬದ-ವೆಚ್ಚ/) ದೊಂದಿಗೂ.

## ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳು

- **ಮುಂದಿನ ಉತ್ತಮ ಪರ್ಯಾಯದ ಬದಲು "ಏನೂ ಮಾಡದಿರುವುದ"ರೊಂದಿಗೆ ಹೋಲಿಸುವುದು.** ನಿಜವಾದ ಅವಕಾಶ ವೆಚ್ಚ ವಿರಳವಾಗಿ ಸೊನ್ನೆಯಾಗಿರುವುದರಿಂದಲೇ Green Book "ಕನಿಷ್ಠ ಮಾಡು" ಆಧಾರರೇಖೆಯನ್ನು ಅಗತ್ಯಪಡಿಸುತ್ತದೆ;
  "ಏನೂ ಮಾಡದಿರುವ" ಮಿತಿಯನ್ನಷ್ಟೇ ದಾಟುವ ವ್ಯವಹಾರ ಪ್ರಕರಣ ವಾಸ್ತವಿಕ ಪರ್ಯಾಯವನ್ನು ಮೀರಿಸಿದೆ ಎಂದು ತೋರಿಸಿಲ್ಲ.
- **ಅದೇ ಹಣದ ಮಡಕೆಗಾಗಿ ಅಂತರ-ಇಲಾಖೆ ಸ್ಪರ್ಧೆಯನ್ನು ನಿರ್ಲಕ್ಷಿಸುವುದು.** ಒಂದು ನಿರ್ದೇಶನಾಲಯದೊಳಗೆ ಮೀಸಲಾದಂತೆ ಕಾಣುವ ಬಜೆಟ್ ಸಾಲುಗಳು ಹೆಚ್ಚಾಗಿ ಉನ್ನತ ಮಟ್ಟದಲ್ಲಿ (ಖರ್ಚು ಪರಿಶೀಲನೆ, ಬಂಡವಾಳ ಕಾರ್ಯಕ್ರಮ)
  ಸ್ಪರ್ಧಿಸುತ್ತವೆ; ನಿಜವಾದ ಅವಕಾಶ ವೆಚ್ಚ ಅಲ್ಲಿ ಸಾಕಾರವಾಗುತ್ತದೆ.
- **ಬಿಡುಗಡೆಯಾದ ಸಿಬ್ಬಂದಿ ಸಮಯಕ್ಕೆ ಮುಂದಿನ ಮೌಲ್ಯ ಸೊನ್ನೆ ಎಂದು ಭಾವಿಸುವುದು.** "ಉಳಿತಾಯ"ವಾದ ಸಮಯವು ಮೌಲ್ಯಯುತವಾದ ಬೇರೆ ಕೆಲಸಕ್ಕೆ ಮರುನಿಯೋಜಿಸಿದರೆ ಮಾತ್ರ ಮೌಲ್ಯ ಸೃಷ್ಟಿಸುತ್ತದೆ;
  ಪರ್ಯಾಯ ಬಳಕೆ ಇಲ್ಲದಿದ್ದರೆ ಉಳಿತಾಯ ಕಾಲ್ಪನಿಕ.
