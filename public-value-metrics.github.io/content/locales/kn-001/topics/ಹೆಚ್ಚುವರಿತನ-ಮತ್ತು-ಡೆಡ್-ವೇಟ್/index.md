# ಹೆಚ್ಚುವರಿತನ ಮತ್ತು ಡೆಡ್‌ವೇಟ್

ಹೆಚ್ಚುವರಿತನ (additionality) ಎಂದರೆ, ಒಂದು ಮಧ್ಯಸ್ಥಿಕೆಯು ಬೇರೆ ರೀತಿಯಲ್ಲಿ ಆಗದಿದ್ದ ಫಲಿತಾಂಶವನ್ನು ನಿಜಕ್ಕೂ ಉಂಟುಮಾಡಿತೇ ಎಂದು ಕೇಳುವುದು. ಡೆಡ್‌ವೇಟ್ (deadweight) ಅದರ ಪ್ರತಿಬಿಂಬ: ಕಾರ್ಯಕ್ರಮ, ಅನುದಾನ ಅಥವಾ ಸಬ್ಸಿಡಿ ಇಲ್ಲದಿದ್ದರೂ ಹೇಗಾದರೂ ಸಂಭವಿಸುತ್ತಿದ್ದ ಫಲಿತಾಂಶದ ಪಾಲು. ಸರ್ಕಾರಿ ಕಾರ್ಯಕ್ರಮ ಅಥವಾ ದತ್ತಿ ಸಂಸ್ಥೆಯ ಬಹುತೇಕ ಪ್ರತಿಯೊಂದು ಪರಿಣಾಮದ ಹೇಳಿಕೆಯೂ ಡೆಡ್‌ವೇಟ್ ಅನ್ನು ಕಳೆಯುವವರೆಗೆ ತನ್ನ ಪರಿಣಾಮವನ್ನು ಹೆಚ್ಚಿಸಿ ಹೇಳುತ್ತದೆ. ಇದೇ ಕಾರಣಕ್ಕೆ ಯುಕೆ ಮೌಲ್ಯಮಾಪನ ಮಾರ್ಗದರ್ಶನವು ಯಾವುದೇ ಮುಖ್ಯ ಸಂಖ್ಯೆಗೆ ಮಾಡುವ ಮೊದಲ ಮತ್ತು ಅತ್ಯಂತ ಮುಖ್ಯ ಹೊಂದಾಣಿಕೆ ಎಂದು ಇದನ್ನು ಪರಿಗಣಿಸುತ್ತದೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

"ನಾವು 500 ವ್ಯವಹಾರಗಳ ಬೆಳವಣಿಗೆಗೆ ಬೆಂಬಲ ನೀಡಿದೆವು" ಎಂಬುದು ಸಾಧನೆಯಂತೆ ಕೇಳಿಸುತ್ತದೆ. ಆದರೆ ಸ್ಥಳೀಯ ಆರ್ಥಿಕತೆ ಚೇತರಿಸಿಕೊಳ್ಳುತ್ತಿದ್ದುದರಿಂದ, ಬೇರೆ ಹಣಕಾಸಿನ ಮಾರ್ಗಗಳಿದ್ದುದರಿಂದ ಅಥವಾ ಕಾರ್ಯಕ್ರಮ ಆರಂಭವಾಗುವ ಮೊದಲೇ ಬೆಳವಣಿಗೆಯ ಹಾದಿಯಲ್ಲಿದ್ದುದರಿಂದ ಆ ವ್ಯವಹಾರಗಳಲ್ಲಿ 300 ಹೇಗಾದರೂ ಬೆಳೆಯುತ್ತಿದ್ದರೆ, ಕಾರ್ಯಕ್ರಮದ ನಿಜವಾದ ಹೆಚ್ಚುವರಿ ಕೊಡುಗೆ 500 ಅಲ್ಲ, 200. ಎಚ್‌ಎಂ ಟ್ರೆಜರಿಯ Magenta Book ಮತ್ತು ಎಚ್‌ಎಂ ಟ್ರೆಜರಿ/BIS ಸಂಸ್ಥೆಗಳ ದೀರ್ಘಕಾಲದ "Additionality Guide" (ಮೂಲತಃ ಪ್ರಾದೇಶಿಕ ಅಭಿವೃದ್ಧಿ ಮತ್ತು ಪುನರುಜ್ಜೀವನ ಕಾರ್ಯಕ್ರಮಗಳಿಗಾಗಿ ರೂಪಿಸಲಾಗಿದ್ದು, ಅಂದಿನಿಂದ ಯುಕೆ ಸರ್ಕಾರದ ಮೌಲ್ಯಮಾಪನದಲ್ಲಿ ವ್ಯಾಪಕವಾಗಿ ಬಳಕೆಯಾಗಿದೆ) ಡೆಡ್‌ವೇಟ್ ಅನ್ನು ಪ್ರಮಾಣಿತ ನಿವ್ವಳ-ಪರಿಣಾಮ ಹಂತಗಳ ಆರಂಭಿಕ ಹೊಂದಾಣಿಕೆಯಾಗಿ ಔಪಚಾರಿಕಗೊಳಿಸಿವೆ: ಒಟ್ಟು ಪರಿಣಾಮ ಮೈನಸ್ ಡೆಡ್‌ವೇಟ್, ಮೈನಸ್ ಸ್ಥಳಾಂತರ, ಮೈನಸ್ ಸೋರಿಕೆ, ಗುಣಕ ಪರಿಣಾಮಗಳಿಗೆ ಹೊಂದಿಸಿದರೆ, ನಿವ್ವಳ ಹೆಚ್ಚುವರಿ ಪರಿಣಾಮ. ಈ ಹಂತವನ್ನು ಬಿಟ್ಟುಬಿಡುವುದು, ಉದ್ದೇಶಪೂರ್ವಕವಾಗಿಯೋ ಅಲ್ಲದೆಯೋ, ಸಾರ್ವಜನಿಕ ಮತ್ತು ಸಾಮಾಜಿಕ ವಲಯದ ಪರಿಣಾಮದ ಹೇಳಿಕೆಗಳನ್ನು ಉಬ್ಬಿಸುವ ಅತ್ಯಂತ ಸಾಮಾನ್ಯ ಮಾರ್ಗ. ಹೋಲಿಕೆ ಗುಂಪು ಇಲ್ಲದೆ ಭಾಗವಹಿಸಿದವರ ಒಟ್ಟು ಫಲಿತಾಂಶಗಳನ್ನು ಮಾತ್ರ ಅಳೆಯುವ ಅನುದಾನ ಕಾರ್ಯಕ್ರಮವು ತನ್ನದೇ ಪರಿಣಾಮವನ್ನು ಹೇಗಾದರೂ ಆಗುತ್ತಿದ್ದುದರಿಂದ ಬೇರ್ಪಡಿಸಲು ಸಾಧ್ಯವಿಲ್ಲ.

ಡೆಡ್‌ವೇಟ್ ನಿಗದಿತ ಶೇಕಡಾವಾರು ಅಲ್ಲ; ಅದು ಸಂಪೂರ್ಣವಾಗಿ ನಿರ್ದಿಷ್ಟ ಜನಸಂಖ್ಯೆ ಮತ್ತು ಮಧ್ಯಸ್ಥಿಕೆಯ ಪ್ರತಿವಾಸ್ತವಿಕ ಸ್ಥಿತಿಯನ್ನು (counterfactual) ಅವಲಂಬಿಸಿದೆ ([ಪ್ರತಿವಾಸ್ತವಿಕ ವಿಶ್ಲೇಷಣೆ](../ಪ್ರತಿವಾಸ್ತವಿಕ-ವಿಶ್ಲೇಷಣೆ/) ನೋಡಿ). ಹಿಂದಿನ ಪ್ರಾದೇಶಿಕ ಅಭಿವೃದ್ಧಿ ಏಜೆನ್ಸಿಗಳ (Regional Development Agencies) ಅಡಿಯಲ್ಲಿ ನಡೆದ ಇಂಗ್ಲೆಂಡ್‌ನ ಪ್ರಾದೇಶಿಕ-ಅಭಿವೃದ್ಧಿ ಮೌಲ್ಯಮಾಪನಗಳು, ವ್ಯವಹಾರ ಬೆಂಬಲದ ಪ್ರಕಾರವನ್ನು ಅವಲಂಬಿಸಿ ಡೆಡ್‌ವೇಟ್ ದರಗಳು ಸಾಮಾನ್ಯವಾಗಿ 20–60% ವ್ಯಾಪ್ತಿಯಲ್ಲಿರುತ್ತವೆ ಎಂದು ಕಂಡುಕೊಂಡಿವೆ. ಆದ್ದರಿಂದಲೇ ವಿಶ್ವಾಸಾರ್ಹ ಕಾರ್ಯಕ್ರಮ ಮೌಲ್ಯಮಾಪನಗಳು ಒಂದೇ ಊಹಿತ ಸಂಖ್ಯೆಯ ಬದಲು ಡೆಡ್‌ವೇಟ್-ಹೊಂದಿಸಿದ ವ್ಯಾಪ್ತಿಯನ್ನು ವರದಿ ಮಾಡುತ್ತವೆ; ಹಾಗೂ National Lottery Community Fund ಮತ್ತು Big Society Capital ನಂತಹ ಹಣಕಾಸು ಒದಗಿಸುವವರು ಒಟ್ಟು ಭಾಗವಹಿಸುವವರ ಸಂಖ್ಯೆಯನ್ನು ವರದಿ ಮಾಡುವುದರ ಬದಲು ಫಲಿತಾಂಶ ವರದಿಯಲ್ಲಿ ಡೆಡ್‌ವೇಟ್ ಅನ್ನು ಸ್ಪಷ್ಟವಾಗಿ ಪರಿಹರಿಸುವಂತೆ ಅನುದಾನ ಪಡೆದವರನ್ನು ಕೇಳುತ್ತವೆ.

## ಗಣಿತ

ಯುಕೆ ಮೌಲ್ಯಮಾಪನ ಮಾರ್ಗದರ್ಶನದಲ್ಲಿ (Magenta Book; HM Treasury/BIS Additionality Guide; ESIF ಮತ್ತು ರಚನಾತ್ಮಕ-ನಿಧಿ ಮೌಲ್ಯಮಾಪನ ಮಾರ್ಗದರ್ಶನ) ನೀಡಿರುವ ಪ್ರಮಾಣಿತ ನಿವ್ವಳ-ಪರಿಣಾಮ ಹೊಂದಾಣಿಕೆ ಹಂತಗಳು:

```
ಒಟ್ಟು ಫಲಿತಾಂಶ
  − ಡೆಡ್‌ವೇಟ್       (ಹೇಗಾದರೂ ಆಗುತ್ತಿದ್ದುದು)
  − ಸ್ಥಳಾಂತರ        (ಬೇರೆಡೆಯಿಂದ ಸ್ಥಳಾಂತರಗೊಂಡ ಚಟುವಟಿಕೆ/ಪ್ರಯೋಜನ, ಹೊಸದಾಗಿ ಸೃಷ್ಟಿಯಾದುದಲ್ಲ — ನೋಡಿ
                       displacement-and-attribution)
  − ಸೋರಿಕೆ          (ಗುರಿ ಗುಂಪು/ಪ್ರದೇಶದ ಹೊರಗೆ ಸೇರುವ ಪ್ರಯೋಜನ)
  × ಗುಣಕ            (ಹೆಚ್ಚುವರಿ ಪರೋಕ್ಷ/ಪ್ರೇರಿತ ಆರ್ಥಿಕ ಚಟುವಟಿಕೆ, ಧನಾತ್ಮಕವಾಗಿದ್ದಲ್ಲಿ)
  = ನಿವ್ವಳ ಹೆಚ್ಚುವರಿ ಪರಿಣಾಮ
```

ಅನುಪಾತವಾಗಿ ಡೆಡ್‌ವೇಟ್ ದರ:

```
ಡೆಡ್‌ವೇಟ್ ದರ = ಮಧ್ಯಸ್ಥಿಕೆ ಇಲ್ಲದೆ ಸಂಭವಿಸುತ್ತಿದ್ದ ಫಲಿತಾಂಶಗಳು
                   / ಗಮನಿಸಿದ ಒಟ್ಟು ಫಲಿತಾಂಶಗಳು

ನಿವ್ವಳ ಹೆಚ್ಚುವರಿ ಫಲಿತಾಂಶಗಳು = ಒಟ್ಟು ಫಲಿತಾಂಶಗಳು × (1 − ಡೆಡ್‌ವೇಟ್ ದರ)
```

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

**ವ್ಯವಹಾರ-ಬೆಂಬಲ ಅನುದಾನ ಕಾರ್ಯಕ್ರಮ**: ಒಂದು ಪ್ರಾದೇಶಿಕ ಅನುದಾನ ಯೋಜನೆಯು, ಬೆಂಬಲ ಪಡೆದ 500 ವ್ಯವಹಾರಗಳು ಮುಂದಿನ ವರ್ಷ ಉದ್ಯೋಗವನ್ನು ಹೆಚ್ಚಿಸಿದವು ಎಂದು ವರದಿ ಮಾಡುತ್ತದೆ, ಪ್ರತಿಯೊಂದರಲ್ಲಿ ಸರಾಸರಿ 3 ಉದ್ಯೋಗಗಳು — ಅಂದರೆ 1,500 ಉದ್ಯೋಗಗಳ ಒಟ್ಟು ಹೇಳಿಕೆ.

ಬೆಂಬಲ ಪಡೆಯದ ಸಮಾನ ವ್ಯವಹಾರಗಳ ಹೊಂದಿಸಿದ ಹೋಲಿಕೆ ಗುಂಪು ([ಪ್ರತಿವಾಸ್ತವಿಕ ವಿಶ್ಲೇಷಣೆ](../ಪ್ರತಿವಾಸ್ತವಿಕ-ವಿಶ್ಲೇಷಣೆ/) ನೋಡಿ), ಅದೇ ಅವಧಿಯಲ್ಲಿ ಹೊಂದಿಸಿದ ಗುಂಪು ಹೇಗೆ ಕಾರ್ಯನಿರ್ವಹಿಸಿತು ಎಂಬುದರ ಆಧಾರದ ಮೇಲೆ, ಬೆಂಬಲ ಪಡೆದ ವ್ಯವಹಾರಗಳ ಉದ್ಯೋಗ ಬೆಳವಣಿಗೆಯ 40% ಹೇಗಾದರೂ ಆಗುತ್ತಿತ್ತು ಎಂದು ತೋರಿಸುತ್ತದೆ.

```
ಡೆಡ್‌ವೇಟ್ ದರ = 40%
ನಿವ್ವಳ ಹೆಚ್ಚುವರಿ ಉದ್ಯೋಗಗಳು = 1,500 × (1 − 0.40) = 900 ಉದ್ಯೋಗಗಳು
```

ಕಾರ್ಯಕ್ರಮದ ಪ್ರಾಮಾಣಿಕವಾಗಿ ವರದಿ ಮಾಡಬಹುದಾದ ಸಾಧನೆ 1,500 ಅಲ್ಲ, 900 ಉದ್ಯೋಗಗಳು — ಸ್ಥಳಾಂತರ ಅಥವಾ ಸೋರಿಕೆಯನ್ನು ಪರಿಗಣಿಸುವ ಮೊದಲೇ, ಕೇವಲ ಡೆಡ್‌ವೇಟ್ ಹೊಂದಾಣಿಕೆಯಿಂದ 40% ಇಳಿಕೆ.

**ದತ್ತಿ ಸಂಸ್ಥೆಯ ಉದ್ಯೋಗ ಕಾರ್ಯಕ್ರಮ**: ಒಂದು ದತ್ತಿ ಸಂಸ್ಥೆಯು ದೀರ್ಘಕಾಲದಿಂದ ನಿರುದ್ಯೋಗಿಗಳಾಗಿದ್ದ 200 ಜನರನ್ನು £600,000 ವೆಚ್ಚದಲ್ಲಿ ಉದ್ಯೋಗಗಳಿಗೆ ಸೇರಿಸುತ್ತದೆ (ಒಟ್ಟು, ಪ್ರತಿ ಸ್ಥಾನಕ್ಕೆ £3,000). ರಾಷ್ಟ್ರೀಯ ಕಾರ್ಮಿಕ-ಮಾರುಕಟ್ಟೆ ದತ್ತಾಂಶವು, ಯಾವುದೇ ಮಧ್ಯಸ್ಥಿಕೆ ಇಲ್ಲದಿದ್ದರೂ, ಹೋಲಿಸಬಹುದಾದ ದೀರ್ಘಕಾಲದ ನಿರುದ್ಯೋಗಿಗಳ ಗುಂಪಿನ ಸುಮಾರು 15% ಜನರು ಉದ್ಯೋಗ ಮಾರುಕಟ್ಟೆಯ ಸಹಜ ಚಲನೆಯಿಂದ ಅದೇ ಅವಧಿಯಲ್ಲಿ ಕೆಲಸ ಪಡೆಯುತ್ತಾರೆ ಎಂದು ತೋರಿಸುತ್ತದೆ.

```
ಡೆಡ್‌ವೇಟ್ ದರ = 15%
ನಿವ್ವಳ ಹೆಚ್ಚುವರಿ ಉದ್ಯೋಗ ಸೇರ್ಪಡೆಗಳು = 200 × (1 − 0.15) = 170
ಪ್ರತಿ ಹೆಚ್ಚುವರಿ ಸೇರ್ಪಡೆಯ ನಿಜವಾದ ವೆಚ್ಚ = £600,000 / 170 ≈ £3,529
```

ಒಟ್ಟು ಪ್ರತಿ-ಸೇರ್ಪಡೆ ವೆಚ್ಚದ ಅಂಕಿ (£3,000) ದತ್ತಿ ಸಂಸ್ಥೆಯ ಹೆಚ್ಚುವರಿ ಕೊಡುಗೆಯ ನಿಜವಾದ ವೆಚ್ಚವನ್ನು ಸುಮಾರು 15% ಕಡಿಮೆ ತೋರಿಸುತ್ತದೆ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್ ಸಂಪರ್ಕ

ಸಾರ್ವಜನಿಕ ಅಥವಾ ಸಾಮಾಜಿಕ ವಲಯಕ್ಕಾಗಿ ಪರಿಣಾಮ-ಮಾಪನ ಅಥವಾ ಅನುದಾನ-ನಿರ್ವಹಣಾ ಸಾಫ್ಟ್‌ವೇರ್ ನಿರ್ಮಿಸುವ ಯಾರಿಗೇ ಆದರೂ ಹೆಚ್ಚುವರಿತನ ಮತ್ತು ಡೆಡ್‌ವೇಟ್ ನೇರವಾಗಿ ಮುಖ್ಯ:

- ಫಲಿತಾಂಶ-ವರದಿ ವ್ಯವಸ್ಥೆಗಳು ಭಾಗವಹಿಸಿದವರ ಫಲಿತಾಂಶಗಳನ್ನು ಮಾತ್ರವಲ್ಲದೆ, ವಿನ್ಯಾಸದಲ್ಲೇ ಹೋಲಿಕೆ ಅಥವಾ ಆರಂಭಿಕ ಗುಂಪನ್ನು ದಾಖಲಿಸಬೇಕು. ಪ್ರತಿವಾಸ್ತವಿಕ ಸ್ಥಿತಿ ಇಲ್ಲದೆ ವ್ಯವಸ್ಥೆ ಬಿಡುಗಡೆಯಾದ ನಂತರ ಅದನ್ನು ಸೇರಿಸುವುದು, ಆರಂಭದಿಂದಲೇ ದಾಖಲಾತಿಯನ್ನು ನಿರ್ಮಿಸುವುದಕ್ಕಿಂತ ಹೆಚ್ಚು ಕಷ್ಟ ([ಪ್ರತಿವಾಸ್ತವಿಕ ವಿಶ್ಲೇಷಣೆ](../ಪ್ರತಿವಾಸ್ತವಿಕ-ವಿಶ್ಲೇಷಣೆ/) ನೋಡಿ).
- ಒಟ್ಟು ಭಾಗವಹಿಸುವವರ ಸಂಖ್ಯೆಯನ್ನು ಮಾತ್ರ ವರದಿ ಮಾಡುವ ಡ್ಯಾಶ್‌ಬೋರ್ಡ್‌ಗಳು ಹಣಕಾಸುದಾರರು ಮತ್ತು ಮೇಲ್ವಿಚಾರಣಾ ಸಂಸ್ಥೆಗಳಿಗೆ ವ್ಯವಸ್ಥಿತವಾಗಿ ಪರಿಣಾಮವನ್ನು ಅತಿಯಾಗಿ ತೋರಿಸುತ್ತವೆ. ಡೆಡ್‌ವೇಟ್ ಅಂದಾಜುಗಳು (ಮೌಲ್ಯಮಾಪನ ಸಾಹಿತ್ಯದಿಂದ ಅಥವಾ ಹೋಲಿಕೆ ಗುಂಪಿನಿಂದ) ಲಭ್ಯವಿದ್ದರೆ, ಸಾಫ್ಟ್‌ವೇರ್ ಒಟ್ಟು ಅಂಕಿಯ ಬದಲು ಅಲ್ಲ, ಅದರ ಜೊತೆಗೇ ಡೆಡ್‌ವೇಟ್-ಕಳೆದ ನಿವ್ವಳ ಅಂಕಿಯನ್ನೂ ತೋರಿಸಬೇಕು.
- ಇದು [ಸಾಮಾಜಿಕ ಹೂಡಿಕೆಯ ಪ್ರತಿಫಲ](../ಸಾಮಾಜಿಕ-ಹೂಡಿಕೆ-ಪ್ರತಿಫಲ/) ವಿಷಯಕ್ಕೆ ನೇರವಾಗಿ ಸಂಬಂಧಿಸಿದೆ. ಅದರ SROI ಅನುಪಾತವು ಕ್ಲೇಮ್ ಮಾಡಿದ ಒಟ್ಟು ಫಲಿತಾಂಶಗಳಿಂದ ಡೆಡ್‌ವೇಟ್ (ಮತ್ತು ಸ್ಥಳಾಂತರ) ಕಳೆದ ನಂತರವಷ್ಟೇ ವಿಶ್ವಾಸಾರ್ಹ. ಈ ಹಂತ ಬಿಟ್ಟುಬಿಡುವ SROI ಕ್ಯಾಲ್ಕುಲೇಟರ್ ಉಬ್ಬಿದ ಅನುಪಾತಗಳನ್ನು ನೀಡುತ್ತದೆ; ಅವು ಪರಿಶೀಲನೆಯಲ್ಲಿ ಉಳಿಯುವುದಿಲ್ಲ.

## ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳು

- **ಒಟ್ಟು ಫಲಿತಾಂಶಗಳೆಲ್ಲವೂ ಹೆಚ್ಚುವರಿ ಎಂಬಂತೆ ವರದಿ ಮಾಡುವುದು.** ಅನುದಾನ ಮತ್ತು ಕಾರ್ಯಕ್ರಮ ವರದಿಗಳಲ್ಲಿ ಇದು ಪರಿಣಾಮ-ಮಾಪನದ ಅತ್ಯಂತ ಸಾಮಾನ್ಯ ತಪ್ಪು; ಮುಖ್ಯ ಸಂಖ್ಯೆಯನ್ನು ಪ್ರಕಟಿಸುವ ಮೊದಲು "ಇದು ಹೇಗಾದರೂ ಆಗುತ್ತಿತ್ತೇ?" ಎಂದು ಯಾವಾಗಲೂ ಕೇಳಿ.
- **ಒಂದೇ ಡೆಡ್‌ವೇಟ್ ಶೇಕಡಾವಾರು ಎಲ್ಲೆಡೆ ಅನ್ವಯಿಸುತ್ತದೆ ಎಂದು ಭಾವಿಸುವುದು.** ಡೆಡ್‌ವೇಟ್ ವಲಯ, ಜನಸಂಖ್ಯೆ ಮತ್ತು ಸ್ಥಳೀಯ ಆರ್ಥಿಕ ಪರಿಸ್ಥಿತಿಗಳಿಗೆ ಅನುಗುಣವಾಗಿ ಬಹಳ ಬದಲಾಗುತ್ತದೆ; ಸಂಬಂಧವಿಲ್ಲದ ಮೌಲ್ಯಮಾಪನದ ಸಂಖ್ಯೆಯನ್ನು ಮರುಬಳಸುವ ಬದಲು ಹೋಲಿಕೆ ಗುಂಪು ಅಥವಾ ವಲಯ-ನಿರ್ದಿಷ್ಟ ಪುರಾವೆಯನ್ನು ಬಳಸಿ.
- **ಡೆಡ್‌ವೇಟ್ ಅನ್ನು ಸ್ಥಳಾಂತರದೊಂದಿಗೆ ಗೊಂದಲಗೊಳಿಸುವುದು.** ಡೆಡ್‌ವೇಟ್ ಅದೇ ಭಾಗವಹಿಸುವವರ ಪ್ರತಿವಾಸ್ತವಿಕ ಫಲಿತಾಂಶಗಳ ಬಗ್ಗೆ; ಸ್ಥಳಾಂತರ ಇತರ ಜನರು ಅಥವಾ ಸ್ಥಳಗಳ ಮೇಲಿನ ಪರಿಣಾಮಗಳ ಬಗ್ಗೆ — [ಸ್ಥಳಾಂತರ ಮತ್ತು ಕಾರಣಾರೋಪಣೆ](../ಸ್ಥಳಾಂತರ-ಮತ್ತು-ಕಾರಣ-ನಿರ್ಣಯ/) ನೋಡಿ. ಇವೆರಡನ್ನು ಬೆರೆಸಿದರೆ ಹೊಂದಾಣಿಕೆ ಎರಡು ಬಾರಿ ಅಥವಾ ಕಡಿಮೆ ಎಣಿಕೆಯಾಗುತ್ತದೆ.
- **ಭಾಗವಹಿಸಿದವರೇ ಸ್ವತಃ ವರದಿ ಮಾಡಿದ ಡೆಡ್‌ವೇಟ್.** ಫಲಾನುಭವಿಗಳಿಗೆ "ನಮ್ಮ ಸಹಾಯವಿಲ್ಲದೆ ಇದು ಆಗುತ್ತಿತ್ತೇ?" ಎಂದು ಕೇಳಿದರೆ ವ್ಯವಸ್ಥಿತವಾಗಿ ಕಡಿಮೆ ಡೆಡ್‌ವೇಟ್ ಅಂದಾಜುಗಳು ಬರುತ್ತವೆ (ಭಾಗವಹಿಸಿದವರು ಕಾರ್ಯಕ್ರಮಕ್ಕೆ ಶ್ರೇಯ ನೀಡುವ ಒಲವು ಹೊಂದಿರುತ್ತಾರೆ); ಸ್ವತಂತ್ರ ಹೋಲಿಕೆ ಗುಂಪು ಹೆಚ್ಚು ವಿಶ್ವಾಸಾರ್ಹ.
