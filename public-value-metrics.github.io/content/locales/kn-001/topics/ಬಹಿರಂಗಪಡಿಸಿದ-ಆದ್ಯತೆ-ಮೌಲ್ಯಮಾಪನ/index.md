# ಬಹಿರಂಗಪಡಿಸಿದ ಆದ್ಯತೆ ಮೌಲ್ಯಮಾಪನ

ಬಹಿರಂಗಪಡಿಸಿದ ಆದ್ಯತೆ ವಿಧಾನಗಳು ಜನರನ್ನು ನೇರವಾಗಿ ಕೇಳುವ ಬದಲು, ಸಂಬಂಧಿತ ಮಾರುಕಟ್ಟೆಯಲ್ಲಿ ಗಮನಿಸಬಹುದಾದ ವರ್ತನೆಯಿಂದ ಮಾರುಕಟ್ಟೆಯಿಲ್ಲದ ವಸ್ತುವಿನ ಮೌಲ್ಯವನ್ನು ಊಹಿಸುತ್ತವೆ. ಹೆಡೋನಿಕ್ ಬೆಲೆ ನಿರ್ಧಾರ
ಮತ್ತು ಪ್ರಯಾಣ-ವೆಚ್ಚ ವಿಧಾನ ಎರಡು ಮುಖ್ಯ ತಂತ್ರಗಳು: ಎರಡೂ ನಿಜವಾದ ವಹಿವಾಟಿನಿಂದ ಆರಂಭಿಸಿ, ನೇರವಾಗಿ ಎಂದೂ ಮಾರಾಟವಾಗದ ವಸ್ತುವಿಗೆ ಅಂತರ್ಗತ ಬೆಲೆಯನ್ನು ಹೊರತೆಗೆಯುತ್ತವೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

[ಹೇಳಿದ ಆದ್ಯತೆ](../ಹೇಳಿಕೆ-ಆದ್ಯತೆ-ಮೌಲ್ಯಮಾಪನ/) ವಿಧಾನಗಳು ಕಾಲ್ಪನಿಕ ಪ್ರಶ್ನೆ ಕೇಳುವಲ್ಲಿ, ಬಹಿರಂಗಪಡಿಸಿದ ಆದ್ಯತೆ ವಿಧಾನಗಳು ಜನರು ನಿಜವಾಗಿ ಏನಕ್ಕೆ ಪಾವತಿಸಿದರು ಎಂಬುದನ್ನು ಗಮನಿಸುತ್ತವೆ; ಇದನ್ನು Green Book,
ಉಳಿದೆಲ್ಲವೂ ಸಮಾನವಾದಾಗ ಸಾಮಾನ್ಯವಾಗಿ ಹೆಚ್ಚು ವಿಶ್ವಾಸಾರ್ಹ ಸಾಕ್ಷ್ಯವೆಂದು ಪರಿಗಣಿಸುತ್ತದೆ, ಏಕೆಂದರೆ ಇದು ಕಾಲ್ಪನಿಕ ಪಕ್ಷಪಾತಕ್ಕೆ ಒಳಪಡುವುದಿಲ್ಲ — ಹೆಡೋನಿಕ್ ಮನೆ-ಬೆಲೆ ಅಧ್ಯಯನದ ಪ್ರತಿಕ್ರಿಯಿಸುವವರು
ಅಳೆಯಲಾಗುತ್ತಿರುವ ಪ್ರೀಮಿಯಂ ಅಥವಾ ರಿಯಾಯಿತಿಯನ್ನು ನಿಜವಾಗಿ ಪಾವತಿಸಿದ್ದರು
(<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>,
Annex 2). ಹೆಡೋನಿಕ್ ಬೆಲೆ ನಿರ್ಧಾರ ಮಾರುಕಟ್ಟೆ ಬೆಲೆಯನ್ನು — ಸಾಮಾನ್ಯವಾಗಿ ಮನೆ ಬೆಲೆಗಳು — ವಸ್ತುವಿನ ಪ್ರತಿ ಲಕ್ಷಣದ ಅಂತರ್ಗತ ಬೆಲೆಗಳಾಗಿ ವಿಭಜಿಸುತ್ತದೆ; ಹೀಗೆ ಮನೆ ಬೆಲೆಯ ಮೇಲೆ ಪ್ರಭಾವ ಬೀರುವ ಇತರ ಪ್ರತಿ
ಲಕ್ಷಣವನ್ನು (ಗಾತ್ರ, ಸ್ಥಳ, ಶಾಲಾ ವ್ಯಾಪ್ತಿ) ಅಂಕಿಅಂಶದ ಮೂಲಕ ನಿಯಂತ್ರಿಸಿ, ಉದಾಹರಣೆಗೆ ಶಾಂತವಾದ ಅಥವಾ ಉತ್ತಮ ವಾಯು ಗುಣಮಟ್ಟದ ಸ್ಥಳದಲ್ಲಿ ವಾಸಿಸಲು ಕುಟುಂಬಗಳು ನಿಜವಾಗಿ ಪಾವತಿಸುವ ಬೆಲೆ ಪ್ರೀಮಿಯಂ ಅನ್ನು ವಿಶ್ಲೇಷಕರು ಪ್ರತ್ಯೇಕಿಸಬಹುದು.
ಪ್ರಯಾಣ-ವೆಚ್ಚ ವಿಧಾನ ಪ್ರವೇಶ ಶುಲ್ಕವಿಲ್ಲದ ಮನರಂಜನಾ ತಾಣಗಳಿಗೆ ಅದೇ ರೀತಿ ಮಾಡುತ್ತದೆ: ತಾಣಕ್ಕೆ ಪ್ರಯಾಣಿಸಲು ಜನರು ಖರ್ಚು ಮಾಡುವ ಸಮಯ ಮತ್ತು ಹಣ, ಆ ತಾಣ ಅವರಿಗೆ ಎಷ್ಟು ಮೌಲ್ಯದ್ದು ಎಂಬುದರ ಕೆಳ ಮಿತಿಯನ್ನು
ಬಹಿರಂಗಪಡಿಸುತ್ತದೆ, ಏಕೆಂದರೆ ಭೇಟಿಯ ಮೌಲ್ಯಕ್ಕಿಂತ ಹೆಚ್ಚಿನ ವೆಚ್ಚವನ್ನು ಯಾರೂ ಮಾಡುವುದಿಲ್ಲ.

ಎರಡೂ ವಿಧಾನಗಳಿಗೆ ರಚನಾತ್ಮಕ ಮಿತಿ ಇದೆ: ಅಸ್ತಿತ್ವದಲ್ಲಿರುವ ಮಾರುಕಟ್ಟೆ ವಹಿವಾಟಿನಲ್ಲಿ ಅಂತರ್ಗತವಾಗಿರುವುದನ್ನು ಮಾತ್ರ ಅವು ಮೌಲ್ಯೀಕರಿಸಬಲ್ಲವು. ವಿಮಾನ ಓಡುದಾರಿ ಹತ್ತಿರದ ಶಬ್ದ ಮನೆ ಬೆಲೆಗಳಲ್ಲಿ ಕಾಣಿಸುತ್ತದೆ,
ಏಕೆಂದರೆ ಶಬ್ದದ ಬಗ್ಗೆ ಕಾಳಜಿ ಇರುವವರು ಶಾಂತ ವಸತಿಗೆ ಹೋಗುತ್ತಾರೆ; ಯಾರೂ ಭೇಟಿ ನೀಡದ ಅಥವಾ ಹತ್ತಿರ ವಾಸಿಸದ ಜೀವಿಯ ಅಸ್ತಿತ್ವ ಮೌಲ್ಯ ಯಾವ ವಹಿವಾಟಿನಲ್ಲೂ ಕಾಣಿಸುವುದಿಲ್ಲ — ಆ ಅಂತರವನ್ನು ತುಂಬಲೆಂದೇ
[ಹೇಳಿದ ಆದ್ಯತೆ](../ಹೇಳಿಕೆ-ಆದ್ಯತೆ-ಮೌಲ್ಯಮಾಪನ/) ವಿಧಾನಗಳಿವೆ.

## ಗಣಿತ

```
Hedonic pricing:
  House price = f(structural attributes, location attributes,
                   environmental attribute of interest, ...)
  Estimate via regression; the coefficient on the environmental
  attribute (holding all else constant) is its implicit price.

  Implicit price of attribute X = ∂(House price) / ∂X

Travel-cost method:
  Visit rate (visits per capita from zone i) = f(travel cost from zone i,
                   substitute sites, socioeconomic controls)
  Estimate a demand curve for visits as a function of travel cost.
  Consumer surplus = area under the estimated demand curve
                    = value of the site to visitors
```

ಎರಡೂ ವಿಧಾನಗಳಿಗೆ ಅಂಕಿಅಂಶದ ದೃಷ್ಟಿಯಿಂದ ಸರಿಯಾದ ನಿಯಂತ್ರಣ ಗುಂಪು ಬೇಕು — ಗೊಂದಲಕಾರಿ ಲಕ್ಷಣವನ್ನು (ಹೆಡೋನಿಕ್) ಅಥವಾ ಹತ್ತಿರದ ಪರ್ಯಾಯ ತಾಣವನ್ನು (ಪ್ರಯಾಣ-ವೆಚ್ಚ) ಬಿಟ್ಟರೆ, ಅಂತರ್ಗತ ಬೆಲೆ ಮುಂಚಿತವಾಗಿ ಯಾವಾಗಲೂ
ಸ್ಪಷ್ಟವಲ್ಲದ ದಿಕ್ಕಿನಲ್ಲಿ ಪಕ್ಷಪಾತಕ್ಕೆ ಒಳಗಾಗುತ್ತದೆ; ಆದ್ದರಿಂದಲೇ Green Book Annex 2 ಕೇವಲ ಮುಖ್ಯ ಗುಣಾಂಕವನ್ನಲ್ಲ, ಹಿಂಜರಿತದ ನಿರ್ದಿಷ್ಟತೆ ಮತ್ತು ನಿಯಂತ್ರಣಗಳನ್ನೂ ವರದಿ ಮಾಡಬೇಕೆಂದು ಅಗತ್ಯಪಡಿಸುತ್ತದೆ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

**ರಾಷ್ಟ್ರೀಯ ಸರ್ಕಾರ**: Green Book ನ ಸ್ವಂತ ಇಂಗಾಲದ ನೆರಳು-ಬೆಲೆ ವಿಧಾನ ಭಾಗಶಃ ಹೆಡೋನಿಕ್ ಸಾಕ್ಷ್ಯವನ್ನು ಬಳಸುತ್ತದೆ, ಆದರೆ ಸರಳ ವಿವರಣಾತ್ಮಕ ಪ್ರಕರಣ ವಿಮಾನ ಶಬ್ದ. ಹಾರಾಟ-ಮಾರ್ಗ ಪ್ರದೇಶದ ಮನೆ ಮಾರಾಟ ಬೆಲೆಗಳನ್ನು ದೂರ-ತೂಕದ
ಶಬ್ದ ಒಡ್ಡಿಕೆಯ ವಿರುದ್ಧ, ಗಾತ್ರ, ವಯಸ್ಸು ಮತ್ತು ಶಾಲಾ ವ್ಯಾಪ್ತಿಯನ್ನು ನಿಯಂತ್ರಿಸಿ ಹಿಂಜರಿತ ಮಾಡುವ ಹೆಡೋನಿಕ್ ಅಧ್ಯಯನ, ಸರಾಸರಿ ಶಬ್ದ ಒಡ್ಡಿಕೆಯಲ್ಲಿ ಪ್ರತಿ 1 ಡೆಸಿಬಲ್ ಹೆಚ್ಚಳ ಮನೆ ಬೆಲೆಯಲ್ಲಿ 0.5% ಇಳಿಕೆಯೊಂದಿಗೆ ಸಂಬಂಧಿಸಿದೆ ಎಂದು ಕಂಡುಕೊಳ್ಳುತ್ತದೆ.
ಬಾಧಿತ ಪ್ರದೇಶದ ವಿಶಿಷ್ಟ £280,000 ಮನೆಗೆ:

```
Implicit price per decibel = £280,000 × 0.5% = £1,400 per household
Households affected by a 3dB increase from a new runway = 18,000
Aggregate implied cost of the noise increase = £1,400 × 3 × 18,000 = £75.6m
```

ಇದು ಒಂದು ಬಾರಿಯ ಬಂಡವಾಳೀಕೃತ ವೆಚ್ಚ (ಮನೆ ಬೆಲೆಯಲ್ಲಿ ಅಂತರ್ಗತ); ಪ್ರತ್ಯೇಕವಾಗಿ ಅಂದಾಜಿಸಿದ ವಾರ್ಷಿಕ ಶಬ್ದ-ಕಿರಿಕಿರಿ ವೆಚ್ಚ ಪ್ರವಾಹದ ವಿರುದ್ಧ ಇದನ್ನು ಎರಡು ಬಾರಿ ಎಣಿಸದಂತೆ ಮೌಲ್ಯಮಾಪನ ಜಾಗರೂಕರಾಗಿರಬೇಕು.

**ಚಾರಿಟಿ**: ಪರಿಸರ ಚಾರಿಟಿಯೊಂದು ಪ್ರವೇಶ-ಉಚಿತ ಪ್ರಕೃತಿ ಮೀಸಲು ಪ್ರದೇಶಕ್ಕೆ ಪ್ರಯಾಣ-ವೆಚ್ಚ ವಿಧಾನದಿಂದ ಮೌಲ್ಯ ಕಟ್ಟುತ್ತದೆ. ಭೇಟಿದಾರರ ಅಂಚೆ ಸಂಕೇತಗಳ ಸಮೀಕ್ಷೆ ಡೇಟಾ, Green Book ಶಿಫಾರಸು ಮಾಡಿದ ಕೆಲಸೇತರ ಸಮಯ ಮೌಲ್ಯದಲ್ಲಿ ಸಮಯ
ಮತ್ತು ಇಂಧನ ಸೇರಿ, ಪ್ರತಿ ಭೇಟಿಗೆ ಸರಾಸರಿ ಸುತ್ತು-ಪ್ರಯಾಣ ವೆಚ್ಚ £14 ನೀಡುತ್ತದೆ, ವರ್ಷಕ್ಕೆ 40,000 ಭೇಟಿಗಳು. ಅಂದಾಜಿಸಿದ ಬೇಡಿಕೆ ವಕ್ರರೇಖೆ — ವಲಯದಿಂದ ಪ್ರಯಾಣ ವೆಚ್ಚ ಹೆಚ್ಚಿದಂತೆ ಭೇಟಿ ದರ ಇಳಿಯುವುದು — ನಿಜವಾಗಿ ಖರ್ಚಾದ £14
ಮೇಲೆ ಪ್ರತಿ ಭೇಟಿಗೆ ಸುಮಾರು £9 ಗ್ರಾಹಕ ಹೆಚ್ಚುವರಿ ಸೂಚಿಸುತ್ತದೆ.

```
Total annual value = 40,000 visits × (£14 spent + £9 consumer surplus)
                    = 40,000 × £23 ≈ £920,000/year
```

ಇದು ಮೀಸಲು ಪ್ರದೇಶದ ಶೂನ್ಯ ಪ್ರವೇಶ-ಶುಲ್ಕ ಆದಾಯವನ್ನು ಬಹಳ ಮೀರಿಸುತ್ತದೆ, ಮತ್ತು ಹಣ ನೀಡುವವರಿಗೆ ವಾದ ಮಂಡಿಸುವಾಗ ತಾಣದ ಮನರಂಜನಾ ಮೌಲ್ಯಕ್ಕೆ ಚಾರಿಟಿಯ ವಿಶ್ವಸ್ತರಿಗೆ ಸಮರ್ಥನೀಯ ಅಂಕಿಅಂಶ ನೀಡುತ್ತದೆ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್ ಸಂಪರ್ಕ

ಬಹಿರಂಗಪಡಿಸಿದ ಆದ್ಯತೆ ಚಿಂತನೆ ಅಭ್ಯಾಸಕಾರರು ಅರಿಯುವುದಕ್ಕಿಂತ ಹೆಚ್ಚಾಗಿ ಸಾರ್ವಜನಿಕ ವಲಯದ ಉತ್ಪನ್ನ ವಿಶ್ಲೇಷಣೆಯಲ್ಲಿ ಕಾಣಿಸುತ್ತದೆ: ಉಚಿತ ಸರ್ಕಾರಿ ಡಿಜಿಟಲ್ ಸೇವೆಯ ಬಳಕೆ ಡೇಟಾ ತಾನೇ ಮೌಲ್ಯದ ಬಹಿರಂಗಪಡಿಸಿದ-ಆದ್ಯತೆ ಸಾಕ್ಷ್ಯ
(ಆವರ್ತನ, ಅಧಿವೇಶನ ಅವಧಿ, ಮತ್ತು — ಅತ್ಯಂತ ಸೂಚಕವಾಗಿ — ಪುನರಾವರ್ತಿತ ಮತ್ತು ಒಮ್ಮೆಯ ಬಳಕೆ ಮಾದರಿಗಳನ್ನು, ಪ್ರಯಾಣ-ವೆಚ್ಚ ಮಾದರಿ ಭೇಟಿ ಆವರ್ತನವನ್ನು ದೂರದ ವಿರುದ್ಧ ಪರಿಗಣಿಸುವಂತೆಯೇ ವಿಶ್ಲೇಷಿಸಬಹುದು). ಸೇವೆಗೆ
ನಿಜವಾದ ಪರ್ಯಾಯಗಳಿದ್ದಲ್ಲಿ (ಕಾಗದ ಮಾರ್ಗ, ದೂರವಾಣಿ ಮಾರ್ಗ), ಬದಲಿಗೆ ಡಿಜಿಟಲ್ ಮಾರ್ಗ ಬಳಸಲು ನಾಗರಿಕರು ಮಾಡುವ "ವೆಚ್ಚ" (ಸಮಯ, ಡೇಟಾ, ಸಾಧನ) ಅಂದಾಜಿಸಿ ಬಳಕೆಯೊಂದಿಗೆ ಹೋಲಿಸಬಹುದು, ಇದು ಪ್ರಯಾಣ-ವೆಚ್ಚ ತರ್ಕವನ್ನೇ
ನೇರವಾಗಿ ಪ್ರತಿಧ್ವನಿಸುತ್ತದೆ. [ಡಿಜಿಟಲ್ ಸೇವಾ ಮಾನದಂಡ](../ಡಿಜಿಟಲ್-ಸೇವಾ-ಮಾನದಂಡ/) ಮತ್ತು ನೇರ ಮಾರುಕಟ್ಟೆ ಬೆಲೆಯಿಲ್ಲದ ವಸ್ತುವಿಗೆ ನಿಖರವಾಗಿ ಇದೇ ಮೌಲ್ಯಮಾಪನ ಸಮಸ್ಯೆ ಎದುರಾಗುವ [ಮುಕ್ತ ಡೇಟಾದ ಮೌಲ್ಯ](../ಮುಕ್ತ-ಡೇಟಾದ-ಮೌಲ್ಯ/) ನೋಡಿ.

## ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳು

- **ಹೆಡೋನಿಕ್ ಮಾದರಿಗಳಲ್ಲಿ ಬಿಟ್ಟುಹೋದ ಚರಾಂಶ ಪಕ್ಷಪಾತ.** ಸಂಬಂಧಿತ ಲಕ್ಷಣವನ್ನು ಬಿಟ್ಟರೆ (ಮನೆ ಬೆಲೆ ಮತ್ತು ಆಸಕ್ತಿಯ ಪರಿಸರ ಚರ ಎರಡರೊಂದಿಗೂ ಸಂಬಂಧಿಸುವ ಶಾಲಾ ಗುಣಮಟ್ಟ), ಅಂತರ್ಗತ ಬೆಲೆ ಅಂದಾಜು ಪಕ್ಷಪಾತಕ್ಕೆ ಒಳಗಾಗುತ್ತದೆ;
  ಫಲಿತಾಂಶವನ್ನಷ್ಟೇ ಅಲ್ಲ, ನಿರ್ದಿಷ್ಟತೆಯನ್ನೂ ವರದಿ ಮಾಡಿ ಪರಿಶೀಲಿಸಬೇಕು.
- **ಪ್ರಯಾಣ-ವೆಚ್ಚ ಅಧ್ಯಯನಗಳಲ್ಲಿ ಪರ್ಯಾಯ ತಾಣಗಳನ್ನು ನಿರ್ಲಕ್ಷಿಸುವುದು.** ಹತ್ತಿರದ ಪರ್ಯಾಯ ಇದ್ದು ನಿಯಂತ್ರಿಸದಿದ್ದರೆ, ತಾಣದ ಬಗ್ಗೆ ಭೇಟಿದಾರರ ಬಹಿರಂಗಪಡಿಸಿದ ಮೌಲ್ಯ ಕಡಿಮೆ ಅಂದಾಜಾಗುತ್ತದೆ — ಅವರು ಮುಖ್ಯವಾಗಿ
  ಅದು ಉಚಿತವೆಂಬ ಕಾರಣಕ್ಕೆ ಭೇಟಿ ನೀಡುತ್ತಿರಬಹುದು, ಅದು ವಿಶಿಷ್ಟವಾಗಿ ಮೌಲ್ಯಯುತವೆಂಬ ಕಾರಣಕ್ಕಲ್ಲ.
- **ಮಾರುಕಟ್ಟೆ ಪ್ರತಿಧ್ವನಿಯೇ ಇಲ್ಲದ ವಸ್ತುವಿಗೆ ಬಹಿರಂಗಪಡಿಸಿದ ಆದ್ಯತೆ ಅನ್ವಯಿಸುವುದು.** ಅಸ್ತಿತ್ವ ಮೌಲ್ಯ, ಆಯ್ಕೆ ಮೌಲ್ಯ ಮತ್ತು ಪರಂಪರೆ ಮೌಲ್ಯ ಯಾವ ವಹಿವಾಟಿನಲ್ಲೂ ಕಾಣಿಸುವುದಿಲ್ಲ ಮತ್ತು ಹೆಡೋನಿಕ್ ಅಥವಾ
  ಪ್ರಯಾಣ-ವೆಚ್ಚ ವಿಧಾನಗಳಿಂದ ಮರುಪಡೆಯಲಾಗದು — ಆ ಅಂತರ [ಹೇಳಿದ ಆದ್ಯತೆ ಮೌಲ್ಯಮಾಪನ](../ಹೇಳಿಕೆ-ಆದ್ಯತೆ-ಮೌಲ್ಯಮಾಪನ/) ಕ್ಕೆ ಸೇರಿದ್ದು.
- **ಬಂಡವಾಳೀಕೃತ (ಒಮ್ಮೆಯ) ಮೌಲ್ಯವನ್ನು ವಾರ್ಷಿಕ ಹರಿವಿನೊಂದಿಗೆ ಗೊಂದಲ ಮಾಡುವುದು.** ಹೆಡೋನಿಕ್ ಮನೆ-ಬೆಲೆ ಪರಿಣಾಮಗಳು ಸಾಮಾನ್ಯವಾಗಿ ಒಮ್ಮೆಯ ಬಂಡವಾಳೀಕೃತ ಮೌಲ್ಯಗಳು;
  ಅವನ್ನು ವಾರ್ಷಿಕ ಪ್ರಯೋಜನ ಪ್ರವಾಹವೆಂದು ಪರಿಗಣಿಸಿದರೆ ಮೌಲ್ಯಮಾಪನ ಉಬ್ಬುತ್ತದೆ.
