# 额外性搭死重

额外性问个是:一项干预有否造成一个“勿搭仔伊就勿会发生”个成果。死重(deadweight)是伊个镜像:就算无没搿个项目、补助或者补贴,成果当中本来就会发生个搿部分比例。政府项目搭慈善机构讲个影响,基本上统统会高估效果,要等到扣脱死重以后才算数,所以英国个评估指南拿死重当作对任何标题数字第一桩、也是最要紧个一桩调整。

## 为啥重要

“阿拉扶持仔 500 家企业成长”听起来蛮有成绩,但是如果搿 500 家里向有 300 家就算无没扶持也会成长——因为本地经济勒浪恢复,因为伊拉还有其他融资渠道,因为项目开始之前伊拉就已经勒浪成长个轨道上——搿个项目真正个额外贡献就是 200 家,而勿是 500 家。英国财政部(HM Treasury)个 Magenta Book(评估指南),搭仔长期使用个 HM Treasury/BIS“Additionality Guide”(额外性指南,最早是为区域发展搭城市更新项目编个,后来英国政府评估普遍采用),拿死重正式定为标准净影响计算顺序个第一步调整:总效应减去死重,减去转移(displacement),减去外溢(leakage),再按乘数效应调整,得出净额外影响。跳过搿一步,是公共部门搭社会领域个影响声明被夸大个最常见原因,有意个也好,无意个也好——一个补助项目如果只量总参与者成果,又无没对照组,就分勿清楚成果到底是项目带来个,还是勿管哪能侪会发生个。

死重勿是一个固定个百分比;伊完全看特定人群搭特定干预个反事实(参见[反事实分析](../反事实分析/))。以前英格兰个区域发展署(Regional Development Agencies)做个区域发展评估,按企业扶持类型个勿同,经常发现死重率勒 20–60% 之间,所以靠得牢个项目评估会报告一个经过死重调整个区间,而勿是一个假定个单一数字;国家彩票社区基金(National Lottery Community Fund)搭 Big Society Capital 之类个出资方也要求受助者勒成果报告里明确处理死重,而勿是光报告总参与人数。

## 数学

英国评估指南(Magenta Book;HM Treasury/BIS Additionality Guide;ESIF 搭结构基金评估指南)规定个标准净影响调整顺序:

```
总成果
  − 死重          (勿搭仔也会发生个部分)
  − 转移          (活动/收益是从别处搬过来个,勿是新创造个 —— 参见
                       displacement-and-attribution)
  − 外溢          (落勒目标群体/区域以外个收益)
  × 乘数          (额外个间接/诱发经济活动,有正效应个辰光)
  = 净额外影响
```

死重率(用比例表示):

```
死重率 = 无没干预也会发生个成果
         / 观察到个总成果

净额外成果 = 总成果 × (1 − 死重率)
```

## 实例演算

**企业扶持补助项目**:一个区域补助计划报告讲 500 家受扶持企业第二年增加仔就业,平均每家 3 个岗位——总共声明 1,500 个岗位。

拿一组配对个、相似但勿受扶持个企业做对照组(参见[反事实分析](../反事实分析/)),根据配对组勒同一段辰光里向个表现,发现受扶持企业个就业增长里有 40% 本来就会发生。

```
死重率 = 40%
净额外岗位 = 1,500 × (1 − 0.40) = 900 个岗位
```

搿个项目可以老老实实报告个成绩是 900 个岗位,勿是 1,500 个——光是死重调整就减脱 40%,还呒没考虑转移搭外溢。

**慈善机构就业项目**:一家慈善机构帮 200 个长期失业个人安排仔工作,花费 £600,000(总共算每个安置 £3,000)。全国劳动力市场数据显示,就算无没任何干预,一批可比较个长期失业人群里,大约 15% 会勒同一段辰光里通过正常个就业市场流动自己寻着工作。

```
死重率 = 15%
净额外安置 = 200 × (1 − 0.15) = 170
真正每个额外安置个成本 = £600,000 / 170 ≈ £3,529
```

总数口径个每个安置成本(£3,000)低估仔搿家慈善机构额外贡献个真实成本,大约低估 15%。

## 搭软件工程个关联

对做公共部门或者社会领域影响测量软件、补助管理软件个人来讲,额外性搭死重是直接相关个:

- 成果报告系统应该勒设计辰光就收集对照组或者基线组,勿是光收集参与者个成果——系统上线以后再补一个反事实,比一开始就设计进去难得多(参见[反事实分析](../反事实分析/))。
- 光报告总参与人数个仪表盘,会系统性地向出资方搭监督机构夸大影响;只要有死重估计(来自评估文献或者对照组),软件就应该拿扣除死重以后个数字搭总数并排显示,而勿是用伊来代替总数。
- 搿个搭[社会投资回报率](../社会投资回报率/)直接相连:SROI 比率一定要从声称个总成果里扣脱死重(搭转移)以后才靠得牢——漏脱搿一步个 SROI 计算器,算出来个比率是虚高个,经勿起检验。

## 容易踏个坑

- **拿总成果当作统统是额外个来报告。** 搿是补助搭项目报告里最常见个影响测量错误;公布标题数字之前,总归要问一句“勿搭仔伊也会发生伐?”
- **以为一个死重百分比到处侪适用。** 死重因行业、人群搭本地经济情况勿同,差别交关大;要用对照组或者针对行业个证据,覅拿一个无关评估里个数字照搬。
- **拿死重搭转移混为一谈。** 死重讲个是同一批参与者个反事实成果;转移讲个是对别人或者别个地方个影响——参见[转移搭归因](../挤出效应搭归因/)。两样混勒一道,调整会重复计算或者少算。
- **靠参与者自己讲个死重。** 问受益人“无没阿拉帮忙搿桩事体会发生伐?”,得出来个死重估计总归偏低(参与者倾向于归功项目);独立个对照组要靠得牢得多。
