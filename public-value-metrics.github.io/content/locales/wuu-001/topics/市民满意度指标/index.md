# 市民满意度指标

市民满意度指标量个是人民对公共服务直接体验个评价——搭对机构个总体信任勿是一桩事体,搭服务到底有无取得好成果也勿是一桩事体。一项服务可以讨人欢喜但是勿起作用,也可以起作用但是勿讨人欢喜;两者之间个差距本身就是一份诊断信息,交付团队应该盯牢。

## 为啥重要

满意度勒两个勿同个层面上测量,但是经常被混为一谈。勒服务层面,英国现已退役个绩效平台(Performance Platform)搭现在个 GOV.UK 服务手册,要求每项服务做一份满意度问卷(通常是从“非常满意”到“非常勿满意”个五级量表,勒交易发生个当口发放),作为四项强制服务 KPI 之一——参见[服务标准搭交易指标](../服务标准搭交易指标/)。勒机构层面,英国《公务员人员调查》(Civil Service People Survey)每年测量每个中央政府部门个员工敬业度搭体验;另外 OECD 个“政府信任”(Trust in Government)项目调查各成员国民众对国家政府个信任,追踪一个长期下降再恢复个规律,深受危机影响(2008 年金融危机搭 COVID-19 疫情,侪使 OECD 信任数字出现明显个剧烈变动)。做面向市民服务个工程师为啥要拿满意度搭成果分开,是因为服务设计里有一个已知个失败模式:一份设计得漂亮、容易用个数字化福利申请表,满意度可以打得交关高,但是底下个政策——资格规则、处理积压、发放金额——并勿让申请人过得更好。满意度量个是界面;伊勿量背后交付个价值。

## 数学

```
净满意度 = 满意(或者非常满意)% − 勿满意(或者非常勿满意)%
           (中立/无意见个回答从两项里排除,但是勒计算每个百分比个
           回答基数里还是要算进去)

满意度-成果差距 = 满意度得分 − 成果达成得分
           (两者侪归一化到 0–100;大个正差距表示
           服务“感觉好”但是实质上交付勿足)

信任指数(OECD 式)= 调查对象里回答“是”个百分比,问题是
           “侬对[国家政府]有信心伐?”
           作为时间序列追踪,通常按
           年龄、收入搭教育程度分解
```

## 实例演算

**地方政府市政税电子账单服务**:勒交易成功个当口做个满意度问卷,显示 2,400 位回答者:1,650 位满意/非常满意,250 位勿满意/非常勿满意,500 位中立。

```
净满意度 = (1,650/2,400 × 100) − (250/2,400 × 100)
         = 68.75% − 10.42%
         = +58.3 净满意度
```

孤立地看,搿个数字蛮强。但是问卷只展示给*成功*完成交易个用户——是一个已知个测量偏差(见下面个坑)。拿伊搭[服务标准搭交易指标](../服务标准搭交易指标/)里个完成率指标配对一看,完成率只有 71%,意思是:

```
放弃仔流程个 29% 个人,真实个总体满意度是量勿到个 ——
伊拉多半是最勿满意个一群,因为放弃本身就是一个强烈个负面信号,
问卷永远收勿到。
```

**国家层面个示例(OECD 式信任序列个结构)**:对国家政府个信任,第 1 年报告 42%,第 2 年(危机年)降到 34%,第 3 年恢复到 39%——是 OECD 记录个各成员国勒重大危机以后冲击加部分恢复个典型轨迹。

## 搭软件工程个关联

勒用户旅程每一个有意义个出口侪要布设满意度问卷,勿光是成功完成个辰光——搿是搿个领域最常见个工程错误,会悄悄拿满意度指标变成有幸存者偏差个虚荣指标。可能个话,勒同一个仪表盘上拿满意度分数搭完成率或者成果指标配对,让团队勿好一面庆祝满意度上升,一面完成率悄悄下降(参见[每笔交易成本](../每笔交易成本/)搭[数字包容](../数字包容/),了解数字满意度抽样里到底哪些人一开始就被排除了——非数字用户搭辅助数字用户勒服务内问卷里系统性代表勿足)。满意度搭信任数据也直接喂给[Moore 战略三角](../公共价值/)里合法性个一条腿,属于[公共价值记分卡](../公共价值计分卡/)个“客户”搭“合法性”视角——参见[信任搭合法性指标](../信任搭合法性指标/),了解搿个服务层面指标对应个机构层面指标。

## 容易踏个坑

- **完成当口问卷个幸存者偏差**:放弃流程个用户永远看勿到问卷,所以服务内个高满意度分数,可以搭低完成率、搭一大批看勿见个勿满意个未完成者共存。
- **拿满意度当成果个代理指标**:为设计勿好个政策做个设计好个界面,满意度得分好,成果得分差——两样总归要一道报告,勿要拿一个当另一个个替身。
- **小而无代表性个样本,报告出虚假个精确度**:几百个自我选择个回答者得出个满意度分数,报告到小数点后一位,暗示仔样本量支撑勿起个置信度。
- **忽略人口特征分解**:国家层面个信任搭满意度数字,如果勿按年龄、收入、残障或者数字接入情况拆开,会掩盖各群体之间截然勿同个体验——OECD 自己个“政府信任”发布就明确做搿种分解。
