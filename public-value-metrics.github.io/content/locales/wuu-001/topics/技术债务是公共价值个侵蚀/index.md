# 技术债务是公共价值个侵蚀

技术债务是沃德·坎宁安 1992 年提出个比喻,指过去权宜个编码决定隐含个未来成本:一个**本金**(欠下个整改工作)搭一个**利息**(伊对交付持续施加个拖累)。辣老旧个政府 IT 资产里,搿个利息直接从公共价值里支付 — 法定变更交付更慢,面向市民个服务故障率更高,搭能够安全碰伊个系统个人越来越少。

## 为啥重要

英国政府各部门个大型机搭 COBOL 时代个遗留系统 — HMRC 搭 DWP 是被引用最多个 — 带有记录充分、而且勿断升级个风险,国家审计署(NAO)已经反复发出警告,包括辣伊个报告《政府数字化转型》(<https://www.nao.org.uk/>)里:老化个平台改起来昂贵、越来越难以保障安全,而且依赖一支退休速度快过补充速度个专业人员队伍。搭私营部门个积压勿一样,搿笔债务直接处辣市民搭伊拉法定权利之间 — 一个勿能安全修改个福利计算引擎,是政策交付个约束,勿光是工程上个麻烦。2013 年"全民福利"(Universal Credit)IT 项目个重启,当辰光国家审计署发现原来个建设勿会交付物有所值,软件资产个相当一部分要核销,是未定价个技术债务追上一个正辣运行、部长层面可见个公共项目个经典例子。

## 数学

```
SQALE 本金 = Σ 违规项(整改辰光)× 开发人员成本率
技术债务比率(TDR)= 整改成本 / 重新开发成本 × 100
                    (SonarQube 评级:A ≤5%,B ≤10%,C ≤20%,D ≤50%)

利息(证明偿还有道理个数字):
  利息/年 = Δ 交付速度 × 每单位速度个价值
          + Δ 面向市民个事故率 × 每次事故成本
          + 专业技能溢价 × 受影响人数
偿还个理由 = PV(期限内避免个利息)− 整改成本
             (按《绿皮书》社会贴现率贴现,见
             social-discount-rate.md)
```

本金说明负债;利息才是拿投资理由讲拨公共账目委员会听个东西。

## 实例演算

一个 250,000 行、用遗留 4GL 写个理赔处理引擎。采用 CAST Appmarq 基准,每行代码大约 $3.61 个技术债务本金(按通常汇率约 £2.85):

```
本金 ≈ 250,000 × £2.85 ≈ £712,500
TDR ≈ 16%(C 级)
```

实测个利息:因为内部技能流失,部门雇用三个专业承包商,日薪比标准高级工程师高 40% — 辣一个六人团队上每年多花 £180,000。搿个系统每年还造成四次重大处理中断,每次让大约 5,000 个申请人个决定暂停,并拿伊拉转到联络中心,每通电话大约 £25:

```
利息 ≈ £180,000(技能溢价)
     + 4 × 5,000 × £25 = £500,000(转移个联络成本)
     ≈ £680,000/年
```

对表现最差个模块做有针对性个整改,花费 £1,200,000,模型显示可以降低 70% 个利息:

```
利息减少 = 0.70 × 680,000 = £476,000/年
回收期 ≈ 1,200,000 / 476,000 ≈ 2.5 年
```

针对性要紧:整改难得碰个代码买勿到任何物事,因为利息集中辣变更频率搭债务密度双双最高个地方。

## 搭软件工程个关联

拿技术债务个理由从"代码老仔"提升上去个公共价值框架:拿遗留资产表达成一份清单,标出损失个交付能力集中辣啥地方,并且明确搭[总拥有成本](../政府-it-里个总拥有成本/)挂钩,因为利息是运营成本,勿管财务有呒没问过,伊侪应该放辣 TCO 一行里。债务缠身个系统也带来勿成比例个[网络安全](../公共部门网络安全个价值/)暴露,因为打补丁个节奏搭债务密度是相关个 — 一个打勿了补丁个遗留系统,是用事故风险而勿是英镑来付利息个技术债务。而且每一个整改对新功能个取舍,本身就是[延误成本](../公共项目个延迟成本/)决策:还债会延后下一次法定变更,伊自家个 CoD 必须搭节省下来个利息相权衡。

## 容易踏个坑

- **只报告本金**:一个庞大吓人个整改估算,呒没利息数字,对支出审批人来讲证明勿了任何物事。
- **拿工具生成个债务数字当真**:SQALE 式个扫描器数个是规则违规;伊拉会漏脱昂贵个那种债务 — 架构决策搭呒没文档个遗留业务规则 — 却标出一堆琐碎个事体。
- **"重写可以避免所有搿些"**:替换项目必须搭任何别个商业方案一样遵守同样个规矩 — 反事实成本、成功概率搭贴现 — 勿是豁免,2013 年全民福利重启就证明仔搿点。
- **债务清零个乌托邦主义**:最优债务水平勿是零;债务是买来更早交付个杠杆。真正个问题永远是利率,而勿是债务存勿存辣。
