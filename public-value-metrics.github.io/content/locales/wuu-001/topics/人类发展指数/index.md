# 人类发展指数（HDI）

HDI 是联合国对单靠收入给国家排名个做法提出个主打替代方案：伊拿预期寿命、教育搭收入合成一个 0 到 1 之间个数字，前提——由经济学家 Amartya Sen 提出，Mahbub ul Haq 为联合国发展出来——是发展讲个是扩大人们能做啥、能成为啥，而勿光是赚多少钞票。自 1990 年起，伊每年发表勒联合国开发计划署（UNDP）个《人类发展报告》（Human Development Report）里。

## 为啥重要

HDI 之前，"发展"几乎完全用人均 GNP 来衡量，而搿个数字对增长有呒没落到普通人个健康或者教育上，一句也讲勿出来。Sen 个能力方法（capability approach）拿发展重新定义成真实自由个扩大，而 ul Haq 拿搿个想法变成一个可以发表、UNDP 能够拿每个国家排名个指数，逼着那些单靠收入变富、却忽视健康或者教育个政府，面对一个比伊拉 GDP 暗示个更差个名次（海湾石油国家搭一些资源开采型经济体是标准例子）。HDI 个三维结构，也是 [多维贫困指数](../多维贫困指数/) 个方法论直系祖先：两者侪用几何平均而勿是算术平均，勿让一个维度买回另一个维度个短板。UNDP 公布每一版个完整技术说明搭底层数据（<https://hdr.undp.org/data-center/human-development-index>），对任何勒指数基础上做事、而勿是重新推导伊个人来讲，搿是权威个来源。

## 数学

```
Life Expectancy Index (LEI)     = (LE − 20) / (85 − 20)

Mean Years Schooling Index      = mean years of schooling / 15
Expected Years Schooling Index  = expected years of schooling / 18
Education Index (EI)            = (Mean Years Index + Expected Years Index) / 2

Income Index (II)               = (ln(GNI per capita) − ln(100)) / (ln(75000) − ln(100))

HDI = (LEI × EI × II) ^ (1/3)     [geometric mean of the three sub-indices]
```

用几何平均是有意为之：因为伊是相乘而勿是平均，一个维度上个很高分数无法完全抵消另一个维度上个很低分数——UNDP 勒 2010 年采用搿个设计，专门为了惩罚失衡，取代了之前个算术平均公式。

## 实例演算

**中等收入国家**：预期寿命 72 岁，平均受教育年限 8 年，预期受教育年限 13 年，人均 GNI $12,000。

```
LEI = (72 − 20) / (85 − 20)              = 52 / 65   = 0.800
MYSI = 8 / 15                                        = 0.533
EYSI = 13 / 18                                       = 0.722
EI = (0.533 + 0.722) / 2                             = 0.628
II = (ln(12000) − ln(100)) / (ln(75000) − ln(100))
   = (9.393 − 4.605) / (11.225 − 4.605)
   = 4.788 / 6.620                                   = 0.723

HDI = (0.800 × 0.628 × 0.723) ^ (1/3)
    = (0.363) ^ (1/3)                                ≈ 0.713
```

HDI 0.713 落勒 UNDP 个"高人类发展"区间（0.700–0.799）；"极高"从 0.800 开始。注意结果对最弱个分项指数有多敏感：假使平均受教育年限是 4 年，勿是 8 年（MYSI = 0.267，EI = 0.494），HDI 就跌到 (0.800 × 0.494 × 0.723)^(1/3) ≈ 0.639——掉了整整一个档次——虽然其他东西一样也呒没变。

## 搭软件工程个关联

- 几何平均个模式，可以直接重用勒任何综合服务或者产品评分上，只要侬勿想让一个强个维度掩盖一个关键个弱项——比方拿一项公共数字服务个无障碍、性能搭可靠性分数用相乘个办法，而勿是加权平均来合并，搿样一个快、但是勿无障碍个服务，就勿可能得"好"。
- HDI 对收入取对数（多一镑个边际价值递减），搭评估里 [分配权重](../分配权重/) 背后是同一个逻辑：多 $1,000 对穷人家比对富人家个意义大得多，对两者侪按线性处理，会给影响定错价。
- 任何报告单一混合个"数字包容"或者"市民成果"分数个仪表盘，侪应该像 UNDP 个技术说明那样，明确记录伊个汇总公式——参见 [公共部门 KPI](../公共部门个关键绩效指标/) 搭 [公共价值记分卡](../公共价值计分卡/)。

## 容易踏个坑

- **用平均而勿是几何平均**——算术平均让高收入完全遮掉健康或者教育个短板；2010 年方法论改动个全部意义，就是为了阻止搿种替代。
- **拿 HDI 逐年比较，好像伊是剔除通胀个 GDP**——UNDP 会定期重新设定基准（新个最小/最大边界、修订个受教育年限上限），所以名次变化可能反映方法更新，勿是真实个变化；一定要查清爽一个数字来自哪一版 HDR。
- **拿 HDI 当成贫困衡量指标**——伊是国家平均数，对一个国家内部个分配啥也勿讲；要看分配，请用 [多维贫困指数](../多维贫困指数/)，或者 UNDP 另外个不平等调整 HDI（Inequality-adjusted HDI）。
