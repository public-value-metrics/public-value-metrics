# 公共项目个延迟成本(CoD)

延迟成本(Cost of Delay)是一个项目、服务或者系统变更*还呒没*交付个辰光,每单位辰光损失个公共价值。伊是搿一组主题里最主要个桥梁指标:拿“上线推迟仔六个月”换算成每周多少镑,或者每周多少 WELLBY,让延迟好用搭业务案例本身同样个货币来争论。

## 为啥重要

Reinertsen 个规则——“如果侬只量化一桩事体,就量化延迟成本”——搬到政府里几乎勿用改,因为公共项目特别容易受伊影响:业务案例是对照预测个收益流批准个,但是收益流要到上线才开始流,每推迟一周,就是一周白白损失个价值,而风险登记册上无人给伊定价。英国国家审计署(National Audit Office)对 Universal Credit 推广个反复审查(参见其“Rolling Out Universal Credit”报告,<https://www.nao.org.uk/>)就是搿个规律个例子:进度滑坡有跟踪、有报告,但是把改革后个系统*还呒没*交付给下一批申请人个每周成本(多少镑),极少作为标题数字讲出来,尽管应该推动优先级排序搭升级个正是搿个数字。无没 CoD 数字,一个延迟个项目对交付委员会来讲看起来是进度问题;有仔伊,对会计官员来讲就是价值流失问题。

## 数学

```
CoD = 未交付期间损失个单位辰光收益   (£/周 或者 WELLBY/周)

总延迟损失 = CoD × 延迟时长

公共项目要加总个收益流:
  现金释放型节省     (减少欺诈/错误、避免个临时成本)
+ 非现金释放个产能   (个案/官员工时 × 含附加成本个成本)
+ 福祉收益           (WELLBY × £13,000/WELLBY,HMT《绿皮书》
                       福祉补充指引,2019 年价格)
```

对面向市民个服务,除仔钱以外还要用福祉计价——参见[福祉调整生命年](../福祉调整生命年/),了解底层单位;参见[公共支出个机会成本](../公共开支里厢个机会成本/),了解被延迟个搿一镑本来可以出资做啥。

## 实例演算

**地方政府**:一次住房福利系统升级,勒 20,000 个现有申请上,每个申请每年减少 £150 个多付错误。

```
年收益 = 150 × 20,000 = £3,000,000/年
CoD = 3,000,000 / 52 ≈ £57,700/周
实施延迟 12 个月,代价 52 × 57,700 ≈ £3,000,000 个本可避免个错误。
```

**中央政府机构**:一项残障福利评估服务,比计划晚交付六个月(26 周),意味着每年 200,000 个申请人要平均多等三周才有决定。每多一周财务勿确定性,按 −0.0018 个 WELLBY(生活满意度点)效应建模:

```
每个申请人个 WELLBY 损失 = 3 × 0.0018 = 0.0054
年 WELLBY 损失 = 200,000 × 0.0054 = 1,080 WELLBY/年
CoD_福祉 = 1,080 / 52 ≈ 20.8 WELLBY/周
CoD_金额 = 20.8 × £13,000 ≈ £270,000/周个福祉价值
```

所以 26 周个延迟“花掉”大约 540 个 WELLBY——按《绿皮书》个福祉估值大约值 700 万镑——拿一个错过个上线日期重新定性为市民福利事件,勿是项目管理个脚注。

## 搭软件工程个关联

CoD 让 [DORA 指标](../公共价值个-dora-指标/)搭[流动指标](../政府交付里个流动指标/)勒财务上看得懂:流水线里个前置辰光 × CoD,就是勒到达市民之前,勒队列里烧脱个钱(或者福祉)。具体来讲:

- **优先级排序**:按 CoD ÷ 工期给待办事项排序,勿是按干系人个资历——搿是《绿皮书》要求按价值、勿是按谁勒提要求来评估方案勒软件工程里个对应做法。
- **采购**:12–18 个月个框架采购周期有 CoD;给伊定价,会改变加速路线个紧迫性论证,也直接喂给[自建搭采购](../政府个自建搭采购/)决策,因为见效辰光是决策驱动因素。
- **收益案例**:批准个辰光引用个每个 CoD 数字,侪要勒[收益兑现](../收益兑现/)个辰光重新出现——如果延迟成本是真个,上线以后加速个收益应该量得出来。

## 容易踏个坑

- **假设 CoD 是线性个**:有些公共服务个价值是截止期限形状个(法定合规日期——日期之后 CoD 跳到执法风险水平,之前接近零),勿是平滑个周费率。相乘之前先分清紧迫性类型。
- **勒无人需要个产出上算 CoD**:只有未交付个东西有价值,延迟才有成本;一个无人会用个系统,再晚 CoD 也是零。
- **延迟搭折现重复计算**:[社会折现率](../社会贴现率/)已经勒多年评估期限上给辰光定仔价;CoD 是期限以内、按周按月个运营版本。进度滑坡用 CoD,多年重新分期用 NPV 平移。
