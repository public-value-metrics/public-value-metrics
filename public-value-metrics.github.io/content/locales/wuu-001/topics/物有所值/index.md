# 物有所值(VFM)

物有所值是英国公共部门个正式检验,看支出是否实现仔成本搭效益之间可得个最佳平衡。英国财政部《绿皮书》通过三个"E"来框定伊 — 经济性(economy)、效率(efficiency)搭效果(effectiveness) — 公平(equity)越来越多地被当作一个有争议个第四个 E。每一份经得起审查个公共部门商业方案,侪必须明确回答三样,勿能光是声称支出"值得"。

## 为啥重要

VFM 勿是"便宜"个同义词。《绿皮书》(英国财政部,2022 年版)明确讲,只买成本最低个方案(经济性)而勿检查伊是否产生预期成果(效果),是一个常见而且代价高昂个错误 — 一次采购辣单位成本上省 10%,但是交付个影响少 40%,是更差个价值,勿是更好。三 E 框架强迫商业方案拿三种真正勿同个失败模式分开:为投入付得太多、辣投入转化成产出个过程里浪费,搭产出勿能转化成呒人想要个成果。英国政府个支出控制 — 财政部个批准节点、国家审计署(NAO)个物有所值研究,搭部门会计官评估 — 侪围绕搿个三部分检验建立,所以一份只讲成本(经济性)个工程商业方案,哪怕技术上站得住,也过勿了审查。

"第四个 E"公平之所以有争议,恰恰因为伊会搭另外三个冲突:辣全国范围交付一项服务最有效率个办法,难得是最公平个,因为拿交付集中辣最便宜触达市民个地方,往往意味着对最难触达个人服务勿足。《绿皮书》2020 年修订回应仔批评(包括 2020 年财政部专责委员会搭 IPPR North 个批评),就是纯粹个成本效益比系统性地偏向已经富裕个地区,要求评估明确处理分配影响 — 见[分配加权](../分配权重/)。

## 数学

VFM 勿是单一个比率,而是一个三部分(或者四部分)个诊断,依次应用:

```
经济性:    投入是否以所需质量下最低个合理成本购入?
           (每单位投入个 £)

效率:      投入转化成产出转化得有多好?
           (产出 / 投入,比方每个个案工作者小时处理个案件数)

效果:      产出是否真个产生预期成果?
           (实现个成果 / 预期个成果)

[公平]:    成本搭效益辣人口里是否公平分配,
           还是集中辣最勿需要个人身上?
```

VFM 失败可以辣任何一个阶段独立发生:经济个采购搭勿高效个交付;高效交付错误个产出;以过高成本买来有效个成果。搿些哪能转化成可衡量个指标,见[公共部门个 KPI](../公共部门个关键绩效指标/);正式个比较方法见[政府里个成本效果分析](../政府个成本效益分析/)。

## 实例演算

**地方政府联络中心**:一个市议会比较新个案管理系统个两个方案。

- *方案 A*:£600,000 个许可证(可得最便宜),但是因为工作流要求辣系统之间手工重复录入,座席平均每件还是 22 分钟 — 效率差。
- *方案 B*:£900,000 个许可证,集成个工作流,座席平均每件 9 分钟。

光看经济性,A 占优(便宜 £300,000)。但是按每年 40,000 件,A 要 40,000 × 22/60 = 14,667 个员工小时;B 要 40,000 × 9/60 = 6,000 个员工小时。按每小时 £28 个全额员工成本,A 每年花 £410,667 员工辰光,B 每年 £168,000 — 每年 £242,667 个效率差距,14 个月之内就盖过 £300,000 个前期经济性差异。算进效率之后,VFM 偏向 B,勿是 A。

**慈善机构交付资助**:一个出资方比较两笔资助:£50,000 实现 200 个成功就业安置(每个安置 £250 — 看起来经济性老好),对 £120,000 实现 350 个安置,搭第一笔资助个安置相比(一半辣 3 个月之内中断),第二笔个安置维持 12 个月以上。效果 — 持久个成果 — 翻转仔表面个 VFM 排名:每个*持久*安置个真实成本,第一笔资助是 £250 ÷ 0.5 = £500,第二笔是 £120,000/350 ≈ £343。

## 搭软件工程个关联

VFM 拨工程团队一套规矩,可以用财务搭审计部门实际会看个方式来框定技术商业方案:

- 辣商业方案里拿经济性、效率搭效果当作独立个明细项列出,勿是一个混合个"价值"数字 — 受过《绿皮书》训练个评审人会正好要求搿个分解。
- 当心为仔优化采购成本(经济性)而牺牲集成搭工作流效率,搿是政府 IT 里非常常见个虚假节省(见[政府 IT 里个总拥有成本](../政府-it-里个总拥有成本/)搭[政府里自建还是购买](../政府个自建搭采购/))。
- 效果要求成果数据,勿光是产出计数 — 拿交付指标连到[成果搭产出](../成果搭产出/),并且通过[反事实分析](../反事实分析/)连到真正个评估,勿要假定产出就意味着成果。
- 当一个系统辣勿同地区或者人群之间服务勿均衡,公平问题是一个正当个 VFM 反对意见,勿是单独个"加分项" — 见[数字包容](../数字包容/)。

## 容易踏个坑

- **拿 VFM 等同于最低价格。** 经济性只占检验个三分之一(或者四分之一);《绿皮书》明确警告勿要用忽视效率搭效果个"最低成本"采购规则。
- **衡量产出,却叫伊成果。** 个案吞吐量(效率)搭个案处理得好(效果)勿是一回事;见[成果搭产出](../成果搭产出/)。
- **拿公平当作可选个。** 自从《绿皮书》2020 年更新,分配影响应该搭传统个三个 E 一道评估,勿是事后附加;辣商业方案批准之后再补,比一开始就纳入要难得多。
- **勿同规模个方案勿经归一化就比较。** 服务勿同人口个方案之间做单位 VFM 比较,必须控制规模,否则效率比较就呒没意义。
