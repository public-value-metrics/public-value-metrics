# 数字包容

数字包容(digital inclusion)是一门确保“数字优先”勿变成“只有数字”个功夫——围绕最便宜渠道设计个公共服务,对勿会或者勿肯无人帮忙就自己用个市民,照样要行得通。GDS 创造仔具体个交付机制“辅助数字”(assisted digital),作为每项政府数字服务个强制要求,勿是可有可无个附加品。

## 为啥重要

2012 年《政府数字战略》清清爽爽定下仔目标:数字服务要按数字优先来建,但是战略本身承认,英国大约 10% 个成年人无人帮忙用勿来,并且承诺各部门提供辅助数字支持——一条有人参与个路径,通过电话、当面或者中介——作为服务个一部分,勿是后头再硬加个单独兜底。搿个承诺现在就是[数字服务标准](../数字服务标准/)第 5 条:“确保每个人侪好用搿项服务”。持续排斥个规模,由 Lloyds Banking Group 个年度英国消费者数字指数(UK Consumer Digital Index)追踪:2024 年版发现英国大约还有 160 万人勿上网,而且搿一群人明显偏向 70–79 岁个人、收入低于 £35,000 个人,以及退休或者失业个人——恰恰是最有可能依赖正勒被重新设计个公共服务个人群。同一份报告发现,英国劳动力里只有 48% 个人可以完成“基本数字技能”框架里个全部 20 项任务,意味着排斥勿是一个有网无网个二元问题,是技能、信心搭信任个光谱,一个简单个“有无宽带”指标完全漏脱仔。

## 数学

数字包容是一个框架搭公平检验,勿是一个单一公式,但是伊通过[分配加权](../分配权重/)搭定量价值评估结合:

```
天真个渠道转移价值:
  价值 = 转移量 × (旧成本 − 数字成本)     [参见 channel-shift-savings]

经包容调整个价值:
  价值 = (转移量 × 未加权节省)
       − (被排斥用户 × 辅助数字供给成本)
       − (对因失去接入或者服务质量下降而受害个
          被排斥群体个分配权重调整)

辅助数字勿是失败个剩余成本 —— 伊是一个设计出来个渠道,
有自己个[每笔交易成本](../每笔交易成本/),
通常每笔交易比自助数字高得多,
但是通常还是比伊部分替代个旧渠道便宜。
```

## 实例演算

**Universal Credit 式个全国福利服务**:每年 250 万个申请,按《政府数字战略》个规划假设,估计 10% 个申请人需要辅助数字支持。

```
被排斥/辅助数字人群 = 2,500,000 × 10% = 250,000 个申请/年

辅助数字渠道成本(电话 + 当面支持,
配备人手处理脆弱性搭复杂性)≈ £9.50/申请
  = 250,000 × £9.50 = £2,375,000/年

另外 90% 个自助数字成本 ≈ £0.40/申请
  = 2,250,000 × £0.40 = £900,000/年

混合每笔交易成本 = (2,375,000 + 900,000) / 2,500,000
  = £1.31/申请

一个为仔达到更低标题每笔交易成本而跳过辅助数字个设计
(比方混合 £0.40,忽略 250,000 个被排斥个申请人),
勿会消除搿 237.5 万镑个成本 —— 只是拿伊转化成
未领取个权益、申诉,以及落勒完全勿同预算上个
下游危机服务需求。
```

## 搭软件工程个关联

辅助数字是一个设计出来个渠道,意味着伊像任何别个渠道一样有接口、SLA 搭仪表化:一个基于电话个个案工作人员工具、一个给公民咨询局(Citizens Advice)或者地方政府用个中介门户,或者一个当面个自助终端流程。拿伊当事后个补丁——小字印个电话号码,勿是从发现阶段起就考虑个渠道——是服务勒评估辰光未通过[数字服务标准](../数字服务标准/)第 5 条最常见个原因。数字包容是搿一组里每个别个主题个公平镜头:伊给[渠道转移节省](../渠道转移节省/)能够多激进地兑现设了上限,伊是必须老实计入[每笔交易成本](../每笔交易成本/)个一个成本项,也是[分配加权](../分配权重/)直接应用勒数字服务场景:一笔勿成比例地落勒本来就被数字搭经济排斥个人身上个节省,应该降权,勿应该当作搭均匀摊勒全人口身上个节省等价。

## 容易踏个坑

- **拿“数字优先”读成“只有数字”**:数字使用率一过门槛,就关脱电话线或者柜台,而勿核实剩下个人群有无真正好用个替代。
- **用有无联网个二元标准衡量包容**:“有宽带”或者“有智能手机”,是衡量完成一项具体交易个能力个糟糕代理指标——基本数字技能个差距(Lloyds 2024:英国劳动力只有 48% 个人完成全部 20 项任务)说明技能搭信心搭接入一样要紧。
- **拿辅助数字当舍入误差来算成本**:预算里只放一条小个应急线,勿是一个有自己[每笔交易成本](../每笔交易成本/)个正式渠道,然后勒上线个辰光发现经费勿够、人手勿够,觉得意外。
- **只调查成功完成个数字用户**:完全勒服务内做个满意度搭可用性研究,漏脱仔根本走勿到搿一步个人,而伊拉恰恰是数字包容工作要保护个人群。
