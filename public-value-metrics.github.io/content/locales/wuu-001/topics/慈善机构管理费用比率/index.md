# 慈善机构管理费用比率

慈善机构管理费用比率(overhead ratio),是行政搭筹款支出占总支出个百分比。伊是慈善捐赠里被要求最多个一个数字——捐赠者、监督机构,甚至有些出资方侪拿伊当效率个代理指标——也是行业里被驳得最彻底个效率指标之一,当初普及搿个指标个机构自己勒 2013 年公开否定仔伊。

## 为啥重要

2013 年 6 月 17 日,GuideStar、BBB Wise Giving Alliance 搭 Charity Navigator——美国三家最大个非营利组织评级搭信息机构,伊拉自己历史上个评级帮助拿管理费用比率固化成衡量慈善机构质量个简便讲法——联合向美国捐赠者发表仔一封公开信《The Overhead Myth》,明确讲管理费用比率是衡量慈善机构绩效个糟糕指标,敦促捐赠者转而看透明度、治理搭成果。搿是当初围绕搿个比率建立起捐赠文化个机构自己做个一次直接反转,前后将近十年。

底层问题是结构性个,勿光是形象问题:低管理费用比率可以靠对恰恰让慈善机构有效个东西投入勿足来实现——一套像样个个案管理系统、受过培训个员工、监测搭评估——因为搿些常常被记成“行政”,勿是“项目”成本。一家为仔报告 5% 管理费用而饿死后台个慈善机构,交付成果个能力可能比一家花 20% 搭好一个资源充足个运作体系个慈善机构还差。勒英格兰搭威尔士,慈善委员会(Charity Commission)给受托人个指引,勿主张拿单一个管理费用百分比当效率检验,而是要求受托人报告慈善机构对照目标实现仔啥——参见[每个受益人成本](../每个受益人成本/)里讨论个 SORP 报告要求。

## 数学

```
管理费用比率 = (行政成本 + 筹款成本) / 总支出

常见变体:
  项目比率   = 项目(直接慈善)支出 / 总支出
             = 1 − 管理费用比率
  筹款效率   = 筹款成本 / 筹到个资金
```

搿些公式里一个也勿含有任何关于已达成成果个信息。一家慈善机构可以拿每一个侪压到最低,照样辜负每一位受益人;真正涉及钱到底有无起作用个指标,参见[每个成果成本](../每个成果成本/)。

## 实例演算

两家慈善机构,总支出一样:

- **慈善机构 A**:总支出 £1,000,000,行政 + 筹款 £80,000 → 管理费用比率 8%。伊无没监测搭评估职能,只有一个忙勿过来个财务人员,也无没个案管理系统;员工流动率高,也勿收集成果数据。
- **慈善机构 B**:总支出 £1,000,000,行政 + 筹款 £220,000 → 管理费用比率 22%。伊出钱养一个小评估团队、一套可以收集成果跟进个个案管理系统,还有像样个保障(safeguarding)培训。

一个光按管理费用比率筛选个捐赠者会选 A、拒掉 B——搭[每个成果成本](../每个成果成本/)个证据可能显示个正好相反,因为两家里向只有 B 有条件证明或者改善自己个真实成果。

## 搭软件工程个关联

行业里个财务搭补助报告软件,经常拿管理费用/项目个划分硬编码成每条成本线上个分类字段,因为监管机构搭有些出资方勒法定申报里还要求搿样。做搿些系统个工程师应该拿搿个要求当作合规义务,勿要当作设计信号,以为管理费用比率就是值得勒仪表盘上突出显示个指标;无论勒哪搭显示,侪要搭一个基于成果个指标配对,让看个人勿好孤立地读管理费用比率。参见[捐赠者投资回报](../捐赠者投资回报/),了解应该放勒伊旁边个指标;参见[物有所值](../物有所值/),了解公共部门反对单一比率效率代理指标个对应论述。

## 容易踏个坑

- **拿管理费用比率当筛选门槛。** 拒绝任何超过某个随意门槛个慈善机构(比方“管理费用勿超过 15%”),会系统性地惩罚资源充足、评估做得好个组织,奖励投入勿足。
- **拿直接交付成本分错成管理费用**,或者反过来——各家慈善机构对啥算“项目”、啥算“行政”个会计惯例差别蛮大,比率光看表面经常根本勿好比。
- **以为管理费用低就意味着影响大。** 两样最多是勿相关;参见 2013 年 Overhead Myth 信件个核心论点。
- **忽略有些正当个策略近期要求更高个管理费用。** 能力建设或者组织发展阶段,是有意提高行政支出,为了以后更好个交付。
