# 社会投资回报率(SROI)

社会投资回报率是一个框架,用来衡量、货币化搭核算一个宽泛概念个价值 — 社会个、环境个搭经济个 — 并且表示成搭投入资源个比率,比方"每投入 £1,产生 £1.44 个社会价值"。伊个设计初衷,是拿财务核算个逻辑延伸到市场勿定价个成果上,又勿丢脱核算个规矩:SROI 里每一个数字,侪必须可以追溯到一个由利益相关方定义个成果、一个证据基础,搭一个对"勿做也会发生个部分"个明确调整。

## 为啥重要

SROI 由 Social Value UK 搭 Social Value International(SROI 网络个继任机构)维护,伊拉个《社会投资回报率指南》(2012)到现辣还是参考方法论。框架建立辣七项原则上 — 让利益相关方参与、理解变化个是啥、给要紧个物事估值、只纳入重大个内容、勿夸大、保持透明,搭验证结果 — 而大部分现实里个 SROI 报告过勿了个,就是第五条"勿夸大"。跳过无谓损失搭归因调整得出个比率,勿是 SROI;伊是披仔 SROI 外衣个营销数字。替慈善机构、社会企业或者委托方做报告工具个软件工程师,要晓得搿个差别,因为工具要么强制执行搿个规矩,要么让跳过伊变得老容易。

## 数学

SROI 依赖[变革理论](../变革理论/)来确定哪些成果辣范围之内,并且用搭[逻辑模型](../逻辑模型/)一样个问责链条来表达:

```
SROI 比率 = 成果个现值 / 投入个价值

流程:
 1. 确定范围,识别要衡量其成果个利益相关方
 2. 梳理成果(变革理论,搭利益相关方一道取证,勿是假定)
 3. 为成果取证,并用财务替代指标给伊拉估值
 4. 确定影响:总价值 − 无谓损失 − 归因 − 挤出,再应用衰减
 5. 计算 SROI:影响个净现值 ÷ 投入个价值
 6. 报告、使用、融入 — 比率是沟通工具,勿是终点
```

无谓损失、归因搭挤出辣[额外性搭无谓损失](../额外性搭死重/)搭[挤出搭归因](../挤出效应搭归因/)里讲过;三样侪是为仔拿真正个[反事实](../反事实分析/)影响从总成果里分离出来。

## 实例演算

**地方政府就业项目**:年投入成本 £250,000。60 个参与者进入稳定就业;搿个成果个财务替代指标(福祉提升、减少福利依赖搭税收合计)是第一年每人 £8,500 — 此类替代指标个来源见[单位成本数据库](../单位成本数据库/)。

- 总成果价值:60 × £8,500 = £510,000
- 减无谓损失(40% 个人没有项目也大概率会找到工作):£510,000 × 0.60 = £306,000
- 减归因(剩下变化个 30% 要归功于别个机构个支持):£306,000 × 0.70 = £214,200
- 第 2 年成果按 30% 衰减:£214,200 × 0.70 = £149,940,按 3.5%/年贴现(见[社会贴现率](../社会贴现率/)):£149,940 ÷ 1.035 = £144,870
- 影响个总现值:£214,200 + £144,870 = £359,070
- **SROI 比率:£359,070 ÷ £250,000 = 1.44**,报告为"每投入 £1,产生 £1.44 个社会价值"

**慈善机构**:一个 £60,000 个结对陪伴服务,减轻 80 个老年人个孤独感,替代指标估值每人每年 £1,100。总价值 £88,000;扣除 35% 无谓损失搭 15% 归因之后,净影响是 £88,000 × 0.65 × 0.85 = £48,620,SROI 比率 0.81 — 低于盈亏平衡,搿是一个正当而且有用个发现,勿是勿好写进报告个失败。

## 搭软件工程个关联

一个 SROI 计算器,如果让用户输入成果数量搭替代指标值,但是呒没无谓损失、归因或者关联变革理论个必填字段,默认就会产生被夸大个比率,因为省略调整是阻力最小个路。要拿规矩内置到数据模型里:每一行成果侪应该引用一个利益相关方群体、一个有证据个数量、一个注明来源个财务替代指标,搭勿可省略个无谓损失/归因字段。SROI 成果梳理所依赖个区别见[成果搭产出](../成果搭产出/),工具个数据模型应该对应个链条见[逻辑模型](../逻辑模型/)。

## 容易踏个坑

- **跳过无谓损失搭归因。** 呒没搿些调整个标题比率是总数,勿是净影响数字,而 Social Value UK 个原则明确要求两样侪要做。
- **辣勿同机构之间比较比率。** SROI 比率取决于逐案做出个范围搭替代指标选择;拿一份报告里 4:1 个比率当作比另一份报告 2:1 个"更好",忽略仔搿些假设勿像财务会计比率那样标准化。
- **重复计算重叠个替代指标。** 对同一批受益人,拿"减轻孤独感"个替代指标搭"改善心理福祉"个替代指标叠加辣一道,会拿同一个底层变化估两次值。
- **跳过利益相关方参与。** 第一条原则要求成果由经历搿些成果个人一道来定义,勿是由搭模型个分析人员假定。
