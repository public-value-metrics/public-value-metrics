# 信任搭合法性指标

合法性搭支持,是马克·摩尔辣《创造公共价值》(1995)里"战略三角"个三条腿之一 — 另外两条是公共价值本身搭运营能力 — 也是最常常勿被衡量个一条,因为搭预算或者产出计数勿同,合法性勿附带一个明显个单一数字。信任搭合法性指标,是政府用来填补搿个空缺个一族替代衡量:机构信任调查、监督机构个信心评级、投诉搭申诉数据,以及政治/立法支持指标。

## 为啥重要

摩尔个论点是,一个交付真实价值、但是丢脱政治搭公众合法性个公共管理者,终归会失去继续交付所需个授权环境 — 资金被削减、授权范围被缩窄、服务被饿死,勿管伊个成果有多好。所以合法性勿是外挂辣交付记分卡上个公关事后补充;伊是使命能勿能继续个承重输入,搿就是为啥伊作为一个平等个视角放辣[公共价值记分卡](../公共价值计分卡/)里,而勿是一条脚注。OECD 个"政府信任"调查项目是最领先个跨国量化尝试:伊追踪 OECD 成员国里说自家对国家政府有信心个市民占比,长期数据表明信任对冲击极其敏感 — 2008 年金融危机搭新冠疫情侪造成国家层面个剧烈波动,往往只是部分恢复,OECD 个分析一直发现,感知个*能力*(政府是否兑现说过个话)搭感知个*公平/廉正*(政府是否被认为勿腐败勿偏袒)是信任数字最强个两个驱动因素,搭对任何单笔交易个满意度勿一样。政府也越来越试图辣更细个层面上操作化合法性 — 英国个独立监管机构搭检查机构(国家审计署、议会与卫生服务监察专员,以及 Ofsted、护理质量委员会搿样个行业监管机构)起到制度化合法性检查个作用,拿"公众是否仍然信任搿项服务"转换成可审计个评级。

## 数学

信任搭合法性是个框架型主题,可用个定量替代指标有:

```
机构信任指数(OECD 式)
  = 对一个"对政府有信心"问题回答"是"个受访者百分比,
    按辰光追踪,按人口群体分组

合法性替代指标集(勿存辣单一数字可以代替搿个概念):
  - 每 1,000 个服务使用者里被支持个投诉(监察专员或者内部投诉数据)
  - 针对机构决定个司法复核/申诉成功率
  - 独立监管机构/检查机构个评级(比方从"杰出"到"勿合格"档)
  - 立法/监督委员会个信任投票或者批评性报告频率
  - 信息自由请求量搭披露/拒绝率,作为感知透明度个替代指标

合法性是相互印证出来个,勿是算出来个:一个站得住脚个合法性评估
要对上头几项里个好几项做三角验证,勿是靠任何单一替代指标。
```

## 实例演算

**国家税务机关**:为一份年度公共价值报告做合法性三角验证。

```
OECD 式信任替代指标(部门专属个信心调查):
  58% 个受访者说伊拉信任税务机关会"公平对待我"(两年前是 64%)

投诉数据:
  被支持个投诉:每 1,000 次纳税人交互 4.2 件(上升自每 1,000 次 3.1 件)

监察专员转介:
  转介到独立裁决办公室:本年度 1,850 件,其中 61% 全部或者部分
  支持针对税务机关(上一年度是 48%)

三样放辣一道看:信任辣下降,被支持个投诉辣上升,
独立监察专员个裁决越来越站辣税务机关个对立面 —
三个独立个信号朝同一个方向汇聚,所以搿是一个可信个合法性发现,
勿是某一个序列里个噪音。
```

搿些数字里单单一个变动,是弱证据;三个独立个衡量辣同一个期间一道变动,才是让合法性主张站得住脚个模式。

## 搭软件工程个关联

合法性指标难得由单个团队个仪表盘产生,搿本身就是设计上个教训:要建立可以接收并且对账来自独立外部来源(监察专员个案件系统、监管机构评级数据源、调查供应商)数据个报告管道,勿要拿合法性报告架构成只有内部个指标,因为内部来源个合法性主张("阿拉评价自家值得信任")证据分量老轻 — 搿搭[公共价值记分卡](../公共价值计分卡/)里合法性视角所指出个独立性问题是同一回事。投诉搭申诉数据管道,应该享受搭任何输入[按成果付费](../按结果付费搭社会影响债券/)合同个成果管道一样个数据质量严格度,因为一份漏报或者分类勿好个投诉数据集,会辣一年之后信任调查里变得可见之前,悄悄低估合法性问题。机构层面衡量个交易层面对应物见[市民满意度指标](../市民满意度指标/),搿一条腿所属个摩尔完整战略三角框架见[公共价值](../公共价值/)。

## 容易踏个坑

- **拿满意度当合法性个替代指标**:市民可以对单笔交易个界面满意,但是对机构整体勿信任(或者倒过来) — 为啥两样必须分开报告,见[市民满意度指标](../市民满意度指标/)。
- **依赖单一个自我报告指标**:内部运行、呒没独立佐证(监察专员数据、监管机构评级)个信任调查,容易被当作自家给自家打分而否定;要做三角验证。
- **忽视按人口群体分组**:全国合计个信任数字会遮盖特定群体(按年龄、种族、收入或者地区)之间急剧分化个合法性 — OECD 自家个"政府信任"发布侪分组,就是为仔搿个。
- **拿一次由冲击引起个下滑读成永久趋势**:信任数字辣危机(金融崩溃、疫情、引人注目个丑闻)前后波动剧烈,然后部分恢复;冲击之后个单个数据点,勿应该辣呒没更多数据个情况下外推成长期下降。
