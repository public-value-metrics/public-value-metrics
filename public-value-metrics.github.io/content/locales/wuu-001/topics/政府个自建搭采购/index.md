# 政府个自建搭采购

自建搭采购(build vs buy)是一种结构化、经风险调整个比较:拿定制开发搭商业或者通用产品个采购放勒一道,按折现个[总拥有成本](../政府-it-里个总拥有成本/)、见效辰光搭风险来比。政府结构上是一个买东西个部门——《技术实务守则》(Technology Code of Practice)预设倾向于通用搭云方案——但是各部门里向个工程团队还是默认去自建,理由搭各地个建设者一样。

## 为啥重要

政府数字服务(Government Digital Service)个《技术实务守则》(<https://www.gov.uk/guidance/the-technology-code-of-practice>)搭配套个《服务手册》(Service Manual)里关于决定自建还是采购个指引,推动各部门对定制开发作出论证:预设是通用能力应该买,勿应该自建,只有真正新颖、体现使命差异个能力才值得写定制代码。英国财政部《绿皮书》关于乐观偏差(optimism bias)个补充指引,源自 2002 年 Mott MacDonald 对大型公共采购个审查,给 IT 项目个上调幅度是所有评估类别里最宽个——资本成本估算勒用于评估之前,建议低端上调 10%,高端上调到 200%,反映公共采购里软件开发历来被低估到啥个程度。自建搭采购分析存在个意义,就是勒批准之前拿搿种风险调整强行摆到台面上,勿要等到年中变成超支申请再冒出来。

## 数学

```
勒同一个 3–5 年期限上比较,按《绿皮书》
社会折现率折现(参见 social-discount-rate.md):

方案 NPV = PV(收益,按见效辰光平移) − PV(TCO)

风险调整(《绿皮书》乐观偏差个做法):
  自建成本 × 1.1–3.0         (IT 项目上调幅度,Mott MacDonald)
  自建见效辰光 + 40–60%      (部署延迟先验)
  采购:改成加上集成现实检验搭合同退出成本

决策驱动因素,按通常起决定作用个顺序:
  1. 差异化 —— 搿项能力是使命本身,还是管道工程?
  2. 见效辰光 × 延迟成本(参见 cost-of-delay-in-public-programmes.md)
  3. 经风险调整个总拥有成本
```

## 实例演算

一个地方政府需要一套成人社会照护个案管理系统。采购:SaaS 每年 £180,000,4 个月上线。自建:估算 £900,000 加每年 £150,000 维护,14 个月上线。

```
经风险调整个自建成本 = 900,000 × 1.4 = £1,260,000
5 年 TCO:
  采购 = 180,000 × 5 = £900,000
  自建 = 1,260,000 + 150,000 × 5 = £2,010,000

延迟项:系统可以避免每月 £40,000 个重复评估;
自建比采购晚 10 个月到。
延迟成本 = 10 × 40,000 = £400,000

有效比较:£900,000(采购)对 £2,010,000 + £400,000 = £2,410,000(自建)
```

五年下来采购胜出大约 150 万镑,而除仔自建估算本身,最大个一项就是延迟成本——光比资本支出个比较永远勿会发现伊。

## 搭软件工程个关联

搿套分析可以直接搬进交付实践个做法:**基于先验个风险调整**——Mott MacDonald 个上调,是软件领域机械套用《绿皮书》乐观偏差个对应物,所以团队应该为例外去争取论证,勿要预设自己个估算就是例外;**比较对象要老实**——自建个替代方案是现有最好个采购方案,勿是“啥也勿做”,搿搭[公共支出个机会成本](../公共开支里厢个机会成本/)直接相连;还有**老实个 TCO 比较**——每份自建提案侪要搭采购方案完整个[总拥有成本](../政府-it-里个总拥有成本/)比,勿是搭伊个标价比。自建真个胜出个辰光,额外个自建辰光带来个[延迟成本](../公共项目个延迟成本/)要勒业务案例里明确定价,勿要留成一个无人讲明个假设,仿佛辰光勿要紧。

## 容易踏个坑

- **拿供应商标价搭未经风险调整个自建估算比**:搿样对自建双重讨好,成本上一次,进度上一次。
- **内部人工按零定价**:公务员系统工程师个辰光被当作“免费”,因为已经勒部门编制预算里,搿就掩盖仔伊对比搿个团队本来好做别个事体个真实机会成本。
- **两个方向个锁定勿定价**:供应商退出搭数据可迁移成本是真个,但是定制自建个巴士因子(bus-factor),搭伊整个生命周期里要靠一小批难以替代个内部团队留任,也是真个。
- **拿管道工程讲成使命差异化**:对集成中间件或者文档存储断言“搿个是阿拉个核心”——拿伊搭一个检验对照:底下跑个是哪一个,市民或者个案工作人员会勿会有感觉。
