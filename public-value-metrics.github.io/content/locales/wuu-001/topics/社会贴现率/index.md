# 社会贴现率

社会贴现率拿未来个成本搭效益换算成当下个价值,让回报分散辣几十年里个项目可以辣统一基础上比较。英国财政部《绿皮书》规定一个递减个时间表,前 30 年锚定辣 3.5%,依据拉姆齐公式 — 一个具体、可引用个数字,每次用辣气候政策或者基础设施搿种长期承诺上,伊就变成活生生个政治搭伦理争论。

## 为啥重要

30 年之后收到个一镑效益,搭今朝收到个一镑效益勿一样值钞票,原因一部分是纯粹个时间偏好(人搭社会偏好好物事早点来),一部分是增长(未来社会预期更富,所以一镑辣边际上对伊拉就没那么要紧)。《绿皮书》附录 6 从拉姆齐公式推出英国个标准贴现率,拿纯粹时间偏好率、预期消费增长率搭消费边际效用弹性结合起来,得出公布个税率:第 0–30 年每年 3.5%,第 31 年以后按公布个时间表递减(第 301 年以后降到 1%)。有搿个时间表,恰恰是因为一个固定 3.5% 复利一百年,几乎会让任何长期效益 — 80 年之后救人命个防洪设施、100 年之后避免危害个碳减排 — 辣现值上看起来微乎其微,财政部认为搿对真正长寿个基础设施搭环境决策来讲,是勿可信个伦理结论。

贴现率有争议,恰恰因为搿个选择勿是中立个技术参数:伊编码仔一个判断,就是社会今朝应该为还呒没出生个人牺牲多少。《气候变化经济学斯特恩报告》(2006)用仔接近零个贴现率(纯粹时间偏好接近 0.1%),认为当危害(灾难性气候变化)勿可逆个辰光,用接近市场利率个税率去贴现后代个福祉,辣伦理上站勿牢脚。批评者 — 尤其是威廉·诺德豪斯 — 认为斯特恩接近零个税率夸大仔立即气候开支个理由,因为对一个几乎呒没贴现个未来效益,任何当下成本看起来侪合理。搿场分歧勿是数学上个,而是该由谁个伦理框架来定税率,搿也一直是说明贴现率是政策选择、勿光是精算输入个标准例子。

## 数学

《绿皮书》税率背后个拉姆齐公式:

```
r = ρ + η·g

其中:
  r = 社会贴现率
  ρ = 纯粹时间偏好率(缺乏耐心 + 灾难风险)
  η = 消费边际效用弹性
  g = 人均消费预期年增长率
```

《绿皮书》个递减时间表(附录 6,示意 — 精确个公布表请查现行版本):

```
第 0–30 年:    3.5%
第 31–75 年:   3.0%
第 76–125 年:  2.5%
第 126–200 年: 2.0%
第 201–300 年: 1.5%
第 301 年以后: 1.0%
```

未来一笔钞票个现值:

```
PV = FV / (1 + r)^t
```

## 实例演算

**防洪方案**:一个项目辣第 40 年带来 £10 million个避免洪水损失。

用固定个 3.5%:PV = 10,000,000 / (1.035)^40 ≈ £2.52 million — 效益看起来勿大。

用《绿皮书》个递减时间表(第 0–30 年 3.5%,之后 3.0%),前 30 年按 3.5% 复利,第 31–40 年按 3.0%:

```
PV = 10,000,000 / [(1.035)^30 × (1.03)^10]
   = 10,000,000 / [2.807 × 1.344]
   ≈ 10,000,000 / 3.773
   ≈ £2.65 million
```

搭固定个高税率比起来,递减时间表适度抬高仔长期效益个现值 — 搿正是时间表个明确目个,因为固定 3.5% 一百年,会拿第 100 年个 £100 million 效益贴现到 £3.3 million 以下。

**数字基础设施**:一个政府云迁移现辣花 £4 million,预期 15 年里每年避免 £500,000 个遗留系统维护成本。按 3.5%,搿笔年金个现值大约是 £500,000 × 11.52(3.5% 下 15 年年金系数)≈ £5.76 million — 稳稳超过 £4 million 个成本,是一个净现值为正个方案,但是如果天真地选一个更高个税率,就明显弱得多(按 7%,同样个年金系数跌到大约 9.11,得 £4.56 million,仍然是正个,但是余量薄得多)。

## 搭软件工程个关联

大部分软件商业方案跑 3–5 年,完全辣固定 3.5% 个区间里,所以递减时间表难得直接起作用 — 但是对任何资产寿命长个政府技术投资(国家平台、数据基础设施项目、几十年个合同),底层个规矩还是要紧个:

- 用《绿皮书》公布个税率,勿要用从私营金融借来个内部"门槛率";审计搭财政部审查人员会期待标准时间表。
- 对多年以后才实现个效益(平台个长期维护节省、开放数据生态个复合价值 — 见[开放数据个价值](../开放数据个价值/)),贴现个选择可以拿商业方案从正个翻成负个;要拿税率搭期限当作明确个假设,勿要埋辣默认值里。
- 搿个直接输入[《绿皮书》评估](../green-book-评估/),也就是正式要求贴现现金流个五案例模型,也输入[福祉估值](../福祉估值/),辣非货币个福祉效益上,同样个贴现问题也会出现。
- 另见[代际公平搭可持续性贴现](../代际公平搭可持续性贴现/),里面是斯特恩对诺德豪斯个辩论,专门应用到环境搭气候技术投资上。

## 容易踏个坑

- **辣很长个期限上用固定税率。** 《绿皮书》个递减时间表专门因为固定税率低估真正长期个效益而设;要查看适用个是哪一档,勿要从头到尾默认 3.5%。
- **拿贴现率当作伦理中立个。** 斯特恩—诺德豪斯之争表明,税率编码仔对后代个价值判断;改变伊,就改变哪些项目看起来合理,所以应该明确说明、加以辩护,勿要藏辣电子表格个默认值里。
- **拿社会贴现率搭私人资本成本搞混。** 政府借款成本搭私营部门个门槛率,搭从拉姆齐推出来个社会税率是勿同个概念,辣公共评估里互相替换,通常会拿结果扭曲到有利短期回报个方向。
- **实际现金流搭名义现金流个贴现勿一致。** 《绿皮书》税率是实际(扣除通胀)税率;用伊来贴现名义现金流,会明显低估现值。
