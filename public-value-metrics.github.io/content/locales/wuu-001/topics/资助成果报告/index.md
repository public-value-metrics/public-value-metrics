# 资助成果报告（IRIS+）

资助成果报告，指个是受资助方向出资方汇报标准化、可比较个成果指标，而勿是每个出资方各自发明一份定制个报告模板。IRIS+ 由全球影响力投资网络（Global Impact Investing Network，GIIN）维护，是采用最广泛个搿类标准：一套预先定义好个社会、环境搭财务绩效指标目录，影响力投资者搭越来越多个资助型基金会要求或者建议受资助方使用。

## 为啥重要

勒有标准化报告之前，每家基金会向受资助方索取勿同格式个勿同一套指标，一家有十个出资方个中型慈善机构，针对重叠个工作可能要并行跑十套报告流程——搿是报告负担个一个有充分记录个来源，资助成果标准化就是为了减轻搿个负担。IRIS+ 个办法是给出资方搭受资助方一套共同个词汇：按主题分组个核心指标集（Core Metrics Sets，比方经济适用房、清洁能源可及性、金融包容），每个指标个定义精确到，勿管啥人报告，"创造个就业岗位"或者"服务个家庭数"侪是同一个意思，而且搭联合国可持续发展目标（SDGs）对齐，所以出资方可以拿受资助方层面个数据汇总成投资组合层面个 SDG 叙事。GIIN 报告讲，大概一半个影响力投资者，以及该领域里活跃个基金经理、银行搭发展金融机构里个绝大多数，使用 IRIS 指标。

标准化最要紧个地方，是搭 [成果搭产出](../成果搭产出/) 交汇个地方：IRIS+ 推动报告朝已定义个成果搭影响指标走，而勿是受资助方现有个案件管理系统碰巧记录啥就报啥，搿恰恰就是 [单位成果成本](../每个成果成本/) 搭 [单个受益人成本](../每个受益人成本/) 所描述个差距。

## 数学

资助成果报告是一个框架搭流程，勿是公式：

```
1. Funder selects a Core Metrics Set relevant to the grant's theme
   (e.g. IRIS+ "Financial Inclusion" or "Sustainable Agriculture")
2. Each metric has a fixed definition, unit, and calculation method
   published by GIIN — not invented per-funder
3. Grantee reports against the same metric definitions across all
   its funders using that standard, cutting duplicate reporting effort
4. Funder aggregates grantee-level metrics into portfolio-level reporting,
   comparable year over year and across grantees using the same metric
```

效率个提高是组合式个：拿 N 个出资方 × M 个受资助方统一到一套共享词汇上，是拿 N×M 个定制报告关系，变成大概对一个标准个 N+M 个映射。

## 实例演算

**一个有三个出资方个受资助方，标准化之前**：对出资方 1 报告"服务人数"，用个是人头计数个定义；对出资方 2 报告"触达个受益人"，用个是家庭个定义；对出资方 3 报告"受影响个个人"，用个是服务次数个定义（所以一个人去了两趟算两趟）。三份报告，三个数字，勿能比较，就算勒同一个出资方个投资组合里，也勿能搭另一个受资助方个数字比较。

**同一个受资助方用 IRIS+**：对照一个已定义个 IRIS+ 触达个人数指标，以及相关核心指标集里个一个已定义个成果指标来报告，两个侪用 GIIN 公布个计算方法。三个出资方现在收到同一个数字，用同样个办法算出来，而且可以用完全一样个指标，拿搿个受资助方每个 IRIS+ 定义单位个成本，搭伊拉投资组合里个其他受资助方比较——勒报告基础设施个规模上，相当于有了一个共享个 [单位成本数据库](../单位成本数据库/)。

## 搭软件工程个关联

资助管理平台应该拿 IRIS+ 指标标识符当成外键，而勿是自由文本：拿公布个指标代码搭受资助方报告个数值存勒一道（而勿是一个本地发明、叫做"beneficiaries"个字段），才能让以后个跨出资方、跨投资组合汇总成为可能，勿需要再做一个数据清洗项目。平台要支持尚未采用 IRIS+ 个出资方个辰光，务实个设计是让一个本地指标映射到最接近个 IRIS+ 定义，而勿是强迫每个出资方马上统一到标准上——图里越多节点映射到共享标识符，可比性就越是一点一点改善。收集上来以后，报告个数字应该用来计算啥，参见姊妹主题 [单位成果成本](../每个成果成本/)。

## 容易踏个坑

- **拿采用 IRIS+ 当成自动具备可比性。** 两个受资助方侪针对同一个 IRIS+ 指标报告，假使底层个数据质量或者反事实假设勿一样，照样勿可比；标准固定个是定义，勿是测量个严谨程度。
- **出资方自家发明个"符合 IRIS"个指标。** 一个只是受 IRIS+ 语言启发、但是勿是实际公布定义个指标，会重新引入标准本来要解决个碎片化。
- **选得太多造成个报告疲劳。** 只有两三个指标对决策有用，却要求受资助方对整套核心指标集报告，是拿负担问题装进一个标准化个包装里重新制造出来。
- **一个成果指标也呒没。** IRIS+ 里有交关纯产出指标（比方服务人数个计数）；只选搿些，一个成果层个指标也勿选，就会勒成果报告个名目下，做出 [单个受益人成本](../每个受益人成本/) 形状个报告。
