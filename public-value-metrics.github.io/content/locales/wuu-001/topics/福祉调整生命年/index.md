# 福祉调整生命年(WELLBY)

一个 WELLBY,是辣标准 0–10 福祉量表上,一个人一年里多一分个生活满意度。伊是卫生经济学里 QALY 个结构类比 — 一个单一个单位,让侬可以比较成果互相呒没任何共同点个干预 — 但是建立辣主观福祉上,勿是临床健康状态,并且辣英国财政部《福祉评估指引:《绿皮书》补充指引》(2021)里阐明。

## 为啥重要

成本效益评估需要一个共同单位,来比较青年俱乐部资助、道路安全方案搭心理健康服务,搿三样勿共享任何一个成果衡量。卫生经济学用 QALY 解决仔临床干预个搿个问题:质量调整生命年,从 0(死亡)到 1(完全健康)加权。英国财政部个福祉指引拿同样个逻辑延伸到非健康类个公共支出,用 ONS 统一个生活满意度问题("总体来讲,侬现辣对自家个生活满意伐?",0–10 回答)作为成果阶梯,替代健康状态指数。WELLBY 为 1,意味着一个人个生活满意度上升整整一分、持续一年(或者等价地,十个人个满意度各上升 0.1 分、持续一年 — WELLBY 辣人群里相加,搭 QALY 一样)。英国财政部个指引设定仔每个 WELLBY 个示意性货币价值(大约 £13,000,2019/20 价格),是拿主观福祉数据搭生命年价值个其他方法调和之后得出个,拨评估者一个办法,拿成果 — 减少孤独感、社区凝聚力、绿地可达性 — 货币化,而[福祉估值](../福祉估值/)技术以前只能描述搿些,勿能辣一个共同个立足点上搭健康或者安全支出相比较。

## 数学

```
WELLBY = Δ 生活满意度(0–10 量表)× 变化持续个年数
        (对所有受影响个人求和)

货币化个福祉效益 = 产生个 WELLBY × 每个 WELLBY 个价值(HMT 参考值)

对照 QALY = Δ 健康状态效用(0–1 量表)× 辣搿个状态里生活个年数
```

0–10 个满意度量表搭 0–1 个 QALY 效用量表,勿经换算步骤勿能互换;英国财政部个指引讨论仔如何调和两者,比方,让辣同一个[《绿皮书》评估](../green-book-评估/)里,用 QALY 评估个健康干预搭用 WELLBY 评估个社会干预,勿会被悄悄重复计算,或者勿可比较。

## 实例演算

**地方政府孤独感服务**:一个结对陪伴方案服务 400 个孤立个老年居民。跟踪调查显示平均生活满意度从 5.2 升到 6.0(升 0.8 分),估计效果持续 2 年然后消退。

```
WELLBY = 400 人 × 0.8 分 × 2 年 = 640 WELLBY

货币化价值 = 640 × £13,000 = £8,320,000
```

对比每年 £300,000 个项目成本(2 年 £600,000),效益成本比大约是 8,320,000 / 600,000 ≈ **13.9:1** — 搿个数字现辣可以搭一个健康方案个每避免一个 QALY 成本,或者一个交通方案个出行辰光节省,放辣同一张评估表里。

**慈善机构,规模较小**:一个社区艺术项目覆盖 50 个参与者,测得个满意度升幅 0.3 分,持续 1 年。

```
WELLBY = 50 × 0.3 × 1 = 15 WELLBY
货币化价值 = 15 × £13,000 = £195,000
```

## 搭软件工程个关联

- 任何已经辣收集生活满意度或者福祉调查题项个面向市民个服务(许多地方政府搭健康与护理平台依据 ONS 个四个标准福祉问题辣做),可以直接从现有个数据管道计算 WELLBY,勿用对每次服务变更委托专门个经济评估。
- 对辣做[《社会价值法》](../社会价值法/)报告或者[社会投资回报率](../社会投资回报率/)个工程团队,WELLBY 拨一个全国标准化、英国财政部认可个分母,避免出现一堆勿能辣合同或者供应商之间比较个专门"影响得分"。
- 因为 WELLBY 辣人搭辰光之间可以相加,伊拉可以顺畅地组合进[基于成果个问责](../基于成果个问责/)系统里使用个人群层面成果追踪 — 服务仪表盘可以像卫生系统报告获得个 QALY 一样,报告每个季度产生个累计 WELLBY。

## 容易踏个坑

- **假定自我报告个满意度提升完全可归因于干预** — 呒没反事实(对照组或者带控制个前后设计),侬就无法拿 WELLBY 个增益搭整体趋势分开;见[反事实分析](../反事实分析/)。
- **勿经调和就拿 WELLBY 搭 QALY 混辣一个总数里** — 英国财政部个指引明确讲,两者用勿同个量表搭勿同个底层价值理论;天真地加总会重复计算重叠个福利。
- **勿加批判地使用参考货币价值** — 每 WELLBY 个 £ 数字是一个有真实不确定区间个全国平均估计;英国财政部个指引建议做敏感性分析,勿要拿伊当固定个汇率。
