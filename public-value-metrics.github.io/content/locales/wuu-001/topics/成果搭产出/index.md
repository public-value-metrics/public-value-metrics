# 成果搭产出

产出是一项活动直接、可以数得出个产物——交付一发生伊就存在，勿管有啥效果。成果是随之而来个，对相关个人、地方或者系统个变化。“500 个人参加了求职工作坊”是产出：就算一个人也呒没寻着工作，搿句话也是真个。“500 个人个就业前景改善了”是成果个主张，需要变化个证据，而勿单单是出席个证据——搿种混淆，比行业里几乎任何其他测量错误，造出来更多误导性个资助汇报。

## 为啥重要

英国财政部《Magenta Book》搭国家彩票社区基金之类个出资方，才要求专门汇报成果，因为产出是项目默认汇报个东西：数起来便宜，随时有，而且看上去总归是正面个。产出个数字实际上永远勿会因为项目失败而下降——多做几场活动总归是“更多”，而成果却可以暴露项目勿起作用。英国国家审计署（National Audit Office）再三批评政府项目拿活动水平当成成功个证据来汇报；一套只让产出容易汇报个软件系统，默认就会强化搿个毛病，因为产出勿需要后续数据采集，成果要。

## 数学

呒没公式，但是有一个可靠个检验可以用来给指标分类：

```
Output test:  is it countable at the point of delivery, true even if the recipient is unaffected?
Outcome test: does it require a before/after or with/without comparison to be meaningful?

If a number can be true with zero benefit to anyone, it is an output.
```

搿个检验处勒更大个[逻辑模型](../逻辑模型/)链条里厢，要依靠[变革理论](../变革理论/)里厢定义个成果环节；拿成果折成钞票，用[社会投资回报率](../社会投资回报率/)里厢个方法。

## 实例演算

**地方政府（就业支持）**：产出——500 个人参加了求职工作坊。成果——12 个月回访个辰光，搿 500 人里厢 140 个（28%）处于持续就业（6 个月以上）。一个特征相似但是呒没参加项目个对照组，同期个基线就业率是 15%。净成果提升：28% − 15% = 13 个百分点，所以估计有 500 × 0.13 = 65 个额外个人就业了，勿然伊拉就勿会就业——搿个是可以归因个成果，搭 500 个出席数字、140 个原始就业数都勿一样。

**慈善机构（识字慈善）**：产出——向 300 个小囡提供了 1,200 次阅读辅导。成果——6 个月里厢平均阅读年龄提高了 8 个月，而 6 个月个自然进步基线是 6 个月。净成果收益：8 − 6 = 2 个月，是每个小囡可以归功于项目个额外阅读年龄提升，而勿是完整个 8 个月。

## 搭软件工程个关联

事件日志搭交易系统几乎自动就给产出埋了点——页面浏览、会话、关闭个工单、预约个预约——因为伊拉是系统做自家工作个辰光生成个。成果要求一个数据模型，能够勒后来个辰光点再捕捉到同一个个体，搭基线或者对照比较，搿个必须有意识地设计进去：后续问卷、关联行政记录，或者一个对照队列。一个汇报工具倘使只支持前者，勿管出资方要求啥，才会悄悄拿机构引向只汇报产出。参见[逻辑模型](../逻辑模型/)了解成果勒问责链里个位置，[单位成果成本](../每个成果成本/)了解怎样拿搿个区分变成单位成本指标，[公共部门 KPI](../公共部门个关键绩效指标/)了解指标选择个更广模式。

## 容易踏个坑

- **拿产出当成果来汇报。** “500 人参加”暗示有好处，却勿证明；要明确拿出席标成产出。
- **呒没基线或者对照组。** 一个呒没反事实个成果数字——参见[反事实分析](../反事实分析/)——分勿清项目效果搭本来就会发生个事体。
- **为资助个指标做优化。** 经费搭产出数量挂钩个辰光，交付团队理性地会追求出席最大化，而勿是持久个变化，搿是古德哈特定律（Goodhart's law）式个失效。
- **成果洗白。** 拿一个产出指标换个听上去像成果个说法（“参与成果：500 名出席者”），后头却呒没任何后续测量。
