# 政府 IT 里个总拥有成本(TCO)

总拥有成本是一个系统个全生命周期成本 — 购置加上运行个每一年 — 贴现到同一个日期。辣政府 IT 里,最稳定个预测错误,就是光凭购置价格来比较供应商或者方案,而运营搭维护通常占整个生命周期账单个一半到五分之四。

## 为啥重要

英国财政部《绿皮书》要求任何五案例模型商业方案里个财务案例涵盖全生命周期成本,勿光是资本支出 — 但是国家审计署反复发现,各部门依据勿完整或者过于乐观个运行成本预测批准 IT 投资,等到系统上线、资本预算科目已经关闭,才发现真正个运营成本。政府数字服务司(GDS)搭中央数字与数据办公室(CDDO)个《技术实践守则》(<https://www.gov.uk/guidance/the-technology-code-of-practice>)推动各部门走向云搭通用托管,部分原因就是伊让持续成本变得可见、可比较,而勿是埋辣一个单一个资本采购数字里 — 搿个数字批准个辰光看起来低得诱人,三年之后又贵得离谱。

## 数学

```
TCO = 购置成本 + Σ(t=1..N) 年度运营成本_t / (1+r)^t
      − 残值(贴现后)

r = 英国财政部《绿皮书》标准社会贴现率,3.5%/年
    (超过 30 年个期限用递减税率时间表)

运营成本构成:托管/许可、支持搭维护、
安全补丁搭合规、人员辰光、计划个更新/迁移
```

贴现因子辣典型 5–10 年系统寿命里为啥要紧,见[社会贴现率](../社会贴现率/);TCO 哪能输入自建还是购买个决策,见[政府里自建还是购买](../政府个自建搭采购/)。

## 实例演算

一个部门按《绿皮书》3.5% 个贴现率,辣 5 年期限上比较两个个案管理系统。

```
系统 A:资本支出 £3,500,000,运营支出 £250,000/年
系统 B:资本支出 £1,800,000(看起来更便宜),运营支出 £650,000/年
        (更重个供应商支持搭集成负担)

只比资本支出个天真比较:B 赢,£1.8M < £3.5M。

贴现因子之和,5 年、3.5%:0.966+0.934+0.902+0.871+0.842 ≈ 4.515

TCO_A = 3,500,000 + 250,000 × 4.515 = 3,500,000 + 1,128,750 = £4,628,750
TCO_B = 1,800,000 + 650,000 × 4.515 = 1,800,000 + 2,934,750 = £4,734,750
```

TCO 翻转仔天真个决定:拿运营成本贴现加总之后,系统 B 五年里略微更贵,因为伊个运营支出占生命周期成本个 62%(2,934,750 / 4,734,750),而系统 A 只占 24% — 搿是"维护占账单大头"搿个发现个具体例子,光比标价就完全看勿出来。

## 搭软件工程个关联

TCO 是应该规范每一个[自建还是购买](../政府个自建搭采购/)决策搭每一个[技术债务](../技术债务是公共价值个侵蚀/)偿还理由个数字,因为债务利息搭推迟个维护,侪是应该放进同一个贴现总数里个运营成本行,勿管有呒没人一直辣追踪伊拉。提出平台或者供应商选择个工程师,应该展示完整个 TCO 表,勿是采购价格,因为采购价格恰恰是《绿皮书》财务案例设计出来、要阻止各部门单靠伊个数字。TCO 也是[物有所值](../物有所值/)判断个诚实分母 — VFM 拿效益搭成本比较,一行少算个成本会夸大商业方案里每一个 VFM 比率。

## 容易踏个坑

- **只比资本支出**:最常见个采购错误 — 比较供应商个标价,但是勿对每个方案配一份对应个运营成本预测。
- **漏脱退出搭迁移成本**:合同结束个数据提取、重新平台化,搭供应商锁定个罚金,是真实个 TCO 项目,但是难得出现辣最初个商业方案里。
- **漏脱安全搭合规成本**:补丁节奏、认证续期搭审计成本,随系统年龄搭复杂度增长 — 见[公共部门网络安全个价值](../公共部门网络安全个价值/) — 但是经常辣运营支出预测里被遗漏。
- **对成本结构勿同个方案做勿贴现个比较**:拿资本支出重个方案搭运营支出重个方案勿经贴现就比较,会系统性地偏向碰巧拿更多成本推迟到后头年份个那个方案。
