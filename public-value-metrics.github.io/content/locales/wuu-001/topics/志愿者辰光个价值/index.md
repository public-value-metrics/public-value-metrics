# 志愿者辰光个价值

志愿者辰光个价值,是拨无薪劳动配个货币估算,最常用来说明一家慈善机构真实个经济足迹 — 伊个账目加上伊勿用付钞票个劳动 — 或者用来论证某项干预比伊个现金预算单独所显示个更有成本效果。两个国家个方法论占主导:美国个 Independent Sector 估算,搭英国个国家统计局/NCVO 做法,两样对同样一个钟头个劳动定价相当勿同。

## 为啥重要

每年,Independent Sector 搭马里兰大学个 Do Good Institute 一道,发布全国志愿者辰光个小时价值,建立辣劳工统计局个工资数据上 — 具体是私营非农业工资单上生产搭非监督岗位工人个平均小时收入,加上一个福利调整 — 并且按美国各州分解。最新一次发布拿 2025 年个价值定辣**每小时 $36.14**,比前一年上升 3.9%,各州个数值从华盛顿特区个 $50 以上,到波多黎各个 $20 以下。辣英国,国家统计局另外估算过正规志愿服务个替代成本是**每小时 £14.43**(2017 年估算),NCVO 个《2024 英国公民社会年鉴》用志愿服务参与数据 — 2021–22 年大约 1,420 万人正规志愿服务 — 估算整个部门个志愿服务贡献大约是 **£18 billion**,约占英国 GDP 个 0.8%。

搿个辣会计粉饰之外还要紧个原因是:一个严重依赖志愿者劳动个项目,辣纯现金[单位成果成本](../每个成果成本/)基础上,看起来可以比依赖有薪员工个项目便宜得多,即使真实个资源成本 — 替换搿种劳动要花多少 — 是相似或者更高个。忽视志愿者辰光价值个出资方搭评估者,会系统性地低估志愿者为主个交付模式个真实成本,从而扭曲搭交付同样成果个有薪员工模式之间个效率比较。

## 数学

```
志愿者辰光个价值 = 志愿者贡献个小时数 × 小时费率

费率个选择要紧,而且会改变答案:
  - 替代成本法:会做同样任务个有薪工人个工资(比方一个合格青少年
    工作者个替代成本费率,勿是一般个平均工资)— 对具体任务估值最站得住
  - 机会成本法:志愿者自家放弃个工资 — 对估算志愿者放弃个物事最站得住
  - 全国平均法:Independent Sector 或者 ONS 个单一混合费率 —
    对标题、跨部门可比性最站得住
```

对同一个钟头,三种方法可以相差一个很大个倍数(一个律师做董事会受托人个机会成本费率,搭全国平均费率相差老大),所以任何报告出来个数字,侪要说明是用啥个方法得出个。

## 实例演算

**英国慈善机构,全国平均法**:一年 5,000 个志愿者小时,按 £14.43/小时估值(ONS 替代成本估算):

```
价值 = 5,000 × £14.43 = £72,150
```

如果搿家慈善机构搿一年个现金支出是 £300,000,伊个真实资源成本 — 现金加志愿者劳动 — 是 £372,150,比光看现金数字所显示个高大约 24%。只用 £300,000 现金数字个单位成果成本计算,以同样个幅度低估真实成本。

**美国慈善机构,全国平均法**:2,000 个志愿者小时,按 $36.14/小时估值(Independent Sector,2025 年发布):

```
价值 = 2,000 × $36.14 = $72,280
```

**同一家美国慈善机构,机会成本法**:如果志愿者里退休专业人士占比勿成比例,伊拉以前个收入平均 $60/小时,机会成本估值会是 $120,000 — 比全国平均个数字高三分之二,说明为啥必须说明所用个方法。

## 搭软件工程个关联

记录志愿者小时个系统(排班工具、志愿者管理平台)应该辣任务或者角色层面捕捉小时数,勿光是总数,让替代成本费率可以按角色应用,勿是对一支混合个志愿者队伍用一个统一个全国平均费率(受托人个一个钟头搭引导员个一个钟头,辣经济上勿等价)。拿所用个费率搭方法,搭计算出来个价值一道保存 — 勿光是最终个货币数字 — 让下游报告(年度账目、[社会投资回报率](../社会投资回报率/)计算、出资方报告)后来可以重现或者质疑搿个数字,勿是拿伊当一个勿透明个常数。为啥省略志愿者辰光价值会系统性低估真实交付成本,见[单位成果成本](../每个成果成本/)。

## 容易踏个坑

- **对结构上勿同个角色用一个统一费率。** 拿全国平均工资率用辣专业个公益钟头(法律、财务、临床)上,会严重低估;只要任务是有技能个,就要拿费率搭被替代个角色相匹配。
- **搭有薪员工成本重复计算。** 如果志愿者替代个是本来要付薪水个工作,要确保估值是现金支出之外额外个,勿是叠加辣一个已经被夸大个人员估算上头。
- **引用勿注明日期个过期费率。** Independent Sector 搭 ONS 个费率每年变化(或者就 ONS 而言,只是定期重新估算);报告里一个勿注明日期个志愿者辰光数字,对比较来讲几乎呒没意义。
- **拿志愿者辰光价值当作筹款资产。** 伊是为仔理解真实资源成本个成本会计调整,勿是慈善机构可以花个新钞票;拿两样混辣一道,会误导看账目个董事会。
