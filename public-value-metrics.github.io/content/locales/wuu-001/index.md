# 公共价值指标

一本全面个入门读物,讲公共价值个数学、例子搭推理,是写拨全世界为政府搭社会领域机构做软件个工程师看个。每个文件讲一个指标或者概念:定义、为啥要紧、方法、实例、搭软件工程个关联、陷阱,搭资料来源。

新来个?先看[公共价值](locales/wuu-001/topics/公共价值/)、[物有所值](locales/wuu-001/topics/物有所值/)搭[变革理论](locales/wuu-001/topics/变革理论/) — 搿三个想法是其他所有物事个基础。

## 公共价值个基础

- [公共价值](locales/en-gb-oxendict/topics/public-value/) — 马克·摩尔个战略三角:合法性、使命搭运营能力,是衡量公共价值个标准
- [物有所值(VFM)](locales/en-gb-oxendict/topics/value-for-money/) — 经济性、效率、效果 — 搭有争议个第四个 E,公平
- [公共开支里厢个机会成本](locales/en-gb-oxendict/topics/opportunity-cost-in-public-spending/) — 部门花脱个每一镑,侪是呒没花辣第二优个项目上个一镑
- [社会贴现率](locales/en-gb-oxendict/topics/social-discount-rate/) — 《绿皮书》个递减贴现率,搭点解 3.5% 变成仔一个现实个政治问题
- [分配权重](locales/en-gb-oxendict/topics/distributional-weighting/) — 为啥一镑钞票对穷人家更加要紧 — 搭《绿皮书》哪能拿搿个定价
- [额外性搭死重](locales/en-gb-oxendict/topics/additionality-and-deadweight/) — 勿做也会发生伐?搿个问题会拿大部分影响声称戳穿
- [挤出效应搭归因](locales/en-gb-oxendict/topics/displacement-and-attribution/) — 侬个收获是别人个损失辰光,搭勿完全算侬头上辰光
- [反事实分析](locales/en-gb-oxendict/topics/counterfactual-analysis/) — 呒没反事实,就呒没证据 — 构造一个呒没干预个世界

## 政府经济评估

- [Green Book 评估（五案例模型）](locales/en-gb-oxendict/topics/green-book-appraisal/) — 英国财政部个五案例模型:战略、经济、商业、财务搭管理案例
- [社会成本效益分析(SCBA)](locales/en-gb-oxendict/topics/social-cost-benefit-analysis/) — 拿所有物事货币化,包括市场从来呒没定过价个物事
- [政府个成本效益分析(成本效果分析)](locales/en-gb-oxendict/topics/cost-effectiveness-analysis-in-government/) — 成果呒法老老实实换算成钞票个辰光,算每单位成果个成本
- [多准则决策分析（MCDA）](locales/en-gb-oxendict/topics/multi-criteria-decision-analysis/) — 单一指标会遮脱取舍个辰光,照加权准则拨各个方案打分
- [福祉估值(WELLBY)](locales/en-gb-oxendict/topics/wellbeing-valuation/) — WELLBY搭福祉调整:用生活满意度个单位来替政策定价
- [陈述偏好估值](locales/en-gb-oxendict/topics/stated-preference-valuation/) — 问人家愿意付多少 — 条件估值搭伊个可信度问题
- [显示偏好估值](locales/en-gb-oxendict/topics/revealed-preference-valuation/) — 从人真正做个事体里推断价值,从特征价格法到旅行成本法
- [影子价格](locales/en-gb-oxendict/topics/shadow-pricing/) — 拨呒没市场价格个物事定价:碳、辰光搭非贸易品

## 社会价值搭影响衡量

- [社会投资回报率(SROI)](locales/en-gb-oxendict/topics/social-return-on-investment/) — SROI比率,搭防止伊变成营销数字个规矩
- [变革理论](locales/en-gb-oxendict/topics/theory-of-change/) — 辰光衡量任何物事之前,先画出从活动到长期成果个因果链
- [逻辑模型](locales/en-gb-oxendict/topics/logic-model/) — 投入、活动、产出、成果、影响 — 项目问责个脊梁
- [成果搭产出](locales/en-gb-oxendict/topics/outcomes-vs-outputs/) — 为啥“500 个人来参加仔”搭“500 个人个生活改善仔”勿是一个说法
- [《社会价值法》](locales/en-gb-oxendict/topics/social-value-act/) — 英国 2012 年个法定责任:公共采购里要考虑社会价值
- [单位成本数据库](locales/en-gb-oxendict/topics/unit-cost-databases/) — HACT个社会价值银行搭 Global Value Exchange:事先定好价个替代指标,让大家勿要从零开始
- [影响评估方法](locales/en-gb-oxendict/topics/impact-evaluation-methods/) — 实验室里做勿来个政策,用 RCT、双重差分搭倾向得分匹配
- [影响评估搭过程评估](locales/en-gb-oxendict/topics/impact-evaluation-vs-process-evaluation/) — 有效果伐,搭是否照设计做仔 — 两个勿同个问题,两种勿同个方法

## 政府绩效搭交付指标

- [公共部门个关键绩效指标（KPI）](locales/en-gb-oxendict/topics/public-sector-kpis/) — 选出经得起古德哈特定律考验个指标
- [公共价值计分卡](locales/en-gb-oxendict/topics/public-value-scorecard/) — 拿卡普兰搭诺顿个平衡记分卡改造成适合勿是为仔赚钞票个使命
- [基于成果个问责（OBA）](locales/en-gb-oxendict/topics/outcomes-based-accountability/) — 马克·弗里德曼个“Results-Based Accountability”:人群成果搭绩效问责
- [按结果付费搭社会影响债券（PbR/SIB）](locales/en-gb-oxendict/topics/payment-by-results-and-social-impact-bonds/) — 为成果付费,勿是为活动付费 — 搭点解激励设计就是全部关键
- [公共服务生产率](locales/en-gb-oxendict/topics/public-service-productivity/) — 衡量呒没市场价格个服务个产出增长,从 ONS 个方法论讲起
- [市民满意度指标](locales/en-gb-oxendict/topics/citizen-satisfaction-metrics/) — 净满意度、信任调查,搭服务质量搭感知价值之间个差距
- [服务标准搭交易指标](locales/en-gb-oxendict/topics/service-standards-and-transaction-metrics/) — GOV.UK 式服务标准:完成率、每笔交易成本、数字服务采用率
- [信任搭合法性指标](locales/en-gb-oxendict/topics/trust-and-legitimacy-metrics/) — 为啥合法性是摩尔三个检验之一,搭政府哪能试着衡量伊

## 社会领域搭慈善指标

- [每个成果成本](locales/en-gb-oxendict/topics/cost-per-outcome/) — 慈善机构个单位经济学:每个真正得到帮助个人个成本,勿是每个接触到个人个成本
- [每个受益人成本](locales/en-gb-oxendict/topics/cost-per-beneficiary/) — 单位成果成本个粗糙、更快个表亲,搭点解出资人还是要问伊
- [融合价值](locales/en-gb-oxendict/topics/blended-value/) — 财务、社会搭环境回报,当作一条勿可分割个底线
- [有效利他主义个成本效益](locales/en-gb-oxendict/topics/effective-altruism-cost-effectiveness/) — GiveWell 式个每救一条命成本推理,搭伊像 QALY 个祖先
- [慈善机构管理费用比率](locales/en-gb-oxendict/topics/charity-overhead-ratio/) — 为啥“多少钞票用到行政上”是错个问题,出资人还是要问
- [捐赠者投资回报](locales/en-gb-oxendict/topics/donor-return-on-investment/) — 捐赠人真正拿回来啥,搭点解搿勿是慈善机构个 ROI
- [资助成果报告（IRIS+）](locales/en-gb-oxendict/topics/grant-outcomes-reporting/) — IRIS+ 指标,搭出资人要求受资助者汇报个内容个标准化
- [志愿者辰光个价值](locales/en-gb-oxendict/topics/volunteer-time-value/) — 拨无薪劳动定价,既勿抹脱伊,也勿夸大伊

## 数字政府里个公共价值

- [数字服务标准](locales/en-gb-oxendict/topics/digital-service-standard/) — GOV.UK 个设计原则搭服务评估,当作公共价值个关口
- [每笔交易成本](locales/en-gb-oxendict/topics/cost-per-transaction/) — 数字渠道醒目个经济账,搭伊最常见个会计把戏
- [渠道转移节省](locales/en-gb-oxendict/topics/channel-shift-savings/) — 一个服务上线之后,电话线搭柜台到底发生啥
- [数字包容](locales/en-gb-oxendict/topics/digital-inclusion/) — 辅助数字服务、数字鸿沟,搭“数字优先”排斥人个辰光损失个价值
- [政府即平台（GaaP）](locales/en-gb-oxendict/topics/government-as-a-platform/) — 共享组件当作公共基础设施:GOV.UK Notify、Pay,搭复用个经济学
- [开放数据个价值](locales/en-gb-oxendict/topics/open-data-value/) — 拨呒没价格个数据估值,从麦肯锡个估算到逐个数据集个案例研究
- [公共部门网络安全个价值](locales/en-gb-oxendict/topics/public-sector-cybersecurity-value/) — 为泄露会暴露个市民数据,拨风险降低定价
- [政府个 AI 价值](locales/en-gb-oxendict/topics/ai-in-government-value/) — 用搭其他一切一样个物有所值标准,评估公共服务里采用 AI

## 福祉、公平搭社会指标

- [GDP 个替代指标](locales/en-gb-oxendict/topics/gdp-alternatives/) — 真实进步指标、国民幸福总值,搭 GDP 众所周知个盲点
- [人类发展指数（HDI）](locales/en-gb-oxendict/topics/human-development-index/) — 预期寿命、教育搭收入合成一个数字 — 搭伊抹平脱个物事
- [多维贫困指数（MPI）](locales/en-gb-oxendict/topics/multidimensional-poverty-index/) — 勿单单看收入,还要数健康、教育搭生活水平方面个剥夺
- [福祉调整生命年(WELLBY)](locales/en-gb-oxendict/topics/wellbeing-adjusted-life-years/) — WELLBY:一个像 QALY 个单位,用辣货币是生活满意度而勿是健康个政策
- [多重剥夺指数（IMD）](locales/en-gb-oxendict/topics/index-of-multiple-deprivation/) — 英格兰小区域个剥夺排名,搭伊哪能引导资金搭关注
- [社会资本指标](locales/en-gb-oxendict/topics/social-capital-metrics/) — 信任、网络搭公民参与,是呒没记账个经济资产
- [自然资本核算](locales/en-gb-oxendict/topics/natural-capital-accounting/) — 拿环境放进资产负债表,从英国个 25 年环境计划讲起
- [代际公平搭可持续性贴现](locales/en-gb-oxendict/topics/intergenerational-equity-and-sustainability-discounting/) — 为啥用任何正个贴现率来贴现遥远个未来,会拿伊从分析里抹脱

## 软件工程搭数字交付个关联

- [技术债务是公共价值个侵蚀](locales/en-gb-oxendict/topics/technical-debt-as-public-value-erosion/) — 本金搭利息,搭老旧公共系统个慢性病经济学
- [政府 IT 里个总拥有成本(TCO)](locales/en-gb-oxendict/topics/total-cost-of-ownership-in-government-it/) — 维护占账单个 50-80%;公共 IT 里天真个采购价格错误
- [政府个自建搭采购](locales/en-gb-oxendict/topics/build-vs-buy-in-government/) — 经过风险调整、拨延误项定好价个比较,适用于大部分靠购买个部门
- [收益兑现](locales/en-gb-oxendict/topics/benefits-realization/) — 上线之后审计商业方案里预测个效益到底有呒没实现
- [公共部门个 AI 生产力](locales/en-gb-oxendict/topics/ai-productivity-in-the-public-sector/) — AI 开发者生产率个证据基础,对公共部门工程团队意味着啥
