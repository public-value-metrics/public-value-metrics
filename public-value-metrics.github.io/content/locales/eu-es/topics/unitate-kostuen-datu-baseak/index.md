# Unitate-kostuen datu-baseak

Unitate-kostuen datu-basea gizarte-emaitzetarako aldez aurretik ikertutako eta ebidentzian oinarritutako proxy finantzarioen liburutegi bat da (langabeziatik enpleguratzearen balioa, bakardadearen murrizketarena, maizter-egonkortasun batena), eta praktikatzaile batek emaitza bat diruztatzea ahalbidetzen du aldiro neurrira egindako balioespen-ikerketa enkargatu gabe. Existitzen dira karitate txiki batek finantzaketa-eskaera bat idazten duenean baliabide onak dituen aholkularitza batek adinako zorroztasuna aplika dezan, beste norbaitek lehendik eratorritako eta argitaratutako proxy bat berrerabiliz.

## Zergatik den garrantzitsua

HACT-en UK Social Value Bank-a, Daniel Fujiwara ekonomialariarekin ongizatearen balioespen-metodoak erabiliz garatua, eta Global Value Exchange, proxy finantzarioen datu-base ireki eta crowdsourced bat, dira Erresuma Batuko hirugarren eta sektore publikoetan gehien erabiltzen diren bi. Biak existitzen dira azpiko balioespen-lana ([ongizatearen balioespena](../ongizatearen-balioespena/) eta [adierazitako lehentasunen balioespena](../adierazitako-lehentasunen-balioespena/)) garestia, metodologikoki zorrotza eta proiektu bakoitzerako hutsetik exekutatzeko motela delako. Partekatutako proxy-liburutegi argitaratu batek hainbat hilabeteko ikerketa-ariketa izango zena kontsulta bihurtzen du, eta horregatik axola dute bai [gizarte-inbertsioaren itzulkina](../gizarte-inbertsioaren-itzulkina/) kalkuluetarako bai [Gizarte Balioaren Legeko](../gizarte-balioaren-legea/) eskaintzen ebaluaziorako: haiek gabe, diruztatze zorrotza bere azterketak enkargatzeko adinako erakunde handiek bakarrik ordain zezaketen.

## Matematika

Unitate-kostuen datu-baseak ez du berak ezer kalkulatzen; beste nonbait egindako kalkulu baterako sarrera bat hornitzen du:

```
Proxy finantzarioaren balioa = merkatu-prezioa, EDO itzal-prezioa, EDO ongizatearen balioespena,
                               EDO adierazitako lehentasunen balioa
                               emaitza-aldaketaren unitate definitu baterako
                               (adib. "langabeziatik enpleguratzen den pertsona bakoitzeko, urtean")

Aplikatutako balioa = lortutako emaitza-kopurua × unitate-proxyaren balioa
```

Ikus [itzal-prezioak](../itzal-prezioak/) merkatu-prezioa existitzen ez denean proxy bat nola eraikitzen den jakiteko, eta [gizarte-inbertsioaren itzulkina](../gizarte-inbertsioaren-itzulkina/) aplikatutako balioa, pisu hilaren eta atribuzioaren doikuntzen ondoren, ratio batera nola elikatzen den jakiteko.

## Adibide landua

**Karitatea (adiskidetze-zerbitzuaren SROI)**: "bakardadearen murrizketa" unitate-kostuen datu-baseko sarrera batek pertsona/urte £1.100eko proxy ilustratibo bat ematen du. 80 onuradunei aplikatuta: 80 × £1.100 = £88.000 balio gordina. Datu-baseak "buruko ongizate hobetua"-ren proxy bat ere badu eta ongizate-inkesta bateko elementu gainjarri bat erabiltzen badu, bi proxyak 80 pertsona berberentzat pilatzeak azpiko aldaketa beraren zati bat bikoiztuko luke: datu-baseak zenbakia ematen du, baina gainjartze hori saihestea analistaren ardura da.

**Toki-agintaritza (enplegu-klubaren SROI)**: "langabeziatik enplegu iraunkorrera igarotzea" unitate-kostuen datu-baseko sarrera bat 45 parte-hartzaileri aplikatzen zaie, pertsona/urte £8.500eko proxy ilustratibo batekin: 45 × £8.500 = £382.500 balio gordina, [gizarte-inbertsioaren itzulkinean](../gizarte-inbertsioaren-itzulkina/) erakutsitako pisu hilaren eta atribuzioaren doikuntzak aurretik.

## Software ingeniaritzarekin lotura

Karitateentzat edo komisionatzaileentzat txosten-tresnak eraikitzen dituzten taldeek onura ateratzen diote barne "emaitza-katalogo" bati: produktu edo zerbitzu batek sinesgarriki aldarrika dezakeen emaitza bakoitza proxy izendatu bati, bere iturburuko datu-baseari, argitaratze-dataz eta bertsio-identifikatzaile bati lotzen dien taula bat, erakunde bateko talde desberdinek emaitza beraren balio apur bat desberdinak aukera ez ditzaten. Global Value Exchange-ren datu irekiak kontsulta-zerbitzu baten atzean biltzeak, iturria eta data beti zifraren ondoan erakutsita, proxya auditagarri mantentzen du, kalkulu-orri batean lurperatutako zenbaki magiko bat izan beharrean. Ikus [gizarte-inbertsioaren itzulkina](../gizarte-inbertsioaren-itzulkina/) eta [Gizarte Balioaren Legea](../gizarte-balioaren-legea/) proxy hauek kontsumitzen diren bi toki nagusietarako.

## Tranpak

- **Proxyak zehatzak balira bezala tratatzea.** Argitaratutako proxy gehienak ongizatearen balioespen-ikerketetatik eratorritako batez besteko modelizatuak dira, konfiantza-tarte zabalekin; liberara zehaztuta aipatzeak azpiko ikerketak onartzen duen zehaztasuna gainestimatzen du.
- **Gainjartzen diren proxyak bikoiztea kontatzea.** Inkesta-eraikuntza gainjarrietatik eratorritako proxyak (adib. "bakardade murriztua" eta "buruko ongizate hobetua") konbinatzeak azpiko aldaketa bera bi aldiz balioesten du.
- **Testuinguruz kanpoko proxy bat doitu gabe erabiltzea.** Nazio-biztanleria eta urte batean kalibratutako proxy bat, inflazio- edo testuinguru-doikuntzarik gabe beste nonbait aplikatuta, isilean balioa gaizki adierazten du.
- **Jatorria ez egiaztatzea.** Global Value Exchange irekia eta crowdsourced da, beraz sarreren kalitatea ekarpen-egilearen arabera aldatzen da; egiaztatu azpiko iturria zifra bat finantzaketa-eskaera edo erosketa-aurkezpen batean aipatu aurretik.
