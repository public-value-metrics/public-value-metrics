# గ్రాంట్ ఫలితాల నివేదన (IRIS+)

గ్రాంట్ ఫలితాల నివేదన అంటే, ప్రతి నిధిదారు తనదైన ప్రత్యేక నివేదన టెంప్లేట్‌ను రూపొందించుకోకుండా, గ్రాంటీలు ప్రామాణిక, పోల్చదగిన ఫలిత కొలమానాలను నిధిదారులకు నివేదించే పద్ధతి. Global Impact Investing Network (GIIN) నిర్వహించే IRIS+ అలాంటి ప్రమాణాల్లో అత్యంత విస్తృతంగా అవలంబించబడింది: ప్రభావ పెట్టుబడిదారులు, పెరుగుతున్న సంఖ్యలో గ్రాంట్ ఇచ్చే ఫౌండేషన్‌లు గ్రాంటీలు వాడాలని కోరే లేదా సిఫార్సు చేసే ముందే నిర్వచించిన సామాజిక, పర్యావరణ, ఆర్థిక పనితీరు కొలమానాల కేటలాగ్.

## ఇది ఎందుకు ముఖ్యం

ప్రామాణిక నివేదన ముందు, ప్రతి ఫౌండేషన్ గ్రాంటీల నుంచి వేర్వేరు ఫార్మాట్‌లో వేర్వేరు సూచికల సమితిని అడిగేది; పది నిధిదారులున్న మధ్య తరహా ఛారిటీ పరస్పరం అతివ్యాప్తమయ్యే పనికి పది సమాంతర నివేదన ప్రక్రియలను నడపాల్సి వచ్చేది. గ్రాంట్-ఫలితాల ప్రామాణీకరణ తగ్గించాలనుకునే నివేదన భారానికి ఇది బాగా నమోదైన కారణం. IRIS+ నిధిదారులకు, గ్రాంటీలకు ఉమ్మడి పదజాలాన్ని ఇవ్వడం ద్వారా దీన్ని పరిష్కరిస్తుంది: ఇతివృత్తాల వారీగా (ఉదా. అందుబాటు ధరల గృహాలు, శుభ్ర శక్తి అందుబాటు, ఆర్థిక సమ్మిళితత్వం) సమూహపరిచిన Core Metrics Sets; "సృష్టించిన ఉద్యోగాలు" లేదా "సేవ అందించిన కుటుంబాలు" ఎవరు నివేదించినా ఒకే అర్థం ఉండేంత కచ్చితంగా ప్రతి కొలమానం నిర్వచించబడింది; నిధిదారు గ్రాంటీ-స్థాయి డేటాను పోర్ట్‌ఫోలియో-స్థాయి SDG కథనంగా రోల్-అప్ చేయగలిగేలా UN సుస్థిర అభివృద్ధి లక్ష్యాలకు (SDGలు) సర్దుబాటు చేయబడింది. IRIS కొలమానాలను ప్రభావ పెట్టుబడిదారుల్లో సుమారు సగం మంది, ఈ రంగంలో చురుకుగా ఉన్న ఫండ్ మేనేజర్లు, బ్యాంకులు, అభివృద్ధి ఆర్థిక సంస్థల్లో అత్యధికులు వాడుతున్నారని GIIN నివేదిస్తుంది.

[ఫలితాలు వర్సెస్ అవుట్‌పుట్‌లు](../ఫలితాలు-వర్సెస్-ఉత్పాదనలు/)తో అనుసంధానమయ్యే చోట ప్రామాణీకరణ అత్యంత ముఖ్యం: గ్రాంటీ ప్రస్తుత కేస్ మేనేజ్‌మెంట్ వ్యవస్థ ఏది లాగ్ చేస్తే అదే కాకుండా, నిర్వచించిన ఫలిత, ప్రభావ కొలమానాల వైపు IRIS+ నివేదనను నెడుతుంది; [ఫలితానికి వ్యయం](../ఒక్కో-ఫలితం-వ్యయం/), [లబ్ధిదారునికి వ్యయం](../ఒక్కో-లబ్ధిదారుని-వ్యయం/) వివరించే అంతరం ఇదే.

## గణితం

గ్రాంట్ ఫలితాల నివేదన ఒక ఫ్రేమ్‌వర్క్, ప్రక్రియ; సూత్రం కాదు:

```
1. Funder selects a Core Metrics Set relevant to the grant's theme
   (e.g. IRIS+ "Financial Inclusion" or "Sustainable Agriculture")
2. Each metric has a fixed definition, unit, and calculation method
   published by GIIN — not invented per-funder
3. Grantee reports against the same metric definitions across all
   its funders using that standard, cutting duplicate reporting effort
4. Funder aggregates grantee-level metrics into portfolio-level reporting,
   comparable year over year and across grantees using the same metric
```

సామర్థ్య లాభం సంయోజనాత్మకం: N నిధిదారులు × M గ్రాంటీలను ఒక ఉమ్మడి పదజాలంపైకి ప్రామాణీకరించడం N×M ప్రత్యేక నివేదన సంబంధాలను, ఒక ప్రమాణంపై సుమారు N+M మ్యాపింగ్‌లుగా మారుస్తుంది.

## ఉదాహరణ సహిత పరిష్కారం

**ముగ్గురు నిధిదారులున్న గ్రాంటీ, ప్రామాణీకరణకు ముందు**: నిధిదారు 1కి "సేవ అందిన ప్రజలు" అని హెడ్‌కౌంట్ నిర్వచనంతో, నిధిదారు 2కి "చేరిన లబ్ధిదారులు" అని కుటుంబ నిర్వచనంతో, నిధిదారు 3కి "ప్రభావితమైన వ్యక్తులు" అని సేవా-ఘట్ట నిర్వచనంతో నివేదిస్తుంది (అంటే ఒక వ్యక్తి రెండుసార్లు సందర్శిస్తే రెండుసార్లు లెక్కిస్తారు). మూడు నివేదికలు, మూడు సంఖ్యలు, ఏదీ పోల్చదగినది కాదు; ఒకే నిధిదారు పోర్ట్‌ఫోలియోలోని మరో గ్రాంటీ సంఖ్యలతో కూడా పోల్చలేం.

**అదే గ్రాంటీ IRIS+ కింద**: సంబంధిత Core Metrics Set నుంచి నిర్వచించిన ఫలిత కొలమానంతో పాటు, నిర్వచించిన IRIS+ చేరిన-వ్యక్తుల కొలమానం ప్రకారం, రెండింటికీ GIIN ప్రచురించిన గణన పద్ధతిని వాడి నివేదిస్తుంది. ఇప్పుడు ముగ్గురు నిధిదారులూ ఒకే సంఖ్యను, ఒకే విధంగా లెక్కించినదాన్ని అందుకుంటారు; ఒకే కొలమానాన్ని వాడి తమ పోర్ట్‌ఫోలియోలోని ఇతర గ్రాంటీలతో ఈ గ్రాంటీ IRIS+-నిర్వచిత యూనిట్‌కు వ్యయాన్ని పోల్చవచ్చు; ఇది నివేదన-మౌలిక సదుపాయాల స్థాయిలో ఉమ్మడి [యూనిట్ వ్యయ డేటాబేస్](../యూనిట్-వ్యయ-డేటాబేస్-లు/) కలిగి ఉండటానికి సమానం.

## సాఫ్ట్‌వేర్ ఇంజనీరింగ్‌తో సంబంధం

గ్రాంట్ మేనేజ్‌మెంట్ వేదికలు IRIS+ కొలమాన ఐడెంటిఫైయర్‌లను ఉచిత పాఠ్యంగా కాక ఫారిన్ కీగా పరిగణించాలి: గ్రాంటీ నివేదించిన విలువతో పాటు ప్రచురిత కొలమాన కోడ్‌ను నిల్వ చేయడం ("లబ్ధిదారులు" అని స్థానికంగా సృష్టించిన ఫీల్డ్ కాకుండా), తర్వాత డేటా-క్లీనింగ్ ప్రాజెక్ట్ లేకుండానే నిధిదారుల మధ్య, పోర్ట్‌ఫోలియోల మధ్య సమగ్రీకరణను సాధ్యం చేస్తుంది. IRIS+ను ఇంకా అవలంబించని నిధిదారులను వేదిక సమర్థించాల్సి వస్తే, ప్రతి నిధిదారునూ వెంటనే ప్రమాణంపైకి బలవంతం చేయకుండా, స్థానిక కొలమానాన్ని సమీప IRIS+ నిర్వచనానికి మ్యాప్ చేయనివ్వడం ఆచరణాత్మక రూపకల్పన; గ్రాఫ్‌లో ఎక్కువ భాగం ఉమ్మడి ఐడెంటిఫైయర్‌లకు మ్యాప్ అయ్యేకొద్దీ పోల్చదగినతనం క్రమంగా మెరుగుపడుతుంది. సేకరించిన సంఖ్యలను దేనిని గణించడానికి వాడాలో తెలుసుకోవడానికి సహోదర అంశం [ఫలితానికి వ్యయం](../ఒక్కో-ఫలితం-వ్యయం/) చూడండి.

## సాధారణ లోపాలు

- **IRIS+ అవలంబనను ఆటోమేటిక్ పోల్చదగినతనంగా చూడటం.** ఇద్దరు గ్రాంటీలు ఒకే IRIS+ కొలమానం ప్రకారం నివేదించినా, వారి ఆధార డేటా నాణ్యత లేదా ప్రతితథ్య ఊహలు భిన్నమైతే పోల్చదగినవి కాకపోవచ్చు; ప్రమాణం నిర్వచనాలను స్థిరపరుస్తుంది, కొలత కఠినతను కాదు.
- **నిధిదారు సృష్టించిన "IRIS-అనుగుణ" కొలమానాలు.** IRIS+ భాష నుంచి ప్రేరణ పొందిందే కానీ అసలు ప్రచురిత నిర్వచనం కాని కొలమానం, ప్రమాణం పరిష్కరించాలనుకున్న విచ్ఛిన్నతను తిరిగి తెస్తుంది.
- **అతిగా ఎంచుకోవడం వల్ల నివేదన అలసట.** రెండు మూడు కొలమానాలు మాత్రమే నిర్ణయానికి సంబంధించినప్పుడు, గ్రాంటీని మొత్తం Core Metrics Set ప్రకారం నివేదించమని కోరడం, ప్రామాణిక పొరలో అదే భార సమస్యను తిరిగి సృష్టిస్తుంది.
- **ఫలిత కొలమానం అసలు లేకపోవడం.** IRIS+లో చాలా స్వచ్ఛమైన అవుట్‌పుట్ కొలమానాలు (ఉదా. సేవ అందిన ప్రజల సంఖ్య) ఉన్నాయి; వాటిని మాత్రమే ఎంచుకుని, ఫలిత-స్థాయి కొలమానాలను ఒక్కటీ ఎంచుకోకపోతే, ఫలితాల-నివేదన లేబుల్ కింద [లబ్ధిదారునికి వ్యయం](../ఒక్కో-లబ్ధిదారుని-వ్యయం/) తరహా నివేదన వస్తుంది.
