# బహుళ ప్రమాణాల నిర్ణయ విశ్లేషణ (MCDA)

MCDA (multi-criteria decision analysis) అనేక విభిన్న, భారం కేటాయించిన ప్రమాణాలపై ఎంపికలకు ఒకేసారి స్కోర్లు ఇచ్చి, భారాలతో తూకం వేస్తుంది. ప్రతి ప్రమాణాన్నీ ఒకే ద్రవ్య లేదా సహజ యూనిట్‌లోకి బలవంతంగా మార్చకుండానే ర్యాంకింగ్‌తో కూడిన పోలికను ఇస్తుంది. ముఖ్యమైన ఫలితాలను నిజంగా ఒకే సంఖ్యకు కుదించలేని నిర్ణయాల్లో ఇది అనుసరించే మదింపు పద్ధతి.

## ఇది ఎందుకు ముఖ్యం

ప్రయోజనాలు "నిజంగా పోల్చలేనివి" (genuinely incommensurable) అయిన మదింపులకు Green Book MCDAను స్పష్టంగా అనుమతిస్తుంది (దాని Box 2 కేస్ స్టడీ అనుబంధం, Annex A రెండూ దీన్ని నేరుగా చర్చిస్తాయి). అంటే [సామాజిక వ్యయ-ప్రయోజన విశ్లేషణ](../సామాజిక-వ్యయ-ప్రయోజన-విశ్లేషణ/) ద్వారా అన్నింటినీ డబ్బులోకి మార్చడం, లేదా [వ్యయ-ప్రభావశీలత విశ్లేషణ](../ప్రభుత్వంలో-వ్యయ-ప్రభావశీలత-విశ్లేషణ/) ద్వారా ఒకే ఫలితంలోకి మార్చడం నిర్ణయాన్ని స్పష్టం చేయకుండా తప్పుగా చూపించే సందర్భాలు
(<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>).
ఉదాహరణకు, కొత్త జైలు కోసం స్థలం ఎంపికలో మూలధన వ్యయం, సమాజంపై ప్రభావం, రవాణా అనుసంధానం, పర్యావరణ ప్రభావం, సిబ్బంది నియామక అవకాశం మధ్య సమతుల్యత చూడాలి. ఈ ప్రమాణాలకు ఉమ్మడి యూనిట్ ఉండదు. బలవంతంగా ఉమ్మడి యూనిట్ (సాధారణంగా డబ్బు) పెడితే, ఉదాహరణకు పర్యావరణ ప్రభావం, ఖర్చు మధ్య ఏది ఎంత ముఖ్యం అనే విలువ తీర్పును, ఆబ్జెక్టివ్ అంకగణితం ముసుగులో చొప్పించినట్లే అవుతుంది.

MCDA నిజాయితీయే దాని ప్రధాన బలహీనత కూడా: భారాలను మదింపు నిర్వహించేవారు (లేదా ఒక ప్యానెల్) నిర్ణయిస్తారు కాబట్టి, భారాల నిర్ణయ ప్రక్రియ ఎంత చట్టబద్ధంగా ఉంటే పద్ధతి అంతే చట్టబద్ధం. ఇష్టపడిన ఎంపిక నుంచి వెనక్కి పనిచేస్తూ దాన్ని సమర్థించే భారాలను ఎంచుకోకుండా ఉండటానికే, ప్రమాణాలు, భారాలను ఎంపికలకు స్కోర్ ఇచ్చే *ముందే* అంగీకరించి ప్రచురించాలని Green Book మార్గదర్శకత్వం స్పష్టంగా చెబుతుంది.

## గణితం

```
For each option i and criterion j:
  Score_ij   = the option's performance against that criterion (often 0-100
               or 1-10, from evidence, expert judgement, or stakeholder scoring)
  Weight_j   = relative importance of criterion j, weights sum to 1 (or 100)

Weighted score of option i = Σ_j (Score_ij × Weight_j)

Procedure:
1. Agree the criteria set and weights BEFORE scoring any option (swing
   weighting or pairwise comparison, e.g. AHP, are common elicitation methods).
2. Score every option against every criterion on a common scale, from
   evidence where possible.
3. Compute weighted totals; rank options.
4. Sensitivity-test the weights: does the ranking survive plausible
   disagreement about how much each criterion should matter?
```

SCBA నికర ప్రస్తుత విలువ (net present value) ఇచ్చినట్లు, MCDA సమర్థించదగిన పరమ విలువను ఇవ్వదు; అంగీకరించిన భారాలకు లోబడిన ర్యాంకింగ్‌ను మాత్రమే ఇస్తుంది. నిర్ణయం నిజంగా పోల్చలేని మంచిల మధ్య సమతుల్యత గురించి అయినప్పుడు ఇది ఒక సుగుణం. ద్రవ్యీకరణ సాధ్యమైనప్పటికీ ఆ కష్టమైన పనిని తప్పించుకోవడానికి వాడితే ఇది ఒక లోపం.

## ఉదాహరణ సహిత పరిష్కారం

**స్థానిక అధికార సంస్థ**: గృహ వ్యర్థాల రీసైక్లింగ్ కేంద్రం కోసం ఒక కౌన్సిల్ మూడు స్థలాలను నాలుగు ప్రమాణాలపై స్కోర్ చేస్తుంది. భారాలను ఏ స్థల సందర్శనకూ ముందే వివిధ విభాగాల ప్యానెల్ నిర్ణయించింది:

```
Criteria (weight):        Capital cost (30%)  Transport access (25%)
                           Community impact (25%)  Environmental impact (20%)

Site scores (0-100, higher = better):
Site A: cost 80, access 60, community 40, environment 70
Site B: cost 60, access 90, community 70, environment 50
Site C: cost 90, access 50, community 80, environment 60

Weighted totals:
Site A = 80(.30) + 60(.25) + 40(.25) + 70(.20) = 24+15+10+14 = 63
Site B = 60(.30) + 90(.25) + 70(.25) + 50(.20) = 18+22.5+17.5+10 = 68
Site C = 90(.30) + 50(.25) + 80(.25) + 60(.20) = 27+12.5+20+12 = 71.5
```

Site C అగ్రస్థానంలో ఉంది. సమాజ ప్రభావ భారాన్ని 25% నుంచి 35%కి పెంచి (మూలధన వ్యయం నుంచి 10 పాయింట్లు తీసుకుని) సున్నితత్వ పరీక్ష చేస్తే, Site C మొత్తం 71.5 − 3 + 8 = 76.5 అవుతుంది, Site B మొత్తం 68 − 6 + 7 = 69 అవుతుంది. అప్పటికీ Site C ముందంజలో ఉంది. కాబట్టి భారాల గురించి ఆమోదయోగ్యమైన భిన్నాభిప్రాయానికి కూడా ర్యాంకింగ్ తట్టుకుంటుంది. Green Book నివేదికలో చూడాలని ఆశించే తనిఖీ ఇదే.

**స్వచ్ఛంద సంస్థ**: రుణ సలహా సేవ, ఫుడ్ బ్యాంక్ నెట్‌వర్క్, ఆర్థిక అక్షరాస్యత కార్యక్రమం మధ్య నిధులు ఇవ్వడాన్ని ఎంచుకునే ఒక గ్రాంట్ ఫౌండేషన్ SROIకి బదులు MCDA వాడుతుంది ([సామాజిక పెట్టుబడి రాబడి](../సామాజిక-పెట్టుబడి-రాబడి/) చూడండి). కారణం, సంక్షోభ సహాయానికి లేదా నివారణకు ఏది ఎక్కువ బరువు ఇవ్వాలనే దానిపై ట్రస్టీలు చిత్తశుద్ధితో విభేదిస్తారు. MCDA వల్ల ఒకే SROI నిష్పత్తి ఆ విభేదాన్ని పరిష్కరించినట్లు నటించకుండా, విభేదం *స్వరూపాన్ని* (భారాల శ్రేణి) వారు అంగీకరించగలరు.

## సాఫ్ట్‌వేర్ ఇంజనీరింగ్‌తో సంబంధం

ప్రమాణాలు నిజంగా పరస్పర విరుద్ధంగా ఉన్నప్పుడు, విక్రేత, ఆర్కిటెక్చర్ ఎంపికకు MCDA సహజమైన సాధనం. క్లౌడ్-హోస్టెడ్, ఆన్-ప్రెమిసెస్ కేస్ మేనేజ్‌మెంట్ వ్యవస్థల మధ్య ఎంచుకోవడంలో ఖర్చు, డేటా సార్వభౌమత్వ ప్రమాదం, అందుబాటు, అమలు వేగం మధ్య సమతుల్యత ఉంటుంది; అవి ఒకే సంఖ్యకు తగ్గవు. Green Book కోరినట్లే, ఎంపికలకు స్కోర్ ఇవ్వడానికి ముందే భారాల నిర్ణయం జరగాలని ఇంజనీరింగ్ లీడ్‌లు పట్టుబట్టాలి. ఎందుకంటే షార్ట్‌లిస్ట్ చూసిన తర్వాత చేసే భారాల కసరత్తు, గదిలో ఉన్నవారు అప్పటికే ఇష్టపడిన ఎంపిక వైపే తప్పనిసరిగా మొగ్గుతుంది. MCDA సాధారణంగా వర్తించే సందర్భానికి [ప్రభుత్వంలో నిర్మించడం వర్సెస్ కొనడం](../ప్రభుత్వంలో-నిర్మించాలా-లేదా-కొనాలా/), నిర్ణయం ముందు కాకుండా తర్వాత వాడే సంబంధిత నిర్మాణాత్మక స్కోరింగ్ సాధనం కోసం [ప్రజా విలువ స్కోర్‌కార్డ్](../ప్రజా-విలువ-స్కోర్-కార్డ్/) చూడండి.

## సాధారణ లోపాలు

- **ఎంపికలను చూసిన తర్వాత భారాలు నిర్ణయించడం.** MCDAను ఉద్దేశపూర్వకంగానో కాకుండానో మభ్యపెట్టే అత్యంత సాధారణ మార్గం ఇదే. స్కోరింగ్‌కు ముందే భారాలను ప్రచురించండి, ఎవరు నిర్ణయించారో నమోదు చేయండి.
- **భారిత మొత్తాన్ని కచ్చితమైన సంఖ్యగా చూడటం.** సున్నితత్వ విశ్లేషణ ర్యాంకింగ్ స్థిరంగా ఉందని నిర్ధారిస్తే తప్ప, 71.5, 68 మధ్య తేడా గణాంకపరంగా అర్థవంతమైనది కాదు. తప్పుడు కచ్చితత్వం కాకుండా పరిధులను నివేదించండి.
- **సాధ్యమైన ద్రవ్యీకరణను తప్పించుకోవడానికి MCDA వాడటం.** చాలా ప్రమాణాలకు నమ్మదగిన ధర కట్టగలిగితే, [SCBA](../సామాజిక-వ్యయ-ప్రయోజన-విశ్లేషణ/)కి బదులు MCDAకి వెళ్లడం మదింపు వాడగలిగే సమాచారాన్ని వదిలేయడమే.
- **ఒక ఆధిపత్య భాగస్వామి మాత్రమే అన్ని భారాలనూ నిర్ణయించడం.** ఆ వ్యక్తి అప్పటికే కోరుకున్నదాన్నే మదింపు మళ్లీ రాబట్టకుండా ఉండేందుకు, భారాలను స్పాన్సర్ చేస్తున్న డైరెక్టర్ కాకుండా ప్రాతినిధ్య ప్యానెల్ నుంచి రాబట్టాలని Green Book మంచి పద్ధతి ఆశిస్తుంది.
