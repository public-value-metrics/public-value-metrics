# యూనిట్ వ్యయ డేటాబేస్‌లు

యూనిట్ వ్యయ డేటాబేస్ (unit cost database) అనేది సామాజిక ఫలితాలకు ముందే పరిశోధించిన, సాక్ష్యాధారిత ఆర్థిక ప్రాక్సీల గ్రంథాలయం — నిరుద్యోగం నుంచి ఉపాధికి మారడం, తగ్గిన ఒంటరితనం, స్థిరమైన అద్దె ఒప్పందం వంటివాటి విలువ — దీనివల్ల ప్రతిసారీ ప్రత్యేక విలువకట్టే పరిశోధనను నియమించకుండానే ఆచరణదారు ఒక ఫలితాన్ని ద్రవ్యరూపంలోకి మార్చగలడు. నిధుల బిడ్ రాస్తున్న చిన్న స్వచ్ఛంద సంస్థ, ఇతరులు ఇప్పటికే రాబట్టి ప్రచురించిన ప్రాక్సీని మళ్లీ వాడటం ద్వారా, వనరులున్న కన్సల్టెన్సీ అంత కఠినతను వర్తింపజేయగలగడానికే ఇవి ఉన్నాయి.

## ఇది ఎందుకు ముఖ్యం

ఆర్థికవేత్త Daniel Fujiwara తో కలిసి శ్రేయస్సు విలువకట్టే పద్ధతులతో అభివృద్ధి చేసిన HACT యొక్క UK Social Value Bank, మరియు ఆర్థిక ప్రాక్సీల ఓపెన్, క్రౌడ్‌సోర్స్డ్ డేటాబేస్ అయిన Global Value Exchange, యూకే మూడో రంగం, ప్రభుత్వ రంగంలో అత్యంత విస్తృతంగా వాడే రెండు. ఆధారమైన విలువకట్టే పని — [శ్రేయస్సు విలువకట్టడం](../శ్రేయస్సు-విలువకట్టడం/) మరియు [ప్రకటిత ప్రాధాన్యత ఆధారిత విలువకట్టడం](../ప్రకటిత-ప్రాధాన్యత-ఆధారిత-విలువకట్టడం/) — ఖరీదైనది, పద్ధతిపరంగా కఠినమైనది, ప్రతి ప్రాజెక్ట్ కోసం మొదటి నుంచి నడపడం నెమ్మదైనది కాబట్టే ఈ రెండూ ఉన్నాయి. భాగస్వామ్య, ప్రచురిత ప్రాక్సీ గ్రంథాలయం, అనేక నెలల పరిశోధన కసరత్తును ఒక లుక్‌అప్‌గా మారుస్తుంది; అందుకే [సామాజిక పెట్టుబడి రాబడి](../సామాజిక-పెట్టుబడి-రాబడి/) లెక్కలకు, [సామాజిక విలువ చట్టం](../సామాజిక-విలువ-చట్టం/) బిడ్ మూల్యాంకనాలకు అవి ముఖ్యం: అవి లేకపోతే, కఠినమైన ద్రవ్యీకరణ తమ సొంత అధ్యయనాలను నియమించగలిగేంత పెద్ద సంస్థలకే భరించదగినదిగా ఉంటుంది.

## గణితం

యూనిట్ వ్యయ డేటాబేస్ స్వయంగా ఏదీ లెక్కించదు; అది మరెక్కడో చేసే లెక్కకు ఒక ఇన్‌పుట్‌ను అందిస్తుంది:

```
ఆర్థిక ప్రాక్సీ విలువ = మార్కెట్ ధర, లేదా షాడో ధర, లేదా శ్రేయస్సు విలువకట్టడం,
                         లేదా ప్రకటిత-ప్రాధాన్యత విలువ
                         ఫలిత మార్పు యొక్క నిర్వచించిన యూనిట్‌కు
                         (ఉదా. "నిరుద్యోగం నుంచి ఉపాధికి మారే ప్రతి వ్యక్తికి, సంవత్సరానికి")

వర్తింపజేసిన విలువ = సాధించిన ఫలితాల సంఖ్య × యూనిట్ ప్రాక్సీ విలువ
```

మార్కెట్ ధర లేనప్పుడు ప్రాక్సీ ఎలా నిర్మించబడుతుందో [షాడో ప్రైసింగ్](../షాడో-ప్రైసింగ్/) లో, వర్తింపజేసిన విలువ డెడ్‌వెయిట్, ఆపాదింపు సర్దుబాట్ల తర్వాత నిష్పత్తిలోకి ఎలా చేరుతుందో [సామాజిక పెట్టుబడి రాబడి](../సామాజిక-పెట్టుబడి-రాబడి/) లో చూడండి.

## ఉదాహరణ సహిత పరిష్కారం

**స్వచ్ఛంద సంస్థ (స్నేహ-సహవాస సేవ SROI)**: "ఒంటరితనం తగ్గింపు" కోసం యూనిట్ వ్యయ డేటాబేస్ నమోదు, ఒక్కొక్కరికి సంవత్సరానికి £1,100 సూచనాత్మక ప్రాక్సీ ఇస్తుంది. 80 మంది లబ్ధిదారులకు వర్తింపజేస్తే: 80 × £1,100 = £88,000 స్థూల విలువ. అదే డేటాబేస్‌లో అతివ్యాప్తమయ్యే శ్రేయస్సు సర్వే అంశంపై ఆధారపడిన "మెరుగైన మానసిక శ్రేయస్సు" ప్రాక్సీ కూడా ఉంటే, అదే 80 మందికి రెండు ప్రాక్సీలనూ పేర్చడం ఒకే అంతర్లీన మార్పులో కొంత భాగాన్ని రెండుసార్లు లెక్కిస్తుంది — డేటాబేస్ సంఖ్యను అందిస్తుంది, కానీ ఈ అతివ్యాప్తిని నివారించడం విశ్లేషకుడి బాధ్యత.

**స్థానిక ప్రభుత్వ సంస్థ (జాబ్ క్లబ్ SROI)**: "నిరుద్యోగం నుంచి స్థిరమైన ఉపాధికి మారడం" కోసం యూనిట్ వ్యయ డేటాబేస్ నమోదు, ఒక్కొక్కరికి సంవత్సరానికి £8,500 సూచనాత్మక ప్రాక్సీతో 45 మంది పాల్గొనేవారికి వర్తింపజేయబడుతుంది: 45 × £8,500 = £382,500 స్థూల విలువ, [సామాజిక పెట్టుబడి రాబడి](../సామాజిక-పెట్టుబడి-రాబడి/) లో చూపిన డెడ్‌వెయిట్, ఆపాదింపు సర్దుబాట్లకు ముందు.

## సాఫ్ట్‌వేర్ ఇంజనీరింగ్‌తో సంబంధం

స్వచ్ఛంద సంస్థలు లేదా కమిషనర్ల కోసం రిపోర్టింగ్ సాధనాలు నిర్మించే బృందాలకు అంతర్గత "ఫలిత కేటలాగ్" ఉపయోగపడుతుంది — ఒక ఉత్పత్తి లేదా సేవ సహేతుకంగా క్లెయిమ్ చేయగల ప్రతి ఫలితాన్ని పేరున్న ప్రాక్సీకి, దాని మూల డేటాబేస్‌కు, ప్రచురణ తేదీకి, వెర్షన్ ఐడెంటిఫైయర్‌కు మ్యాప్ చేసే పట్టిక — దీనివల్ల సంస్థలోని వేర్వేరు బృందాలు ఒకే ఫలితానికి కొద్దిగా భిన్న విలువలను ఎంచుకోవు. Global Value Exchange యొక్క ఓపెన్ డేటాను లుక్‌అప్ సేవ వెనుక ఉంచి, మూలాన్ని, తేదీని ఎల్లప్పుడూ సంఖ్యతో పాటు చూపడం, ప్రాక్సీని స్ప్రెడ్‌షీట్‌లో దాగిన మాయా సంఖ్యగా కాక ఆడిట్ చేయదగినదిగా ఉంచుతుంది. ఈ ప్రాక్సీలు వినియోగించబడే రెండు ప్రధాన స్థలాల కోసం [సామాజిక పెట్టుబడి రాబడి](../సామాజిక-పెట్టుబడి-రాబడి/), [సామాజిక విలువ చట్టం](../సామాజిక-విలువ-చట్టం/) చూడండి.

## సాధారణ లోపాలు

- **ప్రాక్సీలను కచ్చితమైనవిగా భావించడం.** ప్రచురించిన చాలా ప్రాక్సీలు విస్తృత విశ్వాస అంతరాలున్న శ్రేయస్సు విలువకట్టే అధ్యయనాల నుంచి నమూనా చేసిన సగటులు; ఒకదాన్ని పౌండ్ వరకు ఉటంకించడం ఆధార పరిశోధన సమర్థించే కచ్చితత్వాన్ని అతిశయోక్తి చేస్తుంది.
- **అతివ్యాప్తమయ్యే ప్రాక్సీలను రెండుసార్లు లెక్కించడం.** అతివ్యాప్తమయ్యే సర్వే నిర్మాణాల నుంచి రాబట్టిన ప్రాక్సీలను (ఉదా. "తగ్గిన ఒంటరితనం", "మెరుగైన మానసిక శ్రేయస్సు") కలపడం ఒకే అంతర్లీన మార్పుకు రెండుసార్లు విలువ కడుతుంది.
- **సందర్భం వెలుపలి ప్రాక్సీని సర్దుబాటు చేయకుండా వాడటం.** ఒక జాతీయ జనాభా, సంవత్సరంపై క్రమాంకనం చేసిన ప్రాక్సీని, ద్రవ్యోల్బణం లేదా సందర్భ సర్దుబాటు లేకుండా మరెక్కడైనా వర్తింపజేస్తే నిశ్శబ్దంగా విలువను తప్పుగా చూపుతుంది.
- **మూలాన్ని తనిఖీ చేయకపోవడం.** Global Value Exchange ఓపెన్, క్రౌడ్‌సోర్స్డ్ కాబట్టి, నమోదు నాణ్యత సహకారిని బట్టి మారుతుంది; నిధుల బిడ్ లేదా సేకరణ సమర్పణలో సంఖ్యను ఉటంకించే ముందు ఆధార మూలాన్ని తనిఖీ చేయండి.
