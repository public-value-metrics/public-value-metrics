# సామాజిక డిస్కౌంట్ రేటు

సామాజిక డిస్కౌంట్ రేటు (social discount rate) భవిష్యత్ వ్యయాలను, ప్రయోజనాలను ప్రస్తుత కాల విలువలుగా మారుస్తుంది; దశాబ్దాల పాటు ఫలితాలు విస్తరించిన కార్యక్రమాలను ఉమ్మడి ప్రాతిపదికపై పోల్చడానికి ఇది తోడ్పడుతుంది. HM Treasury యొక్క Green Book మొదటి 30 సంవత్సరాలకు 3.5% వద్ద ఆధారపడిన, తగ్గుతూ పోయే షెడ్యూల్‌ను నిర్దేశిస్తుంది; ఇది Ramsey సూత్రంపై ఆధారపడింది. ఇది ఉటంకించదగిన ఒక నిర్దిష్ట సంఖ్య, కానీ వాతావరణ విధానం లేదా మౌలిక సదుపాయాల వంటి దీర్ఘకాల కట్టుబాట్లకు వర్తింపజేసినప్పుడల్లా అది సజీవ రాజకీయ, నైతిక వాదనగా మారింది.

## ఇది ఎందుకు ముఖ్యం

30 సంవత్సరాల తర్వాత లభించే ఒక పౌండ్ ప్రయోజనం, ఈ రోజు లభించే ఒక పౌండ్ ప్రయోజనంతో సమానం కాదు; దీనికి కారణాలు కొంతవరకు స్వచ్ఛమైన కాల ప్రాధాన్యత (వ్యక్తులు, సమాజాలు మంచి విషయాలను త్వరగా కోరుకుంటాయి), కొంతవరకు వృద్ధి (భవిష్యత్ సమాజం ధనికంగా ఉంటుందని ఆశిస్తారు, కాబట్టి ఉపాంతంగా ఒక పౌండ్ దానికి తక్కువ ముఖ్యం). Green Book యొక్క Annex 6, యూకే ప్రామాణిక డిస్కౌంట్ రేటును Ramsey సూత్రం నుంచి రాబడుతుంది; ఇది స్వచ్ఛమైన కాల ప్రాధాన్యత రేటును, ఆశించిన వినియోగ వృద్ధి రేటును, వినియోగం యొక్క ఉపాంత ప్రయోజన స్థితిస్థాపకతను కలుపుతుంది. దీని ఫలితంగా 0–30 సంవత్సరాలకు సంవత్సరానికి 3.5% ప్రచురిత రేటు వస్తుంది, 31వ సంవత్సరం తరువాత ప్రచురిత షెడ్యూల్‌లో తగ్గుతూ (301+ సంవత్సరాలకు 1% వరకు) వెళ్తుంది. ఈ షెడ్యూల్ ఉండటానికి కారణం, శతాబ్దం పాటు స్థిరమైన 3.5% చక్రవడ్డీ దాదాపు ఏ దీర్ఘకాల ప్రయోజనాన్నైనా — 80 సంవత్సరాల తర్వాత ప్రాణాలు కాపాడే వరద రక్షణ, 100 సంవత్సరాల తర్వాత హానిని నివారించే కార్బన్ తగ్గింపు — ప్రస్తుత విలువలో అతి చిన్నదిగా చూపుతుంది; నిజంగా దీర్ఘకాలం నిలిచే మౌలిక సదుపాయాలు, పర్యావరణ నిర్ణయాలకు ఇది నమ్మశక్యం కాని నైతిక నిర్ధారణ అని Treasury భావించింది.

ఈ ఎంపిక తటస్థ సాంకేతిక పరామితి కాకపోవడం వల్లే డిస్కౌంట్ రేటు వివాదాస్పదమవుతుంది: ఇంకా పుట్టని వారి కోసం సమాజం ఈ రోజు ఎంత త్యాగం చేయాలి అనే విషయంపై ఒక తీర్పును అది పొందుపరుస్తుంది. వాతావరణ ఆర్థికశాస్త్రంపై Stern Review (2006) సున్నాకు దగ్గరగా ఉన్న డిస్కౌంట్ రేటును (స్వచ్ఛమైన కాల ప్రాధాన్యత సుమారు 0.1%) వాడింది; హాని (విపత్కర వాతావరణ మార్పు) తిరిగి సరిచేయలేనిదైనప్పుడు భవిష్యత్ తరాల సంక్షేమాన్ని మార్కెట్ రేట్లవంటి రేటుతో డిస్కౌంట్ చేయడం నైతికంగా సమర్థించలేనిదని అది వాదించింది. విమర్శకులు — ముఖ్యంగా William Nordhaus — Stern యొక్క సున్నాకు దగ్గరి రేటు, దాదాపు డిస్కౌంట్ చేయని భవిష్యత్ ప్రయోజనానికి వ్యతిరేకంగా దాదాపు ఏ ప్రస్తుత వ్యయాన్నైనా సమర్థనీయంగా కనిపించేలా చేయడం ద్వారా తక్షణ వాతావరణ వ్యయానికి అనుకూల వాదనను అతిశయోక్తి చేసిందని వాదించారు. ఈ విభేదం గణితం గురించి కాదు; రేటును ఎవరి నైతిక చట్రం నిర్ణయించాలి అనే దాని గురించి. డిస్కౌంట్ రేటు కేవలం బీమా గణన ఇన్‌పుట్ కాక విధాన ఎంపిక అనడానికి ఇది ఇప్పటికీ ప్రామాణిక ఉదాహరణ.

## గణితం

Green Book రేటుకు ఆధారమైన Ramsey సూత్రం:

```
r = ρ + η·g

ఇక్కడ:
  r = సామాజిక డిస్కౌంట్ రేటు
  ρ = స్వచ్ఛమైన కాల ప్రాధాన్యత రేటు (అసహనం + విపత్తు ప్రమాదం)
  η = వినియోగం యొక్క ఉపాంత ప్రయోజన స్థితిస్థాపకత
  g = తలసరి వినియోగం యొక్క ఆశించిన వార్షిక వృద్ధి రేటు
```

Green Book యొక్క తగ్గుతూ పోయే షెడ్యూల్ (Annex 6, సూచనాత్మకం — ఖచ్చితమైన ప్రచురిత పట్టిక కోసం ప్రస్తుత ఎడిషన్ చూడండి):

```
సంవత్సరాలు 0–30:    3.5%
సంవత్సరాలు 31–75:   3.0%
సంవత్సరాలు 76–125:  2.5%
సంవత్సరాలు 126–200: 2.0%
సంవత్సరాలు 201–300: 1.5%
సంవత్సరాలు 301+:    1.0%
```

భవిష్యత్ మొత్తం యొక్క ప్రస్తుత విలువ:

```
PV = FV / (1 + r)^t
```

## ఉదాహరణ సహిత పరిష్కారం

**వరద రక్షణ పథకం**: ఒక ప్రాజెక్ట్ 40వ సంవత్సరంలో £10 మిలియన్ల నివారించిన వరద నష్టాన్ని అందిస్తుంది.

స్థిర 3.5% రేటుతో: PV = 10,000,000 / (1.035)^40 ≈ £2.52 మిలియన్ — ప్రయోజనం చిన్నదిగా కనిపిస్తుంది.

Green Book యొక్క తగ్గుతూ పోయే షెడ్యూల్‌తో (0–30 సంవత్సరాలకు 3.5%, ఆ తర్వాత 3.0%), లెక్క మొదటి 30 సంవత్సరాలకు 3.5% వద్ద, 31–40 సంవత్సరాలకు 3.0% వద్ద చక్రవడ్డీ అవుతుంది:

```
PV = 10,000,000 / [(1.035)^30 × (1.03)^10]
   = 10,000,000 / [2.807 × 1.344]
   ≈ 10,000,000 / 3.773
   ≈ £2.65 మిలియన్
```

స్థిర అధిక రేటుతో పోలిస్తే, తగ్గుతూ పోయే షెడ్యూల్ దీర్ఘకాల ప్రయోజనాల ప్రస్తుత విలువను కొద్దిగా పెంచుతుంది — షెడ్యూల్ యొక్క స్పష్టమైన ఉద్దేశం ఇదే; ఎందుకంటే శతాబ్దం పాటు స్థిర 3.5% రేటు 100వ సంవత్సరంలోని £100 మిలియన్ ప్రయోజనాన్ని £3.3 మిలియన్ల కంటే తక్కువకు డిస్కౌంట్ చేస్తుంది.

**డిజిటల్ మౌలిక సదుపాయం**: ఇప్పుడు £4 మిలియన్లు ఖర్చయ్యే ప్రభుత్వ క్లౌడ్ మైగ్రేషన్, 15 సంవత్సరాల పాటు సంవత్సరానికి £500,000 పాత నిర్వహణ వ్యయాలను నివారిస్తుందని ఆశిస్తున్నారు. 3.5% వద్ద ఆ వార్షికం యొక్క ప్రస్తుత విలువ సుమారు £500,000 × 11.52 (3.5% వద్ద 15 సంవత్సరాల వార్షిక కారకం) ≈ £5.76 మిలియన్ — £4 మిలియన్ల వ్యయాన్ని హాయిగా మించి, సానుకూల నికర ప్రస్తుత విలువ కేసు అవుతుంది. అమాయకంగా ఎంచుకున్న అధిక రేటుతో ఇది గణనీయంగా బలహీనంగా కనిపిస్తుంది (7% వద్ద అదే వార్షిక కారకం సుమారు 9.11 కు పడిపోతుంది, £4.56 మిలియన్ ఇస్తుంది; ఇంకా సానుకూలమే కానీ చాలా సన్నని మార్జిన్‌తో).

## సాఫ్ట్‌వేర్ ఇంజనీరింగ్‌తో సంబంధం

చాలా సాఫ్ట్‌వేర్ బిజినెస్ కేసులు 3–5 సంవత్సరాల పాటు నడుస్తాయి; అవి స్థిర 3.5% శ్రేణిలోనే ఉంటాయి కాబట్టి తగ్గుతూ పోయే షెడ్యూల్ నేరుగా అరుదుగా ప్రభావం చూపుతుంది — కానీ దీర్ఘ ఆస్తి జీవితం ఉన్న ఏ ప్రభుత్వ సాంకేతిక పెట్టుబడికైనా (జాతీయ ప్లాట్‌ఫారమ్, డేటా మౌలిక సదుపాయాల కార్యక్రమం, అనేక దశాబ్దాల ఒప్పందం) ఆధారమైన క్రమశిక్షణ ముఖ్యం:

- ప్రైవేట్ ఫైనాన్స్ నుంచి అరువు తెచ్చుకున్న అంతర్గత "హర్డిల్ రేటు" కాకుండా Green Book ప్రచురిత రేటును వాడండి; ఆడిటర్లు, Treasury సమీక్షకులు ప్రామాణిక షెడ్యూల్‌నే ఆశిస్తారు.
- చాలా సంవత్సరాల తర్వాత సాకారమయ్యే ప్రయోజనాలకు (ప్లాట్‌ఫారమ్ యొక్క దీర్ఘకాల నిర్వహణ పొదుపులు, ఓపెన్-డేటా పర్యావరణ వ్యవస్థ యొక్క పెరుగుతూ పోయే విలువ — [ఓపెన్ డేటా విలువ](../ఓపెన్-డేటా-విలువ/) చూడండి), డిస్కౌంటింగ్ ఎంపిక బిజినెస్ కేసును సానుకూలం నుంచి ప్రతికూలానికి మార్చగలదు; రేటును, కాల పరిధిని దాగిన డిఫాల్ట్‌లుగా కాక స్పష్టమైన ఊహలుగా చేయండి.
- ఇది నేరుగా [Green Book మదింపు](../green-book-మదింపు/) (డిస్కౌంట్ చేసిన నగదు ప్రవాహాన్ని అధికారికంగా కోరే ఐదు-కేసుల నమూనా) లోకి, మరియు ద్రవ్యేతర శ్రేయస్సు ప్రయోజనాలకు అదే డిస్కౌంటింగ్ ప్రశ్న తలెత్తే [శ్రేయస్సు విలువకట్టడం](../శ్రేయస్సు-విలువకట్టడం/) లోకి ప్రవహిస్తుంది.
- పర్యావరణ, వాతావరణ సాంకేతిక పెట్టుబడికి ప్రత్యేకంగా వర్తించే Stern-వర్సెస్-Nordhaus చర్చ కోసం [తరాంతర సమానత్వం మరియు స్థిరత్వ డిస్కౌంటింగ్](../తరాల-మధ్య-సమానత్వం-మరియు-సుస్థిరత-డిస్కౌంటింగ్/) కూడా చూడండి.

## సాధారణ లోపాలు

- **చాలా సుదీర్ఘ కాల పరిధులకు స్థిర రేటు వాడటం.** స్థిర రేటు నిజంగా దీర్ఘకాలం నిలిచే ప్రయోజనాలను తక్కువగా చూపుతుందనే కారణంతోనే Green Book యొక్క తగ్గుతూ పోయే షెడ్యూల్ ఉంది; అంతటా 3.5% డిఫాల్ట్ చేయకుండా ఏ శ్రేణి వర్తిస్తుందో సరిచూడండి.
- **డిస్కౌంట్ రేటును నైతికంగా తటస్థంగా భావించడం.** Stern-Nordhaus వివాదం ఈ రేటు భవిష్యత్ తరాల గురించి విలువ తీర్పును పొందుపరుస్తుందని చూపుతుంది; దాన్ని మార్చితే ఏ కార్యక్రమాలు సమర్థనీయంగా కనిపిస్తాయో మారుతుంది; కాబట్టి దాన్ని స్ప్రెడ్‌షీట్ డిఫాల్ట్‌లో దాచకుండా పేర్కొని, సమర్థించాలి.
- **సామాజిక డిస్కౌంట్ రేటును ప్రైవేట్ మూలధన వ్యయంతో తికమక పెట్టడం.** ప్రభుత్వ రుణ వ్యయాలు, ప్రైవేట్ రంగ హర్డిల్ రేట్లు Ramsey నుంచి రాబట్టిన సామాజిక రేటుకు భిన్న భావనలు; ప్రభుత్వ మదింపులో ఒకదానికి బదులు మరొకటి వాడితే ఫలితం సాధారణంగా స్వల్పకాల రాబడులకు అనుకూలంగా వక్రీకరించబడుతుంది.
- **వాస్తవ మరియు నామమాత్ర నగదు ప్రవాహాలను అస్థిరంగా డిస్కౌంట్ చేయడం.** Green Book రేటు వాస్తవ (ద్రవ్యోల్బణ-సర్దుబాటు) రేటు; నామమాత్ర నగదు ప్రవాహాలను దానితో డిస్కౌంట్ చేస్తే ప్రస్తుత విలువలు గణనీయంగా తక్కువగా అంచనా అవుతాయి.
