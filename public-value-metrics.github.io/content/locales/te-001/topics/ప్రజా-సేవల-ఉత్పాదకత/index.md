# ప్రజా సేవల ఉత్పాదకత

ప్రజా సేవల ఉత్పాదకత (public service productivity) అంటే ఆరోగ్యం, విద్య, పోలీసింగ్, సామాజిక సంరక్షణ వంటి సేవలకు, ప్రజా వ్యయం ఇన్‌పుట్లను (సిబ్బంది, మూలధనం, వస్తు సేవలు) నాణ్యత-సర్దుబాటు చేసిన ఉత్పాదనలుగా ఎంత సమర్థంగా మార్చుతుందో కొలవడం. ఈ సేవలకు మార్కెట్ ధర ఉండదు, కాబట్టి వ్యయాలను భాగించడానికి ఆదాయ సంఖ్య ఉండదు. UK Office for National Statistics 2000ల మధ్య నుంచి ఈ శ్రేణిని ప్రచురిస్తోంది. "డబ్బును ప్రజా సేవలుగా మార్చడంలో ప్రభుత్వం మెరుగవుతోందా, అధ్వాన్నమవుతోందా?" అనే ప్రశ్నకు సమాధానం చెప్పే అత్యంత పద్ధతిపరంగా అభివృద్ధి చెందిన జాతీయ ప్రయత్నం ఇదే.

## ఇది ఎందుకు ముఖ్యం

మార్కెట్‌లో ఉత్పాదకత = (ఉత్పాదన విలువ) / (ఇన్‌పుట్ వ్యయం), ఉత్పాదన విలువ కనిపిస్తుంది ఎందుకంటే ఎవరో దానికి చెల్లిస్తారు. తుంటి మార్పిడి శస్త్రచికిత్సకు, పాఠశాల సీటుకు, పోలీసు గస్తీకి అమ్మకపు ధర ఉండదు; కాబట్టి అమాయకంగా *ఇన్‌పుట్లు* (ఖర్చు చేసినవి) మాత్రమే కొలవగలరు. అది వ్యాఖ్యాతలను పెరుగుతున్న ప్రజా వ్యయాన్ని ఆటోమేటిక్‌గా చెడుగా చూసేలా ప్రలోభపెడుతుంది: శీర్షిక కార్యకలాపం స్థిరంగా ఉండి ఇన్‌పుట్ పెరగడం ఉత్పాదకత పడిపోవడంలా కనిపిస్తుంది. ప్రజా సేవల ఉత్పాదకతపై ONS "Sources and Methods" ప్రచురణల్లో వివరించిన పద్ధతి దీన్ని పరిష్కరిస్తుంది: కార్యకలాప పరిమాణాల (చేసిన శస్త్రచికిత్సలు, బోధించిన విద్యార్థులు, దర్యాప్తు చేసిన నేరాలు) నుంచి *ఉత్పాదన* సూచికను నిర్మించి, ఆ ఉత్పాదన సూచికను *నాణ్యత-సర్దుబాటు* చేస్తుంది. ఆరోగ్యంలో మనుగడ రేట్లు, వేచి ఉండే సమయాలను; విద్యలో సాధనను; పోలీసింగ్‌లో కేసు పరిష్కారం వంటి ఫలితాలను చేరుస్తుంది. అందువల్ల అదే సంఖ్యలో శస్త్రచికిత్సలు చేసి మెరుగైన మనుగడ రేట్లు సాధించే సేవ కేవలం ఖరీదైనదిగా కాకుండా మరింత ఉత్పాదకంగా నమోదవుతుంది. ONS విడుదలల్లో పునరావృతమయ్యే శీర్షిక కనుగొన్న విషయం రంగానికి ఆలోచింపజేసేది: UK ప్రజా సేవల ఉత్పాదకత COVID-19 మహమ్మారి సమయంలో తీవ్రంగా పడిపోయింది, ONS స్వంత 2020ల మధ్య విడుదలల నాటికి ఆరోగ్య సంరక్షణతో సహా అనేక ఉప-రంగాల్లో వ్యయం పెరిగినా ఇంకా 2019 స్థాయిలకు కోలుకోలేదు. ఈ అంతరం "ఎక్కువ నిధులు", "ఎక్కువ ఉత్పాదకత"ను రెండు పూర్తిగా వేర్వేరు ప్రశ్నలుగా పునర్నిర్వచిస్తుంది.

## గణితం

```
Output index (volume) = Σ (activity_i × relative unit cost weight_i), base-year weighted
                          across all service activities (e.g. hip ops, cataract ops,
                          GP consultations), analogous to a Laspeyres/Paasche volume index

Quality adjustment    = output index × quality adjustment factor
                          (e.g. incorporating a change in survival rates, waiting times,
                          attainment, or reoffending as a multiplier on raw volume)

Input index           = Σ (labour hours × labour cost weight) + (goods/services cost,
                          deflated) + (capital consumption)

Total factor productivity growth = % change in quality-adjusted output index
                                    − % change in input index
```

## ఉదాహరణ సహిత పరిష్కారం

**ఉదాహరణ NHS అక్యూట్-రంగ ఉత్పాదకత లెక్క** (నిర్మాణం ONS పద్ధతిని అనుసరిస్తుంది):

```
Year 1: output volume index = 100.0 (base year), input index = 100.0
        → productivity index = 100.0

Year 2: activity volume rises 3.0% (more operations, more appointments)
        but average waiting time worsens, applying a quality-adjustment
        discount of −1.0%
        Quality-adjusted output index = 100 × 1.030 × 0.990 = 101.97

        Inputs rise: staff numbers +4.0%, other costs (deflated) +1.5%,
        weighted input index = 100 × 1.032 = 103.2

Productivity growth = (101.97 / 100 − 1) − (103.2 / 100 − 1)
                     = 1.97% − 3.2% = −1.23 percentage points

Interpretation: activity rose, but inputs rose faster and quality fell
slightly, so productivity — output per unit of input — declined even
though "more care was delivered."
```

మహమ్మారి తర్వాత NHS కొన్ని భాగాలకు ONS విడుదలలు పదేపదే నివేదించిన ఖచ్చితమైన నమూనా ఇదే: నాణ్యత సర్దుబాటు, ఇన్‌పుట్ వృద్ధి రెండింటినీ పరిగణనలోకి తీసుకున్నప్పుడు, పెరుగుతున్న వ్యయం, పెరుగుతున్న ముడి కార్యకలాపం, తగ్గుతున్న కొలిచిన ఉత్పాదకతతో సహజీవనం చేయడం.

## సాఫ్ట్‌వేర్ ఇంజనీరింగ్‌తో సంబంధం

ప్రజా సేవల ఉత్పాదకత ఇంజనీరింగ్ ఉత్పాదకత చర్చలకు (అందించిన స్టోరీ పాయింట్లు వర్సెస్ [DORA మెట్రిక్స్](../ప్రజా-విలువ-కోసం-dora-కొలమానాలు/) వర్సెస్ [ఫ్లో మెట్రిక్స్](../ప్రభుత్వ-డెలివరీలో-ప్రవాహ-కొలమానాలు/)) జనాభా స్థాయి సమాంతరం: నాణ్యత సర్దుబాటు లేని ముడి త్రూపుట్, సాఫ్ట్‌వేర్ బృందంలో "అందించిన కోడ్ లైన్లు" ఎంత తప్పుదారి పట్టిస్తుందో ఆసుపత్రిలో కూడా అంతే. విభాగాల కోసం పనితీరు డేటా పైప్‌లైన్లు నిర్మించే బృందాలు, నాణ్యత సర్దుబాటును అడుగు వ్యాఖ్యలా కాకుండా ప్రథమ శ్రేణి, వెర్షన్ చేసిన పరివర్తన దశగా పరిగణించాలి. ఎందుకంటే ఆ సర్దుబాటు పారదర్శకంగా, పునరుత్పత్తి చేయగలిగేలా, మెరుగైన నాణ్యత డేటా వచ్చినప్పుడు సవరించబడేలా ఉండటంపైనే ONS విశ్వసనీయత ఆధారపడి ఉంది (అంతర్లీన నాణ్యత డేటా, ఉదాహరణకు మనుగడ రేట్లు, ఖరారయ్యేకొద్దీ ONS గత సంవత్సరాల ఉత్పాదకత అంచనాలను సవరిస్తుంది; కాబట్టి ఈ గణాంకాలను వినియోగించే ఏ దిగువ వ్యవస్థ అయినా కొత్త కాలాలను జోడించడమే కాకుండా వెనుకటి సవరణలను నిర్వహించగలగాలి). ఇది [మొత్తం యాజమాన్య వ్యయం](../ప్రభుత్వ-it-లో-మొత్తం-యాజమాన్య-వ్యయం/), [ప్రభుత్వ రంగంలో AI ఉత్పాదకత](../ప్రభుత్వ-రంగంలో-కృత్రిమ-మేధ-ఉత్పాదకత/)తో కూడా నేరుగా కలుస్తుంది: నాణ్యతను మెరుగుపరచకుండా లేదా నిలబెట్టకుండా ముడి కార్యకలాప పరిమాణాన్ని పెంచే వ్యవస్థ, ONS స్వంత నిర్వచనం ప్రకారం, ఉత్పాదకత మెరుగుదల కాదు.

## సాధారణ లోపాలు

- **ఇన్‌పుట్ వృద్ధిని ఉత్పాదకత వృద్ధిగా పరిగణించడం**: ఎక్కువ సిబ్బందికి నిధులిచ్చే ఎక్కువ వ్యయం ఎక్కువ *కార్యకలాపాన్ని* ఇస్తుంది, ఇన్‌పుట్ యూనిట్‌కు ఉత్పాదన కూడా పెరిగితే తప్ప ఎక్కువ *ఉత్పాదకతను* కాదు. రాజకీయ వ్యాఖ్యానంలో ఈ రెండూ తరచూ కలిపేస్తారు.
- **నాణ్యత సర్దుబాటును పూర్తిగా విస్మరించడం**: ముడి కార్యకలాప లెక్కల నుంచే నిర్మించిన ఉత్పాదన సూచిక, తక్కువ విలువ లేదా తక్కువ నాణ్యత గల దాన్ని ఎక్కువ చేయడం ద్వారా "ఉత్పాదకత లాభాలు" చూపుతుంది. దీన్ని పట్టుకోవడానికే ONS నాణ్యత సర్దుబాటు ఉంది.
- **పద్ధతి వెర్షన్ సరిపోల్చకుండా ఉప-రంగాల మధ్య ఉత్పాదకత సూచికలను పోల్చడం**: ఆరోగ్యం, విద్య, పోలీసింగ్ ఉత్పాదకత ప్రతి ఒక్కటీ వేర్వేరు సవరణ చక్రాల్లో వేర్వేరు కార్యకలాప, నాణ్యత డేటా మూలాల నుంచి నిర్మించబడ్డాయి; అమాయక రంగాంతర పోలిక అననుకూల సాధనాలను పోలుస్తుంది.
- **ఒక సంవత్సరం ఉత్పాదకత తగ్గుదలను శాశ్వత ధోరణిగా చదవడం**: మహమ్మారి కాలం, మహమ్మారి అనంతర ఉత్పాదకత సంఖ్యలు, నాణ్యత డేటా (ఉదా. వెయిటింగ్ లిస్టులు, ఎలెక్టివ్ రికవరీ) మారడంతో సంవత్సరం-సంవత్సరం గణనీయ అస్థిరతను చూపాయి; ఒక్క సంవత్సరం కదలికలను అతిగా అర్థం చేసుకోవద్దని ONS స్థిరంగా హెచ్చరిస్తుంది.
