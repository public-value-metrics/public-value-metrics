# ຕົວຊີ້ວັດຄຸນຄ່າສາທາລະນະ

ບົດນຳທີ່ຄົບຖ້ວນກ່ຽວກັບຄະນິດສາດ, ຕົວຢ່າງ ແລະ ການໃຫ້ເຫດຜົນກ່ຽວກັບຄຸນຄ່າສາທາລະນະ, ຂຽນສຳລັບວິສະວະກອນຊອບແວທີ່ສ້າງລະບົບໃຫ້ອົງການລັດຖະບານ ແລະ ອົງກອນຂະແໜງສັງຄົມທົ່ວໂລກ. ແຕ່ລະໄຟລ໌ກວມໜຶ່ງຕົວຊີ້ວັດ ຫຼື ແນວຄິດ: ຄຳນິຍາມ, ເປັນຫຍັງຈຶ່ງສຳຄັນ, ຄະນິດສາດ, ຕົວຢ່າງການຄິດໄລ່, ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ, ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ ແລະ ແຫຼ່ງອ້າງອີງ.

ມາໃໝ່ບໍ? ເລີ່ມຕົ້ນດ້ວຍ [ຄຸນຄ່າສາທາລະນະ](locales/lo-001/topics/ຄຸນຄ່າສາທາລະນະ/), [ຄວາມຄຸ້ມຄ່າເງິນ](locales/lo-001/topics/ຄວາມຄຸ້ມຄ່າເງິນ/) ແລະ [ທິດສະດີການປ່ຽນແປງ](locales/lo-001/topics/ທິດສະດີການປ່ຽນແປງ/) — ສາມແນວຄິດທີ່ທຸກຢ່າງອື່ນສ້າງຂຶ້ນມາຈາກມັນ.

## ພື້ນຖານຄຸນຄ່າສາທາລະນະ

- [ຄຸນຄ່າສາທາລະນະ](locales/en-gb-oxendict/topics/public-value/) — ສາມຫຼ່ຽມຍຸດທະສາດຂອງ Mark Moore: ຄວາມຊອບທຳ, ພາລະກິດ ແລະ ຄວາມສາມາດໃນການດຳເນີນງານ ເປັນບົດທົດສອບຄຸນຄ່າສາທາລະນະ
- [ຄວາມຄຸ້ມຄ່າເງິນ (VFM)](locales/en-gb-oxendict/topics/value-for-money/) — ຄວາມປະຫຍັດ, ປະສິດທິພາບ, ປະສິດທິຜົນ — ແລະ E ທີສີ່ທີ່ຖືກໂຕ້ແຍ້ງ ຄືຄວາມເທົ່າທຽມ
- [ຕົ້ນທຶນໂອກາດໃນການໃຊ້ຈ່າຍສາທາລະນະ](locales/en-gb-oxendict/topics/opportunity-cost-in-public-spending/) — ທຸກເງິນປອນທີ່ກະຊວງໃຊ້ຈ່າຍ ແມ່ນເງິນປອນທີ່ບໍ່ໄດ້ໃຊ້ກັບໂຄງການທີ່ດີທີ່ສຸດຖັດໄປ
- [ອັດຕາຄິດຫຼຸດທາງສັງຄົມ](locales/en-gb-oxendict/topics/social-discount-rate/) — ອັດຕາຄິດຫຼຸດທີ່ຄ່ອຍໆຫຼຸດລົງຂອງ Green Book ແລະ ເຫດຜົນທີ່ 3.5% ກາຍເປັນຄຳຖາມທາງການເມືອງທີ່ຍັງມີຊີວິດ
- [ການຖ່ວງນ້ຳໜັກດ້ານການກະຈາຍຜົນປະໂຫຍດ](locales/en-gb-oxendict/topics/distributional-weighting/) — ເປັນຫຍັງເງິນໜຶ່ງປອນຈຶ່ງມີຄວາມໝາຍຫຼາຍກວ່າຕໍ່ຄົວເຮືອນທີ່ທຸກຍາກ — ແລະ Green Book ຕີລາຄາເລື່ອງນີ້ແນວໃດ
- [ຜົນເພີ່ມເຕີມ ແລະ ຜົນທີ່ຈະເກີດຂຶ້ນຢູ່ແລ້ວ (Additionality ແລະ Deadweight)](locales/en-gb-oxendict/topics/additionality-and-deadweight/) — ສິ່ງນີ້ຈະເກີດຂຶ້ນຢູ່ແລ້ວບໍ? ຄຳຖາມທີ່ເຮັດໃຫ້ຂໍ້ອ້າງກ່ຽວກັບຜົນກະທົບສ່ວນໃຫຍ່ແຫ່ງລົງ
- [ການຍ້າຍທີ່ ແລະ ການລະບຸຜົນງານ](locales/en-gb-oxendict/topics/displacement-and-attribution/) — ເມື່ອໄຊຊະນະຂອງທ່ານແມ່ນຄວາມສູນເສຍຂອງຄົນອື່ນ, ແລະ ເມື່ອມັນບໍ່ແມ່ນຜົນງານຂອງທ່ານທັງໝົດທີ່ຈະອ້າງ
- [ການວິເຄາະສະຖານະການສົມມຸດ (Counterfactual Analysis)](locales/en-gb-oxendict/topics/counterfactual-analysis/) — ບໍ່ມີສະຖານະການສົມມຸດ ກໍບໍ່ມີຫຼັກຖານ — ການສ້າງໂລກທີ່ບໍ່ມີການແຊກແຊງ

## ການປະເມີນເສດຖະກິດຂອງລັດຖະບານ

- [ການປະເມີນຄຸນຄ່າຕາມ Green Book (ແບບຈຳລອງຫ້າກໍລະນີ)](locales/en-gb-oxendict/topics/green-book-appraisal/) — ແບບຈຳລອງຫ້າກໍລະນີຂອງ HM Treasury: ກໍລະນີຍຸດທະສາດ, ເສດຖະກິດ, ການຄ້າ, ການເງິນ ແລະ ການຄຸ້ມຄອງ
- [ການວິເຄາະຕົ້ນທຶນ-ຜົນປະໂຫຍດທາງສັງຄົມ (SCBA)](locales/en-gb-oxendict/topics/social-cost-benefit-analysis/) — ການຕີທຸກຢ່າງເປັນເງິນ ລວມທັງສິ່ງທີ່ຕະຫຼາດບໍ່ເຄີຍຕັ້ງລາຄາ
- [ການວິເຄາະປະສິດທິຜົນຕໍ່ຕົ້ນທຶນໃນລັດຖະບານ (Cost-Effectiveness Analysis)](locales/en-gb-oxendict/topics/cost-effectiveness-analysis-in-government/) — ຕົ້ນທຶນຕໍ່ໜ່ວຍຜົນລັບ ເມື່ອຜົນລັບບໍ່ສາມາດແປງເປັນເງິນໄດ້ຢ່າງຊື່ສັດ
- [ການວິເຄາະການຕັດສິນໃຈຫຼາຍເກນ (MCDA)](locales/en-gb-oxendict/topics/multi-criteria-decision-analysis/) — ການໃຫ້ຄະແນນທາງເລືອກຕາມເກນທີ່ຖ່ວງນ້ຳໜັກ ເມື່ອຕົວຊີ້ວັດດຽວຈະປິດບັງການແລກປ່ຽນ
- [ການຕີມູນຄ່າຄວາມເປັນຢູ່ທີ່ດີ (WELLBY)](locales/en-gb-oxendict/topics/wellbeing-valuation/) — WELLBY ແລະ ການປັບຄວາມເປັນຢູ່ທີ່ດີ: ການຕັ້ງລາຄານະໂຍບາຍໃນໜ່ວຍຄວາມພໍໃຈໃນຊີວິດ
- [ການຕີມູນຄ່າດ້ວຍຄວາມມັກທີ່ລະບຸ](locales/en-gb-oxendict/topics/stated-preference-valuation/) — ການຖາມຜູ້ຄົນວ່າພວກເຂົາຈະຈ່າຍເທົ່າໃດ — ການຕີມູນຄ່າແບບມີເງື່ອນໄຂ ແລະ ບັນຫາຄວາມໜ້າເຊື່ອຖືຂອງມັນ
- [ການປະເມີນມູນຄ່າຈາກຄວາມມັກທີ່ເປີດເຜີຍ](locales/en-gb-oxendict/topics/revealed-preference-valuation/) — ການສະຫຼຸບມູນຄ່າຈາກສິ່ງທີ່ຜູ້ຄົນເຮັດຈິງ, ຈາກການຕັ້ງລາຄາແບບ hedonic ເຖິງວິທີຕົ້ນທຶນການເດີນທາງ
- [ລາຄາເງົາ](locales/en-gb-oxendict/topics/shadow-pricing/) — ການຕັ້ງລາຄາສິ່ງທີ່ບໍ່ມີລາຄາຕະຫຼາດ: ຄາບອນ, ເວລາ ແລະ ສິນຄ້າທີ່ບໍ່ໄດ້ຊື້ຂາຍ

## ຄຸນຄ່າທາງສັງຄົມ ແລະ ການວັດຜົນກະທົບ

- [ຜົນຕອບແທນທາງສັງຄົມຈາກການລົງທຶນ (SROI)](locales/en-gb-oxendict/topics/social-return-on-investment/) — ອັດຕາສ່ວນ SROI ແລະ ລະບຽບວິໄນທີ່ປ້ອງກັນບໍ່ໃຫ້ມັນກາຍເປັນຕົວເລກການຕະຫຼາດ
- [ທິດສະດີການປ່ຽນແປງ](locales/en-gb-oxendict/topics/theory-of-change/) — ການແຕ້ມແຜນທີ່ຕ່ອງໂສ້ເຫດ-ຜົນຈາກກິດຈະກຳໄປຫາຜົນລັບໄລຍະຍາວ ກ່ອນຈະວັດຫຍັງ
- [ແບບຈຳລອງເຫດຜົນ (Logic Model)](locales/en-gb-oxendict/topics/logic-model/) — ປັດໄຈນຳເຂົ້າ, ກິດຈະກຳ, ຜົນຜະລິດ, ຜົນລັບ, ຜົນກະທົບ — ກະດູກສັນຫຼັງຂອງຄວາມຮັບຜິດຊອບຂອງໂຄງການ
- [ຜົນລັບ ທຽບ ຜົນຜະລິດ](locales/en-gb-oxendict/topics/outcomes-vs-outputs/) — ເປັນຫຍັງ "ມີຜູ້ເຂົ້າຮ່ວມ 500 ຄົນ" ຈຶ່ງບໍ່ແມ່ນຂໍ້ອ້າງດຽວກັນກັບ "ຊີວິດຂອງ 500 ຄົນດີຂຶ້ນ"
- [ກົດໝາຍຄຸນຄ່າທາງສັງຄົມ (Social Value Act)](locales/en-gb-oxendict/topics/social-value-act/) — ພັນທະປີ 2012 ຂອງອັງກິດໃຫ້ພິຈາລະນາຄຸນຄ່າທາງສັງຄົມໃນການຈັດຊື້ຈັດຈ້າງສາທາລະນະ
- [ຖານຂໍ້ມູນຕົ້ນທຶນຕໍ່ໜ່ວຍ](locales/en-gb-oxendict/topics/unit-cost-databases/) — Social Value Bank ຂອງ HACT ແລະ Global Value Exchange: ຕົວແທນທີ່ຄິດຕົ້ນທຶນໄວ້ແລ້ວ ເພື່ອບໍ່ໃຫ້ໃຜເລີ່ມຈາກສູນ
- [ວິທີການປະເມີນຜົນກະທົບ](locales/en-gb-oxendict/topics/impact-evaluation-methods/) — RCT, difference-in-differences ແລະ propensity score matching ສຳລັບນະໂຍບາຍທີ່ທ່ານບໍ່ສາມາດທົດລອງໃນຫ້ອງທົດລອງ
- [ການປະເມີນຜົນກະທົບ ທຽບກັບ ການປະເມີນຂະບວນການ](locales/en-gb-oxendict/topics/impact-evaluation-vs-process-evaluation/) — ມັນໄດ້ຜົນບໍ ທຽບກັບ ມັນເກີດຂຶ້ນຕາມທີ່ອອກແບບບໍ — ສອງຄຳຖາມທີ່ແຕກຕ່າງ, ສອງວິທີທີ່ແຕກຕ່າງ

## ຕົວຊີ້ວັດຜົນງານ ແລະ ການສົ່ງມອບຂອງລັດຖະບານ

- [ຕົວຊີ້ວັດຜົນງານຫຼັກ (KPI) ຂອງພາກລັດ](locales/en-gb-oxendict/topics/public-sector-kpis/) — ການເລືອກຕົວຊີ້ວັດທີ່ຢູ່ລອດຈາກກົດຂອງ Goodhart
- [ບັດຄະແນນຄຸນຄ່າສາທາລະນະ](locales/en-gb-oxendict/topics/public-value-scorecard/) — ການດັດແປງ balanced scorecard ຂອງ Kaplan ແລະ Norton ສຳລັບພາລະກິດທີ່ບໍ່ແມ່ນກຳໄລ
- [ຄວາມຮັບຜິດຊອບຕາມຜົນລັບ (OBA)](locales/en-gb-oxendict/topics/outcomes-based-accountability/) — "Results-Based Accountability" ຂອງ Mark Friedman: ຜົນລັບຂອງປະຊາກອນ ທຽບກັບ ຄວາມຮັບຜິດຊອບຕໍ່ການປະຕິບັດງານ
- [ການຈ່າຍຕາມຜົນສຳເລັດ ແລະ ພັນທະບັດຜົນກະທົບທາງສັງຄົມ (PbR/SIB)](locales/en-gb-oxendict/topics/payment-by-results-and-social-impact-bonds/) — ການຈ່າຍເພື່ອຜົນລັບ, ບໍ່ແມ່ນກິດຈະກຳ — ແລະ ເຫດຜົນທີ່ການອອກແບບແຮງຈູງໃຈຄືທັງໝົດຂອງເກມ
- [ຜະລິດຕະພາບຂອງບໍລິການສາທາລະນະ](locales/en-gb-oxendict/topics/public-service-productivity/) — ການວັດການເຕີບໂຕຂອງຜົນຜະລິດໃນບໍລິການທີ່ບໍ່ມີລາຄາຕະຫຼາດ, ຕັ້ງແຕ່ວິທີວິທະຍາຂອງ ONS ເປັນຕົ້ນໄປ

- [ຕົວຊີ້ວັດຄວາມໄວ້ວາງໃຈ ແລະ ຄວາມຊອບທຳ](locales/en-gb-oxendict/topics/trust-and-legitimacy-metrics/) — ເປັນຫຍັງຄວາມຊອບທຳຈຶ່ງເປັນໜຶ່ງໃນສາມບົດທົດສອບຂອງ Moore, ແລະ ລັດຖະບານພະຍາຍາມວັດມັນແນວໃດ

## ຕົວຊີ້ວັດຂະແໜງສັງຄົມ ແລະ ການກຸສົນ

- [ຕົ້ນທຶນຕໍ່ຜົນໄດ້ຮັບ (Cost per Outcome)](locales/en-gb-oxendict/topics/cost-per-outcome/) — ເສດຖະສາດຕໍ່ໜ່ວຍຂອງອົງການການກຸສົນ: ຕົ້ນທຶນຕໍ່ຄົນທີ່ໄດ້ຮັບການຊ່ວຍເຫຼືອຢ່າງມີຄວາມໝາຍ, ບໍ່ແມ່ນຕໍ່ຄົນທີ່ໄດ້ສຳຜັດ
- [ຕົ້ນທຶນຕໍ່ຜູ້ໄດ້ຮັບຜົນປະໂຫຍດ (Cost per Beneficiary)](locales/en-gb-oxendict/topics/cost-per-beneficiary/) — ພີ່ນ້ອງທີ່ຫຍາບກວ່າ ແລະ ໄວກວ່າຂອງຕົ້ນທຶນຕໍ່ຜົນລັບ, ແລະ ເຫດຜົນທີ່ຜູ້ໃຫ້ທຶນຍັງຖາມຫາມັນ
- [ຄຸນຄ່າແບບປະສົມ (Blended Value)](locales/en-gb-oxendict/topics/blended-value/) — ຜົນຕອບແທນທາງການເງິນ, ສັງຄົມ ແລະ ສິ່ງແວດລ້ອມ ເປັນບັນຊີສຸດທິທີ່ແຍກກັນບໍ່ໄດ້
- [ຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນຂອງການໃຫ້ຢ່າງມີປະສິດທິຜົນ](locales/en-gb-oxendict/topics/effective-altruism-cost-effectiveness/) — ເຫດຜົນຕົ້ນທຶນຕໍ່ຊີວິດທີ່ຊ່ວຍໄວ້ແບບ GiveWell ແລະ ເຊື້ອສາຍຮູບແບບ QALY ຂອງມັນ
- [ອັດຕາສ່ວນຄ່າໃຊ້ຈ່າຍບໍລິຫານຂອງອົງການການກຸສົນ (Overhead Ratio)](locales/en-gb-oxendict/topics/charity-overhead-ratio/) — ເປັນຫຍັງຄຳຖາມ "ເງິນໄປບໍລິຫານເທົ່າໃດ" ຈຶ່ງເປັນຄຳຖາມທີ່ຜິດ, ແລະ ຜູ້ໃຫ້ທຶນຍັງຖາມມັນ
- [ຜົນຕອບແທນຈາກການລົງທຶນຂອງຜູ້ບໍລິຈາກ](locales/en-gb-oxendict/topics/donor-return-on-investment/) — ສິ່ງທີ່ຜູ້ບໍລິຈາກໄດ້ຄືນແທ້ໆ, ແລະ ເປັນຫຍັງມັນບໍ່ແມ່ນ ROI ຂອງອົງການການກຸສົນ
- [ການລາຍງານຜົນລັບຂອງທຶນອຸດໜູນ (IRIS+)](locales/en-gb-oxendict/topics/grant-outcomes-reporting/) — ຕົວຊີ້ວັດ IRIS+ ແລະ ການເຮັດໃຫ້ເປັນມາດຕະຖານຂອງສິ່ງທີ່ຜູ້ໃຫ້ທຶນຂໍໃຫ້ຜູ້ຮັບທຶນລາຍງານ
- [ມູນຄ່າເວລາຂອງອາສາສະໝັກ](locales/en-gb-oxendict/topics/volunteer-time-value/) — ການຕັ້ງລາຄາແຮງງານທີ່ບໍ່ໄດ້ຮັບຄ່າຈ້າງ ໂດຍບໍ່ລຶບລ້າງ ແລະ ບໍ່ພອງມັນ

## ຄຸນຄ່າສາທາລະນະໃນລັດຖະບານດິຈິຕອນ

- [ມາດຕະຖານການບໍລິການດິຈິຕອນ](locales/en-gb-oxendict/topics/digital-service-standard/) — ຫຼັກການອອກແບບຂອງ GOV.UK ແລະ ການປະເມີນບໍລິການເປັນດ່ານຄຸນຄ່າສາທາລະນະ

- [ລັດຖະບານໃນຖານະແພລດຟອມ (GaaP)](locales/en-gb-oxendict/topics/government-as-a-platform/) — ອົງປະກອບທີ່ໃຊ້ຮ່ວມກັນເປັນໂຄງຮ່າງພື້ນຖານສາທາລະນະ: GOV.UK Notify, Pay, ແລະ ເສດຖະສາດຂອງການນຳກັບມາໃຊ້ໃໝ່

- [ຄຸນຄ່າຂອງປັນຍາປະດິດ (AI) ໃນລັດຖະບານ](locales/en-gb-oxendict/topics/ai-in-government-value/) — ການປະເມີນການນຳໃຊ້ AI ໃນບໍລິການສາທາລະນະຕາມເກນຄວາມຄຸ້ມຄ່າເງິນດຽວກັນກັບທຸກຢ່າງອື່ນ

## ຄວາມເປັນຢູ່ທີ່ດີ, ຄວາມເທົ່າທຽມ ແລະ ຕົວຊີ້ວັດສັງຄົມ

- [ດັດຊະນີຄວາມທຸກຍາກຫຼາຍມິຕິ (MPI)](locales/en-gb-oxendict/topics/multidimensional-poverty-index/) — ການນັບຄວາມຂາດແຄນ, ບໍ່ແມ່ນພຽງລາຍໄດ້, ໃນດ້ານສຸຂະພາບ, ການສຶກສາ ແລະ ມາດຕະຖານການດຳລົງຊີວິດ

- [ດັດຊະນີຄວາມຂາດແຄນຫຼາຍມິຕິ (IMD)](locales/en-gb-oxendict/topics/index-of-multiple-deprivation/) — ການຈັດອັນດັບຄວາມຂາດແຄນເຂດຍ່ອຍຂອງອັງກິດ, ແລະ ວິທີທີ່ມັນນຳທາງທຶນ ແລະ ຄວາມສົນໃຈ
- [ຕົວຊີ້ວັດທຶນທາງສັງຄົມ](locales/en-gb-oxendict/topics/social-capital-metrics/) — ຄວາມໄວ້ວາງໃຈ, ເຄືອຂ່າຍ ແລະ ການມີສ່ວນຮ່ວມທາງພົນລະເມືອງ ເປັນຊັບສິນເສດຖະກິດທີ່ບໍ່ມີລາຍການໃນບັນຊີ

- [ຕົວຊີ້ວັດ DORA ສຳລັບຄຸນຄ່າສາທາລະນະ](locales/en-gb-oxendict/topics/dora-metrics-for-public-value/) — ຕົວຊີ້ວັດປະສິດທິພາບການສົ່ງມອບ ທີ່ແປເປັນຖ້ອຍຄຳຄວາມຮັບຜິດຊອບຂອງພາກລັດ
- [ຕົວຊີ້ວັດກະແສໃນການສົ່ງມອບຂອງລັດຖະບານ](locales/en-gb-oxendict/topics/flow-metrics-in-government-delivery/) — Little's Law, WIP ແລະ ປະສິດທິພາບກະແສ ນຳໃຊ້ກັບຄິວກໍລະນີ ແທນກະດານ sprint
- [ໜີ້ທາງເທັກນິກໃນຖານະການກັດກ່ອນຄຸນຄ່າສາທາລະນະ](locales/en-gb-oxendict/topics/technical-debt-as-public-value-erosion/) — ເງິນຕົ້ນ ແລະ ດອກເບ້ຍ, ແລະ ເສດຖະສາດໂລກຊຳເຮື້ອຂອງລະບົບສາທາລະນະເກົ່າ
- [ຕົ້ນທຶນການເປັນເຈົ້າຂອງທັງໝົດ (TCO) ໃນ IT ຂອງລັດຖະບານ](locales/en-gb-oxendict/topics/total-cost-of-ownership-in-government-it/) — ການບຳລຸງຮັກສາແມ່ນ 50-80% ຂອງໃບບິນ; ຄວາມຜິດພາດລາຄາຈັດຊື້ແບບຕື້ນເຂີນໃນ IT ສາທາລະນະ
- [ສ້າງເອງ ຫຼື ຊື້ ໃນລັດຖະບານ (Build vs Buy)](locales/en-gb-oxendict/topics/build-vs-buy-in-government/) — ການປຽບທຽບທີ່ປັບຄວາມສ່ຽງ ໂດຍຕັ້ງລາຄາຄ່າຄວາມຊັກຊ້າ, ສຳລັບຂະແໜງທີ່ສ່ວນໃຫຍ່ຊື້
- [ການຮັບຮູ້ຜົນປະໂຫຍດໃຫ້ເປັນຈິງ (Benefits Realization)](locales/en-gb-oxendict/topics/benefits-realization/) — ການກວດສອບວ່າຜົນປະໂຫຍດທີ່ຄາດໄວ້ໃນແຜນທຸລະກິດໄດ້ເກີດຂຶ້ນແທ້ຫຼັງ go-live
- [ຜະລິດຕະພາບຂອງ AI ໃນຂະແໜງສາທາລະນະ](locales/en-gb-oxendict/topics/ai-productivity-in-the-public-sector/) — ສິ່ງທີ່ຖານຫຼັກຖານຜະລິດຕະພາບນັກພັດທະນາດ້ວຍ AI ບົ່ງບອກສຳລັບທີມວິສະວະກຳພາກລັດ
