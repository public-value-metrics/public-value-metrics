# ຜົນເພີ່ມເຕີມ ແລະ ຜົນທີ່ຈະເກີດຂຶ້ນຢູ່ແລ້ວ (Additionality ແລະ Deadweight)

ຜົນເພີ່ມເຕີມ (additionality) ຖາມວ່າ ການແຊກແຊງນັ້ນເປັນສາເຫດຂອງຜົນໄດ້ຮັບທີ່ຖ້າບໍ່ມີການແຊກແຊງກໍຈະບໍ່ເກີດຂຶ້ນຫຼືບໍ່. ສ່ວນ deadweight ເປັນຄູ່ກົງກັນຂ້າມຂອງມັນ: ຄືສັດສ່ວນຂອງຜົນໄດ້ຮັບທີ່ຈະເກີດຂຶ້ນຢູ່ແລ້ວ ເຖິງວ່າຈະບໍ່ມີໂຄງການ, ເງິນອຸດໜູນ ຫຼື ເງິນສະໜັບສະໜູນນັ້ນກໍຕາມ. ເກືອບທຸກຄຳອ້າງເລື່ອງຜົນກະທົບຈາກໂຄງການຂອງລັດຖະບານ ຫຼື ອົງການການກຸສົນ ຈະເວົ້າເກີນຈິງ ຈົນກວ່າຈະຫັກ deadweight ອອກ, ນັ້ນຈຶ່ງເປັນເຫດຜົນທີ່ຄຳແນະນຳການປະເມີນຜົນຂອງສະຫະລາຊະອານາຈັກ ຖືວ່າມັນເປັນການປັບແກ້ອັນດັບທຳອິດ ແລະ ສຳຄັນທີ່ສຸດຕໍ່ຕົວເລກຫົວຂໍ້ໃດໆ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ປະໂຫຍກ "ພວກເຮົາສະໜັບສະໜູນ 500 ທຸລະກິດໃຫ້ເຕີບໂຕ" ຟັງແລ້ວຄືຄວາມສຳເລັດ, ແຕ່ຖ້າ 300 ໃນທຸລະກິດເຫຼົ່ານັ້ນຈະເຕີບໂຕຢູ່ແລ້ວ — ເພາະເສດຖະກິດທ້ອງຖິ່ນກຳລັງຟື້ນຕົວ, ເພາະມີແຫຼ່ງທຶນອື່ນ, ຫຼື ເພາະມີທິດທາງການເຕີບໂຕຢູ່ກ່ອນໂຄງການຈະເລີ່ມ — ການປະກອບສ່ວນເພີ່ມເຕີມທີ່ແທ້ຈິງຂອງໂຄງການກໍແມ່ນ 200, ບໍ່ແມ່ນ 500. ປຶ້ມຄູ່ມື Magenta Book ຂອງ HM Treasury (ກະຊວງການຄັງຂອງສະຫະລາຊະອານາຈັກ) ແລະ "Additionality Guide" ຂອງ HM Treasury/BIS ທີ່ໃຊ້ມາແຕ່ດົນນານ (ເບື້ອງຕົ້ນພັດທະນາສຳລັບໂຄງການພັດທະນາພາກພື້ນ ແລະ ການຟື້ນຟູເມືອງ, ແລະ ຖືກນຳໃຊ້ຢ່າງກວ້າງຂວາງໃນການປະເມີນຜົນຂອງລັດຖະບານສະຫະລາຊະອານາຈັກນັບແຕ່ນັ້ນມາ) ໄດ້ກຳນົດໃຫ້ deadweight ເປັນຂັ້ນຕອນປັບແກ້ທຳອິດໃນລຳດັບມາດຕະຖານຂອງຜົນກະທົບສຸດທິ: ຜົນລວມ ລົບ deadweight, ລົບ ການຍ້າຍທີ່ (displacement), ລົບ ການຮົ່ວໄຫຼ (leakage), ປັບດ້ວຍຜົນຕົວຄູນ, ເທົ່າກັບ ຜົນກະທົບເພີ່ມເຕີມສຸດທິ. ການຂ້າມຂັ້ນຕອນນີ້ ເປັນວິທີທີ່ພົບເລື້ອຍທີ່ສຸດທີ່ເຮັດໃຫ້ຄຳອ້າງຜົນກະທົບຂອງພາກລັດ ແລະ ພາກສັງຄົມຖືກເວົ້າເກີນຈິງ, ບໍ່ວ່າຈະຕັ້ງໃຈຫຼືບໍ່ກໍຕາມ — ໂຄງການເງິນອຸດໜູນທີ່ວັດພຽງຜົນລວມຂອງຜູ້ເຂົ້າຮ່ວມ ໂດຍບໍ່ມີກຸ່ມປຽບທຽບ ບໍ່ສາມາດແຍກຜົນຂອງຕົນເອງອອກຈາກສິ່ງທີ່ຈະເກີດຂຶ້ນຢູ່ແລ້ວໄດ້.

Deadweight ບໍ່ແມ່ນເປີເຊັນຄົງທີ່; ມັນຂຶ້ນກັບສະຖານະການສົມມຸດ (counterfactual) ຂອງກຸ່ມປະຊາກອນ ແລະ ການແຊກແຊງສະເພາະນັ້ນທັງໝົດ (ເບິ່ງ [ການວິເຄາະສະຖານະການສົມມຸດ](../ການວິເຄາະສະຖານະການສົມມຸດ/)). ການປະເມີນຜົນການພັດທະນາພາກພື້ນໃນອັງກິດພາຍໃຕ້ອົງການພັດທະນາພາກພື້ນ (Regional Development Agencies) ໃນເມື່ອກ່ອນ ມັກພົບອັດຕາ deadweight ຢູ່ໃນຊ່ວງ 20–60% ຂຶ້ນກັບປະເພດຂອງການສະໜັບສະໜູນທຸລະກິດ, ເຊິ່ງເປັນເຫດຜົນທີ່ການປະເມີນໂຄງການທີ່ເຊື່ອຖືໄດ້ຈະລາຍງານຊ່ວງຄ່າທີ່ປັບ deadweight ແລ້ວ ແທນການສົມມຸດຕົວເລກດຽວ, ແລະ ເປັນເຫດຜົນທີ່ຜູ້ໃຫ້ທຶນເຊັ່ນ National Lottery Community Fund ແລະ Big Society Capital ກຳນົດໃຫ້ຜູ້ຮັບທຶນຕ້ອງກ່າວເຖິງ deadweight ຢ່າງຊັດເຈນໃນການລາຍງານຜົນໄດ້ຮັບ ແທນການລາຍງານພຽງຈຳນວນຜູ້ເຂົ້າຮ່ວມລວມ.

## ຄະນິດສາດ

ລຳດັບການປັບແກ້ຜົນກະທົບສຸດທິມາດຕະຖານ ຕາມທີ່ກຳນົດໃນຄຳແນະນຳການປະເມີນຜົນຂອງສະຫະລາຊະອານາຈັກ (Magenta Book; HM Treasury/BIS Additionality Guide; ຄຳແນະນຳການປະເມີນຜົນ ESIF ແລະ ກອງທຶນໂຄງສ້າງ):

```
Gross outcome
  − Deadweight       (what would have happened anyway)
  − Displacement     (activity/benefit shifted from elsewhere, not created — see
                       displacement-and-attribution)
  − Leakage          (benefit accruing outside the target group/area)
  × Multiplier        (additional indirect/induced economic activity, where positive)
  = Net additional impact
```

ອັດຕາ deadweight ໃນຮູບສັດສ່ວນ:

```
Deadweight rate = outcomes that would have occurred without the intervention
                   / total gross outcomes observed

Net additional outcomes = Gross outcomes × (1 − Deadweight rate)
```

## ຕົວຢ່າງການຄິດໄລ່

**ໂຄງການເງິນອຸດໜູນສະໜັບສະໜູນທຸລະກິດ**: ໂຄງການເງິນອຸດໜູນລະດັບພາກພື້ນລາຍງານວ່າ 500 ທຸລະກິດທີ່ໄດ້ຮັບການສະໜັບສະໜູນ ເພີ່ມການຈ້າງງານໃນປີຕໍ່ມາ, ສະເລ່ຍ 3 ຕຳແໜ່ງຕໍ່ທຸລະກິດ — ເປັນຄຳອ້າງລວມ 1,500 ຕຳແໜ່ງງານ.

ກຸ່ມປຽບທຽບທີ່ຈັບຄູ່ກັນ ຊຶ່ງເປັນທຸລະກິດທີ່ຄ້າຍຄືກັນແຕ່ບໍ່ໄດ້ຮັບການສະໜັບສະໜູນ (ເບິ່ງ [ການວິເຄາະສະຖານະການສົມມຸດ](../ການວິເຄາະສະຖານະການສົມມຸດ/)) ສະແດງໃຫ້ເຫັນວ່າ 40% ຂອງການເຕີບໂຕດ້ານການຈ້າງງານຂອງທຸລະກິດທີ່ໄດ້ຮັບການສະໜັບສະໜູນ ຈະເກີດຂຶ້ນຢູ່ແລ້ວ, ໂດຍອີງຕາມຜົນງານຂອງກຸ່ມທີ່ຈັບຄູ່ໃນຊ່ວງເວລາດຽວກັນ.

```
Deadweight rate = 40%
Net additional jobs = 1,500 × (1 − 0.40) = 900 jobs
```

ຜົນສຳເລັດທີ່ລາຍງານໄດ້ຢ່າງຊື່ສັດຂອງໂຄງການແມ່ນ 900 ຕຳແໜ່ງງານ, ບໍ່ແມ່ນ 1,500 — ຫຼຸດລົງ 40% ຈາກການປັບ deadweight ເທົ່ານັ້ນ, ກ່ອນທີ່ຈະພິຈາລະນາການຍ້າຍທີ່ ຫຼື ການຮົ່ວໄຫຼເສຍອີກ.

**ໂຄງການຈ້າງງານຂອງອົງການການກຸສົນ**: ອົງການການກຸສົນແຫ່ງໜຶ່ງຈັດຫາງານໃຫ້ຜູ້ຫວ່າງງານໄລຍະຍາວ 200 ຄົນ ດ້ວຍຕົ້ນທຶນ £600,000 (£3,000 ຕໍ່ການຈັດຫາງານ, ແບບລວມ). ຂໍ້ມູນຕະຫຼາດແຮງງານແຫ່ງຊາດສະແດງວ່າ ຖ້າບໍ່ມີການແຊກແຊງໃດໆ ປະມານ 15% ຂອງກຸ່ມຜູ້ຫວ່າງງານໄລຍະຍາວທີ່ປຽບທຽບໄດ້ ຈະຫາງານໄດ້ພາຍໃນໄລຍະເວລາດຽວກັນ ຜ່ານການຫມູນວຽນຕາມທຳມະຊາດຂອງຕະຫຼາດງານ.

```
Deadweight rate = 15%
Net additional placements = 200 × (1 − 0.15) = 170
True cost per additional placement = £600,000 / 170 ≈ £3,529
```

ຕົວເລກຕົ້ນທຶນຕໍ່ການຈັດຫາງານແບບລວມ (£3,000) ຕ່ຳກວ່າຕົ້ນທຶນແທ້ຈິງຂອງການປະກອບສ່ວນເພີ່ມເຕີມຂອງອົງການການກຸສົນປະມານ 15%.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ຜົນເພີ່ມເຕີມ ແລະ deadweight ມີຄວາມສຳຄັນໂດຍກົງຕໍ່ທຸກຄົນທີ່ສ້າງຊອບແວວັດຜົນກະທົບ ຫຼື ຊອບແວຈັດການເງິນອຸດໜູນສຳລັບພາກລັດ ຫຼື ພາກສັງຄົມ:

- ລະບົບລາຍງານຜົນໄດ້ຮັບຄວນເກັບກຸ່ມປຽບທຽບ ຫຼື ກຸ່ມພື້ນຖານໄວ້ຕັ້ງແຕ່ການອອກແບບ, ບໍ່ແມ່ນພຽງຜົນໄດ້ຮັບຂອງຜູ້ເຂົ້າຮ່ວມ — ການເພີ່ມສະຖານະການສົມມຸດພາຍຫຼັງທີ່ລະບົບເປີດໃຊ້ໂດຍບໍ່ມີມັນ ຍາກກວ່າການສ້າງການເກັບຂໍ້ມູນນັ້ນໃສ່ຕັ້ງແຕ່ເລີ່ມຕົ້ນຫຼາຍ (ເບິ່ງ [ການວິເຄາະສະຖານະການສົມມຸດ](../ການວິເຄາະສະຖານະການສົມມຸດ/)).
- ແດຊບອດທີ່ລາຍງານພຽງຈຳນວນຜູ້ເຂົ້າຮ່ວມລວມ ຈະເຮັດໃຫ້ຜູ້ໃຫ້ທຶນ ແລະ ອົງການກວດກາເຂົ້າໃຈຜົນກະທົບເກີນຈິງຢ່າງເປັນລະບົບ; ເມື່ອມີການປະເມີນ deadweight (ຈາກເອກະສານການປະເມີນ ຫຼື ກຸ່ມປຽບທຽບ) ຊອບແວຄວນສະແດງຕົວເລກທີ່ຫັກ deadweight ແລ້ວຄູ່ກັບຕົວເລກລວມ, ບໍ່ແມ່ນແທນທີ່ມັນ.
- ເລື່ອງນີ້ເຊື່ອມໂຍງໂດຍກົງກັບ [ຜົນຕອບແທນທາງສັງຄົມຕໍ່ການລົງທຶນ](../ຜົນຕອບແທນທາງສັງຄົມຈາກການລົງທຶນ/) ຊຶ່ງອັດຕາສ່ວນ SROI ຈະເຊື່ອຖືໄດ້ກໍຕໍ່ເມື່ອໄດ້ຫັກ deadweight (ແລະ ການຍ້າຍທີ່) ອອກຈາກຜົນໄດ້ຮັບລວມທີ່ອ້າງແລ້ວ — ເຄື່ອງຄິດໄລ່ SROI ທີ່ຂ້າມຂັ້ນຕອນນີ້ ຈະໃຫ້ອັດຕາສ່ວນທີ່ເກີນຈິງ ຊຶ່ງບໍ່ຢືນຢັນໄດ້ເມື່ອຖືກກວດສອບ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ລາຍງານຜົນໄດ້ຮັບລວມຄືກັບວ່າທັງໝົດເປັນຜົນເພີ່ມເຕີມ.** ນີ້ແມ່ນຂໍ້ຜິດພາດໃນການວັດຜົນກະທົບທີ່ພົບເລື້ອຍທີ່ສຸດໃນການລາຍງານເງິນອຸດໜູນ ແລະ ໂຄງການ; ຈົ່ງຖາມສະເໝີວ່າ "ສິ່ງນີ້ຈະເກີດຂຶ້ນຢູ່ແລ້ວບໍ?" ກ່ອນເຜີຍແຜ່ຕົວເລກຫົວຂໍ້.
- **ສົມມຸດວ່າເປີເຊັນ deadweight ດຽວໃຊ້ໄດ້ທຸກບ່ອນ.** Deadweight ແຕກຕ່າງກັນຫຼາຍຕາມຂະແໜງ, ກຸ່ມປະຊາກອນ ແລະ ສະພາບເສດຖະກິດທ້ອງຖິ່ນ; ຈົ່ງໃຊ້ກຸ່ມປຽບທຽບ ຫຼື ຫຼັກຖານສະເພາະຂະແໜງ ແທນການນຳຕົວເລກຈາກການປະເມີນທີ່ບໍ່ກ່ຽວຂ້ອງມາໃຊ້ຊ້ຳ.
- **ສັບສົນລະຫວ່າງ deadweight ກັບການຍ້າຍທີ່.** Deadweight ກ່ຽວກັບຜົນໄດ້ຮັບໃນສະຖານະການສົມມຸດຂອງຜູ້ເຂົ້າຮ່ວມກຸ່ມດຽວກັນ; ສ່ວນການຍ້າຍທີ່ກ່ຽວກັບຜົນກະທົບຕໍ່ຄົນ ຫຼື ສະຖານທີ່ອື່ນ — ເບິ່ງ [ການຍ້າຍທີ່ ແລະ ການລະບຸເຫດຜົນ](../ການຍ້າຍທີ່-ແລະ-ການລະບຸຜົນງານ/). ການປົນສອງຢ່າງນີ້ເຂົ້າກັນນຳໄປສູ່ການນັບຊ້ຳ ຫຼື ນັບຂາດໃນການປັບແກ້.
- **deadweight ທີ່ຜູ້ເຂົ້າຮ່ວມລາຍງານເອງ.** ການຖາມຜູ້ໄດ້ຮັບຜົນປະໂຫຍດວ່າ "ສິ່ງນີ້ຈະເກີດຂຶ້ນບໍ ຖ້າບໍ່ມີການຊ່ວຍເຫຼືອຂອງພວກເຮົາ?" ໃຫ້ຄ່າປະເມີນ deadweight ຕ່ຳເກີນໄປຢ່າງເປັນລະບົບ (ຜູ້ເຂົ້າຮ່ວມມັກໃຫ້ເຄຣດິດແກ່ໂຄງການ); ກຸ່ມປຽບທຽບທີ່ເປັນອິດສະຫຼະເຊື່ອຖືໄດ້ຫຼາຍກວ່າຫຼາຍ.
