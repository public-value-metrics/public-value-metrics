# ທິດສະດີການປ່ຽນແປງ

ທິດສະດີການປ່ຽນແປງ (theory of change) ແມ່ນເສັ້ນທາງເຫດ-ຜົນທີ່ຊັດເຈນ ແຕ້ມຍ້ອນກັບຈາກເປົ້າໝາຍໄລຍະຍາວ ໄປຫາເງື່ອນໄຂເບື້ອງຕົ້ນ ແລະ ກິດຈະກຳທີ່ຕ້ອງມີເພື່ອໃຫ້ບັນລຸເປົ້າໝາຍ, ພ້ອມກັບສົມມຸດຕິຖານທີ່ເຊື່ອມແຕ່ລະຂໍ້ຕໍ່. ມັນສ້າງໂດຍເລີ່ມຈາກຜົນລັບທີ່ທ່ານຕ້ອງການ ແລ້ວຖາມວ່າ "ກ່ອນໜ້ານີ້ທັນທີ, ຕ້ອງມີຫຍັງເປັນຈິງ ເພື່ອໃຫ້ສິ່ງນີ້ເກີດຂຶ້ນ?" ຊ້ຳໆ ຈົນເຖິງກິດຈະກຳທີ່ທ່ານສົ່ງມອບໄດ້ຈິງ — ເຊິ່ງເປັນທິດທາງກົງກັນຂ້າມກັບ[ແບບຈຳລອງເຫດຜົນ](../ແບບຈຳລອງເຫດຜົນ/), ແລະ ເປັນເຫດຜົນທີ່ທັງສອງເສີມກັນ ແທນທີ່ຈະແທນກັນໄດ້.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ວິທີແຕ້ມຍ້ອນກັບນີ້ຖືກວາງເປັນທາງການໂດຍ Center for Theory of Change ແລະ ActKnowledge, ຕໍ່ຍອດຈາກວຽກຂອງນັກປະເມີນ Carol Weiss ກ່ຽວກັບການເຮັດໃຫ້ສົມມຸດຕິຖານຂອງໂຄງການຊັດເຈນເພື່ອທົດສອບໄດ້ ແທນທີ່ຈະເຊື່ອດ້ວຍສັດທາ. ການປະເມີນທຶນຂອງອັງກິດໄດ້ຮັບເອົາເລື່ອງນີ້ໂດຍກົງ: Magenta Book ຂອງ HM Treasury ຖືທິດສະດີການປ່ຽນແປງເປັນຈຸດເລີ່ມຕົ້ນຂອງທຸກການອອກແບບການປະເມີນ, ແລະ ຜູ້ໃຫ້ທຶນເຊັ່ນ National Lottery Community Fund ກຳນົດໃຫ້ຜູ້ສະໝັກຕ້ອງອະທິບາຍມັນກ່ອນຈະໃຫ້ທຶນຂໍ້ສະເໜີ. ເຫດຜົນທີ່ມັນສຳຄັນຕໍ່ວິສະວະກອນຊອບແວແມ່ນວ່າ ທິດສະດີການປ່ຽນແປງເປັນເອກະສານທີ່ຄວນກຳນົດສິ່ງທີ່ລະບົບຂອງທ່ານຕ້ອງວັດ — ຖ້າຕ່ອງໂສ້ເຫດ-ຜົນບອກວ່າ "ການຮັບສິດທິປະໂຫຍດຂຶ້ນກັບການທີ່ຜູ້ຮ້ອງຂໍໄດ້ຮັບການຄິດໄລ່ສ່ວນບຸກຄົນ", ນັ້ນເປັນຂໍ້ອ້າງທີ່ທົດສອບໄດ້ ທີ່ຜະລິດຕະພັນຂອງທ່ານສາມາດຕິດຕັ້ງເຄື່ອງມືວັດເພື່ອສະແດງຫຼັກຖານ ຫຼື ໂຕ້ແຍ້ງ.

## ຄະນິດສາດ

ທິດສະດີການປ່ຽນແປງເປັນໂຄງສ້າງ ບໍ່ແມ່ນຕົວເລກ. ແຕ່ລະຂໍ້ຕໍ່ຄວນມີທັງສົມມຸດຕິຖານ ແລະ ຕົວຊີ້ວັດທີ່ສາມາດສະແດງວ່າສົມມຸດຕິຖານນັ້ນຜິດ:

```
Long-term outcome (the goal)
  ↑ precondition + assumption + indicator
Intermediate outcome N
  ↑ precondition + assumption + indicator
  ...
Intermediate outcome 1
  ↑ precondition + assumption + indicator
Activities / interventions
  ↑ resources committed
Inputs
```

ໂຄງສ້າງນີ້ປ້ອນໂດຍກົງເຂົ້າສູ່[ວິທີການປະເມີນຜົນກະທົບ](../ວິທີການປະເມີນຜົນກະທົບ/), ເຊິ່ງມີຢູ່ເພື່ອທົດສອບວ່າສົມມຸດຕິຖານທີ່ແຕ່ລະຂໍ້ຕໍ່ເປັນຈິງຫຼືບໍ່, ແລະ ເຂົ້າສູ່
[ການວິເຄາະສະຖານະການສົມມຸດ](../ການວິເຄາະສະຖານະການສົມມຸດ/), ເຊິ່ງທົດສອບວ່າຜົນລັບໄລຍະຍາວຈະເກີດຂຶ້ນຢູ່ແລ້ວຫຼືບໍ່.

## ຕົວຢ່າງການຄິດໄລ່

**ອົງການປົກຄອງທ້ອງຖິ່ນ (ການປ້ອງກັນການບໍ່ມີທີ່ຢູ່ອາໄສ)**: ຜົນລັບໄລຍະຍາວແມ່ນການເຊົ່າທີ່ຍືນຍົງເມື່ອຄົບ 12 ເດືອນ ສຳລັບຄົວເຮືອນທີ່ມີຄວາມສ່ຽງຖືກຂັບໄລ່.

- ເງື່ອນໄຂເບື້ອງຕົ້ນ: ຄົວເຮືອນມີແຜນຜ່ອນຊຳລະໜີ້ຄ້າງທີ່ເປັນໄປໄດ້ ແລະ ຈ່າຍໄດ້.
  ສົມມຸດຕິຖານ: ແຜນທີ່ເຈົ້າໜ້າທີ່ກໍລະນີເຈລະຈາຍືນຍົງກວ່າແຜນທີ່ສານສັ່ງ.
  ຕົວຊີ້ວັດ: % ຂອງແຜນທີ່ຍັງມີຜົນຢູ່ເມື່ອຄົບ 6 ເດືອນ.
- ເງື່ອນໄຂເບື້ອງຕົ້ນ: ຄົວເຮືອນຮ້ອງຂໍເງິນສະຫວັດດີການທີ່ມີສິດໄດ້ຮັບ.
  ສົມມຸດຕິຖານ: ເຄື່ອງຄິດໄລ່ສິດທິປະໂຫຍດດິຈິຕອນເພີ່ມການຮ້ອງຂໍທີ່ຖືກຕ້ອງເມື່ອທຽບກັບແບບຟອມເຈ້ຍ.
  ຕົວຊີ້ວັດ: ອັດຕາຄວາມຖືກຕ້ອງຂອງການຮ້ອງຂໍ, ທຽບກ່ອນ/ຫຼັງການເປີດໃຊ້ເຄື່ອງມື.
- ກິດຈະກຳ: ການຄັດກອງໂດຍເຈົ້າໜ້າທີ່ກໍລະນີ, ເຄື່ອງຄິດໄລ່ສິດທິປະໂຫຍດດິຈິຕອນ, ການເຈລະຈາໜີ້ຄ້າງ.

ໃນກຸ່ມທົດລອງ 120 ຄົວເຮືອນ, ສົມມຸດຕິຖານເຄື່ອງຄິດໄລ່ສິດທິປະໂຫຍດເປັນຈິງສຳລັບ 102 ຄົວເຮືອນ (85%) ທີ່ໄປຮ້ອງຂໍໄດ້ຖືກຕ້ອງ, ຢືນຢັນດ້ວຍການປະເມີນຂະບວນການຕໍ່ມາ — ໃຫ້ທີມໂຄງການມີຫຼັກຖານສຳລັບຂໍ້ຕໍ່ສະເພາະນັ້ນ ແທນທີ່ຈະເປັນຂໍ້ອ້າງດຽວຈາກຕົ້ນຈົນປາຍກ່ຽວກັບການປ້ອງກັນການບໍ່ມີທີ່ຢູ່ອາໄສ.

**ອົງການການກຸສົນ (ການເປັນຜູ້ແນະນຳເຍົາວະຊົນ)**: ຜົນລັບໄລຍະຍາວແມ່ນການຖືກໄລ່ອອກຈາກໂຮງຮຽນຫຼຸດລົງ. ເງື່ອນໄຂເບື້ອງຕົ້ນທີ່ແຕ້ມຍ້ອນກັບ: ການຄວບຄຸມອາລົມທີ່ດີຂຶ້ນ → ສາຍສຳພັນຕົວຕໍ່ຕົວທີ່ໄວ້ວາງໃຈກັບຜູ້ແນະນຳ → ການຕິດຕໍ່ປະຈຳອາທິດຢ່າງສະໝ່ຳສະເໝີຕະຫຼອດສອງພາກຮຽນ. ທິດສະດີເຮັດໃຫ້ຊັດເຈນວ່າ ຖ້າຂາດເງື່ອນໄຂ "ການຕິດຕໍ່ປະຈຳອາທິດຢ່າງສະໝ່ຳສະເໝີ" (ເຊັ່ນ ຍ້ອນຜູ້ແນະນຳປ່ຽນໜ້າ) ຄາດວ່າຜົນລັບຈະບໍ່ຕາມມາ, ເຊິ່ງເປັນຂໍ້ອ້າງທີ່ທົດສອບໄດ້ ແລະ ພິສູດວ່າຜິດໄດ້ ແທນທີ່ຈະເປັນຄວາມຫວັງ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ທິດສະດີການປ່ຽນແປງຄວນກຳນົດຮູບຮ່າງແບບຈຳລອງຂໍ້ມູນຂອງຜະລິດຕະພັນກ່ອນສ້າງແດຊ໌ບອດໃດໆ: ລະບຸວ່າຂໍ້ຕໍ່ໃດຕ້ອງມີຕົວຊີ້ວັດ, ແລະ ຕິດຕັ້ງເຄື່ອງມືວັດສະເພາະຂໍ້ເຫຼົ່ານັ້ນ, ແທນທີ່ຈະເລືອກສິ່ງທີ່ບັນທຶກໄດ້ງ່າຍທີ່ສຸດເປັນຄ່າເລີ່ມຕົ້ນ. ມັນຍັງເປັນລະບຽບວິໄນຕໍ່ການສົນທະນາແຜນງານ — ຄຸນສົມບັດທີ່ບໍ່ສອດຄ່ອງກັບຂໍ້ຕໍ່ໃດໃນຕ່ອງໂສ້ ບໍ່ເຫັນໄດ້ຊັດວ່າຄຸ້ມຄ່າທີ່ຈະສ້າງ. ເບິ່ງ
[ແບບຈຳລອງເຫດຜົນ](../ແບບຈຳລອງເຫດຜົນ/) ສຳລັບຕ່ອງໂສ້ຄວາມຮັບຜິດຊອບດ້ານໜ້າທີ່ສ້າງຂຶ້ນເມື່ອທິດສະດີໄດ້ຮັບການຕົກລົງ, [ຜົນຕອບແທນທາງສັງຄົມຈາກການລົງທຶນ](../ຜົນຕອບແທນທາງສັງຄົມຈາກການລົງທຶນ/) ສຳລັບວິທີທີ່ຂຶ້ນກັບທິດສະດີການປ່ຽນແປງເພື່ອກຳນົດຂອບເຂດຜົນລັບທີ່ຈະຕີມູນຄ່າ, ແລະ
[ຜົນລັບ ທຽບ ຜົນຜະລິດ](../ຜົນລັບ-ທຽບ-ຜົນຜະລິດ/) ສຳລັບຄວາມແຕກຕ່າງທີ່ຂໍ້ຕໍ່ຜົນລັບລະດັບກາງຂຶ້ນກັບ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ສັບສົນກັບແບບຈຳລອງເຫດຜົນ.** ທິດສະດີການປ່ຽນແປງເປັນເຫດ-ຜົນ ແລະ ອະທິບາຍ (ເປັນຫຍັງພວກເຮົາເຊື່ອວ່າມັນໄດ້ຜົນ); ແບບຈຳລອງເຫດຜົນເປັນລຳດັບ ແລະ ພັນລະນາ (ມີຫຍັງເກີດຂຶ້ນຕາມລຳດັບໃດ). ການສ້າງພຽງຢ່າງດຽວເຮັດໃຫ້ຂາດ "ເປັນຫຍັງ" ຫຼື ຮ່ອງຮອຍຄວາມຮັບຜິດຊອບ.
- **ປ່ອຍສົມມຸດຕິຖານໃຫ້ຄຸມເຄືອ.** ຄຸນຄ່າທັງໝົດຂອງການແຕ້ມຍ້ອນກັບແມ່ນການເຜີຍສົມມຸດຕິຖານທີ່ທົດສອບໄດ້; ທິດສະດີການປ່ຽນແປງທີ່ພຽງລາຍການກ່ອງ ແລະ ລູກສອນ ໂດຍບໍ່ລະບຸວ່າອັນໃດສາມາດເຮັດໃຫ້ແຕ່ລະຂໍ້ຕໍ່ຜິດ ເປັນພຽງເຄື່ອງປະດັບ.
- **ສ້າງຄັ້ງດຽວແລ້ວເກັບໄວ້.** ທິດສະດີການປ່ຽນແປງທີ່ຂຽນສຳລັບຄຳຂໍທຶນ ແລະ ບໍ່ເຄີຍກັບມາເບິ່ງ ຈະເລີກມີປະໂຫຍດທັນທີທີ່ຫຼັກຖານເລີ່ມຂັດກັບຂໍ້ຕໍ່ໃດໜຶ່ງ.
- **ຂ້າມການປ້ອນຂໍ້ມູນຈາກຜູ້ມີສ່ວນໄດ້ສ່ວນເສຍ.** ທິດສະດີການປ່ຽນແປງທີ່ສ້າງທັງໝົດໂດຍຜູ້ວ່າຈ້າງ ໂດຍບໍ່ມີຂໍ້ມູນຈາກພະນັກງານແຖວໜ້າ ຫຼື ຜູ້ໄດ້ຮັບຜົນປະໂຫຍດ ມັກເຂົ້າລະຫັດສົມມຸດຕິຖານທີ່ບໍ່ມີໃຜທີ່ສົ່ງມອບບໍລິການເຊື່ອແທ້ໆ.
