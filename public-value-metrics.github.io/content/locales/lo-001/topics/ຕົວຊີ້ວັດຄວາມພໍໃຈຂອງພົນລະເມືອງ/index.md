# ຕົວຊີ້ວັດຄວາມພໍໃຈຂອງພົນລະເມືອງ

ຕົວຊີ້ວັດຄວາມພໍໃຈຂອງພົນລະເມືອງ ວັດວ່າປະຊາຊົນໃຫ້ຄະແນນປະສົບການໂດຍກົງຂອງຕົນຕໍ່ການບໍລິການສາທາລະນະແນວໃດ — ແຕກຕ່າງຈາກຄວາມໄວ້ວາງໃຈຕໍ່ສະຖາບັນໂດຍທົ່ວໄປ, ແລະ ແຕກຕ່າງຈາກວ່າການບໍລິການນັ້ນໄດ້ຜົນໄດ້ຮັບທີ່ດີແທ້ຫຼືບໍ່. ການບໍລິການອາດເປັນທີ່ຊື່ນຊອບແຕ່ບໍ່ມີປະສິດທິຜົນ, ຫຼື ມີປະສິດທິຜົນແຕ່ບໍ່ເປັນທີ່ຊື່ນຊອບ; ຊ່ອງຫວ່າງລະຫວ່າງສອງຢ່າງນັ້ນເປັນຂໍ້ມູນວິນິດໄສທີ່ທີມສົ່ງມອບຄວນເຝົ້າເບິ່ງ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ຄວາມພໍໃຈຖືກວັດໃນສອງລະດັບທີ່ຖືກສັບສົນກັນເປັນປະຈຳ. ໃນລະດັບການບໍລິການ, Performance Platform ຂອງສະຫະລາຊະອານາຈັກທີ່ປິດໄປແລ້ວ ແລະ GOV.UK service manual ໃນປັດຈຸບັນ ກຳນົດໃຫ້ມີແບບສຳຫຼວດຄວາມພໍໃຈຕໍ່ການບໍລິການ (ໂດຍປົກກະຕິເປັນລະດັບຫ້າຂັ້ນຈາກ "ພໍໃຈຫຼາຍ" ຫາ "ບໍ່ພໍໃຈຫຼາຍ", ດຳເນີນ ໃນຈຸດທີ່ເຮັດທຸລະກຳ) ເປັນໜຶ່ງໃນສີ່ KPI ບັງຄັບຂອງການບໍລິການ — ເບິ່ງ [ມາດຕະຖານການບໍລິການ ແລະ ຕົວຊີ້ວັດທຸລະກຳ](../ມາດຕະຖານບໍລິການ-ແລະ-ຕົວຊີ້ວັດທຸລະກຳ/). ໃນລະດັບສະຖາບັນ, Civil Service People Survey ຂອງສະຫະລາຊະອານາຈັກ ວັດຄວາມຜູກພັນ ແລະ ປະສົບການຂອງພະນັກງານທົ່ວທຸກກົມລັດຖະບານກາງປະຈຳປີ, ແລະ ແຍກຕ່າງຫາກ ໂຄງການ "Trust in Government" ຂອງ OECD ສຳຫຼວດຄວາມໄວ້ວາງໃຈຂອງປະຊາຊົນຕໍ່ລັດຖະບານແຫ່ງຊາດໃນບັນດາປະເທດສະມາຊິກ, ຕິດຕາມຮູບແບບການຫຼຸດລົງ ແລະ ຟື້ນຕົວໄລຍະຍາວທີ່ຖືກກຳນົດໂດຍວິກິດການຢ່າງໜັກ (ທັງວິກິດການເງິນປີ 2008 ແລະ ການລະບາດຂອງ COVID-19 ສ້າງການເຄື່ອນໄຫວທີ່ແຮງ ແລະ ເຫັນໄດ້ຊັດໃນຕົວເລກຄວາມໄວ້ວາງໃຈຂອງ OECD). ເຫດຜົນທີ່ວິສະວະກອນທີ່ສ້າງບໍລິການສຳລັບພົນລະເມືອງຕ້ອງແຍກຄວາມພໍໃຈ ແລະ ຜົນໄດ້ຮັບອອກຈາກກັນ ແມ່ນຮູບແບບຄວາມລົ້ມເຫຼວທີ່ຮູ້ຈັກໃນການອອກແບບບໍລິການ: ແບບຟອມດິຈິຕອນທີ່ອອກແບບຢ່າງສວຍງາມ ແລະ ໃຊ້ງ່າຍສຳລັບການຮ້ອງຂໍເງິນຊ່ວຍເຫຼືອ ສາມາດໄດ້ຄະແນນຄວາມພໍໃຈສູງຫຼາຍ ໃນຂະນະທີ່ນະໂຍບາຍທີ່ຢູ່ເບື້ອງຫຼັງ — ກົດເກນຄຸນສົມບັດ, ງານຄ້າງ, ຈຳນວນເງິນທີ່ໄດ້ຮັບ — ບໍ່ໄດ້ເຮັດໃຫ້ຜູ້ຮ້ອງຂໍດີຂຶ້ນ. ຄວາມພໍໃຈວັດໜ້າຕາ; ມັນບໍ່ໄດ້ວັດຄຸນຄ່າທີ່ສົ່ງມອບຢູ່ເບື້ອງຫຼັງ.

## ຄະນິດສາດ

```
Net satisfaction = % satisfied (or very satisfied) − % dissatisfied (or very dissatisfied)
                    (neutral/no-opinion responses excluded from both terms, but counted
                    in the response base for calculating each percentage)

Satisfaction-to-outcome gap = satisfaction score − outcome achievement score
                    (both normalized 0–100; a large positive gap signals a service
                    that "feels good" but under-delivers on substance)

Trust index (OECD-style) = % of survey respondents answering "yes" to
                    "do you have confidence in [national government]?"
                    tracked as a time series, typically disaggregated by
                    age, income, and education
```

## ຕົວຢ່າງການຄິດໄລ່

**ບໍລິການໃບແຈ້ງໜີ້ພາສີສະພາທາງອີເລັກໂທຣນິກຂອງອົງການປົກຄອງທ້ອງຖິ່ນ**: ແບບສຳຫຼວດຄວາມພໍໃຈໃນຈຸດທີ່ທຸລະກຳສຳເລັດ ສະແດງຜູ້ຕອບ 2,400 ຄົນ: 1,650 ພໍໃຈ/ພໍໃຈຫຼາຍ, 250 ບໍ່ພໍໃຈ/ບໍ່ພໍໃຈຫຼາຍ, 500 ເປັນກາງ.

```
Net satisfaction = (1,650/2,400 × 100) − (250/2,400 × 100)
                  = 68.75% − 10.42%
                  = +58.3 net satisfaction
```

ເບິ່ງແຂງແຮງເມື່ອພິຈາລະນາແບບໂດດດ່ຽວ. ແຕ່ແບບສຳຫຼວດສະແດງໃຫ້ສະເພາະຜູ້ໃຊ້ທີ່ເຮັດທຸລະກຳ*ສຳເລັດ*ເທົ່ານັ້ນ — ເປັນຄວາມລຳອຽງໃນການວັດທີ່ຮູ້ຈັກ (ເບິ່ງຂໍ້ຜິດພາດທີ່ມັກເກີດຂ້າງລຸ່ມ). ເມື່ອຄູ່ມັນກັບຕົວຊີ້ວັດອັດຕາການສຳເລັດຈາກ [ມາດຕະຖານການບໍລິການ ແລະ ຕົວຊີ້ວັດທຸລະກຳ](../ມາດຕະຖານບໍລິການ-ແລະ-ຕົວຊີ້ວັດທຸລະກຳ/) ສະແດງວ່າອັດຕາການສຳເລັດມີພຽງ 71%, ໝາຍຄວາມວ່າ:

```
True population satisfaction is unmeasured for the 29% who abandoned the journey —
plausibly the most dissatisfied cohort, since abandonment is itself a strong negative
signal the survey never captures.
```

**ຕົວຢ່າງລະດັບຊາດ (ໂຄງສ້າງຂອງຊຸດຂໍ້ມູນຄວາມໄວ້ວາງໃຈແບບ OECD)**: ຄວາມໄວ້ວາງໃຈຕໍ່ລັດຖະບານແຫ່ງຊາດລາຍງານທີ່ 42% ໃນປີທີ 1, ຫຼຸດເປັນ 34% ໃນປີທີ 2 (ປີວິກິດ) ແລະ ຟື້ນເປັນ 39% ໃນປີທີ 3 — ເສັ້ນທາງທົ່ວໄປຂອງຮູບແບບການຖືກຊັອກແລ້ວຟື້ນຕົວບາງສ່ວນ ທີ່ OECD ບັນທຶກໃນບັນດາປະເທດສະມາຊິກຫຼັງວິກິດໃຫຍ່.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ຕິດຕັ້ງແບບສຳຫຼວດຄວາມພໍໃຈໃນທຸກຈຸດອອກທີ່ມີຄວາມໝາຍຂອງການເດີນທາງຂອງຜູ້ໃຊ້, ບໍ່ແມ່ນສະເພາະຕອນສຳເລັດ — ເປັນຂໍ້ຜິດພາດດ້ານວິສະວະກຳທີ່ພົບເລື້ອຍທີ່ສຸດໃນເລື່ອງນີ້, ແລະ ປ່ຽນຕົວຊີ້ວັດຄວາມພໍໃຈໃຫ້ກາຍເປັນຕົວຊີ້ວັດຜິວເຜີນທີ່ມີອະຄະຕິຜູ້ລອດຊີວິດຢ່າງງຽບໆ. ເມື່ອເປັນໄປໄດ້ ໃຫ້ຄູ່ຄະແນນຄວາມພໍໃຈກັບຕົວຊີ້ວັດການສຳເລັດ ຫຼື ຜົນໄດ້ຮັບໃນແດຊບອດດຽວກັນ ເພື່ອໃຫ້ທີມບໍ່ສາມາດສະເຫຼີມສະຫຼອງຄວາມພໍໃຈທີ່ເພີ່ມຂຶ້ນ ໃນຂະນະທີ່ການສຳເລັດຫຼຸດລົງຢ່າງງຽບໆ (ເບິ່ງ [ຕົ້ນທຶນຕໍ່ທຸລະກຳ](../ຕົ້ນທຶນຕໍ່ທຸລະກຳ/) ແລະ [ການເຂົ້າເຖິງດິຈິຕອນຢ່າງທົ່ວເຖິງ](../ການເຂົ້າເຖິງດິຈິຕອນຢ່າງທົ່ວເຖິງ/) ເພື່ອຮູ້ວ່າໃຜຖືກຕັດອອກຈາກການເກັບຕົວຢ່າງຄວາມພໍໃຈທາງດິຈິຕອນຕັ້ງແຕ່ຕົ້ນ — ຜູ້ໃຊ້ທີ່ບໍ່ແມ່ນດິຈິຕອນ ແລະ ດິຈິຕອນແບບມີຜູ້ຊ່ວຍ ມີຕົວແທນໜ້ອຍເກີນໄປໃນແບບສຳຫຼວດໃນບໍລິການຢ່າງເປັນລະບົບ). ຂໍ້ມູນຄວາມພໍໃຈ ແລະ ຄວາມໄວ້ວາງໃຈຍັງປ້ອນໂດຍກົງເຂົ້າຂາຄວາມຊອບທຳຂອງ [ສາມຫຼ່ຽມຍຸດທະສາດຂອງ Moore](../ຄຸນຄ່າສາທາລະນະ/), ແລະ ຢູ່ໃນມຸມມອງ "ລູກຄ້າ" ແລະ "ຄວາມຊອບທຳ" ຂອງ [ບັດຄະແນນຄຸນຄ່າສາທາລະນະ](../ບັດຄະແນນຄຸນຄ່າສາທາລະນະ/) — ເບິ່ງ [ຕົວຊີ້ວັດຄວາມໄວ້ວາງໃຈ ແລະ ຄວາມຊອບທຳ](../ຕົວຊີ້ວັດຄວາມໄວ້ວາງໃຈ-ແລະ-ຄວາມຊອບທຳ/) ສຳລັບຕົວຄູ່ໃນລະດັບສະຖາບັນຂອງຕົວຊີ້ວັດລະດັບການບໍລິການນີ້.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ອະຄະຕິຜູ້ລອດຊີວິດໃນແບບສຳຫຼວດຈຸດສຳເລັດ**: ຜູ້ໃຊ້ທີ່ປະຖິ້ມການເດີນທາງບໍ່ເຄີຍເຫັນແບບສຳຫຼວດ, ຄະແນນຄວາມພໍໃຈໃນບໍລິການທີ່ສູງຈຶ່ງຢູ່ຮ່ວມກັບອັດຕາການສຳເລັດຕ່ຳ ແລະ ຄົນທີ່ບໍ່ພໍໃຈທີ່ບໍ່ສຳເລັດຈຳນວນຫຼາຍທີ່ເບິ່ງບໍ່ເຫັນ.
- **ຖືຄວາມພໍໃຈເປັນຕົວແທນຂອງຜົນໄດ້ຮັບ**: ໜ້າຕາທີ່ອອກແບບດີສຳລັບນະໂຍບາຍທີ່ອອກແບບບໍ່ດີ ໄດ້ຄະແນນຄວາມພໍໃຈດີ ແຕ່ຜົນໄດ້ຮັບບໍ່ດີ — ລາຍງານທັງສອງສະເໝີ, ຢ່າໃຊ້ອັນໃດອັນໜຶ່ງແທນອີກອັນ.
- **ຕົວຢ່າງນ້ອຍ ແລະ ບໍ່ເປັນຕົວແທນ ທີ່ລາຍງານດ້ວຍຄວາມແມ່ນຍຳປອມ**: ຄະແນນຄວາມພໍໃຈຈາກຜູ້ຕອບທີ່ເລືອກຕົນເອງສອງສາມຮ້ອຍຄົນ ທີ່ລາຍງານເປັນທົດສະນິຍົມໜຶ່ງຕຳແໜ່ງ ສະແດງຄວາມໝັ້ນໃຈທີ່ຂະໜາດຕົວຢ່າງຮອງຮັບບໍ່ໄດ້.
- **ເມີນເສີຍການແຍກຕາມກຸ່ມປະຊາກອນ**: ຕົວເລກຄວາມໄວ້ວາງໃຈ ແລະ ຄວາມພໍໃຈລະດັບຊາດທີ່ບໍ່ແຍກຕາມອາຍຸ, ລາຍໄດ້, ຄວາມພິການ ຫຼື ການເຂົ້າເຖິງດິຈິຕອນ ສາມາດປິດບັງປະສົບການທີ່ແຕກຕ່າງກັນຢ່າງແຮງລະຫວ່າງກຸ່ມ — ຮູບແບບທີ່ການເຜີຍແຜ່ Trust in Government ຂອງ OECD ເອງແຍກຢ່າງຊັດເຈນ.
