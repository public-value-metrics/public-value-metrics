# ການຈ່າຍຕາມຜົນສຳເລັດ ແລະ ພັນທະບັດຜົນກະທົບທາງສັງຄົມ (PbR/SIB)

ການຈ່າຍຕາມຜົນສຳເລັດ (Payment by results, PbR) ຈ່າຍຜູ້ໃຫ້ບໍລິການຕາມຜົນລັບທີ່ຢັ້ງຢືນແລ້ວທີ່ບັນລຸໄດ້, ບໍ່ແມ່ນກິດຈະກຳທີ່ປະຕິບັດ.
ພັນທະບັດຜົນກະທົບທາງສັງຄົມ (social impact bond, SIB) ແມ່ນໂຄງສ້າງການສະໜອງທຶນ PbR ສະເພາະ ທີ່ນັກລົງທຶນເອກະຊົນ ຫຼື ນັກການກຸສົນໃຫ້ທຶນການສົ່ງມອບບໍລິການລ່ວງໜ້າ
ແລະ ຖືກຊຳລະຄືນ — ພ້ອມຜົນຕອບແທນ — ໂດຍຜູ້ວ່າຈ້າງຂອງລັດຖະບານ ກໍຕໍ່ເມື່ອຜົນລັບທີ່ວັດແທກຢ່າງເປັນເອກະລາດບັນລຸເກນທີ່ຕົກລົງ,
ໂດຍຍ້າຍຄວາມສ່ຽງການສົ່ງມອບຈາກຜູ້ເສຍພາສີໄປຫານັກລົງທຶນ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

SIB ທຳອິດຂອງໂລກເປີດຕົວທີ່ HMP Peterborough ໃນເດືອນກັນຍາ 2010: Social Finance ລະດົມທຶນ £5 ລ້ານຈາກນັກລົງທຶນ 17 ຣາຍເພື່ອໃຫ້ທຶນ "One Service,"
ເຮັດວຽກກັບນັກໂທດຕັດສິນໂທດສັ້ນ (ຕ່ຳກວ່າ 12 ເດືອນ) ເພື່ອຫຼຸດການກະທຳຜິດຊ້ຳ, ໂດຍກະຊວງຍຸຕິທຳ ແລະ Big Lottery Fund ຕົກລົງຈະຊຳລະຄືນນັກລົງທຶນ
ກໍຕໍ່ເມື່ອເຫດການຖືກຕັດສິນຜິດຊ້ຳຫຼຸດລົງຢ່າງໜ້ອຍ 7.5% ທຽບກັບກຸ່ມຕົວຢ່າງປຽບທຽບແຫ່ງຊາດທີ່ຈັບຄູ່. ກຸ່ມສຸດທ້າຍຂອງໂຄງການທົດລອງ Peterborough ບັນທຶກການຫຼຸດລົງ 9.7% ຂອງ
ການຖືກຕັດສິນຜິດຊ້ຳ, ສູງກວ່າເກນຢ່າງສະບາຍ, ແລະ ນັກລົງທຶນໄດ້ຮັບການຊຳລະຄືນພ້ອມຜົນຕອບແທນ. ກົນໄກນີ້ສຳຄັນເພາະມັນແກ້ບັນຫາການວ່າຈ້າງສະເພາະ:
ລັດຖະບານຕ້ອງການຈ່າຍເພື່ອຜົນລັບແທນປັດໄຈນຳເຂົ້າ, ແຕ່ບໍ່ສາມາດຮັບຄວາມສ່ຽງທາງການເງິນຂອງມາດຕະການແຊກແຊງທີ່ອາດບໍ່ໄດ້ຜົນ, ດັ່ງນັ້ນໂຄງສ້າງ SIB
ຈຶ່ງຍ້າຍຄວາມສ່ຽງນັ້ນໄປຫານັກລົງທຶນທີ່ເຕັມໃຈຮັບປະກັນ. Government Outcomes Lab (GO Lab) ທີ່ Blavatnik School of Government ຂອງ Oxford ປັດຈຸບັນຮັກສາ
ຖານຫຼັກຖານສາທາລະນະທີ່ສົມບູນທີ່ສຸດກ່ຽວກັບການປະຕິບັດງານຂອງ PbR ແລະ SIB ທົ່ວໂລກ, ຕິດຕາມພັນທະບັດຜົນກະທົບຫຼາຍກວ່າ 200 ສະບັບທົ່ວໂລກ ແລະ ເຜີຍແຜ່ງານຄົ້ນຄວ້າ
ກ່ຽວກັບຄຸນລັກສະນະການອອກແບບໃດທີ່ສຳພັນກັບຄວາມສຳເລັດ ຫຼື ຄວາມລົ້ມເຫຼວ. ບົດຮຽນທີ່ຖານຫຼັກຖານກັບມາຫາຊ້ຳແລ້ວຊ້ຳອີກແມ່ນ *ຕົວຊີ້ວັດຜົນລັບທີ່ເລືອກ*, ແລະ
ໃຜເປັນຜູ້ແບກຮັບຄວາມສ່ຽງທີ່ຈະພາດມັນ, ກຳນົດເກືອບທຸກຢ່າງອື່ນກ່ຽວກັບວ່າສັນຍາ PbR ປະພຶດຕົວແນວໃດໃນທາງປະຕິບັດ.

## ຄະນິດສາດ

```
ການຈ່າຍ PbR = ການຈ່າຍພື້ນຖານ (ຖ້າມີ) + Σ (ຜົນລັບທີ່ບັນລຸ × ລາຄາຕໍ່ໜ່ວຍຕໍ່ຜົນລັບ)

ຜົນຕອບແທນນັກລົງທຶນ SIB:
  ເງິນລົງທຶນນັກລົງທຶນ = ທຶນລ່ວງໜ້າທີ່ໃຫ້ທຶນການສົ່ງມອບບໍລິການ
  ການຈ່າຍຕາມຜົນລັບ    = ຜູ້ວ່າຈ້າງຈ່າຍກໍຕໍ່ເມື່ອຜົນລັບ ≥ ເກນ, ປັບຕາມ
                          ວ່າການປະຕິບັດງານຢູ່ສູງກວ່າເກນເທົ່າໃດ
  ຜົນຕອບແທນນັກລົງທຶນ  = ການຈ່າຍຕາມຜົນລັບທີ່ໄດ້ຮັບ − ເງິນລົງທຶນນັກລົງທຶນ
                          (ອັດຕາຜົນຕອບແທນ, ມັກມີເພດານ, ສະທ້ອນຄວາມສ່ຽງທີ່ຮັບ)

ພາລາມິເຕີການອອກແບບຫຼັກທີ່ກຳນົດພຶດຕິກຳຂອງທັງສັນຍາ:
  ຕົວຊີ້ວັດຜົນລັບ        — ຕ້ອງເປັນຜົນລັບ, ບໍ່ແມ່ນຜົນຜະລິດ (ເບິ່ງ outcomes-vs-outputs)
  ການປຽບທຽບ/ສະຖານະການສົມມຸດທຽບ — ປົກກະຕິແມ່ນກຸ່ມຕົວຢ່າງທີ່ຈັບຄູ່ (ເບິ່ງ counterfactual-analysis)
  ເກນການຈ່າຍ            — ການປັບປຸງຂັ້ນຕ່ຳກ່ອນທີ່ການຈ່າຍໃດໆຈະຖືກກະຕຸ້ນ
  ເສັ້ນໂຄ້ງການຈ່າຍ       — ເສັ້ນຊື່, ເປັນຂັ້ນ, ຫຼື ມີເພດານເໜືອເກນ
  ສ່ວນຫຼຸດການຖືວ່າເປັນຜົນ/deadweight — ເບິ່ງ additionality-and-deadweight
```

## ຕົວຢ່າງການຄິດໄລ່

**Peterborough One Service** (ຕົວເລກເປັນຕົວຢ່າງທີ່ດຶງຈາກການປະເມີນທີ່ເຜີຍແຜ່):

```
ທຶນນັກລົງທຶນທີ່ລະດົມ:            £5,000,000
ກຸ່ມຕົວຢ່າງ:                       ~3,000 ນັກໂທດຊາຍຕັດສິນໂທດສັ້ນໃນສອງກຸ່ມ
ເກນ:                               ຫຼຸດລົງ ≥7.5% ຂອງເຫດການຖືກຕັດສິນຜິດຊ້ຳ ທຽບກັບກຸ່ມປຽບທຽບ
                                  ແຫ່ງຊາດທີ່ຈັບຄູ່, ຫຼື ບໍ່ມີການຈ່າຍ
ຜົນກຸ່ມ 1:                        ຫຼຸດລົງ 8.4% — ຕ່ຳກວ່າມາດຕະຖານຕາມສັນຍາສຳລັບ
                                  ກຸ່ມນັ້ນຢ່າງດຽວພາຍໃຕ້ກົດເກນເດີມ
ຜົນກຸ່ມລວມ/ສຸດທ້າຍ:              ຫຼຸດລົງ 9.7% — ສູງກວ່າເກນ
ການຈ່າຍຕາມຜົນລັບ:                 ລັດຖະບານ (ກະຊວງຍຸຕິທຳ / Big Lottery Fund)
                                  ຈ່າຍຕໍ່ຈຸດເປີເຊັນທີ່ສູງກວ່າເກນ, ໃຫ້ທຶນ
                                  ການຊຳລະຄືນນັກລົງທຶນບວກຜົນຕອບແທນ
```

**ສັນຍາ PbR ຂອງອົງການປົກຄອງທ້ອງຖິ່ນ (ຕົວຢ່າງ)**: ບໍລິການແຊກແຊງຄອບຄົວຖືກວ່າຈ້າງທີ່
£4,000 ຕໍ່ຄອບຄົວທີ່ຖືກສົ່ງຕໍ່ (ການຈ່າຍກິດຈະກຳ) ບວກ £6,000 ຕໍ່ຄອບຄົວທີ່ບໍ່ມີການສົ່ງຕໍ່ປົກປ້ອງເດັກເພີ່ມອີກ 12 ເດືອນຫຼັງປິດກໍລະນີ (ການຈ່າຍຕາມຜົນລັບ).
ສົ່ງຕໍ່ 200 ຄອບຄົວ, ປິດ 150 ກໍລະນີ, 96 ຍັງບໍ່ມີການສົ່ງຕໍ່ເມື່ອຄົບ 12 ເດືອນ:

```
ການຈ່າຍກິດຈະກຳ  = 200 × £4,000 = £800,000
ການຈ່າຍຕາມຜົນລັບ = 96 × £6,000  = £576,000
ຕົ້ນທຶນສັນຍາທັງໝົດ = £1,376,000 ສຳລັບ 96 ຜົນລັບຍືນຍົງທີ່ຢັ້ງຢືນແລ້ວ
ຕົ້ນທຶນຕໍ່ຜົນລັບທີ່ຢັ້ງຢືນ ≈ £14,333 (ເບິ່ງ cost-per-outcome)
```

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ການຈ່າຍຕາມຜົນສຳເລັດເປັນບັນຫາການປັບແຮງຈູງໃຈກ່ອນທີ່ຈະເປັນບັນຫາຂໍ້ມູນ, ແລະ ລະບົບຂໍ້ມູນຄືບ່ອນທີ່ການປັບນັ້ນຄົງຢູ່ ຫຼື ແຕກຫັກ.
ການຢັ້ງຢືນຜົນລັບແບບເອກະລາດ ແລະ ປ້ອງກັນການດັດແປງແມ່ນທັງໝົດຂອງເກມ: ຜູ້ວ່າຈ້າງ ແລະ ຜູ້ໃຫ້ບໍລິການມີແຮງຈູງໃຈກົງກັນຂ້າມກ່ຽວກັບວ່າກໍລະນີທີ່ຄຸມເຄືອຖືກລະຫັດແນວໃດ,
ສະນັ້ນລະບົບທີ່ບັນທຶກຜົນລັບຕ້ອງມີຮ່ອງຮອຍການກວດສອບ, ຂໍ້ຕົກລົງແບ່ງປັນຂໍ້ມູນກັບຜູ້ຢັ້ງຢືນເອກະລາດ
(ມັກເປັນໜ່ວຍງານຕ່າງຈາກຜູ້ໃຫ້ບໍລິການ, ບາງຄັ້ງເປັນໜ່ວຍງານສະຖິຕິທາງການທີ່ຈັບຄູ່ກັບບັນທຶກຕຳຣວດ ຫຼື ສິດຮັບເງິນອຸດໜູນ), ແລະ ການຄວບຄຸມເວີຊັນທີ່ແກ້ໄຂບໍ່ໄດ້ຂອງ
ນິຍາມຜົນລັບ — ສິ່ງທຽບເທົ່າຂອງ PbR ຂອງຂໍ້ຜິດພາດ "ນິຍາມຕົວຊີ້ວັດໃໝ່" ໃນ
[KPI ຂອງພາກລັດ](../ຕົວຊີ້ວັດຜົນງານຫຼັກ-ຂອງພາກລັດ/). ການຄຳນວນການຖືວ່າເປັນຜົນຂຶ້ນກັບວິທີການກຸ່ມຕົວຢ່າງທີ່ຈັບຄູ່ຂອງ
[counterfactual-analysis](../ການວິເຄາະສະຖານະການສົມມຸດ/), ເຊິ່ງຕ້ອງການໂຄດທີ່ຜະລິດຊ້ຳໄດ້ ແລະ ກວດສອບໄດ້, ບໍ່ແມ່ນສະເປຣດຊີດຄັ້ງດຽວ. ແລະ ຕົວຊີ້ວັດເອງຕ້ອງເປັນ
ຜົນລັບແທ້ຈິງ, ບໍ່ແມ່ນກິດຈະກຳຕົວແທນ — ເບິ່ງ [ຜົນລັບ ທຽບ ຜົນຜະລິດ](../ຜົນລັບ-ທຽບ-ຜົນຜະລິດ/) — ເພາະສັນຍາ PbR
ທີ່ຈ່າຍເພື່ອຜົນຜະລິດພຽງແຕ່ປ່ຽນປ້າຍການໃຫ້ທຶນທຳມະດາ ແລະ ເພີ່ມຕົ້ນທຶນທຸລະກຳ.
ບ່ອນທີ່ຜົນຕອບແທນທາງສັງຄົມຂອງ SIB ຖືກສ້າງແບບຈຳລອງລ່ວງໜ້າ, ການປະເມີນນັ້ນໂດຍທົ່ວໄປຢືມໂດຍກົງຈາກວິທີການ
[ຜົນຕອບແທນທາງສັງຄົມຕໍ່ການລົງທຶນ](../ຜົນຕອບແທນທາງສັງຄົມຈາກການລົງທຶນ/).

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ຈ່າຍເພື່ອຜົນລັບຕົວແທນທີ່ຖືກເກມງ່າຍ**: "ການເຂົ້າຮ່ວມກອງປະຊຸມ" ເປັນກິດຈະກຳທີ່ແຕ່ງຕົວເປັນຜົນລັບ;
  ຢືນຢັນມາດຕະການທີ່ສະທ້ອນການປ່ຽນແປງທີ່ຕ້ອງການຕົວຈິງ (ການກະທຳຜິດຊ້ຳ, ການມີວຽກ, ຄວາມໝັ້ນຄົງຂອງທີ່ຢູ່ອາໄສ).
- **ບໍ່ມີສະຖານະການສົມມຸດທຽບທີ່ໜ້າເຊື່ອຖື**: ຖ້າບໍ່ມີກຸ່ມປຽບທຽບທີ່ຈັບຄູ່, ການປັບປຸງອາດເປັນການກັບຄືນສູ່ຄ່າສະເລ່ຍ
  ຫຼື ແນວໂນ້ມທີ່ກວ້າງກວ່າ, ບໍ່ແມ່ນຜົນຂອງໂຄງການ — ເບິ່ງ
  [counterfactual-analysis](../ການວິເຄາະສະຖານະການສົມມຸດ/) ແລະ
  [additionality-and-deadweight](../ຜົນເພີ່ມເຕີມ-ແລະ-ຜົນທີ່ຈະເກີດຂຶ້ນຢູ່ແລ້ວ/).
- **ປະເມີນຕ່ຳຕົ້ນທຶນທຸລະກຳ ແລະ ການປະເມີນຜົນ**: ການຢັ້ງຢືນເອກະລາດ, ການເຊື່ອມໂຍງຂໍ້ມູນ, ແລະ
  ການບໍລິຫານສັນຍາສຳລັບໂຄງການ PbR/SIB ປົກກະຕິສູງເຖິງສອງຕົວເລກເປັນເປີເຊັນຂອງມູນຄ່າສັນຍາ —
  ຖານຫຼັກຖານຂອງ GO Lab ບັນທຶກສິ່ງນີ້ເປັນຕົວຂັບເຄື່ອນທີ່ເກີດຂຶ້ນຊ້ຳໆຂອງການຢຸດໂຄງການ.
- **ເລືອກສະເພາະລາຍທີ່ງ່າຍ ຫຼື "ຈອດ"**: ຜູ້ໃຫ້ບໍລິການທີ່ໄດ້ຮັບເງິນຕໍ່ຜົນລັບມີແຮງຈູງໃຈໂດຍກົງທີ່ຈະຈັດລຳດັບຄວາມສຳຄັນ
  ລູກຄ້າທີ່ມີໂອກາດສຳເລັດຢູ່ແລ້ວສູງ ແລະ ຫຼຸດຄວາມສຳຄັນກໍລະນີທີ່ຍາກທີ່ສຸດ — ອອກແບບລະດັບການຈ່າຍ
  ຫຼື ການປັບຕາມສ່ວນປະສົມກໍລະນີເພື່ອຕ້ານມັນ.
