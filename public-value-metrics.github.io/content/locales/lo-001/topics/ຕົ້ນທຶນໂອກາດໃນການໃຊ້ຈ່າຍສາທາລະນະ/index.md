# ຕົ້ນທຶນໂອກາດໃນການໃຊ້ຈ່າຍສາທາລະນະ

ຕົ້ນທຶນໂອກາດແມ່ນມູນຄ່າຂອງທາງເລືອກທີ່ດີທີ່ສຸດຮອງລົງມາທີ່ຖືກສະລະ ເມື່ອໜ່ວຍງານສາທາລະນະຜູກພັນເງິນ, ເວລາຂອງພະນັກງານ,
ຫຼື ທຶນທາງການເມືອງກັບທາງເລືອກໜຶ່ງແທນອີກທາງເລືອກໜຶ່ງ. ໃນກະຊວງທີ່ມີງົບປະມານຄົງທີ່, ທຸກປອນທີ່ໃຊ້ຈ່າຍກັບໂຄງການໜຶ່ງ
ແມ່ນປອນທີ່ບໍ່ສາມາດນຳໄປໃຊ້ກັບໂຄງການທີ່ດີທີ່ສຸດຮອງລົງມາໄດ້ — ຕົ້ນທຶນແທ້ຈິງຂອງການຕັດສິນໃຈບໍ່ແມ່ນສິ່ງທີ່ມັນໃຊ້ຈ່າຍ, ແຕ່ແມ່ນສິ່ງທີ່ມັນຍ້າຍອອກໄປ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ງົບປະມານສາທາລະນະມີເງິນສົດຈຳກັດພາຍໃນໄລຍະການທົບທວນລາຍຈ່າຍ, ດັ່ງນັ້ນ — ບໍ່ຄືບໍລິສັດເອກະຊົນທີ່ກຳລັງເຕີບໂຕ — ກະຊວງລັດຖະບານບໍ່ສາມາດ
ພຽງ "ຊອກເງິນເພີ່ມ" ໃຫ້ແນວຄິດທີ່ດີໄດ້; ການໃຫ້ທຶນມັນໝາຍເຖິງການຢຸດໃຫ້ທຶນສິ່ງອື່ນ. Green Book ຂອງ HM Treasury ຖືວ່ານີ້ເປັນພື້ນຖານ:
ທຸກການປະເມີນຕ້ອງປຽບທຽບມາດຕະການແຊກແຊງກັບພື້ນຖານ "ເຮັດຂັ້ນຕ່ຳ" *ແລະ* ກັບການນຳໃຊ້ຊັບພະຍາກອນດຽວກັນທີ່ເປັນໄປໄດ້ຕົວຈິງແບບອື່ນ,
ກໍຍ້ອນວ່າຄຳຖາມແທ້ຈິງທີ່ທີມໃຊ້ຈ່າຍຂອງ Treasury ຖາມບໍ່ເຄີຍແມ່ນ "ສິ່ງນີ້ດີບໍ?" ແຕ່ແມ່ນ "ສິ່ງນີ້ດີກວ່າສິ່ງອື່ນທີ່ເງິນນີ້ຊື້ໄດ້ບໍ?"
ຫຼັກການປະເມີນຫຼັກຂອງ Green Book — ວ່າຊັບພະຍາກອນສາທາລະນະຄວນໄຫຼໄປຫາມາດຕະການແຊກແຊງທີ່ມີມູນຄ່າທາງສັງຄົມສຸດທິຕໍ່ປອນສູງທີ່ສຸດ —
ແມ່ນຕົ້ນທຶນໂອກາດທີ່ຖືກກຳນົດເປັນນະໂຍບາຍ.

ສິ່ງນີ້ກ່າວໄດ້ງ່າຍແຕ່ນຳໃຊ້ຍາກ ເພາະ "ທາງເລືອກດີທີ່ສຸດຮອງລົງມາ" ແທບບໍ່ຄ່ອຍເຫັນໃນກໍລະນີທຸລະກິດດຽວ. ໂຄງການທຶນ £2 ລ້ານສຳລັບການຈ້າງງານຊາວໜຸ່ມ
ຖືກປຽບທຽບ, ໃນກໍລະນີທຸລະກິດ, ກັບການບໍ່ເຮັດຫຍັງ — ແຕ່ຕົວປຽບທຽບທີ່ຊື່ສັດແມ່ນມາດຕະການແຊກແຊງການຈ້າງງານຊາວໜຸ່ມທີ່ດີທີ່ສຸດຮອງລົງມາ,
ຫຼື ແທ້ໆແລ້ວການນຳໃຊ້ £2 ລ້ານທີ່ດີທີ່ສຸດຮອງລົງມາທຸກບ່ອນໃນຜັງລົງທຶນ, ລວມທັງລາຍຈ່າຍທີ່ບໍ່ແມ່ນການຈ້າງງານ. Magenta Book
(HM Treasury, 2020) ເຕືອນຢ່າງຊັດເຈນວ່າການປະເມີນທີ່ປຽບທຽບ "ມີມາດຕະການແຊກແຊງ" ກັບ "ບໍ່ມີມາດຕະການແຊກແຊງ" ປະເມີນຕ່ຳກວ່າມາດຕະຖານທີ່ມາດຕະການແຊກແຊງຕ້ອງຜ່ານ,
ເພາະ "ບໍ່ມີມາດຕະການແຊກແຊງນີ້" ບໍ່ແມ່ນຄືກັບ "ບໍ່ມີຫຍັງເລີຍ" — ເງິນທີ່ປ່ອຍອອກມາຈະໃຫ້ທຶນສິ່ງອື່ນ.

## ຄະນິດສາດ

```
ຕົ້ນທຶນໂອກາດຂອງການເລືອກ A = ມູນຄ່າຂອງທາງເລືອກທີ່ດີທີ່ສຸດທີ່ຖືກສະລະ B

ມູນຄ່າສາທາລະນະສຸດທິຂອງ A = value(A) − value(B), ບໍ່ແມ່ນ value(A) − 0
```

ບໍ່ມີສູດທົ່ວໄປ ເພາະທາງເລືອກທີ່ຖືກສະລະຂຶ້ນກັບບໍລິບົດ, ແຕ່ວິໄນນີ້ໃຊ້ໄດ້ທົ່ວໄປ: ລະບຸການນຳໃຊ້ງົບປະມານສາຍດຽວກັນທີ່ດີທີ່ສຸດຮອງລົງມາທີ່ເປັນໄປໄດ້ຕົວຈິງ
(ບໍ່ແມ່ນ "ບໍ່ເຮັດຫຍັງ" ໃນອຸດົມຄະຕິ), ປະເມີນມູນຄ່າດ້ວຍພື້ນຖານດຽວກັນ (ປ່ຽນເປັນເງິນເທົ່າທີ່ເປັນໄປໄດ້, ຕາມ
[ການວິເຄາະຕົ້ນທຶນ-ຜົນປະໂຫຍດທາງສັງຄົມ](../ການວິເຄາະຕົ້ນທຶນ-ຜົນປະໂຫຍດທາງສັງຄົມ/)), ແລ້ວລົບອອກ.

## ຕົວຢ່າງການຄິດໄລ່

**ສາຍງົບປະມານຂອງກະຊວງ**: ກອງທຶນປ່ຽນແປງດິຈິຕອນ £5 ລ້ານ ສາມາດໃຫ້ທຶນໄດ້ພຽງໜຶ່ງໃນສອງຂໍ້ສະເໜີໃນປີການເງິນນີ້.

- *ທາງເລືອກ A*: ແພລດຟອມຈັດການກໍລະນີໃໝ່, ຜົນປະໂຫຍດທີ່ປ່ຽນເປັນເງິນ £7.2 ລ້ານໃນ 5 ປີ
  (ເງິນປະຢັດຈາກປະສິດທິພາບ ບວກການແກ້ໄຂກໍລະນີໄວຂຶ້ນ).
- *ທາງເລືອກ B*: ບໍລິການຢັ້ງຢືນຕົວຕົນທີ່ໃຊ້ຮ່ວມກັນສາມກະຊວງ, ຜົນປະໂຫຍດທີ່ປ່ຽນເປັນເງິນ £6.4 ລ້ານໃນ 5 ປີ.

ກໍລະນີທຸລະກິດແບບງ່າຍໆຂອງ A ປຽບທຽບຜົນປະໂຫຍດ £7.2 ລ້ານກັບຕົ້ນທຶນ £5 ລ້ານ ແລະ ລາຍງານອັດຕາສ່ວນຜົນປະໂຫຍດ-ຕົ້ນທຶນ 1.44:1 — ເບິ່ງແຂງແຮງ.
ແຕ່ເນື່ອງຈາກ A ແລະ B ແຂ່ງຂັນກັນເພື່ອ £5 ລ້ານດຽວກັນ, ຕົ້ນທຶນໂອກາດຂອງການເລືອກ A ແມ່ນຜົນປະໂຫຍດ £6.4 ລ້ານຂອງ B ທີ່ຖືກສະລະ.
ກໍລະນີ *ສຸດທິ* ຂອງ A ເມື່ອທຽບກັບທາງເລືອກທີ່ເປັນໄປໄດ້ຕົວຈິງແມ່ນພຽງ £7.2m − £6.4m = £0.8 ລ້ານ, ບໍ່ແມ່ນຕົວເລກຫົວຂໍ້ເຕັມ £7.2 ລ້ານ.
ຖ້າທາງເລືອກທີສາມ, C, ໃຫ້ຜົນປະໂຫຍດ £7.5 ລ້ານສຳລັບ £5 ລ້ານດຽວກັນ, ການໃຫ້ທຶນ A ແທນ C ຈະທຳລາຍມູນຄ່າສາທາລະນະ £0.3 ລ້ານ
ເຖິງວ່າກໍລະນີທຸລະກິດຂອງ A ເອງເບິ່ງຄືສົມເຫດສົມຜົນເຕັມທີ່ເມື່ອຢູ່ໂດດດ່ຽວ.

**ເວລາພະນັກງານຂອງອົງການປົກຄອງທ້ອງຖິ່ນ**: ທີມຂໍ້ມູນສາມຄົນຂອງສະພາທ້ອງຖິ່ນສາມາດສ້າງແຜງຄວບຄຸມລາຍຊື່ລໍຖ້າທີ່ຢູ່ອາໄສ
(ຄາດວ່າຈະປະຢັດ 400 ຊົ່ວໂມງເຈົ້າໜ້າທີ່/ປີ, ມູນຄ່າ £28/ຊົ່ວໂມງ = £11,200/ປີ) ຫຼື ເຄື່ອງມືຄັດກອງການສໍ້ໂກງສິດຮັບເງິນອຸດໜູນ
(ຄາດວ່າຈະປ້ອງກັນການຈ່າຍທີ່ບໍ່ຖືກຕ້ອງ £85,000/ປີ). ການສ້າງແຜງຄວບຄຸມມີຕົ້ນທຶນໂອກາດ £85,000/ປີທີ່ສະລະໄປ, ບໍ່ແມ່ນພຽງຕົ້ນທຶນເງິນເດືອນຂອງທີມຂໍ້ມູນ —
ຕົ້ນທຶນແທ້ຈິງຂອງການສ້າງພາຍໃນ "ຟຣີ" ແມ່ນຜົນປະໂຫຍດທີ່ໃຫຍ່ກວ່າຫຼາຍທີ່ທີມສາມາດສ້າງໃນບ່ອນອື່ນ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ຄວາມສາມາດດ້ານວິສະວະກຳພາຍໃນໜ່ວຍງານສາທາລະນະເປັນງົບປະມານທີ່ມີຂໍ້ຈຳກັດເອງ — ຄວາມສາມາດຂອງສະປຣິນ, ບໍ່ແມ່ນປອນ — ແລະ ວິໄນດຽວກັນໃຊ້ໄດ້ໂດຍກົງ:

- ຕັ້ງຊື່ຕົວປຽບທຽບສະເໝີ: ກໍລະນີທຸລະກິດຂອງຄຸນສົມບັດຄວນລະບຸວ່າທີມ-ອາທິດຂອງທີມດຽວກັນສາມາດສົ່ງມອບຫຍັງອີກ,
  ບໍ່ແມ່ນພຽງຜົນຕອບແທນຂອງຕົນເອງ.
- ຖື "ພວກເຮົາມີຄວາມສາມາດດ້ານວິສະວະກຳເຫຼືອ" ເປັນຈຸດເລີ່ມຕົ້ນຂອງການວິເຄາະຕົ້ນທຶນໂອກາດ, ບໍ່ແມ່ນຈຸດສິ້ນສຸດ — ຄວາມສາມາດທີ່ເຫຼືອກໍຍັງມີການນຳໃຊ້ທາງເລືອກທີ່ດີທີ່ສຸດ,
  ເຖິງວ່າການນຳໃຊ້ນັ້ນຈະເປັນການຊຳລະໜີ້ເຕັກນິກ
  (ເບິ່ງ [ໜີ້ເຕັກນິກໃນຖານະການເສື່ອມຖອຍຂອງມູນຄ່າສາທາລະນະ](../ໜີ້ທາງເທັກນິກໃນຖານະການກັດກ່ອນຄຸນຄ່າສາທາລະນະ/)).
- ເຊື່ອມໂຍງສິ່ງນີ້ໂດຍກົງກັບ[ຄວາມຄຸ້ມຄ່າເງິນ](../ຄວາມຄຸ້ມຄ່າເງິນ/): ການທົດສອບ "ປະຢັດ" ຂອງ VFM
  ບໍ່ມີຄວາມໝາຍຖ້າບໍ່ມີຕົວປຽບທຽບຕົ້ນທຶນໂອກາດທີ່ຊື່ສັດ, ແລະກັບ
  [ຕົ້ນທຶນຂອງຄວາມຊັກຊ້າໃນໂຄງການສາທາລະນະ](../ຕົ້ນທຶນຂອງການຊ້າໃນໂຄງການສາທາລະນະ/), ທີ່ກຳນົດລາຄາ
  ມິຕິເວລາຂອງເຫດຜົນທາງເລືອກທີ່ຖືກສະລະດຽວກັນ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ປຽບທຽບກັບ "ບໍ່ເຮັດຫຍັງ" ແທນທາງເລືອກດີທີ່ສຸດຮອງລົງມາ.** Green Book ກຳນົດພື້ນຖານ
  "ເຮັດຂັ້ນຕ່ຳ" ກໍຍ້ອນຕົ້ນທຶນໂອກາດແທ້ຈິງແທບບໍ່ເຄີຍເປັນສູນ; ກໍລະນີທຸລະກິດທີ່ຜ່ານພຽງມາດຕະຖານ "ບໍ່ເຮັດຫຍັງ"
  ຍັງບໍ່ໄດ້ສະແດງວ່າມັນດີກວ່າທາງເລືອກທີ່ເປັນໄປໄດ້ຕົວຈິງ.
- **ເມີນເສີຍການແຂ່ງຂັນຂ້າມກະຊວງເພື່ອເງິນກ້ອນດຽວກັນ.** ສາຍງົບປະມານທີ່ເບິ່ງຄືຖືກກັນໄວ້ພາຍໃນກົມໜຶ່ງ
  ມັກແຂ່ງຂັນໃນລະດັບສູງກວ່າ (ການທົບທວນລາຍຈ່າຍ, ໂຄງການທຶນ) ບ່ອນທີ່ຕົ້ນທຶນໂອກາດແທ້ຈິງເກີດຂຶ້ນ.
- **ສົມມຸດວ່າເວລາພະນັກງານທີ່ປ່ອຍອອກມາບໍ່ມີມູນຄ່າຕໍ່ໄປ.** ເວລາທີ່ "ປະຢັດ" ສ້າງມູນຄ່າຕໍ່ເມື່ອຖືກຍ້າຍໄປເຮັດສິ່ງທີ່ມີຄ່າເທົ່ານັ້ນ;
  ຖ້າການນຳໃຊ້ທາງເລືອກບໍ່ມີ, ເງິນປະຢັດນັ້ນກໍເປັນພຽງໃນນາມ.
