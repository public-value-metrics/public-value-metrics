# Sitemap

Every `*.github.io` SvelteKit site in this family publishes `/sitemap.xml` so search engines can find every
page, generated at build time from the built HTML so it cannot list a page that does not exist.

## Output

- `/sitemap.xml`, [sitemaps.org](https://www.sitemaps.org/protocol.html) `urlset`; one
  `<url><loc>…</loc><lastmod>YYYY-MM-DD</lastmod></url>` per canonical page, sorted, `lastmod` = build date.
- `static/robots.txt` ends with `Sitemap: https://public-value-metrics.github.io/sitemap.xml`.

## Rules

- Generated by `scripts/build-sitemap.mjs`, run by `pnpm run build` after `vite build`; never hand-written.
- One entry per built `index.html`, as its directory URL with a trailing slash; path segments are
  percent-encoded (topic slugs are native-script, see `spec/locale/index.md`).
- Excluded: `404.html` (not an `index.html`) and the two-letter alias pages (`/cs/`, `/pl/`, …), which only
  redirect to their `-001` locale.
- One file must stay under 50 000 URLs; the script fails the build past that and must then be changed to
  emit a sitemap index.
- Verification after each publish: `GET /sitemap.xml` returns 200, its URL count equals the number of
  canonical pages (about 68 per locale plus the home and about pages), and `GET /robots.txt` names it.
