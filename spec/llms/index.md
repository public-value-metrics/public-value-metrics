# llms.txt and llms.json

Every `*.github.io` SvelteKit site in this family publishes a machine-readable map of its content for
AI agents, generated at build time so it can never go stale.

## Outputs

| URL | Format |
|---|---|
| `/llms.txt` | [llmstxt.org](https://llmstxt.org/): H1 title, blockquote summary, a paragraph of facts (topic, part and locale counts, canonical locale, URL pattern), one `##` section per part with `- [Title](url): summary` lines in reading order, and an `## Optional` section |
| `/llms.json` | `{ title, summary, site, repository, defaultLocale, locales[], topicUrlPattern, parts: [{ title, topics: [{ title, slug, summary, url }] }] }` |

## Rules

- Generated by `scripts/build-llms.mjs`, run by `pnpm run build` after `vite build`; never hand-written.
- Source of truth: `content/README.md` (parts and topics, in reading order) and the directories under
  `content/locales/` (the locale list). Counts are computed, never typed.
- URLs point at the canonical locale (`en-gb-oxendict`); `topicUrlPattern` tells an agent how to reach
  any other locale, whose slugs are translated (see `spec/locale/index.md`).
- Verification after each publish: `GET /llms.txt` and `GET /llms.json` return 200, and the topic count in
  both equals the number of topics in the README.
