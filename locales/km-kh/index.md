# រង្វាស់តម្លៃសាធារណៈ

សេចក្តីណែនាំដ៏ទូលំទូលាយអំពីគណិតវិទ្យា ឧទាហរណ៍ និងការវែកញែកអំពីតម្លៃសាធារណៈ ដែលសរសេរសម្រាប់វិស្វករកម្មវិធីដែលកសាងសម្រាប់អង្គការរដ្ឋាភិបាល និងវិស័យសង្គមនៅទូទាំងពិភពលោក រួមទាំងនៅព្រះរាជាណាចក្រកម្ពុជា។ ឯកសារនីមួយៗគ្របដណ្តប់រង្វាស់ ឬគំនិតមួយ៖ និយមន័យ ហេតុអ្វីវាសំខាន់ វិធីសាស្ត្រ ឧទាហរណ៍គណនា ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី កំហុសដែលតែងកើតមាន និងប្រភព។

ទើបមកដល់ថ្មី? សូមចាប់ផ្តើមជាមួយ[តម្លៃសាធារណៈ](locales/km-kh/ប្រធានបទ/តម្លៃសាធារណៈ/) [តម្លៃសមស្របនឹងថ្លៃចំណាយ](locales/km-kh/ប្រធានបទ/តម្លៃសមស្របនឹងថ្លៃចំណាយ/) និង[ទ្រឹស្តីនៃការផ្លាស់ប្តូរ](locales/km-kh/ប្រធានបទ/ទ្រឹស្តីនៃការផ្លាស់ប្តូរ/) គឺគំនិតបីដែលអ្វីៗផ្សេងទៀតកសាងលើ។


## មូលដ្ឋានគ្រឹះនៃតម្លៃសាធារណៈ

- [តម្លៃសាធារណៈ](locales/en-gb-oxendict/topics/public-value/) — ត្រីកោណយុទ្ធសាស្ត្ររបស់ Mark Moore៖ ភាពស្របច្បាប់ បេសកកម្ម និងសមត្ថភាពប្រតិបត្តិការ ជាការវាស់វែងតម្លៃសាធារណៈ
- [តម្លៃសមស្របនឹងថ្លៃចំណាយ](locales/en-gb-oxendict/topics/value-for-money/) — សេដ្ឋកិច្ច ប្រសិទ្ធភាព ប្រសិទ្ធផល និង E ទីបួនដែលចម្រូងចម្រាស គឺសមធម៌
- [ថ្លៃចំណាយឱកាសក្នុងការចំណាយសាធារណៈ](locales/en-gb-oxendict/topics/opportunity-cost-in-public-spending/) — រាល់ផោនដែលក្រសួងមួយចំណាយ គឺជាផោនដែលមិនបានចំណាយលើកម្មវិធីល្អបំផុតបន្ទាប់
- [អត្រាបញ្ចុះតម្លៃសង្គម](locales/en-gb-oxendict/topics/social-discount-rate/) — អត្រាបញ្ចុះតម្លៃថយចុះរបស់ Green Book និងមូលហេតុដែល 3.5% ក្លាយជាសំណួរនយោបាយសកម្ម
- [ការថ្លឹងថ្លែងតាមការបែងចែក](locales/en-gb-oxendict/topics/distributional-weighting/) — ហេតុអ្វីមួយផោនមានតម្លៃជាងចំពោះគ្រួសារក្រីក្រ និងរបៀបដែល Green Book កំណត់តម្លៃនោះ
- [ភាពបន្ថែម និងផលដែលនឹងកើតឡើងដោយខ្លួនឯង](locales/en-gb-oxendict/topics/additionality-and-deadweight/) — តើវានឹងកើតឡើងដោយខ្លួនឯងឬទេ? សំណួរដែលបំបាត់ខ្យល់ពីការអះអាងផលប៉ះពាល់ភាគច្រើន
- [ការបំលាស់ទី និងការសន្មតផល](locales/en-gb-oxendict/topics/displacement-and-attribution/) — នៅពេលជ័យជម្នះរបស់អ្នកជាការខាតបង់របស់អ្នកដទៃ និងនៅពេលដែលវាមិនមែនជារបស់អ្នកទាំងស្រុងដើម្បីអះអាង
- [ការវិភាគ counterfactual](locales/en-gb-oxendict/topics/counterfactual-analysis/) — គ្មាន counterfactual គ្មានភស្តុតាង៖ ការបង្កើតពិភពលោកដែលគ្មានអន្តរាគមន៍

## ការវាយតម្លៃសេដ្ឋកិច្ចរបស់រដ្ឋាភិបាល

- [ការវាយតម្លៃតាម Green Book (គំរូប្រាំករណី)](locales/en-gb-oxendict/topics/green-book-appraisal/) — គំរូប្រាំករណីរបស់ HM Treasury៖ ករណីយុទ្ធសាស្ត្រ សេដ្ឋកិច្ច ពាណិជ្ជកម្ម ហិរញ្ញវត្ថុ និងការគ្រប់គ្រង
- [ការវិភាគថ្លៃដើម-អត្ថប្រយោជន៍សង្គម](locales/en-gb-oxendict/topics/social-cost-benefit-analysis/) — ការបម្លែងអ្វីៗទាំងអស់ជាប្រាក់ រួមទាំងអ្វីដែលទីផ្សារមិនធ្លាប់កំណត់តម្លៃ
- [ការវិភាគប្រសិទ្ធភាពថ្លៃចំណាយក្នុងរដ្ឋាភិបាល](locales/en-gb-oxendict/topics/cost-effectiveness-analysis-in-government/) — ថ្លៃចំណាយក្នុងមួយឯកតាលទ្ធផល នៅពេលលទ្ធផលមិនអាចបម្លែងជាប្រាក់បានដោយស្មោះត្រង់
- [ការវិភាគការសម្រេចចិត្តពហុលក្ខណៈវិនិច្ឆ័យ (MCDA)](locales/en-gb-oxendict/topics/multi-criteria-decision-analysis/) — ការដាក់ពិន្ទុជម្រើសតាមលក្ខណៈវិនិច្ឆ័យមានទម្ងន់ នៅពេលរង្វាស់តែមួយនឹងលាក់ការជួញដូរ
- [ការវាយតម្លៃសុខុមាលភាព (WELLBY)](locales/en-gb-oxendict/topics/wellbeing-valuation/) — WELLBY និងការកែតម្រូវសុខុមាលភាព៖ ការកំណត់តម្លៃគោលនយោបាយជាឯកតាការពេញចិត្តក្នុងជីវិត
- [ការវាយតម្លៃតាមចំណូលចិត្តដែលបានប្រកាស](locales/en-gb-oxendict/topics/stated-preference-valuation/) — ការសួរមនុស្សថាពួកគេនឹងបង់ប៉ុន្មាន៖ ការវាយតម្លៃតាមលក្ខខណ្ឌ និងបញ្ហាភាពជឿជាក់របស់វា
- [ការវាយតម្លៃតាមចំណូលចិត្តដែលបានបង្ហាញ](locales/en-gb-oxendict/topics/revealed-preference-valuation/) — ការសន្និដ្ឋានតម្លៃពីអ្វីដែលមនុស្សធ្វើជាក់ស្តែង ចាប់ពីតម្លៃ hedonic ដល់វិធីសាស្ត្រថ្លៃចំណាយធ្វើដំណើរ
- [តម្លៃស្រមោល](locales/en-gb-oxendict/topics/shadow-pricing/) — ការកំណត់តម្លៃអ្វីដែលគ្មានតម្លៃទីផ្សារ៖ កាបូន ពេលវេលា និងទំនិញដែលមិនមានការជួញដូរ

## តម្លៃសង្គម និងការវាស់វែងផលប៉ះពាល់

- [ផលចំណេញសង្គមលើការវិនិយោគ](locales/en-gb-oxendict/topics/social-return-on-investment/) — សមាមាត្រ SROI និងវិន័យដែលរក្សាវាកុំឱ្យក្លាយជាលេខផ្សព្វផ្សាយ
- [ទ្រឹស្តីនៃការផ្លាស់ប្តូរ](locales/en-gb-oxendict/topics/theory-of-change/) — ការគូសផែនទីច្រវាក់មូលហេតុពីសកម្មភាពទៅលទ្ធផលរយៈពេលវែង មុនពេលអ្នកវាស់អ្វីទាំងអស់
- [គំរូតក្កវិជ្ជានៃកម្មវិធី](locales/en-gb-oxendict/topics/logic-model/) — ធាតុបញ្ចូល សកម្មភាព ទិន្នផល លទ្ធផល ផលប៉ះពាល់៖ ឆ្អឹងខ្នងគណនេយ្យភាពរបស់កម្មវិធី
- [លទ្ធផល ធៀបនឹង ទិន្នផល](locales/en-gb-oxendict/topics/outcomes-vs-outputs/) — ហេតុអ្វី "មនុស្ស 500 នាក់បានចូលរួម" មិនមែនជាការអះអាងដូចគ្នានឹង "ជីវិតរបស់មនុស្ស 500 នាក់ប្រសើរឡើង"
- [ច្បាប់តម្លៃសង្គម](locales/en-gb-oxendict/topics/social-value-act/) — កាតព្វកិច្ចឆ្នាំ 2012 របស់ចក្រភពអង់គ្លេសក្នុងការពិចារណាតម្លៃសង្គមក្នុងលទ្ធកម្មសាធារណៈ
- [មូលដ្ឋានទិន្នន័យថ្លៃចំណាយឯកតា](locales/en-gb-oxendict/topics/unit-cost-databases/) — Social Value Bank របស់ HACT និង Global Value Exchange៖ តំណាងដែលបានកំណត់តម្លៃរួច ដើម្បីកុំឱ្យនរណាចាប់ផ្តើមពីសូន្យ
- [វិធីសាស្ត្រវាយតម្លៃផលប៉ះពាល់](locales/en-gb-oxendict/topics/impact-evaluation-methods/) — RCT, difference-in-differences និង propensity score matching សម្រាប់គោលនយោបាយដែលអ្នកមិនអាចសាកល្បងក្នុងមន្ទីរពិសោធន៍
- [ការវាយតម្លៃផលប៉ះពាល់ ធៀបនឹងការវាយតម្លៃដំណើរការ](locales/en-gb-oxendict/topics/impact-evaluation-vs-process-evaluation/) — តើវាដំណើរការឬទេ ធៀបនឹងតើវាកើតឡើងតាមការរចនាឬទេ៖ សំណួរពីរខុសគ្នា វិធីសាស្ត្រពីរខុសគ្នា

## រង្វាស់ការអនុវត្ត និងការចែកចាយរបស់រដ្ឋាភិបាល

- [សូចនាករសំខាន់ៗនៃការអនុវត្ត (KPI) ក្នុងវិស័យសាធារណៈ](locales/en-gb-oxendict/topics/public-sector-kpis/) — ការជ្រើសរើសសូចនាករដែលរួចផុតពីច្បាប់ Goodhart
- [ក្រដាសពិន្ទុតម្លៃសាធារណៈ](locales/en-gb-oxendict/topics/public-value-scorecard/) — ការសម្របក្រដាសពិន្ទុតុល្យភាពរបស់ Kaplan និង Norton សម្រាប់បេសកកម្មដែលមិនមែនជាប្រាក់ចំណេញ
