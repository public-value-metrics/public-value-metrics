# សមាមាត្រចំណាយរដ្ឋបាលរបស់អង្គការសប្បុរសធម៌

សមាមាត្រចំណាយរដ្ឋបាល (overhead ratio) របស់អង្គការសប្បុរសធម៌ គឺជាការចំណាយរដ្ឋបាល និងការរៃអង្គាសមូលនិធិ ដែលបង្ហាញជាភាគរយនៃការចំណាយសរុប។ វាជាលេខដែលត្រូវបានស្នើសុំច្រើនបំផុតក្នុងការបរិច្ចាគសប្បុរសធម៌ គឺប្រើដោយម្ចាស់ជំនួយ អង្គការត្រួតពិនិត្យ និងសូម្បីតែម្ចាស់មូលនិធិខ្លះជាតំណាងនៃប្រសិទ្ធភាព ហើយវាក៏ជារង្វាស់ប្រសិទ្ធភាពមួយដែលត្រូវបានបដិសេធយ៉ាងហ្មត់ចត់បំផុតក្នុងវិស័យនេះ ដោយអង្គការដែលធ្វើឱ្យវាពេញនិយម បានបដិសេធវាជាសាធារណៈក្នុងឆ្នាំ 2013។

## ហេតុអ្វីបានជាសំខាន់

នៅថ្ងៃទី 17 ខែមិថុនា ឆ្នាំ 2013 GuideStar, BBB Wise Giving Alliance និង Charity Navigator ដែលជាស្ថាប័នវាយតម្លៃ និងព័ត៌មានអង្គការមិនស្វែងរកប្រាក់ចំណេញធំបំផុតទាំងបីរបស់សហរដ្ឋអាមេរិក ហើយការវាយតម្លៃតាមប្រវត្តិរបស់ខ្លួនបានជួយឱ្យសមាមាត្រចំណាយរដ្ឋបាលក្លាយជាអក្សរកាត់នៃគុណភាពអង្គការសប្បុរសធម៌ បានបោះពុម្ពលិខិតបើកចំហរួមមួយជូនអ្នកបរិច្ចាគអាមេរិក ចំណងជើង "The Overhead Myth" ដោយចែងយ៉ាងច្បាស់លាស់ថា សមាមាត្រចំណាយរដ្ឋបាលជារង្វាស់មិនល្អនៃសមិទ្ធផលអង្គការសប្បុរសធម៌ ហើយជំរុញឱ្យអ្នកបរិច្ចាគមើលតម្លាភាព អភិបាលកិច្ច និងលទ្ធផលជំនួសវិញ។ នេះគឺជាការបញ្ច្រាសដោយផ្ទាល់ដោយស្ថាប័នដែលបានកសាងវប្បធម៌អ្នកបរិច្ចាគជុំវិញសមាមាត្រនេះអស់មួយទសវត្ស។

បញ្ហាមូលដ្ឋានគឺជារចនាសម្ព័ន្ធ មិនមែនគ្រាន់តែអំពីរូបភាពទេ៖ សមាមាត្រចំណាយរដ្ឋបាលទាបអាចសម្រេចបានដោយការវិនិយោគតិចតួចលើអ្វីដែលធ្វើឱ្យអង្គការសប្បុរសធម៌មានប្រសិទ្ធភាព គឺប្រព័ន្ធគ្រប់គ្រងករណីសមរម្យ បុគ្គលិកដែលបានបណ្តុះបណ្តាល ការតាមដាន និងការវាយតម្លៃ ព្រោះរឿងទាំងនេះច្រើនតែត្រូវបានកត់ត្រាជាថ្លៃ «រដ្ឋបាល» ជាជាងថ្លៃ «កម្មវិធី»។ អង្គការសប្បុរសធម៌ដែលបង្អត់ការិយាល័យខាងក្រោយរបស់ខ្លួនដើម្បីរាយការណ៍ចំណាយរដ្ឋបាល 5% អាចមានសមត្ថភាពតិចជាងក្នុងការផ្តល់លទ្ធផល ជាងអង្គការដែលចំណាយ 20% លើប្រតិបត្តិការដែលមានធនធានត្រឹមត្រូវ។ ក្នុងប្រទេសអង់គ្លេស និងវែលស៍ ការណែនាំរបស់ Charity Commission ដល់អ្នកគ្រប់គ្រងចៀសវាងភាគរយចំណាយរដ្ឋបាលតែមួយជាការធ្វើតេស្តប្រសិទ្ធភាព ហើយសុំឱ្យអ្នកគ្រប់គ្រងរាយការណ៍អំពីអ្វីដែលអង្គការសប្បុរសធម៌សម្រេចបានធៀបនឹងគោលបំណងរបស់ខ្លួនជំនួសវិញ សូមមើលតម្រូវការរាយការណ៍ SORP ដែលបានពិភាក្សាក្នុង [ថ្លៃចំណាយក្នុងមួយអ្នកទទួលផល](../ថ្លៃចំណាយក្នុងមួយអ្នកទទួលផល/)។

## គណិតវិទ្យា

```
Overhead ratio = (Administrative cost + Fundraising cost) / Total expenditure

Common variants:
  Programme ratio        = Programme (direct charitable) spend / Total expenditure
                          = 1 − overhead ratio
  Fundraising efficiency  = Fundraising cost / Funds raised
```

គ្មានរូបមន្តណាមួយក្នុងចំណោមទាំងនេះមានព័ត៌មានអំពីលទ្ធផលដែលសម្រេចបានទេ។ អង្គការសប្បុរសធម៌អាចបង្រួមតូចទាំងអស់ ហើយនៅតែបរាជ័យចំពោះអ្នកទទួលផលគ្រប់រូប សូមមើល [ថ្លៃចំណាយក្នុងមួយលទ្ធផល](../ថ្លៃចំណាយក្នុងមួយលទ្ធផល/) សម្រាប់រង្វាស់ដែលពិតជាដោះស្រាយថាតើប្រាក់ដំណើរការឬអត់។

## ឧទាហរណ៍គណនា

អង្គការសប្បុរសធម៌ពីរ ចំណាយសរុបស្មើគ្នា៖

- **អង្គការ A**៖ ចំណាយសរុប £1,000,000 រដ្ឋបាល + រៃអង្គាស £80,000 → សមាមាត្រចំណាយរដ្ឋបាល 8%។ វាគ្មានមុខងារតាមដាន និងវាយតម្លៃ មានមន្ត្រីហិរញ្ញវត្ថុម្នាក់ដែលធ្វើការហួសកម្លាំង និងគ្មានប្រព័ន្ធគ្រប់គ្រងករណី ការផ្លាស់ប្តូរបុគ្គលិកខ្ពស់ ហើយមិនមានការប្រមូលទិន្នន័យលទ្ធផលទេ។
- **អង្គការ B**៖ ចំណាយសរុប £1,000,000 រដ្ឋបាល + រៃអង្គាស £220,000 → សមាមាត្រចំណាយរដ្ឋបាល 22%។ វាផ្តល់មូលនិធិដល់ក្រុមវាយតម្លៃតូចមួយ ប្រព័ន្ធគ្រប់គ្រងករណីដែលចាប់យកការតាមដានលទ្ធផល និងការបណ្តុះបណ្តាលការពារសុវត្ថិភាពត្រឹមត្រូវ។

អ្នកបរិច្ចាគដែលពិនិត្យជ្រើសរើសតែលើសមាមាត្រចំណាយរដ្ឋបាល នឹងជ្រើស A ហើយបដិសេធ B ដែលផ្ទុយពីអ្វីដែលភស្តុតាង [ថ្លៃចំណាយក្នុងមួយលទ្ធផល](../ថ្លៃចំណាយក្នុងមួយលទ្ធផល/) ទំនងជាបង្ហាញ ព្រោះ B គឺជាអង្គការតែមួយក្នុងចំណោមពីរដែលស្ថិតក្នុងទីតាំងដើម្បីបង្ហាញ ឬកែលម្អលទ្ធផលពិតរបស់ខ្លួន។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

កម្មវិធីហិរញ្ញវត្ថុ និងរាយការណ៍ជំនួយឧបត្ថម្ភសម្រាប់វិស័យនេះ ច្រើនតែកំណត់ការបែងចែករដ្ឋបាល/កម្មវិធីជាវាលប្រភេទនៅលើរាល់បន្ទាត់ថ្លៃចំណាយ ព្រោះនោះជាអ្វីដែលស្ថាប័នបទប្បញ្ញត្តិ និងម្ចាស់មូលនិធិមួយចំនួននៅតែតម្រូវក្នុងការរាយការណ៍តាមច្បាប់។ វិស្វករដែលកសាងប្រព័ន្ធទាំងនេះគួរចាត់ទុកតម្រូវការនោះជាកាតព្វកិច្ចអនុលោម មិនមែនជាសញ្ញាបង្ហាញពីការរចនាថាសមាមាត្រចំណាយរដ្ឋបាលគឺជារង្វាស់ដែលគួរបង្ហាញលេចធ្លោលើផ្ទាំងគ្រប់គ្រងទេ ហើយគ្រប់កន្លែងដែលបង្ហាញវា ត្រូវផ្គូផ្គងវាជាមួយរង្វាស់ផ្អែកលើលទ្ធផល ដើម្បីកុំឱ្យអ្នកមើលអានសមាមាត្រចំណាយរដ្ឋបាលដាច់ដោយឡែក។ សូមមើល [ផលត្រឡប់លើការវិនិយោគរបស់អ្នកបរិច្ចាគ](../ផលត្រឡប់លើការវិនិយោគរបស់ម្ចាស់ជំនួយ/) សម្រាប់រង្វាស់ដែលគួរស្ថិតនៅក្បែរវា និង [តម្លៃទទួលបានធៀបនឹងថ្លៃចំណាយ](../តម្លៃសមស្របនឹងថ្លៃចំណាយ/) សម្រាប់អំណះអំណាងសមមូលក្នុងវិស័យសាធារណៈប្រឆាំងនឹងតំណាងប្រសិទ្ធភាពសមាមាត្រតែមួយ។

## កំហុសដែលតែងកើតមាន

- **ការប្រើសមាមាត្រចំណាយរដ្ឋបាលជាកម្រិតកាត់ចេញ។** ការបដិសេធអង្គការសប្បុរសធម៌ណាដែលលើសកម្រិតតាមអំពើចិត្ត (ឧទាហរណ៍ «មិនលើស 15% ចំណាយរដ្ឋបាល») ដាក់ទណ្ឌកម្មជាប្រព័ន្ធលើអង្គការដែលមានធនធានត្រឹមត្រូវ និងបានវាយតម្លៃល្អ ហើយផ្តល់រង្វាន់ដល់ការវិនិយោគតិចតួច។
- **ការចាត់ថ្នាក់ថ្លៃផ្តល់ផ្ទាល់ខុសជាចំណាយរដ្ឋបាល** ឬផ្ទុយមកវិញ ព្រោះអនុសញ្ញាគណនេយ្យអំពីអ្វីដែលរាប់ជា «កម្មវិធី» ធៀបនឹង «រដ្ឋបាល» ខុសគ្នាគ្រប់គ្រាន់រវាងអង្គការសប្បុរសធម៌ ដែលសមាមាត្រច្រើនតែមិនអាចប្រៀបធៀបបានតាមការមើលដំបូង។
- **ការសន្មតថាចំណាយរដ្ឋបាលទាបមានន័យថាផលប៉ះពាល់ខ្ពស់។** ទាំងពីរ យ៉ាងល្អបំផុត គឺគ្មានទំនាក់ទំនង សូមមើលការអះអាងស្នូលនៃលិខិត Overhead Myth ឆ្នាំ 2013។
- **ការមិនអើពើថាយុទ្ធសាស្ត្រស្របច្បាប់ខ្លះតម្រូវចំណាយរដ្ឋបាលខ្ពស់ជាងក្នុងរយៈពេលខ្លី។** ដំណាក់កាលកសាងសមត្ថភាព ឬអភិវឌ្ឍអង្គការដោយចេតនាបង្កើនការចំណាយរដ្ឋបាល ដើម្បីកែលម្អការផ្តល់សេវាក្រោយ។
