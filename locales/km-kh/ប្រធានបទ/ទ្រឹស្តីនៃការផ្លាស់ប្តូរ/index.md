# ទ្រឹស្តីនៃការផ្លាស់ប្តូរ

ទ្រឹស្តីនៃការផ្លាស់ប្តូរ (theory of change) គឺជាផ្លូវមូលហេតុច្បាស់លាស់ដែលគូសផែនទីថយក្រោយ ពីគោលដៅរយៈពេលវែងទៅលក្ខខណ្ឌមុន និងសកម្មភាពដែលត្រូវតែមាន ដើម្បីឱ្យវាសម្រេចបាន រួមជាមួយការសន្មត់ដែលភ្ជាប់តំណនីមួយៗ។ វាត្រូវបានកសាងដោយចាប់ផ្តើមពីលទ្ធផលដែលអ្នកចង់បាន ហើយសួរថា "តើអ្វីត្រូវតែពិតភ្លាមៗមុនពេលនេះ ដើម្បីឱ្យវាកើតឡើង?" ម្តងហើយម្តងទៀត រហូតដល់ឈានដល់សកម្មភាពដែលអ្នកអាចអនុវត្តបានពិតប្រាកដ ដែលជាទិសដៅផ្ទុយពី[គំរូតក្កវិជ្ជា](../គំរូតក្កវិជ្ជានៃកម្មវិធី/) ហើយជាមូលហេតុដែលទាំងពីរបំពេញគ្នាទៅវិញទៅមក មិនមែនជំនួសគ្នាទេ។

## គណិតវិទ្យា

ទ្រឹស្តីនៃការផ្លាស់ប្តូរមានលក្ខណៈរចនាសម្ព័ន្ធ ជាជាងលេខ។ តំណនីមួយៗគួរមានទាំងការសន្មត់ និងសូចនាករដែលអាចបង្ហាញថាការសន្មត់ខុស៖

```
លទ្ធផលរយៈពេលវែង (គោលដៅ)
  ↑ លក្ខខណ្ឌមុន + ការសន្មត់ + សូចនាករ
លទ្ធផលកម្រិតមធ្យម N
  ↑ លក្ខខណ្ឌមុន + ការសន្មត់ + សូចនាករ
  ...
លទ្ធផលកម្រិតមធ្យម 1
  ↑ លក្ខខណ្ឌមុន + ការសន្មត់ + សូចនាករ
សកម្មភាព / អន្តរាគមន៍
  ↑ ធនធានដែលបានប្តេជ្ញា
ធាតុបញ្ចូល
```

រចនាសម្ព័ន្ធនេះបញ្ចូលដោយផ្ទាល់ទៅក្នុង[វិធីសាស្ត្រវាយតម្លៃផលប៉ះពាល់](../វិធីសាស្ត្រវាយតម្លៃផលប៉ះពាល់/) ដែលមានដើម្បីសាកល្បងថាតើការសន្មត់នៅតំណនីមួយៗពិតជាមានតម្លៃឬអត់ និងទៅក្នុង
[ការវិភាគ counterfactual](../ការវិភាគ-counterfactual/) ដែលសាកល្បងថាតើលទ្ធផលរយៈពេលវែងនឹងកើតឡើងឯណាមួយឬអត់។

## ឧទាហរណ៍គណនា

**អាជ្ញាធរមូលដ្ឋាន (ការការពារភាពគ្មានផ្ទះសម្បែង)**៖ លទ្ធផលរយៈពេលវែងគឺការជួលផ្ទះយូរអង្វែងនៅ 12 ខែ សម្រាប់គ្រួសារដែលប្រឈមនឹងការបណ្តេញចេញ។

- លក្ខខណ្ឌមុន៖ គ្រួសារមានផែនការសងបំណុលជំពាក់ដែលជាក់ស្តែង និងមានលទ្ធភាពបង់។
  ការសន្មត់៖ ផែនការដែលចរចាដោយបុគ្គលិកដោះស្រាយករណីមានភាពស្ថិតស្ថេរជាងផែនការដែលតុលាការបង្គាប់។
  សូចនាករ៖ % នៃផែនការនៅសកម្មនៅ 6 ខែ។
- លក្ខខណ្ឌមុន៖ គ្រួសារទាមទារអត្ថប្រយោជន៍ដែលពួកគេមានសិទ្ធិ។
  ការសន្មត់៖ ម៉ាស៊ីនគណនាអត្ថប្រយោជន៍ឌីជីថលបង្កើនការទាមទារត្រឹមត្រូវ ធៀបនឹងទម្រង់ក្រដាស។
  សូចនាករ៖ អត្រាភាពត្រឹមត្រូវនៃការទាមទារ ប្រៀបធៀបមុន/ក្រោយការដាក់ឱ្យប្រើឧបករណ៍។
- សកម្មភាព៖ ការវិនិច្ឆ័យបឋមដោយបុគ្គលិកដោះស្រាយករណី ម៉ាស៊ីនគណនាអត្ថប្រយោជន៍ឌីជីថល ការចរចាបំណុលជំពាក់។

ក្នុងក្រុមសាកល្បងនៃគ្រួសារ 120 ការសន្មត់ម៉ាស៊ីនគណនាអត្ថប្រយោជន៍ពិតសម្រាប់គ្រួសារ 102 (85%) ដែលបន្តទាមទារបានត្រឹមត្រូវ ដែលមានភស្តុតាងដោយការវាយតម្លៃដំណើរការបន្តបន្ទាប់ ផ្តល់ឱ្យក្រុមកម្មវិធីនូវភស្តុតាងសម្រាប់តំណជាក់លាក់នោះ ជាជាងការអះអាងពីដើមដល់ចប់តែមួយអំពីភាពគ្មានផ្ទះសម្បែងដែលបានការពារ។

**អង្គការសប្បុរសធម៌ (ការផ្តល់ប្រឹក្សាយុវជន)**៖ លទ្ធផលរយៈពេលវែងគឺការបណ្តេញចេញពីសាលាថយចុះ។ លក្ខខណ្ឌមុនដែលគូសផែនទីថយក្រោយ៖ ការគ្រប់គ្រងអារម្មណ៍ប្រសើរឡើង → ទំនាក់ទំនងមួយទល់មួយដែលទុកចិត្តជាមួយអ្នកប្រឹក្សា → ការទំនាក់ទំនងប្រចាំសប្តាហ៍ជាប់លាប់ក្នុងរយៈពេលពីរឆមាស។ ទ្រឹស្តីនេះបង្ហាញយ៉ាងច្បាស់ថា ការខកខានលក្ខខណ្ឌមុន "ទំនាក់ទំនងប្រចាំសប្តាហ៍ជាប់លាប់" (ឧទាហរណ៍ ដោយសារអ្នកប្រឹក្សាផ្លាស់ប្តូរ) ព្យាករថាលទ្ធផលនឹងមិនកើតឡើង ដែលជាការអះអាងដែលអាចសាកល្បង និងអាចបដិសេធបាន ជាជាងក្តីសង្ឃឹម។

## កំហុសដែលតែងកើតមាន

- **ការច្រលំវាជាមួយគំរូតក្កវិជ្ជា។** ទ្រឹស្តីនៃការផ្លាស់ប្តូរមានលក្ខណៈមូលហេតុ និងពន្យល់ (ហេតុអ្វីយើងជឿថាវាដំណើរការ) គំរូតក្កវិជ្ជាមានលក្ខណៈលំដាប់ និងពិពណ៌នា (អ្វីកើតឡើងតាមលំដាប់ណា)។ ការផលិតតែមួយ ទុកឱ្យខ្វះ "ហេតុអ្វី" ឬខ្សែគណនេយ្យភាព។
- **ការទុកការសន្មត់ឱ្យលាក់។** តម្លៃទាំងមូលនៃការគូសផែនទីថយក្រោយគឺការលើកឡើងការសន្មត់ដែលអាចសាកល្បង ទ្រឹស្តីនៃការផ្លាស់ប្តូរដែលគ្រាន់តែរាយប្រអប់ និងព្រួញ ដោយមិនដាក់ឈ្មោះអ្វីដែលអាចធ្វើឱ្យតំណនីមួយៗខុស គឺគ្រាន់តែជាការតុបតែង។
- **ការកសាងម្តងហើយទុកចោល។** ទ្រឹស្តីនៃការផ្លាស់ប្តូរដែលសរសេរសម្រាប់ការដេញថ្លៃទទួលមូលនិធិ ហើយមិនដែលពិនិត្យឡើងវិញ លែងមានប្រយោជន៍នៅពេលភស្តុតាងចាប់ផ្តើមផ្ទុយនឹងតំណណាមួយ។
- **ការរំលងការចូលរួមរបស់ភាគីពាក់ព័ន្ធ។** ទ្រឹស្តីនៃការផ្លាស់ប្តូរដែលកសាងទាំងស្រុងដោយអ្នកដាក់បញ្ជាទិញ ដោយគ្មានយោបល់ពីបុគ្គលិកជួរមុខ ឬអ្នកទទួលផល ទំនងជាអ៊ិនកូដការសន្មត់ដែលគ្មាននរណាបំពេញសេវាជឿពិតប្រាកដ។
