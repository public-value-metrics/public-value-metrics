# អត្រាបញ្ចុះតម្លៃសង្គម

អត្រាបញ្ចុះតម្លៃសង្គម (social discount rate) បម្លែងថ្លៃចំណាយ និងអត្ថប្រយោជន៍អនាគតមកជាតម្លៃបច្ចុប្បន្ន ដើម្បីឱ្យកម្មវិធីដែលមានផលតបស្នងកើតឡើងក្នុងរយៈពេលជាច្រើនទសវត្សអាចប្រៀបធៀបគ្នាបាននៅលើមូលដ្ឋានរួម។ Green Book របស់ក្រសួងរតនាគារអង់គ្លេស (HM Treasury) កំណត់តារាងថយចុះដែលចាប់ផ្តើមនៅ 3.5% សម្រាប់ 30 ឆ្នាំដំបូង ផ្អែកលើរូបមន្ត Ramsey ដែលជាលេខជាក់លាក់ ដែលអាចដកស្រង់បាន ហើយបានក្លាយជាអំណះអំណាងនយោបាយ និងសីលធម៌ដ៏សកម្មនៅពេលណាដែលវាត្រូវបានអនុវត្តលើកាតព្វកិច្ចរយៈពេលវែង ដូចជា គោលនយោបាយអាកាសធាតុ ឬហេដ្ឋារចនាសម្ព័ន្ធ។

## ហេតុអ្វីបានជាសំខាន់

អត្ថប្រយោជន៍មួយផោនដែលទទួលបានក្នុងរយៈពេល 30 ឆ្នាំ មិនមានតម្លៃស្មើអត្ថប្រយោជន៍មួយផោនដែលទទួលបានថ្ងៃនេះទេ ដោយសារហេតុផលដែលមួយផ្នែកទាក់ទងនឹងចំណូលចិត្តពេលវេលាសុទ្ធ (មនុស្ស និងសង្គមចូលចិត្តអ្វីដែលល្អមកលឿនជាង) និងមួយផ្នែកទាក់ទងនឹងកំណើន (សង្គមអនាគតត្រូវបានរំពឹងថានឹងមានភាពសម្បូរសប្បាយជាង ដូច្នេះមួយផោនមានសារៈសំខាន់តិចជាងចំពោះវាត្រង់ចុងនៃរឹម)។ ឧបសម្ព័ន្ធ 6 នៃ Green Book បង្កើតអត្រាបញ្ចុះតម្លៃស្តង់ដារនៃចក្រភពអង់គ្លេសពីរូបមន្ត Ramsey ដោយបូកបញ្ចូលអត្រាចំណូលចិត្តពេលវេលាសុទ្ធ ជាមួយអត្រាកំណើនដែលរំពឹងទុកនៃការប្រើប្រាស់ និងភាពបត់បែននៃឧបយោគរឹមនៃការប្រើប្រាស់ ដែលផ្តល់អត្រាដែលបានផ្សព្វផ្សាយ 3.5% ក្នុងមួយឆ្នាំ សម្រាប់ឆ្នាំទី 0–30 ថយចុះតាមតារាងដែលបានផ្សព្វផ្សាយសម្រាប់ឆ្នាំទី 31 និងបន្តបន្ទាប់ (ចុះដល់ 1% សម្រាប់ឆ្នាំទី 301+)។ តារាងនេះមានជាក់លាក់ ពីព្រោះ 3.5% ថេរដែលគណនាប្រាក់ចំណេញសមាសធាតុក្នុងរយៈពេលមួយសតវត្ស នឹងធ្វើឱ្យអត្ថប្រយោជន៍រយៈពេលវែងស្ទើរតែទាំងអស់ ដូចជា ការការពារទឹកជំនន់ដែលសង្គ្រោះជីវិតក្នុងរយៈពេល 80 ឆ្នាំ ឬការកាត់បន្ថយកាបូនដែលជៀសវាងគ្រោះថ្នាក់ក្នុងរយៈពេល 100 ឆ្នាំ ហាក់ដូចជាមិនសំខាន់ក្នុងន័យតម្លៃបច្ចុប្បន្ន ដែលក្រសួងរតនាគារបានវិនិច្ឆ័យថាជាសេចក្តីសន្និដ្ឋានសីលធម៌ដែលមិនជឿជាក់សម្រាប់ការសម្រេចចិត្តអំពីហេដ្ឋារចនាសម្ព័ន្ធ និងបរិស្ថានដែលមានអាយុកាលវែងពិតប្រាកដ។

អត្រាបញ្ចុះតម្លៃមានភាពចម្រូងចម្រាស ពីព្រោះជម្រើសនេះមិនមែនជាប៉ារ៉ាម៉ែត្របច្ចេកទេសអព្យាក្រឹតទេ៖ វាអ៊ិនកូដការវិនិច្ឆ័យអំពីចំនួនដែលសង្គមគួរលះបង់ថ្ងៃនេះសម្រាប់មនុស្សដែលមិនទាន់កើត។ ការពិនិត្យ Stern ស្តីពីសេដ្ឋកិច្ចនៃការប្រែប្រួលអាកាសធាតុ (2006) បានប្រើអត្រាបញ្ចុះតម្លៃជិតសូន្យ (ចំណូលចិត្តពេលវេលាសុទ្ធជិត 0.1%) ដោយអះអាងថា ការបញ្ចុះតម្លៃសុខុមាលភាពនៃមនុស្សជំនាន់ក្រោយតាមអត្រាស្រដៀងអត្រាទីផ្សារ គឺមិនអាចការពារបានខាងសីលធម៌ នៅពេលដែលគ្រោះថ្នាក់ (ការប្រែប្រួលអាកាសធាតុមហន្តរាយ) មិនអាចត្រឡប់វិញបាន។ អ្នករិះគន់ ជាពិសេស William Nordhaus បានប្រកែកថា អត្រាជិតសូន្យរបស់ Stern ធ្វើឱ្យករណីសម្រាប់ការចំណាយអាកាសធាតុភ្លាមៗហួសការពិត ដោយធ្វើឱ្យថ្លៃចំណាយបច្ចុប្បន្នស្ទើរតែទាំងអស់មើលទៅសមហេតុផល ធៀបនឹងអត្ថប្រយោជន៍អនាគតដែលស្ទើរតែមិនត្រូវបានបញ្ចុះតម្លៃ។ ការមិនឯកភាពនេះមិនមែនអំពីគណិតវិទ្យាទេ៖ វាគឺអំពីក្របខ័ណ្ឌសីលធម៌របស់អ្នកណាគួរកំណត់អត្រា ហើយវានៅតែជាឧទាហរណ៍ស្តង់ដារដែលបង្ហាញថា ហេតុអ្វីអត្រាបញ្ចុះតម្លៃជាជម្រើសគោលនយោបាយ មិនមែនគ្រាន់តែជាធាតុបញ្ចូលគណនាធានារ៉ាប់រងទេ។

## គណិតវិទ្យា

រូបមន្ត Ramsey ដែលជាមូលដ្ឋាននៃអត្រារបស់ Green Book៖

```
r = ρ + η·g

ដែល៖
  r = អត្រាបញ្ចុះតម្លៃសង្គម
  ρ = អត្រាចំណូលចិត្តពេលវេលាសុទ្ធ (ភាពអត់ធ្មត់ទាប + ហានិភ័យមហន្តរាយ)
  η = ភាពបត់បែននៃឧបយោគរឹមនៃការប្រើប្រាស់
  g = អត្រាកំណើនប្រចាំឆ្នាំដែលរំពឹងទុកនៃការប្រើប្រាស់ក្នុងមួយនាក់
```

តារាងថយចុះរបស់ Green Book (ឧបសម្ព័ន្ធ 6 សម្រាប់ឧទាហរណ៍ សូមពិនិត្យការបោះពុម្ពបច្ចុប្បន្នសម្រាប់តារាងដែលបានផ្សព្វផ្សាយជាក់លាក់)៖

```
ឆ្នាំទី 0–30:    3.5%
ឆ្នាំទី 31–75:   3.0%
ឆ្នាំទី 76–125:  2.5%
ឆ្នាំទី 126–200: 2.0%
ឆ្នាំទី 201–300: 1.5%
ឆ្នាំទី 301+:    1.0%
```

តម្លៃបច្ចុប្បន្ននៃចំនួនទឹកប្រាក់អនាគត៖

```
PV = FV / (1 + r)^t
```

## ឧទាហរណ៍គណនា

**គម្រោងការពារទឹកជំនន់**៖ គម្រោងមួយផ្តល់ការជៀសវាងខូចខាតទឹកជំនន់ចំនួន £10 million ក្នុងឆ្នាំទី 40។

ដោយប្រើអត្រាថេរ 3.5%៖ PV = 10,000,000 / (1.035)^40 ≈ £2.52 million អត្ថប្រយោជន៍មើលទៅតូច។

ដោយប្រើតារាងថយចុះរបស់ Green Book (3.5% សម្រាប់ឆ្នាំទី 0–30 បន្ទាប់មក 3.0%) ការគណនាប្រើអត្រា 3.5% សម្រាប់ 30 ឆ្នាំដំបូង និង 3.0% សម្រាប់ឆ្នាំទី 31–40៖

```
PV = 10,000,000 / [(1.035)^30 × (1.03)^10]
   = 10,000,000 / [2.807 × 1.344]
   ≈ 10,000,000 / 3.773
   ≈ £2.65 million
```

តារាងថយចុះបង្កើនតម្លៃបច្ចុប្បន្ននៃអត្ថប្រយោជន៍រយៈពេលវែងបន្តិចធៀបនឹងអត្រាថេរខ្ពស់ ដែលជាគោលបំណងច្បាស់លាស់នៃតារាង ពីព្រោះ 3.5% ថេរក្នុងមួយសតវត្សនឹងបញ្ចុះតម្លៃអត្ថប្រយោជន៍ £100 million ក្នុងឆ្នាំទី 100 មកក្រោម £3.3 million។

**ហេដ្ឋារចនាសម្ព័ន្ធឌីជីថល**៖ ការផ្លាស់ប្តូរទៅពពក (cloud) របស់រដ្ឋាភិបាលដែលមានថ្លៃចំណាយ £4 million ឥឡូវនេះ ត្រូវបានរំពឹងថានឹងជៀសវាងថ្លៃចំណាយថែទាំប្រព័ន្ធចាស់ £500,000/ឆ្នាំ ក្នុងរយៈពេល 15 ឆ្នាំ។ នៅ 3.5% តម្លៃបច្ចុប្បន្ននៃប្រាក់បៀវត្សរ៍នោះប្រហែល £500,000 × 11.52 (កត្តាប្រាក់បៀវត្សរ៍ 15 ឆ្នាំ ក្នុងអត្រា 3.5%) ≈ £5.76 million ដែលលើសពីថ្លៃចំណាយ £4 million យ៉ាងងាយស្រួល ជាករណីតម្លៃបច្ចុប្បន្នសុទ្ធជាវិជ្ជមាន ដែលនឹងមើលទៅខ្សោយជាងគួរឱ្យកត់សម្គាល់នៅអត្រាខ្ពស់ជាងដែលជ្រើសរើសដោយឆោតល្ងង់ (នៅ 7% កត្តាប្រាក់បៀវត្សរ៍ដដែលធ្លាក់ទៅប្រហែល 9.11 ផ្តល់ £4.56 million នៅតែវិជ្ជមាន ប៉ុន្តែមានរឹមស្តើងជាងច្រើន)។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

ករណីអាជីវកម្មកម្មវិធីភាគច្រើនដំណើរការក្នុងរយៈពេល 3–5 ឆ្នាំ ដែលស្ថិតក្នុងកម្រិត 3.5% ថេរ ដូច្នេះតារាងថយចុះកម្រប៉ះពាល់ដោយផ្ទាល់ ប៉ុន្តែវិន័យមូលដ្ឋានមានសារៈសំខាន់សម្រាប់ការវិនិយោគបច្ចេកវិទ្យារបស់រដ្ឋាភិបាលណាមួយដែលមានអាយុកាលទ្រព្យសកម្មវែង (វេទិកាជាតិ កម្មវិធីហេដ្ឋារចនាសម្ព័ន្ធទិន្នន័យ កិច្ចសន្យាច្រើនទសវត្ស)៖

- ប្រើអត្រាដែលបានផ្សព្វផ្សាយរបស់ Green Book ជាជាង "អត្រាកម្រិត" (hurdle rate) ផ្ទៃក្នុងដែលខ្ចីពីហិរញ្ញវត្ថុឯកជន ព្រោះសវនករ និងអ្នកត្រួតពិនិត្យរបស់ក្រសួងរតនាគាររំពឹងតារាងស្តង់ដារ។
- សម្រាប់អត្ថប្រយោជន៍ដែលសម្រេចបានជាច្រើនឆ្នាំក្រោយ (ការសន្សំថ្លៃថែទាំរយៈពេលវែងរបស់វេទិកា តម្លៃកើនឡើងជាសមាសធាតុនៃប្រព័ន្ធអេកូទិន្នន័យបើកចំហ សូមមើល [តម្លៃនៃទិន្នន័យបើកចំហ](../តម្លៃនៃទិន្នន័យបើកចំហ/)) ជម្រើសនៃការបញ្ចុះតម្លៃអាចបង្វែរករណីអាជីវកម្មពីវិជ្ជមានទៅអវិជ្ជមាន ដូច្នេះត្រូវធ្វើឱ្យអត្រា និងផ្តេកពេលវេលាជាការសន្មត់ច្បាស់លាស់ មិនមែនលំនាំដើមដែលលាក់ទេ។
- នេះបញ្ចូលដោយផ្ទាល់ទៅក្នុង[ការវាយតម្លៃតាម Green Book](../ការវាយតម្លៃតាម-green-book/) ដែលជាគំរូប្រាំករណីដែលតម្រូវជាផ្លូវការនូវលំហូរសាច់ប្រាក់បញ្ចុះតម្លៃ និងទៅក្នុង
  [ការវាយតម្លៃសុខុមាលភាព](../ការវាយតម្លៃសុខុមាលភាព/) ដែលសំណួរបញ្ចុះតម្លៃដូចគ្នាកើតឡើងសម្រាប់អត្ថប្រយោជន៍សុខុមាលភាពដែលមិនមែនជាប្រាក់។
- សូមមើលផងដែរ [សមធម៌រវាងជំនាន់ និងការបញ្ចុះតម្លៃដើម្បីនិរន្តរភាព](../សមធម៌រវាងជំនាន់-និងការបញ្ចុះតម្លៃនិរន្តរភាព/)
  សម្រាប់ការជជែកវែកញែក Stern ធៀប Nordhaus ដែលអនុវត្តជាពិសេសលើការវិនិយោគបច្ចេកវិទ្យាបរិស្ថាន និងអាកាសធាតុ។

## កំហុសដែលតែងកើតមាន

- **ការប្រើអត្រាថេរសម្រាប់ផ្តេកពេលវេលាវែងខ្លាំង។** តារាងថយចុះរបស់ Green Book មានជាក់លាក់ ពីព្រោះអត្រាថេរធ្វើឱ្យអត្ថប្រយោជន៍ដែលមានអាយុកាលវែងពិតប្រាកដទាបជាងការពិត ដូច្នេះត្រូវពិនិត្យថាកម្រិតណាអនុវត្ត ជាជាងប្រើ 3.5% ពេញមួយរយៈពេលតាមលំនាំដើម។
- **ការចាត់ទុកអត្រាបញ្ចុះតម្លៃថាអព្យាក្រឹតខាងសីលធម៌។** ជម្លោះ Stern-Nordhaus បង្ហាញថា អត្រាអ៊ិនកូដការវិនិច្ឆ័យតម្លៃអំពីមនុស្សជំនាន់ក្រោយ ការផ្លាស់ប្តូរវាផ្លាស់ប្តូរថាកម្មវិធីណាមើលទៅសមហេតុផល ដូច្នេះវាគួរតែត្រូវបានបញ្ជាក់ និងការពារ មិនមែនលាក់នៅក្នុងលំនាំដើមរបស់សៀវភៅបញ្ជី (spreadsheet) ទេ។
- **ការច្រលំអត្រាបញ្ចុះតម្លៃសង្គមជាមួយថ្លៃចំណាយដើមទុនឯកជន។** ថ្លៃចំណាយខ្ចីរបស់រដ្ឋាភិបាល និងអត្រាកម្រិតវិស័យឯកជន គឺជាគំនិតខុសពីអត្រាសង្គមដែលបានមកពី Ramsey ហើយការជំនួសមួយដោយមួយទៀតក្នុងការវាយតម្លៃសាធារណៈ ជាទូទៅនឹងបង្ខូចលទ្ធផលក្នុងទិសដៅដែលពេញចិត្តប្រាក់ចំណេញរយៈពេលខ្លី។
- **ការបញ្ចុះតម្លៃលំហូរសាច់ប្រាក់ពិត និងនាមករណ៍មិនស៊ីសង្វាក់គ្នា។** អត្រារបស់ Green Book គឺជាអត្រាពិត (កែតម្រូវអតិផរណា) ការបញ្ចុះតម្លៃលំហូរសាច់ប្រាក់នាមករណ៍ដោយវា ធ្វើឱ្យតម្លៃបច្ចុប្បន្នទាបជាងការពិតយ៉ាងខ្លាំង។
