# ಪ್ರತಿ ಫಲಾನುಭವಿಯ ವೆಚ್ಚ

ಪ್ರತಿ ಫಲಾನುಭವಿಯ ವೆಚ್ಚ (cost per beneficiary) ಎಂದರೆ ಕಾರ್ಯಕ್ರಮದ ಒಟ್ಟು ವೆಚ್ಚವನ್ನು ಸೇವೆ ಪಡೆದ ವಿಶಿಷ್ಟ ಜನರ ಸಂಖ್ಯೆಯಿಂದ ಭಾಗಿಸಿದ್ದು — ಅವರ ಪರಿಸ್ಥಿತಿಗಳು ನಿಜವಾಗಿ ಬದಲಾದವೇ ಎಂಬುದನ್ನು ಲೆಕ್ಕಿಸದೆ, ಸ್ಪರ್ಶಿಸಲ್ಪಟ್ಟ ಯಾರಾದರೂ. ಇದು ಸಂಸ್ಥೆಯೊಂದು ತಯಾರಿಸಬಹುದಾದ ಅತಿ ವೇಗದ ದಕ್ಷತೆಯ ಸಂಖ್ಯೆ, ಏಕೆಂದರೆ "ನಾವು ಯಾರಿಗೆ ಸೇವೆ ನೀಡಿದೆವು" ಎಂಬುದು ಬಹುತೇಕ ಯಾವಾಗಲೂ ಈಗಾಗಲೇ ಪ್ರಕರಣ ನಿರ್ವಹಣಾ ವ್ಯವಸ್ಥೆಯಲ್ಲಿರುತ್ತದೆ, ಆದರೆ "ಯಾರಿಗೆ ಸಹಾಯವಾಯಿತು" ಎಂಬುದು ಸಾಮಾನ್ಯವಾಗಿ ಇರುವುದಿಲ್ಲ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಹಣಕಾಸುದಾರರು ಪ್ರತಿ ಫಲಾನುಭವಿಯ ವೆಚ್ಚವನ್ನು ನಿರಂತರವಾಗಿ ಕೇಳುತ್ತಾರೆ, ಮತ್ತು ಸಮರ್ಥನೀಯ ಕಾರಣಗಳಿಗಾಗಿ: ಇದು ತಕ್ಷಣ ಲಭ್ಯ, ಬಹಳ ಭಿನ್ನವಾದ ಕಾರ್ಯಕ್ರಮಗಳ ಪೋರ್ಟ್‌ಫೋಲಿಯೊದಾದ್ಯಂತ ಹೋಲಿಸಬಹುದಾದದ್ದು, ಮತ್ತು ದೃಢೀಕರಿಸಲು ಹೆಚ್ಚು ಸಮಯ ಬೇಕಾದ ಹಾಗೂ ಉಬ್ಬಿಸಿ ಹೇಳಲು ಸುಲಭವಾದ ಫಲಿತಾಂಶ ಹೇಳಿಕೆಗಳಿಗಿಂತ ವ್ಯಾಪ್ತಿಯ ಬಗ್ಗೆ ಪ್ರಾಮಾಣಿಕ. FRS 102 ಅಡಿಯಲ್ಲಿ ದತ್ತಿ ಸಂಸ್ಥೆಗಳು ಹೇಗೆ ವರದಿ ಮಾಡಬೇಕು ಎಂಬುದನ್ನು ನಿಯಂತ್ರಿಸುವ ಯುಕೆ Charities SORP (Statement of Recommended Practice), ಟ್ರಸ್ಟಿಗಳ ವಾರ್ಷಿಕ ವರದಿಗಳು ಉದ್ದೇಶಗಳ ವಿರುದ್ಧ ಸಾಧನೆಗಳನ್ನು ವಿವರಿಸಬೇಕೆಂದು ಅಗತ್ಯಪಡಿಸುತ್ತದೆ, ಆದರೆ ಹೆಚ್ಚಿನ ಸಣ್ಣ ದತ್ತಿ ಸಂಸ್ಥೆಗಳ ನಿರ್ವಹಣಾ ಲೆಕ್ಕಪತ್ರಗಳು ತಯಾರಿಸಲು ಅಗ್ಗ ಮತ್ತು ಲೆಕ್ಕಪರಿಶೋಧನೆ-ಸ್ನೇಹಿಯಾಗಿರುವುದರಿಂದ ಇನ್ನೂ ವ್ಯಾಪ್ತಿ-ಆಧಾರಿತ ಘಟಕ ವೆಚ್ಚಗಳನ್ನೇ ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ ಬಳಸುತ್ತವೆ.

ಅಪಾಯವೆಂದರೆ, ಪ್ರತಿ ಫಲಾನುಭವಿಯ ವೆಚ್ಚವು ಅದು ಉತ್ತರಿಸಲಾಗದ ಪ್ರಶ್ನೆಗೆ — ಹಣ ಕೆಲಸ ಮಾಡಿತೇ ಎಂಬುದಕ್ಕೆ — ಉತ್ತರಿಸುತ್ತದೆ ಎಂಬಂತೆ ಪರಿಗಣಿಸುವುದು. ಅದಕ್ಕೆ ನಿಜವಾಗಿ ಉತ್ತರಿಸುವ ಮಾಪನಕ್ಕಾಗಿ [ಪ್ರತಿ ಫಲಿತಾಂಶದ ವೆಚ್ಚ](../ಪ್ರತಿ-ಫಲಿತಾಂಶದ-ವೆಚ್ಚ/) ಮತ್ತು ಆಧಾರವಾದ ವ್ಯತ್ಯಾಸಕ್ಕಾಗಿ [ಫಲಿತಾಂಶಗಳು ಮತ್ತು ಉತ್ಪಾದನೆಗಳು](../ಫಲಿತಾಂಶ-ಮತ್ತು-ಉತ್ಪನ್ನ/) ನೋಡಿ. ಪ್ರತಿ ಫಲಾನುಭವಿಯ ವೆಚ್ಚ ನ್ಯಾಯಸಮ್ಮತ ವರ್ಗೀಕರಣ ಮತ್ತು ವ್ಯಾಪ್ತಿ ಮಾಪನ — ಹಣ ಎಷ್ಟು ದೂರ ಹರಡುತ್ತದೆ ಎಂದು ಹಣಕಾಸುದಾರನಿಗೆ ಹೇಳುತ್ತದೆ — ಆದರೆ ಕಡಿಮೆ ಪ್ರತಿ ಫಲಾನುಭವಿ ವೆಚ್ಚ ಎಂದರೆ ನಿಜವಾದ ದಕ್ಷತೆ ಅಥವಾ ಏನನ್ನೂ ಬದಲಾಯಿಸದಷ್ಟು ತೆಳುವಾದ ಸೇವೆ, ಇವೆರಡರಲ್ಲಿ ಯಾವುದಾದರೂ ಆಗಿರಬಹುದು.

## ಗಣಿತ

```
ಪ್ರತಿ ಫಲಾನುಭವಿಯ ವೆಚ್ಚ = ಕಾರ್ಯಕ್ರಮದ ಒಟ್ಟು ವೆಚ್ಚ / ಸೇವೆ ಪಡೆದ ವಿಶಿಷ್ಟ ಜನರ ಸಂಖ್ಯೆ

ವ್ಯತಿರಿಕ್ತ:
ಪ್ರತಿ ಫಲಿತಾಂಶದ ವೆಚ್ಚ      = ಕಾರ್ಯಕ್ರಮದ ಒಟ್ಟು ವೆಚ್ಚ / ವ್ಯಾಖ್ಯಾನಿತ ಫಲಿತಾಂಶ ಸಾಧಿಸಿದ ಜನರ ಸಂಖ್ಯೆ

ಪ್ರತಿ ಫಲಾನುಭವಿಯ ವೆಚ್ಚ ಯಾವಾಗಲೂ ≤ ಪ್ರತಿ ಫಲಿತಾಂಶದ ವೆಚ್ಚ, ಏಕೆಂದರೆ ಫಲಿತಾಂಶ ಜನಸಂಖ್ಯೆ
ಫಲಾನುಭವಿ ಜನಸಂಖ್ಯೆಯ ಉಪಗುಂಪು (ಆಗಾಗ್ಗೆ ಸಣ್ಣದು).
```

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

**ಆಹಾರ ಬ್ಯಾಂಕ್, ಪ್ರತಿ-ಫಲಿತಾಂಶ-ವೆಚ್ಚ ಉದಾಹರಣೆಯ ಅದೇ ವರ್ಷ**:

- ಕಾರ್ಯಕ್ರಮದ ಒಟ್ಟು ವೆಚ್ಚ: £450,000
- ಸೇವೆ ಪಡೆದ ವಿಶಿಷ್ಟ ಮನೆಗಳು (ಮೂರು-ಮತ್ತು-ಹೆಚ್ಚು ಪಾರ್ಸೆಲ್‌ಗಳು): 1,800

```
ಪ್ರತಿ ಫಲಾನುಭವಿಯ ವೆಚ್ಚ = £450,000 / 1,800 = ಸೇವೆ ಪಡೆದ ಪ್ರತಿ ಮನೆಗೆ £250
```

ಎರಡು ಮಾಪನಗಳನ್ನು ಅಕ್ಕಪಕ್ಕ ಹೋಲಿಸಿ:

| ಮಾಪನ | ಛೇದ | ಫಲಿತಾಂಶ |
|---|---|---|
| ಪ್ರತಿ ಫಲಾನುಭವಿಯ ವೆಚ್ಚ | ಸೇವೆ ಪಡೆದ 1,800 ಮನೆಗಳು | £250 |
| ಪ್ರತಿ ಫಲಿತಾಂಶದ ವೆಚ್ಚ | ಆಹಾರ ಭದ್ರತೆ ಸಾಧಿಸಿದ 630 ಮನೆಗಳು | £714 |

ಕೇವಲ £250 ನೋಡುವ ಹಣಕಾಸುದಾರನು ಇದು ಅತ್ಯಂತ ದಕ್ಷ ದತ್ತಿ ಸಂಸ್ಥೆ ಎಂದು ತೀರ್ಮಾನಿಸಬಹುದು. ಎರಡೂ ಸಂಖ್ಯೆಗಳನ್ನು ನೋಡುವವನು ಹೆಚ್ಚು ಉಪಯುಕ್ತ ಪ್ರಶ್ನೆ ಕೇಳಬಹುದು: ವ್ಯಾಪ್ತಿ (1,800) ಮತ್ತು ಫಲಿತಾಂಶ (630) ನಡುವಿನ ಅಂತರವು ದತ್ತಾಂಶ-ಸಂಗ್ರಹ ಅಂತರವೇ, ವಿನ್ಯಾಸ ಅಂತರವೇ, ಅಥವಾ ಆಹಾರ ನೆರವಿನಿಂದ ಮಾತ್ರ ಆಹಾರ ಭದ್ರತೆ ಸಾಧಿಸುವುದು ಎಷ್ಟು ಕಷ್ಟ ಎಂಬುದರ ಪ್ರಾಮಾಣಿಕ ಪ್ರತಿಬಿಂಬವೇ?

**ಉದ್ಯೋಗ-ತರಬೇತಿ ದತ್ತಿ ಸಂಸ್ಥೆ, ವಿವರಣಾತ್ಮಕ**: ಪ್ರತಿ ಫಲಾನುಭವಿಯ ವೆಚ್ಚ (ದಾಖಲಾದವರು) = £2,000; ಪ್ರತಿ ಫಲಿತಾಂಶದ ವೆಚ್ಚ (6 ತಿಂಗಳಲ್ಲಿ ಸುಸ್ಥಿರ ಉದ್ಯೋಗ) = £11,000, ಏಕೆಂದರೆ ದಾಖಲಾದವರಲ್ಲಿ ಕೇವಲ 18% ಜನರು ಕಾರ್ಯಕ್ರಮ ಪೂರ್ಣಗೊಳಿಸಿ ಸುಸ್ಥಿರ ಕೆಲಸ ಪಡೆಯುತ್ತಾರೆ. ಪೂರ್ಣಗೊಳಿಸುವಿಕೆ ಅಥವಾ ಬಾಳಿಕೆ ದರಗಳು ಕಡಿಮೆ ಇರುವಲ್ಲೆಲ್ಲಾ ಎರಡು ಸಂಖ್ಯೆಗಳು ಐದು ಪಟ್ಟು ಭಿನ್ನವಾಗುವುದು ಸಾಮಾನ್ಯ — ತರಬೇತಿ ದತ್ತಿ ಸಂಸ್ಥೆ ಮತ್ತು ಆಹಾರ ಬ್ಯಾಂಕ್ ಇಲ್ಲಿ ರಚನಾತ್ಮಕವಾಗಿ ಒಂದೇ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್ ಸಂಪರ್ಕ

ಲಾಭರಹಿತ ಸಾಫ್ಟ್‌ವೇರ್‌ನಲ್ಲಿ ಪ್ರತಿ ಫಲಾನುಭವಿಯ ವೆಚ್ಚವೇ ಪೂರ್ವನಿಯೋಜಿತ ಮಾಪನ, ಏಕೆಂದರೆ ಫಲಾನುಭವಿ ದಾಖಲೆಯಿಂದ ಹೆಚ್ಚಿನ ಕೆಲಸವಿಲ್ಲದೆ ಹೊರಬರುವ ಮಾಪನ ಇದು: ಪ್ರಕರಣ ರಚಿಸಿ, ಸೇವೆ ದಾಖಲಿಸಿ, ಸಾಲುಗಳನ್ನು ಎಣಿಸಿ. ಪ್ರತಿ ಫಲಿತಾಂಶದ ವೆಚ್ಚವನ್ನೂ ಬೆಂಬಲಿಸುವ ವ್ಯವಸ್ಥೆಯನ್ನು ನಿರ್ಮಿಸುವುದು ಎಂದರೆ ಉದ್ದೇಶಪೂರ್ವಕವಾಗಿ ಎರಡನೇ ಪ್ರಥಮ-ದರ್ಜೆ ಘಟಕವನ್ನು ಸೇರಿಸುವುದು — ಸೇವಾ ವಿತರಣೆಯಿಂದ ಸ್ವತಂತ್ರವಾಗಿ ದಿನಾಂಕ ಮತ್ತು ವ್ಯಾಖ್ಯಾನ ಹೊಂದಿದ ಫಲಿತಾಂಶ ಘಟನೆ — ಮತ್ತು "ಪ್ರಕರಣ ಮುಚ್ಚಲಾಗಿದೆ" ಎಂಬುದು "ಫಲಿತಾಂಶ ಸಾಧಿಸಲಾಗಿದೆ" ಎಂಬುದರ ಸ್ಥಾನ ಪಡೆಯಲು ಬಿಡುವ ಪ್ರಲೋಭನೆಯನ್ನು ಪ್ರತಿರೋಧಿಸುವುದು. ಅನುದಾನ ನಿರ್ವಹಣೆ ಅಥವಾ CRM ವೇದಿಕೆಯ ವ್ಯಾಪ್ತಿ ನಿಗದಿಪಡಿಸುವಾಗ, ಪ್ರತಿ ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ ನಿಜವಾಗಿ ಎರಡರಲ್ಲಿ ಯಾವ ಮಾಪನವನ್ನು ತೋರಿಸುತ್ತಿದೆ ಎಂದು ಕೇಳಿ ಮತ್ತು ಅದಕ್ಕೆ ತಕ್ಕಂತೆ ಲೇಬಲ್ ಮಾಡಿ; ಇವನ್ನು ಒಂದೇ "ಪರಿಣಾಮ" ಟೈಲ್‌ನಲ್ಲಿ ಬೆರೆಸುವುದು ಕೆಳಗಿನ ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳಿಗೆ ಸಾಫ್ಟ್‌ವೇರ್-ಮಟ್ಟದ ಅತ್ಯಂತ ಸಾಮಾನ್ಯ ಕಾರಣಗಳಲ್ಲಿ ಒಂದು. ಯಾವುದೇ ಮಾಪನವನ್ನು ಸರಿಯಾಗಿ ಲೇಬಲ್ ಮಾಡಿದ ನಂತರ ಮಾನದಂಡ ಹೋಲಿಕೆಗಾಗಿ [ಘಟಕ ವೆಚ್ಚ ದತ್ತಾಂಶ ಸಂಗ್ರಹಗಳು](../ಘಟಕ-ವೆಚ್ಚ-ದತ್ತಾಂಶ-ಸಂಗ್ರಹಗಳು/) ನೋಡಿ.

## ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳು

- **ಪ್ರತಿ ಫಲಾನುಭವಿಯ ವೆಚ್ಚವನ್ನು ಪರಿಣಾಮವೆಂದು ಪ್ರಸ್ತುತಪಡಿಸುವುದು.** ಇದು ವ್ಯಾಪ್ತಿಯನ್ನು ಅಳೆಯುತ್ತದೆ, ಬದಲಾವಣೆಯನ್ನಲ್ಲ. ಡ್ಯಾಶ್‌ಬೋರ್ಡ್‌ಗಳು ಮತ್ತು ವರದಿಗಳನ್ನು "ಸಹಾಯ ಪಡೆದ ಪ್ರತಿ ವ್ಯಕ್ತಿಯ ವೆಚ್ಚ" ಅಲ್ಲ, "ಸೇವೆ ಪಡೆದ ಪ್ರತಿ ವ್ಯಕ್ತಿಯ ವೆಚ್ಚ" ಎಂದು ಲೇಬಲ್ ಮಾಡಿ.
- **ಕಾರ್ಯಕ್ರಮಗಳಾದ್ಯಂತ ದ್ವಿಗುಣ ಎಣಿಕೆ.** ಒಂದೇ ದತ್ತಿ ಸಂಸ್ಥೆಯಿಂದ ಆಹಾರ ಪಾರ್ಸೆಲ್ ಮತ್ತು ಸಾಲ ಸಲಹೆ ಎರಡನ್ನೂ ಪಡೆಯುವ ವ್ಯಕ್ತಿ, ಛೇದವು ವಿಶಿಷ್ಟ ವ್ಯಾಪ್ತಿಯನ್ನು ವಿವರಿಸಬೇಕಾದರೆ, ಇಬ್ಬರಲ್ಲ, ಒಬ್ಬ ಫಲಾನುಭವಿ; ಯಾವ ಸಂಪ್ರದಾಯ ಬಳಸಲಾಗಿದೆ ಎಂದು ನಿರ್ಧರಿಸಿ ದಾಖಲಿಸಿ.
- **ಕಡಿಮೆ ಸಂಖ್ಯೆ ಯಾವಾಗಲೂ ಉತ್ತಮ ಎಂದು ಪರಿಗಣಿಸುವುದು.** ಡ್ರಾಪ್-ಇನ್ ಊಟದ ಕ್ಲಬ್ ಯಾವಾಗಲೂ ತೀವ್ರ ಪ್ರಕರಣ-ನಿರ್ವಹಣಾ ಸೇವೆಯನ್ನು ಪ್ರತಿ ಫಲಾನುಭವಿಯ ವೆಚ್ಚದಲ್ಲಿ ಸೋಲಿಸುತ್ತದೆ, ಏಕೆಂದರೆ ಯಾರನ್ನಾದರೂ ಹಗುರವಾಗಿ ಸ್ಪರ್ಶಿಸಲು ಕಡಿಮೆ ವೆಚ್ಚ. ಪ್ರತಿ ಪೌಂಡ್‌ಗೆ ಯಾವುದು ಹೆಚ್ಚು ಬಾಳಿಕೆ ಬರುವ ಬದಲಾವಣೆ ಉತ್ಪಾದಿಸುತ್ತದೆ ಎಂಬುದರ ಬಗ್ಗೆ ಅದು ಏನನ್ನೂ ಹೇಳುವುದಿಲ್ಲ.
- **ವರದಿಗಳ ನಡುವೆ ಛೇದಗಳನ್ನು ಸದ್ದಿಲ್ಲದೆ ಬದಲಿಸುವುದು.** ಒಂದು ವಾರ್ಷಿಕ ವರದಿಯಲ್ಲಿ "ದಾಖಲಾದವರು" ವಿರುದ್ಧ ಮತ್ತು ಮುಂದಿನದರಲ್ಲಿ "ಪೂರ್ಣಗೊಳಿಸಿದವರು" ವಿರುದ್ಧ ಉಲ್ಲೇಖಿಸಿದ ಪ್ರತಿ-ಫಲಾನುಭವಿ-ವೆಚ್ಚ ಅಂಕಿ ವರ್ಷದಿಂದ ವರ್ಷಕ್ಕೆ ಹೋಲಿಸಲಾಗುವುದಿಲ್ಲ; ಪ್ರತಿ ಬಾರಿ ಛೇದವನ್ನು ಹೇಳಿ.
