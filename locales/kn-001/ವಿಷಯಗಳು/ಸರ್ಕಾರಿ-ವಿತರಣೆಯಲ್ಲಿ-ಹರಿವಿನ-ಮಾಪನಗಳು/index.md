# ಸರ್ಕಾರಿ ವಿತರಣೆಯಲ್ಲಿ ಹರಿವಿನ ಮಾಪನಗಳು

ಹರಿವಿನ ಮಾಪನಗಳು (ಲಿಟಲ್ಸ್ ನಿಯಮ, ಕೆಲಸ-ಪ್ರಗತಿಯಲ್ಲಿರುವ (WIP) ಮಿತಿಗಳು ಮತ್ತು ಹರಿವಿನ ದಕ್ಷತೆ) ಸೀಮಿತ ಸಾಮರ್ಥ್ಯದ ವ್ಯವಸ್ಥೆಯ ಮೂಲಕ ಕೆಲಸ ಎಷ್ಟು ವೇಗವಾಗಿ ಚಲಿಸುತ್ತದೆ ಎಂಬುದನ್ನು ವಿವರಿಸುತ್ತವೆ. ಸ್ಪ್ರಿಂಟ್ ಬೋರ್ಡ್ ಇಂತಹ ಒಂದು ವ್ಯವಸ್ಥೆ; ಸೌಲಭ್ಯ-ಹಕ್ಕು ಸರದಿ, ಯೋಜನಾ-ಅರ್ಜಿ ನೋಂದಣಿ ಅಥವಾ ವೀಸಾ ಪ್ರಕರಣ ಬಾಕಿ ಕೆಲಸ ಬೇರೆ ಸಮವಸ್ತ್ರ ತೊಟ್ಟ ಅದೇ ಗಣಿತ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಸರ್ಕಾರಿ ಪ್ರಕರಣ-ಭಾರಗಳು ಸರದಿ ವ್ಯವಸ್ಥೆಗಳು, ಮತ್ತು ಯಾರಾದರೂ ಅಳೆಯಲಿ ಬಿಡಲಿ ಸರದಿ ವ್ಯವಸ್ಥೆಗಳು ಸರದಿ ನಿಯಮಗಳನ್ನು ಪಾಲಿಸುತ್ತವೆ. ಶಾಸನಬದ್ಧ ನಿರ್ಧಾರ ಅವಧಿಗಳು ಇದನ್ನು ಸ್ಪಷ್ಟಪಡಿಸುತ್ತವೆ: ಟೌನ್ ಅಂಡ್ ಕಂಟ್ರಿ ಪ್ಲಾನಿಂಗ್ ಆಡಳಿತದಲ್ಲಿ ಹೆಚ್ಚಿನ ಸಣ್ಣ ಯೋಜನಾ ಅರ್ಜಿಗಳಿಗೆ 8 ವಾರಗಳ ಶಾಸನಬದ್ಧ ನಿರ್ಧಾರ ಗುರಿ ಮತ್ತು ಪ್ರಮುಖ ಅರ್ಜಿಗಳಿಗೆ 13 ವಾರಗಳು ಇವೆ; ಇದು ಕಾನೂನಿನಲ್ಲೇ ಅಡಕವಾದ ಸೈಕಲ್-ಸಮಯದ ಬದ್ಧತೆ. ರಾಷ್ಟ್ರೀಯ ಲೆಕ್ಕಪರಿಶೋಧನಾ ಕಚೇರಿ ಮತ್ತು ಗೃಹ ವ್ಯವಹಾರಗಳ ಆಯ್ದ ಸಮಿತಿಯಿಂದ ಪದೇ ಪದೇ ಪರಿಶೀಲಿಸಲ್ಪಟ್ಟ ಗೃಹ ಕಚೇರಿಯ ಆಶ್ರಯ ಪ್ರಕರಣ ಬಾಕಿ ಕೆಲಸ, ದೀರ್ಘಕಾಲ ಪ್ರಗತಿಯಲ್ಲಿರುವ ಕೆಲಸ ಥ್ರೂಪುಟ್‌ಗಿಂತ ವೇಗವಾಗಿ ಬೆಳೆದು ಸೈಕಲ್ ಸಮಯಗಳನ್ನು ಯಾವುದೇ ಶಾಸನಬದ್ಧ ಅಥವಾ ಸೇವಾ ನಿರೀಕ್ಷೆಯನ್ನು ಮೀರಿ ತಳ್ಳಿದ ಸಾರ್ವಜನಿಕ ವ್ಯವಸ್ಥೆಯ ಚೆನ್ನಾಗಿ ದಾಖಲಾದ ಉದಾಹರಣೆ. ಹರಿವಿನ ಮಾಪನಗಳು ಎಂಜಿನಿಯರ್‌ಗಳಿಗೂ ಪ್ರಕರಣ ನಿರ್ವಹಣಾ ವ್ಯವಸ್ಥಾಪಕರಿಗೂ ಇದೇ ವೈಫಲ್ಯ ಸ್ವರೂಪಕ್ಕೆ ಹಂಚಿಕೆಯ ಪರಿಮಾಣಾತ್ಮಕ ಶಬ್ದಕೋಶವನ್ನು ನೀಡುತ್ತವೆ; ಅದನ್ನು ಗುಣಾತ್ಮಕ "ಬಾಕಿ ಕೆಲಸದ ಸಮಸ್ಯೆ"ಯಾಗಿ ಬಿಡುವುದಿಲ್ಲ.

## ಗಣಿತ

```
Little's Law:  WIP = Throughput × Cycle Time
           →   Cycle Time = WIP / Throughput

Flow efficiency = active (touch) time / total cycle time   (Vacanti)

WIP limit effect: for fixed throughput, halving WIP roughly halves
average cycle time (Little's Law rearranged) — the lever available
without adding headcount.
```

ಪ್ರಕರಣ ನಿರ್ವಹಣೆಗೆ ಬದಲಾಗಿ ತಂತ್ರಾಂಶ ನಿಯೋಜನಾ ಪೈಪ್‌ಲೈನ್‌ಗಳಿಗೆ ಅನ್ವಯಿಸಿದ ಅದೇ ಗಣಿತಕ್ಕೆ [ಸಾರ್ವಜನಿಕ ಮೌಲ್ಯಕ್ಕಾಗಿ DORA ಮಾಪನಗಳು](../ಸಾರ್ವಜನಿಕ-ಮೌಲ್ಯಕ್ಕಾಗಿ-dora-ಮಾಪನಗಳು/) ನೋಡಿ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

**ಸ್ಥಳೀಯ ಪ್ರಾಧಿಕಾರದ ಯೋಜನಾ ಇಲಾಖೆ**: ಯಾವುದೇ ಸಮಯದಲ್ಲಿ 400 ಅರ್ಜಿಗಳು ತೆರೆದಿರುತ್ತವೆ (WIP), ತಂಡವು ವಾರಕ್ಕೆ 50 ಅರ್ಜಿಗಳನ್ನು ಇತ್ಯರ್ಥಗೊಳಿಸುತ್ತದೆ (ಥ್ರೂಪುಟ್).

```
Cycle time = WIP / Throughput = 400 / 50 = 8 weeks
```

ಇದು ಸಣ್ಣ ಅರ್ಜಿಗಳ ಶಾಸನಬದ್ಧ 8 ವಾರಗಳ ಗುರಿಗೆ ನಿಖರವಾಗಿ ಬಂದು ನಿಲ್ಲುತ್ತದೆ, ಆದರೆ ಯಾವುದೇ ಸಡಿಲತೆ ಇಲ್ಲದೆ; ಅಂದರೆ ಒಳಬರುವ ಬೇಡಿಕೆ ಅಥವಾ ಸಲಹೆಗಾರರ ಪ್ರತಿಕ್ರಿಯೆ ಸಮಯದಲ್ಲಿನ ಯಾವುದೇ ಏರಿಳಿತವು ನಿರ್ಧಾರಗಳನ್ನು ಕಾನೂನು ಗಡುವಿನ ಆಚೆಗೆ ತಳ್ಳುತ್ತದೆ.

**ಹರಿವಿನ ದಕ್ಷತೆ**: ಆ 8 ವಾರಗಳಲ್ಲಿ (56 ಕ್ಯಾಲೆಂಡರ್ ದಿನಗಳು) ಒಂದು ಅರ್ಜಿಗೆ ಸಾಮಾನ್ಯವಾಗಿ ಪ್ರಕರಣ ಕಾರ್ಯಕರ್ತರ ನೈಜ ಸಂಸ್ಕರಣಾ ಸಮಯ ಸುಮಾರು 6 ಗಂಟೆ.

```
Flow efficiency = 6 hours / (56 days × 8 working hours/day)
                = 6 / 448 ≈ 1.3%
```

ತಂತ್ರಾಂಶ ತಂಡಗಳಿಗೆ Vacantiಯ ಮಾನದಂಡವು ಸಾಮಾನ್ಯ ಹರಿವಿನ ದಕ್ಷತೆಯನ್ನು 15–20% ಎಂದು ಇಡುತ್ತದೆ; ಹಲವು ಶಾಸನಬದ್ಧ ಸಲಹೆಗಾರರ ಹಸ್ತಾಂತರಗಳು ಮತ್ತು ಸಾರ್ವಜನಿಕ ಸಮಾಲೋಚನಾ ಅವಧಿಗಳಿರುವ ಸರ್ಕಾರಿ ಪ್ರಕರಣ ನಿರ್ವಹಣೆ ಹೆಚ್ಚಾಗಿ ಒಂದು ಮಟ್ಟದಷ್ಟು ಕಡಿಮೆ. ಎಂಟು ವಾರಗಳು ವಾಸ್ತವವಾಗಿ ಹೋಗುವುದು 98.7% "ಕಾಯುವ" ಸಮಯದಲ್ಲಿ, ಪ್ರಕರಣ ಕಾರ್ಯಕರ್ತರ ಸಾಮರ್ಥ್ಯದಲ್ಲಿ ಅಲ್ಲ.

**WIP-ಮಿತಿ ಮಧ್ಯಸ್ಥಿಕೆ**: ಪ್ರತಿ ಪ್ರಕರಣ ಕಾರ್ಯಕರ್ತರ ತೆರೆದ ಅರ್ಜಿಗಳನ್ನು ಮಿತಿಯಿಲ್ಲದ 25ರ ಬದಲು 15ಕ್ಕೆ ಸೀಮಿತಗೊಳಿಸುವುದು (ಥ್ರೂಪುಟ್ ಸ್ಥಿರ ಇಟ್ಟುಕೊಂಡು) 16 ಜನರ ತಂಡದಾದ್ಯಂತ WIP ಅನ್ನು 400ರಿಂದ ಸುಮಾರು 240ಕ್ಕೆ ಬದಲಿಸುತ್ತದೆ:

```
New cycle time = 240 / 50 = 4.8 weeks
```

ಸಿಬ್ಬಂದಿ ಹೆಚ್ಚಳದಿಂದಲ್ಲ, ನೀತಿ ಬದಲಾವಣೆಯಿಂದ ಸೈಕಲ್ ಸಮಯ ಬಹುತೇಕ ಅರ್ಧವಾಗುತ್ತದೆ; DORA-ಶೈಲಿಯ ವಿತರಣಾ ತಂಡಗಳು ಸ್ಪ್ರಿಂಟ್ WIP ಅನ್ನು ಮಿತಿಗೊಳಿಸುವಾಗ ಎಳೆಯುವ ಅದೇ ಲಿವರ್.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್ ಸಂಪರ್ಕ

ವಿತರಣಾ ತಂಡದ ಕಾನ್‌ಬಾನ್ ಬೋರ್ಡ್ ಮತ್ತು ಅದು ತಂತ್ರಾಂಶ ನಿರ್ಮಿಸುತ್ತಿರುವ ಪ್ರಕರಣ ನಿರ್ವಹಣಾ ವಿಭಾಗದ ನಡುವಿನ ಹಂಚಿಕೆಯ ಭಾಷೆಯೇ ಹರಿವಿನ ಮಾಪನಗಳು: ಪ್ರಕರಣ ಕಾರ್ಯಕರ್ತರ ಸರದಿ ಮತ್ತು ಪುಲ್-ರಿಕ್ವೆಸ್ಟ್ ಸರದಿ ಎರಡೂ ಲಿಟಲ್ಸ್ ನಿಯಮಕ್ಕೆ ಒಳಪಡುತ್ತವೆ, ಮತ್ತು ಎರಡೂ ಸೈಕಲ್-ಸಮಯದ ಗುರಿಗಳನ್ನು ಒಂದೇ ರೀತಿ ತಪ್ಪಿಸುತ್ತವೆ: ಥ್ರೂಪುಟ್‌ಗೆ ಹೋಲಿಸಿದರೆ ಹೆಚ್ಚು WIP. ಇದು [ಸಾರ್ವಜನಿಕ ಕಾರ್ಯಕ್ರಮಗಳಲ್ಲಿ ವಿಳಂಬದ ವೆಚ್ಚ](../ಸಾರ್ವಜನಿಕ-ಕಾರ್ಯಕ್ರಮಗಳಲ್ಲಿ-ವಿಳಂಬದ-ವೆಚ್ಚ/) ಗೆ ನೇರವಾಗಿ ಮುಖ್ಯ: ಸೈಕಲ್ ಸಮಯ × CoD ಎಂದರೆ ಯಾವುದೇ ಕ್ಷಣದಲ್ಲಿ ಸರದಿಯಲ್ಲಿ ಕುಳಿತಿರುವ ಪೌಂಡ್‌ಗಳು; ಮತ್ತು [ಸೇವಾ ಮಾನದಂಡಗಳು ಮತ್ತು ವಹಿವಾಟು ಮಾಪನಗಳು](../ಸೇವಾ-ಮಾನದಂಡಗಳು-ಮತ್ತು-ವಹಿವಾಟು-ಅಳತೆಗಳು/) ಗೂ ಮುಖ್ಯ, ಅಲ್ಲಿ ಪ್ರಕಟಿತ ಸಂಸ್ಕರಣಾ-ಸಮಯದ ಗುರಿ ಒಂದು ಸೈಕಲ್-ಸಮಯದ ಬದ್ಧತೆ, ಅದನ್ನು ತಪ್ಪಿಸಿದಾಗ ಹರಿವಿನ ಮಾಪನಗಳು ಮಾತ್ರ ರೋಗನಿರ್ಣಯ ಮಾಡಬಲ್ಲವು. ಪ್ರಕರಣ ನಿರ್ವಹಣಾ ವ್ಯವಸ್ಥೆಯ ತಂತ್ರಾಂಶವು WIP ಮತ್ತು ಸೈಕಲ್ ಸಮಯವನ್ನು ಯಾರೂ ಪ್ರಶ್ನಿಸದ ಪ್ರಕರಣ-ನಿರ್ವಹಣಾ ವ್ಯವಸ್ಥೆಯೊಳಗೆ ಹೂಳುವ ಬದಲು ಪ್ರಥಮ ದರ್ಜೆಯ ಕಾರ್ಯಾಚರಣೆ ಮಾಪನಗಳಾಗಿ ತೆರೆದಿಡಬೇಕು.

## ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳು

- **ನಿಜವಾದ ಅಡಚಣೆಯನ್ನು ಸರಿಪಡಿಸದೆ WIP ಮಿತಿಗಳನ್ನು ಸೇರಿಸುವುದು**: ನಿರ್ಬಂಧ ಹೊರಗಿನ ಶಾಸನಬದ್ಧ ಸಲಹೆಗಾರರ ಪ್ರತಿಕ್ರಿಯೆ ಸಮಯವಾಗಿದ್ದರೆ, ಪ್ರಕರಣ ಕಾರ್ಯಕರ್ತರ WIP ಮಿತಿಗೊಳಿಸುವುದು ಸರದಿಯನ್ನು ಕಡಿಮೆ ಮಾಡದೆ ಮೇಲ್ಭಾಗಕ್ಕೆ ಸರಿಸುತ್ತದೆ.
- **ಹರಿವಿನ ದಕ್ಷತೆಯನ್ನು ದುರುಪಯೋಗಪಡಿಸಬಹುದಾದ ಗುರಿಯಾಗಿ ಪರಿಗಣಿಸುವುದು**: 1.3% ಸಕ್ರಿಯ ಸಮಯವನ್ನು ಆತುರಪಡಿಸುವುದು ಸೈಕಲ್ ಸಮಯವನ್ನು ಅಷ್ಟೇನೂ ಬದಲಿಸುವುದಿಲ್ಲ; ಲಿವರೇಜ್ ಬಹುತೇಕ ಯಾವಾಗಲೂ ಕಾಯುವ ಸ್ಥಿತಿಗಳಲ್ಲಿದೆ, ಅಂದರೆ ಪ್ರಕ್ರಿಯೆ ಮರುವಿನ್ಯಾಸ, ಪ್ರಕರಣ ಕಾರ್ಯಕರ್ತರ ವೇಗವಲ್ಲ.
- **ಏರಿಳಿತವನ್ನು ನಿರ್ಲಕ್ಷಿಸುವುದು**: ಲಿಟಲ್ಸ್ ನಿಯಮವು ಸರಾಸರಿಗಳನ್ನು ವಿವರಿಸುತ್ತದೆ; ಹೆಚ್ಚಿನ ಬೇಡಿಕೆ ವ್ಯತ್ಯಾಸವಿರುವ ಪ್ರಕರಣ-ಭಾರಕ್ಕೆ ಕೇವಲ ಬಿಗಿಯಾದ WIP ಮಿತಿಯಲ್ಲ, ಬಫರ್ ಸಾಮರ್ಥ್ಯವೂ ಬೇಕು; ಇಲ್ಲದಿದ್ದರೆ ಸರಾಸರಿ ಸುಧಾರಿಸಿದರೂ ಅಸ್ಥಿರ ಬಾಲದಲ್ಲಿ ಶಾಸನಬದ್ಧ ಗಡುವುಗಳು ತಪ್ಪುತ್ತವೆ.
- **WIP ಅನ್ನು ಅಸಮಂಜಸವಾಗಿ ಅಳೆಯುವುದು**: ದಾಖಲೆ ವ್ಯವಸ್ಥೆಯಲ್ಲಿ "ತೆರೆದಿರುವ" ಆದರೆ ವಾಸ್ತವವಾಗಿ ಮೂರನೇ ವ್ಯಕ್ತಿಗಾಗಿ ಕಾಯುತ್ತಾ ಸ್ಥಗಿತಗೊಂಡ ಪ್ರಕರಣವೂ WIP; ಅದನ್ನು ಹೊರಗಿಡುವುದು ನಾಗರಿಕರ ವಾಸ್ತವವನ್ನು ಬದಲಿಸದೆ ಸಂಖ್ಯೆಗಳನ್ನು ಹೊಗಳುತ್ತದೆ.
