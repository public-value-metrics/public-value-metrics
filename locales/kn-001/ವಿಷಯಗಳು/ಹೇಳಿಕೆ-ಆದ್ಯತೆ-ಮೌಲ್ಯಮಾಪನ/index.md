# ಹೇಳಿಕೆ ಆದ್ಯತೆ ಮೌಲ್ಯಮಾಪನ

ಹೇಳಿಕೆ ಆದ್ಯತೆ (stated preference) ವಿಧಾನಗಳು ಮಾರುಕಟ್ಟೆಯೇತರ ಸರಕಿನ ಮೌಲ್ಯವನ್ನು, ಅದಕ್ಕಾಗಿ ಜನರು ಎಷ್ಟು ಪಾವತಿಸಲು ಸಿದ್ಧರಿದ್ದಾರೆ, ಅಥವಾ ಅದನ್ನು ಬಿಟ್ಟುಕೊಡಲು ಪರಿಹಾರವಾಗಿ ಎಷ್ಟು ಸ್ವೀಕರಿಸಲು ಸಿದ್ಧರಿದ್ದಾರೆ ಎಂದು ನೇರವಾಗಿ ಕೇಳುವ ಮೂಲಕ ಅಂದಾಜಿಸುತ್ತವೆ; ಸಾಮಾನ್ಯವಾಗಿ ಕಲ್ಪಿತ ಸನ್ನಿವೇಶವನ್ನು ವಿವರಿಸುವ ರಚನಾತ್ಮಕ ಸಮೀಕ್ಷೆಯ ಮೂಲಕ. ಷರತ್ತುಬದ್ಧ ಮೌಲ್ಯಮಾಪನ (contingent valuation) ಈ ಕುಟುಂಬದ ಅತ್ಯಂತ ಪ್ರಸಿದ್ಧ ತಂತ್ರ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

Green Book Annex 2 (ಮಾರುಕಟ್ಟೆಯೇತರ ಪರಿಣಾಮಗಳ ಮೌಲ್ಯಮಾಪನದ ಪೂರಕ ಮಾರ್ಗದರ್ಶನ) ಮೌಲ್ಯವನ್ನು ಊಹಿಸಲು ಯಾವುದೇ ಗಮನಿಸಬಹುದಾದ ಮಾರುಕಟ್ಟೆ ವಹಿವಾಟೇ ಇಲ್ಲದ ಸರಕುಗಳಿಗೆ ಹೇಳಿಕೆ ಆದ್ಯತೆ ವಿಧಾನಗಳನ್ನು ಅನುಮೋದಿಸುತ್ತದೆ — ಗಾಳಿಯ ಗುಣಮಟ್ಟ, ಜೀವವೈವಿಧ್ಯ, ಪ್ರವಾಹ ರಕ್ಷಣೆ, ಯಾರಾದರೂ ಎಂದಿಗೂ ಭೇಟಿ ನೀಡದ ಭೂದೃಶ್ಯದ ಅಸ್ತಿತ್ವ ಮೌಲ್ಯ
(<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>).
ಪರಿಸರ ಮೌಲ್ಯಮಾಪನಕ್ಕಾಗಿ Defra ತನ್ನದೇ ಹೇಳಿಕೆ-ಆದ್ಯತೆ ಮಾರ್ಗದರ್ಶನವನ್ನು ಪ್ರಕಟಿಸಿದೆ; ಕಾರಣ ಪರಿಸರ ಮೌಲ್ಯದ ಬಹುಪಾಲಿಗೆ (ಆವಾಸ ಸಂರಕ್ಷಣೆ, ನೀರಿನ ಗುಣಮಟ್ಟ) ಯಾವುದೇ ಪ್ರಾಕ್ಸಿ ಮಾರುಕಟ್ಟೆಯೇ ಇಲ್ಲ; ಉದಾಹರಣೆಗೆ ಶಬ್ದಕ್ಕೆ ಕನಿಷ್ಠ ಗಮನಿಸಬಹುದಾದ ಮನೆ ಬೆಲೆಗಳೊಂದಿಗೆ ಸಂಬಂಧವಿದೆ (ನೋಡಿ [ಬಹಿರಂಗಪಡಿಸಿದ ಆದ್ಯತೆ ಮೌಲ್ಯಮಾಪನ](../ಬಹಿರಂಗಪಡಿಸಿದ-ಆದ್ಯತೆ-ಮೌಲ್ಯಮಾಪನ/)).

ಹೇಳಿಕೆ ಆದ್ಯತೆಯ ಮುಖ್ಯ ಆಕರ್ಷಣೆ — ಯಾರೂ ಎಂದಿಗೂ ವಹಿವಾಟು ನಡೆಸದ ಸರಕುಗಳೂ ಸೇರಿ ಅಕ್ಷರಶಃ ಯಾವುದಕ್ಕೂ ಮೌಲ್ಯ ಕಟ್ಟಬಲ್ಲದು — ಅದರ ವಿಶ್ವಾಸಾರ್ಹತೆ ಸಮಸ್ಯೆಯ ಮೂಲವೂ ಹೌದು. ಪ್ರತಿಕ್ರಿಯಿಸುವವರು ನಿಜವಾಗಿ ಹಣ ಖರ್ಚು ಮಾಡುತ್ತಿಲ್ಲವಾದ್ದರಿಂದ, ಷರತ್ತುಬದ್ಧ ಮೌಲ್ಯಮಾಪನ ಸಮೀಕ್ಷೆಗಳು ಕಲ್ಪಿತ ಪಕ್ಷಪಾತಕ್ಕೆ (ನಿಜವಾದ ಬಜೆಟ್ ಮಿತಿ ಇಲ್ಲದಿದ್ದಾಗ ಜನರು ಪಾವತಿಸುವ ಇಚ್ಛೆಯನ್ನು ಉತ್ಪ್ರೇಕ್ಷಿಸುತ್ತಾರೆ), ಅಂತರ್ಗತ ಪರಿಣಾಮಗಳಿಗೆ (ಸಮೀಕ್ಷೆಯಲ್ಲಿ ಇನ್ನೇನು ಇದೆ ಎನ್ನುವುದರ ಮೇಲೆ ಅದೇ ಸರಕಿಗೆ ಬೇರೆ ಮೌಲ್ಯ ಸಿಗುವುದು), ಮತ್ತು ಬಿಡ್ಡಿಂಗ್-ಆಟ ವಿನ್ಯಾಸಗಳಲ್ಲಿ ಆರಂಭ ಬಿಂದು ಪಕ್ಷಪಾತಕ್ಕೆ ಒಳಗಾಗುತ್ತವೆ. Exxon Valdez ತೈಲ ಸೋರಿಕೆ ಮೊಕದ್ದಮೆಯ ನಂತರ ಸೇರಿದ ಷರತ್ತುಬದ್ಧ ಮೌಲ್ಯಮಾಪನದ 1993ರ NOAA ಸಮಿತಿ ವಿನ್ಯಾಸ ಮಾನದಂಡಗಳನ್ನು ನಿಗದಿಪಡಿಸಿತು — ಮುಕ್ತ-ಮುಕ್ತಾಯದ ಬಿಡ್ಡಿಂಗ್ ಬದಲು ದ್ವಿಮಾನ "ನೀವು £X ಪಾವತಿಸುವಿರಾ, ಹೌದು/ಇಲ್ಲ" ಜನಮತ ಸ್ವರೂಪ, ಮತ್ತು ಪ್ರತಿಕ್ರಿಯಿಸುವವರ ನಿಜವಾದ ಬಜೆಟ್ ಮಿತಿಯ ಕಡ್ಡಾಯ ನೆನಪೋಲೆಗಳು — ಇವು ಸಮರ್ಥನೀಯ ಸಮೀಕ್ಷೆಗಳಿಗೆ ಈಗಲೂ ಉಲ್ಲೇಖ ಮಾನದಂಡ.

## ಗಣಿತ

```
ಷರತ್ತುಬದ್ಧ ಮೌಲ್ಯಮಾಪನ (ಜನಮತ ಸ್ವರೂಪ):
  ದ್ವಿಮಾನ ಆಯ್ಕೆ ಮುಂದಿಡಿ: "ಫಲಿತಾಂಶ Y ಗಾಗಿ ನೀವು ವರ್ಷಕ್ಕೆ £X ಪಾವತಿಸುವಿರಾ? ಹೌದು/ಇಲ್ಲ"
  ಪ್ರತಿಕ್ರಿಯಿಸುವವರ ನಡುವೆ X ಅನ್ನು ಯಾದೃಚ್ಛಿಕವಾಗಿ ಬದಲಿಸಿ.
  ಪ್ರತಿ X ನಲ್ಲಿ ಹೌದು/ಇಲ್ಲ ಪ್ರತಿಕ್ರಿಯೆ ದರದ ಏರಿಕೆಯಾಗಿ ಪಾವತಿ ಇಚ್ಛೆಯನ್ನು ಹೊಂದಿಸಿ.

ಸರಾಸರಿ WTP = ಅಂದಾಜಿತ ಬೇಡಿಕೆ ವಕ್ರರೇಖೆಯ ಕೆಳಗಿನ ವಿಸ್ತೀರ್ಣ
ಒಟ್ಟು ಮೌಲ್ಯ = ಸರಾಸರಿ WTP × ಬಾಧಿತ ಜನಸಂಖ್ಯೆ

ಆಯ್ಕೆ ಪ್ರಯೋಗ (ವಿಂಗಡಿತ ಆಯ್ಕೆ ಮಾದರಿ) ಪರ್ಯಾಯ:
  ಪ್ರತಿಕ್ರಿಯಿಸುವವರಿಗೆ ಗುಣಲಕ್ಷಣಗಳ ಗುಂಪುಗಳ (ವೆಚ್ಚ ಗುಣಲಕ್ಷಣ ಸೇರಿ) ನಡುವೆ
  ಪುನರಾವರ್ತಿತ ಆಯ್ಕೆಗಳನ್ನು ನೀಡಿ; ಅವರು ತೋರಿಸುವ ಹೊಂದಾಣಿಕೆಗಳಿಂದ ಪ್ರತಿ
  ವೆಚ್ಚೇತರ ಗುಣಲಕ್ಷಣಕ್ಕೆ ಅಂತರ್ಗತ ಬೆಲೆಗಳನ್ನು ಅಂದಾಜಿಸಿ.
```

ಪ್ರಸ್ತುತ ಬ್ರಿಟನ್ ಅಭ್ಯಾಸದಲ್ಲಿ ಏಕ-ಪ್ರಶ್ನೆ ಷರತ್ತುಬದ್ಧ ಮೌಲ್ಯಮಾಪನಕ್ಕಿಂತ ಆಯ್ಕೆ ಪ್ರಯೋಗ ಪರ್ಯಾಯಕ್ಕೆ ಸಾಮಾನ್ಯವಾಗಿ ಆದ್ಯತೆ; ಏಕೆಂದರೆ ಪ್ರತಿಕ್ರಿಯಿಸುವವರನ್ನು ವೆಚ್ಚದ ವಿರುದ್ಧ ಹಲವು ಗುಣಲಕ್ಷಣಗಳನ್ನು ಪದೇಪದೇ ತೂಗುವಂತೆ ಮಾಡುವುದು ಒಂದೇ ಹೌದು/ಇಲ್ಲ ಪ್ರಶ್ನೆಗಿಂತ ಆಂತರಿಕವಾಗಿ ಹೆಚ್ಚು ಸಂಗತ, ಆಟವಾಡಲು ಕಷ್ಟವಾದ ಅಂದಾಜುಗಳನ್ನು ನೀಡುತ್ತದೆ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

**ರಾಷ್ಟ್ರೀಯ ಸರ್ಕಾರ**: ನದಿ ನೀರಿನ ಗುಣಮಟ್ಟ ಸುಧಾರಣಾ ಕಾರ್ಯಕ್ರಮಕ್ಕೆ ಮೌಲ್ಯ ಕಟ್ಟಲು Defra ಷರತ್ತುಬದ್ಧ ಮೌಲ್ಯಮಾಪನ ಸಮೀಕ್ಷೆಯನ್ನು ನಿಯೋಜಿಸುತ್ತದೆ. 2,000 ಕುಟುಂಬಗಳ ಜನಮತ-ಸ್ವರೂಪದ ಸಮೀಕ್ಷೆಯು, 62% ಜನರು ಕಲ್ಪಿತ ನೀರಿನ ಬಿಲ್ ಹೆಚ್ಚುವರಿಯ ಮೂಲಕ ವರ್ಷಕ್ಕೆ £40 ಪಾವತಿಸುತ್ತಾರೆ ಎಂದು ಕಂಡುಕೊಳ್ಳುತ್ತದೆ, ಮತ್ತು ಅಂದಾಜಿತ ಬೇಡಿಕೆ ವಕ್ರರೇಖೆ ಪ್ರತಿ ಕುಟುಂಬಕ್ಕೆ ವರ್ಷಕ್ಕೆ £28 ಸರಾಸರಿ ಪಾವತಿ ಇಚ್ಛೆಯನ್ನು ನೀಡುತ್ತದೆ.

```
ಸರಾಸರಿ WTP = £28/ಕುಟುಂಬ/ವರ್ಷ
ಜಲಾನಯನದ ಕುಟುಂಬಗಳು = 340,000
ವಾರ್ಷಿಕ ಒಟ್ಟು ಮೌಲ್ಯ = £28 × 340,000 = £9.52m/ವರ್ಷ

3.5% ರಿಯಾಯಿತಿ ದರದಲ್ಲಿ 20 ವರ್ಷಗಳ ಮೌಲ್ಯಮಾಪನ ಅವಧಿಗೆ (ವಾರ್ಷಿಕ ಗುಣಕ ≈ 14.2):
PV(ಲಾಭ) ≈ £9.52m × 14.2 ≈ £135m
```

ಈ ಒಟ್ಟು ಅಂಕಿಯನ್ನು ನಂತರ ಕಾರ್ಯಕ್ರಮದ [ಸಾಮಾಜಿಕ ವೆಚ್ಚ-ಲಾಭ ವಿಶ್ಲೇಷಣೆ](../ಸಾಮಾಜಿಕ-ವೆಚ್ಚ-ಲಾಭ-ವಿಶ್ಲೇಷಣೆ/)ಯ ವೆಚ್ಚದ ಭಾಗದೊಂದಿಗೆ ಹೋಲಿಸಲಾಗುತ್ತದೆ. ಇಂತಹ ಹೇಳಿಕೆ-ಆದ್ಯತೆ ಸಾಕ್ಷ್ಯವನ್ನು ಬರೀ ಬಿಂದು ಅಂದಾಜಾಗಿ ಅಲ್ಲ, ಅದರ ವಿಶ್ವಾಸ ಅಂತರ ಮತ್ತು ಸಮೀಕ್ಷೆ ವಿಧಾನದ ಜೊತೆಗೆ ವರದಿ ಮಾಡಬೇಕೆಂದು Green Book ಕೋರುತ್ತದೆ; ಏಕೆಂದರೆ ಆಧಾರ ಸಂಖ್ಯೆ ಮಾರುಕಟ್ಟೆ ಬೆಲೆಗಿಂತ ಹೆಚ್ಚು ದುರ್ಬಲ.

**ದತ್ತಿ ಸಂಸ್ಥೆ**: ಪಾರಂಪರಿಕ ಟ್ರಸ್ಟ್ ಒಂದು ಐತಿಹಾಸಿಕ ಕಟ್ಟಡದ ಮುಚ್ಚುವಿಕೆಯನ್ನು ತಡೆಯಲು ಪಾವತಿ ಇಚ್ಛೆಯ ಬಗ್ಗೆ ಭೇಟಿ ನೀಡುವವರು ಮತ್ತು ನೀಡದವರನ್ನು ಸಮೀಕ್ಷೆ ಮಾಡುತ್ತದೆ (ಅದರ ಅಸ್ತಿತ್ವ ಮೌಲ್ಯ); ಇಬ್ಬರೂ ಗುಂಪುಗಳು ಅದಕ್ಕೆ ಭೇಟಿ ನೀಡಬೇಕೆಂದಿಲ್ಲ. ಕಟ್ಟಡವನ್ನು ಎಂದಿಗೂ ನೋಡದ ಭೇಟಿ ನೀಡದವರೂ ಧನಾತ್ಮಕ WTP ವರದಿ ಮಾಡುವುದರಿಂದ, ಸಮೀಕ್ಷೆಯು ಸರಳ ಸಂದರ್ಶಕ-ಶುಲ್ಕ ಆದಾಯ ಎಣಿಕೆ (ಬಹಿರಂಗ-ಆದ್ಯತೆ ಪ್ರಾಕ್ಸಿ) ಸಂಪೂರ್ಣವಾಗಿ ತಪ್ಪಿಸುವ ಅಸ್ತಿತ್ವ ಮತ್ತು ಪರಂಪರೆ ಮೌಲ್ಯವನ್ನು ಸೆರೆಹಿಡಿಯುತ್ತದೆ — ಮೌಲ್ಯವನ್ನು ಬಹಿರಂಗಪಡಿಸಲು ಯಾವುದೇ ರೀತಿಯ ಮಾರುಕಟ್ಟೆ ವಹಿವಾಟೇ ಇಲ್ಲದಲ್ಲಿ ಹೇಳಿಕೆ ಆದ್ಯತೆಯ ನಿಜವಾದ ಅನುಕೂಲ ಇದು.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್ ಸಂಪರ್ಕ

ಹೇಳಿಕೆ ಆದ್ಯತೆ ವಿಧಾನಗಳು ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್ ಕೆಲಸಕ್ಕೆ ನೇರವಾಗಿ ಅನ್ವಯಿಸುವುದು ಅಪರೂಪ; ಆದರೆ ನಾಗರಿಕ ಸಮಾಲೋಚನೆ ವೇದಿಕೆಗಳು, ಬಜೆಟ್-ಭಾಗವಹಿಸುವಿಕೆ ಸಾಧನಗಳು ಅಥವಾ ಸಾರ್ವಜನಿಕ ಸಮೀಕ್ಷೆ ಮೂಲಸೌಕರ್ಯ ನಿರ್ಮಿಸುವ ಎಂಜಿನಿಯರ್‌ಗಳು ಅರ್ಥಶಾಸ್ತ್ರ ಅವಲಂಬಿಸುವ ಉಪಕರಣವನ್ನೇ ನಿರ್ಮಿಸುತ್ತಿರುತ್ತಾರೆ. ಸಮೀಕ್ಷೆ ವಿನ್ಯಾಸದ ವಿವರಗಳನ್ನು ಸರಿಯಾಗಿ ಮಾಡುವುದು — ಯಾದೃಚ್ಛಿಕ ಬಿಡ್ ಮೊತ್ತಗಳು, ಮುಕ್ತ-ಮುಕ್ತಾಯ ಪ್ರಶ್ನೆಗಳ ಬದಲು ದ್ವಿಮಾನ ಜನಮತ ಚೌಕಟ್ಟು, ಸ್ಪಷ್ಟ ಬಜೆಟ್-ಮಿತಿ ನೆನಪೋಲೆಗಳು — UX ಸೌಜನ್ಯವಲ್ಲ; ಅದೇ ಫಲಿತಾಂಶದ ಮೌಲ್ಯಮಾಪನವನ್ನು ಪರಿಶೀಲನೆಯಲ್ಲಿ ಸಮರ್ಥನೀಯವಾಗಿಸುತ್ತದೆ; ಕಳಪೆಯಾಗಿ ವಿನ್ಯಾಸಗೊಳಿಸಿದ ಅಪ್ಲಿಕೇಶನ್-ಒಳಗಿನ ಸಮೀಕ್ಷೆ ನಂತರದ ತಿಂಗಳುಗಳ ಆರ್ಥಿಕ ವಿಶ್ಲೇಷಣೆಯನ್ನೇ ಅಸಿಂಧುಗೊಳಿಸಬಲ್ಲದು. ವಿಶ್ಲೇಷಣಾತ್ಮಕ ತೂಕ ಹೊರುವ ಸಾರ್ವಜನಿಕ ಅಭಿಪ್ರಾಯ ದತ್ತಾಂಶವನ್ನು ಸಂಗ್ರಹಿಸುವ ಸಾಮಾನ್ಯ ಶಿಸ್ತಿಗಾಗಿ [ನಾಗರಿಕ ತೃಪ್ತಿ ಮಾಪನಗಳು](../ನಾಗರಿಕ-ತೃಪ್ತಿ-ಮಾಪನಗಳು/) ನೋಡಿ.

## ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳು

- **ಮುಕ್ತ-ಮುಕ್ತಾಯದ "ನೀವು ಎಷ್ಟು ಪಾವತಿಸುವಿರಿ?" ಪ್ರಶ್ನೆಗಳು.** ಇವು ದ್ವಿಮಾನ ಜನಮತ ಚೌಕಟ್ಟಿಗಿಂತ ಕಾರ್ಯತಂತ್ರೀಯ ಮತ್ತು ಲಂಗರು ಪಕ್ಷಪಾತಕ್ಕೆ ಹೆಚ್ಚು ಒಳಗಾಗುತ್ತವೆ; ಮುಕ್ತ-ಮುಕ್ತಾಯದ ಹೊರತರುವಿಕೆ ಕಳಪೆಯಾಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸುವ ಕಾರಣಕ್ಕೇ ಜನಮತ ಸ್ವರೂಪ ಬಳಸಬೇಕೆಂಬ NOAA ಸಮಿತಿಯ ಶಿಫಾರಸು ಇದೆ.
- **ಪ್ರತಿಕ್ರಿಯಿಸುವವರ ನಿಜವಾದ ಬಜೆಟ್ ಮಿತಿಯ ನೆನಪೋಲೆ ಇಲ್ಲದಿರುವುದು.** ಅದಿಲ್ಲದೆ, ಹೇಳಿದ WTP ನಿಜವಾದ ಬಜೆಟ್ ಹೊಂದಾಣಿಕೆ ಇದ್ದಾಗ ಅದೇ ಜನರು ಪಾವತಿಸುವುದಕ್ಕಿಂತ ನಿಯತವಾಗಿ ಹೆಚ್ಚಿರುತ್ತದೆ — ಕಲ್ಪಿತ ಪಕ್ಷಪಾತ.
- **ಅಂತರ್ಗತ ಪರಿಣಾಮಗಳನ್ನು ಕಡೆಗಣಿಸುವುದು.** ಅದೇ ಸರಕನ್ನು ಒಂಟಿಯಾಗಿ ಮೌಲ್ಯಮಾಪನ ಮಾಡುವುದು ಮತ್ತು ದೊಡ್ಡ ಗುಂಪಿನ ಭಾಗವಾಗಿ ಮೌಲ್ಯಮಾಪನ ಮಾಡುವುದು ಬೇರೆಬೇರೆ WTP ಅಂದಾಜುಗಳನ್ನು ನೀಡುತ್ತದೆ; ಸಮೀಕ್ಷೆ ಚೌಕಟ್ಟಿನಲ್ಲಿ ಇನ್ನೇನಾದರೂ ಇದ್ದರೆ ಅದನ್ನು ವರದಿ ಮಾಡಿ.
- **ಒಂದೇ ಸಮೀಕ್ಷೆಯ ಬಿಂದು ಅಂದಾಜನ್ನು ಅಂತಿಮವೆಂದು ಪರಿಗಣಿಸುವುದು.** ಮಾರುಕಟ್ಟೆ ಬೆಲೆಯೋ ಎಂಬಂತೆ ಬರೀ ಸಂಖ್ಯೆಯನ್ನು ವೆಚ್ಚ-ಲಾಭ ಕೋಷ್ಟಕಕ್ಕೆ ಒಯ್ಯುವ ಬದಲು, ಒಂದು ವ್ಯಾಪ್ತಿ ಮತ್ತು ತಿಳಿದ ಪಕ್ಷಪಾತಗಳ ಚರ್ಚೆಯನ್ನು Green Book ಅಭ್ಯಾಸ ನಿರೀಕ್ಷಿಸುತ್ತದೆ.
