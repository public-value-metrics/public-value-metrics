# ಘಟಕ ವೆಚ್ಚ ದತ್ತಾಂಶ ಸಂಗ್ರಹಗಳು

ಘಟಕ ವೆಚ್ಚ ದತ್ತಾಂಶ ಸಂಗ್ರಹ (unit cost database) ಎಂದರೆ ಸಾಮಾಜಿಕ ಫಲಿತಾಂಶಗಳಿಗಾಗಿ ಮುಂಚಿತವಾಗಿ ಸಂಶೋಧಿಸಿದ, ಸಾಕ್ಷ್ಯಾಧಾರಿತ ಹಣಕಾಸಿನ ಪ್ರಾಕ್ಸಿಗಳ ಗ್ರಂಥಾಲಯ — ನಿರುದ್ಯೋಗದಿಂದ ಉದ್ಯೋಗಕ್ಕೆ ಸೇರುವ, ಒಂಟಿತನ ಕಡಿಮೆಯಾಗುವ, ಸ್ಥಿರ ಬಾಡಿಗೆ ಹಕ್ಕಿನ ಮೌಲ್ಯ — ಇದು ಪ್ರತಿ ಬಾರಿ ಪ್ರತ್ಯೇಕ ಮೌಲ್ಯಮಾಪನ ಸಂಶೋಧನೆ ನಿಯೋಜಿಸದೆ ವೃತ್ತಿಪರರು ಫಲಿತಾಂಶಕ್ಕೆ ಹಣಕಾಸಿನ ಮೌಲ್ಯ ಕಟ್ಟಲು ಅವಕಾಶ ನೀಡುತ್ತದೆ. ಅವು ಇರುವುದು, ಅನುದಾನ ಬಿಡ್ ಬರೆಯುವ ಸಣ್ಣ ದತ್ತಿ ಸಂಸ್ಥೆ, ಬೇರೆಯವರು ಈಗಾಗಲೇ ರೂಪಿಸಿ ಪ್ರಕಟಿಸಿದ ಪ್ರಾಕ್ಸಿಯನ್ನು ಮರುಬಳಸುವ ಮೂಲಕ, ಸಂಪನ್ಮೂಲ-ಸಮೃದ್ಧ ಸಲಹಾ ಸಂಸ್ಥೆಯಷ್ಟೇ ಕಠಿಣತೆಯನ್ನು ಅನ್ವಯಿಸಲು ಸಾಧ್ಯವಾಗಲೆಂದು.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಅರ್ಥಶಾಸ್ತ್ರಜ್ಞ Daniel Fujiwara ಅವರೊಂದಿಗೆ ಯೋಗಕ್ಷೇಮ ಮೌಲ್ಯಮಾಪನ ವಿಧಾನಗಳನ್ನು ಬಳಸಿ ಅಭಿವೃದ್ಧಿಪಡಿಸಿದ HACT ಯ UK Social Value Bank, ಮತ್ತು ಹಣಕಾಸಿನ ಪ್ರಾಕ್ಸಿಗಳ ಮುಕ್ತ, ಜನಸಮೂಹ-ಮೂಲದ ದತ್ತಾಂಶಕೋಶವಾದ Global Value Exchange — ಇವು ಬ್ರಿಟನ್ನಿನ ಮೂರನೇ ಮತ್ತು ಸಾರ್ವಜನಿಕ ವಲಯಗಳಲ್ಲಿ ಅತಿ ವ್ಯಾಪಕವಾಗಿ ಬಳಸುವ ಎರಡು. ಇವೆರಡೂ ಇರುವುದು ಆಧಾರ ಮೌಲ್ಯಮಾಪನ ಕೆಲಸ — [ಯೋಗಕ್ಷೇಮ ಮೌಲ್ಯಮಾಪನ](../ಯೋಗಕ್ಷೇಮ-ಮೌಲ್ಯಮಾಪನ/) ಮತ್ತು [ಹೇಳಿಕೆ ಆದ್ಯತೆ ಮೌಲ್ಯಮಾಪನ](../ಹೇಳಿಕೆ-ಆದ್ಯತೆ-ಮೌಲ್ಯಮಾಪನ/) — ದುಬಾರಿ, ವಿಧಾನದ ದೃಷ್ಟಿಯಿಂದ ಕಠಿಣ, ಮತ್ತು ಪ್ರತಿ ಯೋಜನೆಗೂ ಮೊದಲಿನಿಂದ ನಡೆಸಲು ನಿಧಾನವಾದ್ದರಿಂದ. ಹಂಚಿಕೆಯ, ಪ್ರಕಟಿತ ಪ್ರಾಕ್ಸಿ ಗ್ರಂಥಾಲಯ ಹಲವು ತಿಂಗಳ ಸಂಶೋಧನೆಯಾಗುತ್ತಿದ್ದುದನ್ನು ಹುಡುಕಾಟವಾಗಿಸುತ್ತದೆ; ಅದಕ್ಕಾಗಿಯೇ ಇವು [ಸಾಮಾಜಿಕ ಹೂಡಿಕೆ ಪ್ರತಿಫಲ](../ಸಾಮಾಜಿಕ-ಹೂಡಿಕೆ-ಪ್ರತಿಫಲ/) ಲೆಕ್ಕಾಚಾರಗಳು ಮತ್ತು [ಸಾಮಾಜಿಕ ಮೌಲ್ಯ ಕಾಯ್ದೆ](../ಸಾಮಾಜಿಕ-ಮೌಲ್ಯ-ಕಾಯ್ದೆ/) ಬಿಡ್ ಮೌಲ್ಯಮಾಪನಗಳೆರಡಕ್ಕೂ ಮುಖ್ಯ: ಅವುಗಳಿಲ್ಲದಿದ್ದರೆ, ಕಠಿಣ ಹಣಕಾಸಿನ ಮೌಲ್ಯ ಕಟ್ಟುವಿಕೆ ತಮ್ಮದೇ ಅಧ್ಯಯನ ನಿಯೋಜಿಸುವಷ್ಟು ದೊಡ್ಡ ಸಂಸ್ಥೆಗಳಿಗೆ ಮಾತ್ರ ಕೈಗೆಟುಕುತ್ತಿತ್ತು.

## ಗಣಿತ

ಘಟಕ ವೆಚ್ಚ ದತ್ತಾಂಶ ಸಂಗ್ರಹ ಸ್ವತಃ ಏನನ್ನೂ ಲೆಕ್ಕ ಹಾಕುವುದಿಲ್ಲ; ಬೇರೆಡೆ ಮಾಡುವ ಲೆಕ್ಕಾಚಾರಕ್ಕೆ ಒಂದು ಇನ್‌ಪುಟ್ ಒದಗಿಸುತ್ತದೆ:

```
ಹಣಕಾಸಿನ ಪ್ರಾಕ್ಸಿ ಮೌಲ್ಯ = ಮಾರುಕಟ್ಟೆ ಬೆಲೆ, ಅಥವಾ ನೆರಳು ಬೆಲೆ, ಅಥವಾ ಯೋಗಕ್ಷೇಮ ಮೌಲ್ಯಮಾಪನ,
                         ಅಥವಾ ಹೇಳಿಕೆ-ಆದ್ಯತೆ ಮೌಲ್ಯ
                         ಫಲಿತಾಂಶ ಬದಲಾವಣೆಯ ವ್ಯಾಖ್ಯಾನಿತ ಘಟಕಕ್ಕೆ
                         (ಉದಾ. "ನಿರುದ್ಯೋಗದಿಂದ ಉದ್ಯೋಗಕ್ಕೆ ಸೇರುವ ಪ್ರತಿ ವ್ಯಕ್ತಿಗೆ, ಪ್ರತಿ ವರ್ಷ")

ಅನ್ವಯಿಸಿದ ಮೌಲ್ಯ = ಸಾಧಿಸಿದ ಫಲಿತಾಂಶಗಳ ಸಂಖ್ಯೆ × ಘಟಕ ಪ್ರಾಕ್ಸಿ ಮೌಲ್ಯ
```

ಮಾರುಕಟ್ಟೆ ಬೆಲೆ ಇಲ್ಲದಿದ್ದಾಗ ಪ್ರಾಕ್ಸಿಯನ್ನು ಹೇಗೆ ರೂಪಿಸಲಾಗುತ್ತದೆ ಎಂಬುದಕ್ಕೆ [ನೆರಳು ಬೆಲೆ ನಿಗದಿ](../ನೆರಳು-ಬೆಲೆ-ನಿಗದಿ/), ಮತ್ತು ಡೆಡ್‌ವೇಟ್ ಹಾಗೂ ಆರೋಪಣೆ ಹೊಂದಾಣಿಕೆಗಳ ನಂತರ ಅನ್ವಯಿಸಿದ ಮೌಲ್ಯ ಅನುಪಾತಕ್ಕೆ ಹೇಗೆ ಸೇರುತ್ತದೆ ಎಂಬುದಕ್ಕೆ [ಸಾಮಾಜಿಕ ಹೂಡಿಕೆ ಪ್ರತಿಫಲ](../ಸಾಮಾಜಿಕ-ಹೂಡಿಕೆ-ಪ್ರತಿಫಲ/) ನೋಡಿ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

**ದತ್ತಿ ಸಂಸ್ಥೆ (ಸ್ನೇಹ ಸೇವೆಯ SROI)**: "ಒಂಟಿತನ ಇಳಿಕೆ"ಗಾಗಿ ಘಟಕ ವೆಚ್ಚ ದತ್ತಾಂಶ ಸಂಗ್ರಹದ ನಮೂದು ಪ್ರತಿ ವ್ಯಕ್ತಿಗೆ ವರ್ಷಕ್ಕೆ £1,100 ವಿವರಣಾತ್ಮಕ ಪ್ರಾಕ್ಸಿ ನೀಡುತ್ತದೆ. 80 ಫಲಾನುಭವಿಗಳಿಗೆ ಅನ್ವಯಿಸಿದರೆ: 80 × £1,100 = £88,000 ಒಟ್ಟು ಮೌಲ್ಯ. ಅದೇ ಸಂಗ್ರಹದಲ್ಲಿ "ಸುಧಾರಿತ ಮಾನಸಿಕ ಯೋಗಕ್ಷೇಮ"ಕ್ಕೂ ಪ್ರಾಕ್ಸಿ ಇದ್ದು ಅದು ಅತಿಕ್ರಮಿಸುವ ಯೋಗಕ್ಷೇಮ ಸಮೀಕ್ಷೆ ಅಂಶವನ್ನು ಆಧರಿಸಿದ್ದರೆ, ಅದೇ 80 ಜನರಿಗೆ ಎರಡೂ ಪ್ರಾಕ್ಸಿಗಳನ್ನು ಜೋಡಿಸುವುದು ಒಂದೇ ಆಧಾರ ಬದಲಾವಣೆಯ ಭಾಗವನ್ನು ಎರಡು ಬಾರಿ ಎಣಿಸುತ್ತದೆ — ಸಂಗ್ರಹ ಸಂಖ್ಯೆಯನ್ನು ಒದಗಿಸುತ್ತದೆ, ಆದರೆ ಈ ಅತಿಕ್ರಮಣ ತಪ್ಪಿಸುವುದು ವಿಶ್ಲೇಷಕರ ಹೊಣೆ.

**ಸ್ಥಳೀಯ ಪ್ರಾಧಿಕಾರ (ಉದ್ಯೋಗ ಕ್ಲಬ್ SROI)**: "ನಿರುದ್ಯೋಗದಿಂದ ಸ್ಥಿರ ಉದ್ಯೋಗಕ್ಕೆ" ಎಂಬ ಘಟಕ ವೆಚ್ಚ ಸಂಗ್ರಹ ನಮೂದನ್ನು 45 ಭಾಗವಹಿಸುವವರಿಗೆ ಪ್ರತಿ ವ್ಯಕ್ತಿಗೆ ವರ್ಷಕ್ಕೆ £8,500 ವಿವರಣಾತ್ಮಕ ಪ್ರಾಕ್ಸಿಯಲ್ಲಿ ಅನ್ವಯಿಸಲಾಗುತ್ತದೆ: 45 × £8,500 = £382,500 ಒಟ್ಟು ಮೌಲ್ಯ, [ಸಾಮಾಜಿಕ ಹೂಡಿಕೆ ಪ್ರತಿಫಲ](../ಸಾಮಾಜಿಕ-ಹೂಡಿಕೆ-ಪ್ರತಿಫಲ/)ದಲ್ಲಿ ತೋರಿಸಿದ ಡೆಡ್‌ವೇಟ್ ಮತ್ತು ಆರೋಪಣೆ ಹೊಂದಾಣಿಕೆಗಳ ಮೊದಲು.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್ ಸಂಪರ್ಕ

ದತ್ತಿ ಸಂಸ್ಥೆಗಳು ಅಥವಾ ಆಯೋಗದಾತರಿಗೆ ವರದಿ ಸಾಧನ ನಿರ್ಮಿಸುವ ತಂಡಗಳಿಗೆ ಆಂತರಿಕ "ಫಲಿತಾಂಶ ಕ್ಯಾಟಲಾಗ್" ಉಪಯುಕ್ತ — ಉತ್ಪನ್ನ ಅಥವಾ ಸೇವೆ ನಂಬಲರ್ಹವಾಗಿ ಹೇಳಿಕೊಳ್ಳಬಹುದಾದ ಪ್ರತಿ ಫಲಿತಾಂಶವನ್ನು ಹೆಸರಿಸಿದ ಪ್ರಾಕ್ಸಿ, ಅದರ ಆಕರ ದತ್ತಾಂಶ ಸಂಗ್ರಹ, ಪ್ರಕಟಣೆ ದಿನಾಂಕ ಮತ್ತು ಆವೃತ್ತಿ ಗುರುತಿಗೆ ಹೊಂದಿಸುವ ಕೋಷ್ಟಕ — ಇದರಿಂದ ಸಂಸ್ಥೆಯ ವಿವಿಧ ತಂಡಗಳು ಒಂದೇ ಫಲಿತಾಂಶಕ್ಕೆ ಸ್ವಲ್ಪ ಬೇರೆಬೇರೆ ಮೌಲ್ಯಗಳನ್ನು ಆರಿಸಿಕೊಳ್ಳುವುದಿಲ್ಲ. Global Value Exchange ನ ಮುಕ್ತ ದತ್ತಾಂಶವನ್ನು ಹುಡುಕಾಟ ಸೇವೆಯ ಹಿಂದೆ ಸುತ್ತಿ, ಅಂಕಿಯ ಪಕ್ಕದಲ್ಲಿ ಆಕರ ಮತ್ತು ದಿನಾಂಕ ಯಾವಾಗಲೂ ತೋರಿಸಿದರೆ, ಪ್ರಾಕ್ಸಿ ಸ್ಪ್ರೆಡ್‌ಶೀಟ್‌ನಲ್ಲಿ ಹುದುಗಿದ ಮಾಯಾ ಸಂಖ್ಯೆಯಾಗುವ ಬದಲು ಲೆಕ್ಕಪರಿಶೋಧಿಸಬಹುದಾದ್ದಾಗಿ ಉಳಿಯುತ್ತದೆ. ಈ ಪ್ರಾಕ್ಸಿಗಳು ಬಳಕೆಯಾಗುವ ಎರಡು ಮುಖ್ಯ ಸ್ಥಳಗಳಿಗಾಗಿ [ಸಾಮಾಜಿಕ ಹೂಡಿಕೆ ಪ್ರತಿಫಲ](../ಸಾಮಾಜಿಕ-ಹೂಡಿಕೆ-ಪ್ರತಿಫಲ/) ಮತ್ತು [ಸಾಮಾಜಿಕ ಮೌಲ್ಯ ಕಾಯ್ದೆ](../ಸಾಮಾಜಿಕ-ಮೌಲ್ಯ-ಕಾಯ್ದೆ/) ನೋಡಿ.

## ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳು

- **ಪ್ರಾಕ್ಸಿಗಳನ್ನು ನಿಖರವೆಂದು ಪರಿಗಣಿಸುವುದು.** ಹೆಚ್ಚಿನ ಪ್ರಕಟಿತ ಪ್ರಾಕ್ಸಿಗಳು ವಿಶಾಲ ವಿಶ್ವಾಸ ಅಂತರಗಳಿರುವ ಯೋಗಕ್ಷೇಮ ಮೌಲ್ಯಮಾಪನ ಅಧ್ಯಯನಗಳ ಮಾದರಿ ಸರಾಸರಿಗಳು; ಒಂದನ್ನು ಪೌಂಡ್‌ವರೆಗೆ ಉಲ್ಲೇಖಿಸುವುದು ಆಧಾರ ಸಂಶೋಧನೆ ಬೆಂಬಲಿಸುವ ನಿಖರತೆಯನ್ನು ಉತ್ಪ್ರೇಕ್ಷಿಸುತ್ತದೆ.
- **ಅತಿಕ್ರಮಿಸುವ ಪ್ರಾಕ್ಸಿಗಳನ್ನು ಎರಡು ಬಾರಿ ಎಣಿಸುವುದು.** ಅತಿಕ್ರಮಿಸುವ ಸಮೀಕ್ಷೆ ಪರಿಕಲ್ಪನೆಗಳಿಂದ ಪಡೆದ ಪ್ರಾಕ್ಸಿಗಳನ್ನು (ಉದಾ. "ಕಡಿಮೆಯಾದ ಒಂಟಿತನ" ಮತ್ತು "ಸುಧಾರಿತ ಮಾನಸಿಕ ಯೋಗಕ್ಷೇಮ") ಸೇರಿಸಿದರೆ ಒಂದೇ ಆಧಾರ ಬದಲಾವಣೆಗೆ ಎರಡು ಬಾರಿ ಮೌಲ್ಯ ಕಟ್ಟಿದಂತಾಗುತ್ತದೆ.
- **ಸಂದರ್ಭಕ್ಕೆ ಹೊರತಾದ ಪ್ರಾಕ್ಸಿಯನ್ನು ಹೊಂದಾಣಿಕೆಯಿಲ್ಲದೆ ಬಳಸುವುದು.** ಒಂದು ರಾಷ್ಟ್ರೀಯ ಜನಸಂಖ್ಯೆ ಮತ್ತು ವರ್ಷದಲ್ಲಿ ಮಾಪನಗೊಂಡ ಪ್ರಾಕ್ಸಿಯನ್ನು ಹಣದುಬ್ಬರ ಅಥವಾ ಸಂದರ್ಭ ಹೊಂದಾಣಿಕೆಯಿಲ್ಲದೆ ಬೇರೆಡೆ ಅನ್ವಯಿಸಿದರೆ ಮೌಲ್ಯ ಮೌನವಾಗಿ ತಪ್ಪಾಗುತ್ತದೆ.
- **ಮೂಲ ಪರಿಶೀಲಿಸದಿರುವುದು.** Global Value Exchange ಮುಕ್ತ ಮತ್ತು ಜನಸಮೂಹ-ಮೂಲದ್ದಾದ್ದರಿಂದ ನಮೂದಿನ ಗುಣಮಟ್ಟ ಕೊಡುಗೆದಾರರ ಪ್ರಕಾರ ಬದಲಾಗುತ್ತದೆ; ಅನುದಾನ ಬಿಡ್ ಅಥವಾ ಖರೀದಿ ಸಲ್ಲಿಕೆಯಲ್ಲಿ ಅಂಕಿಯನ್ನು ಉಲ್ಲೇಖಿಸುವ ಮೊದಲು ಆಧಾರ ಆಕರವನ್ನು ಪರಿಶೀಲಿಸಿ.
