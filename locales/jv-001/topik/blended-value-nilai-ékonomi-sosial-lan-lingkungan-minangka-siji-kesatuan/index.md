# Blended Value: Nilai Ékonomi, Sosial, lan Lingkungan minangka Siji Kesatuan

Blended value iku gagasan Jed Emerson yèn kabèh kegiatan organisasi lan investasi bebarengan nggawé nilai ing telung garis — ékonomi, sosial, lan lingkungan — lan telung garis iki dudu telung bali sing kapisah sing bisa ditukar siji lan sijiné, nanging siji proposisi nilai sing ora bisa dipisah. Ing pigura Emerson, ora ana sing diarani bali finansial murni utawa bali sosial murni; saben pound sing dibelanjaké, diinvestasiké, utawa dihibahké ngasilaké campuran saka katelu-telune.

## Kenapa penting

Emerson nata gagasan iki ing "The Blended Value Proposition: Integrating Social and Financial Returns" (California Management Review, 2003), sing ditulis langsung nglawan konvènsi abad kaping rong puluh sing misahaké modal dadi rong silo — filantropi, sing dikarepaké ngasilaké bali sosial lan ngaturaké bali finansial babar blas, lan investasi, sing dikarepaké ngasilaké bali finansial lan nganggep efek sosial utawa lingkungan minangka eksternalitas. Argumen Emerson yaiku yèn pemilahan iki tansah fiksi: hibah sing mbiayai organisasi sing dikelola kanthi elek ngrusak nilai ing katelu garis, lan bisnis nguntungaké sing nyemari kali uga ngrusak nilai ing katelu garis, apa waé bali para pemegang sahamé ing kertas.

Gagasan iki mlaku paralel karo "triple bottom line" John Elkington (people, planet, profit), sing diciptakaké ing 1994 lan dikembangaké ing bukuné 1997 "Cannibals with Forks," sing ndhesek perusahaan nglaporaké kinerja sosial lan lingkungan bebarengan karo kinerja finansial. Blended value nyurung logika sing padha luwih jauh menyang alokasi modal dhéwé, lan iku leluhur intelektual bidang investasi dampak: Global Impact Investing Network (GIIN), sing didegaké ing 2009, ana khusus kanggo mbangun infrastruktur — kalebu katalog metrik IRIS+, deleng [pelaporan outcome hibah](../pelaporan-outcome-hibah/) — sing ngidinaké investor tenan ngukur campuran kuwi tinimbang mung ngaku.

## Petungan

Blended value iku kerangka, dudu rumus, lan Emerson kanthi gamblang ngélingaké supaya ora nyuda dadi panambahan prasaja saka telung skor. Struktur sing diusulaké:

```
Saben unit modal sing dikerahaké (hibah, investasi, kontrak, pembelian) ngasilaké:
  - efek ékonomi     (bali finansial, biaya dihemat, pendapatan digawé)
  - efek sosial      (kesejahteraan, kapabilitas, owah-owahan kesetaraan kanggo wong)
  - efek lingkungan  (modal alam dilindhungi, dirusak, utawa dipulihaké)

Iki ora dioptimalaké sacara kapisah banjur dijumlahaké. Kaputusan sing nggedhèkake
garis ékonomi nalika ngrusak garis sosial dudu "blended value plus
biaya" — iku kaputusan sing net ngrusak nilai, titik.
```

Ing praktik, organisasi nyedhaki campuran nganggo scorecard: indikator jenengan kanggo saben garis, dilaporaké bebarengan, ora diyèkaké dadi siji angka. Iki naluri padha karo [return sosial atas investasi](../social-return-on-investment-ngukur-bali-modal-sosial-sing-wis-disesuaikan-karo-deadweight-lan-atribusi/) (sing nyoba nganggo netting moneter) lan [akuntansi modal alam](../akuntansi-modal-alam/) (sing nindakaké padha kanggo garis lingkungan) — kekarone jawaban parsial, siji-garis, marang pitakonan sing diwenèhaké blended value sacara kebak.

## Conto petungan

Sawijining investor dampak milih antara rong utang £500.000:

- **Utang A**: marang usaha sosial sing ngelola kafe latihan kerja kanggo mantan narapidana, kanthi bunga 2% (ing ngisor tarif pasar 6% kanggo utang risiko sepadan), dikarepaké nyaluraké 40 wong/taun menyang kerja sing lestari.
- **Utang B**: utang tarif pasar 6% marang bisnis eceran konvènsional tanpa tujuan sosial utawa lingkungan sing dinyatakaké.

Lensa finansial murni milih B (6% > 2%). Lensa blended value njaluk investor nyebutaké katelu garis kanggo kekarone:

| | Ékonomi (taunan) | Sosial (taunan) | Lingkungan |
|---|---|---|---|
| Utang A | Bunga £10.000 | 40 wong disalurake menyang kerja; saben taun-panggonan nggawa penghematan nyegah-residivisme sing masuk akal kanggo negara, dijupuk saka analisis biaya residivisme Ministry of Justice | Netral |
| Utang B | Bunga £30.000 | Ora ana sing dinyatakaké | Netral |

Bali blended Utang A jelas ngungkuli yèn garis sosial wis dihargai, senajan garis finansialé dhéwé kalah saka Utang B £20.000 saben taun. Blended value ora ngandhani investor supaya ngabaikan celah £20.000 — nanging ngandhani supaya aja pura-pura iku siji-sijiné angka sing ana.

## Gegayutan karo rekayasa piranti lunak

Piranti lunak pelaporan utawa manajemen portofolio kanggo yayasan, dana dampak, utawa tim komisioning otoritas lokal kerep dibangun karo buku besar finansial minangka model data utama lan kolom sosial utawa lingkungan ditempèl minangka cathetan teks bébas. Blended value ngimplikasi rancangan kosok balèné: telung aliran nilai kelas siji, sepadan terstruktur, dipasang ing saben cathetan transaksi utawa hibah, saben duwé unit, sumber, lan tingkat keyakinan dhéwé, ditampilaké bebarengan tinimbang diyèkaké dadi siji skor sing akurat sing nyesatake. Deleng [return sosial atas investasi](../social-return-on-investment-ngukur-bali-modal-sosial-sing-wis-disesuaikan-karo-deadweight-lan-atribusi/) lan [scorecard nilai publik](../scorecard-nilai-publik/) kanggo rong cara terstruktur nggawé tampilan kuwi tanpa ngrusak campuran.

## Jebakan

- **Njumlahaké telung garis dadi siji angka.** Tulisan Emerson dhéwé ngélingaké bab iki; siji angka campuran nyingidaké garis endi sing tenan nyambut gawé lan ngundang milih-milih data.
- **Blend-washing.** Ngaku garis sosial utawa lingkungan sing kuwat tanpa indikator jenengan utawa cara pangukuran, kanggo mbenerake bali finansial ing ngisor pasar sing yèn ora bakal katon kurang kinerja.
- **Ora nggatèkaké campuran negatif.** Program sing sukses finansial bisa duwé garis sosial utawa lingkungan negatif; blended value mbutuhaké nglaporaké kabar elek ing garis apa waé, dudu mung kabar apik ing siji garis.
