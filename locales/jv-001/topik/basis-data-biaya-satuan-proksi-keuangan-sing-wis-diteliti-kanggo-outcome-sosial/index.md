# Basis Data Biaya Satuan (Unit Cost Databases): Proksi Keuangan sing Wis Diteliti kanggo Outcome Sosial

Basis data biaya satuan (unit cost database) iku perpustakaan proksi keuangan adhedhasar bukti sing wis diteliti sadurungé kanggo outcome sosial — nilai pindhah saka nganggur menyang kerja, kesepian sing suda, sewa sing stabil — sing ngidini praktisi ngowahi outcome dadi nilai moneter tanpa mréntahaké riset penilaian khusus saben-saben. Ana kanggo supaya lembaga amal cilik sing nulis penawaran pendanaan bisa nerapaké ketelitian sing padha karo konsultan sing sumber dayané cukup, kanthi nganggo maneh proksi sing wis diturunaké lan diterbitaké wong liya.

## Kenapa penting

UK Social Value Bank saka HACT, sing dikembangaké karo ekonom Daniel Fujiwara nganggo metode penilaian kesejahteraan, lan Global Value Exchange, basis data terbuka proksi keuangan sing disumbang rame-rame, iku loro sing paling akèh dienggo ing sektor katelu lan publik Britania Raya. Loro-lorone ana amarga karya penilaian dhasaré — [penilaian kesejahteraan](../penilaian-kesejahteraan-ngregani-kabijakan-langsung-ing-satuan-kepuasan-urip/) lan [penilaian preferensi sing dinyatakaké](../penilaian-preferensi-sing-dinyatakaké-nakokaké-wong-sepira-gelem-mbayar/) — larang, mbutuhaké metodologi sing ketat, lan alon yèn dilakokaké saka nol kanggo saben proyek. Perpustakaan proksi bersama sing diterbitaké ngowahi apa sing bakal dadi latihan riset pirang-pirang sasi dadi pamadhangan, persis alesané penting kanggo itungan [social return on investment](../social-return-on-investment-ngukur-bali-modal-sosial-sing-wis-disesuaikan-karo-deadweight-lan-atribusi/) lan evaluasi penawaran [Social Value Act](../social-value-act-kewajiban-hukum-nimbang-nilai-sosial-ing-pengadaan-publik/): tanpa iku, monetisasi sing ketat mung kejangkau organisasi sing cukup gedhé kanggo mréntahaké studi dhéwé.

## Petungan

Basis data biaya satuan ora ngétung apa-apa dhéwé; iku nyedhiyakaké siji input kanggo itungan sing dilakokaké ing panggonan liya:

```
Nilai proksi keuangan = rega pasar, UTAWA rega bayangan, UTAWA penilaian kesejahteraan,
                         UTAWA nilai preferensi sing dinyatakaké
                         kanggo satuan owah-owahan outcome sing ditetepaké
                         (contoné "saben wong sing pindhah saka nganggur menyang kerja, saben taun")

Nilai sing ditrapaké = cacahé outcome sing kagayuh × nilai proksi satuan
```

Deleng [rega bayangan](../shadow-pricing-ngregani-barang-sing-ora-duwé-rega-pasar/) kanggo kepriyé proksi disusun nalika ora ana rega pasar, lan [social return on investment](../social-return-on-investment-ngukur-bali-modal-sosial-sing-wis-disesuaikan-karo-deadweight-lan-atribusi/) kanggo kepriyé nilai sing ditrapaké banjur mlebu rasio sakwisé panyesuaian deadweight lan atribusi.

## Conto petungan

**Lembaga amal (SROI layanan pendampingan)**: entri basis data biaya satuan kanggo "suda-né kesepian" menehi proksi ilustratif £1.100 saben wong saben taun. Ditrapaké marang 80 penerima manfaat: 80 × £1.100 = £88.000 nilai kasar. Yèn basis data sing padha uga duwé proksi kanggo "kesejahteraan mental sing luwih apik" sing njupuk saka item survei kesejahteraan sing tumpang tindih, numpuk loro-lorone proksi kanggo 80 wong sing padha bakal ngétung kaping pindho sebagéan owah-owahan dhasar sing padha — basis data nyedhiyakaké angka, nanging ngindhari tumpang tindih iki tanggung jawab analis.

**Otoritas lokal (SROI klub pagawéan)**: entri basis data biaya satuan kanggo "pindhah saka nganggur menyang kerja lestari" ditrapaké marang 45 peserta ing proksi ilustratif £8.500 saben wong saben taun: 45 × £8.500 = £382.500 nilai kasar, sadurungé panyesuaian deadweight lan atribusi sing dituduhaké ing [social return on investment](../social-return-on-investment-ngukur-bali-modal-sosial-sing-wis-disesuaikan-karo-deadweight-lan-atribusi/).

## Gegayutan karo rekayasa piranti lunak

Tim sing mbangun piranti pelaporan kanggo lembaga amal utawa komisioner entuk manfaat saka "katalog outcome" internal — tabel sing mapaké saben outcome sing bisa diklaim produk utawa layanan menyang proksi kanthi jeneng, basis data sumberé, tanggal publikasi, lan pengenal versi — supaya tim sing béda ing organisasi ora saben-saben milih nilai sing rada béda kanggo outcome sing padha. Mbungkus data terbuka Global Value Exchange ing mburi layanan pamadhangan, kanthi sumber lan tanggal tansah ditampilaké bebarengan karo angka, njaga proksi tetep bisa diaudit, dudu angka sihir sing kekubur ing spreadsheet. Deleng [social return on investment](../social-return-on-investment-ngukur-bali-modal-sosial-sing-wis-disesuaikan-karo-deadweight-lan-atribusi/) lan [social value act](../social-value-act-kewajiban-hukum-nimbang-nilai-sosial-ing-pengadaan-publik/) kanggo rong panggonan utama proksi iki dikonsumsi.

## Jebakan

- **Nganggep proksi presisi.** Umumé proksi sing diterbitaké iku rata-rata sing dimodelaké saka studi penilaian kesejahteraan kanthi interval kepercayaan jembar; nyebutaké siji nganti pound-é nggedhèkaké presisi sing didhukung riset dhasar.
- **Ngétung kaping pindho proksi sing tumpang tindih.** Nggabungaké proksi (contoné "kesepian suda" lan "kesejahteraan mental apik") sing dijupuk saka konstruk survei sing tumpang tindih ngregani owah-owahan dhasar sing padha kaping pindho.
- **Nganggo proksi njaba konteks tanpa disesuaikan.** Proksi sing dikalibrasi ing siji populasi nasional lan taun, ditrapaké ing panggonan liya tanpa penyesuaian inflasi utawa konteks, meneng-meneng nyalahaké nilai.
- **Ora mriksa asal-usul.** Global Value Exchange iku terbuka lan disumbang rame-rame, mula kualitas entri beda-beda miturut kontributor; priksa sumber dhasar sadurungé nyebutaké angka ing penawaran pendanaan utawa pengajuan pengadaan.
