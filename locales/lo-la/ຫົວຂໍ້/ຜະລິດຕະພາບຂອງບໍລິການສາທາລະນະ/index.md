# ຜະລິດຕະພາບຂອງບໍລິການສາທາລະນະ

ຜະລິດຕະພາບຂອງບໍລິການສາທາລະນະວັດວ່າການໃຊ້ຈ່າຍສາທາລະນະແປງປັດໄຈນຳເຂົ້າ (ພະນັກງານ, ທຶນ, ສິນຄ້າ ແລະ ບໍລິການ) ເປັນຜົນຜະລິດທີ່ປັບຄຸນນະພາບແລ້ວໄດ້ຢ່າງມີປະສິດທິພາບເທົ່າໃດ,
ສຳລັບບໍລິການ — ສຸຂະພາບ, ການສຶກສາ, ການຕຳຣວດ, ການດູແລສັງຄົມ — ທີ່ບໍ່ມີລາຄາຕະຫຼາດ ແລະ ດ້ວຍເຫດນັ້ນຈຶ່ງບໍ່ມີຕົວເລກລາຍຮັບເພື່ອຫານຕົ້ນທຶນ.
ສຳນັກງານສະຖິຕິແຫ່ງຊາດຂອງ UK (ONS) ໄດ້ເຜີຍແຜ່ຊຸດຂໍ້ມູນນີ້ຕັ້ງແຕ່ກາງຊຸມປີ 2000 ແລະ ມັນຍັງເປັນຄວາມພະຍາຍາມແຫ່ງຊາດທີ່ພັດທະນາດ້ານວິທີການທີ່ສຸດ
ເພື່ອຕອບ "ລັດຖະບານກຳລັງດີຂຶ້ນ ຫຼື ຮ້າຍລົງໃນການແປງເງິນເປັນບໍລິການສາທາລະນະ?"

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ໃນຕະຫຼາດ, ຜະລິດຕະພາບແມ່ນ (ມູນຄ່າຜົນຜະລິດ) / (ຕົ້ນທຶນປັດໄຈນຳເຂົ້າ), ແລະ ມູນຄ່າຜົນຜະລິດສັງເກດໄດ້ເພາະມີຄົນຈ່າຍເງິນ. ການປ່ຽນສະໂພກ, ບ່ອນຮຽນໃນໂຮງຮຽນ,
ແລະ ການລາດຕະເວນຂອງຕຳຣວດບໍ່ມີລາຄາຂາຍ, ດັ່ງນັ້ນແບບງ່າຍໆທ່ານວັດໄດ້ແຕ່ *ປັດໄຈນຳເຂົ້າ* (ສິ່ງທີ່ໃຊ້ຈ່າຍ) — ເຊິ່ງລໍ້ໃຈຜູ້ວິຈານໃຫ້ຖືວ່າການໃຊ້ຈ່າຍສາທາລະນະທີ່ເພີ່ມຂຶ້ນ
ເປັນສິ່ງບໍ່ດີໂດຍອັດຕະໂນມັດ, ເພາະປັດໄຈນຳເຂົ້າຫຼາຍຂຶ້ນພ້ອມກິດຈະກຳຫົວຂໍ້ທີ່ຄົງທີ່ເບິ່ງຄືຜະລິດຕະພາບຫຼຸດລົງ. ວິທີການຂອງ ONS, ທີ່ກຳນົດໃນສິ່ງພິມ "Sources and Methods"
ສຳລັບຜະລິດຕະພາບບໍລິການສາທາລະນະ, ແກ້ບັນຫານີ້ໂດຍສ້າງດັດຊະນີ *ຜົນຜະລິດ* ຈາກປະລິມານກິດຈະກຳ (ການຜ່າຕັດທີ່ເຮັດ, ນັກຮຽນທີ່ສອນ, ອາຊະຍາກຳທີ່ສືບສວນ) ແລ້ວ *ປັບຄຸນນະພາບ*
ດັດຊະນີຜົນຜະລິດນັ້ນ — ສຳລັບສຸຂະພາບ, ລວມອັດຕາການລອດຊີວິດ ແລະ ເວລາລໍຖ້າ; ສຳລັບການສຶກສາ, ລວມຜົນສຳເລັດດ້ານການຮຽນ; ສຳລັບການຕຳຣວດ, ລວມຜົນລັບເຊັ່ນການແກ້ໄຂກໍລະນີ — ເພື່ອໃຫ້ບໍລິການ
ທີ່ເຮັດການຜ່າຕັດຈຳນວນເທົ່າກັນແຕ່ບັນລຸອັດຕາການລອດຊີວິດດີກວ່າປາກົດວ່າມີຜະລິດຕະພາບຫຼາຍກວ່າ, ບໍ່ແມ່ນພຽງແພງກວ່າ. ຜົນການຄົ້ນພົບຫົວຂໍ້ທີ່ປາກົດຊ້ຳໃນການເຜີຍແຜ່ຂອງ ONS
ເປັນຕາຕົກໃຈສຳລັບຂະແໜງ: ຜະລິດຕະພາບບໍລິການສາທາລະນະຂອງ UK ຫຼຸດລົງຢ່າງແຮງໃນລະຫວ່າງການລະບາດຂອງ COVID-19 ແລະ ຕາມການເຜີຍແຜ່ກາງຊຸມປີ 2020 ຂອງ ONS ເອງ
ຍັງບໍ່ຟື້ນຄືນເຖິງລະດັບປີ 2019 ໃນຂະແໜງຍ່ອຍຫຼາຍແຫ່ງລວມທັງການດູແລສຸຂະພາບ, ເຖິງແມ່ນການໃຊ້ຈ່າຍເພີ່ມຂຶ້ນ — ຊ່ອງຫວ່າງທີ່ປັບກອບ "ທຶນຫຼາຍຂຶ້ນ"
ແລະ "ຜະລິດຕະພາບຫຼາຍຂຶ້ນ" ໃຫ້ເປັນສອງຄຳຖາມທີ່ແຍກກັນຢ່າງສິ້ນເຊີງ.

## ຄະນິດສາດ

```
ດັດຊະນີຜົນຜະລິດ (ປະລິມານ) = Σ (ກິດຈະກຳ_i × ນ້ຳໜັກຕົ້ນທຶນຕໍ່ໜ່ວຍສຳພັດ_i), ຖ່ວງນ້ຳໜັກປີຖານ
                          ທົ່ວທຸກກິດຈະກຳບໍລິການ (ເຊັ່ນ ການຜ່າຕັດສະໂພກ, ການຜ່າຕັດຕາ,
                          ການປຶກສາແພດທົ່ວໄປ), ຄ້າຍຄືດັດຊະນີປະລິມານ Laspeyres/Paasche

ການປັບຄຸນນະພາບ            = ດັດຊະນີຜົນຜະລິດ × ປັດໄຈປັບຄຸນນະພາບ
                          (ເຊັ່ນ ລວມການປ່ຽນແປງຂອງອັດຕາລອດຊີວິດ, ເວລາລໍຖ້າ,
                          ຜົນສຳເລັດດ້ານການຮຽນ, ຫຼື ການກະທຳຜິດຊ້ຳ ເປັນຕົວຄູນຂອງປະລິມານດິບ)

ດັດຊະນີປັດໄຈນຳເຂົ້າ       = Σ (ຊົ່ວໂມງແຮງງານ × ນ້ຳໜັກຕົ້ນທຶນແຮງງານ) + (ຕົ້ນທຶນສິນຄ້າ/ບໍລິການ,
                          ປັບລາຄາແລ້ວ) + (ການບໍລິໂພກທຶນ)

ການເຕີບໂຕຂອງຜະລິດຕະພາບປັດໄຈລວມ = % ການປ່ຽນແປງຂອງດັດຊະນີຜົນຜະລິດທີ່ປັບຄຸນນະພາບ
                                    − % ການປ່ຽນແປງຂອງດັດຊະນີປັດໄຈນຳເຂົ້າ
```

## ຕົວຢ່າງການຄິດໄລ່

**ການຄິດໄລ່ຜະລິດຕະພາບຂະແໜງ acute ຂອງ NHS (ຕົວຢ່າງ)** (ໂຄງສ້າງຕາມວິທີການຂອງ ONS):

```
ປີ 1: ດັດຊະນີປະລິມານຜົນຜະລິດ = 100.0 (ປີຖານ), ດັດຊະນີປັດໄຈນຳເຂົ້າ = 100.0
        → ດັດຊະນີຜະລິດຕະພາບ = 100.0

ປີ 2: ປະລິມານກິດຈະກຳເພີ່ມຂຶ້ນ 3.0% (ຜ່າຕັດຫຼາຍຂຶ້ນ, ນັດໝາຍຫຼາຍຂຶ້ນ)
        ແຕ່ເວລາລໍຖ້າສະເລ່ຍຮ້າຍລົງ, ໃຊ້ການຫຼຸດປັບຄຸນນະພາບ
        −1.0%
        ດັດຊະນີຜົນຜະລິດທີ່ປັບຄຸນນະພາບ = 100 × 1.030 × 0.990 = 101.97

        ປັດໄຈນຳເຂົ້າເພີ່ມຂຶ້ນ: ຈຳນວນພະນັກງານ +4.0%, ຕົ້ນທຶນອື່ນ (ປັບລາຄາແລ້ວ) +1.5%,
        ດັດຊະນີປັດໄຈນຳເຂົ້າຖ່ວງນ້ຳໜັກ = 100 × 1.032 = 103.2

ການເຕີບໂຕຜະລິດຕະພາບ = (101.97 / 100 − 1) − (103.2 / 100 − 1)
                     = 1.97% − 3.2% = −1.23 ຈຸດເປີເຊັນ

ການຕີຄວາມ: ກິດຈະກຳເພີ່ມຂຶ້ນ, ແຕ່ປັດໄຈນຳເຂົ້າເພີ່ມໄວກວ່າ ແລະ ຄຸນນະພາບຫຼຸດລົງ
ເລັກນ້ອຍ, ດັ່ງນັ້ນຜະລິດຕະພາບ — ຜົນຜະລິດຕໍ່ໜ່ວຍປັດໄຈນຳເຂົ້າ — ຫຼຸດລົງ
ເຖິງວ່າ "ໄດ້ສົ່ງມອບການດູແລຫຼາຍຂຶ້ນ."
```

ນີ້ແມ່ນຮູບແບບທີ່ແນ່ນອນທີ່ການເຜີຍແຜ່ຂອງ ONS ລາຍງານຊ້ຳແລ້ວຊ້ຳອີກສຳລັບບາງສ່ວນຂອງ NHS ຫຼັງການລະບາດ:
ການໃຊ້ຈ່າຍທີ່ເພີ່ມຂຶ້ນ ແລະ ກິດຈະກຳດິບທີ່ເພີ່ມຂຶ້ນຢູ່ຮ່ວມກັບຜະລິດຕະພາບທີ່ວັດໄດ້ຫຼຸດລົງ ເມື່ອທັງການປັບຄຸນນະພາບ ແລະ ການເຕີບໂຕຂອງປັດໄຈນຳເຂົ້າຖືກນັບ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ຜະລິດຕະພາບບໍລິການສາທາລະນະເປັນຕົວຄ້າຍຄືລະດັບປະຊາກອນຂອງການໂຕ້ວາທີຜະລິດຕະພາບວິສະວະກຳ
(story point ທີ່ສົ່ງມອບ ທຽບ [ຕົວຊີ້ວັດ DORA](../ຕົວຊີ້ວັດ-dora-ສຳລັບຄຸນຄ່າສາທາລະນະ/) ທຽບ
[ຕົວຊີ້ວັດການໄຫຼ](../ຕົວຊີ້ວັດກະແສໃນການສົ່ງມອບຂອງລັດຖະບານ/)): ປະລິມານການຜ່ານດິບທີ່ບໍ່ມີການປັບຄຸນນະພາບເຂົ້າໃຈຜິດໃນໂຮງໝໍພໍດີກັບທີ່ "ແຖວໂຄດທີ່ສົ່ງມອບ" ເຂົ້າໃຈຜິດໃນທີມຊອບແວ.
ທີມທີ່ສ້າງທໍ່ຂໍ້ມູນຜົນງານສຳລັບກະຊວງຄວນຖືການປັບຄຸນນະພາບເປັນຂັ້ນຕອນການແປງຊັ້ນໜຶ່ງທີ່ຄວບຄຸມເວີຊັນ, ບໍ່ແມ່ນໝາຍເຫດ — ເພາະຄວາມໜ້າເຊື່ອຖືຂອງ ONS ເອງ
ຂຶ້ນກັບການປັບນັ້ນທີ່ໂປ່ງໃສ, ຜະລິດຊ້ຳໄດ້, ແລະ ປັບປຸງເມື່ອຂໍ້ມູນຄຸນນະພາບທີ່ດີກວ່າມາຮອດ
(ONS ປັບປຸງການຄາດຄະເນຜະລິດຕະພາບຂອງປີຜ່ານມາເມື່ອຂໍ້ມູນຄຸນນະພາບພື້ນຖານ — ເຊັ່ນ ອັດຕາລອດຊີວິດ — ຖືກສຳເລັດ, ສະນັ້ນລະບົບຕໍ່ລຸ່ມໃດໆທີ່ບໍລິໂພກສະຖິຕິເຫຼົ່ານີ້
ຕ້ອງຈັດການການປັບປຸງຍ້ອນຫຼັງ, ບໍ່ແມ່ນພຽງຕື່ມໄລຍະໃໝ່). ມັນຍັງຕັດກັບ

ເພີ່ມປະລິມານກິດຈະກຳດິບໂດຍບໍ່ປັບປຸງ ຫຼື ຮັກສາຄຸນນະພາບບໍ່ແມ່ນການປັບປຸງຜະລິດຕະພາບ ຕາມນິຍາມຂອງ ONS ເອງ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ຖືການເຕີບໂຕປັດໄຈນຳເຂົ້າເປັນການເຕີບໂຕຜະລິດຕະພາບ**: ການໃຊ້ຈ່າຍຫຼາຍຂຶ້ນທີ່ໃຫ້ທຶນພະນັກງານຫຼາຍຂຶ້ນສ້າງ
  *ກິດຈະກຳ* ຫຼາຍຂຶ້ນ, ບໍ່ແມ່ນ *ຜະລິດຕະພາບ* ຫຼາຍຂຶ້ນ, ເວັ້ນແຕ່ຜົນຜະລິດຕໍ່ໜ່ວຍປັດໄຈນຳເຂົ້າກໍເພີ່ມຂຶ້ນ — ທັງສອງຖືກປົນກັນເປັນປະຈຳໃນການວິຈານທາງການເມືອງ.
- **ເມີນເສີຍການປັບຄຸນນະພາບທັງໝົດ**: ດັດຊະນີຜົນຜະລິດທີ່ສ້າງຈາກການນັບກິດຈະກຳດິບເທົ່ານັ້ນ
  ຈະສະແດງ "ຜົນໄດ້ຮັບດ້ານຜະລິດຕະພາບ" ຈາກການເຮັດສິ່ງທີ່ມີມູນຄ່າຕ່ຳກວ່າ ຫຼື ຄຸນນະພາບຕ່ຳກວ່າຫຼາຍຂຶ້ນ; ການປັບຄຸນນະພາບຂອງ ONS ມີຂຶ້ນໂດຍສະເພາະເພື່ອຈັບສິ່ງນີ້.
- **ປຽບທຽບດັດຊະນີຜະລິດຕະພາບຂ້າມຂະແໜງຍ່ອຍໂດຍບໍ່ກົງກັນຂອງລຸ້ນວິທີການ**:
  ຜະລິດຕະພາບສຸຂະພາບ, ການສຶກສາ ແລະ ການຕຳຣວດແຕ່ລະອັນສ້າງຈາກແຫຼ່ງຂໍ້ມູນກິດຈະກຳ ແລະ ຄຸນນະພາບທີ່ແຕກຕ່າງກັນໃນວົງຈອນການປັບປຸງທີ່ແຕກຕ່າງກັນ — ການປຽບທຽບຂ້າມຂະແໜງແບບງ່າຍໆ
  ປຽບທຽບເຄື່ອງມືທີ່ເຂົ້າກັນບໍ່ໄດ້.
- **ອ່ານການຫຼຸດລົງຂອງຜະລິດຕະພາບໃນປີດຽວເປັນແນວໂນ້ມຖາວອນ**: ຕົວເລກຜະລິດຕະພາບຍຸກລະບາດ ແລະ ຫຼັງການລະບາດ
  ສະແດງຄວາມຜັນຜວນປີຕໍ່ປີຢ່າງຫຼວງຫຼາຍເມື່ອຂໍ້ມູນຄຸນນະພາບ (ເຊັ່ນ ລາຍຊື່ລໍຖ້າ, ການຟື້ນຕົວຂອງການຜ່າຕັດເລືອກ) ເອງປ່ຽນແປງ; ONS ເຕືອນຢ່າງສອດຄ່ອງບໍ່ໃຫ້ຕີຄວາມການເຄື່ອນໄຫວໃນປີດຽວເກີນໄປ.
