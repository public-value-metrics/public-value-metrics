# ດັດຊະນີຄວາມທຸກຍາກຫຼາຍມິຕິ (MPI)

MPI ວັດແທກຄວາມທຸກຍາກວ່າເປັນການຂາດແຄນທີ່ຊ້ອນທັບກັນທີ່ບຸກຄົນປະສົບພ້ອມກັນ — ດ້ານສຸຂະພາບ, ການສຶກສາ ແລະ ມາດຕະຖານການດຳລົງຊີວິດ —
ແທນທີ່ຈະເບິ່ງພຽງລາຍໄດ້ຕ່ຳກວ່າເສັ້ນຄວາມທຸກຍາກ. ມັນຖືກພັດທະນາໂດຍ Oxford Poverty and Human Development Initiative (OPHI)
ກັບ Sabina Alkire ແລະ James Foster, ແລະ ໄດ້ຖືກເຜີຍແຜ່ຮ່ວມກັບ UNDP ໃນທຸກລາຍງານການພັດທະນາມະນຸດຕັ້ງແຕ່ປີ 2010,
ຄຽງຄູ່ກັບ[ດັດຊະນີການພັດທະນາມະນຸດ](../ດັດຊະນີການພັດທະນາມະນຸດ/).

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ເສັ້ນຄວາມທຸກຍາກດ້ານລາຍໄດ້ພາດຄົນທີ່ມີລາຍໄດ້ເງິນສົດພຽງພໍແຕ່ຂາດນ້ຳສະອາດ, ການສຶກສາ, ຫຼືສູນເສຍລູກ — ແລະ ພາດຄວາມຈິງທີ່ວ່າ
ການຂາດແຄນມັກລວມກຸ່ມກັນ: ຄົວເຮືອນທີ່ບໍ່ມີໄຟຟ້າມີໂອກາດສູງຢ່າງບໍ່ສົມສ່ວນທີ່ຈະຂາດສຸຂາພິບານ ແລະ ມີເດັກທີ່ຂາດສານອາຫານນຳ.
ວິທີ Alkire-Foster ທີ່ MPI ສ້າງຂຶ້ນມາ ນັບການຂາດແຄນຂອງແຕ່ລະຄົນໃນສິບຕົວຊີ້ວັດທີ່ຈັດເປັນສາມມິຕິທີ່ມີນ້ຳໜັກເທົ່າກັນ —
ສຸຂະພາບ, ການສຶກສາ, ມາດຕະຖານການດຳລົງຊີວິດ — ແລະ ຈັດຜູ້ໃດວ່າ "ທຸກຍາກຕາມ MPI" ກໍຕໍ່ເມື່ອຄະແນນການຂາດແຄນຖ່ວງນ້ຳໜັກຂອງເຂົາຂ້າມເກນທີ່ກຳນົດ,
ເຊິ່ງຈັບການຊ້ອນທັບທີ່ຊຸດສະຖິຕິຕົວຊີ້ວັດດຽວແຍກກັນບໍ່ສາມາດຈັບໄດ້. OPHI ເຜີຍແຜ່ວິທີການທັງໝົດ ແລະ ຂໍ້ມູນລາຍປະເທດທີ່
<https://ophi.org.uk/multidimensional-poverty-index/>; MPI ໂລກທີ່ມັນຮັກສາຮ່ວມກັບ UNDP ປັດຈຸບັນຄຸ້ມຄອງຫຼາຍກວ່າ 110 ປະເທດ.
ສຳລັບຊອບແວທີ່ສ້າງເພື່ອໂຄງການຕ້ານຄວາມທຸກຍາກ — ການໂອນເງິນສົດ, ການຄັດກອງການດູແລສັງຄົມ, ການກຳນົດເປົ້າໝາຍການຊ່ວຍເຫຼືອ —
ຊຸດຕົວຊີ້ວັດຂອງ MPI ມັກເປັນສິ່ງທີ່ໃກ້ເຄີຍທີ່ສຸດກັບແຜນຜັງການຂາດແຄນມາດຕະຖານທີ່ໄດ້ຮັບການກວດສອບໃນຫ້ອງການສະຖິຕິແຫ່ງຊາດຫຼາຍສິບແຫ່ງແລ້ວ.

## ຄະນິດສາດ

```
10 ຕົວຊີ້ວັດ, 3 ມິຕິ, ແຕ່ລະມິຕິມີນ້ຳໜັກ 1/3:

ສຸຂະພາບ (1/3):              ໂພຊະນາການ (1/6), ການເສຍຊີວິດຂອງເດັກ (1/6)
ການສຶກສາ (1/3):             ຈຳນວນປີການຮຽນ (1/6), ການເຂົ້າຮຽນ (1/6)
ມາດຕະຖານການດຳລົງຊີວິດ (1/3): ເຊື້ອໄຟປຸງແຕ່ງອາຫານ, ສຸຂາພິບານ, ນ້ຳດື່ມ,
                              ໄຟຟ້າ, ທີ່ຢູ່ອາໄສ, ຊັບສິນ (ອັນລະ 1/18)

ຄະແນນການຂາດແຄນ (c) = ຜົນລວມນ້ຳໜັກຂອງຕົວຊີ້ວັດທີ່ບຸກຄົນຂາດແຄນ

ບຸກຄົນ "ທຸກຍາກຕາມ MPI" ຖ້າ c ≥ 1/3 (ເກນຄວາມທຸກຍາກ, k = 33%)

H (ອັດຕາສ່ວນຈຳນວນຄົນ) = ຈຳນວນຄົນທຸກຍາກຕາມ MPI / ປະຊາກອນທັງໝົດ
A (ຄວາມເຂັ້ມ)           = ຄະແນນການຂາດແຄນສະເລ່ຍໃນບັນດາຄົນທຸກຍາກຕາມ MPI ເທົ່ານັ້ນ

MPI = H × A
```

ເນື່ອງຈາກ MPI ຄູນ *ສັດສ່ວນ* ຜູ້ທຸກຍາກກັບ *ລະດັບ* ຄວາມທຸກຍາກຂອງເຂົາ, ສອງພາກພື້ນທີ່ມີອັດຕາສ່ວນຈຳນວນຄົນເທົ່າກັນ
ຈຶ່ງສາມາດມີຄະແນນ MPI ແຕກຕ່າງກັນຫຼາຍ ຖ້າການຂາດແຄນຮຸນແຮງກວ່າໃນພາກໜຶ່ງ — ເປັນເຫດຜົນ "ບໍ່ມີການທົດແທນກັນລະຫວ່າງມິຕິ"
ດຽວກັນກັບຄ່າສະເລ່ຍເລຂາຄະນິດຂອງ HDI.

## ຕົວຢ່າງການຄິດໄລ່

**ການສຳຫຼວດແຫ່ງຊາດຂອງ 1,000 ຄົນ**: 350 ຄົນຖືກກຳນົດວ່າທຸກຍາກຫຼາຍມິຕິ (ຄະແນນການຂາດແຄນ ≥ 33%).
ໃນບັນດາ 350 ຄົນທຸກຍາກເຫຼົ່ານັ້ນເທົ່ານັ້ນ, ຄະແນນການຂາດແຄນສະເລ່ຍແມ່ນ 45%.

```
H = 350 / 1000                = 0.350
A = 0.45
MPI = H × A = 0.350 × 0.45    = 0.1575
```

**ປຽບທຽບສອງເມືອງທີ່ມີອັດຕາສ່ວນຈຳນວນຄົນເທົ່າກັນ**: ເມືອງ A ມີ H = 0.30 ແລະ A = 0.40 (ຄົນທຸກຍາກຫຼາຍ, ຂາດແຄນປານກາງ);
ເມືອງ B ມີ H = 0.30 ແລະ A = 0.60 (ຈຳນວນຄົນທຸກຍາກເທົ່າກັນ ແຕ່ຂາດແຄນຮຸນແຮງກວ່າ — ຂາດໄຟຟ້າ *ແລະ* ສຸຂາພິບານ *ແລະ* ການເຂົ້າຮຽນພ້ອມກັນ).

```
MPI_A = 0.30 × 0.40 = 0.120
MPI_B = 0.30 × 0.60 = 0.180
```

ອັດຕາສ່ວນຈຳນວນຄົນເທົ່າກັນ, ແຕ່ MPI ຂອງເມືອງ B ສູງກວ່າ 50% — ລະບົບກຳນົດເປົ້າໝາຍທີ່ອີງໃສ່ຄວາມທຸກຍາກຕາມຈຳນວນຄົນຢ່າງດຽວ
ຈະຈັດອັນດັບສອງເມືອງເທົ່າກັນ ແລະ ພາດວ່າເມືອງ B ຕ້ອງການການແຊກແຊງທີ່ເລິກກວ່າ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

- ລະບົບຈັດການກໍລະນີ ແລະ ລະບົບກວດສອບສິດທິຂອງໂຄງການສັງຄົມມັກເກັບບາງຕົວຊີ້ວັດໃນສິບຕົວນັ້ນໄວ້ແລ້ວ
  (ທີ່ຢູ່ອາໄສ, ການເຂົ້າຮຽນ, ຕົວຊີ້ວັດສຸຂະພາບ) ໃນຊີໂລແຍກກັນ; ວິທີການນັບຂອງ Alkire-Foster ເປັນແຜນຜັງທີ່ພ້ອມໃຊ້
  ສຳລັບລວມພວກມັນເປັນຄະແນນການຂາດແຄນດຽວ ແທນທີ່ຈະສ້າງແບບຈຳລອງໃຫ້ຄະແນນສະເພາະຕັ້ງແຕ່ສູນ.
- ການແຍກຈຳນວນຄົນ/ຄວາມເຂັ້ມ (H × A) ເປັນຮູບແບບທີ່ມີປະໂຫຍດທົ່ວໄປສຳລັບແຜງຄວບຄຸມໃດກໍຕາມທີ່ລາຍງານ
  "ມີຈຳນວນເທົ່າໃດໄດ້ຮັບຜົນກະທົບ" ຄຽງຄູ່ກັບ "ຮຸນແຮງເທົ່າໃດ" — ການຍຸບທັງສອງເປັນຕົວເລກດຽວ ດັ່ງສະຖິຕິອັດຕາຊຸກຊຸມດິບເຮັດ,
  ຈະປິດບັງກໍລະນີທີ່ຕ້ອງການຊັບພະຍາກອນຫຼາຍທີ່ສຸດ.
- ແຜງຄວບຄຸມຕົວຊີ້ວັດແບບ MPI ເຂົ້າກັນໄດ້ດີກັບການລາຍງານ[ຕົ້ນທຶນຕໍ່ຜູ້ໄດ້ຮັບຜົນປະໂຫຍດ](../ຕົ້ນທຶນຕໍ່ຜູ້ໄດ້ຮັບຜົນປະໂຫຍດ/)
  ສຳລັບໂຄງການຕ້ານຄວາມທຸກຍາກ: ຕົ້ນທຶນຕໍ່ຈຸດ MPI ທີ່ຫຼຸດລົງເປັນໜ່ວຍທີ່ປ້ອງກັນໄດ້ສຳລັບປຽບທຽບມາດຕະການແຊກແຊງທີ່ແຕກຕ່າງກັນຫຼາຍ
  (ການໂອນເງິນສົດ ທຽບ ໂຄງລ່າງສຸຂາພິບານ).

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ຖືວ່າສິບຕົວຊີ້ວັດໃຊ້ໄດ້ທົ່ວໂລກ** — ຕົວຊີ້ວັດ MPI ໂລກຂອງ OPHI ຖືກປັບໃຫ້ປຽບທຽບຂ້າມປະເທດໄດ້;
  MPI ແຫ່ງຊາດ (ຫຼາຍປະເທດ, ລວມທັງບາງປະເທດໃນເອເຊຍໃຕ້ ແລະ ອາຟຣິກາ, ເຜີຍແຜ່ຂອງຕົນເອງ) ປັບຕົວຊີ້ວັດ ແລະ ນ້ຳໜັກຕາມບໍລິບົດທ້ອງຖິ່ນ,
  ແລະ ທັງສອງບໍ່ສາມາດປຽບທຽບກັນໂດຍກົງໄດ້.
- **ລາຍງານພຽງ H** — ອັດຕາສ່ວນຈຳນວນຄົນບໍ່ສົນໃຈຄວາມເຂັ້ມເລີຍ; ຕ້ອງລາຍງານ ຫຼື ຄິດໄລ່ A ຄຽງຄູ່ກັບມັນ, ຫຼື ລາຍງານ MPI ເອງ.
- **ສົມມຸດວ່າຄົນທຸກຍາກຕາມ MPI ແລະ ຄົນທຸກຍາກດ້ານລາຍໄດ້ແມ່ນປະຊາກອນກຸ່ມດຽວກັນ** — ບົດສະຫຼຸບລາຍປະເທດຂອງ OPHI ເອງ
  ໂດຍທົ່ວໄປສະແດງການຊ້ອນທັບກັນພຽງບາງສ່ວນ; ໂຄງການທີ່ກຳນົດເປົ້າໝາຍແຕ່ຄົນທຸກຍາກດ້ານລາຍໄດ້ຈະພາດສັດສ່ວນທີ່ສຳຄັນຂອງຄົນທຸກຍາກຫຼາຍມິຕິຢ່າງເປັນລະບົບ.
