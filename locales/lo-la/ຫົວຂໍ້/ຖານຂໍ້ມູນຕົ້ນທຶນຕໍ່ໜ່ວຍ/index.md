# ຖານຂໍ້ມູນຕົ້ນທຶນຕໍ່ໜ່ວຍ

ຖານຂໍ້ມູນຕົ້ນທຶນຕໍ່ໜ່ວຍ (unit cost database) ແມ່ນຄັງຕົວແທນທາງການເງິນ (financial proxy) ທີ່ຄົ້ນຄວ້າໄວ້ລ່ວງໜ້າ ແລະ ອີງຫຼັກຖານ ສຳລັບຜົນລັບທາງສັງຄົມ — ມູນຄ່າຂອງການປ່ຽນຈາກວ່າງງານໄປມີວຽກ, ຂອງຄວາມໂດດດ່ຽວທີ່ຫຼຸດລົງ, ຂອງການເຊົ່າທີ່ໝັ້ນຄົງ — ທີ່ໃຫ້ຜູ້ປະຕິບັດງານຕີຜົນລັບເປັນເງິນໄດ້ ໂດຍບໍ່ຕ້ອງວ່າຈ້າງການຄົ້ນຄວ້າຕີມູນຄ່າສະເພາະທຸກຄັ້ງ. ມັນມີຢູ່ເພື່ອໃຫ້ອົງການການກຸສົນນ້ອຍທີ່ຂຽນຄຳຂໍທຶນນຳໃຊ້ຄວາມເຂັ້ມງວດແບບດຽວກັນກັບບໍລິສັດທີ່ປຶກສາທີ່ມີຊັບພະຍາກອນຫຼາຍ, ໂດຍນຳຕົວແທນທີ່ຄົນອື່ນໄດ້ຄິດຄົ້ນ ແລະ ເຜີຍແຜ່ແລ້ວມາໃຊ້ຊ້ຳ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

UK Social Value Bank ຂອງ HACT, ພັດທະນາກັບນັກເສດຖະສາດ Daniel Fujiwara ໂດຍໃຊ້ວິທີຕີມູນຄ່າຄວາມເປັນຢູ່ທີ່ດີ, ແລະ Global Value Exchange, ຖານຂໍ້ມູນເປີດທີ່ມາຈາກຝູງຊົນຂອງຕົວແທນທາງການເງິນ, ແມ່ນສອງຖານທີ່ໃຊ້ກັນຢ່າງກວ້າງຂວາງທີ່ສຸດໃນພາກສ່ວນທີສາມ ແລະ ພາກລັດຂອງອັງກິດ. ທັງສອງມີຢູ່ກໍເພາະງານຕີມູນຄ່າພື້ນຖານ — [ການຕີມູນຄ່າຄວາມເປັນຢູ່ທີ່ດີ](../ການຕີມູນຄ່າຄວາມເປັນຢູ່ທີ່ດີ/) ແລະ
[ການຕີມູນຄ່າດ້ວຍຄວາມມັກທີ່ລະບຸ](../ການຕີມູນຄ່າດ້ວຍຄວາມມັກທີ່ລະບຸ/) — ມີຄ່າໃຊ້ຈ່າຍສູງ, ຕ້ອງການວິທີວິທະຍາທີ່ເຂັ້ມງວດ, ແລະ ຊ້າໃນການເຮັດຈາກສູນສຳລັບທຸກໂຄງການ. ຄັງຕົວແທນທີ່ເຜີຍແຜ່ ແລະ ໃຊ້ຮ່ວມກັນປ່ຽນສິ່ງທີ່ຈະເປັນການຄົ້ນຄວ້າຫຼາຍເດືອນໃຫ້ເປັນການຄົ້ນຫາ, ເຊິ່ງເປັນເຫດຜົນທີ່ພວກມັນສຳຄັນທັງຕໍ່ການຄິດໄລ່[ຜົນຕອບແທນທາງສັງຄົມຈາກການລົງທຶນ](../ຜົນຕອບແທນທາງສັງຄົມຈາກການລົງທຶນ/) ແລະ ການປະເມີນການປະມູນຕາມ[ກົດໝາຍຄຸນຄ່າທາງສັງຄົມ](../ກົດໝາຍຄຸນຄ່າທາງສັງຄົມ/): ຖ້າບໍ່ມີພວກມັນ, ການຕີມູນຄ່າທີ່ເຂັ້ມງວດຈະຈ່າຍໄດ້ສະເພາະອົງກອນທີ່ໃຫຍ່ພໍທີ່ຈະວ່າຈ້າງການສຶກສາຂອງຕົນເອງ.

## ຄະນິດສາດ

ຖານຂໍ້ມູນຕົ້ນທຶນຕໍ່ໜ່ວຍບໍ່ໄດ້ຄິດໄລ່ຫຍັງດ້ວຍຕົວມັນເອງ; ມັນສະໜອງປັດໄຈນຳເຂົ້າໜຶ່ງໃຫ້ການຄິດໄລ່ທີ່ເຮັດຢູ່ບ່ອນອື່ນ:

```
Financial proxy value = market price, OR shadow price, OR wellbeing valuation,
                         OR stated-preference value
                         for a defined unit of outcome change
                         (e.g. "per person moving from unemployment to employment, per year")

Applied value = number of outcomes achieved × unit proxy value
```

ເບິ່ງ [ລາຄາເງົາ](../ລາຄາເງົາ/) ສຳລັບວິທີທີ່ຕົວແທນຖືກສ້າງເມື່ອບໍ່ມີລາຄາຕະຫຼາດ, ແລະ [ຜົນຕອບແທນທາງສັງຄົມຈາກການລົງທຶນ](../ຜົນຕອບແທນທາງສັງຄົມຈາກການລົງທຶນ/) ສຳລັບວິທີທີ່ມູນຄ່າທີ່ນຳໃຊ້ປ້ອນເຂົ້າອັດຕາສ່ວນຫຼັງການປັບແກ້ deadweight ແລະ ການລະບຸຜົນງານ.

## ຕົວຢ່າງການຄິດໄລ່

**ອົງການການກຸສົນ (SROI ຂອງບໍລິການເປັນເພື່ອນ)**: ລາຍການໃນຖານຂໍ້ມູນຕົ້ນທຶນຕໍ່ໜ່ວຍສຳລັບ "ການຫຼຸດຄວາມໂດດດ່ຽວ" ໃຫ້ຕົວແທນຕົວຢ່າງ £1,100 ຕໍ່ຄົນຕໍ່ປີ. ນຳໃຊ້ກັບຜູ້ໄດ້ຮັບຜົນປະໂຫຍດ 80 ຄົນ: 80 × £1,100 = £88,000 ມູນຄ່າລວມ. ຖ້າຖານຂໍ້ມູນດຽວກັນມີຕົວແທນສຳລັບ "ສຸຂະພາບຈິດທີ່ດີຂຶ້ນ" ທີ່ດຶງຈາກລາຍການສຳຫຼວດຄວາມເປັນຢູ່ທີ່ດີທີ່ຊ້ອນກັນ, ການຊ້ອນທັງສອງຕົວແທນສຳລັບ 80 ຄົນດຽວກັນຈະນັບການປ່ຽນແປງພື້ນຖານອັນດຽວກັນຊ້ຳບາງສ່ວນ — ຖານຂໍ້ມູນສະໜອງຕົວເລກ, ແຕ່ການຫຼີກເວັ້ນການຊ້ອນກັນນີ້ແມ່ນຄວາມຮັບຜິດຊອບຂອງນັກວິເຄາະ.

**ອົງການປົກຄອງທ້ອງຖິ່ນ (SROI ຂອງສະໂມສອນຫາວຽກ)**: ລາຍການໃນຖານຂໍ້ມູນຕົ້ນທຶນຕໍ່ໜ່ວຍສຳລັບ "ການຍ້າຍຈາກວ່າງງານໄປການຈ້າງງານທີ່ຍືນຍົງ" ນຳໃຊ້ກັບຜູ້ເຂົ້າຮ່ວມ 45 ຄົນທີ່ຕົວແທນຕົວຢ່າງ £8,500 ຕໍ່ຄົນຕໍ່ປີ: 45 × £8,500 = £382,500 ມູນຄ່າລວມ, ກ່ອນການປັບແກ້ deadweight ແລະ ການລະບຸຜົນງານທີ່ສະແດງໃນ[ຜົນຕອບແທນທາງສັງຄົມຈາກການລົງທຶນ](../ຜົນຕອບແທນທາງສັງຄົມຈາກການລົງທຶນ/).

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ທີມທີ່ສ້າງເຄື່ອງມືລາຍງານສຳລັບອົງການການກຸສົນ ຫຼື ຜູ້ວ່າຈ້າງໄດ້ປະໂຫຍດຈາກ "ບັນຊີລາຍການຜົນລັບ" ພາຍໃນ — ຕາຕະລາງທີ່ແມັບແຕ່ລະຜົນລັບທີ່ຜະລິດຕະພັນ ຫຼື ບໍລິການອ້າງໄດ້ຢ່າງສົມເຫດສົມຜົນກັບຕົວແທນທີ່ມີຊື່, ຖານຂໍ້ມູນແຫຼ່ງ, ວັນທີເຜີຍແຜ່, ແລະ ຕົວລະບຸເວີຊັນ — ເພື່ອໃຫ້ທີມຕ່າງໆໃນອົງກອນບໍ່ເລືອກຄ່າທີ່ແຕກຕ່າງກັນເລັກນ້ອຍສຳລັບຜົນລັບດຽວກັນ. ການຫໍ່ຂໍ້ມູນເປີດຂອງ Global Value Exchange ໄວ້ຫຼັງບໍລິການຄົ້ນຫາ ໂດຍສະແດງແຫຼ່ງ ແລະ ວັນທີຄຽງຕົວເລກສະເໝີ ຮັກສາຕົວແທນໃຫ້ກວດສອບໄດ້ ແທນທີ່ຈະເປັນຕົວເລກວິເສດທີ່ຝັງໃນສະເປຣດຊີດ. ເບິ່ງ [ຜົນຕອບແທນທາງສັງຄົມຈາກການລົງທຶນ](../ຜົນຕອບແທນທາງສັງຄົມຈາກການລົງທຶນ/) ແລະ
[ກົດໝາຍຄຸນຄ່າທາງສັງຄົມ](../ກົດໝາຍຄຸນຄ່າທາງສັງຄົມ/) ສຳລັບສອງບ່ອນຫຼັກທີ່ຕົວແທນເຫຼົ່ານີ້ຖືກນຳໃຊ້.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ຖືຕົວແທນວ່າແມ່ນຍຳ.** ຕົວແທນທີ່ເຜີຍແຜ່ສ່ວນໃຫຍ່ເປັນຄ່າສະເລ່ຍຈາກແບບຈຳລອງຂອງການສຶກສາການຕີມູນຄ່າຄວາມເປັນຢູ່ທີ່ດີ ທີ່ມີຊ່ວງຄວາມເຊື່ອໝັ້ນກວ້າງ; ການອ້າງຕົວເລກເປັນປອນເປັນການຕີຄວາມແມ່ນຍຳເກີນກວ່າທີ່ການຄົ້ນຄວ້າພື້ນຖານຮອງຮັບ.
- **ນັບຕົວແທນທີ່ຊ້ອນກັນຊ້ຳ.** ການລວມຕົວແທນ (ເຊັ່ນ "ຄວາມໂດດດ່ຽວທີ່ຫຼຸດລົງ" ແລະ "ສຸຂະພາບຈິດທີ່ດີຂຶ້ນ") ທີ່ມາຈາກແນວຄິດການສຳຫຼວດທີ່ຊ້ອນກັນ ຕີມູນຄ່າການປ່ຽນແປງພື້ນຖານອັນດຽວກັນສອງເທື່ອ.
- **ໃຊ້ຕົວແທນນອກບໍລິບົດໂດຍບໍ່ປັບ.** ຕົວແທນທີ່ປັບທຽບໃນປະຊາກອນ ແລະ ປີໜຶ່ງ ແລ້ວນຳໄປໃຊ້ບ່ອນອື່ນໂດຍບໍ່ປັບເງິນເຟີ້ ຫຼື ບໍລິບົດ ຈະລະບຸມູນຄ່າຜິດຢ່າງງຽບໆ.
- **ບໍ່ກວດແຫຼ່ງທີ່ມາ.** Global Value Exchange ເປັນແບບເປີດ ແລະ ມາຈາກຝູງຊົນ, ສະນັ້ນຄຸນນະພາບຂອງລາຍການຕ່າງກັນຕາມຜູ້ປະກອບສ່ວນ; ໃຫ້ກວດແຫຼ່ງພື້ນຖານກ່ອນອ້າງຕົວເລກໃນຄຳຂໍທຶນ ຫຼື ການຍື່ນຈັດຊື້ຈັດຈ້າງ.
