# ການຖ່ວງນ້ຳໜັກດ້ານການກະຈາຍຜົນປະໂຫຍດ

ການຖ່ວງນ້ຳໜັກດ້ານການກະຈາຍຜົນປະໂຫຍດ (distributional weighting) ປັບມູນຄ່າເງິນຂອງຕົ້ນທຶນ ຫຼື ຜົນປະໂຫຍດຕາມຜູ້ທີ່ໄດ້ຮັບ ໂດຍອີງໃສ່ຫຼັກການທີ່ວ່າເງິນຕື່ມອີກໜຶ່ງປອນມີຄ່າຕໍ່ຄົວເຮືອນທີ່ທຸກຍາກຫຼາຍກວ່າຄົວເຮືອນທີ່ຮັ່ງມີ. Green Book ຂອງ HM Treasury ໃຫ້ວິທີການທີ່ຊັດເຈນໃນການຖ່ວງນ້ຳໜັກນີ້ ໂດຍສ້າງຢູ່ເທິງຫຼັກປະໂຫຍດໄດ້ຮັບສ່ວນເພີ່ມທີ່ຫຼຸດລົງຂອງລາຍໄດ້ ເພື່ອບໍ່ໃຫ້ການປະເມີນຄຸນຄ່າ (appraisal) ຖືວ່າເງິນໜຶ່ງປອນທີ່ກຸ່ມຮັ່ງມີທີ່ສຸດ 10% ໄດ້ຮັບ ເທົ່າກັບເງິນໜຶ່ງປອນທີ່ກຸ່ມທຸກຍາກທີ່ສຸດໄດ້ຮັບ ໂດຍບໍ່ຮູ້ຕົວ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ການວິເຄາະຕົ້ນທຶນ-ຜົນປະໂຫຍດມາດຕະຖານລວມເງິນປອນໂດຍບໍ່ຖາມວ່າເປັນເງິນຂອງໃຜ ເຊິ່ງສົມມຸດໂດຍປະລິຍາຍວ່າເງິນໜຶ່ງປອນມີຄ່າເທົ່າກັນສຳລັບທຸກຄົນ — ເປັນສົມມຸດຕິຖານທີ່ນັກເສດຖະສາດຮູ້ມາດົນແລ້ວວ່າບໍ່ຖືກຕ້ອງ. ຄົວເຮືອນທີ່ມີລາຍໄດ້ £15,000/ປີ ຮູ້ສຶກກັບການໄດ້ຮັບ £1,000 ຕ່າງຈາກຄົວເຮືອນທີ່ມີລາຍໄດ້ £150,000/ປີຫຼາຍ ເພາະປະໂຫຍດສ່ວນເພີ່ມຂອງລາຍໄດ້ຫຼຸດລົງເມື່ອລາຍໄດ້ເພີ່ມຂຶ້ນ. ຖ້າບໍ່ຖ່ວງນ້ຳໜັກ ການປະເມີນຄຸນຄ່າມາດຕະຖານຈະເອື້ອປະໂຫຍດຕໍ່ການແຊກແຊງທີ່ເປັນຜົນດີຕໍ່ກຸ່ມທີ່ຮັ່ງມີກວ່າ ແລະ ມີຖານະດີຢູ່ແລ້ວຢ່າງເປັນລະບົບ ເພາະກຳລັງຊື້ທີ່ສູງກວ່າຂອງເຂົາເຈົ້າເຮັດໃຫ້ການປະເມີນມູນຄ່າເປັນເງິນຂອງຜົນປະໂຫຍດທີ່ເຂົ້າເຖິງເຂົາເຈົ້າຖືກຂະຫຍາຍຂຶ້ນ (ການປັບປຸງສວນສາທາລະນະໃກ້ເຮືອນລາຄາແພງ "ສະແດງ" ຜົນປະໂຫຍດດ້ານມູນຄ່າຊັບສິນຫຼາຍກວ່າການປັບປຸງແບບດຽວກັນໃກ້ເຮືອນລາຄາຖືກ ກໍຍ້ອນລາຄາສູງກວ່າເທົ່ານັ້ນ ບໍ່ແມ່ນຍ້ອນຄວາມຢູ່ດີກິນດີທີ່ໄດ້ຮັບຫຼາຍກວ່າ).

ຄຳແນະນຳເສີມຂອງ Green Book ກ່ຽວກັບການວິເຄາະການກະຈາຍຜົນປະໂຫຍດ ເຊິ່ງໄດ້ຮັບການເສີມສ້າງຫຼັງການທົບທວນຂອງ Treasury ປີ 2020 ທີ່ຕອບສະໜອງຕໍ່ຄຳວິຈານວ່າວິທີການປະເມີນຄຸນຄ່າເອື້ອປະໂຫຍດຕໍ່ລອນດອນ ແລະ ພາກຕາເວັນອອກສຽງໃຕ້ຢ່າງເປັນລະບົບ ກຳນົດວິທີຖ່ວງນ້ຳໜັກຢ່າງເປັນທາງການ ໂດຍອີງໃສ່ຄວາມຢືດຢຸ່ນຂອງປະໂຫຍດສ່ວນເພີ່ມຂອງລາຍໄດ້ທີ່ສົມມຸດໄວ້ປະມານ 1.3 — ໝາຍຄວາມວ່າລາຍໄດ້ເພີ່ມເປັນສອງເທົ່າ ມູນຄ່າສ່ວນເພີ່ມຂອງເງິນໜຶ່ງປອນຈະຫຼຸດລົງປະມານເຄິ່ງໜຶ່ງ (ໂດຍສະເພາະ 2^-1.3 ≈ 0.41 ເທົ່າ). ນີ້ບໍ່ແມ່ນການປັບເສດ: ການໃຊ້ມັນສາມາດປ່ຽນໄດ້ວ່າສອງໂຄງການທີ່ແຂ່ງກັນ ໂຄງການໃດຈະມີມູນຄ່າປັດຈຸບັນສຸດທິ (net present value) ສູງກວ່າ ໂດຍສະເພາະເມື່ອທຽບການແຊກແຊງທີ່ເນັ້ນໃນເຂດທຸກຍາກກັບການແຊກແຊງທີ່ກະຈາຍໄປທົ່ວປະຊາກອນທົ່ວໄປ.

## ຄະນິດສາດ

ນ້ຳໜັກການກະຈາຍຜົນປະໂຫຍດຂອງ Green Book ສຳລັບເງິນໜຶ່ງປອນຂອງຜົນປະໂຫຍດທີ່ເຂົ້າສູ່ຄົວເຮືອນທີ່ມີລາຍໄດ້ລະດັບ y ທຽບກັບເງິນໜຶ່ງປອນທີ່ລາຍໄດ້ສະເລ່ຍລະດັບຊາດ ȳ:

```
Weight(y) = (ȳ / y)^e

where:
  y  = household income (or income of the affected group)
  ȳ  = average (reference) household income
  e  = elasticity of marginal utility of income (Green Book: approximately 1.3)
```

ການນຳນ້ຳໜັກໄປໃຊ້ກັບຜົນປະໂຫຍດສຸດທິ:

```
Weighted benefit = Σ [unweighted benefit to group i × Weight(y_i)]
```

ກຸ່ມທີ່ມີລາຍໄດ້ເຄິ່ງໜຶ່ງຂອງສະເລ່ຍລະດັບຊາດ (y = 0.5ȳ) ໄດ້ນ້ຳໜັກ (1/0.5)^1.3 = 2^1.3 ≈ 2.46 — ຜົນປະໂຫຍດທຸກໜຶ່ງປອນທີ່ກຸ່ມນັ້ນໄດ້ຮັບນັບເປັນມູນຄ່າປະມານ 2.46 ເທົ່າຂອງເງິນໜຶ່ງປອນທີ່ຄົວເຮືອນລາຍໄດ້ສະເລ່ຍໄດ້ຮັບ.

## ຕົວຢ່າງການຄິດໄລ່

**ສອງໂຄງການທ້ອງຖິ່ນທີ່ແຂ່ງກັນ** ແຕ່ລະໂຄງການມີຜົນປະໂຫຍດສຸດທິທີ່ບໍ່ຖ່ວງນ້ຳໜັກ £2 ລ້ານ/ປີ ແຂ່ງຂັນກັນຂໍກອງທຶນການເຕີບໂຕຂອງພາກພື້ນດຽວກັນ:

- *ໂຄງການ A*: ໂຄງການສະໜັບສະໜູນທຸລະກິດໃນເມືອງທີ່ຮັ່ງມີ ລາຍໄດ້ສະເລ່ຍຂອງຄົວເຮືອນ £45,000 (ປະມານ 1.3 ເທົ່າຂອງສະເລ່ຍລະດັບຊາດທີ່ສົມມຸດ £35,000).
- *ໂຄງການ B*: ໂຄງການທັກສະໃນເຂດ (ward) ທີ່ທຸກຍາກ ລາຍໄດ້ສະເລ່ຍຂອງຄົວເຮືອນ £18,000 (ປະມານ 0.51 ເທົ່າຂອງສະເລ່ຍລະດັບຊາດ).

```
Weight(A) = (35,000 / 45,000)^1.3 = (0.778)^1.3 ≈ 0.72
Weight(B) = (35,000 / 18,000)^1.3 = (1.944)^1.3 ≈ 2.53

Weighted benefit A = £2,000,000 × 0.72 = £1.44 million
Weighted benefit B = £2,000,000 × 2.53 = £5.06 million
```

ເມື່ອບໍ່ຖ່ວງນ້ຳໜັກ ສອງໂຄງການເທົ່າກັນ. ເມື່ອຖ່ວງນ້ຳໜັກຕາມຜົນກະທົບດ້ານການກະຈາຍ ຜົນປະໂຫຍດຂອງໂຄງການ B ໃຫຍ່ກວ່າຫຼາຍກວ່າສາມເທົ່າ — ຜົນລັບທີ່ປ່ຽນຄຳແນະນຳດ້ານການໃຫ້ທຶນໃຫ້ກົງກັນຂ້າມ ແລະ ສະທ້ອນເຈດຕະນາຂອງ Green Book ທີ່ຕ້ອງການໃຫ້ສະແດງການຖ່ວງນ້ຳໜັກ ບໍ່ແມ່ນພຽງອັດຕາສ່ວນຜົນປະໂຫຍດຕໍ່ຕົ້ນທຶນທີ່ບໍ່ຖ່ວງນ້ຳໜັກ.

**ການຈັດສັນເງິນອຸດໜູນຂອງອົງການກຸສົນ**: ຜູ້ໃຫ້ທຶນທີ່ທຽບເງິນອຸດໜູນ £500,000 ທີ່ເຂົ້າເຖິງ 1,000 ຄົວເຮືອນລາຍໄດ້ຕ່ຳ (ນ້ຳໜັກ ≈ 2.0, ມູນຄ່າຖ່ວງນ້ຳໜັກເທົ່າກັບ £1 ລ້ານ) ກັບ £500,000 ດຽວກັນທີ່ເຂົ້າເຖິງ 1,000 ຄົວເຮືອນລາຍໄດ້ກາງ (ນ້ຳໜັກ ≈ 1.0, ມູນຄ່າຖ່ວງນ້ຳໜັກເທົ່າກັບ £500,000) ຄວນສະແດງເຫດຜົນດ້ານການກະຈາຍຢ່າງຊັດເຈນໃນເອກະສານຄະນະກຳມະການ ບໍ່ແມ່ນປ່ອຍໃຫ້ຜູ້ອ່ານສັນນິຖານເອົາເອງ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ການຖ່ວງນ້ຳໜັກດ້ານການກະຈາຍຜົນປະໂຫຍດບໍ່ຄ່ອຍປາກົດໂດຍກົງໃນຕົວຊີ້ວັດການສົ່ງມອບຊອບແວ ແຕ່ມັນຄວນກຳນົດວິທີທີ່ທີມວິສະວະກຳ ແລະ ຂໍ້ມູນອອກແບບການວັດແທກ ແລະ ການກຳນົດກຸ່ມເປົ້າໝາຍ:

- ເມື່ອສ້າງແດຊບອດຜົນກະທົບ ຫຼື ເຄື່ອງຄິດໄລ່ຜົນປະໂຫຍດ ຄວນສະແດງໂປຣໄຟລ໌ລາຍໄດ້ ຫຼື ຄວາມຂາດແຄນຂອງຜູ້ທີ່ໄດ້ຮັບຜົນກະທົບ ບໍ່ແມ່ນພຽງຍອດລວມຂອງຜົນປະໂຫຍດ — ຕົວເລກລວມທີ່ບໍ່ມີການແຍກຕາມການກະຈາຍຈະເຊື່ອງການກັບດ້ານທີ່ສະແດງຂ້າງເທິງນັ້ນເອງ.
- ເຊື່ອມຕັກກະການກຳນົດເປົ້າໝາຍໃນການອອກແບບບໍລິການເຂົ້າກັບຂໍ້ມູນຄວາມຂາດແຄນດຽວກັນທີ່ Green Book ໃຊ້ — ເບິ່ງ [ດັດຊະນີຄວາມຂາດແຄນຫຼາຍມິຕິ](../ດັດຊະນີຄວາມຂາດແຄນຫຼາຍມິຕິ/) — ເພື່ອໃຫ້ສາມາດປະເມີນການເຂົ້າເຖິງຂອງບໍລິການດິຈິຕອນດ້ານຄວາມເປັນທຳ ບໍ່ແມ່ນພຽງປະສິດທິພາບ (E ທີ່ສີ່ທີ່ຍັງມີຂໍ້ຂັດແຍ້ງໃນ [ຄວາມຄຸ້ມຄ່າເງິນ](../ຄວາມຄຸ້ມຄ່າເງິນ/)).
- ເມື່ອອັນກໍຣິທຶມຈັດສັນຊັບພະຍາກອນທີ່ຫາຍາກ (ຊ່ອງນັດໝາຍ, ເວລາຂອງເຈົ້າໜ້າທີ່ດູແລກໍລະນີ, ເງິນອຸດໜູນ) ຟັງຊັນເປົ້າໝາຍແບບ "ເພີ່ມຜົນປະໂຫຍດລວມໃຫ້ສູງສຸດ" ທີ່ບໍ່ຖ່ວງນ້ຳໜັກ ຈະຜະລິດຊ້ຳຄວາມລຳອຽງດຽວກັນທີ່ການຖ່ວງນ້ຳໜັກຂອງ Green Book ມີຂຶ້ນເພື່ອແກ້ໄຂໂດຍໂຄງສ້າງ — ຄວນແຈ້ງເລື່ອງນີ້ຢ່າງຊັດເຈນຕໍ່ເຈົ້າຂອງນະໂຍບາຍກ່ອນປັບໃຫ້ເໝາະສົມທີ່ສຸດ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ນຳນ້ຳໜັກການກະຈາຍໄປໃຊ້ແບບບໍ່ສອດຄ່ອງໃນພອດໂຟລິໂອ.** ການຖ່ວງນ້ຳໜັກຜົນປະໂຫຍດຂອງໂຄງການໜຶ່ງ ແຕ່ບໍ່ຖ່ວງຂອງໂຄງການທຽບ ໃຫ້ການທຽບທີ່ລຳອຽງ ບໍ່ແມ່ນທີ່ເປັນທຳກວ່າ; Green Book ກຳນົດໃຫ້ປະຕິບັດຕໍ່ກັນແບບເທົ່າທຽມ.
- **ໃຊ້ມູນຄ່າຊັບສິນ ຫຼື ມູນຄ່າຕະຫຼາດເປັນຕົວແທນຄວາມຢູ່ດີກິນດີໂດຍບໍ່ປັບ.** ລາຄາຕະຫຼາດເອງຖືກບິດເບືອນດ້ວຍຄວາມບໍ່ເທົ່າທຽມຂອງລາຍໄດ້ທີ່ມີຢູ່ ເຊິ່ງເປັນສິ່ງທີ່ການຖ່ວງນ້ຳໜັກຖືກອອກແບບມາແກ້ໄຂ — ການໃຊ້ມູນຄ່າຕະຫຼາດທີ່ບໍ່ປັບອາດນັບຄວາມລຳອຽງຊ້ຳສອງຄັ້ງ.
- **ບໍ່ສົນໃຈຄວາມແຕກຕ່າງພາຍໃນກຸ່ມ.** ການຖ່ວງນ້ຳໜັກດ້ວຍລາຍໄດ້ສະເລ່ຍຂອງພື້ນທີ່ (ເຊັ່ນ ເດຊິລຂອງດັດຊະນີຄວາມຂາດແຄນຫຼາຍມິຕິ) ອາດສະທ້ອນບຸກຄົນທີ່ບໍ່ກົງກັບສະເລ່ຍຂອງພື້ນທີ່ຜິດ; ຄວນໃຊ້ຂໍ້ມູນລາຍໄດ້ທີ່ລະອຽດທີ່ສຸດເທົ່າທີ່ເໝາະສົມ.
- **ຖືຄວາມຢືດຢຸ່ນ 1.3 ເປັນຄ່າຄົງທີ່ທົ່ວໄປ.** Green Book ເອງລະບຸວ່ານີ້ເປັນການຄາດຄະເນທີ່ມີຊ່ວງທີ່ເປັນໄປໄດ້; ຄວນທົດສອບຄວາມອ່ອນໄຫວຂອງການຕັດສິນໃຈສຳຄັນກັບຄ່າຄວາມຢືດຢຸ່ນທາງເລືອກ ແທນທີ່ຈະຖື 1.3 ເປັນຄ່າແນ່ນອນ.
