# ການລາຍງານຜົນລັບຂອງທຶນອຸດໜູນ (IRIS+)

ການລາຍງານຜົນລັບຂອງທຶນອຸດໜູນ (grant outcomes reporting) ແມ່ນການປະຕິບັດທີ່ຜູ້ຮັບທຶນລາຍງານຕົວຊີ້ວັດຜົນລັບມາດຕະຖານ ແລະ ທຽບກັນໄດ້ກັບຜູ້ໃຫ້ທຶນ — ກົງກັນຂ້າມກັບການທີ່ຜູ້ໃຫ້ທຶນແຕ່ລະຄົນປະດິດແບບຟອມລາຍງານສະເພາະຂອງຕົນເອງ. IRIS+ ທີ່ບຳລຸງຮັກສາໂດຍ Global Impact Investing Network (GIIN) ເປັນມາດຕະຖານດັ່ງກ່າວທີ່ນຳໃຊ້ກວ້າງຂວາງທີ່ສຸດ: ລາຍການຕົວຊີ້ວັດຜົນງານດ້ານສັງຄົມ, ສິ່ງແວດລ້ອມ ແລະ ການເງິນທີ່ກຳນົດໄວ້ລ່ວງໜ້າ ເຊິ່ງນັກລົງທຶນເພື່ອຜົນກະທົບ ແລະ ມູນນິທິໃຫ້ທຶນອຸດໜູນຫຼາຍຂຶ້ນເລື້ອຍໆກຳນົດ ຫຼື ແນະນຳໃຫ້ຜູ້ຮັບທຶນໃຊ້.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ກ່ອນມີການລາຍງານມາດຕະຖານ ທຸກມູນນິທິຂໍຕົວຊີ້ວັດຕ່າງກັນຈາກຜູ້ຮັບທຶນໃນຮູບແບບຕ່າງກັນ ແລະ ອົງການກຸສົນຂະໜາດກາງທີ່ມີຜູ້ໃຫ້ທຶນສິບຄົນອາດດຳເນີນຂະບວນການລາຍງານຂະໜານສິບຂະບວນການສຳລັບວຽກທີ່ຊ້ອນກັນ — ສາເຫດຂອງພາລະການລາຍງານທີ່ມີເອກະສານບັນທຶກດີ ເຊິ່ງການເຮັດມາດຕະຖານຜົນລັບຂອງທຶນອຸດໜູນມີຂຶ້ນເພື່ອຫຼຸດ. IRIS+ ແກ້ເລື່ອງນີ້ໂດຍໃຫ້ຜູ້ໃຫ້ທຶນ ແລະ ຜູ້ຮັບທຶນມີຄຳສັບຮ່ວມກັນ: ຊຸດຕົວຊີ້ວັດຫຼັກ (Core Metrics Sets) ຈັດກຸ່ມຕາມຫົວຂໍ້ (ເຊັ່ນ ທີ່ຢູ່ອາໄສລາຄາຖືກ, ການເຂົ້າເຖິງພະລັງງານສະອາດ, ການລວມທາງການເງິນ) ແຕ່ລະຕົວຊີ້ວັດຖືກກຳນົດຢ່າງຊັດເຈນພໍທີ່ "ວຽກທີ່ສ້າງ" ຫຼື "ຄົວເຮືອນທີ່ໄດ້ຮັບບໍລິການ" ມີຄວາມໝາຍດຽວກັນບໍ່ວ່າໃຜລາຍງານ ແລະ ສອດຄ່ອງກັບເປົ້າໝາຍການພັດທະນາແບບຍືນຍົງຂອງ UN ເພື່ອໃຫ້ຜູ້ໃຫ້ທຶນລວມຂໍ້ມູນລະດັບຜູ້ຮັບທຶນຂຶ້ນເປັນເລື່ອງເລົ່າ SDG ລະດັບພອດໂຟລິໂອໄດ້. GIIN ລາຍງານວ່າຕົວຊີ້ວັດ IRIS ຖືກໃຊ້ໂດຍປະມານເຄິ່ງໜຶ່ງຂອງນັກລົງທຶນເພື່ອຜົນກະທົບ ແລະ ສ່ວນໃຫຍ່ຂອງຜູ້ຈັດການກອງທຶນ, ທະນາຄານ ແລະ ສະຖາບັນການເງິນເພື່ອການພັດທະນາທີ່ເຄື່ອນໄຫວໃນສາຂານີ້.

ມາດຕະຖານນີ້ສຳຄັນທີ່ສຸດບ່ອນທີ່ມັນພົວພັນກັບ [ຜົນລັບ ທຽບ ຜົນຜະລິດ](../ຜົນລັບ-ທຽບ-ຜົນຜະລິດ/): IRIS+ ຜັກດັນການລາຍງານໄປສູ່ຕົວຊີ້ວັດຜົນລັບ ແລະ ຜົນກະທົບທີ່ກຳນົດໄວ້ ແທນທີ່ຈະເປັນສິ່ງໃດກໍຕາມທີ່ລະບົບຈັດການກໍລະນີຂອງຜູ້ຮັບທຶນບັນທຶກໄວ້ ເຊິ່ງເປັນຊ່ອງຫວ່າງທີ່ [ຕົ້ນທຶນຕໍ່ຜົນລັບ](../ຕົ້ນທຶນຕໍ່ຜົນໄດ້ຮັບ/) ທຽບກັບ [ຕົ້ນທຶນຕໍ່ຜູ້ໄດ້ຮັບຜົນປະໂຫຍດ](../ຕົ້ນທຶນຕໍ່ຜູ້ໄດ້ຮັບຜົນປະໂຫຍດ/) ອະທິບາຍ.

## ຄະນິດສາດ

ການລາຍງານຜົນລັບຂອງທຶນອຸດໜູນເປັນກອບ ແລະ ຂະບວນການ ບໍ່ແມ່ນສູດຄຳນວນ:

```
1. Funder selects a Core Metrics Set relevant to the grant's theme
   (e.g. IRIS+ "Financial Inclusion" or "Sustainable Agriculture")
2. Each metric has a fixed definition, unit, and calculation method
   published by GIIN — not invented per-funder
3. Grantee reports against the same metric definitions across all
   its funders using that standard, cutting duplicate reporting effort
4. Funder aggregates grantee-level metrics into portfolio-level reporting,
   comparable year over year and across grantees using the same metric
```

ການໄດ້ຮັບປະສິດທິພາບເປັນແບບຮວມກັນ: ການເຮັດມາດຕະຖານຜູ້ໃຫ້ທຶນ N × ຜູ້ຮັບທຶນ M ໃຫ້ຢູ່ໃນຄຳສັບຮ່ວມດຽວ ປ່ຽນຄວາມສຳພັນການລາຍງານສະເພາະ N×M ເປັນການແຜນທີ່ປະມານ N+M ເຂົ້າກັບມາດຕະຖານດຽວ.

## ຕົວຢ່າງການຄິດໄລ່

**ຜູ້ຮັບທຶນທີ່ມີຜູ້ໃຫ້ທຶນສາມຄົນ ກ່ອນມີມາດຕະຖານ**: ລາຍງານ "ຜູ້ໄດ້ຮັບບໍລິການ" ໃຫ້ຜູ້ໃຫ້ທຶນ 1 ດ້ວຍນິຍາມນັບຫົວຄົນ, "ຜູ້ໄດ້ຮັບຜົນປະໂຫຍດທີ່ເຂົ້າເຖິງ" ໃຫ້ຜູ້ໃຫ້ທຶນ 2 ດ້ວຍນິຍາມຄົວເຮືອນ ແລະ "ບຸກຄົນທີ່ໄດ້ຮັບຜົນກະທົບ" ໃຫ້ຜູ້ໃຫ້ທຶນ 3 ດ້ວຍນິຍາມຕອນບໍລິການ (ດັ່ງນັ້ນຄົນໜຶ່ງມາສອງຄັ້ງນັບສອງຄັ້ງ). ສາມລາຍງານ, ສາມຕົວເລກ, ບໍ່ມີອັນໃດທຽບກັນໄດ້ ແລະ ບໍ່ມີອັນໃດທຽບກັບຕົວເລກຂອງຜູ້ຮັບທຶນອື່ນໄດ້ ເຖິງແມ່ນພາຍໃນພອດໂຟລິໂອຂອງຜູ້ໃຫ້ທຶນດຽວກັນ.

**ຜູ້ຮັບທຶນດຽວກັນພາຍໃຕ້ IRIS+**: ລາຍງານຕາມຕົວຊີ້ວັດ IRIS+ ບຸກຄົນທີ່ເຂົ້າເຖິງທີ່ກຳນົດໄວ້ ພ້ອມກັບຕົວຊີ້ວັດຜົນລັບທີ່ກຳນົດໄວ້ຈາກຊຸດຕົວຊີ້ວັດຫຼັກທີ່ກ່ຽວຂ້ອງ ໂດຍໃຊ້ວິທີການຄິດໄລ່ທີ່ GIIN ເຜີຍແຜ່ສຳລັບທັງສອງ. ຜູ້ໃຫ້ທຶນທັງສາມໄດ້ຮັບຕົວເລກດຽວກັນ ຄິດໄລ່ດ້ວຍວິທີດຽວກັນ ແລະ ສາມາດທຽບຕົ້ນທຶນຕໍ່ໜ່ວຍທີ່ກຳນົດດ້ວຍ IRIS+ ຂອງຜູ້ຮັບທຶນນີ້ກັບຜູ້ຮັບທຶນອື່ນໃນພອດໂຟລິໂອຂອງຕົນ ໂດຍໃຊ້ຕົວຊີ້ວັດດຽວກັນ — ເທົ່າກັບ ໃນລະດັບໂຄງສ້າງພື້ນຖານການລາຍງານ ການມີ [ຖານຂໍ້ມູນຕົ້ນທຶນຕໍ່ໜ່ວຍ](../ຖານຂໍ້ມູນຕົ້ນທຶນຕໍ່ໜ່ວຍ/) ຮ່ວມກັນ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ແພລດຟອມຈັດການທຶນອຸດໜູນຄວນຖືຕົວລະບຸຕົວຊີ້ວັດ IRIS+ ເປັນຄີຕ່າງປະເທດ (foreign key) ບໍ່ແມ່ນຂໍ້ຄວາມອິດສະຫຼະ: ການເກັບລະຫັດຕົວຊີ້ວັດທີ່ເຜີຍແຜ່ໄວ້ຄຽງຄູ່ກັບຄ່າທີ່ຜູ້ຮັບທຶນລາຍງານ (ແທນທີ່ຈະເປັນຊ່ອງທີ່ປະດິດໃນທ້ອງຖິ່ນຊື່ "beneficiaries") ເປັນສິ່ງທີ່ເຮັດໃຫ້ການລວມຂ້າມຜູ້ໃຫ້ທຶນ ແລະ ຂ້າມພອດໂຟລິໂອເປັນໄປໄດ້ໃນພາຍຫຼັງໂດຍບໍ່ຕ້ອງມີໂຄງການທຳຄວາມສະອາດຂໍ້ມູນ. ເມື່ອແພລດຟອມຕ້ອງສະໜັບສະໜູນຜູ້ໃຫ້ທຶນທີ່ຍັງບໍ່ໄດ້ນຳ IRIS+ ມາໃຊ້ ການອອກແບບທີ່ເປັນຈິງແມ່ນໃຫ້ຕົວຊີ້ວັດທ້ອງຖິ່ນຖືກແຜນທີ່ໄປຫານິຍາມ IRIS+ ທີ່ໃກ້ທີ່ສຸດ ແທນທີ່ຈະບັງຄັບທຸກຜູ້ໃຫ້ທຶນເຂົ້າສູ່ມາດຕະຖານທັນທີ — ການທຽບກັນໄດ້ປັບປຸງເທື່ອລະກ້າວເມື່ອກຣາຟຖືກແຜນທີ່ເຂົ້າກັບຕົວລະບຸຮ່ວມຫຼາຍຂຶ້ນ. ເບິ່ງຫົວຂໍ້ໃກ້ຄຽງ [ຕົ້ນທຶນຕໍ່ຜົນລັບ](../ຕົ້ນທຶນຕໍ່ຜົນໄດ້ຮັບ/) ສຳລັບສິ່ງທີ່ຕົວເລກທີ່ລາຍງານຄວນຖືກໃຊ້ຄິດໄລ່ເມື່ອເກັບໄດ້ແລ້ວ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ຖືການນຳ IRIS+ ມາໃຊ້ວ່າທຽບກັນໄດ້ໂດຍອັດຕະໂນມັດ.** ຜູ້ຮັບທຶນສອງຄົນສາມາດລາຍງານຕາມຕົວຊີ້ວັດ IRIS+ ດຽວກັນ ແຕ່ຍັງທຽບກັນບໍ່ໄດ້ຖ້າຄຸນນະພາບຂໍ້ມູນພື້ນຖານ ຫຼື ສົມມຸດຕິຖານສະຖານະການທຽບຄຽງຕ່າງກັນ; ມາດຕະຖານກຳນົດນິຍາມ ບໍ່ແມ່ນຄວາມເຂັ້ມງວດຂອງການວັດແທກ.
- **ຕົວຊີ້ວັດ "ສອດຄ່ອງກັບ IRIS" ທີ່ຜູ້ໃຫ້ທຶນປະດິດ.** ຕົວຊີ້ວັດທີ່ພຽງໄດ້ແຮງບັນດານໃຈຈາກພາສາ IRIS+ ແຕ່ບໍ່ແມ່ນນິຍາມທີ່ເຜີຍແຜ່ຈິງ ນຳການແຕກແຍກທີ່ມາດຕະຖານມີເພື່ອແກ້ກັບມາໃໝ່.
- **ຄວາມເມື່ອຍລ້າຈາກການລາຍງານຍ້ອນເລືອກຫຼາຍເກີນ.** ການຮຽກຮ້ອງໃຫ້ຜູ້ຮັບທຶນລາຍງານຕາມຊຸດຕົວຊີ້ວັດຫຼັກທັງຊຸດ ທັງທີ່ມີພຽງສອງສາມຕົວຊີ້ວັດທີ່ກ່ຽວຂ້ອງກັບການຕັດສິນໃຈ ສ້າງບັນຫາພາລະຄືນໃນຫໍ່ມາດຕະຖານ.
- **ບໍ່ມີຕົວຊີ້ວັດຜົນລັບເລີຍ.** IRIS+ ມີຕົວຊີ້ວັດຜົນຜະລິດລ້ວນໆຫຼາຍຕົວ (ເຊັ່ນ ການນັບຜູ້ໄດ້ຮັບບໍລິການ); ການເລືອກສະເພາະເຫຼົ່ານັ້ນ ແລະ ບໍ່ເລືອກຕົວຊີ້ວັດຊັ້ນຜົນລັບເລີຍ ໃຫ້ການລາຍງານແບບ [ຕົ້ນທຶນຕໍ່ຜູ້ໄດ້ຮັບຜົນປະໂຫຍດ](../ຕົ້ນທຶນຕໍ່ຜູ້ໄດ້ຮັບຜົນປະໂຫຍດ/) ພາຍໃຕ້ປ້າຍການລາຍງານຜົນລັບ.
