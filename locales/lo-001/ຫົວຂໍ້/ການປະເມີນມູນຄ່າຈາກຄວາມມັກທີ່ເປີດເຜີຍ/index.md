# ການປະເມີນມູນຄ່າຈາກຄວາມມັກທີ່ເປີດເຜີຍ

ວິທີການຄວາມມັກທີ່ເປີດເຜີຍ (revealed preference) ສະຫຼຸບມູນຄ່າຂອງສິ່ງດີທີ່ບໍ່ແມ່ນຕະຫຼາດຈາກພຶດຕິກຳທີ່ສັງເກດໄດ້ໃນຕະຫຼາດທີ່ກ່ຽວຂ້ອງ,
ແທນທີ່ຈະຖາມຄົນໂດຍກົງ. ການກຳນົດລາຄາແບບ hedonic ແລະ ວິທີຕົ້ນທຶນການເດີນທາງແມ່ນສອງເຕັກນິກຫຼັກ:
ທັງສອງເລີ່ມຈາກທຸລະກຳຈິງ ແລະ ຖອດລາຄາທີ່ແຝງຢູ່ຂອງສິ່ງທີ່ບໍ່ເຄີຍຖືກຂາຍໂດຍກົງ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ໃນຂະນະທີ່ວິທີ[ຄວາມມັກທີ່ລະບຸ](../ການຕີມູນຄ່າດ້ວຍຄວາມມັກທີ່ລະບຸ/)ຖາມຄຳຖາມສົມມຸດ,
ວິທີຄວາມມັກທີ່ເປີດເຜີຍສັງເກດສິ່ງທີ່ຄົນຈ່າຍຈິງ, ເຊິ່ງ Green Book ຖືວ່າເປັນຫຼັກຖານທີ່ໜ້າເຊື່ອຖືກວ່າໂດຍທົ່ວໄປ, ເມື່ອປັດໄຈອື່ນເທົ່າກັນ, ເພາະມັນບໍ່ຖືກຜົນກະທົບຈາກຄວາມລຳອຽງແບບສົມມຸດ —
ຜູ້ຕອບໃນການສຶກສາລາຄາເຮືອນແບບ hedonic ໄດ້ຈ່າຍສ່ວນເພີ່ມ ຫຼື ສ່ວນຫຼຸດທີ່ກຳລັງວັດແທກຈິງ
(<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>,
Annex 2). ການກຳນົດລາຄາແບບ hedonic ແຍກລາຄາຕະຫຼາດ — ໂດຍທົ່ວໄປແມ່ນລາຄາເຮືອນ — ເປັນລາຄາແຝງ
ສຳລັບແຕ່ລະຄຸນລັກສະນະຂອງສິ່ງດີນັ້ນ, ເຮັດໃຫ້ນັກວິເຄາະແຍກ, ຕົວຢ່າງ, ສ່ວນເພີ່ມລາຄາທີ່ຄົວເຮືອນຈ່າຍຈິງ
ເພື່ອຢູ່ບ່ອນທີ່ງຽບກວ່າ ຫຼື ມີຄຸນນະພາບອາກາດດີກວ່າ, ໂດຍຄວບຄຸມທາງສະຖິຕິຕໍ່
ທຸກຄຸນລັກສະນະອື່ນທີ່ກະທົບລາຄາເຮືອນ (ຂະໜາດ, ທຳເລ, ເຂດໂຮງຮຽນ). ວິທີຕົ້ນທຶນການເດີນທາງ
ເຮັດສິ່ງທຽບເທົ່າສຳລັບສະຖານທີ່ພັກຜ່ອນທີ່ບໍ່ມີຄ່າເຂົ້າ: ເວລາ ແລະ ເງິນທີ່ຄົນໃຊ້ເດີນທາງໄປສະຖານທີ່ເປີດເຜີຍຂອບລຸ່ມຂອງມູນຄ່າສະຖານທີ່ນັ້ນສຳລັບພວກເຂົາ,
ເພາະບໍ່ມີໃຜຍອມຮັບຕົ້ນທຶນທີ່ສູງກວ່າມູນຄ່າຂອງການເຂົ້າຊົມສຳລັບຕົນເອງ.

ທັງສອງວິທີມີຂໍ້ຈຳກັດໂຄງສ້າງຮ່ວມກັນ: ມັນສາມາດປະເມີນມູນຄ່າໄດ້ແຕ່ສິ່ງທີ່ຝັງໃນທຸລະກຳຕະຫຼາດທີ່ມີຢູ່. ສຽງລົບກວນໃກ້ທາງຂຶ້ນລົງເຮືອບິນປາກົດໃນລາຄາເຮືອນ ເພາະຄົນທີ່ສົນໃຈສຽງ
ຄັດເລືອກເຮືອນທີ່ງຽບກວ່າ; ມູນຄ່າການມີຢູ່ຂອງຊະນິດພັນທີ່ບໍ່ມີໃຜໄປເບິ່ງ ຫຼື ຢູ່ໃກ້ບໍ່ປາກົດໃນທຸລະກຳໃດໆເລີຍ,
ເຊິ່ງແມ່ນຊ່ອງຫວ່າງທີ່ວິທີ[ຄວາມມັກທີ່ລະບຸ](../ການຕີມູນຄ່າດ້ວຍຄວາມມັກທີ່ລະບຸ/)ມີຂຶ້ນເພື່ອເຕີມ.

## ຄະນິດສາດ

```
ການກຳນົດລາຄາແບບ hedonic:
  ລາຄາເຮືອນ = f(ຄຸນລັກສະນະໂຄງສ້າງ, ຄຸນລັກສະນະທຳເລ,
                   ຄຸນລັກສະນະສິ່ງແວດລ້ອມທີ່ສົນໃຈ, ...)
  ຄາດຄະເນດ້ວຍການຖົດຖອຍ; ສຳປະສິດຂອງຄຸນລັກສະນະສິ່ງແວດລ້ອມ
  (ຖືປັດໄຈອື່ນຄົງທີ່) ແມ່ນລາຄາແຝງຂອງມັນ.

  ລາຄາແຝງຂອງຄຸນລັກສະນະ X = ∂(ລາຄາເຮືອນ) / ∂X

ວິທີຕົ້ນທຶນການເດີນທາງ:
  ອັດຕາການເຂົ້າຊົມ (ການເຂົ້າຊົມຕໍ່ຫົວຄົນຈາກເຂດ i) = f(ຕົ້ນທຶນການເດີນທາງຈາກເຂດ i,
                   ສະຖານທີ່ທົດແທນ, ຕົວຄວບຄຸມທາງເສດຖະກິດສັງຄົມ)
  ຄາດຄະເນເສັ້ນໂຄ້ງຄວາມຕ້ອງການການເຂົ້າຊົມເປັນຟັງຊັນຂອງຕົ້ນທຶນການເດີນທາງ.
  ສ່ວນເກີນຂອງຜູ້ບໍລິໂພກ = ພື້ນທີ່ໃຕ້ເສັ້ນໂຄ້ງຄວາມຕ້ອງການທີ່ຄາດຄະເນ
                    = ມູນຄ່າຂອງສະຖານທີ່ສຳລັບຜູ້ເຂົ້າຊົມ
```

ທັງສອງວິທີຕ້ອງການຊຸດຕົວຄວບຄຸມທີ່ຖືກຕ້ອງທາງສະຖິຕິ — ການລະເວັ້ນຄຸນລັກສະນະທີ່ສັບສົນ
(hedonic) ຫຼື ສະຖານທີ່ທົດແທນໃກ້ຄຽງ (ຕົ້ນທຶນການເດີນທາງ) ເຮັດໃຫ້ລາຄາແຝງລຳອຽງໄປໃນທິດທາງທີ່
ບໍ່ແຈ້ງລ່ວງໜ້າສະເໝີໄປ, ເຊິ່ງເປັນເຫດຜົນທີ່ Annex 2 ຂອງ Green Book ກຳນົດໃຫ້ລາຍງານການກຳນົດແບບຈຳລອງຖົດຖອຍ ແລະ ຕົວຄວບຄຸມ, ບໍ່ແມ່ນພຽງສຳປະສິດຫົວຂໍ້.

## ຕົວຢ່າງການຄິດໄລ່

**ລັດຖະບານແຫ່ງຊາດ**: ວິທີການລາຄາເງົາຂອງຄາບອນໃນ Green Book ເອງດຶງຈາກຫຼັກຖານ hedonic ບາງສ່ວນ,
ແຕ່ກໍລະນີຕົວຢ່າງທີ່ງ່າຍກວ່າແມ່ນສຽງເຮືອບິນ. ການສຶກສາ hedonic ທີ່ຖົດຖອຍລາຄາຂາຍເຮືອນ
ໃນເຂດເສັ້ນທາງບິນຕໍ່ການສຳຜັດສຽງຖ່ວງນ້ຳໜັກຕາມໄລຍະທາງ, ຄວບຄຸມຂະໜາດ, ອາຍຸ, ແລະ ເຂດໂຮງຮຽນ, ພົບວ່າທຸກເດຊິເບນເພີ່ມຂຶ້ນ 1 ໃນການສຳຜັດສຽງສະເລ່ຍ
ສຳພັນກັບລາຄາເຮືອນຫຼຸດລົງ 0.5%. ສຳລັບເຮືອນທົ່ວໄປ £280,000 ໃນເຂດທີ່ໄດ້ຮັບຜົນກະທົບ:

```
ລາຄາແຝງຕໍ່ເດຊິເບນ = £280,000 × 0.5% = £1,400 ຕໍ່ຄົວເຮືອນ
ຄົວເຮືອນທີ່ໄດ້ຮັບຜົນກະທົບຈາກການເພີ່ມ 3dB ຈາກທາງຂຶ້ນລົງໃໝ່ = 18,000
ຕົ້ນທຶນຮວມທີ່ຫຍໍ້ມາຂອງສຽງທີ່ເພີ່ມຂຶ້ນ = £1,400 × 3 × 18,000 = £75.6m
```

ນີ້ແມ່ນຕົ້ນທຶນທີ່ຖືກຄິດເປັນທຶນຄັ້ງດຽວ (ຝັງໃນລາຄາເຮືອນ), ເຊິ່ງການປະເມີນຕ້ອງລະມັດລະວັງບໍ່ໃຫ້
ນັບຊ້ຳກັບກະແສຕົ້ນທຶນຄວາມລຳຄານຈາກສຽງປະຈຳປີທີ່ຄາດຄະເນແຍກຕ່າງຫາກ.

**ອົງການການກຸສົນ**: ອົງການການກຸສົນດ້ານສິ່ງແວດລ້ອມໃຊ້ວິທີຕົ້ນທຶນການເດີນທາງເພື່ອປະເມີນມູນຄ່າເຂດສະຫງວນທຳມະຊາດທີ່ເຂົ້າໄດ້ຟຣີ.
ຂໍ້ມູນສຳຫຼວດລະຫັດໄປສະນີຂອງຜູ້ເຂົ້າຊົມໃຫ້ຕົ້ນທຶນການເດີນທາງໄປກັບສະເລ່ຍ (ເວລາມີມູນຄ່າຕາມ
ມູນຄ່າເວລາທີ່ບໍ່ແມ່ນການເຮັດວຽກທີ່ Green Book ແນະນຳ, ບວກນ້ຳມັນ) £14 ຕໍ່ການເຂົ້າຊົມ, ມີການເຂົ້າຊົມ 40,000 ຄັ້ງຕໍ່
ປີ. ເສັ້ນໂຄ້ງຄວາມຕ້ອງການທີ່ຄາດຄະເນ — ອັດຕາການເຂົ້າຊົມຫຼຸດລົງເມື່ອຕົ້ນທຶນການເດີນທາງຈາກເຂດສູງຂຶ້ນ — ສະແດງເຖິງ
ສ່ວນເກີນຂອງຜູ້ບໍລິໂພກຕໍ່ການເຂົ້າຊົມ, ສູງກວ່າ £14 ທີ່ຈ່າຍຈິງ, ປະມານ £9.

```
ມູນຄ່າລວມປະຈຳປີ = 40,000 ການເຂົ້າຊົມ × (£14 ທີ່ຈ່າຍ + £9 ສ່ວນເກີນຜູ້ບໍລິໂພກ)
                    = 40,000 × £23 ≈ £920,000/ປີ
```

ນີ້ໃຫຍ່ກວ່າລາຍຮັບຄ່າເຂົ້າສູນຂອງເຂດສະຫງວນຫຼາຍ ແລະ ໃຫ້ຄະນະຜູ້ຄຸ້ມຄອງຂອງອົງການການກຸສົນມີຕົວເລກທີ່ປ້ອງກັນໄດ້
ສຳລັບມູນຄ່າການພັກຜ່ອນຂອງສະຖານທີ່ເມື່ອສະເໜີກໍລະນີຕໍ່ຜູ້ໃຫ້ທຶນ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ແນວຄິດຄວາມມັກທີ່ເປີດເຜີຍປາກົດໃນການວິເຄາະຜະລິດຕະພັນຂອງພາກລັດຫຼາຍກວ່າທີ່ຜູ້ປະຕິບັດຮູ້: ຂໍ້ມູນການນຳໃຊ້ຈາກບໍລິການດິຈິຕອນຂອງລັດຖະບານທີ່ບໍ່ເສຍຄ່າເອງ
ເປັນຫຼັກຖານຄວາມມັກທີ່ເປີດເຜີຍຂອງມູນຄ່າ (ຄວາມຖີ່, ຄວາມຍາວຂອງເຊສຊັນ, ແລະ — ໜ້າສັງເກດທີ່ສຸດ —
ຮູບແບບການນຳໃຊ້ຊ້ຳທຽບກັບຄັ້ງດຽວສາມາດວິເຄາະໄດ້ແບບດຽວກັບທີ່ແບບຈຳລອງຕົ້ນທຶນການເດີນທາງຖືຄວາມຖີ່ການເຂົ້າຊົມທຽບກັບໄລຍະທາງ).
ບ່ອນທີ່ບໍລິການມີສິ່ງທົດແທນແທ້ (ຊ່ອງທາງເຈ້ຍ, ສາຍໂທລະສັບ), "ຕົ້ນທຶນ" ທີ່ພົນລະເມືອງຮັບເພື່ອໃຊ້ຊ່ອງທາງດິຈິຕອນແທນ (ເວລາ, ຂໍ້ມູນ, ອຸປະກອນ)
ສາມາດຄາດຄະເນ ແລະ ປຽບທຽບກັບການນຳໃຊ້, ສະທ້ອນເຫດຜົນຕົ້ນທຶນການເດີນທາງໂດຍກົງ. ເບິ່ງ
[ມາດຕະຖານບໍລິການດິຈິຕອນ](../ມາດຕະຖານການບໍລິການດິຈິຕອນ/) ແລະ
[ມູນຄ່າຂອງຂໍ້ມູນເປີດ](../ມູນຄ່າຂອງຂໍ້ມູນເປີດ/), ເຊິ່ງປະເຊີນບັນຫາການປະເມີນມູນຄ່າແບບດຽວກັນສຳລັບສິ່ງດີທີ່
ບໍ່ມີລາຄາຕະຫຼາດໂດຍກົງ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ຄວາມລຳອຽງຕົວແປທີ່ຖືກລະເວັ້ນໃນແບບຈຳລອງ hedonic.** ການລະເວັ້ນຄຸນລັກສະນະທີ່ສຳພັນກັນ (ຄຸນນະພາບໂຮງຮຽນ
  ທີ່ສຳພັນທັງກັບລາຄາເຮືອນ ແລະ ຕົວແປສິ່ງແວດລ້ອມທີ່ສົນໃຈ) ເຮັດໃຫ້ການຄາດຄະເນລາຄາແຝງລຳອຽງ;
  ຕ້ອງລາຍງານ ແລະ ກວດສອບການກຳນົດແບບຈຳລອງ, ບໍ່ແມ່ນພຽງຜົນລັບ.
- **ເມີນເສີຍສະຖານທີ່ທົດແທນໃນການສຶກສາຕົ້ນທຶນການເດີນທາງ.** ມູນຄ່າທີ່ເປີດເຜີຍຂອງຜູ້ເຂົ້າຊົມຕໍ່ສະຖານທີ່ຖືກປະເມີນຕ່ຳ
  ຖ້າມີສະຖານທີ່ທົດແທນທີ່ໃກ້ກວ່າ ແລະ ບໍ່ໄດ້ຄວບຄຸມ — ພວກເຂົາອາດຈະໄປຍ້ອນມັນຟຣີເປັນຫຼັກ, ບໍ່ແມ່ນຍ້ອນມັນມີຄ່າເປັນເອກະລັກ.
- **ນຳວິທີຄວາມມັກທີ່ເປີດເຜີຍໄປໃຊ້ກັບສິ່ງດີທີ່ບໍ່ມີສຽງສະທ້ອນຕະຫຼາດເລີຍ.** ມູນຄ່າການມີຢູ່, ມູນຄ່າທາງເລືອກ,
  ແລະ ມູນຄ່າມໍລະດົກບໍ່ປາກົດໃນທຸລະກຳໃດໆ ແລະ ບໍ່ສາມາດຟື້ນຄືນດ້ວຍວິທີ hedonic ຫຼື ຕົ້ນທຶນການເດີນທາງ —
  ຊ່ອງຫວ່າງນັ້ນເປັນຂອງ[ການປະເມີນມູນຄ່າຈາກຄວາມມັກທີ່ລະບຸ](../ການຕີມູນຄ່າດ້ວຍຄວາມມັກທີ່ລະບຸ/).
- **ສັບສົນມູນຄ່າທີ່ຖືກຄິດເປັນທຶນ (ຄັ້ງດຽວ) ກັບກະແສປະຈຳປີ.** ຜົນ hedonic ຕໍ່ລາຄາເຮືອນ
  ປົກກະຕິແມ່ນມູນຄ່າທີ່ຄິດເປັນທຶນຄັ້ງດຽວ; ການຖືມັນເປັນກະແສຜົນປະໂຫຍດປະຈຳປີເຮັດໃຫ້ການປະເມີນສູງເກີນຈິງ.
