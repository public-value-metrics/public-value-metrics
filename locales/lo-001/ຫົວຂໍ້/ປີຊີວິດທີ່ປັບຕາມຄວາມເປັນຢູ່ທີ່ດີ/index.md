# ປີຊີວິດທີ່ປັບຕາມຄວາມເປັນຢູ່ທີ່ດີ (WELLBY)

WELLBY ແມ່ນຄວາມພໍໃຈໃນຊີວິດເພີ່ມຂຶ້ນໜຶ່ງຄະແນນ, ໃນມາດຕາສ່ວນຄວາມເປັນຢູ່ທີ່ດີມາດຕະຖານ 0–10, ສຳລັບໜຶ່ງຄົນເປັນເວລາໜຶ່ງປີ. ມັນເປັນຕົວທຽບເທົ່າຕາມໂຄງສ້າງຂອງ QALY ທີ່ໃຊ້ໃນເສດຖະສາດສຸຂະພາບ — ໜ່ວຍດຽວທີ່ໃຫ້ປຽບທຽບການແຊກແຊງທີ່ຜົນລັບບໍ່ມີຫຍັງຮ່ວມກັນ — ແຕ່ສ້າງຈາກຄວາມເປັນຢູ່ທີ່ດີແບບສ່ວນຕົວ (subjective wellbeing) ແທນສະຖານະສຸຂະພາບທາງຄລີນິກ, ແລະ ກຳນົດໄວ້ໃນ "Wellbeing guidance for appraisal: supplementary Green Book guidance" (2021) ຂອງ HM Treasury.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ການປະເມີນຕົ້ນທຶນ-ຜົນປະໂຫຍດຕ້ອງການໜ່ວຍສາມັນເພື່ອປຽບທຽບທຶນສະໂມສອນເຍົາວະຊົນ ກັບໂຄງການຄວາມປອດໄພທາງຖະໜົນ ກັບບໍລິການສຸຂະພາບຈິດ, ເຊິ່ງບໍ່ມີອັນໃດແບ່ງປັນມາດຕະການຜົນລັບ. ເສດຖະສາດສຸຂະພາບແກ້ເລື່ອງນີ້ສຳລັບການແຊກແຊງທາງຄລີນິກດ້ວຍ QALY: ປີຊີວິດທີ່ປັບຕາມຄຸນນະພາບ, ຖ່ວງນ້ຳໜັກຈາກ 0 (ຕາຍ) ຫາ 1 (ສຸຂະພາບເຕັມ). ຄຳແນະນຳຄວາມເປັນຢູ່ທີ່ດີຂອງ HM Treasury ຂະຫຍາຍເຫດຜົນດຽວກັນໄປສູ່ການໃຊ້ຈ່າຍສາທາລະນະທີ່ບໍ່ແມ່ນສຸຂະພາບ, ໂດຍໃຊ້ຄຳຖາມຄວາມພໍໃຈໃນຊີວິດທີ່ປະສານກັນຂອງ ONS ("ໂດຍລວມແລ້ວ, ປະຈຸບັນນີ້ທ່ານພໍໃຈກັບຊີວິດຂອງທ່ານຫຼາຍປານໃດ?", ຕອບ 0–10) ເປັນຂັ້ນໄດຜົນລັບແທນດັດຊະນີສະຖານະສຸຂະພາບ. WELLBY 1 ໝາຍເຖິງຄວາມພໍໃຈໃນຊີວິດຂອງຄົນໜຶ່ງເພີ່ມຂຶ້ນໜຶ່ງຄະແນນເຕັມເປັນເວລາໜຶ່ງປີ (ຫຼື ເທົ່າກັນ, ຄວາມພໍໃຈຂອງສິບຄົນເພີ່ມຂຶ້ນຄົນລະ 0.1 ຄະແນນເປັນເວລາໜຶ່ງປີ — WELLBY ລວມກັນໄດ້ທົ່ວປະຊາກອນຄືກັນກັບ QALY). ຄຳແນະນຳຂອງ HM Treasury ກຳນົດມູນຄ່າເງິນຕົວຢ່າງຕໍ່ WELLBY (ປະມານ £13,000, ລາຄາປີ 2019/20) ທີ່ໄດ້ຈາກການປະສານຂໍ້ມູນຄວາມເປັນຢູ່ທີ່ດີແບບສ່ວນຕົວກັບວິທີອື່ນໃນການຕີມູນຄ່າປີຊີວິດ, ໃຫ້ຜູ້ປະເມີນມີວິທີຕີຜົນລັບເປັນເງິນ — ຄວາມໂດດດ່ຽວທີ່ຫຼຸດລົງ, ຄວາມສາມັກຄີຊຸມຊົນ, ການເຂົ້າເຖິງພື້ນທີ່ສີຂຽວ — ທີ່ເຕັກນິກ[ການຕີມູນຄ່າຄວາມເປັນຢູ່ທີ່ດີ](../ການຕີມູນຄ່າຄວາມເປັນຢູ່ທີ່ດີ/) ກ່ອນໜ້ານີ້ພຽງພັນລະນາໄດ້ ແຕ່ປຽບທຽບບໍ່ໄດ້ໃນພື້ນຖານດຽວກັນກັບການໃຊ້ຈ່າຍດ້ານສຸຂະພາບ ຫຼື ຄວາມປອດໄພ.

## ຄະນິດສາດ

```
WELLBY = Δ life satisfaction (0–10 scale) × number of years the change persists
        (summed across all people affected)

Monetized wellbeing benefit = WELLBYs generated × value per WELLBY (HMT reference value)

cf. QALY = Δ health-state utility (0–1 scale) × years lived in that state
```

ມາດຕາສ່ວນຄວາມພໍໃຈ 0–10 ແລະ ມາດຕາອຸປະໂພກ QALY 0–1 ແທນກັນບໍ່ໄດ້ໂດຍບໍ່ມີຂັ້ນຕອນການແປງ; ຄຳແນະນຳຂອງ HM Treasury ສົນທະນາການປະສານສອງຢ່າງ ເພື່ອໃຫ້ ຕົວຢ່າງ ການແຊກແຊງດ້ານສຸຂະພາບທີ່ປະເມີນເປັນ QALY ແລະ ການແຊກແຊງທາງສັງຄົມທີ່ປະເມີນເປັນ WELLBY ບໍ່ຖືກນັບຊ້ຳຢ່າງງຽບໆ ຫຼື ປຽບທຽບບໍ່ໄດ້ພາຍໃນ[ການປະເມີນ Green Book](../ການປະເມີນຄຸນຄ່າຕາມ-green-book/) ດຽວກັນ.

## ຕົວຢ່າງການຄິດໄລ່

**ບໍລິການຄວາມໂດດດ່ຽວຂອງອົງການປົກຄອງທ້ອງຖິ່ນ**: ໂຄງການເປັນເພື່ອນໃຫ້ບໍລິການຜູ້ອາໄສສູງອາຍຸທີ່ໂດດດ່ຽວ 400 ຄົນ. ການສຳຫຼວດຕິດຕາມຜົນສະແດງວ່າຄວາມພໍໃຈໃນຊີວິດສະເລ່ຍເພີ່ມຈາກ 5.2 ເປັນ 6.0 (ເພີ່ມ 0.8 ຄະແນນ), ແລະ ຜົນກະທົບຄາດວ່າຈະຢູ່ 2 ປີກ່ອນຈາງລົງ.

```
WELLBYs = 400 people × 0.8 points × 2 years = 640 WELLBYs

Monetized value = 640 × £13,000 = £8,320,000
```

ເມື່ອທຽບກັບຕົ້ນທຶນໂຄງການລາຍປີ £300,000 (£600,000 ໃນ 2 ປີ), ອັດຕາສ່ວນຜົນປະໂຫຍດຕໍ່ຕົ້ນທຶນປະມານ 8,320,000 / 600,000 ≈ **13.9:1** — ຕົວເລກທີ່ຕອນນີ້ສາມາດຢູ່ໃນຕາຕະລາງການປະເມີນດຽວກັນກັບຕົ້ນທຶນຕໍ່ QALY ທີ່ຫຼີກເວັ້ນໄດ້ຂອງໂຄງການສຸຂະພາບ ຫຼື ການປະຫຍັດເວລາເດີນທາງຂອງໂຄງການຂົນສົ່ງ.

**ອົງການການກຸສົນ, ຂະໜາດນ້ອຍກວ່າ**: ໂຄງການສິລະປະຊຸມຊົນເຂົ້າເຖິງຜູ້ເຂົ້າຮ່ວມ 50 ຄົນ ດ້ວຍການເພີ່ມຄວາມພໍໃຈທີ່ວັດໄດ້ 0.3 ຄະແນນ, ຢູ່ 1 ປີ.

```
WELLBYs = 50 × 0.3 × 1 = 15 WELLBYs
Monetized value = 15 × £13,000 = £195,000
```

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

- ບໍລິການທີ່ປະເຊີນໜ້າກັບພົນລະເມືອງໃດກໍຕາມທີ່ເກັບລາຍການສຳຫຼວດຄວາມພໍໃຈໃນຊີວິດ ຫຼື ຄວາມເປັນຢູ່ທີ່ດີຢູ່ແລ້ວ (ແພລດຟອມຂອງອົງການປົກຄອງທ້ອງຖິ່ນ ແລະ ສຸຂະພາບ-ການດູແລຫຼາຍແຫ່ງເຮັດ, ຕາມສີ່ຄຳຖາມຄວາມເປັນຢູ່ທີ່ດີມາດຕະຖານຂອງ ONS) ສາມາດຄິດໄລ່ WELLBY ໂດຍກົງຈາກທໍ່ຂໍ້ມູນທີ່ມີຢູ່ ແທນທີ່ຈະວ່າຈ້າງການປະເມີນເສດຖະກິດສະເພາະສຳລັບທຸກການປ່ຽນແປງບໍລິການ.
- WELLBY ໃຫ້ທີມວິສະວະກຳທີ່ສ້າງສຳລັບການລາຍງານ[ກົດໝາຍຄຸນຄ່າທາງສັງຄົມ](../ກົດໝາຍຄຸນຄ່າທາງສັງຄົມ/) ຫຼື
  [ຜົນຕອບແທນທາງສັງຄົມຈາກການລົງທຶນ](../ຜົນຕອບແທນທາງສັງຄົມຈາກການລົງທຶນ/) ມີຕົວຫານມາດຕະຖານລະດັບຊາດທີ່ HM Treasury ຮັບຮອງ, ຫຼີກເວັ້ນການແຜ່ຂະຫຍາຍ "ຄະແນນຜົນກະທົບ" ສະເພາະທີ່ປຽບທຽບຂ້າມສັນຍາ ຫຼື ຜູ້ສະໜອງບໍ່ໄດ້.
- ເພາະ WELLBY ລວມກັນໄດ້ຂ້າມຄົນ ແລະ ເວລາ, ມັນປະກອບເຂົ້າກັບການຕິດຕາມຜົນລັບລະດັບປະຊາກອນທີ່ໃຊ້ໃນລະບົບ[ຄວາມຮັບຜິດຊອບອີງຜົນລັບ](../ຄວາມຮັບຜິດຊອບຕາມຜົນລັບ/) ໄດ້ຢ່າງລຽບງ່າຍ — ແດຊ໌ບອດບໍລິການສາມາດລາຍງານ WELLBY ສະສົມທີ່ສ້າງຕໍ່ໄຕມາດ ຄືກັບທີ່ລະບົບສຸຂະພາບລາຍງານ QALY ທີ່ໄດ້ຮັບ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ສົມມຸດວ່າຄວາມພໍໃຈທີ່ລາຍງານເອງເພີ່ມຂຶ້ນທັງໝົດເປັນຜົນຂອງການແຊກແຊງ** — ຖ້າບໍ່ມີສະຖານະການສົມມຸດ (ກຸ່ມປຽບທຽບ ຫຼື ການອອກແບບກ່ອນ/ຫຼັງທີ່ມີການຄວບຄຸມ), ທ່ານແຍກການເພີ່ມ WELLBY ອອກຈາກແນວໂນ້ມທົ່ວໄປບໍ່ໄດ້; ເບິ່ງ [ການວິເຄາະສະຖານະການສົມມຸດ](../ການວິເຄາະສະຖານະການສົມມຸດ/).
- **ປົນ WELLBY ແລະ QALY ໃນຍອດລວມດຽວໂດຍບໍ່ປະສານ** — ຄຳແນະນຳຂອງ HM Treasury ລະບຸຢ່າງຊັດເຈນວ່າທັງສອງໃຊ້ມາດຕາສ່ວນຕ່າງກັນ ແລະ ທິດສະດີມູນຄ່າພື້ນຖານຕ່າງກັນ; ການລວມພວກມັນແບບງ່າຍໆນັບສະຫວັດດີການທີ່ຊ້ອນກັນຊ້ຳ.
- **ໃຊ້ມູນຄ່າເງິນອ້າງອີງໂດຍບໍ່ຕັ້ງຂໍ້ສົງໄສ** — ຕົວເລກ £ ຕໍ່ WELLBY ເປັນຄ່າປະເມີນສະເລ່ຍລະດັບຊາດທີ່ມີຊ່ວງຄວາມບໍ່ແນ່ນອນຈິງ; ຄຳແນະນຳຂອງ HM Treasury ແນະນຳການວິເຄາະຄວາມອ່ອນໄຫວ, ບໍ່ແມ່ນຖືວ່າມັນເປັນອັດຕາແລກປ່ຽນຄົງທີ່.
