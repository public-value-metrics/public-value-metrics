# ຜົນຕອບແທນທາງສັງຄົມຈາກການລົງທຶນ (SROI)

ຜົນຕອບແທນທາງສັງຄົມຈາກການລົງທຶນ (social return on investment, SROI) ເປັນກອບສຳລັບການວັດແທກ, ຕີມູນຄ່າເປັນເງິນ ແລະ ບັນຊີມູນຄ່າໃນຄວາມໝາຍກວ້າງ — ທາງສັງຄົມ, ສິ່ງແວດລ້ອມ ແລະ ເສດຖະກິດ — ແລ້ວສະແດງເປັນອັດຕາສ່ວນທຽບກັບຊັບພະຍາກອນທີ່ລົງທຶນ, ຕົວຢ່າງ "ມູນຄ່າທາງສັງຄົມ £1.44 ຕໍ່ທຸກ £1 ທີ່ລົງທຶນ". ມັນຖືກອອກແບບເພື່ອຂະຫຍາຍເຫດຜົນຂອງການບັນຊີການເງິນໄປສູ່ຜົນລັບທີ່ຕະຫຼາດບໍ່ໄດ້ກຳນົດລາຄາ ໂດຍບໍ່ສູນເສຍລະບຽບວິໄນຂອງການບັນຊີ: ທຸກຕົວເລກໃນ SROI ຕ້ອງຕິດຕາມໄດ້ເຖິງຜົນລັບທີ່ຜູ້ມີສ່ວນໄດ້ສ່ວນເສຍກຳນົດ, ຖານຫຼັກຖານ, ແລະ ການປັບແກ້ຢ່າງຊັດເຈນສຳລັບສິ່ງທີ່ຈະເກີດຂຶ້ນຢູ່ແລ້ວ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

SROI ຮັກສາໂດຍ Social Value UK ແລະ Social Value International, ອົງການສືບທອດຂອງ SROI Network, ເຊິ່ງ "A Guide to Social Return on Investment" (2012) ຍັງເປັນວິທີການອ້າງອີງ. ກອບນີ້ວາງຢູ່ເທິງເຈັດຫຼັກການ — ໃຫ້ຜູ້ມີສ່ວນໄດ້ສ່ວນເສຍມີສ່ວນຮ່ວມ, ເຂົ້າໃຈສິ່ງທີ່ປ່ຽນແປງ, ຕີມູນຄ່າສິ່ງທີ່ສຳຄັນ, ລວມສະເພາະສິ່ງທີ່ມີນ້ຳໜັກ (material), ບໍ່ອ້າງເກີນຈິງ, ໂປ່ງໃສ, ແລະ ກວດສອບຜົນ — ແລະ ຫຼັກການຂໍ້ຫ້າ "ບໍ່ອ້າງເກີນຈິງ" ແມ່ນສິ່ງທີ່ລາຍງານ SROI ສ່ວນໃຫຍ່ໃນໂລກຈິງລົ້ມເຫຼວ. ອັດຕາສ່ວນທີ່ໄດ້ມາໂດຍການຂ້າມການປັບແກ້ deadweight ແລະ ການລະບຸຜົນງານບໍ່ແມ່ນ SROI; ມັນເປັນຕົວເລກການຕະຫຼາດທີ່ແຕ່ງຕົວເປັນ SROI. ວິສະວະກອນຊອບແວທີ່ສ້າງເຄື່ອງມືລາຍງານສຳລັບອົງການການກຸສົນ, ວິສາຫະກິດສັງຄົມ ຫຼື ຜູ້ວ່າຈ້າງ ຕ້ອງຮູ້ຄວາມແຕກຕ່າງ, ເພາະເຄື່ອງມືຈະບັງຄັບລະບຽບວິໄນ ຫຼື ເຮັດໃຫ້ຂ້າມມັນໄດ້ງ່າຍ.

## ຄະນິດສາດ

SROI ອີງໃສ່ [ທິດສະດີການປ່ຽນແປງ](../ທິດສະດີການປ່ຽນແປງ/) ເພື່ອລະບຸວ່າຜົນລັບໃດຢູ່ໃນຂອບເຂດ, ແລະ ສະແດງມັນດ້ວຍຕ່ອງໂສ້ຄວາມຮັບຜິດຊອບດຽວກັນກັບ [ແບບຈຳລອງເຫດຜົນ](../ແບບຈຳລອງເຫດຜົນ/):

```
SROI ratio = Present value of outcomes / Value of inputs

Process:
 1. Establish scope and identify stakeholders whose outcomes will be measured
 2. Map outcomes (a theory of change, evidenced with stakeholders, not assumed)
 3. Evidence outcomes and give them a value using financial proxies
 4. Establish impact: gross value − deadweight − attribution − displacement, then apply drop-off
 5. Calculate the SROI: net present value of impact ÷ value of inputs
 6. Report, use, and embed — the ratio is a communication device, not the endpoint
```

Deadweight, ການລະບຸຜົນງານ ແລະ ການຍ້າຍທີ່ ໄດ້ອະທິບາຍໄວ້ໃນ
[ຜົນເພີ່ມເຕີມ ແລະ ຜົນທີ່ຈະເກີດຂຶ້ນຢູ່ແລ້ວ](../ຜົນເພີ່ມເຕີມ-ແລະ-ຜົນທີ່ຈະເກີດຂຶ້ນຢູ່ແລ້ວ/) ແລະ
[ການຍ້າຍທີ່ ແລະ ການລະບຸຜົນງານ](../ການຍ້າຍທີ່-ແລະ-ການລະບຸຜົນງານ/); ທັງສາມຢ່າງມີຢູ່ເພື່ອແຍກຜົນກະທົບແທ້ຈິງຕາມ[ສະຖານະການສົມມຸດ (counterfactual)](../ການວິເຄາະສະຖານະການສົມມຸດ/) ອອກຈາກຜົນລັບລວມ.

## ຕົວຢ່າງການຄິດໄລ່

**ໂຄງການການຈ້າງງານຂອງອົງການປົກຄອງທ້ອງຖິ່ນ**: ຕົ້ນທຶນນຳເຂົ້າລາຍປີ £250,000. ຜູ້ເຂົ້າຮ່ວມ 60 ຄົນໄດ້ວຽກທີ່ຍືນຍົງ; ຕົວແທນທາງການເງິນ (financial proxy) ຂອງຜົນລັບນັ້ນ (ການເພີ່ມຄວາມເປັນຢູ່ທີ່ດີ, ການເພິ່ງພາເງິນສະຫວັດດີການທີ່ຫຼຸດລົງ, ແລະ ລາຍຮັບພາສີລວມກັນ) ແມ່ນ £8,500 ຕໍ່ຄົນໃນປີທຳອິດ — ເບິ່ງ [ຖານຂໍ້ມູນຕົ້ນທຶນຕໍ່ໜ່ວຍ](../ຖານຂໍ້ມູນຕົ້ນທຶນຕໍ່ໜ່ວຍ/) ສຳລັບບ່ອນທີ່ຕົວແທນເຫຼົ່ານັ້ນມາຈາກ.

- ມູນຄ່າຜົນລັບລວມ: 60 × £8,500 = £510,000
- ຫັກ deadweight (40% ຈະຫາວຽກໄດ້ຢູ່ແລ້ວໂດຍບໍ່ມີໂຄງການ): £510,000 × 0.60 = £306,000
- ຫັກການລະບຸຜົນງານ (30% ຂອງການປ່ຽນແປງທີ່ເຫຼືອເກີດຈາກການສະໜັບສະໜູນຂອງອົງການອື່ນ): £306,000 × 0.70 = £214,200
- ຜົນລັບປີທີ 2 ທີ່ drop-off 30%: £214,200 × 0.70 = £149,940, ຄິດຫຼຸດທີ່ 3.5%/ປີ (ເບິ່ງ
  [ອັດຕາຄິດຫຼຸດທາງສັງຄົມ](../ອັດຕາຄິດຫຼຸດທາງສັງຄົມ/)): £149,940 ÷ 1.035 = £144,870
- ມູນຄ່າປັດຈຸບັນລວມຂອງຜົນກະທົບ: £214,200 + £144,870 = £359,070
- **ອັດຕາສ່ວນ SROI: £359,070 ÷ £250,000 = 1.44**, ລາຍງານເປັນ "ມູນຄ່າທາງສັງຄົມ £1.44 ຕໍ່ທຸກ £1 ທີ່ລົງທຶນ"

**ອົງການການກຸສົນ**: ບໍລິການເປັນເພື່ອນ (befriending) ມູນຄ່າ £60,000 ຊ່ວຍຫຼຸດຄວາມໂດດດ່ຽວຂອງຜູ້ສູງອາຍຸ 80 ຄົນ, ຕີມູນຄ່າດ້ວຍຕົວແທນ £1,100/ຄົນ/ປີ. ມູນຄ່າລວມ £88,000; ຫຼັງຫັກ deadweight 35% ແລະ ການລະບຸຜົນງານ 15%, ຜົນກະທົບສຸດທິແມ່ນ £88,000 × 0.65 × 0.85 = £48,620, ອັດຕາສ່ວນ SROI 0.81 — ຕ່ຳກວ່າຈຸດຄຸ້ມທຶນ, ເຊິ່ງເປັນຜົນການຄົ້ນພົບທີ່ຖືກຕ້ອງ ແລະ ມີປະໂຫຍດ, ບໍ່ແມ່ນຄວາມລົ້ມເຫຼວທີ່ຕ້ອງປິດບັງໃນລາຍງານ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ເຄື່ອງຄິດໄລ່ SROI ທີ່ໃຫ້ຜູ້ໃຊ້ໃສ່ຈຳນວນຜົນລັບ ແລະ ມູນຄ່າຕົວແທນ ແຕ່ບໍ່ມີຊ່ອງບັງຄັບສຳລັບ deadweight, ການລະບຸຜົນງານ ຫຼື ທິດສະດີການປ່ຽນແປງທີ່ເຊື່ອມໂຍງ ຈະສ້າງອັດຕາສ່ວນທີ່ເກີນຈິງເປັນຄ່າເລີ່ມຕົ້ນ, ເພາະການຂ້າມການປັບແກ້ເປັນເສັ້ນທາງທີ່ຕ້ານທານໜ້ອຍທີ່ສຸດ. ຝັງລະບຽບວິໄນໃນໂຄງສ້າງຂໍ້ມູນ (schema): ທຸກແຖວຜົນລັບຄວນອ້າງອີງກຸ່ມຜູ້ມີສ່ວນໄດ້ສ່ວນເສຍ, ປະລິມານທີ່ມີຫຼັກຖານ, ຕົວແທນທາງການເງິນພ້ອມແຫຼ່ງ, ແລະ ຊ່ອງ deadweight/ການລະບຸຜົນງານທີ່ບໍ່ແມ່ນທາງເລືອກ. ເບິ່ງ
[ຜົນລັບ ທຽບ ຜົນຜະລິດ](../ຜົນລັບ-ທຽບ-ຜົນຜະລິດ/) ສຳລັບຄວາມແຕກຕ່າງທີ່ການແຕ້ມແຜນທີ່ຜົນລັບຂອງ SROI ຂຶ້ນກັບ,
ແລະ [ແບບຈຳລອງເຫດຜົນ](../ແບບຈຳລອງເຫດຜົນ/) ສຳລັບຕ່ອງໂສ້ທີ່ເຄື່ອງມືຄວນສະທ້ອນໃນແບບຈຳລອງຂໍ້ມູນຂອງມັນ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ການຂ້າມ deadweight ແລະ ການລະບຸຜົນງານ.** ອັດຕາສ່ວນຫຼັກທີ່ບໍ່ມີການປັບແກ້ເຫຼົ່ານີ້ເປັນຕົວເລກລວມ, ບໍ່ແມ່ນຕົວເລກຜົນກະທົບສຸດທິ, ແລະ ຫຼັກການຂອງ Social Value UK ກຳນົດຢ່າງຊັດເຈນໃຫ້ມີທັງສອງ.
- **ການປຽບທຽບອັດຕາສ່ວນຂ້າມອົງກອນ.** ອັດຕາສ່ວນ SROI ຂຶ້ນກັບຂອບເຂດ ແລະ ການເລືອກຕົວແທນທີ່ເຮັດເປັນກໍລະນີໆໄປ; ການຖືວ່າອັດຕາສ່ວນ 4:1 ຈາກລາຍງານໜຶ່ງ "ດີກວ່າ" ອັດຕາສ່ວນ 2:1 ຈາກອີກລາຍງານໜຶ່ງ ເບິ່ງຂ້າມຄວາມຈິງທີ່ວ່າສົມມຸດຕິຖານບໍ່ໄດ້ເປັນມາດຕະຖານແບບອັດຕາສ່ວນບັນຊີການເງິນ.
- **ການນັບຕົວແທນທີ່ຊ້ອນກັນຊ້ຳ.** ການຊ້ອນຕົວແທນ "ຄວາມໂດດດ່ຽວທີ່ຫຼຸດລົງ" ກັບຕົວແທນ "ສຸຂະພາບຈິດທີ່ດີຂຶ້ນ" ສຳລັບຜູ້ໄດ້ຮັບຜົນປະໂຫຍດກຸ່ມດຽວກັນ ສາມາດຕີມູນຄ່າຊ້ຳການປ່ຽນແປງພື້ນຖານອັນດຽວ.
- **ການຂ້າມການມີສ່ວນຮ່ວມຂອງຜູ້ມີສ່ວນໄດ້ສ່ວນເສຍ.** ຫຼັກການຂໍ້ໜຶ່ງກຳນົດໃຫ້ຜົນລັບຖືກກຳນົດຮ່ວມກັບຄົນທີ່ປະສົບກັບມັນ, ບໍ່ແມ່ນສົມມຸດໂດຍນັກວິເຄາະທີ່ສ້າງແບບຈຳລອງ.
