# பல்வகை அளவுகோல் முடிவுப் பகுப்பாய்வு (MCDA)

MCDA என்பது பல தனித்தனி, எடையிடப்பட்ட அளவுகோல்களுக்கு எதிராக வாய்ப்புகளை ஒரே நேரத்தில் மதிப்பெண்ணிட்டு எடைபோடும் முறை; ஒவ்வொரு அளவுகோலையும் ஒரே பண அல்லது இயற்கை அலகு அளவுகோலுக்குள் திணிக்காமல் தரவரிசைப்படுத்தப்பட்ட ஒப்பீட்டைத் தருகிறது. முக்கியமான விளைவுகளை உண்மையில் ஒரே எண்ணாகக் குறைக்க இயலாத முடிவுகளுக்கான மதிப்பீட்டு முறை இது.

## ஏன் இது முக்கியம்

Green Book, நன்மைகள் "உண்மையிலேயே ஒப்பிட இயலாதவையாக" இருக்கும் மதிப்பீடுகளுக்கு MCDA-வை வெளிப்படையாக அங்கீகரிக்கிறது (அதன் Box 2 வழக்காய்வு இணைப்பும் Annex A-வும் இதை நேரடியாக விவாதிக்கின்றன). அங்கே [சமூக செலவு-பலன் பகுப்பாய்வு](../சமூகச்-செலவு-பயன்-பகுப்பாய்வு/) மூலம் அனைத்தையும் பணமாக மாற்றுவதோ, [செலவுத்திறன் பகுப்பாய்வு](../அரசாங்கத்தில்-செலவுப்-பயனுறுதிப்-பகுப்பாய்வு/) மூலம் ஒரே விளைவாகக் குறைப்பதோ முடிவைத் தெளிவுபடுத்துவதற்குப் பதிலாகத் திரித்துக் காட்டும் (<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>). எடுத்துக்காட்டாக, ஒரு புதிய சிறைச்சாலைக்கான இடத் தேர்வு, மூலதனச் செலவு, சமூகத் தாக்கம், போக்குவரத்துத் தொடர்பு, சுற்றுச்சூழல் விளைவு, பணியாளர் ஆட்சேர்ப்புச் சாத்தியம் ஆகியவற்றை ஒன்றுக்கொன்று சமரசம் செய்கிறது; இவற்றுக்குப் பொதுவான அலகு இல்லை, ஒரு பொது அலகை (பொதுவாகப் பணம்) திணிப்பது, சுற்றுச்சூழல் தாக்கத்துக்கும் செலவுக்கும் இடையிலான ஒப்பீட்டு முக்கியத்துவம் குறித்த மதிப்பீட்டு முடிவை, புறவயமான கணக்கீடு போல மாறுவேடமிட்டுக் கடத்திவிடும்.

MCDA-வின் நேர்மையே அதன் முக்கிய பலவீனமும் ஆகும்: எடைகளை மதிப்பீட்டை நடத்துபவர் (அல்லது ஒரு குழு) வழங்குவதால், எடையிடும் செயல்முறை எவ்வளவு நியாயமானதோ அந்த அளவுக்கே இம்முறையும் நியாயமானது. விருப்பமான வாய்ப்பிலிருந்து பின்னோக்கிச் சென்று அதை நியாயப்படுத்தும் எடைகளை ஒரு மதிப்பாய்வாளர் உருவாக்குவதைத் தடுக்கவே, வாய்ப்புகளுக்கு மதிப்பெண் வழங்குவதற்கு *முன்பே* அளவுகோல்களும் எடைகளும் ஒப்புக்கொள்ளப்பட்டு வெளியிடப்பட வேண்டும் என்று Green Book வழிகாட்டுதல் வெளிப்படையாகக் கூறுகிறது.

## கணிதம்

```
For each option i and criterion j:
  Score_ij   = the option's performance against that criterion (often 0-100
               or 1-10, from evidence, expert judgement, or stakeholder scoring)
  Weight_j   = relative importance of criterion j, weights sum to 1 (or 100)

Weighted score of option i = Σ_j (Score_ij × Weight_j)

Procedure:
1. Agree the criteria set and weights BEFORE scoring any option (swing
   weighting or pairwise comparison, e.g. AHP, are common elicitation methods).
2. Score every option against every criterion on a common scale, from
   evidence where possible.
3. Compute weighted totals; rank options.
4. Sensitivity-test the weights: does the ranking survive plausible
   disagreement about how much each criterion should matter?
```

SCBA-வின் நிகர நடப்பு மதிப்பு தருவது போன்ற நிலைநிறுத்தக்கூடிய முழுமையான மதிப்பை MCDA தருவதில்லை; ஒப்புக்கொண்ட எடைகளுக்கு உட்பட்ட தரவரிசையை மட்டுமே தருகிறது. ஒப்பிட இயலாத நன்மைகளுக்கு இடையிலான சமரசமே முடிவின் சாரம் எனும்போது இது ஒரு சிறப்பம்சம்; பணமதிப்பிடல் சாத்தியமாக இருந்தும் அந்தக் கடினமான வேலையைத் தவிர்க்க இதைப் பயன்படுத்தினால் இது ஒரு குறை.

## செயல்முறை எடுத்துக்காட்டு

**உள்ளாட்சி அமைப்பு**: வீட்டுக் கழிவு மறுசுழற்சி மையம் அமைக்க இடம் தேர்ந்தெடுக்கும் ஒரு நகர சபை, எந்த இடப் பார்வைக்கும் முன்பே பல துறைகள் அடங்கிய குழுவால் எடையிடப்பட்ட நான்கு அளவுகோல்களுக்கு எதிராக மூன்று இடங்களுக்கு மதிப்பெண் வழங்குகிறது:

```
Criteria (weight):        Capital cost (30%)  Transport access (25%)
                           Community impact (25%)  Environmental impact (20%)

Site scores (0-100, higher = better):
Site A: cost 80, access 60, community 40, environment 70
Site B: cost 60, access 90, community 70, environment 50
Site C: cost 90, access 50, community 80, environment 60

Weighted totals:
Site A = 80(.30) + 60(.25) + 40(.25) + 70(.20) = 24+15+10+14 = 63
Site B = 60(.30) + 90(.25) + 70(.25) + 50(.20) = 18+22.5+17.5+10 = 68
Site C = 90(.30) + 50(.25) + 80(.25) + 60(.20) = 27+12.5+20+12 = 71.5
```

இடம் C முதலிடம் பெறுகிறது. சமூகத் தாக்க எடையை 25% இலிருந்து 35% ஆக மாற்றி (மூலதனச் செலவிலிருந்து 10 புள்ளிகளை எடுத்து) உணர்திறன் சோதனை நடத்தினால், இடம் C-யின் மொத்தம் 71.5 − 3 + 8 = 76.5 ஆகவும் இடம் B-யின் மொத்தம் 68 − 6 + 7 = 69 ஆகவும் மாறுகிறது — இடம் C தொடர்ந்து முன்னிலையில் உள்ளது; எனவே எடையிடல் குறித்த இந்த நியாயமான கருத்து வேறுபாட்டுக்கும் தரவரிசை உறுதியாக நிற்கிறது; இதையே Green Book அறிக்கையிடப்படுவதைக் காண எதிர்பார்க்கிறது.

**அறக்கட்டளை**: ஒரு கடன் ஆலோசனைச் சேவை, ஒரு உணவு வங்கி வலையமைப்பு, ஒரு நிதி எழுத்தறிவுத் திட்டம் ஆகியவற்றில் எதற்கு நிதியளிப்பது என்று தேர்வுசெய்யும் மானிய வழங்கும் அறக்கட்டளை, SROI-ஐ (பார்க்க [சமூக முதலீட்டு வருவாய்](../சமூக-முதலீட்டு-வருவாய்/)) விடுத்து MCDA-வைப் பயன்படுத்துகிறது; ஏனெனில் நெருக்கடி நிவாரணத்துக்கா தடுப்புக்கா அதிக எடை தர வேண்டும் என்பதில் அறங்காவலர்கள் நல்லெண்ணத்துடன் முரண்படுகின்றனர். ஒரே SROI விகிதம் அதைத் தீர்த்துவிட்டதாகப் பாசாங்கு செய்யாமல், கருத்து வேறுபாட்டின் *வடிவத்தை* (ஒரு எடை வரம்பை) ஒப்புக்கொள்ள MCDA அவர்களை அனுமதிக்கிறது.

## மென்பொருள் பொறியியல் தொடர்பு

அளவுகோல்கள் உண்மையிலேயே முரண்படும் இடங்களில் விற்பனையாளர் மற்றும் கட்டமைப்புத் தேர்வுக்கு MCDA இயல்பான கருவி — மேக வழங்கல் வழக்கு மேலாண்மை அமைப்புக்கும் உள்ளக (on-premises) அமைப்புக்கும் இடையே தேர்வுசெய்வது, செலவு, தரவு இறையாண்மை அபாயம், அணுகல்தன்மை, வழங்கல் வேகம் ஆகியவற்றை ஒரே எண்ணாகக் குறைக்க இயலாத விதங்களில் சமரசம் செய்கிறது. Green Book கோருவது போலவே, வாய்ப்புகளுக்கு மதிப்பெண் வழங்குவதற்கு முன்பே எடையிடல் நடைபெற வேண்டும் என்று பொறியியல் தலைவர்கள் வலியுறுத்த வேண்டும்; ஏனெனில் குறுகிய பட்டியலைப் பார்த்த பின் நடத்தப்படும் எடையிடல் பயிற்சி, அரங்கம் ஏற்கெனவே விரும்பிய வாய்ப்பின் பக்கமே நம்பகமாகச் சாய்ந்துவிடும். MCDA-வின் பொதுவான பயன்பாட்டுக்கு [அரசாங்கத்தில் உருவாக்கு எதிர் வாங்கு](../அரசாங்கத்தில்-உருவாக்கலா-வாங்கலா/) என்பதையும், முடிவுக்கு முன்பல்ல, முடிவுக்குப் பின் பயன்படுத்தப்படும் தொடர்புடைய கட்டமைக்கப்பட்ட மதிப்பெண் கருவிக்கு [பொது மதிப்பு மதிப்பெண் அட்டை](../பொது-மதிப்பு-மதிப்பெண்-அட்டை/) என்பதையும் பார்க்கவும்.

## பொதுவான தவறுகள்

- **வாய்ப்புகளைப் பார்த்த பின் எடைகளை நிர்ணயித்தல்.** வேண்டுமென்றோ அறியாமலோ MCDA தவறாகப் பயன்படுத்தப்படும் மிகப் பொதுவான வழி இது; மதிப்பெண்ணுக்கு முன் எடைகளை வெளியிடுங்கள், அவற்றை யார் நிர்ணயித்தார் என்பதைப் பதிவுசெய்யுங்கள்.
- **எடையிட்ட மொத்தத்தை உறுதியான எண்ணாகக் கருதுதல்.** 71.5-க்கும் 68-க்கும் இடையிலான இடைவெளி, உணர்திறன் பகுப்பாய்வு தரவரிசை நிலையானது என்று உறுதிப்படுத்தாவிட்டால், புள்ளியியல் ரீதியாக அர்த்தமுள்ளதல்ல; தவறான துல்லியத்தை அல்ல, வரம்புகளை அறிக்கையிடுங்கள்.
- **சாத்தியமாக இருந்த பணமதிப்பிடலைத் தவிர்க்க MCDA-வைப் பயன்படுத்துதல்.** பெரும்பாலான அளவுகோல்களை நம்பத்தகுந்த முறையில் விலையிட முடியுமென்றால், [SCBA](../சமூகச்-செலவு-பயன்-பகுப்பாய்வு/) க்கு பதிலாக இயல்பாக MCDA-வுக்குச் செல்வது, மதிப்பீடு பயன்படுத்தியிருக்கக்கூடிய தகவலைக் கைவிடுவதாகும்.
- **ஒரு செல்வாக்குமிக்க பங்குதாரர் மட்டுமே எல்லா எடைகளையும் நிர்ணயிக்க விடுதல்.** அந்த நபர் ஏற்கெனவே விரும்பியதையே மதிப்பீடு மீண்டும் கண்டறிவதைத் தவிர்க்க, எடைகள் திட்டத்தை முன்னெடுக்கும் இயக்குநரிடமிருந்து அல்ல, பிரதிநிதித்துவக் குழுவிடமிருந்து பெறப்பட வேண்டும் என்று Green Book நல்லொழுக்கம் எதிர்பார்க்கிறது.
