# மானிய விளைவு அறிக்கையிடல் (IRIS+)

மானிய விளைவு அறிக்கையிடல் (grant outcomes reporting) என்பது ஒவ்வொரு நிதியளிப்பவரும் தன் சொந்தத் தனிப்பயன் அறிக்கை வார்ப்புருவை உருவாக்குவதற்குப் பதிலாக, மானியம் பெறுவோர் தரப்படுத்தப்பட்ட, ஒப்பிடத்தக்க விளைவு அளவீடுகளை நிதியளிப்பவர்களுக்குத் திருப்பி அறிக்கையிடும் நடைமுறை. உலகளாவிய தாக்க முதலீட்டு வலையமைப்பு (Global Impact Investing Network, GIIN) பராமரிக்கும் IRIS+ இத்தகைய தரநிலைகளில் மிக விரிவாக ஏற்கப்பட்டது: தாக்க முதலீட்டாளர்களும், அதிகரித்து வரும் அளவில் மானியம் வழங்கும் அறக்கட்டளைகளும், மானியம் பெறுவோர் பயன்படுத்த வேண்டும் அல்லது பரிந்துரைக்கும் முன்வரையறுக்கப்பட்ட சமூக, சுற்றுச்சூழல், நிதிசார் செயல்திறன் அளவீடுகளின் பட்டியல்.

## ஏன் இது முக்கியம்

தரப்படுத்தப்பட்ட அறிக்கையிடலுக்கு முன், ஒவ்வொரு அறக்கட்டளையும் மானியம் பெறுவோரிடம் வெவ்வேறு வடிவத்தில் வெவ்வேறு குறிகாட்டிகளைக் கேட்டது; பத்து நிதியளிப்பவர்களைக் கொண்ட நடுத்தர அளவு அறக்கட்டளை, ஒன்றுடன் ஒன்று மேற்பொருந்தும் பணிக்குப் பத்து இணை அறிக்கையிடல் செயல்முறைகளை நடத்த நேரிடலாம்: மானிய-விளைவுத் தரப்படுத்தல் குறைக்க முயலும் அறிக்கையிடல் சுமைக்கு நன்கு ஆவணப்படுத்தப்பட்ட காரணம் இது. IRIS+ நிதியளிப்பவர்களுக்கும் மானியம் பெறுவோருக்கும் பகிரப்பட்ட சொற்களஞ்சியம் அளித்து இதைத் தீர்க்கிறது: கருப்பொருள் வாரியாகத் தொகுக்கப்பட்ட மையஅளவீட்டுத் தொகுப்புகள் (Core Metrics Sets) (எ.கா. மலிவு விலை வீட்டுவசதி, தூய ஆற்றல் அணுகல், நிதி உள்ளடக்கம்); "உருவாக்கப்பட்ட வேலைகள்" அல்லது "சேவை பெற்ற குடும்பங்கள்" யார் அறிக்கையிட்டாலும் ஒரே பொருளைத் தரும் அளவுக்கு ஒவ்வொரு அளவீடும் துல்லியமாக வரையறுக்கப்பட்டுள்ளது; ஐ.நா. நிலையான வளர்ச்சி இலக்குகளுடன் (SDG) இணைக்கப்பட்டுள்ளதால், மானியம் பெறுவோர் அளவிலான தரவை நிதியளிப்பவர் தொகுப்பு அளவிலான SDG கதையாகத் திரட்ட முடியும். தாக்க முதலீட்டாளர்களில் ஏறத்தாழ பாதிப்பேரும், இத்துறையில் செயல்படும் நிதி மேலாளர்கள், வங்கிகள், மேம்பாட்டு நிதி நிறுவனங்களில் பெரும்பான்மையினரும் IRIS அளவீடுகளைப் பயன்படுத்துவதாக GIIN தெரிவிக்கிறது.

தரப்படுத்தல் [outcomes vs outputs](../விளைவுகள்-எதிர்-வெளியீடுகள்/)-உடன் இணையும் இடத்தில் மிக முக்கியம்: மானியம் பெறுவோரின் ஏற்கெனவே உள்ள வழக்கு மேலாண்மை அமைப்பு எதைப் பதிவு செய்கிறதோ அதன் பக்கம் அல்லாமல், வரையறுக்கப்பட்ட விளைவு மற்றும் தாக்க அளவீடுகளை நோக்கி IRIS+ அறிக்கையிடலைத் தள்ளுகிறது; [cost per outcome](../விளைவு-ஒன்றுக்கான-செலவு/) மற்றும் [cost per beneficiary](../பயனாளி-ஒருவருக்கான-செலவு/) விவரிக்கும் இடைவெளி இதுவே.

## கணிதம்

மானிய விளைவு அறிக்கையிடல் ஒரு கட்டமைப்பும் செயல்முறையும், சூத்திரம் அல்ல:

```
1. Funder selects a Core Metrics Set relevant to the grant's theme
   (e.g. IRIS+ "Financial Inclusion" or "Sustainable Agriculture")
2. Each metric has a fixed definition, unit, and calculation method
   published by GIIN — not invented per-funder
3. Grantee reports against the same metric definitions across all
   its funders using that standard, cutting duplicate reporting effort
4. Funder aggregates grantee-level metrics into portfolio-level reporting,
   comparable year over year and across grantees using the same metric
```

திறன் ஆதாயம் சேர்க்கை சார்ந்தது: N நிதியளிப்பவர்கள் × M மானியம் பெறுவோரை ஒரே பகிரப்பட்ட சொற்களஞ்சியத்துக்குத் தரப்படுத்துவது, N×M தனிப்பயன் அறிக்கையிடல் உறவுகளை, ஒரே தரநிலைக்கு எதிரான ஏறத்தாழ N+M இணைப்புகளாக மாற்றுகிறது.

## செயல்முறை எடுத்துக்காட்டு

**மூன்று நிதியளிப்பவர்கள் உள்ள மானியம் பெறுபவர், தரப்படுத்தலுக்கு முன்**: நிதியளிப்பவர் 1-க்குத் தலை எண்ணிக்கை வரையறையில் "சேவை பெற்றோர்" எனவும், நிதியளிப்பவர் 2-க்குக் குடும்ப வரையறையில் "சென்றடைந்த பயனாளிகள்" எனவும், நிதியளிப்பவர் 3-க்குச் சேவை-நிகழ்வு வரையறையில் "தாக்கம் பெற்ற தனிநபர்கள்" எனவும் அறிக்கையிடுகிறார் (எனவே ஒருவர் இருமுறை வந்தால் இருமுறை எண்ணப்படுகிறார்). மூன்று அறிக்கைகள், மூன்று எண்கள்; எதுவும் ஒப்பிடத்தக்கவை அல்ல; அதே நிதியளிப்பவரின் தொகுப்பிலுள்ள வேறொரு மானியம் பெறுவோரின் எண்களுடனும் ஒப்பிட முடியாது.

**அதே மானியம் பெறுபவர், IRIS+ கீழ்**: வரையறுக்கப்பட்ட IRIS+ தனிநபர்-சென்றடைவு அளவீட்டுக்கு எதிராகவும், தொடர்புடைய மையஅளவீட்டுத் தொகுப்பிலிருந்து வரையறுக்கப்பட்ட விளைவு அளவீட்டுக்கு எதிராகவும் அறிக்கையிடுகிறார்; இரண்டுக்கும் GIIN வெளியிட்ட கணிப்பு முறையைப் பயன்படுத்துகிறார். மூன்று நிதியளிப்பவர்களும் இப்போது ஒரே முறையில் கணக்கிடப்பட்ட ஒரே எண்ணைப் பெறுகிறார்கள்; அதே அளவீட்டைப் பயன்படுத்தி, இந்த மானியம் பெறுபவரின் IRIS+-வரையறுக்கப்பட்ட அலகுக்கான செலவைத் தம் தொகுப்பிலுள்ள மற்றவர்களுடன் ஒப்பிட முடியும்: அறிக்கையிடல்-உள்கட்டமைப்பு அளவில், பகிரப்பட்ட [unit cost database](../அலகுச்-செலவுத்-தரவுத்தளங்கள்/) இருப்பதற்குச் சமம்.

## மென்பொருள் பொறியியல் தொடர்பு

மானிய மேலாண்மைத் தளங்கள் IRIS+ அளவீட்டு அடையாளங்காட்டிகளை உரையாக அல்ல, வெளிப்புறத் திறவுகோலாகக் (foreign key) கருத வேண்டும்: மானியம் பெறுபவர் அறிக்கையிட்ட மதிப்புடன் உள்ளூரில் கண்டுபிடிக்கப்பட்ட "beneficiaries" என்ற புலத்தை அல்லாமல், வெளியிடப்பட்ட அளவீட்டுக் குறியீட்டைச் சேமிப்பதே, பின்னர் தரவுத் தூய்மைத் திட்டம் இல்லாமல் நிதியளிப்பவர்களிடையேயும் தொகுப்புகளிடையேயும் திரட்டுவதைச் சாத்தியமாக்குகிறது. IRIS+-ஐ ஏற்காத நிதியளிப்பவர்களை ஆதரிக்க வேண்டிய தளம், ஒவ்வொரு நிதியளிப்பவரையும் உடனடியாகத் தரநிலைக்குள் தள்ளுவதற்குப் பதிலாக, உள்ளூர் அளவீட்டை நெருங்கிய IRIS+ வரையறைக்கு இணைக்க அனுமதிப்பதே நடைமுறை வடிவமைப்பு: வரைபடத்தில் அதிகமானவை பகிரப்பட்ட அடையாளங்காட்டிகளுடன் இணையும்போது ஒப்பிடத்தக்க தன்மை படிப்படியாக மேம்படுகிறது. சேகரித்த பின் அறிக்கையிடப்பட்ட எண்களைக் கொண்டு எதைக் கணக்கிட வேண்டும் என்பதற்கு உடன்பிறந்த தலைப்பு [cost per outcome](../விளைவு-ஒன்றுக்கான-செலவு/) பாருங்கள்.

## பொதுவான தவறுகள்

- **IRIS+ ஏற்பைத் தானாக அமையும் ஒப்பிடத்தக்க தன்மையாகக் கருதுதல்.** இரு மானியம் பெறுவோரும் ஒரே IRIS+ அளவீட்டுக்கு எதிராக அறிக்கையிட்டாலும், அவர்களின் அடிப்படைத் தரவின் தரம் அல்லது மாற்றுநிலை அனுமானங்கள் வேறுபட்டால் ஒப்பிட முடியாதவையாகவே இருக்கலாம்; தரநிலை வரையறைகளை நிர்ணயிக்கிறது, அளவீட்டுக் கடுமையை அல்ல.
- **நிதியளிப்பவர் கண்டுபிடிக்கும் "IRIS-இணக்க" அளவீடுகள்.** IRIS+ மொழியால் தூண்டப்பட்டதேயன்றி உண்மையான வெளியிடப்பட்ட வரையறை அல்லாத அளவீடு, தரநிலை தீர்க்க இருக்கும் சிதறலை மீண்டும் கொண்டுவருகிறது.
- **மிகை-தேர்வால் அறிக்கையிடல் சோர்வு.** இரண்டு அல்லது மூன்று அளவீடுகள் மட்டுமே முடிவுக்குத் தொடர்புடையவை என்னும்போது, முழு மையஅளவீட்டுத் தொகுப்புக்கும் எதிராக அறிக்கையிடுமாறு மானியம் பெறுவோரைக் கோருவது, தரப்படுத்தப்பட்ட உறைக்குள் சுமைச் சிக்கலை மீண்டும் உருவாக்குகிறது.
- **விளைவு அளவீடே இல்லாமை.** IRIS+ பல தூய வெளியீட்டு அளவீடுகளைக் கொண்டுள்ளது (எ.கா. சேவை பெற்றோரின் எண்ணிக்கை); அவற்றை மட்டுமே தேர்ந்தெடுத்து, விளைவு-அடுக்கு அளவீடுகளில் ஒன்றையும் தேர்ந்தெடுக்காவிட்டால், விளைவு-அறிக்கையிடல் என்ற முத்திரையின் கீழ் [cost-per-beneficiary](../பயனாளி-ஒருவருக்கான-செலவு/) வடிவ அறிக்கையிடல் உருவாகிறது.
