# பொதுச் சேவை உற்பத்தித்திறன்

பொதுச் சேவை உற்பத்தித்திறன், சந்தை விலையும் எனவே செலவுகளை வகுக்க வருவாய் எண்ணும் இல்லாத சேவைகளில் — சுகாதாரம், கல்வி, காவல், சமூகப் பராமரிப்பு — பொதுச் செலவு, உள்ளீடுகளை (பணியாளர்கள், மூலதனம், பொருட்கள் மற்றும் சேவைகள்) தரம் சீரமைக்கப்பட்ட வெளியீடுகளாக எவ்வளவு திறமையாக மாற்றுகிறது என்பதை அளவிடுகிறது. ஐக்கிய இராச்சியத்தின் Office for National Statistics 2000-களின் நடுப்பகுதியிலிருந்து இந்தத் தொடரை வெளியிட்டு வருகிறது; "பணத்தைப் பொதுச் சேவைகளாக மாற்றுவதில் அரசாங்கம் மேம்படுகிறதா, மோசமடைகிறதா?" என்ற கேள்விக்கு விடையளிக்கும் மிகவும் வழிமுறை ரீதியாக வளர்ந்த தேசிய முயற்சி இதுவே.

## ஏன் இது முக்கியம்

சந்தையில், உற்பத்தித்திறன் = (வெளியீட்டு மதிப்பு) / (உள்ளீட்டுச் செலவு); வெளியீட்டு மதிப்பு கண்காணிக்கக்கூடியது, ஏனெனில் யாரோ அதற்குப் பணம் செலுத்துகிறார். இடுப்பு மாற்று அறுவை, ஒரு பள்ளி இடம், ஒரு காவல் ரோந்து ஆகியவற்றுக்கு விற்பனை விலை இல்லை; எனவே எளிமையாகப் பார்த்தால் *உள்ளீடுகளை* (செலவிடப்பட்டதை) மட்டுமே அளவிட முடியும் — இது கருத்துரையாளர்களைப் பொதுச் செலவு உயர்வை தானாகவே மோசமானதாகக் கருதத் தூண்டுகிறது, ஏனெனில் தலைப்புச் செயல்பாடு மாறாமல் அதிக உள்ளீடு உற்பத்தித்திறன் வீழ்ச்சியாகத் தெரிகிறது. பொதுச் சேவை உற்பத்தித்திறனுக்கான ONS-இன் "Sources and Methods" வெளியீடுகளில் விவரிக்கப்பட்ட வழிமுறை, செயல்பாட்டு அளவுகளிலிருந்து (செய்யப்பட்ட அறுவைகள், கற்பிக்கப்பட்ட மாணவர்கள், விசாரிக்கப்பட்ட குற்றங்கள்) ஒரு *வெளியீட்டுக்* குறியீட்டை உருவாக்கி, பின்னர் அந்த வெளியீட்டுக் குறியீட்டைத் *தரம் சீரமைப்பதன்* மூலம் இதைத் தீர்க்கிறது — சுகாதாரத்தில் உயிர்பிழைப்பு விகிதங்களையும் காத்திருப்பு நேரங்களையும், கல்வியில் அடைவையும், காவலில் வழக்குத் தீர்வு போன்ற விளைவுகளையும் உள்ளடக்கி — இதனால் அதே எண்ணிக்கை அறுவைகளைச் செய்தும் சிறந்த உயிர்பிழைப்பு விகிதங்களை எட்டும் சேவை, வெறுமனே அதிகச் செலவானதாக அல்ல, அதிக உற்பத்தித்திறனுடையதாகப் பதிவாகிறது. ONS வெளியீடுகள் முழுவதும் மீண்டும் வரும் தலைப்புக் கண்டுபிடிப்பு இத்துறைக்குக் கசப்பானது: ஐக்கிய இராச்சியப் பொதுச் சேவை உற்பத்தித்திறன் COVID-19 பெருந்தொற்றின்போது கூர்மையாகக் குறைந்தது; ONS-இன் 2020-களின் நடுப்பகுதி வெளியீடுகளிலும் சுகாதாரம் உள்ளிட்ட பல துணைத்துறைகளில் அது 2019 நிலைகளுக்கு மீளவில்லை, செலவு உயர்ந்தபோதும் — "அதிக நிதி"யையும் "அதிக உற்பத்தித்திறனையும்" முற்றிலும் தனித்தனிக் கேள்விகளாக மறுவடிவமைக்கும் இடைவெளி இது.

## கணிதம்

```
Output index (volume) = Σ (activity_i × relative unit cost weight_i), base-year weighted
                          across all service activities (e.g. hip ops, cataract ops,
                          GP consultations), analogous to a Laspeyres/Paasche volume index

Quality adjustment    = output index × quality adjustment factor
                          (e.g. incorporating a change in survival rates, waiting times,
                          attainment, or reoffending as a multiplier on raw volume)

Input index           = Σ (labour hours × labour cost weight) + (goods/services cost,
                          deflated) + (capital consumption)

Total factor productivity growth = % change in quality-adjusted output index
                                    − % change in input index
```

## செயல்முறை எடுத்துக்காட்டு

**எடுத்துக்காட்டு NHS தீவிரச் சிகிச்சைத் துறை உற்பத்தித்திறன் கணக்கீடு** (கட்டமைப்பு ONS வழிமுறையைப் பின்பற்றுகிறது):

```
Year 1: output volume index = 100.0 (base year), input index = 100.0
        → productivity index = 100.0

Year 2: activity volume rises 3.0% (more operations, more appointments)
        but average waiting time worsens, applying a quality-adjustment
        discount of −1.0%
        Quality-adjusted output index = 100 × 1.030 × 0.990 = 101.97

        Inputs rise: staff numbers +4.0%, other costs (deflated) +1.5%,
        weighted input index = 100 × 1.032 = 103.2

Productivity growth = (101.97 / 100 − 1) − (103.2 / 100 − 1)
                     = 1.97% − 3.2% = −1.23 percentage points

Interpretation: activity rose, but inputs rose faster and quality fell
slightly, so productivity — output per unit of input — declined even
though "more care was delivered."
```

தரம் சீரமைப்பும் உள்ளீட்டு வளர்ச்சியும் இரண்டையும் கணக்கில் கொண்டால், உயரும் செலவும் உயரும் மூலச் செயல்பாடும் வீழ்ச்சியுறும் அளவிடப்பட்ட உற்பத்தித்திறனுடன் இணைந்திருப்பது, பெருந்தொற்றுக்குப் பிந்தைய NHS-இன் சில பகுதிகளுக்கு ONS வெளியீடுகள் மீண்டும் மீண்டும் அறிக்கையிட்ட அதே வடிவம்.

## மென்பொருள் பொறியியல் தொடர்பு

பொதுச் சேவை உற்பத்தித்திறன் என்பது பொறியியல் உற்பத்தித்திறன் விவாதங்களின் (வழங்கப்பட்ட ஸ்டோரி புள்ளிகள் எதிர் [DORA அளவீடுகள்](../பொது-மதிப்புக்கான-dora-அளவீடுகள்/) எதிர் [ஓட்ட அளவீடுகள்](../அரசின்-சேவை-வழங்கலில்-பாய்வு-அளவீடுகள்/)) மக்கள்தொகை அளவிலான இணை: தரம் சீரமைப்பு இல்லாத மூலத் தொகுப்புத்திறன், ஒரு மென்பொருள் குழுவில் "வழங்கப்பட்ட நிரல் வரிகள்" தவறாக வழிநடத்துவது போலவே மருத்துவமனையிலும் தவறாக வழிநடத்துகிறது. துறைகளுக்கான செயல்திறன் தரவுக் குழாய்களை உருவாக்கும் குழுக்கள் தரம் சீரமைப்பை அடிக்குறிப்பாக அல்ல, முதல்தர, பதிப்புப்படுத்தப்பட்ட உருமாற்றக் கட்டமாகக் கருத வேண்டும் — ஏனெனில் ONS-இன் சொந்த நம்பகத்தன்மை அந்தச் சீரமைப்பு வெளிப்படையாகவும், மீளுருவாக்கக்கூடியதாகவும், சிறந்த தரத் தரவு வரும்போது திருத்தப்படுவதாகவும் இருப்பதில் உள்ளது (அடிப்படைத் தரத் தரவு — எ.கா. உயிர்பிழைப்பு விகிதங்கள் — இறுதிப்படுத்தப்படும்போது ONS கடந்த ஆண்டுகளின் உற்பத்தித்திறன் மதிப்பீடுகளைத் திருத்துகிறது; எனவே இந்தப் புள்ளிவிவரங்களைப் பயன்படுத்தும் எந்தக் கீழ்நிலை அமைப்பும் புதிய காலங்களைச் சேர்ப்பதுடன் நிறுத்தாமல், பின்தேதியிட்ட திருத்தங்களையும் கையாள வேண்டும்). இது [மொத்த உரிமைச் செலவு](../அரசு-தகவல்-தொழில்நுட்பத்தில்-மொத்த-உடைமைச்-செலவு/) மற்றும் [பொதுத்துறையில் AI உற்பத்தித்திறன்](../பொதுத்துறையில்-ai-உற்பத்தித்திறன்/) உடனும் நேரடியாகச் சந்திக்கிறது: தரத்தை மேம்படுத்தாமல் அல்லது பராமரிக்காமல் மூலச் செயல்பாட்டு அளவை அதிகரிக்கும் அமைப்பு, ONS-இன் சொந்த வரையறைப்படி, உற்பத்தித்திறன் மேம்பாடு அல்ல.

## பொதுவான தவறுகள்

- **உள்ளீட்டு வளர்ச்சியை உற்பத்தித்திறன் வளர்ச்சியாகக் கருதுதல்**: அதிக ஊழியர்களுக்கு நிதியளிக்கும் அதிகச் செலவு, ஒரு உள்ளீட்டு அலகுக்கான வெளியீடும் உயர்ந்தால் தவிர, அதிக *செயல்பாட்டை* உருவாக்குகிறது, அதிக *உற்பத்தித்திறனை* அல்ல — அரசியல் கருத்துரையில் இவ்விரண்டும் வழக்கமாகக் குழப்பப்படுகின்றன.
- **தரம் சீரமைப்பை முழுமையாகப் புறக்கணித்தல்**: மூலச் செயல்பாட்டு எண்ணிக்கைகளிலிருந்து மட்டுமே கட்டப்பட்ட வெளியீட்டுக் குறியீடு, குறைந்த மதிப்புள்ள அல்லது குறைந்த தரமுள்ள ஒன்றை அதிகமாகச் செய்வதிலிருந்து "உற்பத்தித்திறன் ஆதாயங்களை" காட்டும்; ONS-இன் தரம் சீரமைப்பு இதைப் பிடிப்பதற்காகவே உள்ளது.
- **வழிமுறைப் பதிப்பு பொருந்தாமல் துணைத்துறைகளுக்கு இடையே உற்பத்தித்திறன் குறியீடுகளை ஒப்பிடுதல்**: சுகாதாரம், கல்வி, காவல் உற்பத்தித்திறன்கள் ஒவ்வொன்றும் வெவ்வேறு செயல்பாட்டு மற்றும் தரத் தரவு மூலங்களிலிருந்து, வெவ்வேறு திருத்தச் சுழற்சிகளில் கட்டப்படுகின்றன — எளிமையான துறைகளுக்கிடையிலான ஒப்பீடு பொருந்தாத கருவிகளை ஒப்பிடுகிறது.
- **ஒரு ஆண்டின் உற்பத்தித்திறன் வீழ்ச்சியை நிரந்தரப் போக்காக வாசித்தல்**: பெருந்தொற்றுக் கால மற்றும் பிந்தைய உற்பத்தித்திறன் எண்கள், தரத் தரவே (எ.கா. காத்திருப்புப் பட்டியல்கள், தேர்வு சிகிச்சை மீட்பு) மாறியதால் ஆண்டுக்கு ஆண்டு குறிப்பிடத்தக்க ஏற்ற இறக்கத்தைக் காட்டியுள்ளன; ஒற்றை ஆண்டு நகர்வுகளை அதிகமாக விளக்குவதற்கு எதிராக ONS தொடர்ந்து எச்சரிக்கிறது.
