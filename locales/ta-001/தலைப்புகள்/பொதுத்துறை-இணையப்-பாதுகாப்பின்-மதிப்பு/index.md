# பொதுத்துறை இணையப் பாதுகாப்பின் மதிப்பு

பொதுத்துறை இணையப் பாதுகாப்பின் மதிப்பு என்பது அபாயக் குறைப்புக்கு விலை நிர்ணயிக்கும் ஒழுங்குமுறை: குடிமக்கள் தரவில் மீறல் நிகழும் வாய்ப்பைக் குறைப்பதன் மதிப்பு என்ன, பாதுகாப்புச் செலவு வெற்றிகரமாக வேலை செய்யும்போது கண்ணுக்குத் தெரியும் வெளியீடு எதையும் தராது, தோல்வியுறும்போது மிகவும் புலப்படும் ஒன்றைத் தருகிறது என்பதைக் கருத்தில் கொண்டு? நலத்திட்டப் பதிவுகள், சுகாதாரத் தரவு அல்லது வரிப் பதிவுகளை வைத்திருக்கும் சேவைக்கு, "வேலை செய்யும்போது கண்ணுக்குத் தெரியாதது" என்ற இந்தப் பண்புதான் அதற்கு வெறும் இணக்கச் சரிபார்ப்பு அல்ல, வெளிப்படையான மதிப்பு வாதம் தேவைப்படுவதற்குக் காரணம்.

## ஏன் இது முக்கியம்

ஐக்கிய இராச்சியத்தின் National Cyber Security Centre-இன் Cyber Assessment Framework (CAF), பாதுகாப்பைச் சரிபார்ப்புப் பட்டியலாக அல்லாமல் மதிப்பிடக்கூடிய, விளைவு அடிப்படையிலான ஒழுங்குமுறையாக்க பொதுத்துறை அமைப்புகளுக்குக் கட்டமைக்கப்பட்ட வழியை வழங்குகிறது: அது நான்கு உயர்மட்ட நோக்கங்களை (பாதுகாப்பு அபாயத்தை நிர்வகித்தல், இணையத் தாக்குதலுக்கு எதிராகப் பாதுகாத்தல், இணையப் பாதுகாப்பு நிகழ்வுகளைக் கண்டறிதல், சம்பவங்களின் தாக்கத்தைக் குறைத்தல்) வரையறுக்கிறது; அவை ஓர் அமைப்பு உரிமையாளர் மதிப்பிடப்படக்கூடிய பங்களிப்பு விளைவுகளாகப் பிரிக்கப்பட்டுள்ளன; இது [digital-service-standard](../டிஜிட்டல்-சேவைத்-தரநிலை/)-இன் 9-ஆம் புள்ளியான ("பயனர்களின் தனியுரிமையைப் பாதுகாக்கும் பாதுகாப்பான சேவையை உருவாக்குங்கள்") அதே உணர்வில் அமைந்துள்ளது. CAF மதிப்பீடு எதற்கு எதிராகப் பாதுகாக்கிறது என்பதற்கு ஆவணப்படுத்தப்பட்ட விலைக்குறி உண்டு: IBM-இன் Cost of a Data Breach Report துறைவாரியாகச் சராசரி மீறல் செலவைக் கண்காணிக்கிறது; நிதி அல்லது சுகாதாரத்துடன் ஒப்பிடுகையில் பொதுத்துறை வரம்பின் கீழ்ப்பகுதியில் இருப்பதை அது தொடர்ந்து கண்டுள்ளது — சமீபத்திய பதிப்புகள் பொதுத்துறை சராசரியை ஒரு மீறலுக்கு சுமார் $2.6–2.9 மில்லியன் எனக் கூறுகின்றன — ஆனால் "நிதியைவிடக் குறைவு" என்பது "குறைவு" அல்ல; அரசாங்க மீறல்கள் அறிக்கையின் எண்கள் முழுமையாகப் பிடிக்காத செலவுகளைச் சுமக்கின்றன: இலக்கமுறைத் தடங்களில் குடிமக்களின் நம்பிக்கை இழப்பு, இது சேனல்-மாற்ற வணிக வழக்குகள் சார்ந்திருக்கும் [இலக்கமுறைப் பயன்பாட்டை](../வழிமாற்றச்-சேமிப்புகள்/) குறைக்கிறது; முதலில் அரசு குடிமக்களைக் கட்டாயப்படுத்திப் பெற்ற தரவை வெளிப்படுத்துவதன் அரசியல் மற்றும் சட்டச் செலவு.

## கணிதம்

பாதுகாப்பு முதலீடு, எந்தவொரு அபாயக் குறைப்புச் செலவும் மதிப்பிடப்படும் விதத்திலேயே மதிப்பிடப்படுகிறது: எதிர்பார்க்கப்படும் இழப்புக் குறைப்பாக, உன்னதமான அபாய மேலாண்மைச் சமன்பாட்டைப் பயன்படுத்தி.

```
Annualized Loss Expectancy (ALE) = Single Loss Expectancy (SLE)
                                  × Annualized Rate of Occurrence (ARO)

Value of a security control =
  ALE_before_control − ALE_after_control − annual cost of the control

A control is worth funding when:
  (ALE_before − ALE_after) > annual cost of the control

CAF assessment doesn't directly output a probability, but a service's
CAF outcome profile (which contributing outcomes are "achieved",
"partially achieved", or "not achieved") is a reasonable proxy input
to estimate ARO — a system with unmanaged privileged access or no
tested incident response plan has a materially higher realistic ARO
than one with both in place.
```

## செயல்முறை எடுத்துக்காட்டு

**40,000 குடியிருப்பாளர்களின் சமூகப் பராமரிப்புப் பதிவுகளை வைத்திருக்கும் மாவட்ட சபை வழக்கு மேலாண்மை அமைப்பு**:

```
Single Loss Expectancy (breach cost), using a public-sector-sector
average from a recent IBM Cost of a Data Breach Report ≈ £2.1m
(converted, order-of-magnitude figure — always re-derive from the
current report edition rather than reusing a fixed number)

Current ARO (unmanaged privileged access, no tested incident
response, per an internal CAF self-assessment showing multiple
"not achieved" outcomes) ≈ estimated 8% per year
  ALE_before = £2.1m × 0.08 = £168,000/year

Proposed control: privileged access management + tested incident
response plan, moving the relevant CAF outcomes to "achieved",
estimated to cut ARO to 3%/year
  ALE_after = £2.1m × 0.03 = £63,000/year

Annual cost of the control (tooling + process + testing) = £45,000

Value of the control = (168,000 − 63,000) − 45,000 = £60,000/year
  net positive — fund it. The arithmetic also shows the control
  would still be worth funding at nearly triple the cost, which is
  the kind of sensitivity check that should accompany any ALE figure
  built on estimated probabilities.
```

## மென்பொருள் பொறியியல் தொடர்பு

ALE சமன்பாட்டின் பெரும்பாலான நெம்புகோல்கள் பொறியாளர்களுக்குச் சொந்தம்: அணுகல் கட்டுப்பாட்டு வடிவமைப்பு, சார்புகள் மற்றும் இணைப்புச் சுகாதாரம், பதிவு மற்றும் கண்டறிதல் பரப்பு, சம்பவ மறுமொழிக் கருவிகள் ஆகியவை ARO உறுப்பை நேரடியாக நகர்த்துகின்றன; அதனால்தான் CAF மதிப்பீடு கொள்கைத் தணிக்கையைப் போலவே தொழில்நுட்பக் கட்டமைப்பு மதிப்பாய்வாகவும் வாசிக்கப்படுகிறது. இது [technical-debt-as-public-value-erosion](../பொது-மதிப்பின்-அரிப்பாகத்-தொழில்நுட்பக்-கடன்/) என்பதன் மிகக் கடுமையான வடிவம் — இணைப்பிடப்படாத, கண்காணிக்கப்படாத, மோசமாக அணுகல் கட்டுப்படுத்தப்பட்ட அமைப்புகள் என்பவை, வட்டித் தொகை நிலையான இழுவையாக அல்ல, வால்முனை அபாயமாக இருக்கும் கடன் — பாதுகாப்புச் செலவு அமைப்பின் உண்மையான இயக்கச் செலவிலிருந்து தனியாகக் கருதப்படாமலிருக்க, இது [total-cost-of-ownership-in-government-it](../அரசு-தகவல்-தொழில்நுட்பத்தில்-மொத்த-உடைமைச்-செலவு/) உடன் ஒத்திசைக்கப்பட வேண்டும். இது Green Book-இன் கீழ் [value-for-money](../பணத்துக்கான-மதிப்பு/) மதிப்பீடுகளுக்கும் நேரடி உள்ளீடு: அபாய-சீரமைக்கப்பட்ட செலவு எந்தவொரு வாய்ப்பு மதிப்பீட்டின் "செலவு" பக்கத்தின் பகுதி, இறுதியில் இணைக்கப்படும் பின்யோசனை அல்ல.

## பொதுவான தவறுகள்

- **CAF சுய மதிப்பீட்டையே பாதுகாப்பாகக் கருதுதல்**: முடிக்கப்பட்ட மதிப்பீடு ஒரு பாதுகாப்பு நிலையை விவரிக்கிறது, அதை உருவாக்குவதில்லை — மதிப்பு ஆவணத்தில் அல்ல, எட்டப்பட்ட விளைவுகளில் உள்ளது.
- **உலகளாவிய சராசரி மீறல் செலவுகளைச் சீரமைப்பின்றி உள்ளூர் மதிப்பீடாகப் பயன்படுத்துதல்**: IBM-இன் எண்கள் பெரிய, வேறுபட்ட மாதிரிகளின் சராசரிகள்; ஒரு சிறிய உள்ளாட்சி அமைப்பின் யதார்த்தமான ஒற்றை இழப்பு எதிர்பார்ப்பு தேசிய அரசுத் துறையுடையதிலிருந்து அரிதாகவே ஒன்றாக இருக்கும்.
- **முதலீட்டு முடிவுகளில் வால்முனை அபாய உளவியலைப் புறக்கணித்தல்**: குறைந்த ஆண்டு நிகழ்தகவு, பாதுகாப்புச் செலவை முடிவில்லாமல் ஒத்திவைப்பதை எளிதாக்குகிறது — அது நடக்கும் ஆண்டு வரை; எடுத்துக்காட்டில் உள்ளது போல ALE கணக்கீட்டை ARO-க்களின் வரம்புக்கு எதிராக உணர்திறன் சோதனை செய்வது இதை எதிர்க்கிறது.
- **IBM பாணி மீறல் செலவை மட்டும் எண்ணி, நம்பிக்கைச் செலவை எண்ணாமை**: இலக்கமுறைத் தடங்களைப் பயன்படுத்தும் குடிமக்களின் விருப்பத்தைக் குறைக்கும் மீறல், [channel-shift-savings](../வழிமாற்றச்-சேமிப்புகள்/) வழக்கை ஆண்டுகள் வரை அரிக்கிறது; மீறல் செலவு மதிப்பீடுகளில் இது அரிதாகவே சேர்க்கப்படுகிறது.
