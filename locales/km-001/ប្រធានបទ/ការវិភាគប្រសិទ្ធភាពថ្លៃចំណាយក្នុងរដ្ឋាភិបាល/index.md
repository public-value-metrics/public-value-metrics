# ការវិភាគប្រសិទ្ធភាពថ្លៃចំណាយក្នុងរដ្ឋាភិបាល

ការវិភាគប្រសិទ្ធភាពថ្លៃចំណាយ (cost-effectiveness analysis ឬ CEA) ប្រៀបធៀបថ្លៃចំណាយនៃមធ្យោបាយជំនួសផ្សេងៗដើម្បីសម្រេចលទ្ធផល*ដូចគ្នា* ដែលបង្ហាញជាឯកតាធម្មជាតិ គឺថ្លៃចំណាយក្នុងមួយអ្នកដេកតាមផ្លូវដែលបានទទួលលំនៅដ្ឋាន ថ្លៃចំណាយក្នុងមួយសិស្សដែលត្រូវបានលើកដល់ស្តង់ដារដែលរំពឹង ថ្លៃចំណាយក្នុងមួយតោន CO2 ដែលបានកាត់បន្ថយ ដោយមិនបម្លែងលទ្ធផលខ្លួនឯងទៅជារូបិយវត្ថុទេ។

## ហេតុអ្វីបានជាសំខាន់

Green Book ចាត់ទុក CEA ជាវិធីសាស្ត្រតាមក្រោយ នៅពេលតម្រូវការនៃ [ការវិភាគថ្លៃចំណាយ-អត្ថប្រយោជន៍សង្គម](../ការវិភាគថ្លៃដើម-អត្ថប្រយោជន៍សង្គម/) ក្នុងការបម្លែងអត្ថប្រយោជន៍ទាំងអស់ទៅជារូបិយវត្ថុ ក្លាយជាមិនត្រឹមតែពិបាក ប៉ុន្តែមិនស្មោះត្រង់ គឺកន្លែងដែលការដាក់តម្លៃដែលអាចជឿជាក់បានលើលទ្ធផលតម្រូវឱ្យមានការសន្មតដែលគ្មានអ្នកណាកាន់ពិតប្រាកដ (<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>, Chapter 5 ស្តីពីការវាយតម្លៃជម្រើសដែលលទ្ធផលមិនអាចបម្លែងជារូបិយវត្ថុបានភ្លាមៗ)។ CEA គឺជាវិធីសាស្ត្រដែលខ្ចីដោយផ្ទាល់បំផុតពីសេដ្ឋកិច្ចសុខភាព ដោយមានរចនាសម្ព័ន្ធដូចគ្នាទៅនឹងរបៀបដែល NICE ប្រៀបធៀបការព្យាបាលដោយប្រើថ្លៃចំណាយក្នុងមួយ Quality-Adjusted Life Year (QALY) ប៉ុន្តែអនុវត្តចំពោះកម្មវិធីសាធារណៈមិនមែនសុខភាព៖ អន្តរាគមន៍អប់រំក្នុងមួយពិន្ទុលទ្ធផលសិស្ស កម្មវិធីលំនៅដ្ឋានក្នុងមួយគ្រួសារដែលត្រូវបានការពារពីការគ្មានទីជម្រក កម្មវិធីការងារក្នុងមួយលទ្ធផលការងារប្រកបដោយនិរន្តរភាព។

មូលហេតុដែល CEA ឈរជាមួយ SCBA ជាជាងត្រូវបានស្រូបចូល គឺដោយសារការបង្ខំតម្លៃរូបិយវត្ថុលើលទ្ធផលមួយចំនួនបង្កើតលេខជាក់លាក់គ្រប់គ្រាន់ដើម្បីមើលទៅមានសិទ្ធិអំណាច និងមានការជំទាស់គ្រប់គ្រាន់ដើម្បីគ្មានតម្លៃក្នុងការពិភាក្សាសាធារណៈ ព្រោះការដាក់តម្លៃលើ «កុមារម្នាក់អានបានតាមស្តង់ដារដែលរំពឹង» អញ្ជើញការជំទាស់ប្រភេទដែលធ្វើឱ្យករណីអាជីវកម្មធ្លាក់ចុះនៅគណៈកម្មាធិការជ្រើសរើស។ CEA គេចចេញពីការជជែកដោយបដិសេធមិនមានវា៖ វាចាត់ថ្នាក់ជម្រើសតាមថ្លៃចំណាយក្នុងមួយឯកតានៃ*លទ្ធផលខ្លួនឯង* ដោយទុកការវិនិច្ឆ័យនយោបាយដាច់ដោយឡែកអំពីថាតើលទ្ធផលនោះគួរតាមដេញឬអត់ ទៅករណីយុទ្ធសាស្ត្រ។

## គណិតវិទ្យា

```
Cost-effectiveness ratio (average) = Total cost / Total outcome units achieved

Incremental cost-effectiveness ratio (ICER), comparing option A to option B:
ICER = (Cost_A − Cost_B) / (Outcome_A − Outcome_B)

Procedure:
1. Fix the outcome unit and measurement method across all options being compared.
2. Cost every option on the same basis (see ../green-book-appraisal/, financial case)
   over the same time horizon.
3. Discard dominated options: any option costing more per unit than a cheaper
   alternative achieving the same or better outcome is dropped.
4. Rank remaining options by incremental, not average, cost-effectiveness ratio.
```

CEA មិនអាចប្រាប់ដោយខ្លួនឯងថាតើកម្មវិធីមួយសមនឹងផ្តល់មូលនិធិអត់ទេ ប្រាប់បានតែថាវិធីសាស្ត្រណាមួយក្នុងចំណោមវិធីសាស្ត្រជាច្រើនសម្រាប់គោលដៅដូចគ្នាថោកជាងក្នុងមួយឯកតា។ ការសម្រេចថាតើគោលដៅខ្លួនឯងសមនឹងចំណាយ តម្រូវឱ្យបម្លែងត្រឡប់ទៅ SCBA (ប្រសិនបើមានការវាយតម្លៃដែលអាចជឿជាក់បាន) ឬការវិនិច្ឆ័យនយោបាយ/យុទ្ធសាស្ត្រក្រៅពីគណិតវិទ្យា។ ក្នុងករណីដែលលទ្ធផលមិនអាចកាត់បន្ថយទៅជាឯកតាតែមួយពិតប្រាកដ ព្រោះកម្មវិធីបង្កើតលទ្ធផលជាច្រើនដែលសំខាន់តាមរបៀបខុសគ្នា សូមប្រើ [ការវិភាគការសម្រេចចិត្តពហុលក្ខណៈវិនិច្ឆ័យ](../ការវិភាគការសម្រេចចិត្តពហុលក្ខណៈវិនិច្ឆ័យ/) ជំនួសវិញ។

## ឧទាហរណ៍គណនា

**អាជ្ញាធរមូលដ្ឋាន**៖ ក្រុមប្រឹក្សាមួយប្រៀបធៀបវិធីសាស្ត្របីដើម្បីកាត់បន្ថយការដេកតាមផ្លូវ ដោយកំណត់ថ្លៃចំណាយក្នុងរយៈពេលមួយឆ្នាំធៀបនឹងលទ្ធផល «បុគ្គលដែលបានផ្លាស់ទៅកន្លែងស្នាក់នៅស្ថិរភាព 6+ ខែ»៖

```
Option                          Cost       Outcomes achieved   Avg CER
Housing First (intensive)       £900,000   60                  £15,000/outcome
Hostel + move-on support        £600,000   50                  £12,000/outcome
Outreach + private rented sector £350,000  20                  £17,500/outcome

ICER, Hostel vs Outreach:  (600k−350k)/(50−20) = £8,333 per additional outcome
ICER, Housing First vs Hostel: (900k−600k)/(60−50) = £30,000 per additional outcome
```

**រដ្ឋាភិបាលជាតិ**៖ កម្មវិធីអានចាប់ទាន់មួយត្រូវបានប្រៀបធៀបតាមគំរូផ្តល់សេវាបីលើ «ថ្លៃចំណាយក្នុងមួយសិស្សដែលឈានដល់ស្តង់ដារអានតាមអាយុ»៖ ការបង្រៀនឯកជនម្នាក់ម្នាក់ (£1,800/សិស្ស) ការបង្រៀនក្រុមតូច (£700/សិស្ស) និងអន្តរាគមន៍ឌីជីថលតែមួយ (£150/សិស្ស ប៉ុន្តែមានតែ 40% នៃអត្រាលទ្ធផលនៃការបង្រៀនក្រុមតូចក្នុងមួយសិស្សដែលបានចុះឈ្មោះ ក្រោយកែតម្រូវតាមការធ្លាក់ចុះនៃការចូលរួម)។ ក្រោយកែតម្រូវតាមការបំពេញជាក់ស្តែង ឌីជីថលតែមួយចំណាយ £375 ក្នុងមួយសិស្សដែលឈានដល់ស្តង់ដារ ដែលនៅតែថោកបំផុត ប៉ុន្តែ CEA មិនអាចប្រាប់ថាតើចំនួនដាច់ខាតតិចជាងនៃសិស្សដែលត្រូវបានជួយដោយឌីជីថលតែមួយ ប្រសិនបើផ្តល់ក្នុងថវិកាដូចគ្នានឹងក្រុមតូច គឺជាការដោះដូរដែលអាចទទួលយកបានធៀបនឹងការឈានដល់សិស្សតិចជាងដោយជម្រៅខ្លាំងជាងដែរឬទេ នោះជាការវិនិច្ឆ័យចែកចាយដែល CEA ប្រគល់ត្រឡប់ទៅអ្នកសម្រេចចិត្ត។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

CEA គឺជាក្របខណ្ឌត្រឹមត្រូវនៅពេលក្រុមវិស្វកម្មវាយតម្លៃវិធីសាស្ត្រផ្តល់សេវាសម្រាប់លទ្ធផលសេវា*ដូចគ្នា* គឺថ្លៃចំណាយក្នុងមួយអត្តសញ្ញាណដែលបានផ្ទៀងផ្ទាត់ដោយជោគជ័យ ឆ្លងកាត់អ្នកលក់ផ្ទៀងផ្ទាត់អត្តសញ្ញាណបី ថ្លៃចំណាយក្នុងមួយករណីដែលបានចាត់ថ្នាក់ត្រឹមត្រូវ ឆ្លងកាត់ការរចនាស្វ័យប្រវត្តិកម្មករណីពីរ ថ្លៃចំណាយក្នុងមួយកំហុសភាពអាចចូលប្រើបានដែលបានដោះស្រាយ ឆ្លងកាត់ការកែតម្រូវក្នុងផ្ទះធៀបនឹងអ្នកម៉ៅការ។ វិន័យដែលវានាំចូលដោយផ្ទាល់៖ កំណត់ឯកតាលទ្ធផលមុនប្រៀបធៀបថ្លៃចំណាយ (មិនមែន «សំបុត្រដែលបានបិទ» ដែលជាផលិតកម្មទេ ប៉ុន្តែ «តម្រូវការអ្នកប្រើដែលបានដោះស្រាយពិតប្រាកដ») ហើយគណនាសមាមាត្របន្ថែមជានិច្ចរវាងប្រព័ន្ធដែលកំពុងដំណើរការ និងការជំនួសដែលបានស្នើ មិនមែនថ្លៃចំណាយមធ្យមនៃប្រព័ន្ធនីមួយៗដាច់ដោយឡែកទេ។ សូមមើល [លទ្ធផល ធៀបនឹងផលិតកម្ម](../លទ្ធផល-ធៀបនឹង-ទិន្នផល/) និង [ថ្លៃចំណាយក្នុងមួយលទ្ធផល](../ថ្លៃចំណាយក្នុងមួយលទ្ធផល/)។

## កំហុសដែលតែងកើតមាន

- **ការប្រៀបធៀបសមាមាត្រមធ្យម មិនមែនសមាមាត្របន្ថែម នៅពេលសម្រេចចិត្តលើការពង្រីក។** ដូចឧទាហរណ៍ការដេកតាមផ្លូវបង្ហាញ ជម្រើសដែលមានសមាមាត្រមធ្យមល្អបំផុតមិនមែនជាឯកតាលទ្ធផលបន្ទាប់ដែលថោកបំផុតដើម្បីទិញជានិច្ចទេ។
- **ការជ្រើសរើសឯកតាលទ្ធផលដែលពិតជាផលិតកម្ម។** «ការបញ្ជូនបន្តដែលបានធ្វើ» ឬ «វគ្គដែលបានផ្តល់» វាស់សកម្មភាព មិនមែនលទ្ធផលដែលកម្មវិធីមានដើម្បីបង្កើតទេ ហើយ CEA លើផលិតកម្មបង្កើតលេខដែលមើលទៅមានទំនុកចិត្ត ប៉ុន្តែឆ្លើយសំណួរខុស។
- **ការប្រៀបធៀបឆ្លងលទ្ធផលខុសគ្នាពិតប្រាកដ។** CEA ត្រឹមត្រូវតែនៅពេលជម្រើសទាំងអស់កំណត់គោលដៅលទ្ធផលដូចគ្នា ដែលបានវាស់តាមវិធីដូចគ្នា ការប្រៀបធៀប «ថ្លៃចំណាយក្នុងមួយអ្នកដេកតាមផ្លូវដែលបានទទួលលំនៅដ្ឋាន» ធៀបនឹង «ថ្លៃចំណាយក្នុងមួយអ្នកចាកចេញពីការថែទាំក្នុងកិច្ចសន្យាជួលស្ថិរភាព» ត្រូវការរង្វាស់លទ្ធផលទូទៅ ឬ [ការវិភាគការសម្រេចចិត្តពហុលក្ខណៈវិនិច្ឆ័យ](../ការវិភាគការសម្រេចចិត្តពហុលក្ខណៈវិនិច្ឆ័យ/) មិនមែន CEA ទេ។
- **ការមិនអើពើនឹងភាពស្ថិតស្ថេរនៃលទ្ធផល។** ជម្រើសថោកជាងដែលបង្កើតលទ្ធផលដែលមិនស្ថិតស្ថេរ (សិស្សដែលថយក្រោយបន្ទាប់ពីអន្តរាគមន៍បញ្ចប់) មិនមែនមានប្រសិទ្ធភាពថ្លៃចំណាយច្រើនជាងពិតប្រាកដទេ នៅពេលវាស់ក្នុងចក្ខុវិស័យអាចប្រៀបធៀប ដូច្នេះត្រូវផ្គូផ្គងរយៈពេលតាមដានឆ្លងកាត់ជម្រើសដែលកំពុងប្រៀបធៀប។
