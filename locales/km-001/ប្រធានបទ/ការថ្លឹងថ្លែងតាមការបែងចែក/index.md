# ការថ្លឹងថ្លែងតាមការបែងចែក

ការថ្លឹងថ្លែងតាមការបែងចែក (distributional weighting) កែតម្រូវតម្លៃជាប្រាក់នៃការចំណាយ ឬអត្ថប្រយោជន៍ តាមអ្នកដែលទទួលវា ដោយផ្អែកលើគោលការណ៍ថា ផោនបន្ថែមមួយមានតម្លៃច្រើនជាងសម្រាប់គ្រួសារក្រីក្រ ជាងគ្រួសារអ្នកមាន។ សៀវភៅ Green Book របស់ HM Treasury ផ្តល់វិធីសាស្ត្រច្បាស់លាស់សម្រាប់អនុវត្តការថ្លឹងថ្លែងនេះ ដែលសង់លើឧបភោគប្រយោជន៍ទីបំផុតនៃប្រាក់ចំណូលដែលថយចុះ ដើម្បីកុំឱ្យការវាយតម្លៃចាត់ទុកដោយស្ងាត់ៗថា ផោនដែលទទួលបានដោយក្រុមដេស៊ីលអ្នកមានបំផុត មានតម្លៃស្មើនឹងផោនដែលទទួលបានដោយក្រុមក្រីក្របំផុត។

## ហេតុអ្វីបានជាសំខាន់

ការវិភាគចំណាយ-អត្ថប្រយោជន៍ស្តង់ដារបូកផោនដោយមិនសួរថាជាផោនរបស់អ្នកណា ដែលសន្មតដោយបង្កប់ថាផោនមួយមានតម្លៃដូចគ្នាសម្រាប់មនុស្សគ្រប់គ្នា — ជាការសន្មតដែលអ្នកសេដ្ឋកិច្ចដឹងតាំងពីយូរមកហើយថាមិនពិត។ គ្រួសារដែលរកបាន £15,000/ឆ្នាំ ទទួលអារម្មណ៍ចំពោះប្រាក់ចំណេញ £1,000 ខុសគ្នាខ្លាំងពីគ្រួសារដែលរកបាន £150,000/ឆ្នាំ ពីព្រោះឧបភោគប្រយោជន៍ទីបំផុតនៃប្រាក់ចំណូលធ្លាក់ចុះនៅពេលប្រាក់ចំណូលកើនឡើង។ ប្រសិនបើមិនថ្លឹងថ្លែង ការវាយតម្លៃស្តង់ដារនឹងពេញចិត្តជាប្រព័ន្ធចំពោះអន្តរាគមន៍ដែលផ្តល់ផលដល់ក្រុមមានជាង និងមានស្រាប់ ព្រោះអំណាចចំណាយខ្ពស់ជាងរបស់ពួកគេបំផ្លើសតម្លៃជាប្រាក់នៃអត្ថប្រយោជន៍ដែលទៅដល់ពួកគេ (ការកែលម្អសួនច្បារនៅជិតផ្ទះថ្លៃ "បង្ហាញ" អត្ថប្រយោជន៍តម្លៃអចលនទ្រព្យធំជាងការកែលម្អដូចគ្នានៅជិតផ្ទះថោក គ្រាន់តែពីព្រោះតម្លៃខ្ពស់ជាង មិនមែនពីព្រោះផលសុខុមាលភាពធំជាងទេ)។

ការណែនាំបន្ថែមរបស់ Green Book ស្តីពីការវិភាគតាមការបែងចែក ដែលត្រូវបានពង្រឹងបន្ទាប់ពីការពិនិត្យឡើងវិញរបស់ Treasury ឆ្នាំ 2020 ឆ្លើយតបនឹងការរិះគន់ថាវិធីសាស្ត្រវាយតម្លៃពេញចិត្តជាប្រព័ន្ធចំពោះទីក្រុងឡុងដ៍ និងភាគអាគ្នេយ៍ កំណត់វិធីថ្លឹងថ្លែងជាផ្លូវការ ដោយផ្អែកលើបត់បែនភាព (elasticity) នៃឧបភោគប្រយោជន៍ទីបំផុតនៃប្រាក់ចំណូលដែលសន្មតប្រហែល 1.3 — មានន័យថា ប្រាក់ចំណូលកើនពីរដងធ្វើឱ្យតម្លៃទីបំផុតនៃផោនបន្ថែមថយចុះប្រហែលពាក់កណ្តាល (ជាក់លាក់គឺ 2^-1.3 ≈ 0.41 ដង)។ នេះមិនមែនជាការកែតម្រូវបង្គត់ទេ៖ ការអនុវត្តវាអាចផ្លាស់ប្តូរថាតើកម្មវិធីប្រកួតប្រជែងពីរណាមួយបង្ហាញតម្លៃបច្ចុប្បន្នសុទ្ធ (net present value) ខ្ពស់ជាង ជាពិសេសនៅពេលប្រៀបធៀបអន្តរាគមន៍ដែលប្រមូលផ្តុំក្នុងតំបន់ខ្វះខាត ជាមួយអន្តរាគមន៍ដែលរាលដាលទូទាំងប្រជាជនទូទៅ។

## គណិតវិទ្យា

ទម្ងន់តាមការបែងចែករបស់ Green Book សម្រាប់ផោនអត្ថប្រយោជន៍ដែលធ្លាក់លើគ្រួសារនៅកម្រិតប្រាក់ចំណូល y ធៀបនឹងផោនមួយនៅកម្រិតប្រាក់ចំណូលមធ្យមជាតិ ȳ៖

```
Weight(y) = (ȳ / y)^e

where:
  y  = household income (or income of the affected group)
  ȳ  = average (reference) household income
  e  = elasticity of marginal utility of income (Green Book: approximately 1.3)
```

ការអនុវត្តទម្ងន់ទៅលើអត្ថប្រយោជន៍សុទ្ធ៖

```
Weighted benefit = Σ [unweighted benefit to group i × Weight(y_i)]
```

ក្រុមដែលរកបានពាក់កណ្តាលនៃមធ្យមជាតិ (y = 0.5ȳ) ទទួលបានទម្ងន់ (1/0.5)^1.3 = 2^1.3 ≈ 2.46 — ផោនអត្ថប្រយោជន៍នីមួយៗសម្រាប់ក្រុមនោះរាប់ថាមានតម្លៃប្រហែល 2.46 ដងនៃផោនសម្រាប់គ្រួសារដែលមានប្រាក់ចំណូលមធ្យម។

## ឧទាហរណ៍គណនា

**កម្មវិធីក្នុងមូលដ្ឋានពីរដែលប្រកួតប្រជែងគ្នា** ម្នាក់ៗមានអត្ថប្រយោជន៍សុទ្ធដែលមិនទាន់ថ្លឹងថ្លែង £2 លាន/ឆ្នាំ ប្រកួតប្រជែងសម្រាប់មូលនិធិកំណើនតំបន់តែមួយ៖

- *កម្មវិធី A*៖ គម្រោងគាំទ្រអាជីវកម្មក្នុងទីក្រុងមានបាន ប្រាក់ចំណូលគ្រួសារមធ្យម £45,000 (ប្រហែល 1.3× នៃមធ្យមជាតិដែលសន្មត £35,000)។
- *កម្មវិធី B*៖ កម្មវិធីជំនាញក្នុងសង្កាត់ខ្វះខាត ប្រាក់ចំណូលគ្រួសារមធ្យម £18,000 (ប្រហែល 0.51× នៃមធ្យមជាតិ)។

```
Weight(A) = (35,000 / 45,000)^1.3 = (0.778)^1.3 ≈ 0.72
Weight(B) = (35,000 / 18,000)^1.3 = (1.944)^1.3 ≈ 2.53

Weighted benefit A = £2,000,000 × 0.72 = £1.44 million
Weighted benefit B = £2,000,000 × 2.53 = £5.06 million
```

មុនថ្លឹងថ្លែង កម្មវិធីទាំងពីរស្មើគ្នា។ បន្ទាប់ពីថ្លឹងថ្លែងសម្រាប់ផលប៉ះពាល់តាមការបែងចែក អត្ថប្រយោជន៍របស់កម្មវិធី B ធំជាងបីដង — លទ្ធផលដែលបញ្ច្រាសអនុសាសន៍មូលនិធិ ហើយឆ្លុះបញ្ចាំងពីគោលបំណងច្បាស់លាស់របស់ Green Book ក្នុងការតម្រូវឱ្យបង្ហាញការថ្លឹងថ្លែង មិនមែនគ្រាន់តែសមាមាត្រអត្ថប្រយោជន៍-ចំណាយដែលមិនទាន់ថ្លឹងថ្លែងប៉ុណ្ណោះ។

**ការបែងចែកជំនួយសប្បុរសធម៌**៖ អ្នកផ្តល់មូលនិធិដែលប្រៀបធៀបជំនួយ £500,000 ដែលទៅដល់គ្រួសារចំណូលទាប 1,000 (ទម្ងន់ ≈ 2.0 តម្លៃថ្លឹងថ្លែង ស្មើ £1 លាន) ជាមួយជំនួយ £500,000 ដូចគ្នាដែលទៅដល់គ្រួសារចំណូលមធ្យម 1,000 (ទម្ងន់ ≈ 1.0 តម្លៃថ្លឹងថ្លែង ស្មើ £500,000) គួរបង្ហាញករណីតាមការបែងចែកយ៉ាងច្បាស់ក្នុងឯកសារក្រុមប្រឹក្សារបស់ខ្លួន មិនទុកឱ្យគេសន្និដ្ឋានខ្លួនឯងទេ។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

- នៅពេលសាងសង់ផ្ទាំងគ្រប់គ្រងផលប៉ះពាល់ ឬម៉ាស៊ីនគិតអត្ថប្រយោជន៍ ត្រូវបង្ហាញទម្រង់ប្រាក់ចំណូល ឬភាពខ្វះខាតរបស់អ្នកដែលរងផលប៉ះពាល់ មិនមែនគ្រាន់តែសរុបអត្ថប្រយោជន៍រួមទេ — តួលេខរួមដែលគ្មានការបំបែកតាមការបែងចែកលាក់ពិតជាការបញ្ច្រាសដែលបានបង្ហាញខាងលើ។
- ភ្ជាប់តក្កកម្មកំណត់គោលដៅក្នុងការរចនាសេវា ទៅនឹងទិន្នន័យភាពខ្វះខាតដូចគ្នាដែល Green Book ប្រើ — សូមមើល [សន្ទស្សន៍ភាពខ្វះខាតច្រើនវិមាត្រ](../សន្ទស្សន៍ភាពខ្វះខាតច្រើនវិមាត្រ/) — ដើម្បីឱ្យការទៅដល់នៃសេវាឌីជីថលអាចត្រូវបានវាយតម្លៃផ្នែកសមធម៌ មិនមែនគ្រាន់តែប្រសិទ្ធភាពទេ (E ទីបួនដែលមានភាពចម្រូងចម្រាសក្នុង [តម្លៃសមស្របនឹងប្រាក់ចំណាយ](../តម្លៃសមស្របនឹងថ្លៃចំណាយ/))។
- នៅពេលក្បួនដោះស្រាយបែងចែកធនធានកម្រ (ពេលណាត់ជួប ពេលវេលាអ្នកគ្រប់គ្រងករណី ឧបត្ថម្ភធន) អនុគមន៍គោលដៅ "ពង្រីកអត្ថប្រយោជន៍សរុបឱ្យអតិបរមា" ដែលមិនទាន់ថ្លឹងថ្លែង នឹងបង្កើតឡើងវិញនូវភាពលម្អៀងដដែលដែលការថ្លឹងថ្លែងរបស់ Green Book មានដើម្បីកែតម្រូវ — ត្រូវបង្ហាញរឿងនេះដល់ម្ចាស់គោលនយោបាយឱ្យច្បាស់ មុនពេលធ្វើឱ្យប្រសើរ។

## កំហុសដែលតែងកើតមាន

- **អនុវត្តទម្ងន់តាមការបែងចែកមិនស៊ីសង្វាក់គ្នាក្នុងផលប័ត្រ។** ការថ្លឹងថ្លែងអត្ថប្រយោជន៍របស់កម្មវិធីមួយ ប៉ុន្តែមិនថ្លឹងថ្លែងអ្នកប្រៀបធៀប បង្កើតការប្រៀបធៀបលម្អៀង មិនមែនយុត្តិធម៌ជាងទេ។ Green Book តម្រូវឱ្យមានការព្យាបាលស្មើគ្នា។
- **ប្រើតម្លៃអចលនទ្រព្យ ឬតម្លៃទីផ្សារជាតំណាងសុខុមាលភាពដោយមិនកែតម្រូវ។** តម្លៃទីផ្សារខ្លួនឯងត្រូវបានបង្ខូចដោយវិសមភាពប្រាក់ចំណូលដែលមានស្រាប់ ដែលជាអ្វីដែលការថ្លឹងថ្លែងតាមការបែងចែកមានគោលបំណងកែតម្រូវ — ការប្រើតម្លៃទីផ្សារដែលមិនបានកែអាចរាប់ភាពលម្អៀងពីរដង។
- **មិនអើពើភាពខុសគ្នាក្នុងក្រុម។** ការថ្លឹងថ្លែងតាមប្រាក់ចំណូលមធ្យមតំបន់ (ឧទាហរណ៍ ដេស៊ីលនៃសន្ទស្សន៍ភាពខ្វះខាតច្រើនវិមាត្រ) អាចតំណាងខុសចំពោះបុគ្គលដែលមិនត្រូវនឹងមធ្យមតំបន់របស់ខ្លួន។ ត្រូវប្រើទិន្នន័យប្រាក់ចំណូលលម្អិតបំផុតដែលអាចរកបានដោយសមហេតុផល។
- **ចាត់ទុកបត់បែនភាព 1.3 ជាថេរសកល។** Green Book ខ្លួនឯងកត់សម្គាល់ថានេះជាការប៉ាន់ស្មានដែលមានដែនសមហេតុផល។ ត្រូវសាកល្បងភាពរសើបនៃការសម្រេចចិត្តធំៗចំពោះបត់បែនភាពជំនួស ជាជាងចាត់ទុក 1.3 ជាតម្លៃច្បាស់លាស់។
