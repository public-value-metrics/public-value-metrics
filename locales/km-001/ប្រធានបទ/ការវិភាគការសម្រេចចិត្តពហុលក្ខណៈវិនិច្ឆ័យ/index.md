# ការវិភាគការសម្រេចចិត្តពហុលក្ខណៈវិនិច្ឆ័យ (MCDA)

MCDA ដាក់ពិន្ទុ និងថ្លឹងជម្រើសប្រឆាំងនឹងលក្ខណៈវិនិច្ឆ័យផ្សេងៗគ្នាជាច្រើនដែលមានទម្ងន់ក្នុងពេលតែមួយ បង្កើតការប្រៀបធៀបតាមចំណាត់ថ្នាក់ ដោយមិនបង្ខំលក្ខណៈវិនិច្ឆ័យនីមួយៗទៅក្នុងមាត្រដ្ឋានរូបិយវត្ថុ ឬឯកតាធម្មជាតិតែមួយ។ វាជាវិធីសាស្ត្រវាយតម្លៃសម្រាប់ការសម្រេចចិត្តដែលលទ្ធផលសំខាន់ៗពិតជាមិនអាចកាត់បន្ថយទៅជាលេខតែមួយបាន។

## ហេតុអ្វីបានជាសំខាន់

Green Book អនុញ្ញាតយ៉ាងច្បាស់នូវ MCDA (ឧបសម្ព័ន្ធករណីសិក្សា Box 2 និង Annex A របស់វាទាំងពីរពិភាក្សាវាដោយផ្ទាល់) សម្រាប់ការវាយតម្លៃដែលអត្ថប្រយោជន៍ "មិនអាចប្រៀបធៀបជាមួយគ្នាបានពិតប្រាកដ" — ដែលការបម្លែងអ្វីៗទាំងអស់ទៅជាប្រាក់តាម[ការវិភាគថ្លៃដើម-ផលប្រយោជន៍សង្គម](../ការវិភាគថ្លៃដើម-អត្ថប្រយោជន៍សង្គម/) ឬទៅជាលទ្ធផលតែមួយតាម[ការវិភាគប្រសិទ្ធភាពថ្លៃដើមក្នុងរដ្ឋាភិបាល](../ការវិភាគប្រសិទ្ធភាពថ្លៃចំណាយក្នុងរដ្ឋាភិបាល/) នឹងបង្ខូចការសម្រេចចិត្ត ជាជាងធ្វើឱ្យច្បាស់
(<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>)។
ឧទាហរណ៍ ការជ្រើសរើសទីតាំងសម្រាប់ពន្ធនាគារថ្មី ដោះដូរថ្លៃដើមដើមទុនជាមួយផលប៉ះពាល់សហគមន៍ ការតភ្ជាប់ដឹកជញ្ជូន ផលប៉ះពាល់បរិស្ថាន និងលទ្ធភាពជ្រើសរើសបុគ្គលិក — លក្ខណៈវិនិច្ឆ័យដែលមិនចែករំលែកឯកតាធម្មតា ហើយការបង្ខំឱ្យមានឯកតារួម (ជាធម្មតាប្រាក់) នឹងលួចបញ្ចូលការវិនិច្ឆ័យតម្លៃអំពីសារៈសំខាន់ដែលទាក់ទងនៃឧទាហរណ៍ ផលប៉ះពាល់បរិស្ថាន ធៀបនឹងថ្លៃដើម ដែលបិទបាំងជាការគណនាដែលមើលទៅអព្យាក្រឹត។

ភាពស្មោះត្រង់របស់ MCDA ក៏ជាភាពងាយរងគ្រោះសំខាន់របស់វាដែរ៖ ដោយសារទម្ងន់ត្រូវបានកំណត់ដោយអ្នកដែលធ្វើការវាយតម្លៃ (ឬដោយក្រុមប្រឹក្សា) វិធីសាស្ត្រនេះស្របធម៌បានតែស្មើនឹងដំណើរការថ្លឹងទម្ងន់ប៉ុណ្ណោះ។ ការណែនាំរបស់ Green Book ច្បាស់ថាលក្ខណៈវិនិច្ឆ័យ និងទម្ងន់ត្រូវតែត្រូវបានយល់ព្រម និងបោះពុម្ពផ្សាយ*មុន*ពេលជម្រើសត្រូវបានដាក់ពិន្ទុ ពិតជាដើម្បីការពារអ្នកត្រួតពិនិត្យមិនឱ្យធ្វើការថយក្រោយពីជម្រើសដែលពេញចិត្ត ទៅរកទម្ងន់ដែលបង្ហាញភាពសមហេតុផលរបស់វា។

## គណិតវិទ្យា

```
សម្រាប់ជម្រើស i និងលក្ខណៈវិនិច្ឆ័យ j នីមួយៗ៖
  Score_ij   = ដំណើរការរបស់ជម្រើសប្រឆាំងនឹងលក្ខណៈវិនិច្ឆ័យនោះ (ជារឿយៗ 0-100
               ឬ 1-10 ពីភស្តុតាង ការវិនិច្ឆ័យអ្នកជំនាញ ឬការដាក់ពិន្ទុភាគីពាក់ព័ន្ធ)
  Weight_j   = សារៈសំខាន់ដែលទាក់ទងនៃលក្ខណៈវិនិច្ឆ័យ j ទម្ងន់បូកបាន 1 (ឬ 100)

ពិន្ទុថ្លឹងទម្ងន់នៃជម្រើស i = Σ_j (Score_ij × Weight_j)

នីតិវិធី៖
1. យល់ព្រមលើសំណុំលក្ខណៈវិនិច្ឆ័យ និងទម្ងន់ មុនដាក់ពិន្ទុជម្រើសណាមួយ (swing
   weighting ឬការប្រៀបធៀបគូ ឧ. AHP គឺជាវិធីសាស្ត្របង្កើតទូទៅ)។
2. ដាក់ពិន្ទុជម្រើសនីមួយៗប្រឆាំងនឹងលក្ខណៈវិនិច្ឆ័យនីមួយៗលើមាត្រដ្ឋានរួម ពី
   ភស្តុតាងកន្លែងដែលអាច។
3. គណនាសរុបថ្លឹងទម្ងន់ ចាត់ថ្នាក់ជម្រើស។
4. សាកល្បងភាពប្រែប្រួលនៃទម្ងន់៖ តើចំណាត់ថ្នាក់នៅតែបន្តក្នុងករណីមានការមិនយល់ស្របសមហេតុផល
   អំពីថាតើលក្ខណៈវិនិច្ឆ័យនីមួយៗគួរសំខាន់ប៉ុណ្ណា?
```

MCDA មិនបង្កើតតម្លៃដាច់ខាតដែលអាចការពារបានដូចតម្លៃបច្ចុប្បន្នសុទ្ធរបស់ SCBA ទេ — វាបង្កើតតែចំណាត់ថ្នាក់ដែលមានលក្ខខណ្ឌលើទម្ងន់ដែលបានយល់ព្រមប៉ុណ្ណោះ។ នេះគឺជាលក្ខណៈពិសេស នៅពេលការសម្រេចចិត្តពិតជាអំពីការដោះដូរទំនិញដែលមិនអាចប្រៀបធៀបជាមួយគ្នា ហើយជាបន្ទុកប្រសិនបើប្រើដើម្បីគេចពីការងារពិបាកជាងនៃការបម្លែងជាប្រាក់ នៅកន្លែងដែលការបម្លែងជាប្រាក់ពិតជាអាចធ្វើទៅបាន។

## ឧទាហរណ៍គណនា

**អាជ្ញាធរមូលដ្ឋាន**៖ ក្រុមប្រឹក្សាដែលជ្រើសរើសទីតាំងសម្រាប់មជ្ឈមណ្ឌលកែឆ្នៃកាកសំណល់គ្រួសារថ្មី ដាក់ពិន្ទុទីតាំងបីប្រឆាំងនឹងលក្ខណៈវិនិច្ឆ័យបួន ថ្លឹងទម្ងន់ដោយក្រុមប្រឹក្សាឆ្លងនាយកដ្ឋានមុនការទស្សនាទីតាំងណាមួយ៖

```
លក្ខណៈវិនិច្ឆ័យ (ទម្ងន់)៖  ថ្លៃដើមដើមទុន (30%)  ការចូលដំណើរការដឹកជញ្ជូន (25%)
                           ផលប៉ះពាល់សហគមន៍ (25%)  ផលប៉ះពាល់បរិស្ថាន (20%)

ពិន្ទុទីតាំង (0-100 ខ្ពស់ជាង = ល្អជាង)៖
ទីតាំង A: ថ្លៃដើម 80, ការចូលដំណើរការ 60, សហគមន៍ 40, បរិស្ថាន 70
ទីតាំង B: ថ្លៃដើម 60, ការចូលដំណើរការ 90, សហគមន៍ 70, បរិស្ថាន 50
ទីតាំង C: ថ្លៃដើម 90, ការចូលដំណើរការ 50, សហគមន៍ 80, បរិស្ថាន 60

សរុបថ្លឹងទម្ងន់៖
ទីតាំង A = 80(.30) + 60(.25) + 40(.25) + 70(.20) = 24+15+10+14 = 63
ទីតាំង B = 60(.30) + 90(.25) + 70(.25) + 50(.20) = 18+22.5+17.5+10 = 68
ទីតាំង C = 90(.30) + 50(.25) + 80(.25) + 60(.20) = 27+12.5+20+12 = 71.5
```

ទីតាំង C ចាត់ថ្នាក់ខ្ពស់បំផុត។ ការដំណើរការភាពប្រែប្រួលដែលផ្លាស់ប្តូរទម្ងន់ផលប៉ះពាល់សហគមន៍ពី 25% ទៅ 35% (យក 10 ពិន្ទុពីថ្លៃដើមដើមទុន) ផ្លាស់ប្តូរសរុបទីតាំង C ទៅ 71.5 − 3 + 8 = 76.5 និងទីតាំង B ទៅ 68 − 6 + 7 = 69 — ទីតាំង C នៅតែនាំមុខ ដូច្នេះចំណាត់ថ្នាក់មានភាពរឹងមាំចំពោះការមិនយល់ស្របសមហេតុផលអំពីការថ្លឹងទម្ងន់នោះ ដែលជាការពិនិត្យពិតប្រាកដដែល Green Book រំពឹងថានឹងឃើញបានរាយការណ៍។

**សប្បុរសធម៌**៖ មូលនិធិផ្តល់ជំនួយដែលជ្រើសរើសរវាងការផ្តល់មូលនិធិដល់សេវាប្រឹក្សាបំណុល បណ្តាញធនាគារអាហារ និងកម្មវិធីអក្ខរកម្មហិរញ្ញវត្ថុ ប្រើ MCDA ជំនួស SROI (សូមមើល
[ផលចំណេញសង្គមលើការវិនិយោគ](../ផលចំណេញសង្គមលើការវិនិយោគ/)) ពិតជាព្រោះអ្នកគ្រប់គ្រងមូលនិធិ (trustees) មិនយល់ស្របគ្នាដោយសុចរិតភាពល្អ ថាតើជំនួយវិបត្តិ ឬការទប់ស្កាត់គួរមានទម្ងន់ធ្ងន់ជាង — MCDA អនុញ្ញាតឱ្យពួកគេយល់ព្រមលើ*រូបរាង*នៃការមិនយល់ស្រប (ជួរទម្ងន់) ជាជាងធ្វើពុតថាសមាមាត្រ SROI តែមួយដោះស្រាយវា។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

MCDA គឺជាឧបករណ៍ធម្មជាតិសម្រាប់ជ្រើសរើសអ្នកលក់ និងស្ថាបត្យកម្ម នៅពេលលក្ខណៈវិនិច្ឆ័យមានជម្លោះពិតប្រាកដ — ការជ្រើសរើសរវាងប្រព័ន្ធគ្រប់គ្រងករណីដែលរក្សាទុកលើ cloud និងនៅទីតាំងផ្ទាល់ ដោះដូរថ្លៃដើម ហានិភ័យអធិបតេយ្យទិន្នន័យ ភាពអាចចូលប្រើ និងល្បឿនផ្តល់ជូន តាមរបៀបដែលមិនកាត់បន្ថយទៅជាលេខតែមួយ។ អ្នកដឹកនាំវិស្វកម្មគួរទទូចឱ្យការថ្លឹងទម្ងន់កើតឡើងមុនពេលជម្រើសត្រូវបានដាក់ពិន្ទុ ដូច Green Book តម្រូវ ព្រោះលំហាត់ថ្លឹងទម្ងន់ដែលធ្វើក្រោយឃើញបញ្ជីខ្លីតែងតែរសាត់ទៅរកជម្រើសណាដែលបន្ទប់ពេញចិត្តរួចហើយ។ សូមមើល
[សាងសង់ ឬ ទិញ ក្នុងរដ្ឋាភិបាល](../ការសម្រេចចិត្តសាងសង់-ឬទិញក្នុងរដ្ឋាភិបាល/) សម្រាប់ការអនុវត្ត MCDA ទូទៅ និង
[ក្រដាសពិន្ទុតម្លៃសាធារណៈ](../ក្រដាសពិន្ទុតម្លៃសាធារណៈ/) សម្រាប់ឧបករណ៍ដាក់ពិន្ទុមានរចនាសម្ព័ន្ធដែលពាក់ព័ន្ធ ប្រើក្រោយការសម្រេចចិត្ត ជាជាងមុនការសម្រេចចិត្ត។

## កំហុសដែលតែងកើតមាន

- **កំណត់ទម្ងន់បន្ទាប់ពីឃើញជម្រើស។** នេះជាវិធីទូទៅបំផុតតែមួយដែល MCDA ត្រូវបានបន្លំ ទាំងដោយចេតនា ឬអត់។ បោះពុម្ពទម្ងន់មុនដាក់ពិន្ទុ ហើយកត់ត្រាថាអ្នកណាកំណត់វា។
- **ចាត់ទុកសរុបថ្លឹងទម្ងន់ជាលេខរឹង។** ពិន្ទុ 71.5 ធៀបនឹង 68 មិនមែនជាគម្លាតមានន័យតាមស្ថិតិទេ លុះត្រាតែការវិភាគភាពប្រែប្រួលបញ្ជាក់ថាចំណាត់ថ្នាក់ស្ថិរ។ ត្រូវរាយការណ៍ជួរ មិនមែនភាពជាក់លាក់មិនពិតទេ។
- **ប្រើ MCDA ដើម្បីគេចពីការបម្លែងជាប្រាក់ដែលអាចធ្វើទៅបានពិតប្រាកដ។** ប្រសិនបើលក្ខណៈវិនិច្ឆ័យភាគច្រើនអាចកំណត់តម្លៃបានដោយអាចជឿជាក់ ការជ្រើស MCDA តាមលំនាំដើមជំនួស[SCBA](../ការវិភាគថ្លៃដើម-អត្ថប្រយោជន៍សង្គម/) បោះបង់ព័ត៌មានដែលការវាយតម្លៃអាចប្រើបាន។
- **ឱ្យភាគីពាក់ព័ន្ធលេចធ្លោតែម្នាក់កំណត់ទម្ងន់ទាំងអស់តែឯង។** ការអនុវត្តល្អរបស់ Green Book រំពឹងថាទម្ងន់ត្រូវបានបង្កើតពីក្រុមប្រឹក្សាតំណាង មិនមែននាយកអ្នកឧបត្ថម្ភទេ ដើម្បីជៀសវាងការវាយតម្លៃគ្រាន់តែទាញយកឡើងវិញនូវអ្វីដែលអ្នកនោះចង់បានរួចហើយ។
