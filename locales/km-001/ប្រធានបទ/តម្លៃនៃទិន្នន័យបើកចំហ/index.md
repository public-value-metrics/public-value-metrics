# តម្លៃនៃទិន្នន័យបើកចំហ

តម្លៃនៃទិន្នន័យបើកចំហ គឺជាបញ្ហានៃការប៉ាន់ស្មានថាតើទិន្នន័យរដ្ឋាភិបាល និងទិន្នន័យសាធារណៈមានតម្លៃប៉ុន្មាន នៅពេលដែលវាគ្មានតម្លៃលក់៖ វាមិនត្រូវបានលក់ទេ ដូច្នេះគ្មានបន្ទាត់ចំណូលទេ ប៉ុន្តែការបញ្ចេញទិន្នន័យនោះ (កំណត់ត្រាអាកាសធាតុ ពេលវេលាដឹកជញ្ជូន ព្រំប្រទល់លេខកូដប្រៃសណីយ៍ បញ្ជីក្រុមហ៊ុន) បង្កើតសកម្មភាពសេដ្ឋកិច្ច និងសង្គមនៅខាងក្រោមយ៉ាងជាក់ស្តែង។ ការវាយតម្លៃឱ្យបានល្អគឺសំខាន់ ព្រោះទាំង "ការបញ្ចេញគឺឥតគិតថ្លៃ" និង "វាគ្មានតម្លៃអ្វីទេ" សុទ្ធតែខុស ហើយវិស្វករកម្មវិធីដែលសម្រេចចិត្តថាតើគួរបើក API ឬសំណុំទិន្នន័យមួយឬអត់ ត្រូវការអំណះអំណាងល្អជាងទាំងពីរនេះ។

## ហេតុអ្វីបានជាសំខាន់

ការប៉ាន់ស្មានពីលើចុះក្រោមដែលត្រូវបានដកស្រង់ច្រើនបំផុតមកពីរបាយការណ៍ឆ្នាំ 2013 របស់ McKinsey Global Institute ឈ្មោះ "Open data: Unlocking innovation and performance with liquid information" ដែលបានកំណត់តម្លៃប្រចាំឆ្នាំដែលអាចមាននៃទិន្នន័យបើកចំហក្នុងវិស័យប្រាំពីរ — ការអប់រំ ការដឹកជញ្ជូន ផលិតផលអតិថិជន អគ្គិសនី ប្រេង និងឧស្ម័ន សុខាភិបាល និងហិរញ្ញវត្ថុអតិថិជន — ចន្លោះពី $3 ទ្រីលាន ដល់ $5 ទ្រីលាន ក្នុងមួយឆ្នាំទូទាំងពិភពលោក តាមរយៈយន្តការរួមមានតម្លាភាពកើនឡើង ការផ្គូផ្គងការផ្គត់ផ្គង់ទៅនឹងតម្រូវការប្រកបដោយប្រសិទ្ធភាពជាងមុន និងការអនុញ្ញាតឱ្យមានផលិតផល និងសេវាថ្មីៗដែលសាងសង់លើទិន្នន័យ។ តួលេខនោះគឺជាការប៉ាន់ស្មានតាមសេណារីយ៉ូ មិនមែនជាលទ្ធផលដែលបានវាស់ជាក់ស្តែងទេ ហើយត្រូវបានដកស្រង់ខុសជាប្រចាំ ដូចជាវាជាចំណូលដែលរដ្ឋាភិបាលអាចចាប់យកដោយផ្ទាល់ ខណៈដែលតម្លៃភាគច្រើនធ្លាក់ទៅលើភាគីទីបី — អាជីវកម្ម អ្នកស្រាវជ្រាវ ប្រជាពលរដ្ឋ — ដែលប្រើទិន្នន័យ ដែលជាចំណុចពិតប្រាកដនៃការបើកចំហជាជាងការលក់។ Open Data Institute របស់ចក្រភពអង់គ្លេស ដែលបានបង្កើតរួមគ្នាដោយ Sir Tim Berners-Lee និង Sir Nigel Shadbolt ក្នុងឆ្នាំ 2012 បានបង្កើតសំណុំករណីសិក្សាលម្អិតជាងមុនពីក្រោមឡើងលើ — តាមវិស័យនីមួយៗ តាមសំណុំទិន្នន័យនីមួយៗ — ដែលមានប្រយោជន៍ជាងលេខចំណងជើងរបស់ McKinsey សម្រាប់ករណីអាជីវកម្មពិតប្រាកដ ព្រោះវាបង្ហាញយន្តការនៃការបង្កើតតម្លៃ មិនមែនត្រឹមទំហំសរុបរបស់វាទេ។

## គណិតវិទ្យា

ទិន្នន័យបើកចំហគ្មានតម្លៃទីផ្សារទេ ដូច្នេះវិធីសាស្ត្រវាយតម្លៃចូលមកជំនួស។ វិធីសាស្ត្របីតែងកើតឡើងម្តងហើយម្តងទៀត ហើយគ្មានវិធីណាមួយគ្រប់គ្រាន់តែឯងទេ៖

```
1. វិធីសាស្ត្រថ្លៃដើមជៀសវាងបាន / ថ្លៃជំនួស៖
   តម្លៃ ≈ អ្វីដែលអ្នកប្រើនឹងបានបង់ដើម្បីផលិត ឬទទួលអាជ្ញាប័ណ្ណ
   ទិន្នន័យស្មើគ្នាដោយខ្លួនឯង — ជាបន្ទាត់ខាងក្រោម មិនរាប់តម្លៃដែលបង្កើតដោយ
   ការប្រើប្រាស់ដែលអ្នកផលិតដើមមិនបានគិតទុកជាមុន

2. វិធីសាស្ត្រគំរូទីផ្សារ / សកម្មភាពខាងក្រោម៖
   តម្លៃ ≈ ចំណូល ឬការសន្សំដែលបង្កើតដោយអាជីវកម្ម/សេវាដែលសាងសង់
   លើទិន្នន័យ (ឧ. កម្មវិធីរុករកផ្លូវសាងសង់លើទិន្នន័យផែនទី និងចរាចរណ៍បើកចំហ)
   — ចាប់យកសកម្មភាពសេដ្ឋកិច្ចពិត ប៉ុន្តែពិបាកសន្និដ្ឋានមូលហេតុឱ្យច្បាស់មកការបញ្ចេញទិន្នន័យ
   (សូមមើល additionality-and-deadweight)

3. វិធីសាស្ត្រតាមលក្ខខណ្ឌ/ចំណូលចិត្តដែលបានប្រកាស៖
   តម្លៃ ≈ អ្វីដែលអ្នកប្រើនិយាយថាពួកគេនឹងបង់ ឬពេលវេលាដែលពួកគេនិយាយថា
   វាសន្សំឱ្យពួកគេ — សូមមើល stated-preference-valuation សម្រាប់វិធីសាស្ត្រ
   ទូទៅ និងភាពលំអៀងរបស់វា

គ្មានវិធីណាមួយបង្កើតតួលេខស្អាតដូចតម្លៃទីផ្សារទេ។ ករណីអាជីវកម្មទិន្នន័យបើកចំហ
ដែលអាចជឿជាក់បាន ធ្វើត្រីកោណរវាងពីរ ឬច្រើនជាងនេះ ហើយបញ្ជាក់ច្បាស់
ថាយន្តការណាដែលកំពុងធ្វើការងារ។
```

## ឧទាហរណ៍គណនា

**ការបញ្ចេញទិន្នន័យផែនទី/អាសយដ្ឋានថ្នាក់ជាតិជាឧទាហរណ៍** (វិធីសាស្ត្រតាមបែបករណីសិក្សារបស់ ODI តួលេខគ្រាន់តែបង្ហាញពីមាត្រដ្ឋានដែលការសិក្សាបែបនេះតែងរកឃើញ)៖

```
ការប៉ាន់ស្មានថ្លៃដើមជៀសវាងបាន៖
  អាជីវកម្មដែលបើមិនដូច្នោះនឹងទទួលអាជ្ញាប័ណ្ណទិន្នន័យផ្គូផ្គងអាសយដ្ឋានស្មើគ្នា
  ជាពាណិជ្ជកម្ម ក្នុងថ្លៃអាជ្ញាប័ណ្ណមធ្យមប៉ាន់ស្មាន £4,000/ឆ្នាំ
  លើ SMEs ប៉ាន់ស្មាន 15,000 ដែលឥឡូវប្រើសំណុំទិន្នន័យបើកចំហឥតគិតថ្លៃ
  = 15,000 × £4,000 = £60,000,000/ឆ្នាំ ក្នុងថ្លៃអាជ្ញាប័ណ្ណជៀសវាងបានតែមួយ

ការប៉ាន់ស្មានសកម្មភាពខាងក្រោម (មានការស្មានច្រើនជាង តម្រូវស្ថានភាពផ្ទុយពីការពិត)៖
  ផលិតផលរៀបចំផ្លូវដឹកជញ្ជូន និងភស្តុភារថ្មីៗដែលសាងសង់លើទិន្នន័យបើកចំហ
  ដែលនឹងមិនមាន ឬនឹងអាក្រក់ជាងយ៉ាងសំខាន់ បើគ្មានវា —
  តម្រូវការប្រៀបធៀបជាមួយស្ថានភាពផ្ទុយពីការពិតដែលទិន្នន័យនៅបិទ
  ឬមានអាជ្ញាប័ណ្ណពាណិជ្ជកម្ម (counterfactual-analysis) ព្រោះ
  សកម្មភាពខ្លះនឹងកើតឡើងដោយខ្លួនឯងនៅលើទិន្នន័យបង់ប្រាក់ក្នុងតម្លៃខ្ពស់ជាង
  ដែលជា deadweight ក្នុងន័យ "តម្លៃដែលបង្កើតដោយការបើកវា"

ករណីអាជីវកម្មដែលអាចការពារបាន រាយការណ៍តួលេខថ្លៃដើមជៀសវាងបានជាបន្ទាត់ខាងក្រោម
ដ៏រឹងមាំ ហើយចាត់ទុកតួលេខសកម្មភាពខាងក្រោមជាសេណារីយ៉ូកម្រិតខាងលើ មិនមែនការពិតទេ។
```

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

សម្រាប់វិស្វករ សំណួរជាក់ស្តែងអំពីតម្លៃទិន្នន័យបើកចំហ ជាធម្មតាតូចចង្អៀតជាងតួលេខចំណងជើងថ្នាក់ជាតិ៖ តើការបើក API ឬសំណុំទិន្នន័យជាក់លាក់នេះ (ជាជាងរក្សាទុកក្រោមកិច្ចព្រមព្រៀងដៃគូ) បង្កើនការប្រើប្រាស់ឡើងវិញគ្រប់គ្រាន់ដើម្បីបង្ហាញភាពសមហេតុផលនៃថ្លៃដើមបន្តបន្ទាប់ក្នុងការចងក្រងឯកសារ ការគ្រប់គ្រងកំណែ និងការគាំទ្រវាជាចំណុចប្រទាក់សាធារណៈដែរឬទេ? ថ្លៃថែទាំនោះជាថ្លៃពិត ហើយជាគូប្រៀបធៀបនៃសេដ្ឋកិច្ចសាងសង់ម្តងប្រើច្រើនដងនៃ[រដ្ឋាភិបាលជាវេទិកា](../រដ្ឋាភិបាលជាវេទិកា/) — ប្រធានបទទាំងពីរជាសាច់ញាតិជិតស្និទ្ធ ម្ខាងអំពីកូដ និងហេដ្ឋារចនាសម្ព័ន្ធរួម ម្ខាងទៀតអំពីទិន្នន័យរួម។ ការអះអាងអំពីតម្លៃទិន្នន័យបើកចំហណាមួយគួរត្រូវបានពិនិត្យប្រៀបធៀបនឹង[ភាពបន្ថែម និងផលដែលនឹងកើតឡើងដោយខ្លួនឯង (additionality និង deadweight)](../ភាពបន្ថែម-និងផលដែលនឹងកើតឡើងដោយខ្លួនឯង/) មុនពេលដាក់ក្នុងករណីអាជីវកម្ម៖ សកម្មភាពដែលនឹងកើតឡើងដោយខ្លួនឯងដូចគ្នា នៅលើទិន្នន័យដែលមានអាជ្ញាប័ណ្ណពាណិជ្ជកម្ម មិនមែនជាតម្លៃដែលការ*បើកចំហ*បង្កើតទេ។

## កំហុសដែលតែងកើតមាន

- **ដកស្រង់តួលេខ $3–5 ទ្រីលានរបស់ McKinsey ជាតួលេខសម្រាប់ចក្រភពអង់គ្លេសជាក់លាក់ ឬជាចំណែករបស់សំណុំទិន្នន័យនេះ**៖ វាជាការប៉ាន់ស្មានតាមសេណារីយ៉ូទូទាំងពិភពលោកក្នុងវិស័យប្រាំពីរ ពីឆ្នាំ 2013 — ការប្រើវាជាមេគុណច្បាស់លាស់សម្រាប់សំណុំទិន្នន័យថ្នាក់ជាតិតែមួយ គឺបង្ខូចអ្វីដែលលេខនោះជា។
- **គ្មានស្ថានភាពផ្ទុយពីការពិត (counterfactual)**៖ ទាមទារកិត្តិយសចំពោះសកម្មភាពសេដ្ឋកិច្ចខាងក្រោមទាំងអស់ដែលសាងសង់លើទិន្នន័យបើកចំហ ដោយមិនសួរថាតើប៉ុន្មានភាគរយនឹងកើតឡើងដោយខ្លួនឯងនៅលើទិន្នន័យបង់ប្រាក់ ឬមានអាជ្ញាប័ណ្ណក្នុងតម្លៃខ្ពស់ជាងនេះ (សូមមើល [ភាពបន្ថែម និងផលដែលនឹងកើតឡើងដោយខ្លួនឯង](../ភាពបន្ថែម-និងផលដែលនឹងកើតឡើងដោយខ្លួនឯង/) និង [ការវិភាគស្ថានភាពផ្ទុយពីការពិត](../ការវិភាគ-counterfactual/))។
- **ច្រឡំថ្លៃផលិតកម្មជាមួយតម្លៃដែលបានបង្កើត**៖ សំណុំទិន្នន័យដែលថ្លៃក្នុងការប្រមូល មិនមែនមានតម្លៃក្នុងការបញ្ចេញដោយស្វ័យប្រវត្តិទេ ហើយសំណុំទិន្នន័យដែលថោក ក៏មិនមែនមានតម្លៃទាបដោយស្វ័យប្រវត្តិដែរ — តម្លៃតាមការប្រើប្រាស់ខាងក្រោម មិនមែនតាមថ្លៃដើមខាងលើទេ។
- **មិនអើពើនឹងថ្លៃថែទាំបន្តបន្ទាប់នៃ "ការបើកចំហ"**៖ ការបោះពុម្ពផ្សាយឯកសារ CSV ម្តងតែមួយ មិនមែនជាការប្តេជ្ញាចិត្តដូចគ្នាទៅនឹងការដំណើរការ API បើកចំហដែលមានឯកសារ មានកំណែ និងមានការគាំទ្រទេ — ការផ្តល់មូលនិធិមិនគ្រប់គ្រាន់ដល់ក្រោយបន្ទាប់ពីការប្រកាសបើកដំណើរការ គឺជាទម្រង់បរាជ័យទូទៅ។
