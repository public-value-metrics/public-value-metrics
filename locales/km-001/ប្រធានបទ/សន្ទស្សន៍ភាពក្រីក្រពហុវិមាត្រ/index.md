# សន្ទស្សន៍ភាពក្រីក្រពហុវិមាត្រ (MPI)

MPI វាស់ភាពក្រីក្រជាការខ្វះខាតត្រួតស៊ីគ្នាដែលបុគ្គលម្នាក់ជួបប្រទះក្នុងពេលតែមួយ — ក្នុងសុខភាព ការអប់រំ និងកម្រិតជីវភាព — ជាជាងប្រាក់ចំណូលតែមួយដែលធ្លាក់ក្រោមបន្ទាត់។ វាត្រូវបានបង្កើតឡើងដោយ Oxford Poverty and Human Development Initiative (OPHI) ជាមួយ Sabina Alkire និង James Foster ហើយត្រូវបានបោះពុម្ពរួមគ្នាជាមួយ UNDP ក្នុងរាល់របាយការណ៍ Human Development Report តាំងពីឆ្នាំ 2010 ជាមួយ[សន្ទស្សន៍អភិវឌ្ឍន៍មនុស្ស](../សន្ទស្សន៍អភិវឌ្ឍន៍មនុស្ស/)។

## ហេតុអ្វីបានជាសំខាន់

បន្ទាត់ភាពក្រីក្រប្រាក់ចំណូលខកខានមនុស្សដែលមានប្រាក់ចំណូលសាច់ប្រាក់គ្រប់គ្រាន់ ប៉ុន្តែខ្វះទឹកស្អាត ការសិក្សា ឬបានឆ្លងកាត់ការស្លាប់របស់កូន — ហើយវាខកខានការពិតដែលថាការខ្វះខាតប្រមូលផ្តុំគ្នា៖ គ្រួសារដែលគ្មានអគ្គិសនីទំនងខ្លាំងជាងសមាមាត្រដែលក៏ខ្វះអនាម័យ និងមានកុមារខ្វះអាហារូបត្ថម្ភដែរ។ វិធីសាស្ត្រ Alkire-Foster ដែល MPI សាងសង់លើនោះ រាប់ការខ្វះខាតរបស់បុគ្គលម្នាក់ៗឆ្លងសូចនាករដប់ ដែលដាក់ជាក្រុមក្នុងវិមាត្របីមានទម្ងន់ស្មើគ្នា — សុខភាព ការអប់រំ កម្រិតជីវភាព — ហើយចាត់ថ្នាក់នរណាម្នាក់ជា "ក្រ MPI" លុះត្រាតែពិន្ទុខ្វះខាតថ្លឹងទម្ងន់របស់ពួកគេឆ្លងកម្រិតថេរ ដោយចាប់យកការត្រួតស៊ីគ្នាដែលសំណុំស្ថិតិសូចនាករតែមួយដាច់ដោយឡែកមិនអាចចាប់បាន។ OPHI បោះពុម្ពវិធីសាស្ត្រពេញលេញ និងទិន្នន័យប្រទេសនៅ
<https://ophi.org.uk/multidimensional-poverty-index/>។ MPI សកលដែលវាថែរក្សារួមគ្នាជាមួយ UNDP ឥឡូវគ្របដណ្តប់លើសពី 110 ប្រទេស។ សម្រាប់កម្មវិធីដែលសាងសង់សម្រាប់កម្មវិធីប្រឆាំងភាពក្រីក្រ — ការផ្ទេរសាច់ប្រាក់ ការចាត់ថ្នាក់ការថែទាំសង្គម ការកំណត់គោលដៅជំនួយ — សំណុំសូចនាករ MPI ជារឿយៗជាអ្វីដែលជិតបំផុតទៅនឹងគ្រោងការខ្វះខាតស្តង់ដារដែលត្រូវបានផ្ទៀងផ្ទាត់រួចហើយនៅក្នុងការិយាល័យស្ថិតិជាតិរាប់សិប។

## គណិតវិទ្យា

```
សូចនាករ 10 វិមាត្រ 3 វិមាត្រនីមួយៗមានទម្ងន់ 1/3៖

សុខភាព (1/3)៖            អាហារូបត្ថម្ភ (1/6) មរណភាពកុមារ (1/6)
ការអប់រំ (1/3)៖           ឆ្នាំសិក្សា (1/6) ការចូលរៀន (1/6)
កម្រិតជីវភាព (1/3)៖       ឥន្ធនៈចម្អិនអាហារ អនាម័យ ទឹកផឹក
                          អគ្គិសនី លំនៅដ្ឋាន ទ្រព្យសម្បត្តិ (1/18 ម្នាក់ៗ)

ពិន្ទុខ្វះខាត (c) = ផលបូកទម្ងន់នៃសូចនាករដែលបុគ្គលម្នាក់ខ្វះខាត

បុគ្គលម្នាក់ជា "ក្រ MPI" ប្រសិនបើ c ≥ 1/3 (កម្រិតភាពក្រីក្រ k = 33%)

H (សមាមាត្រចំនួនក្បាល) = ចំនួនក្រ MPI / ចំនួនប្រជាជនសរុប
A (អាំងតង់ស៊ីតេ)        = ពិន្ទុខ្វះខាតមធ្យមក្នុងចំណោមអ្នកក្រ MPI តែប៉ុណ្ណោះ

MPI = H × A
```

ព្រោះ MPI គុណ*ចំណែក*ដែលក្រជាមួយ*កម្រិតដែលពួកគេក្រ* តំបន់ពីរដែលមានសមាមាត្រចំនួនក្បាលដូចគ្នា អាចមានពិន្ទុ MPI ខុសគ្នាខ្លាំង ប្រសិនបើការខ្វះខាតធ្ងន់ធ្ងរជាងនៅតំបន់មួយ — តក្កវិជ្ជា "គ្មានការជំនួសរវាងវិមាត្រ" ដូចគ្នានៅពីក្រោយមធ្យមធរណីមាត្រនៃ HDI។

## ឧទាហរណ៍គណនា

**ការស្ទង់មតិថ្នាក់ជាតិរបស់មនុស្ស 1,000 នាក់**៖ 350 នាក់ត្រូវបានកំណត់ថាក្រពហុវិមាត្រ (ពិន្ទុខ្វះខាត ≥ 33%)។ ក្នុងចំណោមបុគ្គលក្រ 350 នាក់នោះតែប៉ុណ្ណោះ ពិន្ទុខ្វះខាតមធ្យមគឺ 45%។

```
H = 350 / 1000                = 0.350
A = 0.45
MPI = H × A = 0.350 × 0.45    = 0.1575
```

**ប្រៀបធៀបស្រុកពីរដែលមានចំនួនក្បាលស្មើគ្នា**៖ ស្រុក A មាន H = 0.30 និង A = 0.40 (ក្រច្រើន ខ្វះខាតកម្រិតមធ្យម)។ ស្រុក B មាន H = 0.30 និង A = 0.60 (ចំនួនក្រដូចគ្នា ប៉ុន្តែខ្វះខាតធ្ងន់ធ្ងរជាង — ខ្វះអគ្គិសនី *និង* អនាម័យ *និង* ការចូលរៀនក្នុងពេលតែមួយ)។

```
MPI_A = 0.30 × 0.40 = 0.120
MPI_B = 0.30 × 0.60 = 0.180
```

សមាមាត្រចំនួនក្បាលដូចគ្នា MPI ខ្ពស់ជាង 50% នៅស្រុក B — ប្រព័ន្ធកំណត់គោលដៅផ្អែកលើភាពក្រីក្រចំនួនក្បាលតែមួយ នឹងចាត់ថ្នាក់ស្រុកទាំងពីរដូចគ្នា ហើយខកខានថាស្រុក B ត្រូវការអន្តរាគមន៍ស៊ីជម្រៅជាង។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

- ប្រព័ន្ធគ្រប់គ្រងករណី និងសិទ្ធិទទួលបានសម្រាប់កម្មវិធីសង្គម ជារឿយៗរក្សាទុកសូចនាករទាំងដប់មួយចំនួនរួចហើយ (លំនៅដ្ឋាន ការចូលរៀន សញ្ញាសុខភាព) ក្នុងស៊ីឡូដាច់ដោយឡែក។ វិធីសាស្ត្ររាប់ Alkire-Foster គឺជាគ្រោងការដែលរួចរាល់សម្រាប់ផ្សំវាទៅជាពិន្ទុខ្វះខាតតែមួយ ជំនួសឱ្យការសាងសង់ម៉ូដែលដាក់ពិន្ទុតាមបំណងពីសូន្យ។
- ការបំបែកចំនួនក្បាល/អាំងតង់ស៊ីតេ (H × A) គឺជាលំនាំមានប្រយោជន៍ទូទៅសម្រាប់ផ្ទាំងគ្រប់គ្រងណាមួយដែលរាយការណ៍ "ប៉ុន្មានរងផលប៉ះពាល់" ជាមួយ "កម្រិតណា" — ការបង្រួមទាំងពីរទៅជាលេខតែមួយ ដូចស្ថិតិប្រេវ៉ាឡង់ឆៅធ្វើ លាក់ករណីដែលត្រូវការធនធានច្រើនបំផុត។
- ផ្ទាំងគ្រប់គ្រងសូចនាករបែប MPI ត្រូវគ្នាធម្មជាតិជាមួយរបាយការណ៍[ថ្លៃដើមក្នុងមួយអ្នកទទួលផល](../ថ្លៃចំណាយក្នុងមួយអ្នកទទួលផល/) សម្រាប់កម្មវិធីប្រឆាំងភាពក្រីក្រ៖ ថ្លៃដើមក្នុងមួយពិន្ទុថយចុះនៃ MPI គឺជាឯកតាដែលអាចការពារបានសម្រាប់ប្រៀបធៀបអន្តរាគមន៍ខុសគ្នាខ្លាំង (ការផ្ទេរសាច់ប្រាក់ ធៀបនឹងហេដ្ឋារចនាសម្ព័ន្ធអនាម័យ)។

## កំហុសដែលតែងកើតមាន

- **ចាត់ទុកសូចនាករទាំងដប់ជាសកល** — សូចនាករ MPI សកលរបស់ OPHI ត្រូវបានកែសម្រួលសម្រាប់ភាពអាចប្រៀបធៀបឆ្លងប្រទេស។ MPI ជាតិ (ប្រទេសជាច្រើន រួមទាំងប្រទេសជាច្រើនក្នុងអាស៊ីខាងត្បូង និងអាហ្វ្រិក បោះពុម្ពរបស់ខ្លួនផ្ទាល់) សម្របសូចនាករ និងទម្ងន់ទៅនឹងបរិបទមូលដ្ឋាន ហើយទាំងពីរមិនអាចប្រៀបធៀបដោយផ្ទាល់បានទេ។
- **រាយការណ៍តែ H** — សមាមាត្រចំនួនក្បាលមិនអើពើអាំងតង់ស៊ីតេទាំងស្រុង។ ត្រូវតែរាយការណ៍ ឬគណនា A ជាមួយវាជានិច្ច ឬ MPI ខ្លួនវា។
- **សន្មតថាក្រ MPI និងក្រប្រាក់ចំណូលជាប្រជាជនតែមួយ** — សង្ខេបប្រទេសរបស់ OPHI ផ្ទាល់ជាធម្មតាបង្ហាញការត្រួតស៊ីគ្នាតែមួយផ្នែករវាងទាំងពីរ។ កម្មវិធីដែលកំណត់គោលដៅតែអ្នកក្រប្រាក់ចំណូលនឹងខកខានជាប្រព័ន្ធនូវចំណែកសំខាន់នៃអ្នកក្រពហុវិមាត្រ។
