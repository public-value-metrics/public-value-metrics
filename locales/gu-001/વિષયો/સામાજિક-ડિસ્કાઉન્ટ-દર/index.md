# સામાજિક ડિસ્કાઉન્ટ દર

સામાજિક ડિસ્કાઉન્ટ દર ભાવિ ખર્ચ અને લાભને વર્તમાન મૂલ્યમાં ફેરવે છે, જેથી દાયકાઓ સુધી ફેલાયેલા વળતરવાળા કાર્યક્રમોની સામાન્ય ધોરણે સરખામણી થઈ શકે. HM Treasury ની Green Book પ્રથમ 30 વર્ષ માટે 3.5% પર આધારિત ઘટતી સૂચિ ફરજિયાત કરે છે, જે Ramsey સૂત્ર પર આધારિત છે — એક ચોક્કસ, ટાંકી શકાય તેવો આંકડો, જે જ્યારે પણ આબોહવા નીતિ કે માળખાકીય સુવિધા જેવી લાંબા ગાળાની પ્રતિબદ્ધતાઓ પર લાગુ થાય ત્યારે જીવંત રાજકીય અને નૈતિક દલીલ બની જાય છે.

## તે શા માટે મહત્વનું છે

30 વર્ષ પછી મળતા એક પાઉન્ડના લાભની કિંમત આજે મળતા એક પાઉન્ડના લાભ જેટલી નથી, જેનાં કારણો અંશતઃ શુદ્ધ સમય પસંદગી (લોકો અને સમાજો સારી વસ્તુઓ વહેલી પસંદ કરે છે) અને અંશતઃ વૃદ્ધિ (ભાવિ સમાજ વધુ સમૃદ્ધ હશે એવી અપેક્ષા, તેથી સીમાંત રીતે એક પાઉન્ડ તેના માટે ઓછો મહત્વનો છે) સાથે જોડાયેલાં છે. Green Book નો Annex 6 યુકેનો પ્રમાણભૂત ડિસ્કાઉન્ટ દર Ramsey સૂત્રમાંથી તારવે છે, જેમાં શુદ્ધ સમય પસંદગીનો દર, વપરાશની અપેક્ષિત વૃદ્ધિ દર અને વપરાશની સીમાંત ઉપયોગિતાની સ્થિતિસ્થાપકતા ભેગા થાય છે; પરિણામે વર્ષ 0–30 માટે વાર્ષિક 3.5% નો પ્રકાશિત દર મળે છે, અને વર્ષ 31 તથા પછી માટે પ્રકાશિત સૂચિમાં ઘટતો જાય છે (વર્ષ 301+ માટે 1% સુધી). આ સૂચિ એટલા માટે અસ્તિત્વમાં છે કે એક સદી સુધી ચક્રવૃદ્ધિ પામતો સ્થિર 3.5% લગભગ કોઈપણ લાંબા ગાળાના લાભ — 80 વર્ષ પછી જીવ બચાવતું પૂર સંરક્ષણ, 100 વર્ષ પછીના નુકસાનને ટાળતો કાર્બન ઘટાડો — ને વર્તમાન મૂલ્યની દૃષ્ટિએ નગણ્ય બનાવી દેત, જેને Treasury એ ખરેખર લાંબા આયુષ્યવાળી માળખાકીય અને પર્યાવરણીય નિર્ણયો માટે અવિશ્વસનીય નૈતિક નિષ્કર્ષ ગણ્યો.

ડિસ્કાઉન્ટ દર વિવાદાસ્પદ છે કારણ કે આ પસંદગી તટસ્થ તકનીકી પરિમાણ નથી: તે એ અંગેનો નિર્ણય દર્શાવે છે કે સમાજે હજુ જન્મ્યા નથી એવા લોકો માટે આજે કેટલો ત્યાગ કરવો જોઈએ. Stern Review on the Economics of Climate Change (2006) એ શૂન્યની નજીકનો ડિસ્કાઉન્ટ દર (શુદ્ધ સમય પસંદગી લગભગ 0.1%) વાપર્યો, દલીલ કરીને કે જ્યારે નુકસાન (વિનાશક આબોહવા પરિવર્તન) અપરિવર્તનીય હોય ત્યારે ભાવિ પેઢીઓના કલ્યાણને બજાર દરો જેવા કોઈપણ દરે ડિસ્કાઉન્ટ કરવું નૈતિક રીતે અયોગ્ય છે. ટીકાકારો — ખાસ કરીને William Nordhaus — એ દલીલ કરી કે Stern નો શૂન્યની નજીકનો દર તાત્કાલિક આબોહવા ખર્ચ માટેનો કેસ વધારી દે છે, કારણ કે તે લગભગ ડિસ્કાઉન્ટ વિનાના ભાવિ લાભ સામે લગભગ કોઈપણ વર્તમાન ખર્ચને વાજબી દર્શાવે છે. મતભેદ ગણિત અંગે નહોતો; તે એ અંગે હતો કે દર નક્કી કરવા કોનું નૈતિક માળખું વાપરવું, અને તે ડિસ્કાઉન્ટ દર ફક્ત વીમાગણિતીય ઇનપુટ નહીં પણ નીતિગત પસંદગી છે તે દર્શાવતું પ્રમાણભૂત ઉદાહરણ છે.

## ગણિત

Green Book ના દર પાછળનું Ramsey સૂત્ર:

```
r = ρ + η·g

જ્યાં:
  r = સામાજિક ડિસ્કાઉન્ટ દર
  ρ = શુદ્ધ સમય પસંદગીનો દર (અધીરાઈ + વિનાશનું જોખમ)
  η = વપરાશની સીમાંત ઉપયોગિતાની સ્થિતિસ્થાપકતા
  g = માથાદીઠ વપરાશની અપેક્ષિત વાર્ષિક વૃદ્ધિ દર
```

Green Book ની ઘટતી સૂચિ (Annex 6, દૃષ્ટાંતરૂપ — ચોક્કસ પ્રકાશિત કોષ્ટક માટે વર્તમાન આવૃત્તિ તપાસો):

```
વર્ષ 0–30:    3.5%
વર્ષ 31–75:   3.0%
વર્ષ 76–125:  2.5%
વર્ષ 126–200: 2.0%
વર્ષ 201–300: 1.5%
વર્ષ 301+:    1.0%
```

ભાવિ રકમનું વર્તમાન મૂલ્ય:

```
PV = FV / (1 + r)^t
```

## ઉદાહરણ સાથે ગણતરી

**પૂર સંરક્ષણ યોજના**: એક પ્રોજેક્ટ વર્ષ 40 માં £10 મિલિયનનું ટાળેલું પૂર નુકસાન આપે છે.

સપાટ 3.5% દર વાપરતાં: PV = 10,000,000 / (1.035)^40 ≈ £2.52 મિલિયન — લાભ નાનો લાગે છે.

Green Book ની ઘટતી સૂચિ વાપરતાં (વર્ષ 0–30 માટે 3.5%, ત્યારબાદ 3.0%), ગણતરી પ્રથમ 30 વર્ષ 3.5% પર અને વર્ષ 31–40 માટે 3.0% પર ચક્રવૃદ્ધિ કરે છે:

```
PV = 10,000,000 / [(1.035)^30 × (1.03)^10]
   = 10,000,000 / [2.807 × 1.344]
   ≈ 10,000,000 / 3.773
   ≈ £2.65 મિલિયન
```

ઘટતી સૂચિ સપાટ ઊંચા દરની સરખામણીએ લાંબા ગાળાના લાભોનું વર્તમાન મૂલ્ય સાધારણ વધારે છે — જે સૂચિનો સ્પષ્ટ હેતુ છે, કારણ કે એક સદી માટે સપાટ 3.5% વર્ષ 100 ના £100 મિલિયનના લાભને £3.3 મિલિયનથી ઓછામાં ડિસ્કાઉન્ટ કરી નાખત.

**ડિજિટલ માળખું**: હાલ £4 મિલિયનના ખર્ચે સરકારી ક્લાઉડ સ્થળાંતર 15 વર્ષ સુધી દર વર્ષે £500,000 જૂની જાળવણી ખર્ચ ટાળે તેવી અપેક્ષા છે. 3.5% પર તે annuity નું વર્તમાન મૂલ્ય લગભગ £500,000 × 11.52 (3.5% એ 15-વર્ષનો annuity factor) ≈ £5.76 મિલિયન છે — £4 મિલિયનના ખર્ચથી સરળતાથી વધુ, એક હકારાત્મક ચોખ્ખા વર્તમાન મૂલ્યનો કેસ, જે ભોળપણે પસંદ કરેલા ઊંચા દરે નોંધપાત્ર નબળો દેખાત (7% એ એ જ annuity factor લગભગ 9.11 થઈ જાય છે, જે £4.56 મિલિયન આપે છે, હજુ હકારાત્મક પણ ઘણા પાતળા માર્જિન સાથે).

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

મોટા ભાગના સોફ્ટવેર બિઝનેસ કેસ 3–5 વર્ષ ચાલે છે, જે સપાટ 3.5% પટ્ટીની અંદર છે, તેથી ઘટતી સૂચિ ભાગ્યે જ સીધી અસર કરે છે — પરંતુ લાંબા અસ્કયામત આયુષ્યવાળા કોઈપણ સરકારી ટેક્નોલોજી રોકાણ (રાષ્ટ્રીય પ્લેટફોર્મ, ડેટા માળખાકીય કાર્યક્રમ, અનેક દાયકાનો કરાર) માટે મૂળભૂત શિસ્ત મહત્વની છે:

- ખાનગી નાણાકીય ક્ષેત્રમાંથી ઉછીના લીધેલા આંતરિક "હર્ડલ રેટ" ને બદલે Green Book નો પ્રકાશિત દર વાપરો; ઑડિટર્સ અને Treasury સમીક્ષકો પ્રમાણભૂત સૂચિની અપેક્ષા રાખશે.
- ઘણાં વર્ષો પછી મળતા લાભો (પ્લેટફોર્મની લાંબા ગાળાની જાળવણી બચત, ઓપન-ડેટા ઇકોસિસ્ટમનું ચક્રવૃદ્ધિ મૂલ્ય — જુઓ [ઓપન ડેટાનું મૂલ્ય](../ખુલ્લા-ડેટાનું-મૂલ્ય/)) માટે ડિસ્કાઉન્ટિંગની પસંદગી બિઝનેસ કેસને હકારાત્મકમાંથી નકારાત્મક કરી શકે છે; દર અને સમયક્ષિતિજને સ્પષ્ટ ધારણાઓ બનાવો, છુપાયેલા ડિફોલ્ટ નહીં.
- આ સીધું [Green Book મૂલ્યાંકન](../green-book-મૂલ્યાંકન/) ને પોષે છે, પાંચ-કેસ મૉડલ જે ઔપચારિક રીતે ડિસ્કાઉન્ટ કરેલો રોકડ પ્રવાહ માગે છે, અને [કલ્યાણ મૂલ્યાંકન](../કલ્યાણ-મૂલ્યાંકન/) ને, જ્યાં બિન-નાણાકીય કલ્યાણ લાભો માટે એ જ ડિસ્કાઉન્ટિંગનો પ્રશ્ન ઊભો થાય છે.
- પર્યાવરણીય અને આબોહવા ટેક્નોલોજી રોકાણ પર ખાસ લાગુ થતી Stern-વિરુદ્ધ-Nordhaus ચર્ચા માટે જુઓ [આંતરપેઢી સમાનતા અને ટકાઉપણા ડિસ્કાઉન્ટિંગ](../આંતર-પેઢી-સમાનતા-અને-ટકાઉપણા-માટે-ડિસ્કાઉન્ટિંગ/).

## સામાન્ય ભૂલો

- **ખૂબ લાંબી સમયક્ષિતિજ માટે સપાટ દર વાપરવો.** Green Book ની ઘટતી સૂચિ ખાસ એટલા માટે છે કે સ્થિર દર ખરેખર લાંબા ગાળાના લાભોને ઓછા આંકે છે; આખા સમય માટે 3.5% ડિફોલ્ટ કરવાને બદલે કઈ પટ્ટી લાગુ પડે છે તે તપાસો.
- **ડિસ્કાઉન્ટ દરને નૈતિક રીતે તટસ્થ ગણવો.** Stern-Nordhaus વિવાદ દર્શાવે છે કે દર ભાવિ પેઢીઓ અંગેનો મૂલ્ય-નિર્ણય દર્શાવે છે; તેને બદલવાથી કયા કાર્યક્રમો વાજબી લાગે તે બદલાય છે, તેથી તેને જણાવવો અને બચાવવો જોઈએ, સ્પ્રેડશીટના ડિફોલ્ટમાં છુપાવવો નહીં.
- **સામાજિક ડિસ્કાઉન્ટ દરને ખાનગી મૂડી ખર્ચ સાથે ગૂંચવવો.** સરકારી ઉધાર ખર્ચ અને ખાનગી ક્ષેત્રના હર્ડલ રેટ Ramsey-તારવેલા સામાજિક દરથી જુદા ખ્યાલો છે, અને જાહેર મૂલ્યાંકનમાં એકને બીજા સ્થાને વાપરવાથી પરિણામ સામાન્ય રીતે ટૂંકા ગાળાના વળતરની તરફેણ તરફ વિકૃત થશે.
- **વાસ્તવિક અને નજીવા રોકડ પ્રવાહોનું અસંગત ડિસ્કાઉન્ટિંગ.** Green Book નો દર વાસ્તવિક (ફુગાવા-સમાયોજિત) દર છે; તેનાથી નજીવા રોકડ પ્રવાહો ડિસ્કાઉન્ટ કરવાથી વર્તમાન મૂલ્યો ભૌતિક રીતે ઓછા આંકાય છે.
