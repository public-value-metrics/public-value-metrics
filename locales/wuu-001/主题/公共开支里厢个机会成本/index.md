# 公共开支里厢个机会成本

机会成本是指公共机构拿钞票、人手辰光或者政治资本投到一个选项上，而放弃个顶好个替代选项个价值。预算固定个部门里厢，花勒一个项目上个每一镑，就勿好再花勒次优个项目上——一个决策个真正成本，勿是伊花脱多少，而是伊挤脱啥。

## 为啥重要

公共预算勒一个开支审查期内是现金封顶个，所以勿像一家勒成长个私营企业，政府部门勿可能为了一个好点子“再去寻点钞票出来”；要为伊出钞票，就是要拿别样东西个经费砍脱。英国财政部《Green Book》拿搿点当作基础：每一份评估都必须拿一项干预搭“最低限度”基线比较，*而且*要搭同一份资源个其他现实用途比较，因为财政部开支团队真正问个问题从来勿是“搿个好勿好”，而是“搿笔钞票还能买到个其他东西，比搿个好伐”。《Green Book》个核心评估原则——公共资源应该流向每镑净社会价值最高个干预——就是拿机会成本写成了政策。

搿桩事体讲讲容易，做起来难，因为“次优替代”勒单个商业方案里厢难得看见。一个 200 万镑个青年就业资助项目，勒商业方案里厢是搭“啥也勿做”比个，但是诚实个对照对象是次优个青年就业干预，或者其实是搿 200 万镑勒整个组合里厢任何地方个次优用途，包括勿是就业个开支。《Magenta Book》（英国财政部，2020）明确警告，拿“有干预”搭“无干预”比较个评估，会低估干预必须跨过个门槛，因为“无搿项干预”勿等于“啥也呒没”——省下来个钞票会去资助别样东西。

## 数学

```
Opportunity cost of choosing A = value of the best forgone alternative B

Net public value of A = value(A) − value(B), not value(A) − 0
```

呒没通用公式，因为被放弃个替代选项随情境而变，但是搿个纪律是通用个：认出同一条预算线个现实次优用途（勿是理想化个“啥也勿做”），用同样个口径给伊估价（尽量货币化，参见[社会成本效益分析](../社会成本效益分析/)），然后相减。

## 实例演算

**部门预算线**：一笔 500 万镑个数字化转型基金，搿个财政年度刚好只能资助两个提案当中个一个。

- *方案 A*：一个新个个案管理平台，5 年里货币化效益 720 万镑（效率节省加上更快结案）。
- *方案 B*：三个部门共用个身份验证服务，5 年里货币化效益 640 万镑。

一份天真个商业方案拿 A 个 720 万镑效益搭 500 万镑成本比，汇报效益成本比 1.44:1——看上去老强。但是 A 搭 B 抢个是同一笔 500 万镑，选 A 个机会成本，就是放弃 B 个 640 万镑效益。A 对现实替代方案个*净*价值，只有 720 万 − 640 万 = 80 万镑，而勿是 720 万个标题数字。倘使还有第三个选项 C，同样 500 万镑能带来 750 万镑效益，资助 A 而勿资助 C，会毁脱 30 万镑个公共价值，虽然 A 自家个商业方案单独看起来完全站得住。

**地方政府人手辰光**：一个市议会三个人个数据团队，可以做一个住房轮候名单仪表盘（估计每年省 400 个官员工时，按每小时 £28 计，每年 £11,200），也可以做一个福利欺诈分诊工具（估计每年防止 £85,000 个错误支付）。做仪表盘个机会成本是每年放弃个 £85,000，而勿单单是数据团队个工资成本——“免费”内部自建个真正成本，是搿个团队本来可以勒别处创造个大得多个效益。

## 搭软件工程个关联

公共机构内部个工程产能本身就是一笔受限个预算——是冲刺（sprint）产能，勿是镑——同样个纪律直接适用：

- 一定要点明对照对象：一个功能个商业方案，应该讲清爽同样个团队周数还能交付点啥，而勿单是自家个回报。
- 拿“我们还有多余个工程产能”当成机会成本分析个开始，而勿是结束——多余个产能也有顶好个替代用途，哪怕搿个用途是偿还技术债（参见[技术债是公共价值个侵蚀](../技术债务是公共价值个侵蚀/)）。
- 直接搭[物有所值](../物有所值/)联系起来：VFM 个“经济性”检验，呒没诚实个机会成本对照就毫无意义；也搭[公共项目个延迟成本](../公共项目个延迟成本/)联系起来，伊拿同一个放弃替代选项个逻辑放勒辰光维度上定价。

## 容易踏个坑

- **搭“啥也勿做”比，而勿是搭次优替代方案比。** 《Green Book》要求“最低限度”基线，正是因为真正个机会成本难得是零；一份商业方案只跨过“啥也勿做”个门槛，并勿说明伊比现实个替代方案好。
- **忽视跨部门抢同一个池子。** 勒一个司局里厢看上去专款专用个预算线，往往勒更高层面（开支审查、资本项目）抢同一笔钞票，真正个机会成本是勒搿搭落实个。
- **以为释放出来个人手辰光就呒没进一步个价值。** “省下来”个辰光只有重新调配去做有价值个事体才创造价值；假使呒没替代用途，节省就只是名义上个。
