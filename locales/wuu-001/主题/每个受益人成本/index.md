# 每个受益人成本

每个受益人成本(cost per beneficiary)是项目总成本除以接受过服务个不同个人个数——只要碰到过,勿管伊个境况实际有无改变。伊是一个组织可以最快算出来个效率数字,因为“阿拉服务仔啥人”几乎总归已经勒个案管理系统里向,而“啥人得到仔帮助”通常勿勒。

## 为啥重要

出资方经常要每个受益人成本,理由也站得牢:伊马上就有,勒一批差别交关大个项目当中好比较,而且伊对覆盖面个讲法是老实个,成果声明要更长辰光才好核实,也更容易夸大。英国《慈善机构 SORP》(Statement of Recommended Practice),规范慈善机构勒 FRS 102 下怎样报告,要求受托人年度报告描述对照目标个成就,但是大多数小慈善机构个管理账目还是默认用基于覆盖面个单位成本,因为伊便宜、容易做,审计也友好。

危险勒拿每个受益人成本当作伊回答勿了个问题个答案:钱到底起勿起作用。参见[每个成果成本](../每个成果成本/),了解真正回答搿个问题个指标;参见[成果搭产出](../成果搭产出/),了解底层区别。每个受益人成本是一个正当个分流搭覆盖面指标——伊告诉出资方钱好摊多远——但是低个每个受益人成本,可能意味着真个效率高,也可能意味着服务薄到啥也改变勿了。

## 数学

```
每个受益人成本 = 项目总成本 / 服务个不同个人个数

对比:
每个成果成本   = 项目总成本 / 达成所定义成果个人数

每个受益人成本总归 ≤ 每个成果成本,因为成果人群是受益人群个子集
(经常是一个小个子集)。
```

## 实例演算

**食物银行,搭每个成果成本个例子同一年**:

- 项目总成本:£450,000
- 服务个不同家庭(三次以上食物包):1,800

```
每个受益人成本 = £450,000 / 1,800 = 每服务一户 £250
```

拿两个指标并排比较:

| 指标 | 分母 | 结果 |
|---|---|---|
| 每个受益人成本 | 1,800 户被服务 | £250 |
| 每个成果成本 | 630 户达到食物安全 | £714 |

光看到 £250 个出资方,可能得出结论:搿是一家效率交关高个慈善机构。看到两个数字个出资方,可以问更有用个问题:覆盖面(1,800)搭成果(630)之间个差距,是数据收集个差距、设计个差距,还是老实反映仔光靠食物援助要达到食物安全有多难?

**职业培训慈善机构,示意**:每个受益人成本(已报名)= £2,000;每个成果成本(6 个月持续就业)= £11,000,因为只有 18% 个报名者完成项目并且寻着持续个工作。两个数字相差五倍,勒完成率或者持久率低个地方是常见个——培训慈善机构搭食物银行勒搿搭结构上是一样个。

## 搭软件工程个关联

每个受益人成本是非营利软件里个默认指标,因为伊是从受益人记录里勿用再多做啥就掉出来个指标:建一个个案,记一次服务,数行数。要建一个同时支持每个成果成本个系统,意味着有意加第二个一等实体——一个成果事件,日期搭定义侪独立于服务交付——而且抵制让“个案关闭”代替“成果达成”个诱惑。给补助管理或者 CRM 平台划范围个辰光,要问每个仪表盘实际显示个是两个指标里个哪一个,并且照实标注;勒一个“影响”卡片里拿两样混勒一道,是下面搿些坑勒软件层面最常见个原因之一。参见[单位成本数据库](../单位成本数据库/),了解两个指标标注正确以后做基准对比。

## 容易踏个坑

- **拿每个受益人成本当影响来呈现。** 伊量个是覆盖面,勿是改变。仪表盘搭报告要标“每服务一人个成本”,勿是“每帮助一人个成本”。
- **跨项目重复计数。** 同一家慈善机构既给食物包又给债务建议个一个人,如果分母要描述个是不同个人个覆盖面,就是一个受益人,勿是两个;要决定并且记录用个是哪种惯例。
- **以为数字越低总归越好。** 一个临时午餐俱乐部,每个受益人成本总归胜过密集个案管理服务,因为轻轻碰一下人成本更低。搿讲勿出来每镑钱哪一种产生更持久个改变。
- **勒各份报告之间悄悄换分母。** 一个每个受益人成本数字,今年年报对“已报名”,明年对“已完成”,两年之间勿好比;每次侪要讲明分母。
