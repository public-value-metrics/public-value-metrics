# 政府个成本效益分析(成本效果分析)

成本效果分析(cost-effectiveness analysis,CEA)比较个是达到*同一个*成果个各种办法个成本,成果用自然单位表示——每个安置个露宿者个成本、每个达到预期水平个学生个成本、每减排一吨 CO2 个成本——勿拿成果本身折算成钱。

## 为啥重要

《绿皮书》拿 CEA 当作兜底办法:[社会成本收益分析](../社会成本效益分析/)要求拿每项收益货币化,当搿个要求勿光是困难,而且变得勿老实个辰光——给成果定一个靠得牢个价格,要依靠无人真个相信个假设(<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>,第 5 章,讲成果勿容易货币化个方案评估)。CEA 是最直接从卫生经济学借来个办法——结构上搭 NICE 用每质量调整生命年(Quality-Adjusted Life Year)成本比较治疗个办法完全一样——但是用勒非卫生公共项目上:教育干预按每个学生成果分数,住房项目按每个防止无家可归个家庭,就业项目按每个持续就业成果。

CEA 能够搭 SCBA 并排占一席之地,而勿是被伊吞并,理由是:硬拿一个货币价值套勒某些成果上,得出个数字精确到看上去有权威,又争议到勒公共辩论里毫无价值——给“一个达到预期阅读水平个小囡”定价,正好招来会勒专责委员会上拖垮一份业务案例个那种质疑。CEA 绕开搿场争论,办法是拒绝参加:伊按*成果本身*每单位个成本给方案排序,至于搿个成果到底值勿值得追求,搿个单独个政治判断留给战略案例。

## 数学

```
成本效果比(平均)= 总成本 / 达成个成果单位总数

增量成本效果比(ICER),方案 A 对比方案 B:
ICER = (成本_A − 成本_B) / (成果_A − 成果_B)

步骤:
1. 勒所有被比较个方案之间,固定成果单位搭测量办法。
2. 每个方案按同一口径算成本(参见 ../green-book-appraisal/,财务案例),
   用同一个时间跨度。
3. 剔除被支配个方案:任何每单位成本比一个更便宜个
   替代方案高、成果又勿比伊好个方案,统统剔除。
4. 剩下个方案按增量(勿是平均)成本效果比排序。
```

CEA 本身勿能讲一个项目到底值勿值得出资——只好讲达成同一个目标个几种办法里哪一种每单位最便宜。要判断目标本身值勿值得花搿笔钱,要么折回 SCBA(如果有靠得牢个估值),要么靠数学以外个政治/战略判断。成果真个无法归结成一个单位个辰光——因为一个项目产生几种以勿同方式要紧个成果——就改用[多准则决策分析](../多准则决策分析/)。

## 实例演算

**地方政府**:一个议会比较三种减少露宿个办法,每种按一年成本算,成果定义是“个人搬进稳定住所满 6 个月以上”:

```
方案                            成本       达成成果   平均 CER
Housing First(密集型)          £900,000   60         £15,000/成果
收容所 + 迁出支持                £600,000   50         £12,000/成果
外展 + 私人租赁住房              £350,000   20         £17,500/成果

ICER,收容所对外展:(600k−350k)/(50−20) = 每多一个成果 £8,333
ICER,Housing First 对收容所:(900k−600k)/(60−50) = 每多一个成果 £30,000
```

按平均成本,外展被收容所支配,但是从外展到收容所个*增量*一步,每多安置一个人只要 £8,333——比 Housing First 搿一步便宜,后者勒收容所已经达成个之上,每多一个人要 £30,000。预算受限、要扩大规模个议会应该先扩收容所,再考虑 Housing First,哪怕 Housing First 按自己个平均比率看上去更好。

**国家政府**:一个识字补习项目按“每个达到年龄预期阅读水平个学生成本”,比较三种交付模式:一对一辅导(£1,800/学生)、小组辅导(£700/学生)、纯数字干预(£150/学生,但是按参与度流失调整以后,每个报名学生个成果率只有小组辅导个 40%)。按实际完成情况调整以后,纯数字干预每个达标学生是 £375——还是最便宜,但是 CEA 讲勿出来:如果纯数字干预搭小组辅导用同样预算,受帮助个学生绝对数更少个话,搿个换法搭覆盖更少人但是更深入搿样比,到底可勿可以接受;搿是 CEA 交还给决策者个分配判断。

## 搭软件工程个关联

只要工程团队评估*同一个*服务成果个交付办法,CEA 就是合适个框架——三个身份核验供应商之间每个成功核验个身份个成本、两种个案自动化设计之间每个正确分流个个案个成本、内部搭外包整改之间每解决一个无障碍缺陷个成本。伊直接带进来个规矩:比较成本之前先定义成果单位(勿是“关闭个工单”——搿是产出——而是“真正解决个用户需求”),而且总归计算现有系统搭拟议替换系统之间个增量比,勿是孤立地看各个系统个平均成本。参见[成果搭产出](../成果搭产出/)搭[每个成果成本](../每个成果成本/)。

## 容易踏个坑

- **决定扩张个辰光比平均比率,勿比增量比率。** 像露宿例子显示个,平均比率最好个方案,勿一定是下一个单位成果最便宜个买法。
- **选个成果单位其实是产出。** “做仔个转介”或者“交付个场次”量个是活动,勿是项目为之存在个成果;对产出做 CEA,得出一个看上去有把握个数字,回答个是错个问题。
- **勒真正勿同个成果之间比较。** 只有当每个方案瞄准同一个成果、用同一个办法测量,CEA 才有效;拿“每个安置个露宿者成本”搭“每个稳定租住个离开照护青年成本”比,需要一个通用成果量度或者[多准则决策分析](../多准则决策分析/),勿是 CEA。
- **忽略成果个持久性。** 一个更便宜但是成果勿持久个方案(干预结束以后学生退步),一旦拿可比个期限测量,实际上勿更有成本效果;被比较个方案之间,跟进期要对齐。
