# 陈述偏好估值

陈述偏好方法,通过直接问人家愿意为一样物事付多少钞票,或者愿意接受多少补偿来放弃伊,来估算非市场物品个价值,通常用一份描述假设场景个结构化调查。条件估值是搿个家族里最有名个技术。

## 为啥重要

《绿皮书》附录 2(关于非市场影响估值个补充指引)赞同拿陈述偏好方法用辣根本呒没可观察市场交易可以推断价值个物品上 — 空气质量、生物多样性、防洪保护、某个人可能永远勿会去看个风景个存在价值(<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>)。环境、食品与农村事务部(Defra)专门发布仔自家个环境评估陈述偏好指引,因为大量环境价值(栖息地保护、水质)根本呒没替代市场,勿像噪音,至少搭可观察个房价有关(见[显示偏好估值](../显示偏好估值/))。

陈述偏好个核心吸引力 — 伊可以拿真真正正任何物事估值,包括从来呒人交易过个物品 — 也是伊可信度问题个来源。因为受访者并勿是真个辣花钞票,条件估值调查容易受到假设性偏差(人辣呒没真实预算约束个辰光夸大支付意愿)、嵌入效应(同一样物品,依据调查里还有啥别个物事,估值勿同),搭竞价游戏设计里个起点偏差影响。1993 年辣埃克森·瓦尔迪兹号漏油诉讼之后召集个 NOAA 条件估值专家组,定出仔设计标准 — 用二元个"侬愿意付 £X 伐,愿意/勿愿意"公投格式,而勿是开放式竞价,而且强制提醒受访者个实际预算约束 — 到现辣还是站得住脚个调查个参考标准。

## 数学

```
条件估值(公投格式):
  提出二元选择:"侬愿意每年付 £X 来换取成果 Y 伐?愿意/勿愿意"
  X 辣受访者之间随机变化。
  拿支付意愿拟合成各个 X 上"愿意/勿愿意"回答比例个函数。

平均 WTP = 估计需求曲线下面个面积
总价值 = 平均 WTP × 受影响人口

选择实验(离散选择建模)变体:
  拿属性组合(包括一个成本属性)之间个反复选择提拨受访者,
  根据受访者显示出来个取舍,估算每一个非成本属性个隐含价格。
```

选择实验变体,辣现行英国实践里一般比单问题条件估值更受欢迎,因为强制受访者反复拿几个属性搭成本相权衡,比单一个"愿意/勿愿意"问题产生更内部一致、更难以操纵个估计。

## 实例演算

**中央政府**:Defra 委托一项条件估值调查,为一个河流水质改善项目估值。一份对 2,000 户家庭做个公投格式调查发现,62% 愿意通过一项假设个水费附加每年付 £40,估计出来个需求曲线给出每户平均支付意愿每年 £28。

```
平均 WTP = £28/户/年
集水区户数 = 340,000
年总价值 = £28 × 340,000 = £9.52m/年

辣 20 年评估期、3.5% 贴现率下(年金系数 ≈ 14.2):
PV(效益) ≈ £9.52m × 14.2 ≈ £135m
```

然后拿搿个总数搭项目个[社会成本效益分析](../社会成本效益分析/)成本一侧相比较。《绿皮书》要求此类陈述偏好证据搭置信区间搭调查方法一道报告,勿是光秃秃个点估计,恰恰因为底层数字比市场价格更脆弱。

**慈善机构**:一个遗产信托调查参观者搭勿参观者,问伊拉为防止一幢历史建筑关闭愿意付多少(两类人勿一定去过搿幢建筑,也就是伊个存在价值)。因为永远勿会看到搿幢建筑个勿参观者仍然报告正个 WTP,调查抓到仔存在价值搭遗赠价值,而光数参观者门票收入(一个显示偏好替代指标)就会完全漏脱 — 说明辣呒没任何市场交易可以显示价值个地方,陈述偏好个真正优势。

## 搭软件工程个关联

陈述偏好方法难得直接用辣软件工程工作上,但是搭建市民咨询平台、预算参与工具或者公共调查基础设施个工程师,常常辣搭建经济学依赖个工具。拿调查设计细节做对 — 随机化个出价金额、二元公投框架而勿是开放式问题、明确个预算约束提醒 — 勿是用户体验上个讲究,而是让估值经得起审查个关键;一份设计勿好个应用内调查,可以让后面几个月个经济分析作废。更一般地,关于要承担分析重量个公众意见数据个获取规矩,见[市民满意度指标](../市民满意度指标/)。

## 容易踏个坑

- **开放式个"侬愿意付多少?"问题。** 搿种问题比二元公投框架更容易有策略性偏差搭锚定偏差;NOAA 专家组建议用公投格式,就是因为开放式引出表现勿好。
- **勿提醒受访者个实际预算约束。** 呒没搿个,陈述个 WTP 常常超过同样个人辣真正有预算取舍个辰光会付个数 — 假设性偏差。
- **忽视嵌入效应。** 同一样物品单独估值搭作为更大个组合一部分估值,会产生勿同个 WTP 估计;要报告调查框架里还有啥别个(如果有)。
- **拿单次调查个点估计当作定论。** 《绿皮书》个做法期望给出一个区间搭对已知偏差个讨论,勿是光秃秃一个数字,像市场价格那样被带到成本效益表里。
