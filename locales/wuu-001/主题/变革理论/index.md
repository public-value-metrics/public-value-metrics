# 变革理论

变革理论是一条明确个、从后往前梳理个因果路径:从长期目标出发,到实现伊所必须具备个前提条件搭活动,并且标明连接每一环个假设。构建个办法是从侬想要个成果开始,反复问"为仔让伊发生,紧挨辣伊前头必须是啥情况?",一直问到侬实际可以交付个活动 — 搿搭[逻辑模型](../逻辑模型/)个方向正好相反,所以两样是互补个,勿是可以互相替代个。

## 为啥重要

倒推个方法,由变革理论中心(Center for Theory of Change)搭 ActKnowledge 正式化,建立辣评估学者卡罗尔·韦斯(Carol Weiss)关于拿项目假设明确讲出来、让伊拉可以被检验而勿是凭信仰接受个工作上。英国个资助评估直接吸收仔搿套做法:英国财政部个《品红皮书》(Magenta Book)拿变革理论当作任何评估设计个起点,国家彩票社区基金(National Lottery Community Fund)搿样个出资方要求申请人先阐明一个,才会资助提案。搿对软件工程师要紧个原因是,变革理论是应该决定侬个系统需要衡量啥个文件 — 如果因果链上写"福利申领个参与度取决于申领人收到个性化个计算结果",搿就是侬个产品可以埋点来取证或者反驳个可检验主张。

## 数学

变革理论是结构性个,勿是数字性个。每一环应该既带一个假设,又带一个可以表明假设为假个指标:

```
长期成果(目标)
  ↑ 前提条件 + 假设 + 指标
中间成果 N
  ↑ 前提条件 + 假设 + 指标
  ...
中间成果 1
  ↑ 前提条件 + 假设 + 指标
活动 / 干预措施
  ↑ 投入个资源
投入
```

搿个结构直接输入[影响评估方法](../影响评估方法/),后者就是为仔检验每一环个假设是否真个成立;也输入[反事实分析](../反事实分析/),后者检验长期成果是否勿做也会发生。

## 实例演算

**地方政府(预防无家可归)**:长期成果是面临驱逐风险个家庭 12 个月之后保持稳定租约。

- 前提条件:家庭有一个现实、负担得起个欠租偿还计划。
  假设:个案工作者协商个计划比法院裁定个更可持续。
  指标:6 个月之后仍然有效个计划占个百分比。
- 前提条件:家庭申领伊拉有权享受个福利。
  假设:数字福利计算器搭纸质表格相比,可以提高正确申领率。
  指标:申领准确率,工具推出前后对比。
- 活动:个案工作者分流、数字福利计算器、欠租协商。

辣一批 120 户家庭个试点队列里,福利计算器个假设对 102 户(85%)成立,伊拉后来正确申领仔,有后续个过程评估佐证 — 拨项目团队就搿一环拿到证据,而勿是一个关于"预防仔多少无家可归"个端到端笼统主张。

**慈善机构(青少年辅导)**:长期成果是减少学校开除。倒推出来个前提条件:改善个情绪调节 → 搭辅导员建立受信任个一对一关系 → 两个学期里每周持续接触。搿套理论明确点出,如果缺脱"每周持续接触"搿个前提条件(比方因为辅导员流动),预计成果就勿会随之而来,搿是一个可检验、可证伪个主张,勿是一种希望。

## 搭软件工程个关联

变革理论应该辣做出任何一个仪表盘之前,就塑造产品个数据模型:确定哪几环需要指标,专门针对搿些埋点,而勿是默认记录最容易记个物事。伊也规范路线图个讨论 — 一个对应勿到链条上任何一环个功能,显然勿值得做。理论达成一致之后搭建个、朝前看个问责链条见[逻辑模型](../逻辑模型/),依赖变革理论来划定要估值哪些成果个方法见[社会投资回报率](../社会投资回报率/),中间成果各环所依赖个区别见[成果搭产出](../成果搭产出/)。

## 容易踏个坑

- **搭逻辑模型搞混。** 变革理论是因果性、解释性个(阿拉为啥相信搿个有效);逻辑模型是顺序性、描述性个(啥个事体按啥个顺序发生)。只做一个,要么缺脱"为啥",要么缺脱问责轨迹。
- **假设勿讲明白。** 倒推个全部价值就是拿可检验个假设摆到台面上;一个只列方框搭箭头、勿点出啥会让每一环为假个变革理论,只是摆设。
- **做一次就束之高阁。** 为资助申请写个变革理论,从来勿再回头看,证据一开始搭某一环矛盾,伊就用勿着仔。
- **跳过利益相关方个意见。** 完全由委托方、勿听一线员工或者受益人意见建立个变革理论,常常编码仔一些实际提供服务个人谁也勿相信个假设。
