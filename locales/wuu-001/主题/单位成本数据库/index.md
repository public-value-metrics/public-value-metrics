# 单位成本数据库

单位成本数据库,是一个事先研究好个、有证据支撑个社会成果财务替代指标库 — 从失业到就业个价值、孤独感减轻个价值、稳定租约个价值 — 让从业者勿用每趟侪委托专门个估值研究,就可以拿成果货币化。伊拉存辣个意义是,让一家写资助申请个小慈善机构,可以达到搭资源充足个咨询公司一样个严谨度,办法是重复使用别人已经推导并且发布个替代指标。

## 为啥重要

HACT 个英国社会价值银行(UK Social Value Bank)由经济学家丹尼尔·藤原(Daniel Fujiwara)用福祉估值方法开发,Global Value Exchange 是一个开放、众包个财务替代指标数据库,两个是英国第三部门搭公共部门里使用最广泛个。两个存辣,是因为底层个估值工作 — [福祉估值](../福祉估值/)搭[陈述偏好估值](../陈述偏好估值/) — 代价昂贵、方法上要求高、而且每个项目侪从零开始做太慢。一个共享、公开发布个替代指标库,拿本来要几个月个研究工作变成一次查询,所以对[社会投资回报率](../社会投资回报率/)个计算搭[《社会价值法》](../社会价值法/)个投标评估侪要紧:呒没伊拉,严谨个货币化只有大到可以委托自家研究个机构才负担得起。

## 数学

单位成本数据库本身勿计算任何物事;伊为辣别处完成个计算提供一个输入:

```
财务替代指标值 = 市场价格,或者影子价格,或者福祉估值,
                 或者陈述偏好值
                 对应一个明确定义个成果变化单位
                 (比方"每人每年从失业转为就业")

应用价值 = 实现个成果数量 × 单位替代指标值
```

呒没市场价格个辰光替代指标哪能构造,见[影子价格](../影子价格/);应用价值之后哪能经过无谓损失搭归因调整,输入一个比率,见[社会投资回报率](../社会投资回报率/)。

## 实例演算

**慈善机构(结对陪伴服务 SROI)**:单位成本数据库里"减轻孤独感"个条目,给出一个示意性个替代指标,每人每年 £1,100。应用到 80 个受益人:80 × £1,100 = £88,000 总价值。如果同一个数据库里还有一个"改善心理福祉"个替代指标,用个是重叠个福祉调查题项,拿两个替代指标叠加辣同样 80 个人身上,会重复计算同一个底层变化个一部分 — 数据库提供数字,但是避免搿种重叠是分析人员个责任。

**地方政府(求职俱乐部 SROI)**:数据库里"从失业转为稳定就业"个条目,按示意性个替代指标每人每年 £8,500,应用到 45 个参与者:45 × £8,500 = £382,500 总价值,还没经过[社会投资回报率](../社会投资回报率/)里展示个无谓损失搭归因调整。

## 搭软件工程个关联

为慈善机构或者委托方搭建报告工具个团队,受益于一份内部个"成果目录" — 一张表,拿一个产品或者服务可以合理主张个每一个成果,对应到一个命名个替代指标、伊个来源数据库、发布日期搭一个版本标识 — 让一个机构里勿同个团队,勿要对同一个成果各自选略有勿同个数值。拿 Global Value Exchange 个开放数据包装辣一个查询服务后头,数字旁边永远显示来源搭日期,让替代指标保持可审计,勿是埋辣电子表格里个一个神奇数字。搿些替代指标被使用个两个主要地方,见[社会投资回报率](../社会投资回报率/)搭[《社会价值法》](../社会价值法/)。

## 容易踏个坑

- **拿替代指标当作精确个。** 大部分公布个替代指标是来自福祉估值研究个模型化平均值,置信区间老宽;精确到一镑来引用,夸大仔底层研究所能支撑个精度。
- **重复计算重叠个替代指标。** 拿从重叠个调查构念推导出来个替代指标(比方"减轻孤独感"搭"改善心理福祉")组合起来,会拿同一个底层变化估值两次。
- **勿经调整就用脱离情境个替代指标。** 一个依据某一国家人口搭年份校准个替代指标,勿经通胀或者情境调整就用到别处,会悄悄拿价值说错。
- **勿检查出处。** Global Value Exchange 是开放、众包个,所以条目质量因贡献者而异;辣资助申请或者采购提交材料里引用一个数字之前,要检查底层来源。
