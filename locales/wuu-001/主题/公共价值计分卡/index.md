# 公共价值计分卡

公共价值计分卡拿 Robert Kaplan 搭 David Norton 1992 年提出个平衡计分卡改编过来——原来是为企业设计个，勒财务、客户、内部流程、学习与成长四个视角上优化利润——现在用勒底线是使命而勿是利润率个机构。伊逼公共机构同时勒好几个勿可压缩个维度上汇报绩效，而勿是拿一切折成一个数字，拿权衡取舍藏起来。

## 为啥重要

Kaplan 搭 Norton 勒《哈佛商业评论》里厢个原始论点是：单个财务指标是滞后指标，伊勿会告诉侬下一季度个绩效*为啥*会变。私营部门个解法是四个相互关联个视角。勒政府里厢，Mark Moore 个“战略三角”（出自《Creating Public Value》，1995）提供了对应个结构：一项服务必须同时交付**公共价值**（使命成果）、维持**合法性搭支持**（政治搭公众个支持）、并且**运营上可行**（凭实际有个资源搭能力交付得了）。Paul Niven 个《Balanced Scorecard: Step-by-Step for Government and Nonprofit Agencies》（2003）是拿 Kaplan 搭 Norton 个四个格子翻译成搿个三角个实践手册——通常是拿“财务”重新标成“资源个管家责任”，拿“使命”放勒顶上而勿是拿“股东价值”放勒底下，并且拿客户搭利益相关方视角看作平等个，而勿是附属于利润。对交付团队来讲，搿个要紧，是因为一项只用财务或者效率指标（比如单笔交易成本）来评判个公共数字服务，会系统性地对合法性搭成果维度投入不足，而搿些维度是财务指标看勿见个。

## 数学

公共价值计分卡是个框架，勿是公式，但是伊个结构是固定个，值得原样重现：

```
Perspective          Public-sector question                    Example indicator
--------------------------------------------------------------------------------
Mission / outcomes    Are we achieving the public value we      Population outcome measure
                       exist to create?                         (see outcomes-vs-outputs)
Stewardship of        Are we using public money efficiently     Cost per outcome, budget
  resources            and within authorized limits?             variance
Customer / user        Are users and citizens able to access    Completion rate, satisfaction
                        and benefit from the service?
Legitimacy / support    Do political principals, oversight       Trust metrics, audit findings,
                        bodies, and the public still back us?    complaints upheld
Internal process /      Do we have the capability and process   Staff turnover, cycle time,
  learning              to keep improving?                       backlog age

A defensible scorecard reports 3–5 indicators per perspective, chosen so that
no single perspective can be gamed without the damage showing up in another.
```

## 实例演算

**地方政府成人社会照护部门**：一项康复促进服务（短期支持，帮助人拉住院之后恢复自理能力）个计分卡汇报：

```
Mission:       68% of service users no longer need ongoing care after 6 weeks (target 65%)
Stewardship:   cost per completed reablement episode = £1,850 (budget assumption £2,000)
Customer:      user satisfaction 82%, average wait for service start 4.1 days
Legitimacy:    3 upheld complaints per 1,000 episodes; adult safeguarding board rates
               service "good"
Process:       staff vacancy rate 14%, average caseload 23 (safe caseload ceiling: 25)
```

单独看，使命搭资源管家两栏个数字像是一个直截了当个成功故事：低于预算、高于成果目标。搭流程一行一道看，14% 个空缺率对 25 个个案量上限，说明好个成果是靠接近勿安全个人手水平换来个——搿个警告，单看使命数字永远发现勿了，恰恰是单一视角 KPI（参见[公共部门 KPI](../公共部门个关键绩效指标/)）招来个失效模式。

## 搭软件工程个关联

对一个做内部或者面向公众仪表盘个团队来讲，计分卡直接反对做一个单一个“健康分”组件：每个视角一块面板，勿要顶着产品压力拿伊拉综合成一盏红绿灯，因为综合个步骤恰恰是权衡信息被毁脱个地方。伊也可以清清爽爽对应产品团队个 OKR 结构：一个使命 OKR 倘使呒没配对个资源管家或者流程 OKR，就重现了 Kaplan 搭 Norton 1992 年写文章时反对个单一指标失效模式。参见[公共价值](../公共价值/)了解 Moore 关于“使命”一格到底该装啥个底层理论，参见[信任搭合法性指标](../信任搭合法性指标/)了解怎样用真实、有出处个指标，而勿是一个呒没人辩护得了个代理指标，来填充合法性视角。

## 容易踏个坑

- **拿计分卡压成一个分数**：拿四个视角平均成一个数字，就重新带回了计分卡本来要防止个问题——差个合法性得分被好个资源管家得分掩盖。
- **原封勿动照搬私营部门个“财务”视角**：公共机构个资源管家视角讲个是守勒授权个、往往专款专用个预算之内，而勿是收入最大化——Niven 个重新标注勿只是表面功夫。
- **选了拥有计分卡个团队自己就能单方面拨动个指标**：合法性指标倘使来自伊所评判个同一个团队（比如自我汇报个投诉处理），就勿是独立个证据。
- **计分卡做一次就再勿重新审视权重搭指标**：Kaplan 搭 Norton 本意是每年做一次战略审视；一张冻结好几年个计分卡，会渐渐偏离伊本来要追踪个使命。
