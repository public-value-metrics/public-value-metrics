# 影子价格

影子价格,是拨一样呒没可观察市场价格、或者市场价格被扭曲而勿能反映真实社会价值个物品、资源或者外部性估算出来个价值。政府评估靠一小套官方影子价格 — 碳、非工作辰光、失业劳动力 — 由中央统一发布,让每个部门用同一个数字。

## 为啥重要

之所以有影子价格,是因为[社会成本效益分析](../社会成本效益分析/)必须拨每一项成本搭效益侪配一个货币价值,而最要紧个几样 — 排放一吨碳、通勤者一个钟头个辰光、本来要失业个劳动力干一个钟头 — 要么根本呒没市场价格,要么市场价格勿能反映伊拉真实个社会成本。英国财政部搭能源安全与净零排放部联合发布全英国政府评估通用个碳影子价格(<https://www.gov.uk/government/publications/valuing-greenhouse-gas-emissions-in-policy-appraisal>),伊勿是从任何碳市场价格里得出来个,而是用目标一致法:碳价设定辣为仔达到英国法定碳预算所需个边际减排成本,搿搭观察碳辣欧盟或者英国排放交易体系里实际卖啥价钿,逻辑完全勿同。

影子工资率辣劳动力一头也是类似个逻辑。雇用一个本来要失业个人,勿等于社会付出伊全部个工资 — 工资里一部分是原来福利金搭放弃个闲暇/求职辰光转移过来个,勿是对社会资源个净新增占用 — 所以《绿皮书》指引拨从失业中吸收个劳动力定了一个低于市场工资个影子价格,反映搿种劳动力真实个机会成本(见[公共支出里个机会成本](../公共开支里厢个机会成本/)),而勿是伊个市场价格。

## 数学

```
碳个影子价格(结构示意,现行数值请看官方 BEIS/DESNZ 碳价值工具,
勿要用过期个数字):
  贸易部门价值:参考 ETS 配额价格走势
  非贸易部门(目标一致)价值:设定为达到法定碳预算所需个
    边际减排成本,随辰光上升,因为容易个减排选项会用完
  应用方式:£/吨 CO2e × 方案排放或者减排个吨数,
    未来年份按社会贴现率贴现

影子工资率(SWR):
  SWR = 市场工资 −(节省下来个闲暇/求职辰光个价值
                    + 勿再支付个福利金价值)
  通常表示为市场工资个一个比例(比如辣高失业率地区
    SWR = 0.6 × 市场工资,依据《绿皮书》附录 A 关于
    有闲置产能个劳动力市场个指引)
```

搿两个数字侪是中央设定个政策惯例,勿是对市场个经验观察 — 影子价格个全部意义,就是替代缺失或者被扭曲个市场,所以用到伊个评估必须引用现行官方来源,勿好自家推导数字,恰恰是为仔让每个部门个评估可以互相比较。

## 实例演算

**中央政府**:一个防洪方案个评估估计,搭"最低限度作为"个基线比起来,每年可以避免 400 吨 CO2e 排放(因为少用应急设备,搭避免重建而减少隐含碳),评估期 30 年。

```
碳影子价格(示意):£280/吨 CO2e(第 1 年,按官方非贸易碳价值
  时间表辣评估期内逐年上升)
第 1 年碳效益 = 400 × £280 = £112,000
```

因为官方时间表里碳价值辣评估期里是*上升*个(反映碳预算越收越紧),分析人员必须对 30 年个每一年用对应年份个数值,勿能用固定税率 — 全程用第 1 年个数值,会低估后头年份个效益,搭碳排放曲线勿同个其他防洪设计比起来,排名也会被扭曲。

**地方政府**:一个市议会为长期失业居民做个就业扶持项目,拿 150 个人安排到时薪 £11 个工作上。如果用全额市场工资来估值,会拿 £11 × 工作辰光算成项目个社会效益,但是影子工资率个做法认为,搿些人勿是从别个工作里挖过来个 — 项目之前伊拉劳动力个真实机会成本是低个。

```
市场工资:£11.00/小时
影子工资率(示意,本地失业率高):0.6 × 市场工资 = £6.60/小时
每工作一小时个净社会效益 ≈ £11.00 − £6.60 = £4.40/小时
  (拿真正闲置个劳动力转入生产所创造个"额外"价值,
   搭工资本身是两回事,工资大部分是转移支付)
```

搿就是为啥辣高失业率地区,就业项目个评估可以显示正个净社会价值,而同样个项目辣充分就业地区,被替代个劳动力只是从别个工作里抽过来,就做勿到搿点。

## 搭软件工程个关联

影子价格难得直接碰着软件交付,但是只要商业方案声称某个 IT 变更带来碳效益或者社会效益,伊就要紧了 — 数据中心整合声称节省碳排放,或者无纸化服务声称避免印刷搭邮寄个碳排放,必须用现行官方碳影子价格,勿能自家编个数字,而且必须逐年照时间表,勿能用固定税率,搭其他任何《绿皮书》评估输入一样。参见[政府 IT 里个总拥有成本](../政府-it-里个总拥有成本/)搭[公共部门网络安全个价值](../公共部门网络安全个价值/),两篇里常常需要拨难以货币化个输入(泄露风险、停机辰光)配一个影子价格,搭直接核算个成本项并列。

## 容易踏个坑

- **用过期个碳价或者工资数字。** 两个数值侪由中央指引定期修订;建立辣被取代个数字上个评估,经勿起财政部个审查。
- **辣几十年个评估期里用固定个碳影子价格。** 官方时间表是逐年上升个;全程用第 1 年个数值,会拿效益或者成本个曲线搞错。
- **拿影子工资搭对工人实际工资个折扣搞混。** 影子工资率调整个是*评估*对劳动力投入个估值,勿是工人实际拿到个工资 — 搿两样混淆起来,会(错误地)为低于市场个工资辩护。
- **勿用官方价格,自家推导一个专门个影子价格。** 影子价格是政策惯例,目个就是让各部门个评估可以比较;本地自创个数字,哪怕推理得再好,也会破坏搿种可比性。
