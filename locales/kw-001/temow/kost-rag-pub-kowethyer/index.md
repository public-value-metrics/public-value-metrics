# Kost rag Pub Kowethyer

Kost rag pub kowethyer yw kost hollek an towlen rannys dre niver an bobel unnik a dhegemmeras servis — pynag dhe'n re a veu tuchys, hedna a vynn gwari ha dhe'n pyth a dreylyas aga kyfeyth yn gwir. Hi yw an niver effeythyans skonnya a yll organyzasyon kreas, drefen bos "piw a servyn ni" kyns yn kas yn system maner kasow, hag "piw a veu gweresys" nyns yw yn kemmyn.

## Perag y talvos

Arghansoryon a wovyn kost rag pub kowethyer yn pub-prys, ha rag skilyow defendyadow: yw dhe-les yn skon, yw keskomparadow dres portfolio a dowlennow pur dihaval, hag yw onest a-dro dhe dhrehedh yn fordh na yw hawlow sewyans — a gemmer termyn hirra dhe wiriya hag yw es dhe overstatya. Charities SORP an Rywvaneth Unys (Statement of Recommended Practice), a rewl fatel wra kharitys rapportya herwydh FRS 102, a erghy dhe rapportow bledhenyek an fydhyoryon dhe dhysplegya dhrehedhans erbyn pennow, mes lies kharite byghan a'n jeves hweth kostow unyans herwydh dhrehedh yn aga akontow maner drefen y vos sempel dhe grea ha da dhe awdyt.

An peryl yw trettya kost rag pub kowethyer avel pe worthypa an govynn na yll gorthyp: mar tel an arghans. Gwelewgh [kost rag pub sewyans](../kost-rag-pub-sewyans/) rag an metrik a worthyp yn gwir, ha [sewyansow erbyn askorrow](../sewyansow-erbynn-dyllyansow/) rag an dhispartyans a-dhelergh. Kost rag pub kowethyer yw metrik triage ha dhrehedh dewisadow — hi a wra godhvos dhe arghansor fatel hys a ystyn an arghans — mes kost isel rag pub kowethyer a yll styrya po effeythyans gwir po servis mar gwann na dreyl tra vyth.

## An matematik

```
Kost rag pub kowethyer = Kost hollek an towlen / Niver a dus unnik servys

Kontrast:
Kost rag pub sewyans   = Kost hollek an towlen / Niver a dus a dhrehedhas an sewyans dyffynys

Kost rag pub kowethyer yw pub-prys ≤ kost rag pub sewyans, drefen bos an poblans sewyans
isel-sed (yn aswonnys bian) a'n poblans kowethyer.
```

## Ensampel oberys

**Bank bwyd, an keth bledhen avel ensampel kost-rag-sewyans**:

- Kost hollek an towlen: £450,000
- Teylyow unnik servys (tri-plus parsel): 1,800

```
Kost rag pub kowethyer = £450,000 / 1,800 = £250 rag pub teylu servys
```

Keskomparewgh an dhew vetrik ryb y gila:

| Metrik | Hanow-ranner | Sewyans |
|---|---|---|
| Kost rag pub kowethyer | 1,800 teylu servys | £250 |
| Kost rag pub sewyans | 630 teylu a dhrehedhas diogeledh bwyd | £714 |

Arghansor na wel marnas £250 a yll konkludya bos kharite pur effeythus. Arghansor a wel an dhew niver a yll govynn an govynn moy bryntyn: yw an skell ynter dhrehedh (1,800) ha sewyans (630) skell kuntell data, skell dhesein, po gwiryans onest a'n kaletter a dhrehedha diogeledh bwyd dre weres bwyd hepken?

**Kharite dyskans gweythysans, dhiskwedhek**: kost rag pub kowethyer (ynskrifys) = £2,000; kost rag pub sewyans (gweythysans parys orth 6 mis) = £11,000, drefen bos hepken 18% a'n ynskrifyoryon ow kowlwul an towlen ha kavos gweyth parys. An dhew niver ow dhiverya dre faktour a bymp yw kemmyn pub le may fo skeulyow kowlwiryans po durabilita isel — kharite dyskans ha bank bwyd yw strokturel kehaval omma.

## Kevrenn gans ynjynnerieth medhelweyth

Kost rag pub kowethyer yw an metrik dre dhefowt yn medhelweyth nonprofit drefen bos an metrik a dheu yn skon dhiworth rekord kowethyer heb ober ynwedh: krea kas, logya servis, kyfrifa rowyow. Byldya system a skoodh ynwedh kost rag pub sewyans a styr ynwedh dre zesein dhe ynkressya a'n nessa antiti kynsa-klas — hwarvos sewyans, dedhys ha dyffynys heb dibyn a delivrans servis — ha fyllel a'n temptasyon dhe asa "kas degeys" dhe sevel rag "sewyans dhrehedhys". Pan wrewgh skopya platform maner grant po CRM, govynnewgh pyw a'n dhew vetrik yw pub daskbord ow diskwedhes, ha henwewgh hi herwydh; kemmyska hi yn unn teyl "impakt" yw unn a'n skilyow medhelweyth moyha kemmyn a'n trapow a-woeles. Gwelewgh [bonkow data kost unyans](../ostelyow-kost-an-unnenn/) rag benchmarkya an metrik pan vo henwys yn ewn.

## Trapow

- **Dhiskwedhes kost rag pub kowethyer avel impakt.** Hi a vusur dhrehedh, ha nyns chanj. Henwewgh daskbordow ha rapportow "kost rag pub den servys," ha nyns "kost rag pub den gweresys."
- **Kyfrifa dewblek dres towlennow.** Den ow tegemmeres hweth parselyow bwyd ha kusul dyvyow dhiworth an keth kharite yw unn kowethyer, ha nyns dew, mar pe an hanow-ranner dhe dhesperya dhrehedh unnik; dewisewgh ha dogumentewgh pyw usadow a vo devnydhys.
- **Trettya niver isella avel pub-prys gwell.** Klub kynyow drop-in a wayn pub-prys erbyn servis maner kasow ynkresys war kost rag pub kowethyer, drefen bos le kostys dhe dhuchya nebonan yn skav. Henna ny lever tra vyth a-dro dhe byw a wra chanj moy dewr rag pub puns.
- **Chanjya hanow-rannyer yn tawesek ynter rapportow.** Niver kost rag pub kowethyer dhywedhys y'n unn rapport bledhenyek erbyn "ynskrifys" hag y'n nessa erbyn "kowlwrys" nyns yw keskomparadow bledhen dhe vledhen; leverewgh an hanow-ranner pub-prys.
