# AGENTS.md

Guidance for AI coding agents working in this repository. `CLAUDE.md` points here. Keep this file
under 40 KB; the details live in `spec/`, `skills/`, and `README.md`, and this file only says where.

## What this repo is

*Public Value Metrics*: 64 topics on public-value maths for software engineers, published in 52
locales, plus the SvelteKit site that publishes them.

```
README.md                         categorized index of the 64 topics (links into en-gb-oxendict); also the site's table of contents
locales/<locale>/                 one directory per locale: index.md (Contents page) + the topics directory
locales/<locale>/<topics-dir>/<slug>/{index.md, README.md -> index.md, .locale-peer-id}
bin/                              test, derive-locales, locale-peer-id, grep-locale-peer-id, slug-case, markdown-read-to-headline
spec/                             specifications: single source of truth for behaviour (read before changing behaviour)
skills/                           agent skills: public-value-metrics-skill (use the book), -maintainer-skill (edit it)
public-value-metrics.github.io/   SvelteKit + adapter-static + Lily Design System site, deployed by GitHub Pages
```

## Rules that are easy to get wrong

1. **Canonical content is `locales/en-gb-oxendict/topics/<slug>/index.md`.** `en-gb`, `en-001` and
   `en-us` are derived from it by `sh bin/derive-locales` (never hand-edit them); `cy-001` is a copy
   of `cy-gb` and `zh-cn` a copy of `zh-001`, also via `derive-locales`.
2. **English locales use `topics/` and English slugs. Every other locale translates both the topics
   directory name and each topic slug** into its own language and script (`locales/cs-001/témata/veřejná-hodnota/`).
   A slug is the translated H1 with parentheticals dropped, lower-cased, runs of non-letter/mark/digit
   characters turned into hyphens, native script kept. `.locale-peer-id` (copied verbatim, never edited,
   never shared by two topics) is what ties translated slugs together.
3. **Links between topics are relative `../<slug>/`** and must use that locale's own slugs. Index pages
   link to `locales/<locale>/<topics-dir>/<slug>/` (intro) and `locales/en-gb-oxendict/topics/<slug>/` (entries).
4. **Adding a locale**: scaffold `topics/<english-slug>/` with copied `.locale-peer-id` and a
   `README.md -> index.md` symlink, translate every topic **yourself, one after another, never with
   subagents**, write `index.md`, then translate the paths and register the locale (README count and
   bullet, `src/lib/locales.js`, `src/lib/i18n.js` UI-strings block and mapping). Full procedure:
   `skills/public-value-metrics-maintainer-skill/SKILL.md`.
5. **Do not reword** Green Book / Magenta Book citations such as "Chapter 5"; "chapters" in the book's
   own structure are called topics (groups of topics are parts).
6. `public-value-metrics.github.io/content/` is generated by `node bin/sync-content.mjs` and committed;
   never edit it by hand. Re-sync before committing any change under `locales/` or `README.md`.

## Commands

```sh
sh bin/test                       # structure checks (every locale), link check; exits 1 on failure
bin/check-links                   # relative-link check on its own
bin/translate-paths [--apply] [locale...]   # translate topics dir + slugs of non-English locales
sh bin/derive-locales             # regenerate derived locales (idempotent)
cd public-value-metrics.github.io
pnpm install                      # postinstall copies Lily theme CSS into static/
pnpm run sync                     # book -> content/
pnpm run build                    # vite build + search index + llms.txt/llms.json + sitemap.xml -> build/
```

Before committing locale work: `sh bin/test`, sync, `pnpm run build`, and check that every relative link
resolves (a script that walks `locales/**/index.md` links works well).

## Site notes

- Site URLs are `/<locale>/topics/<slug>/` for every locale. The sync step maps each locale's translated
  topics directory back to `topics/` in `content/`, so routes stay locale-agnostic; slugs are native-script
  (percent-encoded in URLs).
- UI strings live in `src/lib/i18n.js` (one block per locale; do not add `contentsIntro` or
  `topicsCountSubtitle`, which were removed). Labels live in `src/lib/locales.js`.
- The contents page is a plain nested list per `spec/contents-for-global-sharing-with-svelte/index.md`
  (parts "N Title", topics "N.M Title"; no tiles, tables, columns, flexbox or grid).
- `pnpm` 11 holds back packages released in the last day; leave that gate on. `typescript` stays on 6.x
  until `@sveltejs/kit` accepts 7.
